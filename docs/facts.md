# 観測事実と条件の食い違い

既存実験の資料と実装を確認して整理したものです。出典は MolCasta-InternalResearch の各ブランチで、調査の詳細は notes/ の3件にあります。
数値はすべて出典のあるものだけを書いています。出典が食い違う場合は、その旨を書いています。

## 1. 実軌道に指導力があるという測定

### 1-1. 未見100配列の実験（資料A）

- 構成は、凍結した本体モデル T1I2006 に、小さな補正モデル（HistGradientBoosting）を予測幅ごとに付けたものです。
- 入力の実軌道は絶対時刻 0〜1 ns（100 ps 間隔、11フレーム）で固定です。予測の起点は 1 ns、予測幅 1/5/10/30/50/90 ns に対応するラベルの時刻は絶対時刻 2/6/11/31/51/91 ns です。
- 候補は、起点で距離が 3.5〜6.0 Å のドナー・アクセプター重原子ペアです。未来時刻に 3.5 Å 以下になれば陽性という、距離だけのラベルです。
- 履歴の特徴量は10個で、すべて候補ペア自身の距離の時系列から作ります（平均、標準偏差、最小、最大、変化量、3.5 Å 以下・4.5 Å 以下にいたフレームの割合など）。周辺原子の運動は入っていません。
- 補正モデルの学習は別の8タンパク質×3レプリカ、評価は未見100タンパク質×3レプリカです。候補の総数は 163,074 件です。
- 指導力の代表値とされる AUPRC の改善 +0.0712（1 ns 先）は、「初期履歴つき補正モデル − 構造のみ補正モデル」の、タンパク質ごとの差の平均です（95/100 タンパク質で改善、95%区間は約 0.062〜0.080）。90 ns 先では +0.0273（78/100 で改善）です。
- 注意点として、この +0.0712 は本体モデルそのものとの差ではありません。本体そのものと比べると、履歴つき補正モデルの AUPRC の差は候補全体で +0.0364 です（0.49292 → 0.52930）。構造のみの補正モデルは 0.45908 で、本体そのものより低いです。つまり +0.0712 の一部は、補正モデルの形にしたことで下がった分を取り戻した分を含みます。
- 他の指標も改善しています（1 ns 先で AUC +0.0119、Brier +0.0028、Log Loss +0.0092。いずれも差の向きは改善側）。
- 外部の配列への外挿では改善が安定せず、悪化する点もあります（Fs の 30 ns 先で AUPRC −0.0707）。
- 生の軌道と特徴量の行列は保存されていません。残っているのは候補ごとのラベルと3条件の予測確率（全6予測幅）と、指標をまとめた結果ファイルです。

### 1-2. 履歴の使い方を調べた実験（資料C）

- 静的な特徴量は起点1フレームから作る118個です。履歴の特徴量は16個で、起点から 0.1〜4.9 ns 前の13時点の距離の差や傾きなどと、過去全体を 0.5 ns 間隔で見た成立の頻度や遷移の割合です。
- 水素結合形成の 1 ns 先（1mix_A、候補 119,085 件）では、単一構造の AUC 0.92405 / AUPRC 0.43790 に対して、距離の履歴を入れると AUC 0.94993 / AUPRC 0.57492 になりました。角度の履歴を足しても効果はありませんでした。
- 塩橋形成と接触形成でも、検証の範囲では履歴で大きく良くなっています（塩橋の AUPRC 0.18278 → 0.45207、接触の AUPRC 0.38148 → 0.65061）。ただし、どちらも事前に決めた合格の基準には届かず、最終テストは開けられていません。
- 候補の作り方は、起点で未成立かつ 8 Å 以内のペアを残す方式です（資料Aの 3.5〜6.0 Å とは範囲が違います）。

### 1-3. 起点を 1 ns に固定した3現象の実験（資料D）

- ATLAS の解析版 6タンパク質×3レプリカで、学習4・テスト2（1mix_A と 2qt4_A の合算）です。起点は 1 ns に固定し、履歴は 0〜1 ns の11フレームを6個の統計量にまとめています。静的な特徴量は現象ごとに5〜7個だけで、モデルは条件ごとに学習し直しています。
- 水素結合の AUPRC は 1 ns 先で 0.3637 → 0.4815、90 ns 先で 0.3035 → 0.4246 と、すべての予測幅で改善しました。接触もすべての幅で改善しています。塩橋は候補が少なく荒く、10 ns 先で AUPRC が下がり、1 ns 先と 10 ns 先で Brier が悪化しました。
- 静的な土台が弱い条件なので、伸びの大きさ（約 +0.12）は土台の弱さを含んだ参考値です。
- 結果は GitHub Actions の実行記録にだけあり、リポジトリには保存されていません。同じディレクトリにある別の実装は成績が大きく違うので、混同しないよう注意が必要です。

## 2. 生成軌道で指導力が得られなかったという測定

### 2-1. 24方式の実験（資料B）

- 「24案」は第2〜25案です（第1案の全原子MDは除く）。同じ案番号に実装が2系統あります。距離の系列や局所の配置への軽い近似で済ませた系統と、重原子の Langevin 積分やループの閉じ直し、側鎖の回転遷移、学習型の座標生成など、本来の仕組みに近い系統です。
- 再学習の比較（検証は固定10配列、候補 153,212 件）では、静的な対照の AUPRC 0.466841 に対して、全案が 0.464363〜0.467213 の範囲でした。最良の第22案でも差は +0.000372 で、配列単位の再標本化による95%区間は 0 を含みます。
- 凍結した最良の静的モデル（AUPRC 0.500030）への混合では、192条件のどれも、4指標すべてが同時には改善しませんでした。
- 軽い近似の系統でも、対照 0.475917 に対して全案が 0.474552〜0.476749 でした。
- 単一構造の探索の中で試した生成の前段4種も、対照 0.477008 に対してすべて下でした。
- 第2〜20案の生成軌道は、ステップに実際の時間（ns）を割り当てていません。実際の時刻に対応するのは、実MDを教師に学習した第21〜25案だけです（教師は 0.1、0.3、0.5、1.0 ns の座標と距離）。
- 生成軌道そのものの質（距離の分布や時間の相関が実軌道にどれだけ近いか）は、一度も測られていません。軌道の長さや保存間隔の記録もありません。評価はすべて判別器を通した予測精度だけです。
- 資料側の限定として、力場・温度・軌道の長さ・分岐の数の系統的な調整は行っていないこと、読み出し側（特徴量と予測器）で実装し直した場合の性能は測っていないことが、明記されています。

## 3. 実験どうしの条件の食い違い（主なもの）

1. 予測の起点と入力が違います。資料Aは起点 1 ns で過去 0〜1 ns を入力します。生成軌道の実験は起点の1フレームを入力し、1 ns 先だけを見ています。
2. 土台のモデルが違います。資料Aは凍結した本体＋補正モデル、生成側の再学習の比較は静的特徴＋8特徴の XGBoost で、その静的な対照自体が最良の静的モデルより弱い構成です。資料Cは118個の静的特徴を持つ強い土台、資料Dは5〜7個の弱い土台です。
3. 特徴量の作り方が違います。実軌道の履歴は資料Aで10個、資料Cで16個、資料Dで6個の集計です。生成側は軌道を8個の特徴量に要約して静的特徴に足す形が前提です。
4. 評価の集合が違います。資料Aは未見100配列です。生成側の検証は固定10配列で、混合の割合を決めることと評価が同じ集合です。
5. 予測幅が違います。生成側は 1 ns 先だけで、他の幅は資料自身が「判断できない」としています。
6. 候補の集合が違います。資料Aは起点の距離が 3.5〜6.0 Å のペア、資料Cの系統は起点で未成立かつ 8 Å 以内のペアです。

## 4. 集計で失われていそうな情報（実装を読んだ指摘）

- 距離の並びは平均・標準偏差・最小値・割合にまとめられるため、最小値になった時刻、近づき方の単調さ、境界をまたいだ回数、成立していた時間の分布は残りません。1回の長い接近と、複数の短い接近を区別できません。
- 過去全体の頻度は、古い成立と直前の成立をほぼ同じに扱います。
- 履歴はそのペア自身の距離だけで、周辺のペアや環境の時間変化は入っていません（角度の履歴は効果がありませんでした）。
- 塩橋と接触は残基どうしの最小距離にまとめられるため、どの原子が近づいたかは分かりません。探索の打ち切り（7 Å、15 Å）より遠くからの接近は記録されません。
