## 1. 履歴特徴量の正確な定義

### 水素結合（tseries/hb_history.py の history 関数）

対象はドナー・アクセプター原子ペアで、使う量はそのペアの距離だけです。履歴は16個の数値にまとめられます。

- 短期の動き（8個）: 起点から 0.1、0.2、0.3、0.5、0.8、1.0、1.3、1.7、2.0、2.6、3.2、4.0、4.9 ns 前の13時点で距離を測ります（フレーム間隔100 ps、間隔は直近ほど細かい）。そこから、起点距離との差を5つの時点で取ったもの、13時点の標準偏差、隣り合う時点の距離変化の平均、距離の差と時間間隔から求めた最小二乗の傾き（近づく速さ）を計算します。
- 占有と遷移（8個）: 13時点での最小距離と平均距離、距離が3.5 Å以下だった割合（13時点全体と、直近1.0 ns分の6時点）、レプリカの起点より前の全区間を0.5 ns間隔で見たときの成立頻度、未成立から1 ns後に成立していた割合、そのうち起点距離と0.5 Å以内の距離から始まった場合の遷移割合と、その条件に当てはまった回数の対数です。

予測は1 ns先の形成のみで、候補は起点距離が3.5〜6.0 Åのペアです（HB_HISTORY_EXPERIMENTS.md）。

### 塩橋・接触（tseries/event_history.py と tseries/event_kinetics.py）

対象は残基ペアで、使う量は残基間の最小原子間距離です。

- 直近の履歴（16個、event_history.py）: 水素結合と同じ13時点（直近4.9 ns）で最小距離を測り、起点距離との差（5時点）、最小・平均・標準偏差、閾値（塩橋4.0 Å、接触4.5 Å）以下だった割合、閾値からの距離を柔らかく数えた占有量、直近1.0 ns分だけの同じ2量、近づく速さの傾き、直近1.0 nsの平均とそれより前の平均の差、最初に閾値以下になった時点、隣り合う時点の距離変化の平均を計算します。起点距離が15 Åを超える行は履歴を作らず、起点距離で埋めた値が入ります。
- 長期の頻度（12個、event_kinetics.py）: 起点より前の全区間を0.5 ns間隔で測り（距離は7 Åまでの探索で測り、それより遠いものは8.0 Åとして記録）、成立頻度、直近10時点（5 ns分）の成立頻度、柔らかい占有量、未成立から1 ns後に成立した割合、起点距離と0.5 Å以内・1.0 Å以内から始まった場合の遷移の回数と割合（平滑化つき）、測った時点の数、全期間の最小距離を計算します。

### 起点フレームの静的特徴量（tseries/features.py）

履歴とは別に、起点の1フレームだけから作る特徴量があります。structural 関数は118個を返します。内訳は、基礎14個（起点距離、Cα間距離、配列距離の対数、ドナーとアクセプターの種類、結合角の余弦2つ、競合する近傍ペアの数、すでに結合しているか、埋没度2つ）と、追加104個（ドナー側とアクセプター側の5原子同士の距離25個、重原子の最小距離、Cβ間距離、重心間距離、競合ペアの最近傍距離と6 Å以内の数、二面角の正弦・余弦8個、周辺の水素結合の数、原子の詰まり具合、アミノ酸の種類など）です。feature_graph 関数は候補全体の中での競合の強さを24個追加し（合計142個）、enriched_features 関数は競合と幾何の組み合わせをさらに24個追加します（合計166個）。feature_graph の中では、候補同士で確率の質量を取り合う計算を2回繰り返す処理も入っています。

## 2. モデル構成（対象1）

- tseries/rod.py: 候補を作る部分です。全原子ペアを数え上げ、ドナー・アクセプターの型と「別の残基であること」の条件を通し、起点で未成立（距離3.5 Å超）で、ふるい距離（標準は8 Å）以内のペアを残します。未来の座標はラベルと保持率の計算にだけ使います。
- tseries/models.py: 試行の登録表と学習・読み込みです。試行 T1I01〜T1I10（予備）と T1I11〜T1I20（確認）があり、モデルの種類（ロジスティック回帰、MLP、XGBoost）、特徴量の幅（118、142、166）、表現の種類（environment、competition、interaction）の組み合わせが決まっています。学習は CUDA で行い、XGBoost は深さ5、240ラウンド、MLP は 96→48 の2層で30エポックです。種は 27182 に固定されています。保存したモデルは CPU で推論できます。
- tseries/experiment.py: 学習と評価の流れです。select は学習配列で全試行を学習し、検証配列で評価して、検証の AUPRC の平均が最も大きく、同点なら Log Loss の平均が小さいものを勝者として固定し、チェックポイントの SHA-256 を selection.json に記録します。final は分割とチェックポイントが変わっていないことを確かめてから、テスト配列と過去の評価用配列で一度だけ評価します。指標は AUC、AUPRC、Brier スコア、Log Loss で、距離だけの単純な予測の成績も併記されます。
- 履歴実験（hb_history.py、search_events.py）はこの基盤を再利用しつつ、履歴特徴量を横に足して XGBoost（CUDA）で学習し直します。モデル選択は検証配列だけで行い、合格条件を満たさない場合は最終テストを開けません。

## 3. 実軌道の履歴が精度に与えた影響（対象1）

評価のものさしは「確認数」です。予測確率の高い順に候補を確認していったとき、全適格正例の80%を拾うまでに必要な確認の数で、小さいほど良い値です。合格条件は、確認数が旧モデルの3分の1以下で、AUC、AUPRC、Brier スコア、Log Loss の4指標が悪化しないことでした。

## 4. 対象2の実験（fixed_1ns_history_3phen_6h.py）

### 条件

- データは ATLAS の解析版（100 ps刻み、全原子、溶媒なし）を MiniTopol で変換したもので、6タンパク質×3レプリカです。学習は 1bgf_A、1ifg_A、1j8r_A、2b0a_A の4つ、テストは 1mix_A と 2qt4_A を合わせた集合です。
- 予測起点は全条件で軌道の10フレーム目（1 ns地点）に固定されています。履歴は0〜1 nsの11フレームだけで、予測幅によらず同じです。予測先は起点から1、5、10、30、50、90 ns先、絶対時刻では2、6、11、31、51、91 nsです。
- 現象と候補とラベルは距離だけで決まります。水素結合はドナー・アクセプター距離が3.5 Å超6.0 Å以下、塩橋は荷電残基間の最小距離が4.0 Å超10.0 Å以下（配列距離2以上）、接触は Cα間距離12 Å以内のペアで重原子の最小距離が4.5 Å超のものです。ラベルは予測先で閾値（3.5、4.0、4.5 Å）以下になることです。
- 静的特徴量は現象ごとに5〜7個だけです（起点距離、Cα間距離、配列距離の対数、原子や残基の種類など）。履歴特徴量は、11フレームの距離の並びから作る6個（最初の値、平均、標準偏差、最小値、最後と最初の差、閾値以下だった割合）です。
- モデルは HistGradientBoostingClassifier（反復120回、学習率0.075、葉31、L2 0.02、種42）で、現象×予測幅×入力条件ごとに学習し直します。候補とラベルは2条件で共通です。スクリプト自身に「現行の最良モデル（T1I2006）の評価ではなく、独立した参考実験」と明記されています。

### 対象1や100配列実験との条件の違い

- 対象1との違い: 対象1は学習・検証・テストの配列を分け、モデル選択を検証だけで行います。静的特徴量は118個あり、履歴は直近4.9 nsの13時点と起点より前の全区間の頻度まで使います。学習の起点も多数あります（学習は25フレーム間隔）。対象2は学習4タンパク質、テストの起点は1 ns地点の1つだけ、静的特徴量は5〜7個、履歴は0〜1 nsだけです。対象2の単一構造の成績が対象1より低いのは、特徴量が少なく学習配列も少ないためで、履歴の伸び幅をそのまま比べることはできません。
- 100配列の水素結合形成実験との違い: そちらは未見100配列×3レプリカで、AUPRC の平均改善は1 ns先で約+0.0712、90 ns先で約+0.0273 でした。対象2は6タンパク質だけの小さな参考実験で、静的側が弱い分、見かけの伸び（+0.12前後）は大きくなっています。絶対値も伸び幅も別条件の値として扱う必要があります。
- なお同じディレクトリには、条件の違う別実装 run_observed_history_3phen_6h.py（水素結合のふるい8 Å、学習の起点が10 ns刻みで10個、静的特徴量12個など）もあり、成績も違います（例: 水素結合1 ns先の単一構造 AUC 0.9673、履歴あり0.9725。Actions 実行ログ run 44882967231）。対象2の数値と混ぜないよう注意が必要です。

## 5. 集計で失われていそうな情報（実装から読み取れる範囲）

- 時間の並びの情報: どの履歴も、距離の並びを平均、標準偏差、最小値、特定の時点の差、閾値以下の割合といった少数の数値に潰しています。たとえば水素結合の短期履歴は13時点を8個の数値にしています。最小値がいつ出たか、近づき方が単調だったか、閾値を何回またいだか、成立していた長さの分布は残りません。標準偏差と変化量の平均だけでは、1回の長い接近と何回もの短い接近を区別できません。
- どの時刻の情報か: 長期の成立頻度と遷移割合は、起点より前の全区間を1つにまとめます。ずっと前に成立していたことと、起点の直前に成立していたことが、直近分の割合（水素結合では直近1.0 ns分、塩橋・接触では直近5 ns分）を除いて同じ扱いになります。
- 距離以外の情報: 履歴はすべてそのペア自身の距離だけから作られます。角度の履歴は水素結合の追加試行（T1I504）で足されましたが成績は変わりませんでした。周辺のペアの動きや、環境の時間変化は履歴に入っていません。
- 残基ペアへの潰し方: 塩橋と接触の履歴は残基間の最小距離の並びです。どの原子同士が近づいたかは残りません。
- 測る範囲の打ち切り: 塩橋・接触の長期頻度は7 Åまでの探索で測るため、それより遠い位置からの接近は8.0 Åとして記録され、動きが見えません。直近の履歴でも、起点距離が15 Åを超える行は過去の動き自体が捨てられ、起点距離で埋められます。
- 対象2の履歴はさらに粗く、11フレームを6個の数値にしています。順序の情報は「最後と最初の差」だけです。
