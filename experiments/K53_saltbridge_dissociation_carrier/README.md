# K53: 塩橋の解離でも、担い手は平均か（K15 の広げた条件、塩橋の解離）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。解離でも指導力があり、平均だけで利得の 0.75〜1.38 が戻りました。先に固定した目安（8割）は 6幅中5幅で超え、1 ns先では 0.921 でした。担い手の形は水素結合・接触の解離と共通です。

## 1. 何を確かめる実験か

水素結合の解離（K46）と接触の解離（K50）では、担い手は平均でした。塩橋の解離でも同じか確かめます。

読み方は先に固定しました。解離でも指導力があり、平均だけで利得の8割以上が戻れば、担い手の形は水素結合・接触の解離と共通です。指導力が無い、または平均だけでは戻らなければ、塩橋の解離は違います。「8割以上」は全幅または多くの幅での読みとし、1 ns先を主判断とします。

## 2. 解離の定義（結果を見る前に固定）

形成の対になる形です。K46 の水素結合の解離と同じ考え方で、塩橋の形成の候補規則を鏡像にしました。

- 候補: 形成と同じ正側・負側の規則（正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2、距離は荷電重原子ペアの最小値）で、起点フレーム10の最小距離が 4.0 Å 以下（塩橋ができている状態）で、配列距離が2以上の残基ペア。形成の候補（起点で 4.0 Å 超〜10.0 Å 以下）とは重なりません。起点の距離の範囲は、学習側 2.52〜3.99 Å、テスト側 2.49〜4.00 Å でした。
- ラベル: 予測先のフレームで最小距離が 4.0 Å を超えること（解離した）を 1 とします。
- 静的特徴は形成と同じ5個（起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）です。
- 履歴の6統計量も形成と同じ定義（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å以下だった割合）です。ただし解離では起点で 4.0 Å 以下の候補だけなので、4.0 Å以下割合の分布は形成と違います。テスト側では平均 0.788、中央値 0.909、全体の 48.9% が11フレームすべて 4.0 Å 以下でした。K46（65.9% がすべて以下）や K50（81.0%）より飽和は弱いですが、この統計量の変化は形成より小さく、情報は主に他の統計量にあります。
- 候補数: 学習 735件、テスト 360件で、合計 1,095件です。形成（学習 2,557件、テスト 1,170件）より少ないのは、起点で結んでいるペアの数が、結んでいないが届く範囲にあるペアの数より少ないためです。テストのタンパク質ごとの候補数は、1mix_A 30件、2qt4_A 15件、2hu9_A 24件、5yrv_I 25件、2end_A 27件など、1〜27件の範囲でした。
- テストの陽性数（解離した件数）: 1 ns先 101件（陽性率 28.1%）、5 ns先 139件（38.6%）、10 ns先 131件（36.4%）、30 ns先 149件（41.4%）、50 ns先 166件（46.1%）、90 ns先 160件（44.4%）。形成の陽性率（テストで 7.9〜12.7%）より高く、陽性数も形成（93〜149件）と同程度か多いため、解離の利得は読みやすい条件です。ただしテスト候補そのものは 360件と形成（1,170件）の3分の1程度なので、幅ごとの値は形成より振れやすくなります。
- 候補の対応の確認: 抽出時に、解離の候補数と形成の候補数を合わせると、規則に合う残基ペアの総数（起点で 10.0 Å 以下、配列距離2以上）と軌道ごとに一致しました（例: 1mix_A R1 は解離 11件＋形成 31件＝42件）。K50 と同じ確認です。
- K15 の欠け: 2hng_A の R3 と 4cv4_A の R2 は、記録された箱が全フレームで 0 のため、解離でも候補が0件でした（抽出時に箱が全て 0 であることを確認し、警告を出しています）。形成と同じ2レプリカが欠けており、解離では1レプリカあたり平均約4件なので、欠けは約8件（テストの約2%）程度と見込まれます。K15・K19 の結果と結論には影響しない、という K15 の記録と同じ扱いです。抽出ログの RuntimeWarning（`invalid value encountered in divide` と `invalid value encountered in minimum`、各2回）は、この2レプリカの箱が 0 であることが原因です。距離計算で箱の長さ 0 で割るため値が無効になり、そのまま最小値を取るところでも警告が出ます。ただし最小距離は無限大のままになるため、この2レプリカからは候補が1件も選ばれず、無効な値が特徴量やラベルに混ざることはありません。結果への影響はありません。なお、1l9l_A の R3 も解離候補が0件ですが、こちらは警告が出ておらず、起点で結んでいるペアが本当に0件だったためで、箱の問題とは別です。

## 3. 条件

- 土台は K15 の広げた条件です。ATLAS 解析版、学習58タンパク質・テスト30タンパク質、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 条件は3つです（分け方は K21/K27/K31/K46 と同じ）。
  - 静的のみ: 静的5特徴だけ
  - 全部入り: 静的＋実履歴6統計量
  - 平均だけ: 静的＋履歴6統計量のうち平均1つだけ（他の統計量は入れない）
- 対照の確認: 塩橋の形成を同じコードで再計算し、静的のみと全部入りが全予測幅で K15 の記録と完全に一致しました（差 0.0。1 ns先で静的のみ 0.2402、全部入り 0.3842）。形成の平均だけの条件も併せて測ったところ、K31 の記録と全予測幅で完全に一致しました（1 ns先で平均だけ 0.3682、戻り方 0.889）。

## 4. 結果

AUPRC（テスト合算）です。利得は静的のみに対する全部入りの改善、戻り方は「平均だけの利得÷全部入りの利得」です。

| 予測幅 | 静的のみ | 全部入り | 平均だけ | 利得 | 平均だけの戻り方 |
|---:|---:|---:|---:|---:|---:|
| 1 ns | 0.3734 | 0.5522 | 0.5382 | +0.1788 | 0.921 |
| 5 ns | 0.4641 | 0.5780 | 0.5794 | +0.1139 | 1.012 |
| 10 ns | 0.3572 | 0.5353 | 0.5302 | +0.1781 | 0.971 |
| 30 ns | 0.4799 | 0.5432 | 0.5673 | +0.0633 | 1.381 |
| 50 ns | 0.4863 | 0.6165 | 0.5845 | +0.1302 | 0.754 |
| 90 ns | 0.4824 | 0.5405 | 0.5430 | +0.0581 | 1.043 |

AUC / Brier も全予測幅で改善しました（1 ns先: AUC 0.5771 → 0.7858、Brier 0.2309 → 0.1835）。Log Loss も 30 ns先を除く全幅で改善しました（1 ns先: 0.7509 → 0.6453）。30 ns先の Log Loss は 0.7907 → 0.7910 と 0.0003 だけ悪化しており、ほぼ変わらない幅です。詳しくは `results.csv` / `results.json` を参照してください。

## 5. 読み取り

- **解離でも指導力ははっきりあります。** 利得は 1 ns先 +0.1788、5 ns先 +0.1139、10 ns先 +0.1781、30 ns先 +0.0633、50 ns先 +0.1302、90 ns先 +0.0581 で、全予測幅で正です。形成の利得（+0.027〜+0.144）より大きく、特に 1 ns先と 10 ns先では形成の利得を上回ります。
- **平均だけで、利得の 0.75〜1.38 が戻りました。** 先に固定した目安の8割を、6幅中5幅で超えています。1 ns先 0.921、5 ns先 1.012、10 ns先 0.971、30 ns先 1.381、50 ns先 0.754、90 ns先 1.043 です。50 ns先だけが 0.754 と8割をわずかに下回りました。30 ns先で1.38 と大きいのは、利得そのものが小さい（+0.0633）幅で平均だけの方が全部入りを上回ったためで、比率が振れやすい幅です。単一の学習 seed の結果でもあります。
- 塩橋の形成では平均だけでは 0.34〜1.10 と幅ごとに大きく振れました（K31: 1 ns先 0.889、5 ns先 0.876、10 ns先 0.341、30 ns先 1.096、50 ns先 0.800、90 ns先 0.459）。**塩橋のなかでも、形成と解離で担い手の形が違います。** 解離は水素結合の解離（K46、0.84〜1.30）や接触の解離（K50、0.81〜0.99）と同じく平均が担い手で、形成は平均だけでは担えません。接触でも同じ違いがありました（形成 K27 は 0.65〜0.71、解離 K50 は 0.81〜0.99）。

## 6. 判断できること・まだ分からないこと

- 判断できること: 塩橋の解離でも実履歴に指導力があり、担い手はペアの平均距離という1つの量でほぼ担えます。事前に固定した読み方に沿うと、担い手の形は水素結合・接触の解離と共通です。塩橋の形成とは担い手の形が違います。
- まだ分からないこと: 平均以外の統計量が単独でどれだけ戻るか（最小値だけ・割合だけ・形だけ）は測っていません。解離では 4.0 Å以下割合が形成より飽和しているため、割合だけの戻り方は形成より小さいはずですが、未測定です。また、50 ns先の戻り方 0.754 が本当に8割を下回るのか、テスト 360件という規模の揺れなのかも、この実験だけでは分かりません。なぜ形成では平均が担い手にならず、解離では平均が担い手になるのかも、この実験だけでは分かりません。
