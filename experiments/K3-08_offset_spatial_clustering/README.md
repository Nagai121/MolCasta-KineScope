# K3-08: ずれはペアごとに独立か、近いペア同士で似るか

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる系列 K3 の1件。K3 の候補6つ（側鎖の状態、ペアの周りの水素結合のつながり方、電場、背骨の形、ペアの間の水、相互作用のエネルギー）はすべてずれの正体ではなかった。候補を探す前に、ずれ自体の性質として「近いペア同士でずれが似るか」を測る。似るなら、ずれはペアだけの性質ではなく、タンパク質の中の場所の性質ということになる。
- 状態: 進行中。

## 1. 何を確かめる実験か

強い土台（K06(b)、水素結合の形成）のずれ（0〜1 ns の平均距離の実測値から、静的特徴5個だけの予測を引いたもの。K39・K42 と同じ作り方）について、同じタンパク質×レプリカの中で候補ペアの組を作り、組の2つのずれ同士の Pearson 相関を測る。評価は未見100タンパク質×3レプリカの候補 163,074件。

組の作り方（3通り）:

1. 残基を1つ共有するペア同士（ドナー側・アクセプター側のどちらか一方でも、両方でもよい）。
2. 起点フレーム（フレーム10）でペアの中点同士の距離が 8 Å 以内のペア同士。ただし残基を共有する組は除く。中点は、ペアの2原子のうち一方を他方の最も近い像に置いて、その中間とする（周期境界をまたいでも正しくなる置き方）。中点同士の距離も周期境界を考慮して測る。
3. 対照として、同じタンパク質×レプリカの中で、中点同士の距離が 20 Å 以上離れたペア同士。中点はレプリカごとの量なので、対照も同じタンパク質×レプリカの中で作る。

それぞれについて、(a) ずれをそのまま使った場合と、(b) タンパク質×レプリカごとのずれの平均を引いた場合の両方を測る。(b) は、タンパク質全体が同じ向きに寄っているために似て見える場合と分けるためである。

対照として、同じタンパク質×レプリカの中でずれを無作為に入れ替えた場合に、相関が消えることも確かめる。

判定は先に固定した。

1. 相関が 0.3 以上なら「ずれは近いペア同士で似る」と記録する。
2. 0.3 未満の場合は、数値をそのまま記録する。
3. 組の数が膨大になる場合は無作為に抜き出してよい。その場合は抜き出し方と組の数を記録する。同じ候補が何度も組に出るため、組の数は独立な標本の数ではない。その点は注意書きとして残す。

## 2. 条件

- ずれは K39・K42 と同じ作り方。実の平均は K06(b) の履歴特徴のうち平均距離（0〜1 ns の11フレームの平均）で、静的な予測は静的特徴5個だけから実の平均を予測したもの。当てはめは較正8タンパク質の候補だけ、評価は未見100タンパク質×3レプリカ。当てはめは HistGradientBoosting 回帰（160回、学習率 0.065、葉 15、葉あたり最小 20、L2 0.15、種 20261121）。進める前に、テスト側のずれのばらつきが GBM で 0.6002 Å になることを確認する。
- ペアの中点と残基の対応は、変換済み軌道（MiniTopol の A.zarr）の起点フレーム（フレーム10）の座標と atoms.parquet から取る。対応の確認として、起点フレームのペア距離と K06(b) に保存された起点距離（静的特徴の2列目）の差を全グループで確かめる。
