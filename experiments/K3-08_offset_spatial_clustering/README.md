# K3-08: ずれはペアごとに独立か、近いペア同士で似るか

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる系列 K3 の1件。K3 の候補6つ（側鎖の状態、ペアの周りの水素結合のつながり方、電場、背骨の形、ペアの間の水、相互作用のエネルギー）はすべてずれの正体ではなかった。候補を探す前に、ずれ自体の性質として「近いペア同士でずれが似るか」を測る。似るなら、ずれはペアだけの性質ではなく、タンパク質の中の場所の性質ということになる。
- 状態: 完了。最も大きい相関でも、残基を共有するペアの組で +0.112（タンパク質×レプリカの平均を引くと +0.096）で、判定の線 0.3 には届かなかった。ずれはペアごとにほぼ独立であり、残基を共有するペアの間にだけ小さい共通した分がある。

## 1. 何を確かめる実験か

強い土台（K06(b)、水素結合の形成）のずれ（0〜1 ns の平均距離の実測値から、静的特徴5個だけの予測を引いたもの。K39・K42 と同じ作り方）について、同じタンパク質×レプリカの中で候補ペアの組を作り、組の2つのずれ同士の Pearson 相関を測る。評価は未見100タンパク質×3レプリカの候補 163,074件。

組の作り方（3通り）:

1. 残基を1つ共有するペア同士（ドナー側・アクセプター側のどちらか一方でも、両方でもよい）。
2. 起点フレーム（フレーム10）でペアの中点同士の距離が 8 Å 以内のペア同士。ただし残基を共有する組は除く。中点は、ペアの2原子のうち一方を他方の最も近い像に置いて、その中間とする（周期境界をまたいでも正しくなる置き方）。中点同士の距離も周期境界を考慮して測る。
3. 対照として、同じタンパク質×レプリカの中で、中点同士の距離が 20 Å 以上離れたペア同士。中点はレプリカごとの量なので、対照も同じタンパク質×レプリカの中で作る。

それぞれについて、(a) ずれをそのまま使った場合と、(b) タンパク質×レプリカごとのずれの平均を引いた場合の両方を測る。(b) は、タンパク質全体が同じ向きに寄っているために似て見える場合と分けるためである。

対照として、同じタンパク質×レプリカの中でずれを無作為に入れ替えた場合に、相関が消えることも確かめる。

判定は先に固定した。

1. 相関が 0.3 以上なら「ずれは近いペア同士で似る」と記録する。
2. 0.3 未満の場合は、数値をそのまま記録する。
3. 組の数が膨大になる場合は無作為に抜き出してよい。その場合は抜き出し方と組の数を記録する。同じ候補が何度も組に出るため、組の数は独立な標本の数ではない。その点は注意書きとして残す。

## 2. 条件

- ずれは K39・K42 と同じ作り方。実の平均は K06(b) の履歴特徴のうち平均距離（0〜1 ns の11フレームの平均）で、静的な予測は静的特徴5個だけから実の平均を予測したもの。当てはめは較正8タンパク質の候補だけ、評価は未見100タンパク質×3レプリカ。当てはめは HistGradientBoosting 回帰（160回、学習率 0.065、葉 15、葉あたり最小 20、L2 0.15、種 20261121）。進める前に、テスト側のずれのばらつきが GBM で 0.6002 Å になることを確認する。
- ペアの中点と残基の対応は、変換済み軌道（MiniTopol の A.zarr）の起点フレーム（フレーム10）の座標と atoms.parquet から取る。対応の確認として、起点フレームのペア距離と K06(b) に保存された起点距離（静的特徴の2列目）の差を全グループで確かめる。

## 3. 結果

前提の確認は通った。ずれの再現値はテスト側で GBM 0.6002 Å（実測 0.60019 Å）で、K39・K42 の記録と一致した。中点と残基の対応の確認は300グループすべてで通り、起点フレームのペア距離と保存された起点距離の差は最大で 0.0000007 Å だった。

組の数は、残基を共有する組が 1,770,883（うち2残基とも共有する組が 82,582）、中点同士が 8 Å 以内で残基を共有しない組が 2,763,646、中点同士が 20 Å 以上離れた組が 19,740,349（残基を共有する組は 0 件）だった。抜き出しはしていない。全グループのすべての組について、相関の計算に必要な合計を数え上げた。組の作り方の確認として、残基を共有する組の数は、残基ごとの候補一覧から作る方法と、距離の計算のついでに数える方法の2通りで一致した。

注意として、同じ候補は何度も組に出る。候補1件が出る組の数は平均で、残基を共有する組で約22組、中点が近い組で約34組、離れた組で約242組である。組の数は独立な標本の数ではないので、相関の値の細かい有意性を組の数から見積もることはできない。

ずれ同士の Pearson 相関（全グループをまとめて計算）:

| 組 | ずれをそのまま | 平均を引いたずれ | 入れ替え対照（そのまま、3回の範囲） | 入れ替え対照（平均引き、3回の範囲） |
|---|---:|---:|---:|---:|
| 残基を共有する | +0.112 | +0.096 | +0.009〜+0.011 | −0.004〜−0.001 |
| 中点が 8 Å 以内、残基を共有しない | +0.033 | +0.020 | +0.010〜+0.011 | −0.002〜−0.001 |
| 中点が 20 Å 以上（対照） | −0.001 | −0.012 | +0.010 | −0.002 |

入れ替え対照で、ずれをそのまま使った場合に残る +0.010 は、同じタンパク質×レプリカのずれ全体が同じ向きに寄っている分であり、どの組でも同じ大きさで出る。タンパク質×レプリカの平均を引くと入れ替え対照はほぼ 0（−0.004〜−0.001）になり、相関が消えることが確かめられた。このため、近さによる似方は平均を引いた値で読む。

## 4. 読み取り

- **判定の線 0.3 に届いた組はなかった。** 最も大きい残基を共有する組でも、ずれをそのまま使って +0.112、平均を引いて +0.096 である。先に固定した判定では、「ずれは近いペア同士で似る」とは記録しない。
- 似方はゼロではない。平均を引いた値で、残基を共有する組は +0.096（入れ替え対照はほぼ 0）、残基を共有せず中点が近い組は +0.020、20 Å 以上離れた組は −0.012 だった。残基を共有する場合の似方が一番大きく、空間的に近いだけの場合はその5分の1ほどで、離れれば見えなくなる。
- つまり、ずれの大部分はペアごとの性質であり、タンパク質の中の場所の性質ではない。共通した分があるのは主に残基を共有するペアの間で、その大きさは相関で +0.10 ほど（単純に分けて考えれば、ずれのばらつきの1割ほどの共通分）にとどまる。空間的な近さそのものの寄与はもっと小さい。

## 5. 判断と残り

- 判断できること: ずれはペアごとにほぼ独立で、場所ごとにまとまった値にはなっていない。残基の単位では小さい共通分がある。
- まだ分からないこと: 残基を共有するペア同士の小さい似方が、その残基の何によるのかは測っていない。また、20 Å 以上離れた組の平均を引いた値が −0.012 とわずかに負である理由も測っていない（大きさとしては、ほかの値と比べて小さい）。
