# E01: 真の短時間実 MD 指導力（タイムギャップ除去・100% 公開特徴量）および実 GPU コスト実測

- **確かめる仮説**: キネスコ Finding 1（G02〜G180・L01〜L74・G04）「0.1 ns の実 MD で 90 ns 先まで指導力の 50% 以上を回収でき、コストは 1.0 ns の約 1/8 である」が、(1) `[0, 1]` と起点フレーム `10` の間の **1.0 ns タイムギャップ**、(2) 独自モデル `T1I2006` 依存、(3) CPU 専用・20 ps 平衡化の G04 コスト前提、をすべて取り除いた公開条件でも成立するか。
- **状態**: 完了（2026-11-26）。
- **データ・軌道**: ATLAS 公開解析版トラジェクトリ（未見 100 タンパク質 × 3 レプリカ、4 現象合計 `484,049` 候補ペア、予測幅 `1/5/10/30/50/90 ns`）。コスト実測は `3bpj_B`（80 残基）・`2w9y_A`（140 残基）・`1mix_A`（206 残基, G04 同一タンパク質）。
- **比較条件（変更点と固定点）**:
  - 静的土台: `T1I2006` を使わない 100% 公開 20 特徴量（起点距離・配列間隔・主鎖/側鎖・二次構造近傍・接触密度・埋没度・ドナー/アクセプター化学種）。
  - 評価: 5-fold タンパク質群交差検証（各 fold 学習 80 / テスト 20、予測器は条件ごとに再学習）。
  - **Protocol A（真の定常隣接窓）**: 起点フレーム `10`（`t = 1.0 ns`）に隣接する直前区間 `[10-k .. 10]`（ギャップゼロ）。
  - **Protocol B（真の初期前進窓）**: `t = 0.0 ns` から長さ `L` を走らせ、起点を `t = L` に置く（ギャップゼロ、H結合形成）。
  - **Control C（従来のギャップ条件）**: キネスコ G/L と同じく `[0 .. k]` を起点 `f10` と組む対照。
  - **GPU コスト実測**: OpenMM 8.6.1（OpenCL / `NVIDIA GeForce RTX 4060 Ti`）、AMBER14 + TIP3P + 150 mM NaCl、2 fs 刻み。標準 200 ps 平衡化（100 ps NVT + 100 ps NPT）と G04 条件（20 ps）を併記。

## 判断できることと、まだ分からないこと
- **棄却**: G/L 系列の「定常 0.1 ns で全ホライズン ≥50%」は 1.0 ns タイムギャップによる水増し（定常隣接 0.1 ns では HB 形成 36–44%・HB 解離 28–45% で全 6 幅不合格）。G04 の「コスト 1/8」も実 GPU・標準 200 ps 平衡化では成立せず、実コスト比は `0.27–0.28`（約 1/3.6）。
- **確立**: (1) `t = 0.0 → 0.1 ns` の初期緩和は `48–60%` と定常 `0.9 → 1.0 ns`（`36–44%`）を上回る**初期緩和 vs 定常の非対称性**がある。(2) 定常での実用スイートスポットは **0.2–0.5 ns**（`0.5 ns` で `75–88%`）、`1.0 ns mean` 1 本で 6 統計量ゲインの **90–96%** を占める。
- **未解決**: 100 ps より細かい時間刻み（1–10 ps）での初期緩和カーブの立ち上がり速度は解析版トラジェクトリ（100 ps 刻み）からは測れない。
