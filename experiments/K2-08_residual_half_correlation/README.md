# K2-08: 残りの平均は履歴の前半と後半でどれだけ続くか

- 確かめること: K2-02 で距離そのものは 100 ps 以内に忘れられることが分かった。でも、平均のうち静的に予測できない部分（K2-03 の「残りの平均」）は、前半と後半で同じペアの値が続くのか。続くなら、指導力の担い手はペアごとの「ずれ」そのものである。
- 状態: 完了。残りの平均の前半・後半の相関は、GBM の残りで合算のピアソン +0.703・スピアマン +0.698、線形の残りで +0.729・+0.734 だった。先に固定した読み方（絶対値 0.5 以上なら「担い手は前半と後半で続いている」）に照らして、担い手は前半と後半で続いている。距離そのものは 100 ps 以内に忘れられる（K2-02）が、残りの平均はペアごとの「ずれ」として続く。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-03 では、履歴の平均のうち静的な特徴量で予測できない部分（残りの平均）を作り、その残りと一緒に動く量の候補を 4 つ試したが、どれも相関の絶対値が 0.3 に届かなかった。ここでは、その残りの平均が、履歴の前半と後半で同じペアの値として続くかどうかを見る。続くなら、残りの平均はペアごとの「ずれ」そのもので、指導力の担い手はそのずれだと読める。

測るものは先に固定した。資料Dの条件のデータで、K2-03 と同じ形で残りの平均を出す（前半と後半の平均ごとに、K2-03 と同じ設定の GBM で静的な予測を作る）。前半（フレーム [0..4]）の平均の残りと、後半（フレーム [6..10]）の平均の残りの相関（ピアソンとスピアマン、合算とテスト 2 タンパク質ごと）を測る。比較のため、生の平均の前半・後半の相関も同じ形で記録する。

読み方は先に固定した。残りの平均の前半・後半の相関の絶対値が 0.5 以上なら「担い手は前半と後半で続いている」、0.3 未満なら「続いていない」と記録する。0.3 以上 0.5 未満の場合は、そのどちらでもない（中間）と記録する。

## 2. 条件

- 資料Dの条件。水素結合の形成の候補ペア。学習は 4 タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A、9,610件）、テストは 1mix_A と 2qt4_A（4,972件、うち 1mix_A が 3,101件、2qt4_A が 1,871件）。
- 前半の平均は履歴フレーム [0..4] のドナー・アクセプター間距離の平均、後半の平均はフレーム [6..10] の平均（フレーム 5 は除く。K2-01・K2-04 と同じ分け方）。テストでの半分の平均は、前半 5.079 Å、後半 5.016 Å、全部の平均は 5.049 Å。
- 静的な予測は、資料Dの静的な特徴量（X の 7 列）から各半分の平均を予測したもの。線形回帰と HistGradientBoosting 回帰（K39 と同じ設定: 160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）の 2 通りで、どちらも学習側の候補だけで当てはめ、テスト側の統計は使わない。残りの平均 = 半分の平均 − 静的な予測。
- 予測は半分ごとに当てはめ直した。形成の候補は原点に向けて距離が縮む向きに動くため、前半と後半では平均の水準が系統的に違う。全部の平均に対する予測をそのまま当てはめると、その水準の違いが残りに混ざるためである。
- K2-03 のスクリプトと同じ形で、X は保存されたままの型で sklearn に渡した。sklearn の学習はスレッド数を 1 に絞って、この仮想マシンで実行した（半分の平均に対する回帰 4 件だけで、軽い計算である。K2-03 と同じ規模）。
- 当てはまり: 前半は線形で R² が学習 0.575・テスト 0.573、GBM で学習 0.655・テスト 0.562。後半は線形で学習 0.745・テスト 0.775、GBM で学習 0.786・テスト 0.772。テストでの残りの平均の標準偏差は、前半が線形 0.635 Å・GBM 0.642 Å、後半が線形 0.395 Å・GBM 0.398 Å（全部の平均では K2-03 で線形 0.487 Å・GBM 0.488 Å）。

## 3. 結果

### 残りの平均の前半・後半の相関

| 残りの作り方 | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| GBM | +0.703 / +0.698 | +0.668 / +0.657 | +0.795 / +0.771 |
| 線形 | +0.729 / +0.734 | +0.696 / +0.695 | +0.826 / +0.808 |

### 比較：生の平均の前半・後半の相関

| | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| 生の平均 | +0.893 / +0.917 | +0.875 / +0.901 | +0.942 / +0.947 |

生の平均の前半・後半の相関は +0.89 と高いが、これはペアごとの水準（静的な特徴量で決まる部分）が両半分に共通に入るためである。静的な予測を引いた残りでも、相関は合算で +0.70（GBM）・+0.73（線形）と高く、タンパク質ごとでも 1mix_A で +0.67・2qt4_A で +0.80 と 0.5 を上回る。

### 参考：K2-03 の全部の平均の残りとの相関（GBM、合算）

前半の残りと全部の平均の残り（GBM）の相関はピアソン +0.950・スピアマン +0.935、後半の残りとは +0.873・+0.858。全部の平均の残りは、前半と後半の残りの平均に近いものであることと整合する。

## 4. 読み取り

先に固定した読み方に照らすと、残りの平均の前半・後半の相関は、GBM・線形のどちらでも、合算でもタンパク質ごとでも、ピアソンでもスピアマンでも、絶対値が 0.5 を上回った（最も小さい 1mix_A の GBM のスピアマンでも +0.657）。**担い手は前半と後半で続いている。** 残りの平均は、ペアごとの「ずれ」そのものとして、前半と後半で同じ値を持つ。

K2-02 との対比が大事である。距離そのものは 100 ps 以内に忘れられるのに、残りの平均は 500 ps ほど離れた前半と後半で +0.70 の相関を持つ。つまり、履歴の各フレームの距離は「静的な水準＋ペアごとのずれ＋速いゆらぎ」からなり、速いゆらぎは 100 ps で忘れられるが、ペアごとのずれは窓のあいだ続く。平均を取ると速いゆらぎは消え、ずれが残る。このずれが、指導力を担う残りの平均の正体である。

## 5. 判断できること・まだ分からないこと

- 判断できること: 残りの平均は前半と後半で続いている（相関は合算で +0.70〜+0.73）。指導力の担い手は、ペアごとのずれそのものである。後半の平均は前半より静的に予測しやすい（R² が 0.56 から 0.77 へ上がり、残りの標準偏差が 0.64 Å から 0.40 Å へ下がる）。これは後半が原点のフレーム（フレーム 10）に近く、静的な特徴量にフレーム 10 の距離そのものが入っているためである。
- まだ分からないこと: ペアごとのずれが何の影なのか（K2-03 の 4 つの候補では説明できなかった）。ずれが窓の外でも続くのか（1 ns の窓の中だけの話か、もっと長い時間でも続くのか）。ずれが指導力にどう効くのか（この実験は相関だけを見ており、予測への寄与までは測っていない）。
