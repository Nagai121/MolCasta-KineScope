# K38 塩橋でも、生成の平均の誤差の出方は水素結合・接触と共通か（K15 の広げた条件）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H7（実軌道が持つ追加の観測情報）に関わる誤差の出方の切り分け
- 状態: 完了。塩橋でも、水素結合・接触と同じ大まかな形でした。境界付近で誤差は大きくならず、実の平均が外れた候補で大きくなります。ただし誤差の大きさ自体は水素結合の約3倍で、その大半は実側の未来と履歴の違いによるものです。

## 1. 何を確かめる実験か

水素結合と接触では、生成の平均の誤差は境界付近では大きくならず、実の平均が外れた候補で大きいという共通の形でした（K30・K35）。塩橋でも同じ形か確かめ、3現象の誤差の地図をそろえます。ラベルとの関係（K29 の (a) と同じ測定）も、塩橋の 1 ns先について測ります。

読み方は先に固定しました。塩橋でも同じ形なら、誤差の出方は3現象に共通です。形が違えば、誤差の出方は現象ごとに違います。

## 2. 対象と定義

- 対象は K15 で広げた塩橋の集合の全 3,727件（学習 2,557件＋テスト 1,170件）です。生成系列は K20 の第11〜14案（残基レベルの生成）で、作業領域の `~/workspace/k20/out/` にあるタンパク質・複製ごとのファイルを使いました。
- 実の平均は、K15 のキャッシュにある 11フレームの最小距離系列（0〜1 ns）の平均です。塩橋の履歴の統計量でいう「平均」と同じ量です。生成の平均は、分岐4本の平均を取った9点の生成系列（起点＋8ステップ）の平均で、K30 の第22案と同じ約束（起点を含む系列の平均）です。
- 確認: 生成系列の起点は実の未来の系列の起点と完全に一致しました（最大の差 0.0）。実の履歴・ラベル・残基番号も、確かめたファイルでは K15 のキャッシュと完全に一致しました。箱が 0 のため候補が 0件の 2軌道（4cv4_A の R2、2hng_A の R3）は K15・K20 と同じ扱いで含めていません。
- 分け方は K30 と同じ3通りです。(a) 起点の距離の帯: 境界 4.0 Å の付近（4.0〜5.0 Å）とそれ以外（5.0 Å 超）、細かく刻んだ帯でも測りました。(b) 実の平均の全体の平均（7.693 Å）からのずれの大きさ: 0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。(c) 残基間の隔たり: 隣り合う残基、2〜5、6〜10、11〜20、21以上。ただし塩橋の候補は隔たりが2以上と決まっているため、「隣り合う残基」の帯は 0件です。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。
- 対照として、実の未来の5点の最小値系列（起点＋0.1／0.3／0.5／1.0 ns）の平均と実履歴の平均との差も同じ分け方で測りました。生成の平均の誤差のうち、どれだけが「未来の系列と履歴の系列の違い」によるものかを見るためです。塩橋の生成系列は各時点で荷電原子ペアの最小値を取るものなので、接触（K35）のような代表ペアと最小値の量の違いはありません。
- ラベルとの関係は 1 ns先について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測りました（K29 の (a) と同じ）。比較のため、生成の平均（第14案）を実の平均の線形の式で当てはめたもの（生成の平均 = 2.937 + 0.585 × 実の平均、残差の標準偏差 1.148）から作る「縮み＋乱数」の合成の誤差も、3つの乱数 seed で測りました。

## 3. 結果

|---|---:|---:|---:|
| 第11案 | −0.265 | 1.453 | 1.070 |
| 第12案 | −0.266 | 1.453 | 1.071 |
| 第13案 | −0.264 | 1.456 | 1.072 |
| 第14案 | −0.252 | 1.452 | 1.067 |
| 対照: 実の未来の5点系列 | −0.050 | 1.291 | 0.911 |

4つの生成方式の誤差はほぼ同じです。誤差のばらつきは水素結合（K30、第22案の 0.483 Å）の約3倍ですが、実の平均の候補間のばらつきも塩橋では 2.145 Å と水素結合（0.880 Å）の約2.4倍です。対照として、実の未来の系列の平均でも実履歴の平均との差のばらつきは 1.291 と、生成の誤差の大半を占めます。つまり塩橋では、生成の平均の誤差の大きさのうちかなりの部分は、未来の系列と履歴の系列が別のものであることによるもので、生成器そのものの誤差はそれに上乗せされる形です。

## 4. 読み取り

- **(a) 境界付近で誤差は大きくならず、水素結合・接触と同じ形でした。** 境界付近の 1.294 Å に対してそれ以外は 1.467 Å と、むしろやや小さいです。細かい帯でも境界の側に山はなく、遠い帯ほどやや大きくなります。全体のずれは境界付近で −0.583 Å と大きめに出ますが、ばらつきは小さめです。
- **(b) 実の平均が外れた候補で誤差が大きくなる形も、3現象で共通でした。** ずれ 0.25 未満の 1.113 Å に対して 1.0 以上は 1.581 Å で約1.4倍です。水素結合の約2.2倍、接触の約1.5倍と比べると、塩橋の増え方は接触と同じくらいです。生成の平均は全体の平均の側に縮む（当てはめの傾き 0.585）ため、平均が外れに位置するペアについていけていない、という形は共通です。ただし対照の実の未来の系列でも 1.0 以上の帯で 1.355 Å と大きくなるため、外れでの増え方の一部は未来と履歴の系列の違いによるもので、生成器だけのものではありません。
- **(c) 隔たりによる差はほとんどありませんでした。** 2〜5 の 1.403 Å に対して 21以上は 1.498 Å で、約1.07倍です。水素結合（約1.2倍）・接触（約1.5倍）より弱いです。
- **ラベルとの関係は、水素結合（K29）と同じ形で、接触（K35）と逆でした。** 生成の誤差はラベルと相関 +0.15、AUC 0.66 で、縮み＋乱数の合成（相関 +0.19、AUC 0.69）より弱いです。水素結合でも生成の誤差のラベルとの関係は合成より弱かったのに対し、接触では生成のほうが合成より強かったので、この点では塩橋は水素結合寄りです。4つの生成方式の間でラベルとの関係に差はほとんどありません。
- 先に固定した読み方に照らすと、**(a)(b) の2つの分け方で、誤差の出方は3現象に共通**ということになります。境界付近で大きくならず、外れた候補で大きくなる、という形は塩橋でも出ました。量の違いとして、塩橋の誤差は水素結合の約3倍と大きいですが、その大半は実側の未来と履歴の違いで説明でき、生成方式の間の差はほとんどありません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 塩橋でも、生成の平均の誤差は境界付近で特に大きくならず、実の平均が外れた候補で大きくなります。誤差の出方の大まかな形は3現象で共通です。ラベルとの関係では、生成の誤差は縮み＋乱数の合成より弱く、水素結合と同じ形です。
- まだ分からないこと: (b) の外れでの増え方が水素結合より弱い理由。塩橋の実の平均のばらつきが大きいこと（標準偏差 2.145 Å）と、未来と履歴の系列の違いが大きいことが、量の違いにどう関わるかは、この実験だけでは分かりません。また、生成の誤差の大きさのうち未来と履歴の違いを除いた生成器そのものの分が、現象ごとにどう違うかも、切り分けられていません。
