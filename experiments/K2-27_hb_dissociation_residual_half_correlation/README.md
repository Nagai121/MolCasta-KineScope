# K2-27: K2-08 の問い（平均の残りが前半と後半で続くか）を水素結合の解離で測る

- 確かめること: 形成の 3 現象では残りの平均の前半・後半の相関が +0.64〜+0.73 だった。解離でも同じ形かを見る。
- 状態: 完了。残りの平均の前半・後半の相関は、GBM の残りで合算のピアソン +0.693・スピアマン +0.578、線形の残りで +0.733・+0.757 だった。先に固定した読み方（絶対値 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」）に照らして、水素結合の解離でも、指導力を運ぶずれは前半から後半へ続いている。形成の 3 現象（水素結合 +0.703、接触 +0.719、塩橋 +0.641）と合わせて、残りの平均の続き方は 4 つの現象の向きすべてで共通している。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-08 では、履歴の平均のうち静的な特徴量で予測できない部分（残りの平均）を作り、その残りが履歴の前半と後半で同じペアの値として続くかどうかを見た。水素結合の形成では合算ピアソン +0.703（GBM の残り）、接触の形成（K2-17）では +0.719、塩橋の形成（K2-22）では +0.641 と、形成の 3 現象ではどれも先に固定した 0.5 の線を超えた。ここでは、同じ問いを水素結合の解離で測る。解離でも同じ形かどうかを見る。

測るものは K2-08 と同じく先に固定した。資料Dの条件のデータで、K2-08 と同じ形で残りの平均を出す（前半と後半の平均ごとに、K39 と同じ設定の GBM で静的な予測を作る）。前半（フレーム [0..4]）の平均の残りと、後半（フレーム [6..10]）の平均の残りの相関（ピアソンとスピアマン、合算とテスト 2 タンパク質ごと）を測る。比較のため、生の平均の前半・後半の相関も同じ形で記録する。

読み方は K2-08 と同じく先に固定した。相関の絶対値が 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」、0.3 未満なら「続いていない」と記録する。0.3 以上 0.5 未満の場合は、そのどちらでもない（中間）として数値をそのまま記録する。

## 2. 条件

- 資料Dの条件。水素結合の解離の候補ペア。学習は 4 タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A、4,051件）、テストは 1mix_A と 2qt4_A（2,080件）。起点はフレーム 10（1 ns）、履歴は 0〜1 ns の 11 フレーム。距離はドナー・アクセプター間の距離で、境界は 3.5 Å。候補は起点で水素結合ができているペア。
- 前半の平均は履歴フレーム [0..4] のドナー・アクセプター間距離の平均、後半の平均はフレーム [6..10] の平均（フレーム 5 は除く。K2-01・K2-08 と同じ分け方）。テストでの半分の平均は、前半 2.883 Å、後半 2.824 Å、全部の平均は 2.855 Å と、前半から後半へ 0.06 Å 縮む向きに動く。形成（K2-08）でも前半 5.079 Å から後半 5.016 Å へ 0.06 Å 縮んだ。形成と解離のどちらでも、後半の平均は原点のフレームの条件に寄る。候補は原点のフレームの距離で選ばれているため、原点に近いほうの半分の平均が原点の条件に近づくのは、選び方からくる自然な形である。
- 静的な予測は、資料Dの静的な特徴量（X の 7 列）から各半分の平均を予測したもの。線形回帰と HistGradientBoosting 回帰（K39 と同じ設定: 160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）の 2 通りで、どちらも学習側の候補だけで当てはめ、テスト側の統計は使わない。残りの平均 = 半分の平均 − 静的な予測。
- 予測は半分ごとに当てはめ直した。解離の候補は原点に向けて距離が離れる向きに動くため、前半と後半では平均の水準が系統的に違う。全部の平均に対する予測をそのまま当てはめると、その水準の違いが残りに混ざるためである。
- K2-08 のスクリプトと同じ形で、X は保存されたままの型で sklearn に渡した。K46 の保存値は hist が (11, N) の向きなので、転置してから使った（K08 と同じ向き）。sklearn の学習はスレッド数を 1 に絞って、この仮想マシンで実行した（半分の平均に対する回帰 4 件だけで、軽い計算である）。
- 当てはまり: 前半は線形で R² が学習 0.644・テスト 0.518、GBM で学習 0.819・テスト 0.467。後半は線形で学習 0.780・テスト 0.765、GBM で学習 0.876・テスト 0.727。テストでの残りの平均の標準偏差は、前半が線形 0.516 Å・GBM 0.543 Å、後半が線形 0.272 Å・GBM 0.293 Å。後半は前半より静的に予測しやすい（R² が 0.47〜0.52 から 0.73〜0.77 へ上がり、残りの標準偏差が 0.52〜0.54 Å から 0.27〜0.29 Å へ下がる）。これは後半が原点のフレーム（フレーム 10）に近く、静的な特徴量にフレーム 10 の距離そのものが入っているためである。前半では GBM のテストの R²（0.467）が線形（0.518）を下回り、学習の R²（0.819）からも大きく落ちる。学習が 4,051件と少ないため、GBM が学習側に寄りすぎている。

## 3. 結果

### 残りの平均の前半・後半の相関

| 残りの作り方 | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| GBM | +0.693 / +0.578 | +0.675 / +0.521 | +0.781 / +0.678 |
| 線形 | +0.733 / +0.757 | +0.703 / +0.704 | +0.880 / +0.853 |

### 比較：生の平均の前半・後半の相関

| | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| 生の平均 | +0.871 / +0.899 | +0.851 / +0.889 | +0.970 / +0.921 |

生の平均の前半・後半の相関は +0.871 と高いが、これはペアごとの水準（静的な特徴量で決まる部分）が両半分に共通に入るためである。静的な予測を引いた残りでも、相関は合算で +0.69（GBM）・+0.73（線形）と高く、タンパク質ごとでも 1mix_A で +0.68、2qt4_A で +0.78 と 0.5 を上回る。

GBM の残りでは、スピアマンがピアソンより低い（合算で +0.578 対 +0.693、1mix_A で +0.521 対 +0.675）。GBM の残りには順位を崩す外れ値が混ざっており、線形の残りではスピアマンが +0.757 とピアソン（+0.733）とほぼ同じである。GBM の当てはまりが前半で線形を下回っていることと合わせて、解離では線形の残りのほうが安定している。どちらの残りでも、合算の相関は 0.5 の線を超えている。

## 4. 読み取り

先に固定した読み方に照らすと、残りの平均の前半・後半の相関は、GBM・線形のどちらでも、合算でもタンパク質ごとでも、ピアソンでもスピアマンでも、絶対値が 0.5 を上回った（最も小さい 1mix_A の GBM のスピアマンでも +0.521）。**指導力を運ぶずれは前半から後半へ続いている。** 形成の 3 現象（水素結合 +0.703、接触 +0.719、塩橋 +0.641）と合わせて、残りの平均の続き方は 4 つの現象の向きすべてで共通している。

解離では、平均そのものの動きが形成と向きが違うはずだったが、実際には前半から後半へ 0.06 Å 縮む向きに動いた。形成（K2-08）でも同じ 0.06 Å 縮んだ。候補は原点のフレームの距離で選ばれているため、原点に近いほうの半分の平均が原点の条件に近づくのは、選び方からくる自然な形である。平均の水準の動きは現象の向きでは決まらず、残りの平均の続き方も現象の向きでは変わらなかった。

## 5. 判断できること・まだ分からないこと

- 判断できること: 水素結合の解離でも、残りの平均は前半と後半で続いている（合算の相関は GBM で +0.69、線形で +0.73）。指導力を運ぶペアごとのずれは、前半から後半へ続く。形成の 3 現象と合わせて、残りの平均の続き方は 4 つの現象の向きすべてで共通している。解離では線形の残りのほうが GBM より安定している（前半のテストの R² は線形 0.518 対 GBM 0.467、スピアマンは線形 +0.757 対 GBM +0.578）。
- まだ分からないこと: ペアごとのずれが何の影なのか（水素結合の形成では K2-03 の 4 つの候補で説明できなかった。解離ではまだ試していない）。ずれが窓の外でも続くのか。ずれが指導力にどう効くのか（この実験は相関だけを見ており、予測への寄与までは測っていない）。
