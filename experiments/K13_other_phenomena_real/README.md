# K13: 塩橋形成と接触形成での実履歴の指導力と時間の加工

## 仮説
H2（時間の表現の不一致）、H5（特徴量の抽出と読み出し）に関わる確認です。これまでの加工実験はすべて水素結合形成でした。塩橋形成と接触形成でも、実履歴の指導力がどれだけあり、時間の加工への反応が水素結合と同じかを確かめます。

読み方は実験前に固定しました。両現象でも指導力が時間の順序ではなく距離の分布にあるなら、水素結合で見えた形は現象によらないことになります。現象ごとに反応が違うなら、指導力の担い手は現象ごとに違うことになります。

## データと定義（実験Dのコードから確認）
定義は MolCasta-InternalResearch ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py` をそのまま使いました。同じディレクトリの `run_observed_history_3phen_6h.py` は使っていません。

- 共通: ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算。起点はフレーム10（1 ns）、履歴は 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直します。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 塩橋形成: 正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2 で、距離は荷電重原子ペアの最小値です。候補は起点で最小距離が 4.0 Å 超〜10.0 Å 以下で、配列距離が2以上の残基ペアです。ラベルは予測先で最小距離が 4.0 Å 以下になることです。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）。履歴の閾値は 4.0 Å です。
- 接触形成: 残基ペア（i<j）で、Cα間距離が 12 Å 以下、配列距離が2以上です。距離は重原子（名が H で始まらず、先頭が数字でない原子）ペアの最小値です。候補は起点で最小距離が 4.5 Å 超のペアです。ラベルは予測先で最小距離が 4.5 Å 以下になることです。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、両残基の重原子数）。履歴の閾値は 4.5 Å です。
- 履歴の6統計量は両現象とも水素結合と同じ形です（最初の値、平均、標準偏差、最小値、最後−最初、閾値以下だった割合）。
- 候補数: 塩橋は学習 251件、テスト 116件（陽性は予測幅ごとに 8〜11件）。接触は学習 15,926件、テスト 7,384件（陽性 214〜257件）。

## 土台の再現（静的のみ → 実履歴あり）
資料Dの参照値（GitHub Actions run 44883044790 のログ由来、notes/C の表）と、AUPRC・AUC・Brier のすべてが小数第4位まで一致しました。

| 現象 | 予測幅 | AUPRC 静的→履歴 | AUC 静的→履歴 | Brier 静的→履歴 |
|---|---:|---:|---:|---:|
| 塩橋 | 1 ns | 0.2130 → 0.2604 | 0.7009 → 0.7684 | 0.0737 → 0.1022 |
| 塩橋 | 5 ns | 0.3487 → 0.6260 | 0.6905 → 0.8468 | 0.0825 → 0.0509 |
| 塩橋 | 90 ns | 0.1377 → 0.5054 | 0.6840 → 0.8785 | 0.0922 → 0.0627 |
| 接触 | 1 ns | 0.3398 → 0.5669 | 0.9007 → 0.9560 | 0.0230 → 0.0186 |
| 接触 | 5 ns | 0.2870 → 0.5192 | 0.8910 → 0.9433 | 0.0239 → 0.0187 |
| 接触 | 90 ns | 0.2872 → 0.4722 | 0.8734 → 0.9136 | 0.0283 → 0.0236 |

指導力（AUPRC の差）は、塩橋では 1 ns先で +0.047、5 ns先で +0.277、90 ns先で +0.368 と幅によって大きく違い、10 ns先では −0.041 と履歴が下回る点もあります。接触では全幅で +0.152〜+0.232 と大きく、水素結合（+0.063〜+0.121）より大きいです。全幅の値は `results.csv` / `results.json` にあります。

## 時間の加工（K01 と同じ加工）
間引き（11→6フレーム [0,2,4,6,8,10]、11→3フレーム [0,5,10]）、順序シャッフル（K01 と同じ流儀、seed 固定）、時間逆転を、学習・テストの両方に当てました。残存率 =（加工条件の AUPRC − 静的のみ）÷（実履歴の AUPRC − 静的のみ）です。

### 接触形成（候補が十分にあり、残存率が読める現象）
| 予測幅 | 間引き6 | 間引き3 | シャッフル | 逆転 |
|---:|---:|---:|---:|---:|
| 1 ns | 0.843 | 0.821 | 1.050 | 0.940 |
| 5 ns | 0.867 | 0.704 | 1.008 | 0.972 |
| 90 ns | 0.859 | 0.700 | 0.929 | 0.987 |

水素結合と同じ形です。間引きでは指導力の8割前後が残り（3点では7割前後まで下がる幅もあります）、順序シャッフルと時間逆転ではほぼ変化しません。

### 塩橋形成（候補が少なく、値は荒い）
テスト候補は116件、陽性は8〜11件しかないため、残存率は大きく振れます。1 ns先では間引き6で 3.06、間引き3で 0.67、シャッフルで 1.09、逆転で 1.03 でした。10 ns先は土台の指導力そのものが負（−0.041）なので残存率が負の大きな値になり、解釈できません。90 ns先のシャッフルは 0.06 まで落ちていますが、陽性8件での値であり、1条件の揺れと区別できません。塩橋については、加工への反応を水素結合・接触と同精度では判定できない、というのが正確な記録です。

## 判断できること
- 接触形成では、加工への反応が水素結合と同じ形です。間引き6フレームでは全幅で残存率 0.84〜0.99、間引き3フレームでは 0.62〜0.84 で、順序シャッフルは 0.93〜1.21、時間逆転は 0.94〜1.13 でした。つまり接触でも、指導力は時間の順序ではなく、履歴期間中の距離の分布（平均、最小値、閾値以下にいた割合）の側にあります。事前に固定した読み方に沿うと、「指導力は時間の順序ではなく距離の分布にある」という形は、水素結合と接触の2現象で共通し、現象によらないことが支持されます。
- 塩橋形成については、この土台のままでは判定を持ち越します。テスト候補116件・陽性8〜11件では残存率が大きく振れ、10 ns先は土台の指導力自体が負（−0.041）で残存率が解釈できず、90 ns先のシャッフル 0.06 も陽性8件の揺れと区別できません。塩橋で水素結合・接触と同じ判定をするには、候補を増やす条件変更（タンパク質数の増加や候補範囲の見直しなど）が別途必要です。
- 接触の指導力は水素結合より大きく、全幅で AUPRC の差 +0.152〜+0.232 でした。塩橋の指導力は幅によって大きく違い（1 ns先 +0.047、5 ns先 +0.277、90 ns先 +0.368、10 ns先 −0.041）、候補数の少なさとあわせて、幅ごとの値を1つずつ読む必要があります。

## まだ分からないこと
- 塩橋形成で、指導力が時間の順序ではなく距離の分布にあるかどうかは、この土台では分かりません。候補不足のためです。
- 接触と水素結合で指導力の大きさが違う理由（接触の方が大きいこと）は、この実験だけでは分かりません。候補の作り方や陽性率、距離の定義の違いが絡んでいる可能性があります。
