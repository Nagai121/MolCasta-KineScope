# K40 静的な特徴を増やすと、実の平均はもっとよく予測できるか（資料Dの条件、水素結合）

## 問い

K23 では、資料Dの静的な特徴（7つ）から実の平均を予測したときの残差は 0.492 Å で、生成器の誤差とほぼ同じでした。ただ、使った静的な特徴は資料Dの7つだけです。もっと豊かな静的な特徴を使えば、実の平均がもっとよく予測できるかもしれません。

## 対象と条件

- K23 と同じ候補（資料Dの条件、水素結合形成、6タンパク質×3複製、14,582件）。目的変数は実の平均＝11点の履歴系列の平均です。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、評価は 1mix_A・2qt4_A（4,972件）です。
- 豊かな静的特徴は 99 個で、資料Dの7つを先頭に含む形です。起点のフレーム（1 ns）だけから取れるもので、残基の種類（20アミノ酸の one-hot、両残基）、原子名（one-hot、両原子）、残基間の隔たり、Cβ間距離、局所の鎖の形（Cαの i±2 距離、ドナー→アクセプター方向と Cα方向・鎖方向のなす角）、局所の密度（ドナー・アクセプター・中点まわりの重原子数）、競合する相手（4 Å以内の他の O・N の数、最も近い他の O・N までの距離）、詰まり具合（他の重原子までの最短距離）、残基の大きさと近傍の残基数です。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 予測器は HistGradientBoostingRegressor です。資料Dと同じ設定（120本、学習率0.075、葉31、葉あたり最小15件、L2 0.02）で、豊かな特徴でも同じ設定を使い、容量を大きくした設定（400本、学習率0.05、葉63、葉あたり最小10件）と Ridge も比べました。

## 結果（評価タンパク質での残差）

| 条件 | 残差の標準偏差 | R² | 相関 |
|---|---:|---:|---:|
| 起点の距離をそのまま予測値にする | 0.4891 | 0.684 | 0.834 |
| 資料Dの7特徴（K23 の再現） | 0.4921 | 0.687 | 0.831 |
| 豊かな99特徴（同じ設定） | **0.4698** | 0.716 | 0.848 |
| 豊かな99特徴（容量を大きく） | 0.4794 | 0.704 | 0.841 |
| 豊かな99特徴（Ridge） | 0.4813 | 0.702 | 0.839 |

資料Dの7特徴での残差 0.4921 は K23 の値と完全に一致しました（再現の確認）。豊かな特徴では 0.4698 までしか下がらず、改善は 0.022 Å（約4.5%）にとどまりました。レプリカ間のばらつき 0.249 Å と比べると、依然として約1.9倍です。容量を大きくしても良くならず、むしろ悪くなりました（学習側の残差は 0.139 まで下がるのに評価側は 0.479 で、学習タンパク質への過適合です）。

## グループごとの寄与（豊かな特徴から1グループずつ抜いたときの評価残差）

| 抜いたグループ | 評価残差 |
|---|---:|
| なし（全部入り） | 0.4698 |
| 残基の種類 one-hot | 0.4688 |
| 原子名 one-hot | 0.4737 |
| 局所の密度・競合・詰まり具合 | 0.4804 |
| 幾何（Cβ距離・鎖の形・角度） | 0.4742 |
| 近傍の残基数・残基の大きさ | 0.4746 |
| 資料Dの7特徴 | 0.5868 |

どのグループを抜いても悪化は小さく、1つのグループが情報を持っているわけではありません。資料Dの7特徴を抜くと 0.5868 まで悪くなり、追加した特徴だけでは資料Dの7特徴に及びません。起点の距離などが持つ情報が中心で、追加した特徴はその上に少しだけ上乗せする形です。

## 結論

先に固定した読み方に沿うと、後者の側です。豊かな静的な特徴を使っても残差は 0.49 前後（0.470）にとどまり、0.492 よりずっと小さくはなりませんでした。入力の状態の不足という読みが残ります。ペアの平均の情報は、起点の構造から取れる静的な特徴の中には、レプリカ間のばらつきの水準（0.249）まで届くほどは含まれていません。残差の大部分は、溶媒の配置や速度といった、起点の構造には無い状態の側にあると見られます。

## ファイル

- `k40_build.py`：起点フレームからの豊かな静的特徴の作成（18軌道分）
- `k40_eval.py`：学習・評価とグループごとの寄与の計測
- `k40_results.json`：全条件の残差（標準偏差・平均・MAE・R²・相関）と K23 の物差し
- 特徴量そのものは `~/workspace/k40/out/` にあります（軌道ごとに 1ファイル、Xrich・X7・real_mean など）
