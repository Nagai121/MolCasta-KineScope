# K3-03: ずれと電場の関係（強い土台、水素結合の形成）

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる検証で、K3 系列（軌道が知っていて静的構造が知らないペアの物理的な状態は何か）の一つです。ずれ（0〜1 ns の平均距離の実測値から、静的構造だけの予測を引いたもの）の現れとして、初期構造の部分電荷が作る電場がずれと一緒に動くかを測ります。
- 状態: 完了。電場はずれと一緒に動きませんでした。ペアを結ぶ方向の電場の成分との相関はピアソン +0.012・スピアマン +0.037、中点での電場の大きさとの相関はピアソン −0.014・スピアマン −0.024 で、先に固定した「関係あり」の目安（絶対値 0.3）に遠く届きません。静的な予測に電場を足しても、ずれのばらつきは 0.600 Å から 0.599 Å とほぼ変わりませんでした（「ずれの大部分を説明できた」の線は 0.30 Å）。

## 1. 何を確かめる実験か

強い土台（K06(b) の条件、未見 100 タンパク質×3レプリカ、水素結合の形成の候補ペア 163,074件）でずれを作り直し、各ペアについて起点フレーム（履歴のフレーム 10）の構造から次の 2 つの量を計算して、ずれとの関係を測ります。

- ペアを結ぶ方向の電場の成分: ペアの中点での電場ベクトルと、ドナーからアクセプターへの単位ベクトルの内積。
- ペアの中点での電場の大きさ: その電場ベクトルの長さ。

読み方は先に固定しました。

1. ずれとの相関（ピアソンとスピアマン、全体とタンパク質ごと）で、絶対値 0.3 以上を「関係あり」の目安にします（K2-03 と同じ線）。
2. 静的な予測にその量を足したときに、ずれのばらつき（テストでの残差の標準偏差）が 0.30 Å 以下になれば「ずれの大部分を説明できた」とします。下限は 0.249 Å です（レプリカ間で平均そのものがずれる大きさ）。
3. 対照として、その量を別のペアのものと入れ替えた場合に効果が消えることも確かめます。

## 2. 条件

- ずれは K39・K42 と同じ作り方です。実の平均は履歴 11 フレーム（フレーム 0〜10）のドナー・アクセプター間距離の平均で、静的な予測は静的特徴 5 個から実の平均を予測したもの（線形回帰と HistGradientBoosting 回帰の 2 通り、GBM は 160回・学習率 0.065・葉 15・葉あたり最小 20・L2 0.15・種 20261121）。どちらも較正用の 8 タンパク質（候補 13,808件）だけで当てはめ、テスト側の統計は使いません。
- 電場の計算: 部分電荷は CHARMM36（2022年7月版の GROMACS 移植版、MacKerell 研究室の配布ファイル）の重原子の電荷を使いました。軌道の保存データが重原子だけのため、水素の電荷は含みません。ヒスチジンの電荷は主の計算では HSE（NE2 側に水素がある形）とし、感度の確認として HSD（ND1 側に水素がある形）でも計算しました。末端はパッチを当てました（N 末端は NH3+ の形: N が −0.30 など、C 末端は COO− の形: C が +0.34、OT1/OT2 が各 −0.67）。電場は、ドナー原子とアクセプター原子自身を除く全重原子の電荷から、中点で計算しました（クーロンの法則、周期境界は最小イメージ、単位は V/Å）。
- 座標は ATLAS の解析データ（MiniTopol 経由で取得）から取り直しました。前提の確認として、読み直した座標から計算したドナー・アクセプター間距離が、K06(b) の保存値（フレーム 10 の距離と 11 フレームの平均）と全ペアで一致すること（最大の差 2×10⁻⁶ Å 以下）を、108 タンパク質×3レプリカすべてで確かめました。
- 実行はローカルVM です。軌道の取得と量の計算は 108 タンパク質分で約 2 時間（取得が律速）、相関と当てはめの計算は数十秒でした。sklearn の学習はスレッド数を 1 に絞りました。

### 前提の確認（ずれの作り直し）

テストでのずれのばらつきは、GBM の残りで標準偏差 0.600 Å、線形の残りで 0.608 Å で、K42 の記録（GBM 0.60 Å、線形 0.61 Å）と一致しました。較正側では GBM 0.528 Å、線形 0.565 Å でした。

電場の分布（テスト全体）: 方向成分は平均 −0.215 V/Å・標準偏差 5.889 V/Å（絶対値の中央値 1.84 V/Å）、大きさは平均 5.35 V/Å・中央値 4.56 V/Å でした。大きさが 50 V/Å を超えるペアは全体の 0.25% で、中点のすぐ近くに電荷のある原子が来たペアに限られます。ピアソンの相関はこの少数の大きな値に引っ張られやすいため、スピアマンの値とあわせて読みます。

## 3. 結果

### ずれとの相関（テスト全体、163,074件）

| 量 | GBM のずれ: ピアソン | GBM のずれ: スピアマン | 線形のずれ: ピアソン | 線形のずれ: スピアマン |
|---|---:|---:|---:|---:|
| ペアを結ぶ方向の電場の成分 | +0.012 | +0.037 | +0.022 | +0.043 |
| ペアの中点での電場の大きさ | −0.014 | −0.024 | −0.025 | −0.044 |

タンパク質ごと（3レプリカをまとめて 100 タンパク質で計算）のピアソン相関は、方向成分で中央値 +0.014（四分位範囲 −0.007〜+0.037）、大きさで中央値 −0.013（四分位範囲 −0.034〜+0.003）で、絶対値 0.3 以上になったタンパク質はどちらも 0 件でした。

ヒスチジンの電荷を HSD に変えた感度の確認でも形は同じでした（方向成分: ピアソン +0.012・スピアマン +0.037、大きさ: ピアソン −0.014・スピアマン −0.024）。

### 静的な予測に電場を足したときの、ずれのばらつき

| 当てはめ | 静的な予測だけ | 電場 2 量を足した | 入れ替え対照（GBM） |
|---|---:|---:|---:|
| GBM 回帰 | 0.600 Å | 0.599 Å | 0.605 Å |
| 線形回帰 | 0.608 Å | 0.608 Å | ― |

「ずれの大部分を説明できた」の線（0.30 Å）には遠く届きません。GBM で 0.0016 Å だけ減っていますが、入れ替え対照（別のペアの電場を割り当てたもの）では 0.605 Å と土台より悪くなることからも、この減り方は情報によるものとは読めません。入れ替え対照の相関は、方向成分でピアソン +0.003・スピアマン −0.001、大きさでピアソン −0.000・スピアマン −0.013 と、ほぼ 0 でした（もとの相関もほぼ 0 なので、消える効果自体がありませんでした）。

## 4. 判断

先に固定した読み方に沿うと、**電場は「この量ではない」** です。起点フレームの構造の部分電荷（重原子）が作る電場は、ペアを結ぶ方向の成分でも中点での大きさでも、ずれと一緒には動きません。ずれ（ばらつき約 0.60 Å）が何の現れなのかは、静的な電場では説明できませんでした。

## 5. 読みの注意点

- 電場は重原子の電荷だけで計算しています。水素の電荷（たとえば背骨の NH の +0.31）を含む本来の力場の電場とは違います。ただし、ずれとの相関がピアソン・スピアマンとも 0.05 未満と小さいため、水素の分を足しても形が大きく変わる見込みは薄いと考えます。これは見立てであり、測ってはいません。
- 電場は起点フレーム（フレーム 10）の一時点の構造から計算しています。履歴の間の電場の動き（平均など）は測っていません。
- 相関は「一緒に動くか」だけを見ています。非線形な関わりは、当てはめに足す形（GBM）でも拾いに行きましたが、そちらでもばらつきは減りませんでした。

## 訂正（2026-11-25、割り当て文の訂正）

割り当て文の「ずれのばらつきは約 0.49 Å」は資料D条件の値（K23 の静的7特徴からの残差 0.492 Å）で、強い土台では 0.6002 Å（GBM のずれ、テスト側）が正しい値です。この実験でも同じ値を測り直しました（GBM 0.6002 Å、線形 0.6076 Å）。下限の 0.249 Å も資料D条件で K23 が測った複製間のばらつきで、強い土台での測り直しは記録にありません。判定の線（0.30 Å 以下）は変わりませんが、強い土台で 0.30 Å が届きうる線かは、下限の測り直しがないと分かりません。

力場の確認: ATLAS の論文（Vander Meersche ら、Nucleic Acids Research 52, D384–D392, 2024、doi:10.1093/nar/gkad1084）には、軌道は GROMACS v2019.4 で CHARMM36m（2020年7月版）の力場、TIP3P の水、150 mM NaCl で計算したと書いてあります。使った電荷表は CHARMM36 2022年7月版の GROMACS 移植版ですが、CHARMM36m は CHARMM36 の CMAP（二面角の補正）を直した版で、標準的な残基の部分電荷は変わらないため、電荷の出所としては合っています。ただし、ヒスチジンの電荷の取り方は軌道の保存データに水素がないため記録からは決められず、主の計算は HSE、感度の確認は HSD で行いました（両方で形は同じでした）。
