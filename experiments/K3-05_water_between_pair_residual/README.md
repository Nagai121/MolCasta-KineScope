# K3-05: ペアの間にある水と、ずれ（平均距離の実測値と静的な予測の差）の関係

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる、新しい系列 K3（問いは「軌道が知っていて、静的構造が知らない、ペアの物理的な状態は何か」）の1件。ずれ（0〜1 ns の平均距離の実測値から、静的構造だけの予測を引いたもの）を指導力の主な現れとして、その正体の候補として「ペアの間に割り込んでいる水」を測る。
- 状態: 完了。ペアの間にある水の量とずれの相関は、最も強いものでも −0.143（最初の 0.1 ns の橋渡し水の数の平均）で、先に固定した「関係あり」の目安（相関の絶対値 0.3）に届かなかった。静的な予測に水の量を足しても、ずれのばらつきは 0.600 Å から 0.585 Å までしか減らず、0.30 Å の線には遠く届かない。ペアの間にある水は、ずれの正体ではない。弱い負の関係（水が多いペアほど、実の平均が静的な予測より短い）はあり、別のペアの値と入れ替える対照では消えるので、小さいが本物の関係ではある。

## 1. 何を確かめる実験か

強い土台（K06(b)、水素結合の形成、未見100タンパク質×3レプリカ、候補 163,074件）のペアについて、初期構造と最初の 0.1 ns で「ペアの2原子の両方から 3.5 Å 以内にある水分子」の量を取り、ずれとの関係を測る。

K36/K49 で測ったのは残基全体の水の環境（ドナー・アクセプターの近くの水の数など）で、ここで測るのはペアの間に割り込んでいる水に限った量であり、別の量である。K36/K49 の結果は「水の環境は安定した担い手とは読めない」だったが、間にいる水だけに絞った量は測られていなかった。

判定は先に固定した。

1. 相関の絶対値 0.3 以上を「関係あり」の目安にする（K2-03 と同じ）。
2. 静的な予測に水の量を足して、ずれのばらつき（標準偏差）が 0.30 Å 以下になれば「ずれの大部分を説明できた」とする。下限は 0.249 Å。
3. 相関が高いだけでは正体とは言わない。原因の確認は後の手順で行う。

あわせて対照として、テスト側の水の量を別のペアのものと入れ替えた（全体を並べ替えた）場合に、相関とばらつきの減りが消えることを確かめる。

## 2. 条件

- ずれは K39/K42 と同じ作り方。実の平均（履歴の統計量のうち平均）を、静的な特徴5個だけから線形回帰と HistGradientBoosting 回帰（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）で予測し、その差を取る。当てはめは較正用の8タンパク質の候補（13,808件）だけ、評価は未見100タンパク質の候補（163,074件）。ずれのばらつきはテスト側で線形 0.608 Å、GBM 0.600 Å で、K42 の記録（線形 0.61 Å、GBM 0.60 Å）と一致した。なお、判定の線で使う 0.249 Å は資料Dの条件で測った複製間のばらつきの下限で、強い土台での測り直しは記録にない。今回の比較は、割り当てで固定された 0.30 Å の線に対して行う。
- 水の量は、候補の2原子（K06(b) の保存済み特徴量のペアの通し番号）について、完全形式（水を含む形式）の軌道から取る。使うのは完全形式のフレーム0と10で、解析版のフレーム0と1（履歴の 0 ns と 0.1 ns、つまり初期構造と最初の 0.1 ns）に対応する。距離はフレームごとの箱で最小イメージ。水は SOL 残基の酸素。
- 対応の確認: フレーム0と1のペア距離を完全形式から計算し、G05 の系列と突き合わせた。108タンパク質×3レプリカすべてで最大の差は 0.0042 Å 以内だった（原子の並びとフレームの対応は正しい）。
- 量（候補ごと）:
  - n_bridge_f0 / n_bridge_f1: フレーム0 / フレーム1で、2原子の両方から 3.5 Å 以内にある水の数
  - n_bridge_mean: 上の2つの平均
  - has_bridge_f0: フレーム0で橋渡し水が1個以上あるか（0/1）
  - frac_frames_bridge: フレーム0と1のうち、橋渡し水が1個以上あるフレームの割合
  - persistence: フレーム0の橋渡し水のうち、フレーム1でも橋渡し水であるものの割合（フレーム0に橋渡し水が無い候補では 0）
- 完全形式の軌道は手元に無かったため、ATLAS から取り直した。zip は1タンパク質あたり 3.0〜7.6 GB あるため、HTTP の範囲リクエストで目次と各ファイルの先頭だけを取り、XTC は先頭の数 MB（フレーム0と10を含む）だけを伸ばして使った。108タンパク質すべてで上の対応確認が通っている。4 GB を超える zip（ZIP64 形式）の8タンパク質は、目次の読み方を直して取り直した。抽出が終わったタンパク質から、取得した先頭ファイルは消した。

### 水の量の水準（テスト全体の平均）

橋渡し水はまれである。フレーム0で橋渡し水の数の平均は 0.065 個、1個以上ある候補は全体の 6.2%。フレーム1では 0.068 個。persistence の平均は 0.011（フレーム0に橋渡し水がある候補が自体少ない）。

## 3. 結果

### 相関（テスト全体、163,074件）

| 量 | Pearson（GBM のずれ） | Spearman（GBM のずれ） | Pearson（線形のずれ） |
|---|---:|---:|---:|
| n_bridge_f0 | −0.115 | −0.116 | −0.114 |
| n_bridge_f1 | −0.123 | −0.123 | −0.123 |
| n_bridge_mean | −0.143 | −0.143 | −0.142 |
| has_bridge_f0 | −0.114 | −0.116 | −0.114 |
| frac_frames_bridge | −0.139 | −0.142 | −0.139 |
| persistence | −0.053 | −0.056 | −0.050 |

符号はすべて負で、橋渡し水が多いペアほど、実の平均が静的な予測より短い（ずれが負）という向き。最も強い n_bridge_mean でも絶対値 0.143 で、目安の 0.3 の半分以下。

タンパク質ごとに見ても同じ形で、Pearson の平均は −0.049〜−0.145、絶対値 0.3 以上になったタンパク質は、どの量でも 0 だった（persistence は、ばらつきのある 97タンパク質での数え）。

### 静的な予測に水の量を足したときの、ずれのばらつき

当てはめは較正用だけ、評価はテスト側。静的な特徴だけの予測では、ずれのばらつきは GBM で 0.600 Å、線形で 0.608 Å。

| 足す量 | GBM | 線形 |
|---|---:|---:|
| n_bridge_f0 | 0.592 Å | 0.604 Å |
| n_bridge_f1 | 0.590 Å | 0.603 Å |
| n_bridge_mean | 0.585 Å | 0.601 Å |
| has_bridge_f0 | 0.592 Å | 0.604 Å |
| frac_frames_bridge | 0.585 Å | 0.601 Å |
| persistence | 0.599 Å | 0.607 Å |
| 6つの量すべて | 0.585 Å | 0.601 Å |

最も減る場合でも GBM で 0.600 → 0.585 Å（減りは 0.015 Å、割合で 2.5%）。6つの量を全部足しても同じ 0.585 Å。0.30 Å の線には遠く届かない。

### 対照（別のペアの値と入れ替え）

テスト側の水の量を全体で並べ替えると、相関はどの量でも 0.001 前後まで消えた。ばらつきも、入れ替えた値では 0.604〜0.610 Å となり、減りは消えた（静的な特徴だけの 0.600 Å よりむしろ少し大きい）。もとの弱い関係は、並べ替えで消える種類のものであることは確かめられた。

## 4. 読み取り

- **ペアの間にある水は、ずれの正体ではない。** 相関は最も強くても −0.143 で目安の 0.3 に届かず、静的な予測に足してもばらつきは 0.600 Å から 0.585 Å までしか減らない。判定の線（0.30 Å）との差は大きい。
- **弱い負の関係は本物である。** 符号は6つの量すべてで負にそろい、タンパク質ごとの平均でも同じ向きで、別のペアの値と入れ替えると消える。橋渡し水がいるペアは、静的な予測が思うより平均距離が少し短い、という程度の関係である。
- 橋渡し水自体がまれ（フレーム0で1個以上ある候補は 6.2%）なため、この量がずれ全体（ばらつき 0.60 Å）の大きな部分を担うことは、数の上でも考えにくい形だった。

## 5. 判断できること・まだ分からないこと

- 判断できること: ペアの間に割り込んでいる水（2原子の両方から 3.5 Å 以内、初期構造と最初の 0.1 ns）は、ずれとは弱い負の関係（相関 −0.05〜−0.14）を持つが、ずれの大部分を説明しない。K36/K49 の残基全体の水の環境に続いて、間にいる水に絞った量でも、水はないものとして候補から外してよい形になった。
- まだ分からないこと: ずれの正体そのものは、この実験では分からない。弱い負の関係がなぜあるのか（水が間に入るペアは構造的に何が違うのか）は測っていない。橋渡し水の定義は今回の1通り（両方から 3.5 Å 以内）だけで、別の定義（片側だけ近い水、水の向きなど）で違う結果になる可能性は残る。
