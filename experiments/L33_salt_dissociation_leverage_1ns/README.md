# L33: L01 の曲がりを塩橋の解離で測る（K15 の土台、1 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 1 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は 0 ns の 0.609 から緩やかに上がり、0.8 ns で 1.260 を頂点に、1.0 ns で 0.921 でした。増え分は特定の場所に集中せず、段と呼べる跳ねはありません。塩橋の形成（L27）と違い、解離では曲がりが単調に近い形になりました。

## 1. 何を確かめる実験か

L27 と同じ段取りで、現象を塩橋の解離に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点で結合しているペア）。学習 735件、テスト 360件、1 ns先の陽性 101件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量：最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.3734、全部入り 0.5522、利得 全体 +0.1788／平均 +0.1148 で、K2-13 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G09 の記録と一致しました（0.1 ns で 0.693、0.5 ns で 0.951）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.4 ns（全体 0.803）**。平均では 0.3 ns（0.905）。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.5 ns（全体 0.951）**。平均では 0.3 ns（0.905）。
3. **増え幅がいちばん大きい場所: 全体では 0.7→0.8 ns（+0.166）**、平均では 0.2→0.3 ns（+0.514）。全体の増え分は +0.08〜+0.17 が 0.4 ns 以降に分散しており、突出した段はありません。全体の段の位置（0.7→0.8 ns）でのタンパク質ごとの増え分は中央値 0.000、正だったのは 17タンパク質のうち 35% でした。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 17タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 塩橋の解離・1 ns先では、回復率は覆う長さに対して緩やかに積み上がる形で、0.8 の線は 0.4 ns、0.9 の線は 0.5 ns で届きます。形成側（L27）の上下する曲がりとは対照的です。
- 頂点は 0.8 ns（1.260）で、1.0 ns（全部の平均、0.921）より高い値です。全部入りの分母が 6統計量の利得であるため、平均だけの条件がそれを上回ることがあります（L02 でも同じ形が見えました）。
- 区間は全体で幅 0.6〜1.3 とまだ広く、線に届く長さの前後（0.3〜0.6 ns）の順序までは決められません。
