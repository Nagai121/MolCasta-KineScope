# K2-39: K2-06 の問い（漂いが足しになるか）を塩橋の解離で測る（K15 の広げた条件、塩橋の解離、1 ns先）

- 確かめる問い: K2-06 は水素結合の形成（資料Dの条件、1 ns先）で、履歴の漂い（前半の平均 − 後半の平均）を全部の平均の上に足しても足しにならないことを示した（(c) 0.4834 は (b) 0.4865 を −0.0031 下回る）。水素結合の解離（K2-15）では漂いは足しになった（+0.0232）。塩橋の形成（K2-30）では足しにならなかった（−0.0178）。接触の形成（K2-34）では足しになった（+0.0367）。ここでは同じ問いを塩橋の解離で測る。
- 状態: 完了。**先に固定した読み方に沿い、「漂いは足しにならない」と記録した。**(c) 全部の平均＋漂い（0.5213）は (b) 全部の平均だけ（0.5382）を AUPRC で −0.0169 下回り、+0.01 の線に届かなかった。ただし漂いだけ（(a)）の利得は全部入りの利得の 0.556 と、漂いの系列ではいちばん大きい。漂いだけでは情報があるのに、全部の平均の上に足すと予測が悪くなる形である。

## 1. 何を確かめる実験か

K15 の広げた条件（学習 58 タンパク質、テスト 30 タンパク質）で、塩橋の解離、1 ns先。静的な特徴量に足す履歴の情報を「(a) 漂いだけ」「(b) 全部の平均だけ」「(c) 全部の平均＋漂い」の 3 通りに変え、(c) が (b) を AUPRC で +0.01 以上上回るかを見る。K2-06・K2-15・K2-30・K2-34 と同じ形で、現象だけを塩橋の解離に変えた。

読み方は結果を見る前に固定した（K2-06 と同じ）。

- (c) が (b) を AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) 漂いだけの利得も記録する。全部入りの利得に対する割合もあわせて記録する。
- AUPRC の差も記録する。

## 2. 条件

- 土台は K15 の広げた条件（塩橋の解離）。学習 58 タンパク質、テスト 30 タンパク質（`experiments/K15_saltbridge_expansion/split.json` の分け方。元の 6 タンパク質に学習 54・テスト 28 を足したもの）、候補は学習 735件・テスト 360件（テスト陽性 101件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）。境界は 4.0 Å。
- 塩橋の解離の定義（K53 と同じ）: 候補は形成と同じ正側・負側の規則（正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2、距離は荷電重原子ペアの最小値）で、起点フレーム10の最小距離が 4.0 Å 以下（塩橋ができている状態）で、配列距離が2以上の残基ペア。ラベルは予測先のフレームで最小距離が 4.0 Å を超えること（解離した）を 1 とする。形成の候補（起点で 4.0 Å 超〜10.0 Å 以下）とは重ならない。
- K53 のキャッシュ（`~/workspace/kinescope/work/k53_cache/` の塩橋の解離の距離系列）を再利用した。距離はフレームごとの箱を軸ごとに扱って計算済み。実行はローカルVM（学習 735件・テスト 360件と行数が少なく、約 7 秒で終わったため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 漂いの定義（K2-06 と同じ）

| 名前 | フレーム | 時刻の範囲 | 特徴量 |
|---|---|---|---|
| 前半 | [0..4] | 0〜0.4 ns | その5フレームの距離の平均 |
| 後半 | [6..10] | 0.6〜1.0 ns | その5フレームの距離の平均 |
| 全部 | [0..10] | 0〜1.0 ns | 11フレーム全部の距離の平均 |
| 漂い | ― | ― | 前半の平均 − 後半の平均 |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である**（K2-01・K2-06 と同じ）。

漂いが正なら「前半のほうが距離が大きい」、負なら「後半のほうが距離が大きい」という意味である。解離では、距離が開く方向に動いた（漂いが負の）ペアほど解離しやすい、という読みが直感に合う。

### 注意：土台の利得が小さい

塩橋の解離は土台の利得が小さい（1 ns先で +0.1788）。割合の読みには留保がつく。AUPRC の差とあわせて読む。タンパク質ごとではさらに、利得が 0 に近いタンパク質が多く、陽性が 0 件のタンパク質も 3 つある（1uha_A、1pch_A、2hng_A）。利得が 0 のタンパク質は 5 つある。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3734、全部入り 0.5522、利得 +0.1788 で、K53 の記録（`experiments/K53_saltbridge_dissociation_carrier/README.md` 第4節と `results.json`）と小数第4位まで一致した。テスト陽性も 101件で K53 の記録と一致した。前半・後半・両方・全部の平均も K2-13 の記録と小数第4位まで一致した（前半 0.5170、後半 0.5380、両方 0.5778、全部 0.5382）。

## 4. 先に固定した読み方への答え

**(c) が (b) を −0.0169 下回り、+0.01 の線に届かなかったため、「漂いは足しにならない」と記録する。**

ただし (a) 漂いだけの利得は +0.0995 で、全部入りの利得の 0.556 と、漂いの系列ではいちばん大きい（K2-06 の 0.231、K2-15 の 0.314、K2-16 の −0.075、K2-25 の 0.375、K2-30 の 0.200、K2-34 の 0.057 を上回る）。漂いだけでは利得の半分以上が戻るのに、全部の平均の上に足すと予測が悪くなる。漂いの情報は、全部の平均と重なっており、1 つの量として足す形では取り出せない。

K2-13 の「前半と後半の両方」（0.5778）と (c)（0.5213）の差は −0.0565 で、前半と後半の両方を入れたときの上積みは、漂いを 1 つの量として足した形では再現できなかった。K2-06（水素結合の形成、1 ns先）でも同じ形だった（両方 0.4902 に対し (c) 0.4834）。効いているのは「動き」ではなく、2 つの時間帯それぞれの「水準」と考えられる。

## 5. K2-06・K2-15・K2-16・K2-25・K2-30・K2-34 との比較

| 実験 | 現象・予測幅 | (a) 漂いだけの割合 | (c) − (b) の AUPRC の差 | 判定 |
|---|---|---:|---:|---|
| K2-06 | 水素結合の形成、1 ns先 | 0.231 | −0.0031 | 足しにならない |
| K2-15 | 水素結合の解離、1 ns先 | 0.314 | +0.0232 | 足しになる |
| K2-16 | 水素結合の形成、30 ns先 | −0.075 | −0.0014 | 足しにならない |
| K2-25 | 水素結合の解離、30 ns先 | 0.375 | +0.0154 | 足しになる |
| K2-30 | 塩橋の形成、1 ns先 | 0.200 | −0.0178 | 足しにならない |
| K2-34 | 接触の形成、1 ns先 | 0.057 | +0.0367 | 足しになる |
| K2-39 | 塩橋の解離、1 ns先 | **0.556** | **−0.0169** | **足しにならない** |

漂いの役割は、形成と解離で単純には分かれない。水素結合の解離では 1 ns先も 30 ns先も漂いが足しになったが、塩橋の解離では足しにならなかった。形成でも、接触では足しになったが、水素結合と塩橋では足しにならなかった。現象と向きの組み合わせで、漂いの役割が違う。

塩橋のなかでも、形成（K2-30、−0.0178）と解離（K2-39、−0.0169）で (c) − (b) の差はほぼ同じ大きさで、どちらも足しにならない。ただし (a) 漂いだけの割合は形成の 0.200 に対し解離では 0.556 と大きく違う。解離では漂いだけでも利得の半分以上が戻るが、全部の平均の上に足すと悪くなる、という形である。

## 6. 判断できること・まだ分からないこと

- 判断できること: 塩橋の解離では、漂いを全部の平均の上に 1 つの量として足しても、予測はよくならない（−0.0169）。先に固定した読み方では「漂いは足しにならない」。漂いだけでは利得の 0.556 が戻るので、漂いの情報そのものが無いわけではない。
- まだ分からないこと: 漂いだけの利得が 0.556 と大きいのに、全部の平均と組み合わせると悪くなる理由は、この実験だけでは分からない。全部の平均と漂いが強く重なっているのか、漂いを足すことで HistGBM が平均の読み方を変えてしまうのかは、測っていない。タンパク質ごとでは (c) − (b) の符号が分かれ、合算の −0.0169 が一般の形かも、この実験だけでは決められない。
