# K66: 平均の指導力は、凍結した本体の予測の高さによって違うか（強い土台、水素結合）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。高いほうの組では平均だけで利得の 0.89〜1.09 が全予測幅で戻りましたが、低いほうの組では陽性がほとんど無く、戻り方は測れる形になりませんでした。事前に固定した読み方に沿うと組によって戻り方ははっきり違うため「平均の指導力は本体の予測と関係する」という読みになりますが、この違いは陽性の有無の違いと分けられていない点が最大の留保です。

## 1. 何を確かめる実験か

これまで平均が担い手だと分かりましたが、平均の指導力が凍結した本体の予測と関係するかは測っていません。候補を本体の予測確率で分け、組ごとに利得と平均だけの戻り方を確かめます。

読み方は先に固定しました。どちらの組でも平均だけで利得の8割以上が戻れば、平均の指導力は本体の予測と関係しません。組によって戻り方がはっきり違えば、平均の指導力は本体の予測と関係します。「8割以上」は全幅または多くの幅での読みとし、1 ns先を主判断とします。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A）で学習し、未見100タンパク質×3複製（163,074件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`、108タンパク質分）をそのまま使いました。軌道の取り直しも、本体の読み込みも、生成器の読み込みも行っていません。
- 補正モデルの入力は、静的5特徴（本体の予測確率、起点距離、基礎記述子3個）に履歴の量を足す形です。実履歴10特徴は、実軌道の11フレーム（0〜1 ns）の系列から作った「最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å 以下割合、4.5 Å 以下割合、増えたステップの割合」です。
  - 静的のみ: 静的5特徴だけ
  - 全部入り: 静的＋実履歴10特徴（K06(b) の実履歴条件そのもの）
  - 平均だけ: 静的＋実履歴の平均の列だけ（history[:,1]）。K21 の条件 (a) と同じです。
- 分け方（結果を見る前に固定）: 候補を凍結した本体の予測確率（`r*_frozen`、静的特徴の0列目）で分けます。境目は、評価集合全体（163,074件）の凍結確率の中央値 **0.0030838** で、学習側（較正用8タンパク質）にも同じ境目を当てました。つまり「高い・低い」は両側で同じ確率の境目です。高いほうは frozen >= 0.0030838、低いほうは frozen < 0.0030838 です。
- 各組について、学習と評価の両方をその組だけに絞って補正モデルを学習し直し、評価しました（K55 の幅分けと同じやり方。全体で学習して組ごとに評価するのではありません）。
- K12 との違い: K12 は生成6統計量のうち1列を実系列の値に差し替える形でしたが、本実験の平均だけの条件は、他の履歴統計量を入れずに平均の列だけを足す K21 の形です。差し替えではなく「足す」実験です。
- 利得は静的補正に対する AUPRC の改善で、タンパク質ごとの平均（マクロ）を主、全体をまとめた値（ミクロ）を従としました。戻り率は「平均だけの利得÷全部入りの利得」です。
- 対照の確認: 組を分けずに測った条件は、静的補正と全部入りが全予測幅で K06(b) の記録と小数第4位まで一致しました（1 ns先で静的 0.4539、全部入り 0.5251、利得 +0.0712）。平均だけの条件も K21 の記録と一致しました（1 ns先の戻り方マクロ 0.958、K21 は 0.957）。

## 3. 結果

### 組の大きさと陽性の偏り

凍結した本体の予測確率は全体としてとても小さく、中央値は 0.0030838 でした。中央値で分けると、評価集合の陽性は高いほうの組にほぼ全部集まりました。

|---|---:|---:|---:|---:|
| 高いほう | 6,795 | 81,537 | 11,641 | 14.3% |
| 低いほう | 7,013 | 81,537 | 71 | 0.09% |

1 ns先の陽性は全体で 11,712件で、そのうち 99.4% が高いほうの組にあります。学習側も同じ形で、1 ns先の陽性は高いほう 881件、低いほう 4件でした。低いほうの組では、予測幅ごとのテストの陽性数は 71〜255件しかありません。

## 4. 読み取り

- **高いほうの組では、平均が担い手です。** 平均だけで利得の 0.89〜1.09 が全予測幅で戻り、先に固定した目安の8割を超えました。K21 の全体の結果（0.87〜1.08）とほぼ同じ形です。
- **低いほうの組では、戻り方は測れる形になりませんでした。** ミクロでは 0.15〜0.41 と8割を下回りますが、これは「平均が担い手ではない」ことを示すのではなく、陽性がほとんど無いために利得そのものが測れていない、というのが正確な読みです。ミクロの利得は +0.003〜+0.017 で、平均だけの利得も +0.001〜+0.003 と、AUPRC の絶対値としてはほぼ 0 に近い値どうしの比です。マクロの戻り方も、含まれるタンパク質が幅ごとに違うため、幅をまたいで比べられる数値ではありません。
- 事前に固定した読み方に沿うと、組によって戻り方ははっきり違うため「平均の指導力は本体の予測と関係する」という枝に当たります。ただし、この違いは「本体の予測の高さ」と「陽性の有無」の違いを分けていません。凍結した本体の予測は陽性の有無をほぼ分けてしまうため、中央値で分けると低いほうの組には陽性が残らない、という設計上の問題です。**この実験だけでは、平均の指導力が本体の予測と関係するかは決められません。** 決められるのは、「本体の予測が低い候補には、実履歴の指導力を測るだけの陽性がそもそも無い」ということです。

## 5. 判断できること・まだ分からないこと

- 判断できること: 本体の予測が高い候補（陽性の 99.4% がここにある）では、平均だけで利得の大半が戻ります。低い候補では、実履歴の利得も平均だけの利得も、測れる大きさではありません。
- まだ分からないこと: 平均の指導力が本体の予測と本当に関係するかは、この分け方では決められません。両方の組に陽性が残る分け方（たとえば、陽性の中での予測の高さで分ける、境目を中央値より高くする、起点の距離などで陽性率をそろえてから分ける）が要ります。また、低いほうの組で全部入りのマクロの利得が 5 ns先で +0.2365 と大きいのは、27タンパク質だけの平均の揺れなのか、平均以外の統計量が低予測の候補で働いているのかも、この実験だけでは分かりません。
