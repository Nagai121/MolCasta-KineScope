# GA 静的構造による指導力代替 300試行

KineScopeでG20として測定された静的滞在率推定を出発点とする。G20は資料Dの弱い土台で、静的99特徴から推定した割合のAUPRC回復率は0.211。本実験は固定T1I2007を用いるATLASの異なるパネルと候補集合であり、数値の直接比較は行わない。GAでは開始時に利用できる静的構造だけから予測する。実履歴は学習教師と診断参照に用いる。

入力12種、生成の学習目標5種、生成器構造5種を直積で比較する。入力は距離、既存静的、局所応答、ネットワーク応答、到達確率、競合、既存特徴の併用、直進、迂回、方向差、迂回時の候補間競合、全結合。仮想変形は静的な入力特徴として用い、軌道の時刻や物理的な状態遷移を生成する方式ではない。出力は点推定、モーメントと閾値内割合、閾値に一度でも入る確率と条件付き割合、8区間の距離分布、分布と複数統計の併用。構造は線形加算、低ランク交互作用、ゲート、エキスパート混合、残差層。補正器は全試行で同型で、凍結モデルへの補正を±0.35ロジット以内に制限する。

- 実履歴の教師は起点前500 psにある5点。教師の距離分布はフレームの占有割合。
- 生成器学習12配列、補正器学習12配列、検証10配列、選定後の比較4配列。各配列の全レプリカを同じ分割に置く。生成器と補正器は別配列からそれぞれ65,536候補を抽出してCUDA学習。検証153,212候補をCPU推論。固定モデルとの学習履歴の重複や配列相同性は未監査。
- 水素結合形成の距離代理ラベル、1 ns先。候補集合・T1I2007の確率を全試行で固定。生成器は本体の静的スコアと各静的記述子を入力にする。実履歴ありの参照は別扱いで、補正器に24配列を使うため、生成条件との学習データを揃えた因果比較とは扱わない。
- 検証AUPRC最大の1方式を選定し、4配列の比較に用いる。選定にはテストを使わない。固定10配列は既存の研究にも使っている。
- チェックポイント、実測、コードのSHA-256はresults.json。個別のCUDA学習とCPU推論を行う。記録のCPU計時は重み保存も含む。

    python -m t2i.ga300
    python -m t2i.ga300_audit

既存のATLAS、MiniTopol、T1I2007、G2I前段の再現環境から実行する。

### 実行履歴

263試行の確定後に Windows の一時的なファイル置換エラーを検出した。確定済み結果を残し、記録操作が PermissionError の場合だけ100 ms間隔で再試行するラッパーから再開した。生成方式、学習条件、選定指標、元コードのSHA-256に変更はない。失敗時に記録されなかったGA264は再学習した。

## 結果

GA01〜GA300を完走。300個のチェックポイントのSHA-256が台帳と一致した。CUDAの生成器・補正器学習および中間推論を含む計時の合計は61.32秒。別途データ準備・CPU評価・保存がある。生成目標別の最高AUPRCは点0.500367、モーメント0.500580、ハードル0.500323、距離分布0.500319、併用0.500462。93/300件は検証AUPRCが凍結本体より高かった。

検証選定は GA259。仮想迂回の候補間競合を入力し、エキスパート混合で平均・ばらつき・閾値内割合・近接端を生成した。下表の評価は候補を固定した。

| 比較 | AUC | AUPRC | Brier | Log Loss | R80 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 検証 凍結T1I2007 | 0.932855 | 0.500030 | 0.043723 | 0.144245 | 24,114 |
| 検証 GA259 | 0.932870 | 0.500580 | 0.043710 | 0.144201 | 24,061 |
| テスト 凍結T1I2007 | 0.928058 | 0.470244 | 0.041071 | 0.138314 | 6,166 |
| テスト GA259 | 0.928012 | 0.469791 | 0.041057 | 0.138292 | 6,116 |

採用試行と同じ補正器学習条件に合わせた追加対照では、観測履歴のAUPRCは0.514223、静的特徴の直接補正は0.499918。生成条件の上積み+0.000550は観測履歴の上積み+0.014193の3.9%に相当する。これは検証選定後の比で、G20の回復率とは条件が異なる。

同じフレームで起点距離と凍結スコアが近い正負例の順位一致率は凍結50.84%、GA259 51.93%、観測履歴61.44%。GA259の対応付き95%区間は差+0.03〜+1.94ポイントで、300試行の選択を補正していない。同一原子ペア・同一起点の別レプリカで観測割合が異なり、静的距離と凍結スコアが近い2,939比較では、GA259が滞在率の高い側を当てた割合は50.83%。観測履歴を代替できたとは判断しない。
