# L42: 統計量6種で L05 の曲がりを測る（K06(b) の条件、水素結合の形成、10 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L39（1 ns先）では履歴の要約を平均だけから統計量6種（実験Dの定義）に広げると必要な覆う長さが 0.1 ns 縮み、L40（90 ns先）では縮まなかった。ここでは同じ土台・同じ長さの定義で予測幅 10 ns の曲がりを統計量6種で測り直し、平均だけ（L05）と比べて必要な長さが縮むかを見る。
- 状態: 完了。**統計量6種でも、必要な長さは縮まなかった。** 回復率 0.8 に届く最小の長さは 0.4 ns、0.9 に届く最小の長さは 0.6 ns（どちらも全体・タンパク質ごとの平均とも）で、平均だけ（L05）の答えと完全に同じだった。同じ長さで比べると、6種は 0.6〜0.7 ns で平均だけをわずかに上回る（全体 +0.027、+0.093）ほかは下回り、特に 0.1 ns（−0.138）と 0.9 ns（−0.142）で差が大きい。増え幅がいちばん大きい場所は 0.5→0.6 ns（全体 +0.214）だが、その直前の 0.4→0.5 ns で −0.159 の落ち込みがあり、その戻りの面が大きい。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの統計量6種」を履歴の特徴量として強い土台の補正モデルに入れたときの 10 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。比較のために、L05 と同じ作り方の「切り取りの平均だけ」の条件も同じ実行で学習し直し、回復率を並べる。

読み方は先に固定した（L39 と同じ）。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。平均だけ（L05）の答え（0.8 は 0.4 ns、0.9 は 0.6 ns、全体・平均とも）と比べて、縮んだかどうかを明記する。
2. 増え幅が最大の区間の場所と大きさを読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 10 ns先。条件ごとに学習し直す。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`、タンパク質ごとの `r{r}_series`、11点×候補数）をそのまま使う。静的特徴と履歴の要約値10個は K06(b) の保存値（`~/workspace/k06b/run/k06b_out/`）を使う。実行はローカルVM（学習24条件と premise の照合で約3分、ブートストラップ 10,000回で約38分、全体約41分。並行作業と CPU を分け合ったため L39 より遅かった）。

### 統計量6種の定義（実験Dの定義どおり、L39・L40 で確認済み）

統計量6種は、実験D（固定した 1 ns 履歴の実験）の `features_from_history` の定義をそのまま使う。出典は MolCasta-InternalResearch ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py` で、並びは次の通り。

1. 最初の値（系列の最初のフレームの距離）
2. 平均
3. 標準偏差（ddof=0、numpy の `std` の既定）
4. 最小値
5. 最後−最初（系列の最後のフレーム − 最初のフレーム）
6. 閾値以下だった割合（閾値は水素結合の形成の境界 3.5 Å。同スクリプトの `THRESH["hb"] = 3.5` で、割合は `(series <= bound).mean`）

値は float32 に落とす（同スクリプトの作り方どおり）。切り取りへの適用は、同じ式を切り取りの部分系列（フレーム 0〜k）にそのまま適用する。「最後」は切り取りの最後のフレーム、「割合」は切り取りの中での割合になる。覆う長さ 0 ns（1フレーム）では標準偏差と最後−最初は 0 になり、割合は「最初の値が 3.5 Å以下かどうか」の 0/1 になる。

### K06(b) の履歴特徴10個との関係

K06(b) の全部入りの履歴特徴10個は、同じ g05_series の11フレームから次の式で再現できる（下の premise で全数照合した）。

| 位置 | K06(b) の要約値10個 | 実験Dの6種に入るか |
|---:|---|---|
| 0 | 最初 | 入る（1番目） |
| 1 | 平均 | 入る（2番目） |
| 2 | 標準偏差 | 入る（3番目） |
| 3 | 最小 | 入る（4番目） |
| 4 | 最大 | 入らない |
| 5 | 最後−最初 | 入る（5番目） |
| 6 | 最後−直前 | 入らない |
| 7 | 3.5 Å以下割合 | 入る（6番目） |
| 8 | 4.5 Å以下割合 | 入らない |
| 9 | 増加割合（隣り合うフレームで増えた割合） | 入らない |

つまり実験Dの6種は K06(b) の10個の部分集合で、10個は6種に「最大、最後−直前、4.5 Å以下割合、増加割合」の4つを足した拡張である。したがって全部入り（11フレーム全部の要約値10個）は6種の上位集合で、覆う長さ 1.0 ns の6種の条件は、全部入りから4特徴を落とした条件にあたる。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけの1フレーム、1.0 ns はフレーム 0〜10 の11フレーム全部）。起点フレーム10（1 ns）は変えず、ラベルは 10 ns先のまま。G 系列の呼び方との対応も L02 と同じで、L42 の覆う長さ 1.0 ns は G05 の「全部」側の定義（11フレーム全部）であり、G145 の「1.0 ns」（フレーム [0..9]）とは違う。

### 条件の一覧（10 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。L05 と同じ作り方（premise の照合と比較用）。
- 切り取りの統計量6種: 静的特徴＋切り取りの統計量6種。覆う長さ 0.0〜1.0 ns の11通り（主役）。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（L02 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（結果を見る前に固定、L39 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・各長さの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。6種と平均だけの両方の系列を、同じ抽出で測っている。
- 全体の AUPRC の計算は L02・L39 と同じ numpy 実装（sklearn の average_precision_score と同じ段取り）を使い、実際の予測確率で全24条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.4 ns**（全体 0.879、タンパク質ごとの平均 0.886）。**回復率 0.9 に届く最小の長さ: 覆う長さ 0.6 ns**（全体 0.934、タンパク質ごとの平均 0.921）。平均だけ（L05）では 0.8 が 0.4 ns、0.9 が 0.6 ns（どちらも全体・平均とも）だったので、**必要な長さは縮まなかった（どちらの線でも同じ）**。ただしどちらの線も、届いた直後の 0.5 ns で回復率が線の下へ戻る（0.8 の線に対して 0.5 ns は全体 0.720）。「初めて届く長さ」で読む約束は L05 と同じで、L05 の平均だけの曲がりにも同じ戻りがある。

## 5. 読み取り

- **10 ns先では、統計量6種を使っても必要な覆う長さは縮まない**（0.8 の線で 0.4 ns、0.9 の線で 0.6 ns、平均だけと同じ）。線に届く位置だけでなく、同じ長さでの回復率もほとんどの長さで平均だけ以下で、6種が効くのは 0.6〜0.7 ns の範囲だけだった。1 ns先で見えた「平均以外の要約値が 0.6〜0.8 ns で押し上げる」形は、10 ns先では 0.6〜0.7 ns に狭まり、他の長さでは逆に下がる。
- 増え幅最大の 0.5→0.6 ns（全体 +0.214）は、直前の落ち込み（−0.159）からの戻りを含む値で、段と呼べる跳ねではない。落ち込み自体は平均だけの曲がりにもあり、タンパク質ごとの中央値でも見えるが、ブートストラップ区間は重なっており、大きさの解釈には留保がいる。
- 覆う長さ 1.0 ns では、6種だけで全部入り（要約値10個）の AUPRC に並び、わずかに上回った（全体 0.4897 対 0.4881）。この点は L39（1 ns先）と同じで、11フレーム全部を使えば残りの4特徴（最大、最後−直前、4.5 Å以下割合、増加割合）は 10 ns先でもほぼ足しになっていない。
- 費用の側は L02・L39 と同じくまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03 の形（G04 の実測との対応付け）で行う。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、10 ns先）で履歴に統計量6種を使っても、回復率 0.8 に届く最小の覆う長さは 0.4 ns、0.9 に届く最小の覆う長さは 0.6 ns（全体・タンパク質ごとの平均とも）で、平均だけの場合と変わらない。同じ長さでの回復率は、0.6〜0.7 ns を除いて平均だけ以下だった。増え幅がいちばん大きいのは 0.5→0.6 ns（全体 +0.214）だが、直前の落ち込みからの戻りを含むため段とは読まない。覆う長さ 1.0 ns では6種だけで全部入り（要約値10個）に並んだ。
- まだ分からないこと: 残りの予測幅（5・30・50 ns先。L41・L43・L44 の担当）でも必要な長さが縮むかどうか。0.5 ns の落ち込みが 10 ns先で繰り返し出る理由（平均だけと6種の両方に出るので、要約の形ではなく 10 ns先のラベル側か学習側の性質かもしれないが、この実験では切り分けていない）。0.1 ns で6種が平均だけを下回る理由。6種のうちどの要約値が 0.6〜0.7 ns の押し上げを担っているかは、この実験では切り分けていない。
