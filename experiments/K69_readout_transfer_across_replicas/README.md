# K69: ある複製で学習した読み出しは、別の複製でも使えるか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。K63 で、あるタンパク質で学習した読み出しの移し替えは安定しませんでした。複製の間ではどうか確かめます。

読み方は実験前に固定しました。別の複製でも利得の8割以上が戻れば、平均の読み出しは複製によらず同じです。戻らなければ、読み出しは複製ごとに違います。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、学習回数160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付けます。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- タンパク質は K06(b) の100タンパク質のテストで、学習と評価は同じタンパク質を使い、複製で分けます。
  - 移し替え: 複製1だけで学習し、複製2、複製3、複製2＋3で評価
  - 参照（指示通り）: 全複製で学習し、複製2、複製3、複製2＋3で評価
  - きれいな参照: 複製1＋2で学習して複製3で評価、複製1＋3で学習して複製2で評価（評価する複製は学習に入っていません）
- 利得は、同じ学習条件で学習した静的な特徴だけの条件との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。戻り率は、移し替えの利得を、参照の利得で割った値です。
- 対照の確認: 較正用8タンパク質で学習したモデルを100タンパク質のテストで評価すると、K06(b) の記録と、全体をまとめた AUPRC が全予測幅で完全に一致しました（差 0.0）。タンパク質ごとの平均は、この実験のスクリプトでは（タンパク質、複製）ごとに平均するため K06(b) の値と約 0.011〜0.015 ずれますが、これは平均の取り方の違いです。K06(b) と同じ取り方（複製をタンパク質ごとにまとめてから100タンパク質で平均）で計算し直すと、差は 0.0 になります。

### 指示通りの参照（全複製で学習）が膨らむ理由

全複製で学習したモデルは、評価する複製の候補を学習に含んでいるため、利得が大きめに出ます。例えば、複製2＋3で評価したときの実履歴の AUPRC は、複製1だけで学習した条件では 0.5460 / 0.5229 / 0.4998 / 0.5009 / 0.4894 / 0.4853 ですが、全複製で学習した条件では 0.5705 / 0.5452 / 0.5244 / 0.5278 / 0.5123 / 0.5172 と高くなります（K63 の両方で学習の参照と同じ形です）。この分母で見ると、戻り率は 10・30・90 ns先で8割を下回ります。

## 判断

先に固定した8割の線で見ると、**評価する複製を学習に含まないきれいな参照で比べれば、複製1だけで学習した読み出しは、別の複製でも利得の8割以上が戻ります**。戻り率は、全体をまとめた値で 0.84〜1.04、タンパク質ごとの平均で 0.85〜1.06 です。全予測幅で8割以上です。複製1だけで学習した条件の利得そのものも、複製2＋3で +0.0629 / +0.0544 / +0.0379 / +0.0386 / +0.0335 / +0.0330 と、K06(b) の利得（+0.0702 / +0.0514 / +0.0376 / +0.0363 / +0.0354 / +0.0265）とほぼ同じ大きさです。

つまり、平均の読み出しは複製によらず同じです。K63 のタンパク質の移し替えとは違い、複製の移し替えは安定しています。指示通りの参照（全複製で学習）では戻り率が 0.67〜0.99 と下がりますが、これは参照が評価する複製の候補を学習に含んでいるためで、読み出しが複製ごとに違う証拠ではありません。
