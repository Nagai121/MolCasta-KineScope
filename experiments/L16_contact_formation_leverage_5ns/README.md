# L16: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の形成、5 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L01（水素結合の形成、1 ns先）と同じ曲がりの測り方で、接触の形成の 5 ns先を測る。
- 状態: 完了。回復率 0.8 に届く最小の長さは覆う長さ 0.8 ns（統合値 0.8491）。0.9 にはどの長さでも届かない（最大は 0.8 ns の 0.8491）。増え幅がいちばん大きいのは 0→0.1 ns（+0.1534）だが、タンパク質ごとでは符号が分かれる。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの条件のモデルに入れたときの 5 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、統合・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 214件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 5 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（13条件の学習で約10〜50秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（5 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.8 ns**（統合値 0.8491）。0.2 ns で 0.7842 と線の近くまで来ますが、届くのは 0.8 ns が初めてです。
2. **回復率 0.9 に届く最小の長さ: なし**。最大でも 0.8 ns の 0.8491 で、0.9 には届きません。
3. **増え幅がいちばん大きい場所: 0→0.1 ns（+0.1534）**。次に大きいのは 0.1→0.2 ns（+0.1433）で、増え幅は短い側に寄っています。0.2 ns 以降は増え幅が小さく、負の区間も 4 つあります。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1939（静的のみ 0.3480、全部入り 0.5419）、2qt4_A が +0.3140（静的のみ 0.1833、全部入り 0.4973）で、2qt4_A の利得のほうが大きい。

段の位置（0→0.1 ns）でのタンパク質ごとの回復率は、1mix_A が 0.2539 → 0.5852（+0.3313）、2qt4_A が 0.8942 → 0.6128（−0.2814）で、符号が分かれます。統合値でいちばん大きい増え幅は、2 タンパク質の合算の形で、タンパク質ごとに共通する段ではありません。

## 4. 読み取り

- 接触の形成の 5 ns先では、回復率は 0.2 ns で 0.7842 まで上がったあと 0.7 ns まで 0.73〜0.78 の範囲でほぼ平らになり、0.8 ns で 0.8491 と最大になって、1.0 ns では 0.6928 まで下がります。単調な曲がりではありません。
- 0.9 の線には届きませんでした。全部入り（6 個の統計量）の利得が +0.2322 と大きい一方、平均だけでは 8 割台の半ばが上限でした。
- フレーム 0 だけでも回復率 0.4876 が戻ります。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
