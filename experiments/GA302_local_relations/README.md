# GA302 RODの候補関係とMiniCalc局所座標による過去距離残差

GA301と同じ配列・候補・起点、教師、Ridge静的基準を使用。学習10,222、選定4,820、最終確認9,843候補。静的構造だけを推論入力とする。

既存RODの各対象ペアについて、各端点の近傍原子を最大26個ずつ列挙し、対象ペアの両端と7 Åより遠い原子をマスクする。各関係の入力は両端までの距離、元素、残基の一致、端点側、ROD候補に現れる役割、および位置座標。隣接原子同士のメッセージ伝播や候補スクリーニングの変更は行わない。重複した近傍が両端側に現れる場合は端点側の違う関係として残す。

ペアの軸を第1軸、残基Cαの方向を優先した直交成分を第2軸とする。この軸の決め方はGA302の実装で、基底構築と局所変換はD:/MiniCalc/local_frames.py の unit、perpendicular、basis、to_local_displacement を直接利用。MiniCalcファイルのハッシュを結果に保存。実験側では同じ関係について距離のみ、元の座標、局所座標を比較する。個々の関係は学習器まで保持し、学習した集合プーリングまたは注意で集約する。2損失×2読み出し×3表現の12モデルをCUDA学習し、CPUで評価した。

検証の残差相関最良は、距離のみ0.234406、元の座標0.148536、局所座標0.211257。局所座標の最良条件 local-attention-squared を最終確認前に固定した。

| GA302 MiniCalc局所座標 | 0.226438 | 0.519852 |

相関0.500、誤差SD 0.30 Åの双方に未達。第2段は未実施。局所座標は元の座標より検証で改善したが、距離のみの関係表現を上回らなかった。GA301とは読み出し方式や入力も異なるので、最終確認の差を局所変換だけに帰属できない。

再現はGA301と同じ作業ディレクトリにGA301の ga_static_offset.py と本実験の ga_local_relations.py を t2i/ に置き、python -m t2i.ga_local_relations --minicalc D:/MiniCalc/local_frames.py。保存重み、予測と実測、正規化およびRidge設定を添付。
