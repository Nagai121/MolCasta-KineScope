# L2-31: 区間を起点フレーム10の直前に置き直した測り直し（接触の形成、統計量6種、資料Dの条件、予測幅 1/5/10/30/50/90 ns）

- 状態: 完了。前提確認（長さ 1.0 ns の点で L51〜L56 の記録と一致すること）は、6つの予測幅すべてで一致した（静的のみ・全部入りの AUPRC と利得が、表示した範囲で記録値と完全に同じ）。区間を起点の直前に置くと、回復率 0.8 に届く長さは 1 ns先で 0.3 ns（L では 0.5 ns）と短くなった一方、50 ns先では 0.6 ns（L では 0.1 ns）、90 ns先では 0.7 ns（L では 0.3 ns）と長くなり、置き直しで一様に下がるわけではなかった。長さ 0（フレーム10だけ）の回復率は全予測幅で ちょうど 0 で、L の長さ 0（フレーム0だけ）の 0.38〜0.80 とは対照的だった。これは、接触の形成の静的な特徴に起点フレームの距離がすでに含まれているためで、フレーム10だけの統計量は静的な予測に何も足さない。一方 L の長さ 0 は、静的な特徴に含まれていないフレーム0の距離を持ち込んでいた。

## 1. 何を確かめる実験か

L51〜L56（接触の形成、統計量6種、資料Dの条件）と同じ土台・同じ候補・同じ予測器で、履歴の区間だけを置き直して、回復率の曲がりを測り直す。

L では区間は先頭から（フレーム 0〜k）で、短い長さでは起点フレーム10との間に時間の空きがあった。E01 で、この空きが回復率を水増ししていたことが分かっている（E01 の Protocol A は、区間を起点の直前に置く置き方）。ここでは区間を起点フレーム10の直前に置き、L と同じ読み方で測る。

## 2. 条件

- 土台: 資料Dの条件（K13 のキャッシュ）。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テストは 1mix_A と 2qt4_A（候補 7,384件）。予測器は L51〜L56 と同じ HistGradientBoosting（120回、学習率 0.075、葉31、最小葉15、L2 0.02、種 42）で、条件ごとに学習し直す。特徴量の作り方（型を含む）も L51 と同じにした。
- 区間: 覆う長さ L ns の区間は、フレーム (10 − L/0.1) 〜 10 の L/0.1 + 1 フレーム。長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10。長さは 0〜1.0 ns の11通り。
- 統計量6種は資料Dの定義（最初・平均・標準偏差・最小・最後−最初・4.5 Å以下の割合）を、その区間のフレームで計算する。区間の「最初」は区間の先頭フレーム、「最後」は常にフレーム10。
- 条件は、静的のみ、全部入り（フレーム 0〜10 の6統計量、回復率の分母の参照）、区間の6統計量（11通り）、区間の平均だけ（11通り、平均だけの形との比較用）。
- 回復率 = (その長さの AUPRC − 静的のみ) / (全部入りの利得)。
- 読み方（L と同じ）: 回復率 0.8 と 0.9 に最初に達する長さ（全体）、隣り合う長さの間の最大の増え幅、信頼区間は全体・1mix_A・2qt4_A の3値の最小〜最大。増え幅が最大の場所ではタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録）。
- 前提確認: 長さ 1.0 ns の点は区間がフレーム 0〜10 になり L と同じ条件になる。静的のみ・全部入りの AUPRC と利得が L51〜L56 の記録と 5e-4 以内で一致しなければ止める、と先に決めた。結果は6つの予測幅すべてで、表示した小数第6位まで記録値と一致した。

## 4. 読み取り

- **長さ 0 の意味が、L と L2 で違う。** L の長さ 0（フレーム0だけ）の回復率は 0.38〜0.80 あったが、これは「履歴なし」ではなく、静的な特徴に含まれていないフレーム0の距離を持ち込んだ値である。L2 の長さ 0（フレーム10だけ）は、起点の距離が静的な特徴にすでに含まれているため、回復率はちょうど 0 になる。L の曲がりの出発点は、この持ち込みの分だけ押し上げられていた。
- **必要な長さは、予測幅によって伸びも縮みもした。** 0.8 の線では、1 ns先と10 ns先で L より短くなり（0.5→0.3 ns、0.5→0.4 ns）、5 ns先・50 ns先・90 ns先で長くなった（0.3→0.4 ns、0.1→0.6 ns、0.3→0.7 ns）。50 ns先の差が最も大きく、L では 0.1 ns で 0.8 を超えていた（回復率 0.8103）のが、置き直しでは 0.1 ns で 0.6572、0.8 に届くのは 0.6 ns になった。
- **0.1 ns の回復率は、置き直しで 0.39〜0.66 の範囲になった。** L の同じ長さ（0.40〜0.81）と比べると、1 ns先と30 ns先ではわずかに高く、5 ns先・10 ns先・50 ns先・90 ns先では低くなった。
- **平均だけとの比較（同じ実行）:** 統計量6種は、ほとんどの予測幅で平均だけより短い長さで 0.8 と 0.9 に届くか、平均だけでは届かない線に届いた。例外は 5 ns先の 0.8 の線で、平均だけが 0.3 ns、統計量6種が 0.4 ns と、平均だけのほうが短かった。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の形成（資料Dの条件）では、区間を起点の直前に置き直しても、短い区間で利得の大半が戻るという形は残る（0.1 ns で回復率 0.39〜0.66、0.8 の線には 0.2〜0.7 ns で届く）。ただし L の記録は、長さ 0 の持ち込みと区間の置き方の両方で押し上げられていて、必要な長さは予測幅によっては L の記録よりかなり長い（50 ns先で 0.1 ns → 0.6 ns）。
- まだ分からないこと: 予測幅によって置き直しの影響が逆向きになる理由は、この実験では分からない。資料Dの条件はテストが2タンパク質だけなので、区間は3値の最小〜最大で粗い。
