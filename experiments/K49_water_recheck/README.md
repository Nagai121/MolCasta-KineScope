# K49: 水の環境の履歴を、別の量で再確認する

## 仮説

H7（実軌道が持つ追加の観測情報）の残りです。K36 では、水の環境の履歴を足すと 1 ns先の利得が +0.0266 増えましたが、予測幅をまたぐと符号が一定しませんでした（5・10・50 ns先では負）。別の量で再確認します。

読み方は実験前に固定しました。別の量でも利得の増えが全予測幅で同じ符号なら、水の環境は安定した担い手です。符号がまた一定しなければ、水の環境は安定した担い手ではありません。「同じ符号」は増分が全幅で正（または全幅で負）であることとし、1 ns先だけの正では不十分です。増分が小さい（土台の利得の1割未満）幅が混じる場合は、その旨も記録します。補助の目安として、増分が土台の利得（1 ns先で +0.1178）の1割（約0.012）未満なら「ほぼ増えない」と読むことにしました（K36 と同じ目安）。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。水素結合形成、起点1 ns、履歴0〜1 ns（11フレーム）、予測幅1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。モデルは条件ごとに学習し直す比較です。
- 条件は6つです。
  - 静的のみ: 静的特徴7個
  - 土台 D6: 静的＋ペア自身の履歴6統計量
  - 履歴＋水5.0 Å: 静的＋ペア自身の履歴6統計量＋水の環境（5.0 Å の量、24特徴量）
  - 履歴＋滞在: 静的＋ペア自身の履歴6統計量＋水の滞在の割合（4特徴量）
  - 水5.0 Åのみ: 静的＋水の環境（5.0 Å の量）のみ（参考条件）
  - 滞在のみ: 静的＋水の滞在の割合のみ（参考条件）
- 静的のみと土台 D6 は土台の記録と全予測幅・全指標で完全に一致しました（最大の絶対差 0.0）。

## 水の環境の量の定義（結果を見る前に固定した）

定義は、結果を見る前にこの形に固定しました。途中で定義を変えて測り直すことはしていません。

- 水の読み方: K36 と同じです。ATLAS の完全形式（total）の TPR + XTC を MDAnalysis で直接読みます（MiniTopol の変換は通しません。2026-11-16 に Echizen が明言した例外の範囲です）。完全形式のファイルは `~/workspace/rod-survival-exp/atlas-ws/storage/sources/ATLAS/` の `{タンパク質}-total/` にあります。使うフレームは完全形式の 0, 10, ..., 100（解析版の 0〜10、履歴 0〜1 ns に対応）の11個だけです。
- 候補の同定（ドナー原子・アクセプター原子）は base_reproduction のキャッシュと同一です。
- 水は SOL 残基の酸素 OW です。距離はフレームごとの箱で最小イメージ（直交箱、軸ごとの箱長）で計算しています。
- 条件 (1)「水を数える距離を 5.0 Å に変える」: K36 の案A・案Bの 3.5 Å の量を 5.0 Å に置き換えた条件です。系列は6つで、ドナー原子から 5.0 Å 以内にある OW の数（nd50_d）、アクセプター原子から 5.0 Å 以内（nd50_a）、ドナー原子とアクセプター原子の両方から 5.0 Å 以内にある OW の数（nbridge50）、ドナー原子から最も近い OW までの距離（dmin_d）、アクセプター原子から最も近い OW までの距離（dmin_a）、ドナー・アクセプターの中点から最も近い OW までの距離（dmin_mid）です。要約は系列ごとに4量（平均、標準偏差、最小値、最後−最初）で、24特徴量です。K36 の案Aには nd50_d・nd50_a が既に含まれていたため、この条件では K36 の案Aとの重複を避け、「3.5 Å の量を 5.0 Å に置き換えた」条件として定義し直しています。dmin_d・dmin_a・dmin_mid はカットオフによらない量で、K36 と同じ定義です。
- 条件 (2)「滞在」: 水が近くにいたフレームの割合（11フレーム中の割合）です。4特徴量で、ドナー原子から 3.5 Å 以内に水がいたフレームの割合（frac_d35）、アクセプター原子から 3.5 Å 以内に水がいたフレームの割合（frac_a35）、両方から 3.5 Å 以内に水がいたフレームの割合（frac_bridge35）、どちらかから 3.5 Å 以内に水がいたフレームの割合（frac_either35）です。
- 系列の水準（全候補・全フレームの平均）: nd50_d は 3.79〜4.71個、nbridge50 は 0.62〜0.98個、滞在の割合は frac_d35 が 0.488、frac_a35 が 0.632、frac_bridge35 が 0.078、frac_either35 が 0.772 でした。3.5 Å の橋渡し水はめったにいませんが、5.0 Å まで広げると橋渡し水は 1フレームあたり平均 0.6〜1.0個になります。

## sanity check

- K36 の保存系列との一致: この抽出で再計算した nd50_d・nd50_a・dmin_d・dmin_a・dmin_mid は、K36 の保存系列と最大で 4.7e-07 Å（個）の差で一致しました（float32 の丸めの範囲）。nbridge50 だけが新規の系列です。滞在の割合は K36 の保存系列（nd35_d・nd35_a・nbridge）から計算しています。
- 抽出の計算時間は 18レプリカで合計 355秒（約6分）でした。1レプリカあたり 5〜29秒で、K36（約20分）より速く済みました。

## 判断できること

- 別の量でも、利得の増えの符号は一定しませんでした。水5.0 Åの増分は 1 ns先 +0.0101、5 ns先 +0.0016、10 ns先 −0.0284、30 ns先 +0.0379、50 ns先 +0.0046、90 ns先 +0.0018 で、10 ns先ではっきり負になります。滞在の増分は 1 ns先 −0.0063、5 ns先 +0.0213、10 ns先 +0.0003、30 ns先 +0.0081、50 ns先 +0.0105、90 ns先 −0.0140 で、1 ns先と 90 ns先が負です。先に固定した読み方に沿うと、水の環境は安定した担い手ではありません。
- 増分の大きさも、ほとんどの幅で土台の利得の1割（約0.012）未満です。水5.0 Åで目安を超えたのは 30 ns先（+0.0379）のみ、滞在で目安を超えたのは 5 ns先（+0.0213）のみで、幅をまたいで一貫しません。
- K36 で 1 ns先にあった +0.0266 の増分も、別の量では再現しませんでした。水5.0 Åでは 1 ns先 +0.0101 で目安を下回り、滞在では 1 ns先 −0.0063 と負です。K36 の 1 ns先の増分は、量の選び方に依存する揺れだった可能性が高いです。
- 水の環境のみの条件にも、利得らしい利得はありませんでした。

## まだ分からないこと

- 水の環境の増分が幅ごとに符号を変える理由（ノイズか、幅ごとの性質の違いか）は、この実験だけでは分かりません。単一の種での結果でもあります。
- 水の環境の定義は K36 と今回の2通り（近くの水の数と最も近い水までの距離、5.0 Å への置き換え、滞在の割合）だけです。水の配向や水素結合ネットワークなど、さらに別の切り方で情報が出る可能性は残りますが、今回の2通りの量では安定した担い手は見つかりませんでした。
