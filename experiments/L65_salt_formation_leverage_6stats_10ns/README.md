# L65: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、10 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L29（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）の 10 ns先です。
- 状態: 完了。平均だけの曲がりが長さとともに下がる予測幅（L29）で、統計量6種は下がり方が緩やかでした。ただし 0.8 と 0.9 の線にはどちらもフレーム0の時点で届いているため、必要な長さの読みは両方とも 0 ns で、縮みは 0 でした。

## 1. 何を確かめる実験か

L63 と同じ段取りで、予測幅だけを 10 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、10 ns先の陽性 131件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

静的のみ AUPRC 0.2034、全部入り 0.2627、利得 全体 +0.0594／平均 +0.0352 で、L29 の記録と 5e-4 以内で一致しました。同じ実行で測り直した平均だけの回復率は、L29 の results.json の値と全長さで完全一致しました（最大の差 0.0）。統計量6種の 1.0 ns の回復率は 1.000 でした（`premise_check.json`）。

### 先に固定した読み方への答え

1. **回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.209）**。平均だけも 0 ns（1.246）で、**必要な長さの縮みは 0** でした。
2. **増え幅がいちばん大きい場所: 全体では 0.4→0.5 ns（+0.593）**。ただし段の位置でのタンパク質ごとの増え分は中央値 −0.081、正だったのは 15タンパク質のうち 40% で、段とは読めません。
3. **平均だけとの比較で目立つのは長い側です。** 平均だけは長さとともに 1.246 → 0.341 へ下がるのに対し、統計量6種は 0.68〜1.30 の範囲にとどまり、差（6種 − 平均、全体）は 0.5 ns で +0.772、0.9 ns で +0.870 でした。短い側（0.1〜0.2 ns）では逆に6種が大きく下回ります（−0.516、−0.173）。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 10 ns先は、フレーム0の時点の情報がどちらの形でも利得を上回る特殊な予測幅で（L29）、読み方の主眼である「必要な長さ」では差が出ませんでした。
- 長い覆う長さで平均だけが下がっていくところを6種が保つ形は、平均以外の統計量（割合や最小など）が長い範囲では効いている可能性を示しますが、区間が広く、ここでは形の記録にとどめます。
