# G81: 強い土台で、水素結合の形成の長い予測幅でも短い切り取りで指導力が戻るか（K06(b) の条件、水素結合の形成、5・10・30・50・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G05 は強い土台（K06(b)、凍結した本体 T1I2006＋補正モデル）で 1 ns先だけだったので、長い予測幅での形が空白だった。ここを埋める。
- 状態: 完了。5・10・30・50・90 ns先のすべてで、0.1 ns の切り取りの平均だけで回復率 0.5 を超えた。

## 1. 切り取りの定義（G02/G05 と同じ、結果を見る前に固定）

- 軌道の保存間隔は 100 ps（0.1 ns）。フレーム k は時刻 k*0.1 ns。
- 0.1 ns → フレーム 0, 1（2フレーム、覆う長さ 0.1 ns）
- 0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さは 0.2 ns。0.25 ns は 100 ps 刻みに合わない）
- 0.5 ns → フレーム 0〜5（6フレーム、覆う長さ 0.5 ns）
- 起点フレーム10（1 ns）は変えない。条件は「静的特徴＋切った平均だけ」（K21 の「平均だけ」と同じ形）。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（その予測幅での実履歴の利得）。利得は全体まとめ（pooled）とタンパク質ごとの平均（macro）の両方で測る。

## 2. 土台と利得の出所

- 土台は K06(b) と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行）で評価する。静的特徴は5個。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`）をそのまま使った。作り直した系列から導いた要約値は保存値と 1e-05 Å 未満で一致することが G05 で 108タンパク質すべてで確かめてある。軌道の取り直しや本体の読み込みは行っていない。
- 土台の利得は K06(b) の記録値（`k06b_results.json`、K12 の記録と同じ）で、再計算でも一致した。利得は次のとおり。
  - 1 ns先: 全体 +0.0702、タンパク質ごとの平均 +0.0712
  - 5 ns先: 全体 +0.0514、タンパク質ごとの平均 +0.0518
  - 10 ns先: 全体 +0.0376、タンパク質ごとの平均 +0.0388
  - 30 ns先: 全体 +0.0363、タンパク質ごとの平均 +0.0370
  - 50 ns先: 全体 +0.0354、タンパク質ごとの平均 +0.0344
  - 90 ns先: 全体 +0.0265、タンパク質ごとの平均 +0.0273
- 土台の再現は全予測幅で K06(b) と一致した（静的のみ・実履歴の AUPRC が全体まとめ・タンパク質ごとの平均とも 5e-4 以内で一致）。1 ns先の切り取りの平均だけも G05 と一致した（0.1 ns 0.545／0.553、0.5 ns 0.695／0.686。全体／タンパク質ごとの平均）。0.25 ns の 1 ns先は 0.573／0.588 で新規。
- 実行はローカルVMのみ（`~/workspace/mt-venv/bin/python`、sklearn 1.9.1、OpenMP スレッド数 2）。全30条件の学習・評価は約4分で終わった。途中で止まっても再開できるよう、予測幅ごとに途中結果を `results_g81_partial.json` に書き出す作りにした。

## 4. 読み取り（先に固定した読み方に沿う）

- 長い予測幅 5・10・30・50・90 ns先では、0.1 ns の切り取りの平均だけで回復率 0.5 を超えた。最小の切り取りは 5つの予測幅すべてで 0.1 ns で、全体まとめでもタンパク質ごとの平均でも同じ形。0.5 ns まででも届かない予測幅はなかった。
- ただし 50 ns先の 0.1 ns は全体 0.524、タンパク質ごとの平均 0.540 と、0.5 の線をわずかに超えただけ。50 ns先の利得は全体 +0.0354 と小さく、回復率の分母が小さい点には注意が要る。0.25 ns に長くすると 0.648／0.687 まで上がる。
- 90 ns先では 0.1 ns の切り取りだけで 0.747／0.695 と、1 ns先（0.545／0.553）よりむしろ高く戻る。0.5 ns では 1.025／1.008 と実履歴の利得を上回る。90 ns先の利得は全体 +0.0265 と 6つの予測幅の中で最も小さいため、回復率の分母が小さい点には注意が要る。
- 切り取りを長くしても回復率は単調には上がらない。10 ns先では 0.1 ns の 0.686／0.683 から 0.25 ns の 0.668／0.674 へわずかに下がる。30 ns先では 0.1 ns と 0.25 ns が 0.625／0.650 と 0.639／0.725 でほぼ同じで、0.5 ns で 0.927／0.957 へ上がる。
- 弱い土台での G74（平均だけ、0.1 ns の切り取り）と比べると、強い土台のほうが 5・10・30・50 ns先では低い（5 ns先 0.846 → 0.549、10 ns先 0.771 → 0.686、30 ns先 0.979 → 0.625、50 ns先 0.745 → 0.524。全体まとめ）。90 ns先だけは強い土台のほうが高い（0.590 → 0.747）。弱い土台では 1 ns先 0.570 と 90 ns先 0.590 が低かったのに対し、強い土台では 90 ns先が 0.747 と高い点で、予測幅による形が違う。ただし強い土台では実履歴の利得そのものが小さい（5 ns先で弱い土台 +0.1155 に対して強い土台 +0.0514）ため、同じ AUPRC の差でも回復率は動きやすい点には注意が要る。AUPRC の差で見ると、0.1 ns の切り取りの利得は 5 ns先で弱い土台 +0.0977 に対して強い土台 +0.0282 と、絶対量では弱い土台のほうが大きい。
- 0〜1 ns の平均だけの回復率は 10・30・90 ns先で 1 を超え、実履歴の利得を上回る。短い切り取りでも担い手は平均のまま。切る長さを伸ばすほど平均が 0〜1 ns の平均に近づき、回復率も上がる、という素直な関係。

## 5. 残りのばらつき（切った平均 − 0〜1 ns の平均、テスト側の標準偏差）

- 0.1 ns: 0.538 Å、0.25 ns: 0.445 Å、0.5 ns: 0.261 Å（G05 の 0.1 ns 0.538 Å、0.5 ns 0.261 Å と一致し、0.25 ns が新規）。
- 参照と比べると、複製の下限 0.249 Å、生成器の平均の誤差 0.483 Å に対して、0.1 ns の切り取りの 0.538 Å は生成器の誤差より大きい。それでも回復率は 0.545／0.553 と5割を超えた。ばらつきが 0.30 Å の線を下回らなくても、回復率は5割を超えうる（G05 と同じ）。
