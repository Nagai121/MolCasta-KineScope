# K64: 最も短い予測幅でも、担い手は平均か（資料Dの条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。0.1 ns先でも指導力があり、平均だけで利得の 0.913 が戻りました。先に固定した目安（8割）を超え、担い手は最も短い予測幅でも同じです。

## 1. 何を確かめる実験か

これまでの予測幅は 1〜90 ns先でした。最も短い 0.1 ns先でも、担い手は平均か確かめます。

読み方は先に固定しました。0.1 ns先でも指導力があり、平均だけで利得の8割以上が戻れば、担い手は最も短い予測幅でも同じです。指導力が無い、または平均だけでは戻らなければ、短い予測幅では違います。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）です。ATLAS 解析版、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 候補の定義は K01 の抽出コード（再現した資料Dの条件）と同じです。起点フレーム10の距離が 3.5 Å 超〜6.0 Å 以下、ラベルは予測先で 3.5 Å 以下です。指示文では候補の上限を 10.0 Å と書いていましたが、再現した抽出コードでは 6.0 Å までで、K55 の記録とも一致します。ここでは抽出コードの 6.0 Å を採用しました。
- 0.1 ns先のラベルは、軌道の保存間隔が 100 ps（0.1 ns）のため、起点フレーム10の次のフレームであるフレーム11での距離が 3.5 Å 以下かどうかです。K01 のキャッシュにはフレーム11が無かったため、`extract_k64.py` で変換済み軌道から直接計算しました。検証として、フレーム10の距離を再計算してキャッシュの履歴の最後の値と比べたところ最大差 0.0、フレーム20のラベルを再計算してキャッシュの 1 ns先のラベルと比べたところ不一致 0件でした。
- 静的特徴は7個（起点距離、Cα間距離、配列距離の log1p、ドナー主鎖か、アクセプター主鎖か、ドナー酸素系か、アクセプター側鎖酸素か）です。履歴の6統計量は K27/K31 と同じ定義（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下だった割合）です。
- 条件は3つです（分け方は K21 の「平均だけ」と同じで、資料Dの土台での測定です）。
  - 静的のみ: 静的7特徴だけ
  - 全部入り: 静的＋実履歴6統計量
  - 平均だけ: 静的＋履歴6統計量のうち平均1つだけ（他の統計量は入れない）
- 対照の確認: 1 ns先の静的のみと全部入りは、全指標で K01 の記録と完全に一致しました（差 0.0。静的のみ AUPRC 0.3637、全部入り 0.4815）。

## 3. 結果

| 予測幅 | 静的のみ AUPRC | 全部入り AUPRC | 平均だけ AUPRC | 利得 | 平均だけの戻り方 |
|---:|---:|---:|---:|---:|---:|
| 0.1 ns | 0.3922 | 0.5496 | 0.5359 | +0.1574 | 0.913 |
| 1 ns | 0.3637 | 0.4815 | 0.4865 | +0.1178 | 1.042 |

全指標は `results.csv` / `results.json` にあります。0.1 ns先の他の指標は、静的のみ AUC 0.9236・Brier 0.0422・Log Loss 0.1406、全部入り AUC 0.9623・Brier 0.0347・Log Loss 0.1095、平均だけ AUC 0.9574・Brier 0.0349・Log Loss 0.1136 です。1 ns先の他の指標は K01 の記録と同じです。

- 候補数: 学習 9,610件、テスト 4,972件（1 ns先と同じ候補です。ラベルだけが違います）。
- 陽性数: 0.1 ns先は学習 453件、テスト 288件（陽性率 5.8%）。1 ns先は学習 489件、テスト 290件（陽性率 5.8%）で、陽性数はほぼ同じです。

## 4. 読み取り

- **0.1 ns先でも指導力ははっきりあります。** 利得は +0.1574 で、1 ns先の +0.1178 より大きく、予測幅が短いほど利得が大きい形です。
- **平均だけで、利得の 0.913 が戻りました。** 先に固定した目安の8割を超えているので、担い手は最も短い予測幅でも同じです。1 ns先の戻り方も 1.042 で、平均だけの方が全部入りをわずかに上回りました（強い土台の K21 でも、平均だけが全部入りを上回る予測幅がありました）。
- 0.1 ns先は起点の次のフレームがラベルなので、静的のみの値も 1 ns先より高くなりました（AUPRC 0.3922 対 0.3637、AUC 0.9236 対 0.9056）。起点距離とラベルの関係が強いためです。履歴の最後のフレーム（フレーム10）とラベルのフレーム（フレーム11）が隣り合っているため、「最後−最初」などの統計量とラベルの関係も 1 ns先とは違う可能性がありますが、平均だけの戻り方は 0.913 と高く、担い手が平均であることは変わりませんでした。
- 利得そのものは 0.1 ns先で +0.1574 と 1 ns先より大きいため、戻り率の分母が小さいことによる振れの心配はありません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 最も短い予測幅 0.1 ns先でも、実履歴に指導力があり、担い手はペアの平均距離という1つの量でほぼ担えます。形成の担い手は、予測幅 0.1〜90 ns先の範囲で同じ形です。
- まだ分からないこと: 0.1 ns先よりさらに短い予測幅（軌道の保存間隔より短い）では測れません。また、平均以外の統計量だけの戻り方（最小値だけ・割合だけ・形だけ）は 0.1 ns先では測っていません。
