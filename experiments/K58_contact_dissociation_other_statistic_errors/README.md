# K58 接触の解離でも、平均以外の統計量の誤差の形は同じか（K50 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。接触の解離では、標準偏差ではなく 4.5 Å 以下割合の誤差が最大の担い手で、3つまとめでは利得がさらに落ちます。水素結合の解離（K54）とは形が違います。

## 1. 何を確かめる実験か

水素結合の解離では、標準偏差の誤差だけで利得の大半が消えました（K54、第14案）。接触の解離でも同じ切り分けをします。

読み方は先に固定しました。接触の解離でも標準偏差の誤差だけで利得の大半が消えれば、水素結合の解離と共通です。別の統計量が担い手なら、現象ごとに違います。

## 2. 条件

- 土台は K50 の接触の解離の条件（資料D）です。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383件）、テストは 1mix_A＋2qt4_A 合算（2,915件、陽性は予測幅ごとに 207〜294件）で、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・4.5 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、4.5 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、4.5 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は残基レベルの生成方式（第11〜14案、K11/K17/K20 の手順）です。詳しくは第4節です。
- 実の統計量は起点までの11フレームの履歴（0〜1 ns）から、生成の統計量は起点からの分岐平均の9点系列（起点＋8ステップ）から計算しています。後ろ向きと前向きの違いは、K33 と同じ作りです。
- 対照の確認: 静的のみと実履歴は、K50 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.3105、実履歴 0.5246）。

## 3. K41 の系列では測れなかった理由

- 最初に K41 の生成系列（K14 の接触の系列）で測ろうとしましたが、そのままでは解離の候補に使えません。K41 の系列は 4,968件で、起点の距離がすべて 4.5 Å より大きく（最小 4.507 Å）、形成の候補だけを対象に作られています。K50 の解離の候補は 9,298件で、起点の距離はすべて 4.5 Å 以下（最大 4.4997 Å）です。同じ軌道では、形成の候補（起点 4.5 Å 超）と解離の候補（起点 4.5 Å 以下）は重ならないため、K41 の系列は解離の候補に1件も合いません。
- そこで、K54 の作り直しと同じく、残基レベルの生成方式（第11〜14案）で解離の候補の系列を作り直しました。以下の結果はこの方式での測定です。

## 6. 読み取り

- **接触の解離では、標準偏差の誤差はほとんど利得を落としません。** 第14案の残存率は 0.73 / 1.08 / 0.97 / 0.83 / 1.03 / 0.89 で、5 ns先と 50 ns先では実の履歴より利得がわずかに増えました。最小値だけでも 0.90〜1.02 とほとんど落ちません。
- **4.5 Å 以下割合の誤差が、1つずつの中では最大の担い手です。** 第14案の残存率は 0.69 / 0.46 / 0.56 / 0.78 / 0.71 / 0.72 で、第11案では 0.65 / 0.31 / 0.47 / 0.69 / 0.74 / 0.65 です。2案で並びがそろいます。
- **3つまとめでは、利得がさらに落ちます。** 第14案の残存率は 0.31 / 0.47 / 0.58 / 0.60 / 0.59 / 0.33 で、第11案では 0.46 / 0.32 / 0.57 / 0.46 / 0.63 / 0.21 です。1つだけでは利得は消えず、3つ合わせると半分ほどまで落ちます。
- **水素結合の解離（K54）とは形が違います。** K54 では第14案の標準偏差だけで残存率が 0.34 / 0.62 / 0.61 / 0.60 / 0.43 / 0.75 まで落ち、最大の担い手でした。接触の解離では標準偏差だけでは 0.73〜1.08 が残り、代わりに割合が最大の担い手です。先に固定した読み方に照らすと、**担い手は現象ごとに違います。**
- 接触の形成（K41）とも違います。形成では 1 ns先で割合だけの残存率が 0.10 まで落ち、3つまとめでは −0.22 まで消えました。解離では 1 ns先で割合だけが 0.65〜0.69、3つまとめが 0.31〜0.46 と、利得が残ります。同じ接触でも、形成と解離で誤差の出方が違います。
- 割合が担い手になる理由を、統計量そのものの性質で確かめました。実の履歴の 4.5 Å 以下割合は平均 0.932、ペア間のばらつき 0.167 で、ペアの 23.3% は履歴の中で一度でも 4.5 Å を超えています（すでに接触が切れかけているペアです）。第14案の生成の割合は平均 0.989、ばらつき 0.062 で、実との相関は 0.321 しかありません。第11案では平均 0.998、ばらつき 0.029、相関 0.091 です。生成の割合はほぼ一定の 1.0 に近く、実と結びついていないため、置き換えると「すでに切れかけている」という信号が消えます。なお、実の標準偏差も生成との相関は 0.216 と低いのに、置き換えても利得が落ちないため、接触の解離では標準偏差の情報はモデルの予測にあまり使われていない、という読みになります。
- なお、6統計量すべてを生成の値にした条件は、両案ともほとんどの予測幅で静的のみ並みでした（第14案 −0.10〜+0.21、第11案 −0.08〜+0.10）。生成の統計量には、接触の解離の利得はほとんどありません。

## 7. 判断できること・まだ分からないこと

- 判断できること: 接触の解離では、平均以外の統計量の誤差の最大の担い手は 4.5 Å 以下割合で、全予測幅で成り立ちます。標準偏差ではありません。水素結合の解離（K54）とは形が違います。ただし1つだけでは利得は消えず、3つまとめで半分ほどまで落ちるので、割合だけですべてを説明できるわけではありません。
- 判断できること: 接触の形成（K41）とも形が違います。形成では 1 ns先で割合の誤差だけで利得がほぼ消えましたが、解離では割合だけでも利得が残ります。
- まだ分からないこと: 割合の誤差が利得を削るのは、生成の系列が 4.5 Å をほとんど超えないためなのか、それとも分岐平均で揺れが半分になるためなのかは、この実験だけでは分けられません。分岐ごとの系列で統計量を作れば、分岐平均より実に近づくはずですが、その場合の置き換えの評価はまだしていません。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
