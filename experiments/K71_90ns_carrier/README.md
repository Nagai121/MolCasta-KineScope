# K71 90 ns先の指導力は、どの統計量が担うか（資料Dの条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。90 ns先では、3.5 Å以下割合だけが利得の 0.973 を戻し、先に固定した目安（8割）を超えました。平均だけは 0.772 と8割に届きませんでした。90 ns先の担い手は、割合の統計量です。

## 1. 何を確かめる実験か

K68 で、90 ns先だけは平均だけで利得の8割以上が戻りませんでした（全体まとめ 0.772、1mix_A 0.764、2qt4_A 0.795）。90 ns先の指導力をどの統計量が担うか、1つの統計量だけを入れた条件で切り分けます。

読み方は先に固定しました。どれか1つの統計量だけで利得の8割以上が戻れば、その統計量が 90 ns先の担い手です。どれも戻らなければ、90 ns先の指導力は複数の統計量に分散しています。「8割以上」は 90 ns先の主判断とします。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）です。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム、HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）、条件ごとに学習し直しました。距離の計算では箱をフレームごとに軸別に扱いました。学習側は変えず、評価は全体まとめとタンパク質ごとの両方を記録しました。
- 履歴の6統計量は「最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下割合」です。条件は8つで、静的特徴7個に次の履歴の量を足したものです。
  - 静的のみ: 履歴なし
  - 全部入り: 6統計量すべて
  - 最初の値だけ / 平均だけ / 標準偏差だけ / 最小値だけ / 最後−最初だけ / 3.5 Å以下割合だけ: その列だけ
- 「平均だけ」の条件の定義は K21・K68 と同じで、他の統計量の列を入れない形です。K21 は強い土台（K06(b)）での同じ切り分けで、こちらは資料Dの弱い土台での切り分けです。
- 利得 =（全部入りの AUPRC − 静的のみ）、各条件の回復率 =（その条件の AUPRC − 静的のみ）÷（全部入りの AUPRC − 静的のみ）で測りました。
- 対照の確認: 静的のみ・全部入り・平均だけは、90 ns先と 1 ns先の両方で K68 の全体まとめと全4指標で完全に一致しました（最大差 0.0、1 ns先で静的のみ 0.3637、全部入り 0.4815、平均だけ 0.4865）。

## 3. 結果

90 ns先（主判断）の利得と、各条件の回復率（全体まとめ／1mix_A／2qt4_A）です。90 ns先の利得は +0.1211（静的のみ AUPRC 0.3035、全部入り 0.4246）で、1 ns先の +0.1178 と同程度の大きさのため、回復率の分母が小さいことによる振れの心配はありません。

| 静的のみ | 0.3035 | 0.000 | 0.000 |
| 全部入り | 0.4246 | 1.000 | 1.000 |
| 最初の値だけ | 0.3663 | 0.519 / 0.451 / 0.653 | 0.311 / 0.285 / 0.366 |
| 平均だけ | 0.3970 | 0.772 / 0.764 / 0.795 | 1.042 / 1.250 / 0.894 |

1 ns先の参考値です。利得は +0.1178（静的のみ 0.3637、全部入り 0.4815）。平均だけ 1.042、割合だけ 1.011 と、1 ns先では平均と割合の両方が利得をほぼ全部戻します。最小値だけ 0.570、最初の値だけ 0.311、標準偏差だけ 0.350、最後−最初だけ 0.350 です。

## 4. 読み取り

- **90 ns先では、3.5 Å以下割合だけが利得の 0.973 を戻し、先に固定した目安の8割を超えました。** タンパク質ごとでも 1mix_A 1.030、2qt4_A 0.921 と両方で8割以上です。読み方の1つ目の枝に当たり、90 ns先の担い手は 3.5 Å以下割合の統計量です。
- 平均だけは 0.772 と8割にわずかに届きませんでした。K68 の結果と同じ値です。平均は 90 ns先でも利得の大半を担いますが、担い手の名前を1つに絞るなら割合の側です。
- 最小値だけ 0.580、最後−最初だけ 0.536、最初の値だけ 0.519 と、他の統計量も半分ほどを戻します。標準偏差だけは 0.149 とほとんど戻しません。90 ns先の指導力は割合に集中していますが、他の統計量にも情報は重なっています。
- 1 ns先との違いです。1 ns先では平均だけ 1.042 と割合だけ 1.011 の両方が利得をほぼ全部戻し、担い手の名前を平均と割合のどちらに付けるかは決められませんでした。90 ns先では平均が 0.772 まで下がり、割合が 0.973 と残ったため、長い予測幅では割合の側が担い手として残ります。予測幅が長くなるにつれて、平均の担い手としての働きが弱まり、割合の側が残る形です。
- K21（強い土台）とのつながりです。強い土台でも 90 ns先の割合だけの回復率は 1.032（マクロ）で、平均だけは 1.060 でした。強い土台では 90 ns先でも平均と割合の両方が8割を超えていましたが、弱い土台では平均だけが 0.772 まで下がり、割合だけが 0.973 と残りました。土台によらず、90 ns先の割合の働きは強いです。
- K68 の結果とのつながりです。K68 で 90 ns先だけ平均が 0.8 をわずかに下回ったのは、両タンパク質そろっての弱まりでした。K71 では、その弱まりの分を割合が担っていることが分かりました。90 ns先の指導力そのものは消えておらず、担い手が平均から割合に移っている形です。

## 5. 判断できること・まだ分からないこと

- 判断できること: 90 ns先の指導力は、3.5 Å以下割合の統計量だけでほぼ担えます（回復率 0.973、タンパク質ごとでも両方8割以上）。平均だけでは 0.772 と8割に届かず、90 ns先の担い手は平均ではなく割合です。1 ns先では平均と割合の両方が利得をほぼ全部戻すため、担い手の名前は予測幅によって違います。
- まだ分からないこと: 平均と割合の情報の重なりの内訳（割合の利得のうち、平均と相関する分がどれだけか）。また、割合が 90 ns先で担い手として残る理由（履歴の中で 3.5 Å以下にいた時間の割合が、90 ns先の形成とどう結びつくか）は、この実験だけでは分かりません。
