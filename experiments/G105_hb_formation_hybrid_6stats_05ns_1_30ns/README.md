# G105: 水素結合の形成の混合で、切り取りを 6 個の統計量にした場合の、切り取りの長さを変えた場合も測る（資料Dの条件、水素結合の形成、1 ns先と 30 ns先）

- 確かめること: 切り取り 0.5 ns の 6 個の統計量に、第11〜14案の生成平均を別々の特徴量として足すと、混合の差は +0.05 を超えるか。G80 は切り取り 0.1 ns、G100 は 0.25 ns だけだった。1 ns先と 30 ns先は、0.1 ns の切り取りで混合の足しがもっとも大きかった幅。
- 状態: 完了。混合の差は 1 ns先では第12案だけが +0.05 を超え（+0.071）、30 ns先では第11案（+0.098）と第12案（+0.165）が +0.05 を超えた。切り取りを 0.5 ns に延ばしても、30 ns先では第11・12案の足しが残った。

## 1. 何を確かめる実験か

条件は資料Dの条件（水素結合の形成）。予測幅は 1 ns先と 30 ns先。切り取り 0.5 ns の 6 個の統計量に、第11〜14案の生成平均を別々の特徴量として足す。比べる相手は 0.5 ns の 6 個の統計量の切り取りだけの回復率。G80・G100 は切り取り 0.1 ns と 0.25 ns だけだった。1 ns先と 30 ns先は、0.1 ns の切り取りで混合の足しがもっとも大きかった幅。

読み方は先に固定した。混合の差が +0.05 を超えるかどうかで見る。

割り当て文の「方法22の生成平均（案 11〜14）」の読み方は G80・G100 と同じ。第11〜14案は K11 の弾性モード・揺らぎの生成系列（`experiments/K11_method_generality/series/`）を使い、方法22（K05 の生成系列）は参考の追加条件として 1条件だけ入れる。読み方の +0.05 の線は第11〜14案の 4条件に適用する。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴7個。キャッシュは `~/workspace/kinescope/work/data_cache/`（`{protein}_R{rep}.npz`、hist は (11, N) で保存されているため (N, 11) に直して使う）。
- 6 統計量の定義は G48 と同じ形で、境界は水素結合の 3.5 Å：[最初, 平均, 標準偏差, 最小, 最後−最初, 3.5 Å以下割合] を切り取りのフレームで計算する。切り取りは 0.5 ns = フレーム [0,1,2,3,4,5]（6フレーム、覆う長さ 0.5 ns）。
- 注記: フレーム [0,1,2] は実際には 0.2 ns を覆う。0.25 ns という呼び名は 100 ps 刻みに合わないため、フレーム [0,1,2] の覆う長さは 0.2 ns になる（G100 の記録にも同じ注記がある）。
- 生成平均の出所（第11〜14案）: K11 の系列 `experiments/K11_method_generality/series/atlas-*.npz`。第11〜14案は弾性モード・揺らぎの生成で、系列は 4分岐×8点。生成平均は K11 の k11_compare.py と同じ定義で、4分岐×8点の平均（nanmean）。対応付けのキーは (軌道ID, ドナー原子, アクセプター原子) で、K05・G11 と同じ。候補は K05 と完全に同じ 14,582件。
- 参考の第22案の生成平均: K05 の `generated_series.npz`（5点系列の平均、G11 と同じ）。
- 条件（各予測幅、すべて条件ごとに学習し直す）: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取り 0.5 ns の 6 統計量／生成平均だけ（各案）／混合（切り取り 0.5 ns の 6 統計量＋生成平均を別々の特徴量として 7列）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。土台の静的のみ・全部入りの AUPRC は、K01 の記録値と小数第4位まで一致することを各予測幅で確かめた。

## 4. 読み取り

先に固定した読み方に照らすと、混合の差は 1 ns先では第12案だけが +0.05 を超え（+0.071）、30 ns先では第11案（+0.098）と第12案（+0.165）が +0.05 を超える。切り取りを 0.1 ns から 0.25 ns に延ばすと、混合の足しは 1 ns先では消え、30 ns先では第13案だけ残った（G100）。0.5 ns まで延ばすと、1 ns先では第12案だけが残り、30 ns先では第11・12案の足しが出た。30 ns先では、切り取りを長くしても第11・12案の足しは消えない。

切り取りだけの回復率は、1 ns先では 0.1 ns の 0.583 から 0.25 ns の 0.700、0.5 ns の 0.803 へ単調に上がる。30 ns先では 0.1 ns の 0.747 から 0.25 ns の 0.658 へ下がり、0.5 ns で 1.319 と実履歴を大きく上回る。30 ns先の 0.5 ns の切り取りだけでも全部入りを上回る（AUPRC 0.4464 対 0.4264）ため、そこに生成平均を足しても AUPRC の差は小さい（第12案で +0.0103）。30 ns先の利得は +0.0626 と小さいため、回復率の差は AUPRC の小さな差でも大きく出る点には注意が要る。

第22案だけは 30 ns先で 0.1 ns の +0.547、0.25 ns の +0.624、0.5 ns の +0.252 と、切り取りの長さによらず大きく残る。ただし 0.5 ns では +0.252 と、0.1・0.25 ns の半分以下に小さくなった。1 ns先では 0.1 ns の +0.155 から 0.25 ns の −0.010、0.5 ns の −0.037 と、切り取りを長くすると足しは消える。

## 5. 判断できること・まだ分からないこと

- 判断できること: 水素結合の形成の 6統計量の混合は、切り取りを 0.5 ns に延ばしても、1 ns先では第12案だけ、30 ns先では第11・12案が +0.05 を超える。切り取りを長くすると足しが消える形ではなかった（G100 の 0.25 ns では 1 ns先は 0 案、30 ns先は第13案だけだったのに対し、0.5 ns では 1 ns先 1 案、30 ns先 2 案になった）。参考の第22案は 30 ns先で +0.252 と大きく、切り取りの長さによらず残るが、0.5 ns では 0.1・0.25 ns より小さくなった。
- まだ分からないこと: 30 ns先で第11・12案だけが足しになる理由と、第13・14案が 0.5 ns では足しにならない理由。1 ns先で第11・14案の混合の差が負になる（−0.073・−0.078）理由。生成平均だけでは第13案は +0.170 と正なのに、混合では +0.034 にとどまる理由。G105 のセルのタンパク質単位の区間は測っていない。
