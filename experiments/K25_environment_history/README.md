# K25: 実履歴に候補ペア以外の情報が入っているか

## 仮説

H7（実軌道が持つ追加の観測情報）の残りです。これまでの履歴特徴量はすべて候補ペア自身の距離系列から作ったものでした。ペアの周りの環境（近くの残基）の履歴の要約を足したときに利得が増えるかを見て、実履歴の追加情報がペア自身の系列の中にあるのか、環境側にも担い手があるのかを確かめます。

読み方は実験前に固定しました。環境の履歴を足しても利得がほぼ増えなければ、実履歴の追加情報はペア自身の系列の中にあることになります。利得がはっきり増えれば、環境側にも担い手があります。補助の目安として、増分が土台の利得（1 ns先で +0.1178）の1割（約0.012）未満なら「ほぼ増えない」と読むことにしました。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。水素結合形成、起点1 ns、履歴0〜1 ns（11フレーム）、予測幅1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。モデルは条件ごとに学習し直す比較です。
- 条件は4つです。
  - 静的のみ: 静的特徴7個
  - 土台 D6: 静的＋ペア自身の履歴6統計量
  - 履歴＋環境: 静的＋ペア自身の履歴6統計量＋環境の履歴12特徴量（主条件）
  - 環境のみ: 静的＋環境の履歴12特徴量（参考条件）
- 静的のみと土台 D6 は土台の記録と全予測幅・全指標で完全に一致しました（最大の絶対差 0.0）。

## 環境の履歴特徴量の定義（結果を見る前に固定した）

定義は、結果を見る前にこの形に固定しました。途中で定義を変えて測り直すことはしていません。

- 残基ペア距離系列: 履歴11フレームの各フレームで、全残基ペアについて重原子間の最小距離を計算したもの。距離はフレームごとの箱を軸ごとに扱う周期境界です。重原子の選び方は土台の K04 と同じ（名前が H で始まるものと数字で始まるものを除く）です。残基ペア単位で一度だけ計算し、全候補で共有しています。
- 近傍集合: 候補ペアの各残基 r について、起点フレーム（フレーム10）で Cα 間距離が 10.0 Å 以下で、配列距離が2以上の残基の集合です。近傍の数は候補側の平均で12〜16残基でした。集合が空になる側は全候補・全軌道で3件だけでした。
- 特徴量は、ドナー残基側とアクセプター残基側で同じ6量ずつ、合計12個です。各側では、近傍集合から相手残基を取り除いたうえで、その残基と近傍残基との距離系列（11フレーム分）から次を作ります。
  1. 距離の平均（近傍残基とフレームの全体）
  2. 距離の最小値
  3. 距離が 4.5 Å 以下だった割合
  4. 接触数の平均（フレームごとに 4.5 Å 以下で接している近傍残基の数を数えた系列の平均）
  5. 接触数の標準偏差
  6. 接触数の最後−最初
- 近傍集合が空の側では、距離系の3量は欠損値（HistGradientBoosting の欠損値の扱いに任せる）とし、接触数系の3量は 0 としました。欠損値の数は学習側で3個、テスト側で6個です（空の側1つにつき距離系3量分）。

## 水の有無の確認

変換済み軌道の `atoms.parquet` の残基名を確認したところ、20種類の標準アミノ酸だけであり、水（HOH など）の残基は含まれていませんでした。ATLAS 解析版（reduced）は溶媒を除いた形式のためです。完全形式（total）は水を含みますが、形式が違い土台の条件が変わるため、今回は使いませんでした。そのため、水の履歴特徴量は作らず、環境は残基の側だけで測っています。この実験の結論は「残基の環境」についてのもので、水の環境については何も言えません。

## 判断できること

- 主判断の 1 ns先では、環境の履歴を足しても利得はほぼ増えませんでした。増分は +0.0012 で、土台の利得 +0.1178 の約1%であり、先に固定した目安（利得の1割、約0.012）をはっきり下回ります。
- 他の予測幅でも、増分は +0.016〜−0.028 の範囲で符号が一定せず、90 ns先ではむしろ下がっています。一貫した上乗せとは読めません。環境のみの条件も、静的のみとの差は 1 ns先で +0.012、他の幅では負か +0.035（90 ns先）までで、環境の履歴だけでは指導力らしい利得は出ていません。
- 先に固定した読み方に沿うと、今回の定義の残基環境については、実履歴の追加情報はペア自身の系列の中にあり、環境側に独立した担い手は見つからなかった、ということになります。

## まだ分からないこと

- 水の環境については測れていません（データに水が無いため）。溶媒の配置が担い手かどうかは、この実験では分かりません。K23 では「溶媒の配置など入力に無い状態」が容疑に残っており、その線はこの実験では閉じていません。
- 環境の定義は今回の1通り（近傍 10.0 Å、重原子最小距離の要約）だけです。別の切り方（角度、二次構造の文脈、もっと広い近傍など）で情報が出る可能性は残ります。
- 5 ns先と 30 ns先では増分が +0.016 前後あり、目安の1割をわずかに超えています。ただし符号が幅ごとに一定しないため、ノイズと区別するには別の種や別の土台での再確認が必要です。
