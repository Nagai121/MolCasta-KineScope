# 土台の再現: 実験D（固定1 ns・水素結合形成）

K01〜K04 の共通の土台として、実験Dの条件を再現した記録です。

## 条件（実験Dから取得したコードで確認）

- 出典コード: MolCasta-InternalResearch、ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py` と `atlas_minitopol_models.py`（gh api の trees/blobs で取得）。
- データ: ATLAS 解析版を MiniTopol A 変換した 6タンパク質×3レプリカ（この仮想マシンの変換済み軌道、100 ps間隔・1001フレーム・座標単位 Å）。学習は 1bgf_A、1ifg_A、1j8r_A、2b0a_A、テストは 1mix_A と 2qt4_A の合算です。
- 起点はフレーム10（1 ns）。履歴はフレーム0〜10の11フレームです。予測幅は1/5/10/30/50/90 ns（絶対時刻2/6/11/31/51/91 ns、フレーム20/60/110/310/510/910）。
- 候補: 起点でドナー・アクセプター重原子距離が3.5 Å超〜6.0 Å以下で、同一残基でないペア。ドナー・アクセプターの定義は出典コードのとおりです（主鎖Nは PRO を除外、側鎖のドナーは窒素系 kind=1 と酸素系 kind=2、アクセプターは主鎖O/OXT kind=0 と側鎖O kind=1）。ラベルは予測先で距離が3.5 Å以下になることです。
- 静的特徴量は7個です。起点距離、Cα間距離、配列距離（残基番号差）の log1p、ドナーが主鎖か、アクセプターが主鎖か、ドナーが酸素系か、アクセプターが側鎖酸素か、です。
- 履歴特徴量は6個です。最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下だったフレームの割合です。
- 距離は周期境界を軸ごとに処理しました。箱はフレームごとに保存された 3×3 行列（対角）を使い、出典コードの `distance` と同じく、対角の場合は軸ごとの長さで最小イメージを計算しています。箱を x 方向の長さだけの数値として扱う過去の不具合は入れていません。
- モデルは HistGradientBoostingClassifier（max_iter=120、learning_rate=0.075、max_leaf_nodes=31、min_samples_leaf=15、L2=0.02、random_state=42）で、条件×予測幅ごとに学習し直す比較です。
- 候補数は学習 9,610 件、テスト 4,972 件です。テストの陽性数は予測幅順に 290/312/325/345/325/335 件です。
- 実行はこの仮想マシン上で行いました（Colab は使っていません。この規模ではローカルで十分でした）。

## 判断

- 再現できました。AUC、AUPRC、Brier は全予測幅で、資料に残っていた実験Dの参照値と小数第4位まで一致しました（Log Loss は参照値が残っていないため比較対象外です）。
- 指導力にあたる差（履歴あり − 静的のみ）は AUPRC で +0.063〜+0.121、AUC で +0.030〜+0.048 と、全予測幅で出ています。
- この土台のうえで K01〜K04 を進めました。

## コードと出力

- `extract.py`: 軌道から候補・静的特徴・履歴系列（原子ペア、残基最小、Cα）・ラベルを抽出するコードです。
- `run_experiments.py`: 土台と K01〜K04 の全条件を学習・評価するコードです。
- `results.csv` / `results.json`: この土台の結果です。大きな中間データ（候補ごとの系列）はリポジトリに入れていません。
