## 1. 何を確かめる実験か

L 系列では、履歴の区間を先頭からの区間（フレーム 0〜k）に取っていたため、短い長さでは区間の終わりと起点フレーム10の間に時間の空きがあった。E01 で、この空きが回復率を大きく見せていたことが分かった。L2系列では、区間を起点フレーム10の直前に置き直す（E01 の Protocol A と同じ置き方）。長さ L ns の区間はフレーム (10 − L/0.1)〜10 で、長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10（この点だけは L と同じ条件になる）。

各長さで、区間から計算した統計量6種（最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合。ここで「最初」は区間の最初のフレーム、「最後−最初」はフレーム10から区間の最初のフレームを引いたもの）を履歴の特徴量として K15 の土台のモデルに入れたときの利得の回復率を、予測幅 1/5/10/30/50/90 ns先で測る。回復率の分母は、L と同じく全部入り（静的特徴＋実履歴6統計量、フレーム 0〜10）の利得である。

前提確認（先に固定）: 長さ 1.0 ns の点は L と同じ条件になるので、静的のみ・全部入りの AUPRC が対応する L 実験（L63〜L68）の記録値と 5e-4 以内で一致すること、長さ 1.0 ns の平均だけの回復率（統合）が L63〜L68 で測り直された値と 5e-4 以内で一致すること、長さ 1.0 ns の統計量6種の回復率が 1.0 と 1e-6 以内で一致すること（全部入りと同一の特徴量になるため）を、6つの予測幅すべてで最初に確かめる。一致しなければ、その時点で止めて統括へ報告する。

読み方は L と同一に先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む（タンパク質ごとの平均も併記）。
2. 隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（種42、パーセンタイル法）で、統計量6種の曲がりについて計算する。
4. 増え幅が最大の場所では、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、0.8 と 0.9 に必要な長さが縮んだかどうかを記録し、対応する L 実験の記録（最小の長さ・最大の増え幅・回復率の曲がり）と並べて記録する。

## 2. 条件

- 土台は K15 の条件（塩橋の形成）と同じ。学習58タンパク質・テスト30タンパク質（分け方は `experiments/K15_saltbridge_expansion/split.json` の orig＋additions）、候補は学習 2,557件・テスト 1,170件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）を条件ごとに学習し直す。塩橋の定義は L と同じ（境界 4.0 Å）。
- K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/`）を再利用する。
- 条件の一覧（予測幅ごと）: 静的のみ（静的特徴5個だけ）、全部入り（静的特徴＋実履歴6統計量、フレーム 0〜10。回復率の分母の参照）、区間の統計量6種（静的特徴＋区間の6統計量。長さ 0.0〜1.0 ns の11通り）、区間の平均だけ（静的特徴＋区間の距離の平均だけ。長さ 0.0〜1.0 ns の11通り）。

- 実行はローカルVM（L63 と同じ規模で、重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞る。

## 4. 読み取り

- 長さ 0（フレーム10だけ）の回復率は、全予測幅で統合・平均とも 0 だった。フレーム10だけから計算した統計量6種は、すべて起点の距離で決まる量であり、その距離は静的特徴にすでに入っているためである。L では長さ 0（フレーム0だけ）の時点で回復率が 0.57〜1.22 あり、10・50・90 ns先ではその時点で線に届いていた。L の短い長さの高い回復は、起点から約 1 ns 前の距離が持っていた情報だった。
- 線に届く長さは、5 ns先（0.9 の線が 0.9→0.4 ns）を除いて L より伸びた。起点の直前の区間では、回復は長さとともに緩やかに積み上がる形になり、L のように最初のほうのフレームだけで線に届くことはなかった。
- 統計量6種と平均だけ（同じ実行）の比べでは、統計量6種のほうが線に届く、あるいは短い場合が多い（1 ns先の 0.9 の線、10 ns先、90 ns先では平均だけは線に届かなかった）。ただし 30 ns先の 0.8 の線と50 ns先では平均だけのほうが短く、形による短縮は一様ではない。この点は L で見られた形（L63〜L68 と平均だけの比較）と同じである。
- 塩橋の形成は利得そのものが小さい（+0.027〜+0.144）ため、回復率の振れが大きい。信頼区間は広く、50 ns先ではブートストラップ 10,000回のうち 1,457回で統合の利得が正にならなかった。50 ns先と90 ns先の「最大の増え幅」が 0.9→1.0 ns にあるのは、長さ 0.9 ns で回復率が落ち込んだところから、定義上 1.0 になる長さ 1.0 ns へ戻る動きを見たもので、実質的な段とは読まない。個別の数値より、線に届く長さが L より伸びたという向きのほうを結果として読む。

## 5. 読みの注意点

- テストは30タンパク質だが、タンパク質ごとに陽性が少ないため、回復率を定義できるのは予測幅ごとに 15〜20タンパク質だけである。統合値とタンパク質ごとの平均で読みが分かれる場所がある（1 ns先の最大の増え幅など）。
- 実測の費用への換算はしていない。分母はシミュレーションの長さ（ns）。

## ファイル
