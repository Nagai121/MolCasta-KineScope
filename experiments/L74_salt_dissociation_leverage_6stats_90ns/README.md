# L74: L01 の曲がりを塩橋の解離で測る（統計量6種、K15 の土台、90 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L38（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）はここまでです。
- 状態: 完了。平均だけの L38 と同じく、土台の利得が +0.0582 と小さく、回復率が長さごとに大きく上下するため、曲がりの形は決められませんでした。先に固定した読み方を機械的に当てた結果は併記しますが、結論には使いません。

## 1. 何を確かめる実験か

L69 と同じ段取りで、予測幅だけを 90 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、90 ns先の陽性 160件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

静的のみ AUPRC 0.4824、全部入り 0.5405、利得 全体 +0.0582／平均 +0.0343 で、L38 の記録と 5e-4 以内で一致しました。同じ実行で測り直した平均だけの回復率は、L38 の results.json の値と全長さで完全一致しました（最大の差 0.0）。統計量6種の 1.0 ns の回復率は 1.000 でした（`premise_check.json`）。

### 先に固定した読み方への答え（機械的な適用の結果）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0.1 ns（全体 1.134）。平均だけもどちらも 0.1 ns で、縮みは 0 という機械的な結果になりますが、下記のとおり読みには使いません。
2. 増え幅がいちばん大きい場所: 0→0.1 ns（全体 +0.570）。タンパク質ごとの増え分は中央値 −0.100、正だったのは 18タンパク質のうち 44% で、段とは読めません。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 90 ns先では、分母の利得（+0.0582）が小さく、回復率の点推定も長さごとに 0.565〜1.135 と上下するため、曲がりの形は決められません。平均だけの L38 と同じ事情で、統計量6種に変えても変わりませんでした。
- AUPRC の水準としては、統計量6種の条件（全体 0.515〜0.548）が静的のみ（0.4824）と全部入り（0.5405）の周辺にあり、長さに対する傾向は見えません。
- 塩橋の統計量6種の担当分（L63〜L74）を通すと、必要な長さが縮んだのは形成では 90 ns先の 0.9 の線（0.8→0.2 ns）だけ、解離では 1 ns先（両線とも 0.1 ns 分）と 10 ns先（0.8 が 0.1 ns 分、0.9 が 0.2 ns 分）で、50 ns先の解離では平均だけが届かなかった 0.9 の線に届きました。一様に縮むわけではありません。
