# G103: 水素結合の解離の混合で、切り取りを 6 個の統計量にした場合の、切り取りの長さを変えた場合も測る（資料Dの条件、水素結合の解離、1 ns先と 30 ns先）

- 確かめること: 切り取り 0.25 ns の 6 個の統計量に、第11〜14案の生成平均を別々の特徴量として足すと、混合の差は +0.05 を超えるか。G95 は切り取り 0.1 ns だけだった。1 ns先と 30 ns先は、0.1 ns の切り取りで混合の足しが大きかった幅。
- 状態: 完了。混合の差は 1 ns先では第11案 +0.051・第13案 +0.051 が +0.05 をわずかに超え、30 ns先ではどの案も +0.05 を超えなかった。切り取りを 0.1 ns から 0.25 ns に延ばすと、切り取りだけの回復率が大きく上がり（1 ns先 0.590→0.747、30 ns先 0.582→0.834）、生成平均の入る余地が小さくなった。

## 1. 何を確かめる実験か

条件は資料Dの条件（水素結合の解離）。予測幅は 1 ns先と 30 ns先。切り取り 0.25 ns の 6 個の統計量に、第11〜14案の生成平均を別々の特徴量として足す。比べる相手は 0.25 ns の 6 個の統計量の切り取りだけの回復率。G95 は切り取り 0.1 ns だけだった。1 ns先と 30 ns先は、0.1 ns の切り取りで混合の足しが大きかった幅。

読み方は先に固定した。混合の差が +0.05 を超えるかどうかで見る。

割り当て文の「G18 で作り直した方法22の生成平均（案 11〜14）」の読み方は G95 と同じ。第11〜14案は、G18 の README に選択肢 (b) として記録された K54 の残基レベル生成系列（`~/workspace/kinescope/work/k54_gen_residue/`、解離の候補 6,131件を全件覆う）を使う。G18 で作り直した第22案（`~/workspace/kinescope/work/g18_gen22/`）は、G80 と同じ前例で参考の追加条件として 1条件だけ入れる。読み方の +0.05 の線は第11〜14案の 4条件に適用する。

## 2. 条件

- 土台は資料Dの条件（水素結合の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 4,051件・テスト 2,080件。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴7個。キャッシュは `~/workspace/kinescope/work/data_cache_k46/`（`{protein}_R{rep}.npz`、hist は (11, N) で保存されているため (N, 11) に直して使う）。
- 6 統計量の定義は G48 と同じ形で、境界は水素結合の 3.5 Å：[最初, 平均, 標準偏差, 最小, 最後−最初, 3.5 Å以下割合] を切り取りのフレームで計算する。切り取りは 0.25 ns = フレーム [0,1,2]。
- 生成平均の出所（第11〜14案）: K54 の残基レベル生成系列 `~/workspace/kinescope/work/k54_gen_residue/`（`{protein}_R{rep}.npz`、gen11〜gen14 は 4分岐×9点、donor_atom・acceptor_atom 付き）。生成平均は K17・G13・G84 と同じ定義で、4分岐×9点の平均。対応付けはファイルの並びそのままで、donor_atom・acceptor_atom が K46 キャッシュと一致することを確かめた。
- 参考の第22案の生成平均: G18 で作り直したもの `~/workspace/kinescope/work/g18_gen22/`（atlas-*.npz、pair と gen_dist の 4列）。gen5 = [起点距離, gen_dist] の 5点系列の平均（G44・G50 と同じ）。対応付けのキーは (軌道ID, ドナー原子, アクセプター原子)。第22案は生成器が学習した範囲（形成の候補だけ）の外への当てはめである点に留保がつく（G18 の README 第7節）。
- 条件（各予測幅、すべて条件ごとに学習し直す）: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取り 0.25 ns の 6 統計量／切り取り 0.25 ns の平均だけ（参考）／生成平均だけ（各案）／混合（切り取り 0.25 ns の 6 統計量＋生成平均を別々の特徴量として 7列）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。土台の静的のみ・全部入りの AUPRC は、K46 の記録値と小数第4位まで一致することを各予測幅で確かめた。

## 4. 読み取り

先に固定した読み方に照らすと、混合の差は 1 ns先では第11・13案が +0.05 をわずかに超え、30 ns先ではどの案も +0.05 を超えない。切り取りを 0.1 ns から 0.25 ns に延ばすと、切り取りだけの回復率が大きく上がった（1 ns先 0.590→0.747、30 ns先 0.582→0.834）。切り取りの側が強くなった分、生成平均の入る余地が小さくなり、30 ns先では混合の足しが消えた。1 ns先では第11・13案が +0.051 と線のすぐ上に残ったが、0.1 ns のとき（第11案 +0.059、第12案 +0.071、第14案 +0.087）より小さい。

水素結合の形成の G100 と同じ形。G100 でも切り取りを 0.25 ns に延ばすと 1 ns先では混合の足しが消えた。解離では 1 ns先に +0.051 が 2 案だけ残った。

## 5. 判断できること・まだ分からないこと

- 判断できること: 水素結合の解離の 6統計量の混合は、切り取りを 0.25 ns に延ばすと 1 ns先では第11・13案だけが +0.05 をわずかに超え、30 ns先ではどの案も線を超えない。0.1 ns の切り取りでは 1 ns先は第11・12・14案、30 ns先は第13・14案が線を超えていたので、混合の足しは切り取りの長さで小さくなる。
- まだ分からないこと: 1 ns先の第11・13案の +0.051 は線のすぐ上で、タンパク質単位の区間を付ければ 0 を含むかもしれない（G101 が G95・G97 のセルに区間を付けているが、G103 のセルは対象外）。G103 のセルのタンパク質単位の区間は測っていない。
