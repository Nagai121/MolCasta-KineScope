# G27: 塩橋の形成で、切り取りを長くすればどこまで戻るか（K15 の条件、塩橋の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDの経路の続き。G03 では 0.1 ns の切り取りの平均だけの回復率が 0.647 だった。切り取りを 0.25 ns と 0.5 ns に長くし、それぞれ平均だけと 6 統計量の両方を入れる。
- 状態: 完了。0.5 ns の 6 統計量の回復率は 0.716 で、先に固定した 8 割の線には届かなかった。ただし 5 割未満でもなく、先に固定した読み方のどちらにも当てはまらない中間の結果になった。0.25 ns の 6 統計量は 0.334 と大きく落ち込み、長さに対して単調ではない。

## 1. 何を確かめる実験か

K15 の条件（塩橋の形成、1 ns先）で、切り取りを 0.25 ns（フレーム [0,1,2]、実際に覆う長さは 0.2 ns）と 0.5 ns（フレーム [0〜5]）に長くし、それぞれ平均だけと 6 統計量の両方を補正モデルに入れる。0.1 ns の 6 統計量もあわせて測り、長さの走査をそろえる。参照は実履歴の利得で、+0.1440（K15 と一致）。回復率は実履歴の利得に対する比で測る。

6 統計量の定義は K15/K53 と同じ（閾値 4.0 Å）: [最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合] を切り取りのフレームで計算する。

判定は先に固定した。0.5 ns の 6 統計量で回復率 8 割以上なら、塩橋の形成も切り取りを長くすれば短い実MDの路線でいける。0.5 ns でも 5 割未満なら、塩橋の形成は切り取りを長くしても足りないことになる。

## 2. 条件

- 土台は K15 の条件。ATLAS 解析版、学習58タンパク質（2,557件）・テスト30タンパク質（1,170件、1 ns先の陽性 93件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 塩橋の形成の候補（K15 と同じ）: 正側（LYS の NZ、ARG の NE/NH1/NH2）と負側（ASP の OD1/OD2、GLU の OE1/OE2）の荷電重原子ペアの最小距離が、起点で 4.0 Å より大きく（塩橋ができていない状態）で配列距離2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å 以下になること。静的特徴は5個、履歴の閾値は 4.0 Å。
- 切り取りの定義（G02/G03 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。0.1 ns → フレーム 0, 1（2フレーム）、0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さ 0.2 ns）、0.5 ns → フレーム 0〜5（6フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴だけ。
- 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
- 平均だけ（0〜1 ns）: 静的特徴＋0〜1 ns の平均だけ。
- 切った平均だけ: 静的特徴＋切った履歴の平均だけ（0.1 / 0.25 / 0.5 ns）。
- 切った6統計量: 静的特徴＋切った履歴の6統計量全部（0.1 / 0.25 / 0.5 ns）。

## 3. 結果

### 土台の再現

静的のみと全部入りが、K15 の記録と小数第4位まで完全一致した。1 ns先で静的のみ AUPRC 0.2402、全部入り 0.3842、利得 +0.1440。0.1 ns の平均だけも G03 と一致した（AUPRC 0.3333、回復率 0.647）。

### (a) 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差、テスト側

| 切る長さ | テスト | 学習 | 偏り（テスト） |
|---|---:|---:|---:|
| 0.1 ns | 1.242 Å | 1.314 Å | −0.024 Å |
| 0.25 ns | 1.068 Å | 1.093 Å | +0.004 Å |
| 0.5 ns | 0.655 Å | 0.631 Å | +0.034 Å |

切った平均は、0〜1 ns の平均から大きく外れる（0.1 ns で 1.24 Å）。偏りはほぼ 0 で、散らばりが大きいだけ。参考: 水素結合の形成（G02）では 0.1 ns で 0.396 Å、塩橋の解離（G09）では 1.150 Å。

### (b) 1 ns先の利得の回復率（主判断）

| 条件 | AUPRC | 回復率 |
|---|---:|---:|
| 静的のみ | 0.2402 | ― |
| 全部入り | 0.3842 | 1.000 |
| 平均だけ（0〜1 ns） | 0.3682 | 0.889 |
| 切った平均だけ 0.1 ns | 0.3333 | 0.647 |
| 切った6統計量 0.1 ns | 0.3388 | 0.685 |

## 4. 読み取り

- **0.5 ns の 6 統計量の回復率は 0.716 で、先に固定した 8 割の線には届かなかった。** ただし 5 割未満でもないので、先に固定した読み方のどちらにも当てはまらない。切り取りを 0.5 ns まで長くしても、塩橋の形成では 8 割には届かない。路線が成り立つとも、足りないとも、この測定だけでは言えない。
- 平均だけの回復率は、切る長さが 0.1 ns → 0.25 ns → 0.5 ns と伸びても 0.647 → 0.616 → 0.659 とほぼ横ばいで、長くしても上がらない。平均は短い切り取りでもほぼ決まる。
- 6統計量は長さに対して単調ではない。0.1 ns で 0.685、0.25 ns で 0.334 と大きく落ち込み、0.5 ns で 0.716 と戻る。0.25 ns の落ち込みは、同じ長さの平均だけ（0.616）より 0.28 も低い。水素結合の形成（G12/G16）では 6 統計量は 0.1 ns で 0.446、0.25 ns で 0.649、0.5 ns で 0.768 と単調に上がったのと対照的。3フレームしかない切り取りでは、塩橋の形成の候補（起点が境界から遠い）で標準偏差や最小、4.0 Å以下割合がほとんど情報を持たず、読み出しを乱す側に働く、という見立てが自然。確かめの計算はしていない。
- 0〜1 ns の平均だけの回復率は 0.889 と、水素結合の形成（強い土台で 0.975）や塩橋の解離（0.921）より低い。塩橋の形成では平均以外の統計量も利得の一部を持っている、という K31/K48 の形と合っている。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.5 ns の 6 統計量でも 8 割には届かない（0.716）。平均だけは長さを伸ばしても 0.65 前後で横ばい。6統計量は 0.25 ns で大きく落ち込む。
- まだ分からないこと: 0.25 ns の 6 統計量の落ち込み（0.334）が、3フレームの統計量の性質によるものか、テストが小さいことによる揺れかは、この測定だけでは分けられない。テストは 1,170件、1 ns先の陽性は 93件と小さく、単一の学習 seed の結果でもある。0.5 ns より長い切り取り（0.75 ns、1 ns）で 8 割に届くかも、この実験では測っていない。
