# L2-12: 短いMDの長さに対して、指導力がどれだけ戻るか（区間を起点の直前に置き直した測り直し、資料Dの条件、接触の解離、平均だけ）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる L 系列の全面改訂（L2系列）の1件。L21〜L26（接触の解離、資料Dの条件、平均だけ、予測幅 1/5/10/30/50/90 ns先）と同じ土台・同じ読み方で、履歴の区間の置き方だけを変えて測り直す。
- 状態: 完了。前提確認（長さ 1.0 ns の点で L21〜L26 の記録と一致）は6つの予測幅すべてで通った。回復率 0.8／0.9 に届く最小の長さは、1 ns先で 0.3 ns／0.5 ns（L では 0.1 ns／0.1 ns）、5 ns先で 0.6 ns／届かない（L では 0.1 ns／届かない）、10 ns先で 0.4 ns／0.9 ns（L では 0.5 ns／0.6 ns）、30 ns先で 0.5 ns／届かない（L では 0.3 ns／届かない）、50 ns先で 0.7 ns／0.8 ns（L では 0.5 ns／0.9 ns）、90 ns先で 0.9 ns／届かない（L では 0.1 ns／0.1 ns）で、接触の形成（L2-11）と違い、必要な長さはおおむね伸びた。増え幅が最大なのは全予測幅で 0→0.1 ns。長さ 0（フレーム10だけ）の回復率は全予測幅で 0 だった。

## 1. 何を確かめる実験か

L 系列では、履歴の区間を先頭からの区間（フレーム 0〜k）に取っていたため、短い長さでは区間の終わりと起点フレーム10の間に時間の空きがあった。E01 で、この空きが回復率を大きく見せていたことが分かった。L2系列では、区間を起点フレーム10の直前に置き直す（E01 の Protocol A と同じ置き方）。長さ L ns の区間はフレーム (10 − L/0.1)〜10 で、長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10（この点だけは L と同じ条件になる）。

各長さで「区間の平均だけ」を履歴の特徴量として資料Dの条件のモデルに入れたときの利得の回復率を、予測幅 1/5/10/30/50/90 ns先で測る。回復率の分母は、L と同じく全部入り（静的特徴＋実履歴6統計量、フレーム 0〜10）の利得である。

前提確認（先に固定）: 長さ 1.0 ns の点は L と同じ条件になるので、静的のみ・全部入り・長さ 1.0 ns の平均だけの AUPRC が、対応する L 実験（L21〜L26）の記録値と 5e-4 以内で一致することを、6つの予測幅すべてで最初に確かめる。一致しなければ、その時点で止めて統括へ報告する。

読み方は L と同一に先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む。
2. 隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、統合・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 増え幅が最大の場所では、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。
5. あわせて、対応する L 実験の記録（最小の長さ・最大の増え幅・回復率の曲がり）と並べて記録する。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）を条件ごとに学習し直す。候補と距離の定義は L と同じ（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/`）を再利用する。
- 条件の一覧（予測幅ごと）: 静的のみ（静的特徴5個だけ）、全部入り（静的特徴＋実履歴6統計量、フレーム 0〜10、境界 4.5 Å。回復率の分母の参照）、区間の平均だけ（静的特徴＋区間の距離の平均だけ。長さ 0.0〜1.0 ns の11通り）。
- 回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルVM（L21 と同じ規模で、重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞る。

## 4. 読み取り

- 長さ 0（フレーム10だけ）の回復率は全予測幅で 0 だった（L2-11 と同じ）。フレーム10の距離は静的特徴にすでに入っているためである。L では長さ 0（フレーム0だけ）の時点で回復率が 0.55〜0.79 あり、長さ 0.1 ns（フレーム 0〜1）で 0.58〜0.93 に達していた。つまり L の短い長さの高い回復は、起点から約 1 ns 前の距離が持っていた情報だった。
- 起点の直前の 0.1 ns（フレーム 9〜10）の回復率は 0.34〜0.51 にとどまり、そこから長さとともに緩やかに上がる。線に届く長さは、1 ns先で 0.1／0.1 ns（L）から 0.3／0.5 ns へ、5 ns先で 0.1 ns（L）から 0.6 ns へ、90 ns先で 0.1／0.1 ns（L）から 0.9 ns／届かない、へと伸びた。10 ns先と50 ns先は混ざっていて、0.8 の線は 10 ns先で 0.5→0.4 ns と少し縮み、50 ns先で 0.5→0.7 ns と伸び、0.9 の線は 10 ns先で 0.6→0.9 ns と伸び、50 ns先で 0.9→0.8 ns と縮んだ。
- 接触の形成（L2-11）では区間を起点の直前に置くと短い区間の回復が大きくなったが、解離では逆に小さくなった。解離については、起点から離れた過去の距離（そのペアが以前から離れ気味だったかどうか）が効いていて、起点の直前ではペアはまだ接触しているため情報が少ない、という形になっている。
- 統計量6種で同じ置き直しをした L2-32 でも、0.1 ns の回復率が L の 0.66〜0.94 から 0.35〜0.53 に下がったことが記録されていて、平均だけの本実験と向きが一致する。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められない。特に 30 ns先では 2qt4_A の回復率が 1 を超える長さが多く、タンパク質ごとの利得の小ささが効いている。
- 実測の費用への換算はしていない。分母はシミュレーションの長さ（ns）。
