# K12: 強い土台で統計量を1つずつ実系列の値に差し替える

## 仮説

H5/H6（特徴量の抽出と読み出し、運動の生成そのもの）の検証です。K09（弱い土台）では、生成の統計量を1つずつ実系列の値に戻すと平均だけで回復率が 1.078（1 ns先）になり、「平均の統計量が喪失の主な通り道」という結論でした。K06(b) では、強い土台（凍結した本体 T1I2006＋補正モデル、未見100タンパク質）で実履歴の利得 +0.0712（1 ns先）が再現され、生成特徴は補正に何も足さないことが分かりました。そこで、K09 の結論が強い土台でも成り立つかを確かめます。

## データと条件

- 条件は K06(b) と同一です。凍結した本体 T1I2006 の上に補正モデル（HistGradientBoosting、160本、学習率0.065、葉15、葉あたり最小20件、L2 0.15、seed 20261121）を、較正用8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件、学習 13,808件）で評価します。予測幅は 1/5/10/30/50/90 ns の6幅、指標は AUC、AUPRC、Brier、Log Loss です。
- 補正モデルの入力は、静的5特徴（本体の予測確率、起点距離、基礎記述子3個）に履歴特徴を足す形です。実履歴補正は静的＋実履歴10特徴、生成条件は静的＋生成6統計量です。条件ごとに、予測幅ごとに学習し直します。
- 計算済みデータの再利用: K06(b) の計算済み特徴 `~/workspace/k06b/run/k06b_out/`（108タンパク質×3レプリカの npz、凍結確率・静的・実履歴・ラベル・生成8・生成6）をそのまま使いました。軌道の取り直しも、本体 T1I2006 の読み込みも、生成器のチェックポイントの読み込みも行っていません。`gen6` は K06(b) の `score_b.py` の `gen6()` で作られたもので、生成5点系列（起点距離＋前方 0.1/0.3/0.5/1.0 ns）からの D式6統計量です。
- 対照の確認: 静的のみ・実履歴・生成8・生成6 の4条件すべてで、K06(b) の記録（`k06b_results.json`）と AUC・AUPRC・Brier・Log Loss・タンパク質マクロ AUPRC が全予測幅で完全一致しました（最大差 0.0）。

### 生成特徴の定義（K06(b) の記録で確認）

- K06(b) の「生成特徴」は2種類あり、生成8特徴（`gen8`、生成経路を要約する `summarize` の8個）と生成6特徴（`gen6`、生成した距離の列から資料D式で作った6特徴）です。本実験の生成ベースラインは **生成6特徴（`gen6`）** で、K09/K09b と同じ D式6統計量です。
- 生成6統計量の並びは [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下だった割合] で、最初の値は起点距離です。
- 実系列の6統計量は、K06(b) の実履歴10特徴から取りました。実履歴10特徴の並び（`score_b.py`）は [系列の最初の値（0 ns）、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å 以下割合、4.5 Å 以下割合、距離が増えたステップの割合] なので、対応は 最初←history[0]、平均←history[1]、標準偏差←history[2]、最小値←history[3]、最後−最初←history[5]、3.5 Å 以下割合←history[7] です。

### 差し替えの方法と留保

- 生成6統計量のうち1つだけを、同じ候補の実系列の6統計量の値に置き換え、学習・評価の両方に同じ処理を適用し、条件ごとに学習し直します。差し替える統計量は 平均、3.5 Å 以下割合、最小値、標準偏差、最後−最初、最初 の6つです。
- 留保1（点数と向きの違い）: 実系列の統計量は 11フレームの後方（履歴）系列から、生成系列の統計量は 5点の前方系列から作られています。K09 と同じ扱いで、向きの違い自体の効果は本実験では分離していません。「最初」は生成では起点距離、実では 0 ns の距離であり、「最後−最初」も向きが逆の量です。平均は向きに依らない量なので、この留保の影響を受けにくいです。
- 留保2（実履歴補正との違い）: 実履歴補正は10特徴（最大値、4.5 Å 以下割合などを含む）を使いますが、差し替え条件は生成6統計量の枠組みの中での置き換えです。したがって全6統計量を同時に差し替えても実履歴補正とは一致しません（本実験では同時差し替えは行っていません）。

### 回復率の定義

- 主判断は 1 ns先のタンパク質マクロ平均 AUPRC です。補助的に全幅と候補ミクロ（全体）の AUPRC も見ます。
- 回復率 =（差し替え条件の改善量 − 生成6の改善量）÷（実履歴の改善量 − 生成6の改善量）。改善量は各条件の AUPRC から静的のみ補正の AUPRC を引いたものです。
- 生成6は 1 ns先で静的のみを下回るため（マクロ改善量 −0.0058）、分母は実履歴の利得そのもの（+0.0712）ではなく、実履歴の利得から生成6のマイナス分を差し引いた 0.0770 になります。つまり回復率 1.0 は「生成6の不足分を埋めて実履歴と並ぶ」ことではなく、「実履歴の利得に加えて生成6のマイナス分まで埋める」ことです。AUPRC の絶対値と改善量も併記します。

## 判断できること

読み方は実験前に固定したとおりに判定します。主に 1 ns先で判断します。

- 平均の差し替えだけで回復率は 0.933（マクロ）、0.956（ミクロ）で、事前に固定した目安の 0.8 を超えました。**K09 の結論は強い土台でも成り立ちます。** 生成器の失敗は平均の統計量に集中していることになります。平均だけを実系列の値に戻すと、生成6の不足分がほぼ完全に戻ります（マクロ AUPRC 0.4481 → 0.5200、実履歴は 0.5251）。
- 3.5 Å 以下割合の差し替えも回復率 0.799（マクロ）、0.820（ミクロ）で、目安の 0.8 にほぼ届きました。K09 と同じく、平均と割合は大きく重なる量で、どちらか1つが「真の」担い手かは本実験だけでは分離できません。
- 最小値は 0.616 で半分ほど、最初は 0.389、最後−最初は 0.410、標準偏差は 0.112 とほぼ回復しませんでした。標準偏差が全幅で 0.03〜0.14 とほぼ何も戻さないことは、K07（揺らぎの大きさは主因ではない）と合います。
- 平均の回復率は 5 ns先では 0.716 とやや下がりますが、10 ns先以降では 0.87〜1.11 と高く、全幅で平均が最大の回復率です（90 ns先で割合 0.910 に対して平均 1.108）。割合も全幅で 0.80〜1.09 と高く、平均と割合の2つがそろって高い点は K09/K09b と同じ形です。
- K06(b) の「生成特徴は補正に何も足さない」という結果と合わせると、強い土台で生成が何も足さないのは、生成の統計量のうち平均（とそれと結びついた割合）の値が実系列とずれているためで、平均さえ実系列の値になれば、生成の他の統計量のままでも実履歴の利得の大半が戻る、ということになります。

## まだ分からないこと

- 6統計量は互いに相関するため、単独差し替えで回復しないことは、その統計量が無関係であることの証明にはなりません。特に平均と 3.5 Å 以下割合、最小値は結びついており、どれか1つが「真の」担い手かは本実験だけでは分離できません（K09 と同じ留保）。
- 実系列の統計量は 11フレーム、生成系列は 5点で、点数と向きが違います。実5点（フレーム [0,1,3,5,10] や [0,3,5,7,10]）の統計量で差し替えた場合に結果が変わるかは、本実験では測っていません。
- 回復率が 1 を超える幅があります（平均の差し替えで 10 ns先 1.025、30 ns先 1.037、90 ns先 1.108 など）。生成の他の統計量と実の平均の組み合わせが、実履歴そのものよりわずかに良く働く場合があることを示しますが、単一の学習 seed の結果であり、ばらつきの範囲は測っていません。
- 本実験は第22案の生成系列だけが対象です。他の生成方式でも平均の統計量が主な通り道かは、K11 の一般性の結果と合わせて読む必要があります。
