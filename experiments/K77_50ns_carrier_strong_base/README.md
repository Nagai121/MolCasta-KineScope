# K77 50 ns先の指導力は、どの統計量が担うか（K06(b) の条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。強い土台では、50 ns先で平均だけ 0.933、3.5 Å以下割合だけ 0.888 と両方が利得の8割以上を戻しました。90 ns先（K73）と同じ形で、平均と割合の両方が担えます。K56 の「1 ns先で学習した読み出しを 50 ns先に当てると 0.608 と弱い」は、50 ns先の指導力に担い手がないからではなく、読み出しの移し替えの弱さです。

## 1. 何を確かめる実験か

K56 で、強い土台（K06(b) の条件）で実履歴の補正モデルを 1 ns先で学習し、50 ns先で評価すると利得の戻り率は 0.608 と弱いことが分かりました。50 ns先の指導力そのものをどの統計量が担うか、50 ns先で学習したモデルで切り分けます。

読み方は先に固定しました。どれか1つの統計量だけで利得の8割以上が戻れば、その統計量が 50 ns先の担い手です。どれも戻らなければ、50 ns先の指導力は複数の統計量に分散しています。両方とも8割以上に戻る場合は、その旨を正直に記録します（「1つの統計量だけが担い手」ではなく「平均と割合の両方が担える」という読みになります）。

K56 との問いの違いに注意してください。K56 は「1 ns先で学習したモデルを 50 ns先に当てる」（読み出しの移し替え）で、K77 は「50 ns先で学習したモデル」の担い手です。K77 で 50 ns先の担い手が見つかっても、K56 の移し替えの弱さは説明されません。逆に、K77 で担い手が見つからなければ、K56 の弱さの一因になります。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A）で学習し、未見100タンパク質×3レプリカ（163,074件、学習 13,808件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`）をそのまま使いました。軌道の取り直しも、本体 T1I2006 の読み込みも、生成器のチェックポイントの読み込みも行っていません。距離は K06(b) の保存済み特徴量に含まれるもので、この実験では距離の計算をし直していません。
- 補正モデルの入力は、静的5特徴（本体の予測確率、起点距離、基礎記述子3個）に履歴の量を足す形です。実履歴10特徴の並びは [最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å以下割合、4.5 Å以下割合、距離が増えたステップの割合] で、6統計量はそのうちの [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下割合] です。
- 条件は9つで、静的特徴に次の履歴の量を足したものです。
  - 静的のみ: 履歴なし
  - real6: 6統計量すべて（K71 の「全部入り」に対応。K77 の回復率の主たる参照）
  - full: 実履歴10特徴すべて（K06(b) の実履歴条件そのもの。K21 の参照）
  - 最初の値だけ / 平均だけ / 標準偏差だけ / 最小値だけ / 最後−最初だけ / 3.5 Å以下割合だけ: その列だけ
- 利得 =（参照条件の AUPRC − 静的のみ）、各条件の回復率 =（その条件の AUPRC − 静的のみ）÷ 利得で測りました。回復率は real6 を参照にしたものを主、full を参照にしたものを従としました。評価はタンパク質マクロ平均 AUPRC を主、全体まとめ（ミクロ）を従としました。
- 測った予測幅は 50 ns先（主判断）と 1 ns先（参考）の2幅です。
- 対照の確認: 静的のみと full は、50 ns先と 1 ns先の両方で K06(b)・K12・K21 の記録と全4指標で完全に一致しました（最大差 0.0、1 ns先で静的のみ マクロ AUPRC 0.4539、full 0.5251、50 ns先で静的のみ 0.4407、full 0.4752）。50 ns先の full の利得はマクロ +0.0344 で、K21 の 50 ns先の行の +0.0344 と一致します。

## 4. 読み取り

- **強い土台では、50 ns先で平均だけ 0.933 と割合だけ 0.888 の両方が、real6 の利得の8割以上を戻しました。** 先に固定した読み方の3つ目の枝に当たり、担い手は「平均と割合の両方が担える」という読みになります。full を参照にしても平均 0.917、割合 0.873 と両方8割以上で、読みは変わりません。
- K73（90 ns先）との比較です。90 ns先では real6 参照で平均だけ 0.910、割合だけ 0.886 で、50 ns先の 0.933 と 0.888 とほぼ同じ形です。強い土台では、50 ns先も 90 ns先も平均と割合の両方が担い手で、予測幅による担い手の変わり方はありません。
- K21 との照合です。full を参照にした回復率は、平均 0.917/0.906、割合 0.873/0.843、最小値 0.596/0.554、最初の値 0.448/0.407、最後−最初 0.458/0.404、標準偏差 0.047/0.049 と、K21 の 50 ns先の行（平均 0.917/0.906、割合 0.873/0.843、最小値 0.596/0.554）と完全に一致しました。K21 はすでに強い土台の 50 ns先を測っており、K77 はその値を K73 と同じ 6統計量の分け方・real6 参照で測り直したものですが、食い違いはありません。K21 の「形だけ」（標準偏差＋最後−最初の2列）の 0.432/0.399 は、K77 の標準偏差だけ 0.047/0.049 と最後−最初だけ 0.458/0.404 を合わせた形と整合します。
- 参照の違いについてです。K21 の参照は 10特徴の full（利得 +0.0344）で、K77 の主たる参照は 6統計量の real6（利得 +0.0338）です。50 ns先では real6 と full の利得はほぼ同じで、回復率の関係は 0.983 倍と 1 ns先（0.992 倍）と同程度です。参照をどちらにしても、50 ns先で平均と割合の両方が8割以上という読みは変わりません。
- 他の統計量です。最小値だけ 0.606、最初の値だけ 0.456、最後−最初だけ 0.466 と半分ほどを戻し、標準偏差だけは 0.048 とほとんど戻しません。標準偏差が 50 ns先でも何も戻さないことは、K07（揺らぎの大きさは主因ではない）と合います。
- K56 との関係です。K56 は 1 ns先で学習した読み出しを 50 ns先に当てると 0.608 と弱い、という結果でした。K77 では 50 ns先で学習したモデルで平均だけ 0.933、割合だけ 0.888 と担い手がはっきりあるため、K56 の弱さは「50 ns先の指導力に担い手がないから」ではありません。1 ns先で学習した読み出しが 50 ns先に移らない、という読み出しの移し替えの問題です。
- 1 ns先の参考値です。real6 参照で平均だけ 0.965、割合だけ 0.864 と両方8割以上で、強い土台の 1 ns先では平均と割合の両方が担い手です。K12 の差し替え実験（平均 0.933、割合 0.799）とも同じ形です。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、50 ns先の指導力は平均だけでも割合だけでもほぼ担えます（回復率 0.933 と 0.888、full 参照では 0.917 と 0.873）。90 ns先（K73）と同じ形で、強い土台では 50 ns先も 90 ns先も平均と割合の両方が担い手です。K56 の移し替えの弱さは、50 ns先の担い手の不在では説明できません。
- まだ分からないこと: 平均と割合の情報の重なりの内訳（割合の利得のうち、平均と相関する分がどれだけか）。また、1 ns先で学習した読み出しが 50 ns先に移らない理由（読み出しの移し替えの弱さの中身）は、この実験だけでは分かりません。
