# G136: 水素結合の形成で、切り取り 1.0 ns の平均だけで指導力がどれだけ戻るか（資料Dの条件、水素結合の形成、1・5・10・30・50・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G74 は切り取り 0.1・0.25・0.5 ns までだったので、1.0 ns の切り取りが空白だった。ここを埋める。
- 状態: 完了。

## 1. 切り取りの定義（G02/G74 と同じ、結果を見る前に固定）

- 軌道の保存間隔は 100 ps（0.1 ns）。フレーム k は時刻 k*0.1 ns。
- 0.1 ns → フレーム 0, 1（2フレーム、覆う長さ 0.1 ns）
- 0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さは 0.2 ns。0.25 ns は 100 ps 刻みに合わない）
- 0.5 ns → フレーム 0〜5（6フレーム、覆う長さ 0.5 ns）
- **1.0 ns → フレーム 0〜9（10フレーム、実際に覆う長さは 0.9 ns）**。フレームは 100 ps 間隔なので、フレーム 0 からフレーム 9 までが覆う長さは 0.9 ns になる。0〜1 ns の履歴全部はフレーム 0〜10 の11フレームで、起点フレーム 10 はこの切り取りには入らない。呼び名の「1.0 ns」と実際に覆う長さ（0.9 ns）は違う。これまでの切り取りの呼び名（0.1 ns → フレーム [0,1]、0.25 ns → フレーム [0,1,2] で実際には 0.2 ns を覆う、0.5 ns → フレーム 0〜5）と同じ数え方である。
- 平均の計算に使うフレームの範囲はフレーム 0〜9。平均だけの条件は、他の履歴統計量を入れずに平均の列だけを足す K21 の形。
- 起点フレーム10（1 ns）は変えない。条件は「静的特徴＋切った平均だけ」。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（その予測幅での実履歴の利得）。

## 2. 土台の再現と利得の出所

- 土台は K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/`、18軌道）を再利用。資料Dの条件（学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件）。
- 土台の利得は K01 の記録値（`experiments/K01_time_degradation/results.json` の静的のみと全部入りの AUPRC の差）で、再計算でも一致した。1 ns +0.1178、5 ns +0.1155、10 ns +0.0829、30 ns +0.0626、50 ns +0.0739、90 ns +0.1211。
- 静的のみ・全部入りは全予測幅で K01 の記録と小数第4位まで一致した（1 ns先で静的のみ 0.3637、全部入り 0.4815。90 ns先で静的のみ 0.3035、全部入り 0.4246）。
- 0.1・0.25・0.5 ns の切り取りの平均だけも G74 の記録と全予測幅で小数第3位まで一致した（コード内の assert で確認）。
- 実行はローカルVMのみ。HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、seed 42）。実行時間は約5分。

## 3. 結果（切り取りの平均だけの回復率）

| 予測幅 | 土台の利得 | 0.1 ns | 0.25 ns | 0.5 ns | 1.0 ns | 0.5 を超える最小の切り取り |
|---:|---:|---:|---:|---:|---:|---|
| 1 ns | +0.1178 | 0.570 | 0.647 | 0.770 | **1.114** | 0.1 ns |
| 5 ns | +0.1155 | 0.846 | 1.029 | 1.037 | **1.119** | 0.1 ns |
| 10 ns | +0.0829 | 0.771 | 0.975 | 1.229 | **0.839** | 0.1 ns |
| 30 ns | +0.0626 | 0.979 | 1.053 | 1.138 | **1.121** | 0.1 ns |
| 50 ns | +0.0739 | 0.745 | 1.004 | 1.266 | **1.340** | 0.1 ns |
| 90 ns | +0.1211 | 0.590 | 0.825 | 0.658 | **0.826** | 0.1 ns |

参考の 0〜1 ns の平均だけ（フレーム 0〜10 の11フレーム全部）の回復率は、1 ns 1.042、5 ns 1.190、10 ns 1.108、30 ns 1.258、50 ns 1.182、90 ns 0.772（G74 の記録と同じ値）。

1.0 ns の切り取りの平均だけの AUPRC は、1 ns先 0.4949、5 ns先 0.4785、10 ns先 0.4243、30 ns先 0.4340、50 ns先 0.4332、90 ns先 0.4035。全部入り（実履歴の6統計量）との AUPRC の差は、1 ns先 +0.0134、5 ns先 +0.0137、10 ns先 −0.0134、30 ns先 +0.0075、50 ns先 +0.0251、90 ns先 −0.0211。

## 4. 読み取り（先に固定した読み方に沿う）

- 0.5 を超える最小の切り取りは、6つの予測幅すべてで 0.1 ns のまま。1.0 ns の切り取りでも 0.5 を超えない予測幅はない。G74 の結論は変わらない。
- 切り取りを長くしても回復率は単調には上がらない。10 ns先では 0.5 ns の 1.229 から 1.0 ns の 0.839 へ大きく下がり、30 ns先でも 1.138 から 1.121 へわずかに下がる。1 ns先と 5 ns先では 0.5 ns から 1.0 ns へ上がり（0.770 → 1.114、1.037 → 1.119）、50 ns先でも 1.266 → 1.340 と上がる。90 ns先では 0.658 → 0.826 と上がる。
- 1.0 ns の切り取りの平均だけでも、1・5・30・50 ns先では実履歴を上回る（回復率 1.114〜1.340）。10 ns先と 90 ns先では実履歴に届かない（0.839、0.826）。0〜1 ns の平均だけ（11フレーム全部）と比べると、1.0 ns の切り取り（10フレーム）は 1 ns先で 1.114 と 1.042 を上回り、50 ns先でも 1.340 と 1.182 を上回る一方、10 ns先では 0.839 と 1.108、30 ns先では 1.121 と 1.258 と、11フレーム全部のほうが大きい。起点フレーム 10 を入れるかどうかで、10 ns先の回復率が 0.839 から 1.108 へ大きく変わる点には注意が要る。
- 30 ns先の利得は +0.0626 と 6つの予測幅の中で最も小さいため、回復率の分母が小さい点には注意が要る。ただし 1.0 ns の回復率 1.121 は、AUPRC では静的のみ 0.3639 から 0.4340 へ +0.0701 の上がりで、利得を上回る量である。

## 5. 残りのばらつき（切った平均 − 0〜1 ns の平均、テスト側の標準偏差）

| 切り取り | 残りのばらつき（テスト側） |
|---|---:|
| 0.1 ns | 0.396 Å |
| 0.25 ns | 0.319 Å |
| 0.5 ns | 0.188 Å |
| 1.0 ns | 0.049 Å |

- 1.0 ns の切り取りでは残りのばらつきは 0.049 Å で、複製間の下限 0.249 Å を大きく下回る。切った平均と 0〜1 ns の平均の差の平均は +0.025 Å で、始めの短い部分の平均のほうがわずかに大きい（G02 の記録と同じ向き）。
- 0.1・0.25・0.5 ns の値は G02 の記録と同じ値。
