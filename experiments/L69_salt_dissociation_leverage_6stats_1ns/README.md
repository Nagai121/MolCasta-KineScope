# L69: L01 の曲がりを塩橋の解離で測る（統計量6種、K15 の土台、1 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L33（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分のうち、解離の最初（L69〜L74）です。
- 状態: 完了。必要な長さがわずかに縮みました。0.8 の線は平均だけの 0.4 ns に対して 0.3 ns、0.9 の線は 0.5 ns に対して 0.4 ns で、どちらも 0.1 ns 分の縮みです。曲がりの形は平均だけと同じく緩やかな上がり方でした。

## 1. 何を確かめる実験か

L63 と同じ段取りで、現象を塩橋の解離に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、1 ns先の陽性 101件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns（全体 0.848）**。平均だけでは 0.4 ns で、**0.1 ns 分縮みました**。平均（タンパク質平均）では 0.7 ns でした。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.4 ns（全体 0.933）**。平均だけでは 0.5 ns で、**0.1 ns 分縮みました**。
3. **増え幅がいちばん大きい場所: 全体では 0.8→0.9 ns（+0.214）**。増え分は各区間に分散していて（+0.05〜+0.21）、段の位置でのタンパク質ごとの増え分は中央値 0.000 で、段とは読めません。緩やかな上がり方という L33 の形は6種でも同じです。
4. 長さごとの回復率の差（6種 − 平均、全体）は、0.3〜0.6 ns で +0.03〜+0.13 と小さい正、0.8 ns で −0.409 と大きい負でした。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 17タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 解離の 1 ns先では、統計量6種は平均だけより少しだけ早く線に届きました。ただし縮みは 0.1 ns 分で、区間の広さを考えると、両形の曲がりはほぼ同じと見るのが妥当です。
- 形成側（L63〜L68）では縮みは 90 ns先の 0.9 の線だけでしたが、解離側では最初の予測幅で両方の線に小さい縮みが出ました。
