# K3-06: 相互作用のエネルギーとずれの関係

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K3 系列（軌道が知っていて、静的構造が知らない、ペアの物理的な状態は何か）の一つです。ずれ（0〜1 ns の平均距離の実測値から、静的な特徴だけの予測を引いたもの）が指導力の大半を担うことが K39・K42・K44 で分かっています。ここでは、初期構造における相互作用のエネルギーがずれと関係するかを測ります。候補の量は、ペアの 2 残基の間の非結合相互作用のエネルギーと、各残基と周り全体との相互作用のエネルギーで、どちらも静電とファンデルワールスに分けます。

読み方は実験前に固定しました（K3 系列共通）。ずれとの相関の絶対値が 0.3 以上なら「関係あり」の目安とし（K2-03 と同じ線）、静的な予測にその量を足したときにずれのばらつきが 0.30 Å 以下になれば「ずれの大部分を説明できた」とします（下限は資料D条件で K23 が測った複製間のばらつき 0.249 Å で、強い土台での測り直しは記録にありません。詳しくは下の「訂正」を参照）。相関が高いだけでは正体とは言いません。対照として、その量を別のペアのものと入れ替えた場合に効果が消えることも確かめます。

## データと条件

- 強い土台（K06(b)）の水素結合の形成の候補ペアです。較正用の 8 タンパク質（候補 13,808 件）で当てはめ、未見の 100 タンパク質×3 レプリカ（候補 163,074 件）で測ります。
- ずれは K39・K42 と同じ作り方です。実の平均は履歴 10 特徴の 1 列目（0〜1 ns の平均距離）で、静的な予測は静的 5 特徴（本体の予測確率、起点距離、基礎記述子 3 個）から平均を予測したものです。予測は HistGradientBoosting 回帰（反復 160 回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）と線形回帰の 2 通りで、どちらも較正用の候補だけで当てはめます。前提の確認として K39 の記録と比べ、当てはまりが完全に一致しました（GBM で R² 0.6352・ずれの標準偏差 0.6002 Å、線形で R² 0.6262・標準偏差 0.6076 Å。K39 の記録値と小数点以下まで同じ）。以下、ずれは GBM のものを主に使い、線形のものも併記します。
- エネルギーを計算する構造は初期構造（履歴のフレーム 0）です。座標は ATLAS の初期構造とレプリカごとの軌道ファイル（xtc）のフレーム 0 から取りました。前提の確認として、読み直した座標から計算したドナー・アクセプター間距離が、保存済みの履歴の最初の値と全候補で一致すること（324 組のタンパク質×レプリカすべてで、最大の差 1.8×10⁻⁶ Å）を確かめました。ドナー原子とアクセプター原子の対応は、変換済み軌道の原子の並び（重原子の通し番号）から初期構造の原子へ、元の PDB の原子番号でつないでいます。
- 力場は、土台のデータである ATLAS の実行そのものに使われた CHARMM36m です。電荷は各タンパク質の tpr ファイル（ATLAS の実行時のトポロジー）から原子ごとに取りました（tpr の原子と PDB の原子は、残基ごとに位置と元素で対応付けました。水素の名前の付け方が両者で違うためで、重原子の位置は両者で 10⁻⁵ Å の桁まで一致しています。タンパク質全体の電荷の合計は 108 タンパク質すべてで整数に一致しました）。ファンデルワールスの σ と ε は原子種ごとに OpenMM の charmm36.xml の LennardJonesForce の表から取りました（CHARMM36 と CHARMM36m で非結合のパラメータは共通で、36m の変更は背骨のねじれと CMAP の側です）。組み合わせ規則は σ の平均と ε の幾何平均（GROMACS の組み合わせ規則 2 と同じ）です。
- エネルギーの計算式は、静電が 1389.35456 × q_i q_j / r[Å]（kJ/mol）、ファンデルワールスが通常のレナード・ジョーンズ式です。周期境界の最小イメージで、フレーム 0 の箱を使い、打ち切りはしません。結合で 1 つと 2 つ離れた原子の組（1-2 と 1-3）は除き、3 つ離れた組（1-4）はそのまま入れます（CHARMM では 1-4 の縮小率は静電・ファンデルワールスとも 1.0 です）。原子の組ごとの特別な上書き（NBFIX）は入れていません。PME の逆格子側の分は原子の組に分けられないので含みません。「周り全体」はタンパク質の残りの原子すべてです（土台のデータには水やイオンが含まれないため、水とイオンは相手に入れていません）。
- 測った量は、候補ごとに次の 6 つが主です。(1) ペアの 2 残基の間の静電エネルギー、(2) 同じくファンデルワールス、(3) ドナー側の残基と残り全体との静電、(4) 同じくファンデルワールス、(5) アクセプター側の残基と残り全体との静電、(6) 同じくファンデルワールス。(3)〜(6) の「残り全体」には相手の残基も含みます。相手を除いた形と、合計の形（ペアの合計、残りの静電の合計など）も併せて記録しました。同じ残基の中のペアはテスト全体で 0 件でした。
- 入れ替え対照は、タンパク質×レプリカの中で量をシャッフルしました（seed 20261125）。相関の測り直しと、静的な予測に足す当てはめ（較正側は本物の量で当てはめ、テスト側だけ入れ替える）の両方で確かめます。

### 静的な予測に足したときのずれのばらつき

静的 5 特徴だけのときのずれの標準偏差は 0.6002 Å（GBM）です。量を足して較正側で当てはめ直すと、テストでの標準偏差は次のようになりました。

|---|---:|---:|
| ペアの間の静電だけ | 0.5859 | — |
| ペアの間のファンデルワールスだけ | 0.5619 | — |
| ドナー残基と残り全体の静電だけ | 0.6029 | — |
| ドナー残基と残り全体のファンデルワールスだけ | 0.5985 | — |
| アクセプター残基と残り全体の静電だけ | 0.5983 | — |
| アクセプター残基と残り全体のファンデルワールスだけ | 0.5992 | — |
| ペアの 2 つ | 0.5477 | 0.6061 |
| 残り全体の 4 つ | 0.5913 | 0.6066 |
| 主の 6 つ全部 | 0.5473 | 0.6059 |

全部足しても 0.547 Å までしか減らず、**0.30 Å の線には遠く届きません**。減りの中心はペアの 2 残基の間のエネルギーで、残り全体とのエネルギーはほとんど効きません。線形の当てはめでは、どの組み合わせでもほぼ減りませんでした（0.606〜0.607 Å、静的だけの線形 0.6076 Å とほぼ同じ）。GBM での減りは、直線的でない使い方をした分です。

### 入れ替え対照

量をタンパク質×レプリカの中で入れ替えると、相関は −0.004〜+0.013 とほぼ 0 になり、足したときの標準偏差はペアの 2 つで 0.6473 Å、残り全体の 4 つで 0.6246 Å、主の 6 つで 0.6536 Å と、**静的だけの 0.6002 Å よりむしろ悪くなりました**。GBM で見えた小さな減りは、量とペアの正しい対応に依存するもので、量を足すこと自体で生じる見かけの減りではありません。ただし、その効果の大きさ自体が小さいことは変わりません。

## 判断

先に固定した読み方に沿うと、答えは次のとおりです。

- 初期構造の相互作用のエネルギーは、どの量も相関の絶対値が 0.3 に届かず、「関係あり」とは言えません。
- 静的な予測に全部足しても、ずれのばらつきは 0.600 Å から 0.547 Å までしか減らず、「ずれの大部分を説明できた」とは言えません（分散で見ても減りは 2 割弱です）。
- つまり、**ペアの 2 残基の間のエネルギーでも、各残基と周り全体とのエネルギーでも、ずれの正体ではありません**。ペアの間のエネルギーには、入れ替えで消える弱い信号が含まれていますが（GBM で標準偏差が約 0.05 Å 減る分）、ずれの大部分はここにはありません。

K2-03 で候補から外れた量（周りの詰まり具合、その散らばり、Cα のゆらぎ、接触する残基の数）と合わせると、初期構造から静的に計算できる量では、ずれはこれまでのところ説明できていません。ずれは履歴の前半と後半で続くペアごとの性質ですが（K2）、その中身は初期構造のエネルギーの状態ではない、という形が強まりました。

## 読みの注意点

- 「周り全体」はタンパク質の残りの原子だけです。水やイオンを含めた環境とのエネルギーは測っていません。残り全体との静電は水の遮蔽を受けない直接の和なので、水を含めれば値も相関も変わり得ます。ペアの間にある水そのものは K3-05 が別に測っています。
- エネルギーはフレーム 0 の一瞬の値です。ずれは 0〜1 ns の平均の性質なので、時間平均したエネルギーでは形が変わる可能性は残ります。ただし K2-02 で距離そのものは 100 ps 以内に忘れられることが分かっており、フレーム 0 のエネルギーが平均のずれを決めるという読みは、今回の結果では支えられませんでした。
- PME の逆格子側の分と NBFIX の上書きは含んでいません。どちらも組ごとのエネルギーの内訳を大きく変えるものではありませんが、厳密な力場のエネルギー分解そのものではありません。
- 相関と当てはめの減りは「一緒に動くか」と「予測に使えるか」を見たもので、因果の確認はしていません（K3 系列の進め方どおり、原因の確認は後の手順で行います）。

## 訂正（2026-11-25）

割り当て文にあった「ずれのばらつきは約 0.49 Å」は、資料D条件の値でした（K23 の、静的 7 特徴から実の平均を予測したときの残差 0.492 Å）。K3 が使う強い土台では、ずれのばらつきは 0.6002 Å です（K39・K42 の形で作った GBM のずれの、テスト側の標準偏差。K44 の記録も 0.60 Å としています。この実験でも前提の確認として同じ値を再現しました）。この実験の測り方は強い土台のずれを使っているので、この訂正で結論は変わりません。

同じく、下限 0.249 Å も資料D条件で K23 が測った複製間のばらつきで、強い土台での測り直しは記録にありません。判定の線（0.30 Å 以下）は先に固定した判断のまま変わりませんが、強い土台で 0.30 Å が届きうる線なのかどうかは、下限を測り直さないと分からない点に注意が必要です。
