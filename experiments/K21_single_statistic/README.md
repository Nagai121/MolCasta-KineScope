# K21 担い手は1つの量か（強い土台、水素結合）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H6（運動の生成そのものの問題）に関わる担い手の特定
- 状態: 完了。平均だけを入れると利得の 0.87〜1.08 が戻り、先に固定した目安（8割）を超えました。一方で、形の統計量だけでも利得の 0.39〜0.55 が戻ります。

## 1. 何を確かめる実験か

K18 では、実履歴の統計量を1つずつ落としても利得はほとんど減りませんでした（統計量どうしで代わりが利く）。本実験は逆向きで、実履歴から1つの量だけを入れたら利得のどれだけが戻るかを測ります。

読み方は先に固定しました。(a) 平均だけで (e) 全部入りの利得の8割以上が戻れば、担い手はペアの平均距離という1つの量だと言えます。(a) が部分的で (d) 形の統計量も意味のある利得を持つなら、担い手は位置と形の両方ということになります。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質で学習し、未見100タンパク質×3複製（163,074件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`）をそのまま使いました。
- 補正モデルの特徴は、静的5特徴に次の履歴の量を足したものです。実履歴10特徴は、実軌道の11フレーム（0〜1 ns）の系列から作った「最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å 以下割合、4.5 Å 以下割合、増えたステップの割合」です。
  - (a) 平均だけ: 平均の列だけ
  - (b) 最小値だけ: 最小値の列だけ
  - (c) 3.5 Å 以下割合だけ: その列だけ
  - (d) 形の統計量だけ: 標準偏差と最後−最初の2列（位置を表す統計量は入れない）
  - (e) 全部入り: 静的＋実履歴10特徴で、K06(b) の実履歴条件そのものです。K09/K12 でいう6統計量は、この10特徴のうちの6つです。
  - 参考条件として、6統計量だけ（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合）も測りました。(e) との差を見るためです。
- 利得は静的補正に対する AUPRC の改善で、タンパク質ごとの平均（マクロ）を主、全体をまとめた値（ミクロ）を従としました。表の値は「その条件の利得÷(e) の利得」です。
- 対照の確認: 静的補正と (e) は、全予測幅で K06(b) の記録と小数第4位まで一致しました（1 ns先で静的 0.4539、(e) 0.5251、利得 +0.0712）。

## 4. 読み取り

- **(a) 平均だけで、全予測幅で (e) の利得の 0.87〜1.08 が戻りました。** 先に固定した目安の8割を全予測幅で超えているので、読み方の1つ目の枝に当たります。担い手は、ペアの平均距離という1つの量だと言えます。
- ただし (d) 形の統計量だけ（標準偏差と最後−最初、位置の情報なし）でも、利得の 0.39〜0.55 が戻ります。形の側にも独立した情報があります。平均と形は重なり合っていて、どちらか一方だけが情報を持っているわけではありません。(c) 割合だけでも 0.85〜1.03 と高く、平均と割合はほぼ同じ情報の別の表れ方です。(b) 最小値だけは 0.49〜0.63 で、単独では半分ほどです。
- 参考条件の6統計量だけは 0.97〜1.17 で、(e) の10特徴と実質同じでした。K06(b) の実履歴条件の利得は、6統計量でほぼ尽きています。
- K18 と合わせた絵はこうなります。平均を落としても利得は減らない（他の統計量から平均に近い情報が作れる）一方で、平均だけを入れると利得の大半が戻る（平均は履歴の状態をよく要約している）。つまり担い手は「ペア自身の履歴の平均距離」という1つの量に名前を付けられますが、その量の情報は履歴の他の統計量とも広く重なっています。生成側で失われているのは、このペアごとの平均距離の値そのものです（K11b で、生成系列の平均の誤差はペアごとのばらつきが主でした）。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、実履歴の利得はペアの平均距離という1つの量でほぼ担えます（全予測幅で8割以上）。形の統計量にも独立した情報があり（約4〜5割）、統計量どうしの重なりは大きいです。
- まだ分からないこと: 平均と形の情報の重なりの内訳（形の利得のうち、平均と相関する分がどれだけか）。また、生成器がペアごとの平均距離をなぜ再現できないかは、生成の側の問いとして残ります。
