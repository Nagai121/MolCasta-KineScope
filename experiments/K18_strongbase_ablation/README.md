# K18 実履歴の統計量を1つずつ落とす（強い土台、水素結合）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H6（運動の生成そのものの問題）に関わる担い手の特定
- 状態: 完了。どの統計量を1つ落としても利得はほとんど減らず、平均は必要ではない（他の統計量で代わりが利く）という結果でした。

## 1. 何を確かめる実験か

K09 と K12 では、生成側の統計量を実の値に差し替えると平均だけで利得の大半が戻ること（十分さの側）を見ました。本実験は逆向きで、実履歴の統計量を1つずつ落とすと利得がどれだけ減るか（必要さの側）を測ります。

読み方は先に固定しました。平均を落としただけで利得の大半が消えれば、平均は必要でもあることになり、K09/K12 の十分さと合わせて担い手が確定します。平均を落としても利得があまり減らなければ、平均は他の統計量で代わりが利くことになり、担い手は1つの統計量ではなく組み合わせの側ということになります。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質で学習し、未見100タンパク質×3複製（163,074件）で評価しました。学習器と指標の計算は K06(b) の eval_b.py からそのまま使っています。
- 特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`、108タンパク質分）をそのまま使いました。軌道の取り直しも本体の読み込みもしていません。
- 全部入りの条件は K06(b) の実履歴条件そのもの（静的5特徴＋実履歴10特徴）です。実履歴10特徴は、実軌道の11フレーム（0〜1 ns）の系列から作った「最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å 以下割合、4.5 Å 以下割合、増えたステップの割合」です。
- 落とす対象の6統計量は、実履歴10特徴の中の列として落としました（平均=列1、3.5 Å 以下割合=列7、最小値=列3、標準偏差=列2、最後−最初=列5、最初の値=列0）。残りの履歴特徴（最大値、最後−1つ前、4.5 Å 以下割合、増えたステップの割合）は全条件に残ります。つまり必要さは、実履歴の特徴量全体の中で、その統計量の列が要るかどうかとして測っています。代わりの利き方には、この残った特徴が効く余地も含みます。
- 利得は、静的補正に対する AUPRC の改善です。タンパク質ごとの平均（マクロ）を主、全体をまとめた値（ミクロ）を従としました。減り方は「全部入りとの差÷全部入りの利得」で出しました。
- 対照の確認: 静的補正と全部入りの AUPRC（マクロ・ミクロとも）は、全予測幅で K06(b) の記録と小数第4位まで一致しました（1 ns先で静的 0.4539、全部入り 0.5251、利得 +0.0712。90 ns先で利得 +0.0273）。

## 4. 読み取り

- **どの統計量を1つ落としても、利得はほとんど減りませんでした。** 全予測幅・全統計量を通じて、失われる利得は最大で約12%（50 ns先の割合、ミクロ）で、1 ns先では平均が最大の 7.0% 、他は 4.8% 以下です。負の値も多く、落としたほうがわずかに良くなる条件もあります。
- 先に固定した読み方では、**平均は必要ではありません**。平均を落としても他の統計量で代わりが利きます。1 ns先で個別の減り方を全部足しても約17%で、利得の大半は「どれか1つを落としても残る」形で、統計量どうしの重なりに担われています。
- K09/K12 の十分さと合わせると、非対称な絵になります。生成側に実の平均を入れると利得の大半が戻る（平均は通り道として十分）一方で、実履歴の中では平均がなくても困りません。平均は履歴の状態と強く結びついた量なので、差し替えでは「平均の値そのもの」ではなく履歴全体の状態が運ばれている、という読みが合います。担い手は1つの統計量ではなく、実履歴の統計量の組み合わせ（言い換えると、ペアごとの履歴の状態そのもの）ということになります。
- 注意点として、必要さの判定は実履歴10特徴の中での話です。残った特徴（最小値・最大値・割合など）は平均と強く結びついているため、平均の情報は形を変えて残ります。「平均という量そのものが予測に要らない」という意味ではありません。また、2つ以上の統計量を同時に落とした場合の減り方は測っていません。同時に落とすと大きく減る組み合わせがある可能性は残ります。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台の実履歴条件では、6統計量のどれも単独では必要ではありません。平均についても、K09/K12 の十分さに対して必要さは成り立ちませんでした。喪失の担い手は単一の統計量ではなく、実履歴の統計量が重なって持つペアごとの情報です。
- まだ分からないこと: 複数の統計量を同時に落とした場合に利得がどう減るか（組み合わせのうちのどこまでが要るか）。また、生成側で不足しているのが、この重なりのどの部分に対応するかは、K11b の分解（平均と割合の誤差はペアごとのばらつきが主）と合わせて読む必要があります。
