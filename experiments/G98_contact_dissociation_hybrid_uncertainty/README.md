# G98: 接触の解離の混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G79・G85・G89 では、接触の解離の混合の差が +0.05 を超えたのは 90 ns先の +0.054 だけで、1 ns先 −0.040、5 ns先 +0.033、10 ns先 +0.035、30 ns先 +0.025、50 ns先 −0.010 でした。全予測幅（1・5・10・30・50・90 ns先）について、混合と切り取り平均だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G59・G62・G67 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（90 ns先だけ）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの接触の解離です。G79・G85・G89 と同じ段取りで、実側は K50 キャッシュ（`~/workspace/kinescope/work/k50_cache/`、候補は最小距離が 4.5 Å 以下の残基ペア、ラベルは予測幅で 4.5 Å より大きい）と、生成平均は G18 の第22案の生成系列（ドナー・アクセプター原子ペアごとの 4点系列）から、接触の候補（残基ペア）に重なるものだけを取り、残基ペアごとに生成ペアの 4点系列の点ごとの最小値を取って 4点で平均したものを使いました。生成器のチェックポイントは読み込んでいません。
- 測るのは、G18 の生成系列と重なる候補だけです（学習 4,489件、テスト 2,226件、テストの 76%）。重ならない候補は測れません。テストの陽性のうち重なるのは、1 ns先で 105件（全 207件のうち）、5 ns先で 110件（211件）、10 ns先で 122件、30 ns先で 124件（246件）、50 ns先で 149件、90 ns先で 160件です。土台（静的のみ・全部入り・切り取り平均だけ）も、重なる候補だけの集合で測り直しています。そのため回復率の分母は、重なる候補だけの集合での実履歴の利得です。全集合での土台は別に確かめました（下の「全集合での土台の確認」）。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）の平均です（G79・G85・G89 と同じ）。6統計量ではなく平均だけです。生成平均は、生成系列の平均です。対応付けは、G18 の生成系列のドナー・アクセプター原子ペアを残基ペアに直し、接触の候補の残基ペアと合わせるものです。重なる残基ペアのうち、生成ペアが1つだけのものが中央値で、最大で10個の生成ペアが重なるものもあります（G79 の overlap.json）。生成ペアが複数ある残基ペアでは、生成系列は点ごとの最小値です（候補の距離が重原子ペア間の最小値であるのと同じ考え方）。留保として、生成系列はドナー・アクセプターのペアしか覆わないため、生成の最小値は実の最小値を決める原子ペアの一部分だけにわたるものです（G79 と同じ留保）。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、境界 4.5 Å、参照）、切り取り平均 0.1 ns だけ、生成平均だけ、混合（切り取り平均＋生成平均、別々の特徴量として 2列）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G79・G85・G89 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（重なる候補 1,494件）と 2qt4_A（重なる候補 732件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G79・G85・G89 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。重なる候補のマスクと生成平均は、G79・G85・G89 の3つの `matched_gen_mean.npz` が配列単位で一致することを確かめた上で、G79 のファイルから読みました。学習し直した予測確率は、ブートストラップの前に `test_predictions.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

### 土台の再現

6つの予測幅すべてで、重なる候補だけの集合での静的のみ・全部入り・切り取り平均だけ・生成平均だけ・混合の合算 AUPRC が G79・G85・G89 の記録と小数第4位まで一致しました。実履歴の利得は、1 ns先 +0.1688、5 ns先 +0.3213、10 ns先 +0.2030、30 ns先 +0.1907、50 ns先 +0.1837、90 ns先 +0.1524 です。

### 全集合での土台の確認

重なる候補だけの集合とは別に、全集合（学習 6,383件、テスト 2,915件）での静的のみ・全部入り・切り取り平均だけも学習し直し、K50 の記録値と G06 の切り取り平均の回復率と照合しました。6つの予測幅すべてで一致しました。静的のみは 1・5・10・30・50・90 ns先で 0.3105・0.3022・0.2772・0.2756・0.2927・0.2886、全部入りは 0.5246・0.5528・0.4794・0.5124・0.4533・0.4750、切り取り平均の回復率は 0.919・0.802・0.578・0.796・0.612・0.935 です。

### 6つの予測幅の差とブートストラップ 95% 区間

太字は +0.05 を超えたセル（先に固定した読みの対象）です。

| 予測幅 | 差 | 95% 区間 |
|---|---:|---|
| 1 ns | −0.040 | **[−0.058, −0.040]** |
| 5 ns | +0.033 | **[+0.033, +0.070]** |
| 10 ns | +0.035 | **[+0.028, +0.053]** |
| 30 ns | +0.025 | [−0.077, +0.466] |
| 50 ns | −0.010 | [−0.014, +0.104] |
| 90 ns | **+0.054** | **[+0.032, +0.119]** |

重なる候補だけの集合でのテスト陽性は、1 ns先 105件、5 ns先 110件、10 ns先 122件、30 ns先 124件、50 ns先 149件、90 ns先 160件です。

### タンパク質ごとの差（回復率の差）

| 予測幅 | 1mix_A | 2qt4_A |
|---|---:|---:|
| 1 ns | −0.040 | −0.058 |
| 5 ns | +0.067 | +0.070 |
| 10 ns | +0.053 | +0.028 |
| 30 ns | −0.077 | +0.466 |
| 50 ns | −0.014 | +0.104 |
| 90 ns | +0.032 | +0.119 |

30 ns先と 50 ns先では、2タンパク質で差の向きが食い違います（30 ns先は 1mix_A で −0.077、2qt4_A で +0.466。50 ns先は 1mix_A で −0.014、2qt4_A で +0.104）。それ以外の予測幅では、2タンパク質とも差の向きが同じです。30 ns先の 2qt4_A だけの差 +0.466 は、2qt4_A だけの実履歴の利得が小さいために大きく出ています。

## 判断

先に固定した読み方に沿うと、+0.05 を超えたセルは 90 ns先だけで、その区間 **[+0.032, +0.119] は 0 を含みません**。2タンパク質とも差が正です（1mix_A で +0.032、2qt4_A で +0.119）。

+0.05 を超えなかったセルでは、1 ns先の区間 [−0.058, −0.040] は 0 を含まず負で、2タンパク質とも差が負です。5 ns先の区間 [+0.033, +0.070] と 10 ns先の区間 [+0.028, +0.053] は 0 を含まず正ですが、点推定が +0.033・+0.035 と +0.05 の線には届きません。30 ns先の区間 [−0.077, +0.466] と 50 ns先の区間 [−0.014, +0.104] は 0 を含みます。

なお、5 ns先の区間 [+0.033, +0.070] は、下限が点推定とほぼ同じ値です。2タンパク質のうち小さい方の差が点推定とほぼ同じ値で、もう一方の差だけが大きいためではなく、合算の差（+0.033）が 1mix_A だけの差（+0.067）と 2qt4_A だけの差（+0.070）より小さいためです。合算の差は、2タンパク質の差を利得で重み付けした平均ではなく、合算の AUPRC から計算し直した値なので、タンパク質ごとの差の外側に出ることがあります。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- **測ったのは、G18 の生成系列と重なる候補だけ（テストの 76%）です。** 重ならない候補（テストの 24%）については、この実験では何も言えません。重なる候補だけの集合でのテスト陽性は、全集合の陽性のおよそ半分です（1 ns先で 105件／207件、30 ns先で 124件／246件）。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約2分でした。
