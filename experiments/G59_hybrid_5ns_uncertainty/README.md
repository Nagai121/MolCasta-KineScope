# G59: 5 ns先での混合の差について、0.25 nsの切り取りだけが上がるのは本物か

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G26 では 0.1 ns の切り取りで 5 ns先の混合の差が −0.169、G56 では 0.25 ns の切り取りで +0.082、G35 では 0.5 ns の切り取りで −0.143 でした。真ん中の切り取りだけが上がるのが切り取りの長さによる本物の形か、タンパク質単位の再標本化によるブートストラップ 95% 区間（G49 と同じやり方）で確かめます。

読み方は実験前に固定しました。0.25 ns の切り取りの差の区間が、0.1 ns と 0.5 ns の切り取りの差の区間と重ならなければ、真ん中だけ上がるのは切り取りの長さによる本物の形だということになります。区間が重なれば、真ん中の上がりは揺れの範囲だということになります。「重なる」は 0.25 ns の区間と 0.1 ns の区間の重なり、0.25 ns の区間と 0.5 ns の区間の重なりの両方で読みます。片方だけ重なる場合も、そのまま記録します。

## データと条件

- 条件は資料Dの水素結合の形成、5 ns先です。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件）。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（キャッシュの取り出し時に適用済み）。
- 切り取りの定義は G02 と同じです。0.1 ns はフレーム [0,1]（2フレーム）、0.25 ns はフレーム [0,1,2]（3フレーム、実際に覆う長さは 0.2 ns）、0.5 ns はフレーム [0,1,2,3,4,5]（6フレーム）です。生成平均は K05 の生成系列（第22案の5点系列 [起点距離 d0（フレーム10）, +0.1, +0.3, +0.5, +1.0 ns]）の平均です。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、土台候補 14,582件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å でした（G11・G17・G49 と同じ値）。
- 生成器のチェックポイント .pt ファイルは読み込んでいません（保存済みの生成系列を使いました）。
- 条件は切り取りの長さごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、混合（切り取り平均＋生成平均の2列）。回復率は、5 ns先での実履歴の利得（+0.1155）で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G49・G23 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（3,101件）と 2qt4_A（1,871件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G26・G56・G35 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

### 土台の再現

3つの切り取りの長さすべてで、静的のみ・全部入り・切り取り平均だけ・混合の合算 AUPRC が G26・G56・G35 の記録と小数第4位まで一致しました。実履歴の利得は 3つの切り取りで同じ +0.1155 です（G26・G56・G35 の記録と同じ）。

### 3つの切り取りの長さの差とブートストラップ 95% 区間

| 切り取り | 切り取り平均だけ | 混合 | 差（点推定） | 95% 区間 | 0 を含むか |
|---|---:|---:|---:|---|---|
| 0.1 ns | 0.846 | 0.677 | −0.169 | [−0.254, −0.068] | 含まない |
| 0.25 ns | 1.029 | 1.111 | +0.082 | [−0.032, +0.252] | 含む |
| 0.5 ns | 1.037 | 0.894 | −0.143 | [−0.220, −0.086] | 含まない |

実履歴の利得（回復率の分母）は 5 ns先で +0.1155 です。テスト陽性は 312件です。

### タンパク質ごとの差（回復率の差）

| 切り取り | 1mix_A だけ | 2qt4_A だけ | 合算 |
|---|---:|---:|---:|
| 0.1 ns | −0.254 | −0.068 | −0.169 |
| 0.25 ns | −0.032 | +0.252 | +0.082 |
| 0.5 ns | −0.220 | −0.086 | −0.143 |

0.25 ns だけ、2タンパク質で差の向きが食い違います（1mix_A で −0.032、2qt4_A で +0.252）。0.1 ns と 0.5 ns では、2タンパク質とも差が負です。

### 区間の重なり

- 0.25 ns の区間 [−0.032, +0.252] と 0.1 ns の区間 [−0.254, −0.068] は**重なりません**（0.25 ns の下限 −0.032 が、0.1 ns の上限 −0.068 より大きい）。
- 0.25 ns の区間 [−0.032, +0.252] と 0.5 ns の区間 [−0.220, −0.086] は**重なりません**（0.25 ns の下限 −0.032 が、0.5 ns の上限 −0.086 より大きい）。

## 判断

先に固定した読み方に沿うと、**真ん中だけ上がるのは切り取りの長さによる本物の形です。** 0.25 ns の切り取りの差の区間は、0.1 ns と 0.5 ns の切り取りの差の区間のどちらとも重なりませんでした。5 ns先での混合の差は、切り取りの長さに対して単調ではなく、0.1 ns で −0.169、0.25 ns で +0.082、0.5 ns で −0.143 と、真ん中だけが上がる形です。

ただし、0.25 ns の区間は 0 を含んでいます。真ん中の切り取りの差が他の2つの切り取りの差より高いことは確かですが、差そのものが 0 より大きいとまでは言えません。0.25 ns の「上がり」は、2qt4_A で差が正（+0.252）になったことが大きく、1mix_A だけでは −0.032 とわずかに負です。3つめのタンパク質でも同じ形になるとまでは言えません。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「重なる／重ならない」は、実質的には「2タンパク質の差の向きと大きさが、切り取りの長さごとにどう違うか」と同じ読みです。
- 5 ns先の回復率 1.029（0.25 ns の切り取り平均だけ）や 1.111（0.25 ns の混合）は、実履歴の利得の分母が小さい（+0.1155）ため膨らんだ面があります。AUPRC の絶対値で見ると、0.25 ns の混合が切り取り平均だけを上回る幅は +0.0094 です。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的で、G17 の確認では種 1 と 7 でも同じ AUPRC になりました。

## ファイル

- `run_g59.py`: G26・G56・G35 と同じ段取りでの学習・評価（候補ごとの予測確率を保存）、タンパク質単位のブートストラップ（10,000回、seed 42、パーセンタイル法）。3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行う（G23 のやり方と数学的に同じ結果になる）。
