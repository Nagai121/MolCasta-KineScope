# G126: 接触の解離の混合で、切り取り 0.5 ns の 6 個の統計量にした場合の差に、区間を付ける（G99・G121・G89 で +0.05 を超えたセル）

- 確かめること: G99 の 1 ns先（+0.237）、G121 の 10 ns先（+0.055）、G89 の 90 ns先（+0.054）の 3 セルについて、タンパク質単位の再標本化によるブートストラップ 95% 区間を出す。区間が 0 を含むかどうかを見る。
- 状態: 完了。3 セルのうち、区間が 0 を含まないのは G99 の 1 ns先と G89 の 90 ns先。G121 の 10 ns先の区間は 0 を含む。

## 1. 何を確かめる実験か

G99・G121・G89 で +0.05 を超えた 3 セルについて、タンパク質単位の再標本化によるブートストラップ 95% 区間を出す。G59・G62・G67 と同じやり方（10,000回、seed 42、パーセンタイル法）。モデルを学習し直してよいが、出し直した AUPRC が G99・G121・G89 の記録と小数第4位まで一致することを確かめる。テストは 2 タンパク質だけなので区間は粗い、という留保も記録する。

3 セルは切り取りの条件がそれぞれ違う。G99 の 1 ns先は切り取り 0.1 ns の 6統計量、G121 の 10 ns先は切り取り 0.5 ns の 6統計量、G89 の 90 ns先は切り取り 0.1 ns の平均だけ。区間はそれぞれの元の測り方のまま出す。G99・G121・G89 はいずれも G18 の生成系列と重なる候補だけ（テストの 76%）で測っている。

読み方は先に固定した。これらのセルの区間が 0 を含むかどうかを見る。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は K50 のキャッシュの X（5列）。キャッシュは `~/workspace/kinescope/work/k50_cache/`（`{protein}_R{rep}_contact_diss.npz`、hist は (N, 11) で保存されているため直しはしない）。
- 測る候補は G18 の生成系列と重なる候補だけ。重なる候補の作り方は G79・G99 と同じ。1つの残基ペアに生成ペアが複数ある場合は、生成ペアの 4点系列の点ごとの最小値をその残基ペアの生成系列とし、4点で平均する。対応付けは残基の添え字の組（小さい方・大きい方）で行う。学習は 6,383件中 4,489件（70%）、テストは 2,915件中 2,226件（76%）が重なる。残基の添え字は `/tmp/g79_atoms/trajectories` が消えたため、元の置き場 `~/workspace/gpt-model-check/data/trajectories/` の atoms.parquet を使った（G121 と同じ。重なる候補の数は G99・G115 と同じ）。
- 3 セルの切り取りの条件: G99 の 1 ns先は切り取り 0.1 ns = フレーム [0,1] の 6 統計量（境界は接触の 4.5 Å）。G121 の 10 ns先は切り取り 0.5 ns = フレーム [0,1,2,3,4,5]（0〜0.5 ns を覆います）の 6 統計量。G89 の 90 ns先は切り取り 0.1 ns = フレーム [0,1] の平均だけ。
- 生成平均は G18 で作り直した方法22の系列 `~/workspace/kinescope/work/g18_gen22/`。方法22は生成器が学習した範囲（形成の候補だけ）の外への当てはめである点に留保がつく（G18 の README 第7節）。
- 条件（各セル、すべて条件ごとに学習し直す）: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取りだけ／生成平均だけ／混合（切り取り＋生成平均を別々の特徴量として足す）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。出し直した AUPRC は、3 セルとも G99・G121・G89 の記録と小数第4位まで一致することを確かめた（スクリプトの中の照合で確かめている）。
- ブートストラップ: 再標本化の単位はタンパク質。テストのタンパク質は 1mix_A と 2qt4_A の 2つだけなので、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかない。10,000回、seed 42、パーセンタイル法（2.5%点と 97.5%点）。各組み合わせの中でも、静的のみ・全部入り・切り取りだけ・混合の AUPRC を測り直し、利得と回復率をその組み合わせの中で計算し直す。AUPRC の差の絶対値の区間も同じやり方で出す。

## 4. 読み取り

先に固定した読み方に照らすと、3 セルのうち区間が 0 を含まないのは G99 の 1 ns先と G89 の 90 ns先で、G121 の 10 ns先の区間は 0 を含む。

G121 の 10 ns先は、点推定では +0.055 と線を超えたが、タンパク質ごとに分けると 1mix_A では +0.100、2qt4_A では −0.076 と符号が分かれる。タンパク質の水準では足しがあるとは言えない。

G99 の 1 ns先は、タンパク質ごとに分けても 1mix_A +0.139、2qt4_A +0.551 と両方とも正で、区間も 0 を含まない。ただし G99 の読みにも書かれているとおり、混合の回復率（1.049）は平均だけの切り取り（1.072）を上回っておらず、6 個の統計量の切り取りの弱さを平均だけの水準まで戻した形だった点には留保がつく。

G89 の 90 ns先は、タンパク質ごとに分けても 1mix_A +0.032、2qt4_A +0.119 と両方とも正で、区間も 0 を含まない。AUPRC の差は +0.0082 と小さい。

## 5. 判断できること・まだ分からないこと

- 判断できること: +0.05 を超えた 3 セルのうち、タンパク質の水準で区間が 0 を含まないのは G99 の 1 ns先と G89 の 90 ns先で、G121 の 10 ns先は区間が 0 を含む。テストは 2 タンパク質だけなので区間は粗く、取りうる組み合わせは 3通りしかない。測った候補は全体の 76% だけ（テスト 2,915件中 2,226件）という留保がつく。
- まだ分からないこと: G121 の 10 ns先でタンパク質ごとに符号が分かれる理由。G126 のセルのタンパク質単位の区間は、テストが 2 タンパク質だけなのでこれ以上は細かくできない。
