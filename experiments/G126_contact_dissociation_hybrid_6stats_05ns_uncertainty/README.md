# G126: 接触の解離の混合で、切り取り 0.5 ns の 6 個の統計量にした場合の差に、区間を付ける（G99・G121・G89 で +0.05 を超えたセル）

- 確かめること: G99 の 1 ns先（+0.237）、G121 の 10 ns先（+0.055）、G89 の 90 ns先（+0.054）の 3 セルについて、タンパク質単位の再標本化によるブートストラップ 95% 区間を出す。区間が 0 を含むかどうかを見る。
- 状態: 進行中。

## 1. 何を確かめる実験か

G99・G121・G89 で +0.05 を超えた 3 セルについて、タンパク質単位の再標本化によるブートストラップ 95% 区間を出す。G59・G62・G67 と同じやり方（10,000回、seed 42、パーセンタイル法）。モデルを学習し直してよいが、出し直した AUPRC が G99・G121・G89 の記録と小数第4位まで一致することを確かめる。テストは 2 タンパク質だけなので区間は粗い、という留保も記録する。

3 セルは切り取りの条件がそれぞれ違う。G99 の 1 ns先は切り取り 0.1 ns の 6統計量、G121 の 10 ns先は切り取り 0.5 ns の 6統計量、G89 の 90 ns先は切り取り 0.1 ns の平均だけ。区間はそれぞれの元の測り方のまま出す。G99・G121・G89 はいずれも G18 の生成系列と重なる候補だけ（テストの 76%）で測っている。

読み方は先に固定した。これらのセルの区間が 0 を含むかどうかを見る。
