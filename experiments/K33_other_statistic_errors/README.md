# K33: 平均以外の統計量の誤差は、どれだけ利得を落とすか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証です。K22・K24・K28 は平均だけを劣化させ、K12 では平均だけを実の値に戻すと利得の 0.93 が戻るのに、生成の特徴量をそのまま入れると静的補正を下回ります（K12b）。残りのダメージが平均以外の統計量の誤差にあるか、確かめます。

読み方は実験前に固定しました。どれか1つの置き換えで利得が生成条件の水準まで落ちれば、その統計量の誤差が残りのダメージの担い手です。3つまとめても落ちなければ、平均以外の統計量の誤差では説明できません。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的補正との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。
- 補正モデルは実の履歴（静的＋実履歴10特徴）で学習したものを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・閾値以下の割合を1つずつ、また3つまとめて、生成の値に置き換えます。
- 列の対応は K12 と同じです。生成6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合]、実履歴10特徴は [最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å 以下割合、4.5 Å 以下割合、距離が増えたステップの割合] です。置き換えは、標準偏差は実履歴[2]←生成6[2]、最小値は実履歴[3]←生成6[3]、3.5 Å 以下割合は実履歴[7]←生成6[5] です。
- 参考条件として、4.5 Å 以下割合（実履歴[8]）を生成8特徴の 4.0 Å 以下割合（生成8[5]）で置き換えたものと、3つにそれを加えた4つまとめも測りました。生成側に 4.5 Å 以下割合そのものは無いので、閾値が違う点に注意してください。
- 対照の確認: 実の履歴で学習したモデルをそのまま評価した値は、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。

## 判断

先に固定した読み方に照らすと、答えは予測幅によって違います。1つの結論にはなりません。

- 1 ns先（実履歴の利得が最も大きい予測幅）では、平均以外の統計量の誤差では説明できません。1つずつの置き換えでは利得の 0.89〜0.94 が残り、3つまとめても 0.65 が残ります。生成条件の水準（−0.006）には届きません。
- 5 ns先と 30 ns先では、3つまとめると利得が生成条件の水準まで落ちます（5 ns先で −0.003、30 ns先で +0.005）。この2つの予測幅では、平均以外の3つの統計量の誤差を合わせると説明がつきます。
- 90 ns先では、標準偏差だけの置き換えで利得が静的補正を下回ります（−0.009、残存率 −0.35）。生成系列の変動が実系列よりずっと小さいこと（K05 で、候補ごとの変動の大きさは生成 0.060 Å に対して実 0.332 Å）と整合し、長い予測幅では標準偏差の誤差だけで利得が消えます。
- 10 ns先と 50 ns先では、3つまとめでも利得の 0.52〜0.72 が残り、説明は部分的です。

また、3つの誤差の効き方は足し算ではありません。5 ns先では1つずつの残存率は 0.49〜0.84 ですが、3つまとめると −0.06 まで落ちます。実の履歴で学習したモデルは、標準偏差・最小値・割合の組み合わせのパターンに頼っており、3つ同時に壊れると利得が崩れます。4.5 Å 以下割合だけの置き換えはほとんど効かず（残存率 0.93〜1.02）、4つまとめも3つまとめとほぼ同じです。この統計量は担い手ではありません。

留保として、本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているか（学習し直した場合）は、K10 の (c) や K12 の設計で測る別の問いです。K12 で平均だけを戻すと 0.93 が戻ったことと合わせると、平均以外の統計量は 1 ns先では残りの 0.07 のうちの一部にしかならず、5・30・90 ns先では担い手になる、というのが現時点での整理です。
