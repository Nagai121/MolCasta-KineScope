# K2-03: 残りの平均と一緒に動く量は、ほかに何かあるか

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。K39・K42 で、ペアの平均距離のうち静的な特徴量で予測できない部分（以下「残りの平均」）が指導力を担うことが分かりました。ここでは資料Dの条件で残りの平均を作り直し、残りの平均と一緒に動く量がほかにあるかを探します。候補は、周りの詰まり具合と数とゆらぎの量に限ります。

候補の量（履歴の 11 フレーム、フレーム 0〜10 で測る）:

- (a) ペアの中点から 8 Å 以内にある重原子の数の平均（周りの詰まり具合）
- (b) その数のばらつき（11 フレームでの標準偏差）
- (c) ペアの 2 残基の Cα の履歴内でのゆらぎの大きさ（各残基の Cα の 11 フレームでの RMSF の、2 残基での平均）
- (d) ペアのどちらかの残基と接触する残基の数の平均（接触 = 重原子同士の最小距離が 4.5 Å 以下。ペアの 2 残基自身は数に入れない）

水の出入り（K36・K49 で閉じた）と残基の環境そのもの（K25 で閉じた）は候補に入れていません。今回は数とゆらぎの量です。

読み方は実験前に固定しました。残りの平均との相関（ピアソンとスピアマン、合算とテスト 2 タンパク質ごと）で、絶対値 0.3 以上なら「候補として残す」、未満なら「この量ではない」と記録します。

## データと条件

- 資料Dの条件です。水素結合の形成の候補ペアで、学習は 4 タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A、9,610件）、テストは 1mix_A と 2qt4_A（4,972件、うち 1mix_A が 3,101件、2qt4_A が 1,871件）です。
- 残りの平均は K39・K42 の形で作ります。実の平均は履歴 11 フレームのドナー・アクセプター間距離の平均です。静的な予測は、資料Dの静的な特徴量（X の 7 列）から実の平均を予測したもので、線形回帰と HistGradientBoosting 回帰（K39 と同じ設定: 160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）の 2 通りです。どちらも学習側の候補だけで当てはめ、テスト側の統計は使いません。残りの平均 = 実の平均 − 静的な予測です。当てはまりは、線形回帰で R² が学習 0.688・テスト 0.695、GBM 回帰で学習 0.744・テスト 0.693 でした。テストでの残りの平均の標準偏差は、線形 0.487 Å、GBM 0.488 Å です（強い土台の K39・K42 では 0.60〜0.61 Å でした。資料Dの静的な特徴量にはフレーム 10 の距離そのものが入っているため、資料Dでは残りがやや小さくなります）。
- 候補の量は、軌道の座標から測り直しました。軌道は `/home/hatch/workspace/gpt-model-check/data/trajectories` の atlas-<タンパク質>-analysis-R<レプリカ>（atoms.parquet と A.zarr）で、資料Dのキャッシュを作った extract.py と同じ並びで残基と原子を対応付けています。距離はすべて周期境界の最小イメージで測ります（箱は対角で、軸ごとに箱の長さで丸めます）。(a) の中点は、ドナーの座標に最小イメージでの変位の半分を足して作ります。重原子の数え方は extract.py と同じです（原子名が H で始まらず、先頭が数字でないもの）。
- 前提の確認として、読み直した座標から計算したドナー・アクセプター間距離が、資料Dのキャッシュの hist と全フレームで一致すること（最大の差が 1e-6 Å 未満、実際の確認では 0.0）を、テストの 6 軌道すべてで確かめました。(c) の Cα のゆらぎは、座標が箱をまたいで飛んでいないことを確かめたうえで（Cα の隣のフレームとの移動が 20 Å 未満）、素の座標の RMSF で測りました。参考として、フレームごとの Cα の重心を引いた座標での RMSF（全体の平行移動を除いた形）も測りましたが、値は素の座標の RMSF とほぼ同じで（平均 0.702 Å 対 0.702 Å）、相関の形も変わりませんでした。
- 候補の量の分布（テスト全体）: (a) 重原子の数の平均は平均 81.2・標準偏差 18.8（最小 24.5、最大 130.9）、(b) そのばらつきは平均 2.99・標準偏差 1.21（最大 13.18）、(c) Cα のゆらぎは平均 0.702 Å・標準偏差 0.288 Å（最大 3.37 Å）、(d) 接触する残基の数の平均は平均 12.8・標準偏差 3.9（最小 3.0、最大 25.5）でした。

## 結果

残りの平均との相関です。左が GBM 回帰の残り、右が線形回帰の残りで、各セルはピアソン / スピアマンの順です。

| 候補 | GBM の残り（合算） | GBM（1mix_A） | GBM（2qt4_A） | 線形の残り（合算） | 線形（1mix_A） | 線形（2qt4_A） |
|---|---:|---:|---:|---:|---:|---:|
| (a) 重原子の数の平均 | −0.087 / −0.053 | −0.102 / −0.033 | −0.033 / −0.061 | −0.074 / −0.022 | −0.102 / −0.016 | −0.002 / −0.014 |
| (b) その数のばらつき | +0.119 / +0.015 | +0.136 / +0.010 | +0.016 / −0.027 | +0.124 / +0.006 | +0.145 / +0.001 | +0.014 / −0.021 |
| (c) Cα のゆらぎ | +0.129 / +0.092 | +0.127 / +0.084 | +0.049 / +0.047 | +0.121 / +0.068 | +0.123 / +0.065 | +0.034 / +0.026 |
| (d) 接触する残基の数の平均 | −0.070 / −0.071 | −0.069 / −0.053 | −0.059 / −0.100 | −0.063 / −0.051 | −0.065 / −0.034 | −0.049 / −0.082 |

4 つの候補すべてで、合算・タンパク質ごとのどちらでも、ピアソン・スピアマンのどちらでも、絶対値 0.3 に届きませんでした。最も大きいものでも、(b) の 1mix_A でのピアソン +0.145（線形の残り）と、(c) の合算でのピアソン +0.129（GBM の残り）です。(b) と (c) は、ピアソンに比べてスピアマンがはっきり小さい形です（(b) は合算で +0.119 対 +0.015、(c) は +0.129 対 +0.092）。(b) の数のばらつきの最大は 13.18（平均 2.99）、(c) の Cα のゆらぎの最大は 3.37 Å（平均 0.702 Å）と、大きな値を持つペアが少数あり、ピアソンの小さな正の値は全体の傾向というより、その少数のペアに引っ張られた形です。

## 判断

先に固定した読み方に沿うと、**4 つの候補はすべて「この量ではない」**です。ペアの中点の周りの詰まり具合（重原子の数の平均とそのばらつき）、ペアの 2 残基の Cα のゆらぎ、ペアの残基と接触する残基の数は、どれも残りの平均と一緒には動きません。残りの平均（標準偏差 約 0.49 Å）が何の影なのかは、この 4 つの量では説明できませんでした。K39・K42 の残りの平均は、周りの詰まり具合や残基のゆらぎのような、ペアの周囲の量とは別のものを見ていることになります。

## 読みの注意点

- 相関は「一緒に動くか」だけを見ています。相関が小さいことは、その量が残りの平均の成り立ちに関係しないことまでは言えません（たとえば非線形な関わりや、他の量と組み合わさった関わりは、この測り方では拾えません）。先に固定した読み方の範囲では、4 つとも候補として残りませんでした。
- 残りの平均は資料Dの静的な特徴量で作っています。資料Dの静的な特徴量にはフレーム 10 の距離そのものが入っているため、強い土台（K39・K42）とは残りの大きさが違います（テストで標準偏差 0.49 Å、K39・K42 では 0.60〜0.61 Å）。強い土台の残りの平均で同じ候補を測ると形が変わる可能性は残ります。
- (a) の重原子の数には、ペア自身の 2 残基の原子も含まれます（中点の近くにあるため）。(d) の接触の数には、配列上で隣り合う残基も含まれます（ペアの 2 残基自身だけを除きました）。どちらも、すべてのペアにほぼ一様に足される分は相関に影響しません。
