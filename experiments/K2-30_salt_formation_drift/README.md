# K2-30: K2-06 の問い（漂いが足しになるか）を塩橋の形成で測る

- 確かめる問い: K2-06 では、水素結合の形成で、履歴の漂い（前半の平均 − 後半の平均）を全部の平均の上に足しても足しになりませんでした（(c) 0.4834 は (b) 0.4865 を −0.0031 下回る）。K2-15 では水素結合の解離で足しになりました（+0.0232）。ここでは同じ問いを塩橋の形成で測ります。
- 状態: 完了。先に固定した読み方に沿い、**漂いは足しにならない**。全部の平均＋漂い (c) の AUPRC 0.3504 は、全部の平均だけ (b) の 0.3682 を −0.0178 下回った（+0.01 の線に届かない）。漂いだけ (a) の利得は全部入りの利得の 0.200 で、単独ではわずかな利得しか持たない。

## 1. 何を確かめる実験か

K15 の広げた条件（塩橋の形成、1 ns先）で、静的な特徴量に足す履歴の情報を「漂いだけ」「全部の平均だけ」「全部の平均＋漂い」の 3 通りに変え、全部の平均の上に漂いが足しになるかを測る。

背景は K2-06 と K2-15 の結果である。形成では水素結合（K2-06）で漂いは足しにならず、解離では水素結合（K2-15）で足しになった。塩橋の形成でどちらになるかを見る。K2-10 では塩橋の形成で前半 0.545・後半 0.600 と、前半と後半がほぼ並んでいた。

読み方は結果を見る前に固定した（K2-06 と同じ）。

- (c) 全部の平均＋漂いが (b) 全部の平均だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) 漂いだけの利得も記録し、全部入りの利得に対する割合もあわせて記録する。
- K2-10 の「前半と後半の両方」（割合 0.830）と (c) の結果の関係も記録する。(c) は (b) の上に漂いを足した形で、K2-10 の「前半と後半の両方」は前半と後半の平均を 2 つ入れた形。2 つの条件の AUPRC の差も記録する。
- 割合の分母は全部入りの利得（静的＋履歴 6 統計量の利得）を主とし、あわせて全部の平均の利得に対する割合も記録する（分母の確認のため）。
- 塩橋の形成は土台の利得が小さい（1 ns先で +0.144）ため、AUPRC の差も記録する。

## 2. 条件

- 土台は K15 の広げた条件（塩橋の形成）。学習 58 タンパク質、テスト 30 タンパク質（`experiments/K15_saltbridge_expansion/split.json` の分け方。元の 6 タンパク質に学習 54・テスト 28 を足したもの）、候補は学習 2,557件・テスト 1,170件（テスト陽性 93件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は5個。境界は 4.0 Å。
- 塩橋の定義は K13・K15 と同じ。正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2 で、距離は荷電重原子ペアの最小値。候補は起点（フレーム10、1 ns）で最小距離が 4.0 Å 超〜10.0 Å 以下で、配列距離が2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å 以下になること。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）。履歴は 0〜1 ns の11フレームの距離系列の6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下だった割合）。
- K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/` の塩橋の形成の距離系列）を再利用した。距離はフレームごとの箱を軸ごとに扱って計算済み。実行はローカルVM（8条件の学習で約23秒）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。
- ATLAS のダウンロードが絞られ取得済み82件で集合を凍結した点と、2hng_A の R3 と 4cv4_A の R2 は箱が全フレームで 0 のため候補0件でテスト側が約20件（約2%）欠けている点は、K15 の記録のとおり。

### 漂いの定義（結果を見る前に固定、K2-06 と同じ）

| 名前 | 定義 |
|---|---|
| 漂い | 前半の平均 − 後半の平均。前半はフレーム [0..4]（0〜0.4 ns）の距離の平均、後半はフレーム [6..10]（0.6〜1.0 ns）の距離の平均 |
| 符号 | 漂いが正なら「前半のほうが距離が大きい」（履歴のなかで距離が縮む方向に動いた）、負なら「後半のほうが距離が大きい」（距離が開く方向に動いた）という意味 |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である。** K2-01 と同じ分け方で、前半と後半をきれいに分けるためである。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ（土台の照合用）。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。割合の分母（全部入りの利得）の参照。
- (a) 漂いだけ: 静的特徴＋漂い。
- (b) 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の距離の平均。
- (c) 全部の平均＋漂い: 静的特徴＋全部の平均＋漂い。
- 前半の平均だけ・後半の平均だけ・前半と後半の両方: K2-10 の記録との照合用。

### タンパク質ごとの値（AUPRC の差 (c) − (b)）

30 タンパク質のうち、(c) − (b) が +0.01 以上なのは 14 タンパク質、0 未満なのは 9 タンパク質、0 以上 +0.01 未満なのは 7 タンパク質（うち 4 つは陽性が 0 件で AUPRC の差が 0 になるタンパク質：2qt4_A、2ftx_A、1pch_A、6fc0_B）。中央値は 0.0000、範囲は [−0.2361, +0.5000] と大きく広がる。最も大きいのは 3bwu_D の +0.5000、最も小さいのは 2hu9_A の −0.2361 で、どちらも陽性の少ないタンパク質の揺れと見られる。タンパク質ごとでは符号が分かれ、合算の −0.0178 が一般の形かは、この実験だけでは決められない。

なお、陽性が 0 件の 4 タンパク質では AUPRC と AUC が定義されないため、タンパク質ごとの AUPRC は 1.0、AUC は nan になる（sklearn の警告のとおり）。合算の値には影響しない。

## 4. 先に固定した読み方への答え

- **漂いは足しにならない。**(c) の AUPRC 0.3504 は (b) の 0.3682 を −0.0178 下回り、+0.01 の線に届かなかった。AUC では (c) が 0.8542 と (b) の 0.8519 をわずかに上回ったが、読み方で固定した指標は AUPRC であり、判定は AUPRC で行う。
- (a) 漂いだけの利得は +0.0288 で、全部入りの利得に対する割合は 0.200。漂いだけでもわずかな利得はあるが、全部の平均の利得（+0.1280）の 2 割ほどでしかない。
- K2-10 の「前半と後半の両方」（AUPRC 0.3597、割合 0.830）と (c)（AUPRC 0.3504、割合 0.766）の差は −0.0093 で、(c) のほうが低い。前半と後半の両方を入れたときの上積みは、漂いを 1 つの量として足した形では再現できなかった。

## 5. K2-06（水素結合の形成）・K2-15（水素結合の解離）・K2-16（水素結合の形成、30 ns先）との比較

| 実験 | 現象・予測幅 | (a) 漂いだけの割合 | (c) − (b) の AUPRC の差 | 判定 |
|---|---|---:|---:|---|
| K2-06 | 水素結合の形成、1 ns先 | 0.231 | −0.0031 | 足しにならない |
| K2-15 | 水素結合の解離、1 ns先 | 0.314 | +0.0232 | 足しになる |
| K2-16 | 水素結合の形成、30 ns先 | −0.075 | −0.0014 | 足しにならない |
| K2-30 | 塩橋の形成、1 ns先 | 0.200 | −0.0178 | 足しにならない |

形成では、水素結合の 1 ns先（K2-06、−0.0031）・30 ns先（K2-16、−0.0014）に続き、塩橋の 1 ns先でも漂いは足しにならなかった。塩橋の形成では (c) − (b) の差が −0.0178 と、水素結合の形成の 2 件より大きく負に出た。解離では水素結合（K2-15）で漂いが足しになったのと逆の形である。漂いの役割は、形成と解離で違う。形成の側では、現象（水素結合と塩橋）をまたいで「漂いは足しにならない」がそろった。

ただし塩橋の形成は土台の利得が小さい（+0.144）ため、割合の読みには留保がつく。タンパク質ごとでは (c) − (b) の符号が分かれる（+0.01 以上が 14、0 未満が 9）ため、合算の −0.0178 が一般の形かは、この実験だけでは決められない。

なお、この記録を書いているあいだに K2-34（接触の形成、1 ns先）の結果が出た。接触の形成では (c) 0.5375 が (b) 0.5008 を +0.0367 上回り、「漂いは足しになる」だった。形成の側でも現象で違い、塩橋の形成（足しにならない）と接触の形成（足しになる）で逆になる。漂いだけの利得は接触の形成では全部入りの 0.057 と小さいが、(c) − (b) の差はほとんど 1mix_A が担っている。

## 6. 判断できること・まだ分からないこと

- 判断できること: K15 の広げた条件・塩橋の形成・1 ns先では、履歴の漂い（前半の平均 − 後半の平均）は、全部の平均の上に足しにならない（AUPRC の差 −0.0178）。漂いだけの利得も全部入りの利得の 0.200 と小さい。K2-10 の「前半と後半の両方」の上積みは、漂いを 1 つの量として足した形では再現できなかった。
- まだ分からないこと: 漂いの符号（縮む方向か開く方向か）で分けたときの形（今回は符号を分けて測っていない）。塩橋の解離で漂いが足しになるか（水素結合の解離では足しになったが、塩橋の解離では測っていない）。長い予測幅での塩橋の形成の漂いの形。
