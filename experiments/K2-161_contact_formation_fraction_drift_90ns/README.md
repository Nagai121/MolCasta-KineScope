# K2-161: K2-15 の問い（漂い）を割合で測る（資料Dの条件、接触の形成、90 ns先、割合だけ）

- 確かめる問い: 漂いは、前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）である。割合は、ペアの最小重原子間距離が接触の閾値（4.5 Å）以下の時間の割合である。接触の形成では、平均の漂いは 1 ns先（K2-34、+0.0367）、30 ns先（K2-55、+0.0116）、50 ns先（K2-75、+0.0331）で足しになった。ここでは、同じ問いを割合の漂いの形で 90 ns先で測る。
- 状態: 完了。**全部の割合＋漂いは 0.4185 で、全部の割合だけ（0.4198）を −0.0013 下回り、「漂いは足しにならない」になった。** 平均の漂いの形では足しになった 1・30・50 ns先と違い、割合の漂いの形では 90 ns先で足しにならなかった。

## 1. 何を確かめる実験か

資料Dの条件で、接触の形成、90 ns先、割合だけ。漂いは前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）である。静的な特徴量に、つぎのどれか 1 つを足した形で比べる。

- (a) 漂いだけ
- (b) 全部の割合だけ（フレーム [0..10] の 4.5 Å以下割合）
- (c) 全部の割合＋漂い

読み方は結果を見る前に固定した（K2-06・K2-15 と同じ）。

- (c) 全部の割合＋漂いが (b) 全部の割合だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、そうでなければ「足しにならない」と記録する。
- (a) 漂いだけの利得も、全部入りの利得に対する割合とあわせて記録する。
- K2-124 の「前半と後半の両方」（割合の形での利得 0.662）と (c) の結果の関係も記録する。(c) は (b) の上に漂いを足した形で、K2-124 の「前半と後半の両方」は前半と後半の割合を 2 つ入れた形である。

## 2. 条件

- 土台は資料Dの条件（6 タンパク質×3 レプリカで学習、2 タンパク質×3 レプリカでテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、接触の形成、90 ns先、割合だけ。静的な特徴量は 5 個である。学習・テストのタンパク質の分け方は K13 の条件（学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A・2qt4_A）に従う。
- 入力は K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/`、接触の形成の候補ごとの残基どうしの最小距離の系列）を再利用した。履歴は (n, 11) で保存されているため、転置はしない（K46 のキャッシュとは違う）。
- 実行はローカルVM（8 条件の学習で 1 分ほどで終わったため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 前半と後半の定義（K2-01 と同じ）

| 名前 | フレーム | 時刻の範囲 |
|---|---|---|
| 前半 | [0..4] | 0〜0.4 ns |
| 後半 | [6..10] | 0.6〜1.0 ns |
| 全部 | [0..10] | 0〜1.0 ns |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である**（K2-01 と同じ）。

## 3. 結果

### 土台の再現

90 ns先で静的のみ AUPRC 0.2872、全部入り（6 個の統計量）0.4722、利得 +0.1850 で、接触の形成の 90 ns先の記録と小数第4位まで一致した。テスト 7,384件・陽性 257件も一致した。全部の割合だけは AUPRC 0.4198、前半の割合だけは 0.4171、後半の割合だけは 0.3947 で、K2-124 と小数第4位まで一致した。results.json と実行スクリプトの horizon_ns は 90 である。

### 条件ごとの AUPRC と利得（テスト、90 ns先）

| 条件 | AUPRC | 利得 | 割合（対 全部入りの利得） |
|---|---:|---:|---:|
| 静的のみ | 0.2872 | ― | ― |
| 全部入り（6 個の統計量） | 0.4722 | +0.1850 | 1.000 |
| (a) 漂いだけ | 0.3776 | +0.0904 | 0.489 |
| (b) 全部の割合だけ | 0.4198 | +0.1326 | 0.717 |
| (c) 全部の割合＋漂い | 0.4185 | +0.1313 | 0.710 |

全指標は `results.json` にある。

### 漂いの足し（(c) − (b) の AUPRC の差）

**−0.0013 で、「漂いは足しにならない」になった。** 先に固定した +0.01 の線を下回った。(c) は (b) とほぼ同じで、漂いを足しても何も変わらなかった。(c) は前半と後半の割合を 2 つ入れた形（0.4097）も +0.0088 上回ったが、+0.01 の線には届かなかった。

### タンパク質ごと（テスト 2 タンパク質）

漂いの足しのタンパク質ごとの差（(c) − (b) の AUPRC）は、1mix_A で +0.0023、2qt4_A で −0.0326 である。1mix_A ではほぼ変わらず、2qt4_A では下がった。2 タンパク質の土台では粗いため、合算の −0.0013 は 2qt4_A の下がりが 1mix_A の上がりを打ち消した形である。

## 4. 先に固定した読み方への答え

全部の割合＋漂いが全部の割合だけを AUPRC で −0.0013 下回ったため、**「漂いは足しにならない」** である。
