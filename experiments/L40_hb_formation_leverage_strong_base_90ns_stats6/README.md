# L40: 統計量6種を使った場合の曲がりを予測幅 90 ns で測る（K06(b) の条件、水素結合の形成、90 ns先）

- 状態: 完了。**90 ns先では、統計量6種を使っても必要な長さは縮まなかった。** 回復率 0.8 に届く最小の長さは全体・平均とも 0.4 ns で、平均だけ（L08）の 0.2 ns よりむしろ 0.2 ns 長くなった。0.9 に届く最小の長さは全体・平均とも 0.4 ns で、平均だけと同じ。短い側（0.1〜0.3 ns）では統計量6種の回復率が平均だけを大きく下回り（0.1 ns で全体 0.585 対 0.747）、長い側（0.6 ns 以後）ではほぼ並び、覆う長さ 1.0 ns では統計量6種が平均だけを上回った（全体 1.162 対 1.084）。増え幅がいちばん大きい場所は全体で 0.3→0.4 ns（+0.208）、タンパク質ごとの平均で 0.1→0.2 ns（+0.224）で、全体と平均で場所がずれ、曲がり自体も単調ではないため、段と呼べる跳ねとは読まない。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02・L08 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの統計量6種」を履歴の特徴量として強い土台の補正モデルに入れたときの 90 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。平均だけの条件も同じ実行の中で測り直し、L08・G81 の記録との照合（前提確認）と、統計量6種との同じ長さでの比較に使う。

読み方は L02・L08 と同じで、先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。L08（平均だけ）の答え（0.8 は全体・平均とも 0.2 ns、0.9 は全体・平均とも 0.4 ns）と比べて、縮んだかどうかを明記する。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する。

### 統計量6種の定義（実験Dどおり）

統計量6種は、実験D（固定した 1 ns 履歴の実験）の `features_from_history` の定義をそのまま使う。元の記録は MolCasta-InternalResearch ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py`（この仮想マシンのコピーは `~/workspace/kinescope/work/fixed_1ns_history_3phen_6h.py`）。フレームごとの供与体・受容体間距離の系列に対して、次の6つを float32 で並べたもの。

1. 最初の値（フレーム0の距離）
2. 平均
3. 標準偏差（numpy の std、ddof=0）
4. 最小値
5. 最後−最初
6. 閾値以下だった割合（系列 ≤ 閾値 のフレームの割合）

閾値は実験Dの `THRESH["hb"] = 3.5` Å（水素結合の形成のラベルの境界と同じ 3.5 Å）。実験Dでは系列は 0〜1 ns の11フレーム全部だが、L40 では各覆う長さまでのフレーム（フレーム 0〜(L/0.1)）に対して同じ6種を計算する。

K06(b) の履歴特徴10個との関係: K06(b) の保存値を作った `~/workspace/k06b/run/score_b.py` の history は、全11フレームに対して [最初, 平均, 標準偏差, 最小, 最大, 最後−最初, 最後−直前, 3.5 Å以下割合, 4.5 Å以下割合, 増加割合] の10個で、**統計量6種はその [0, 1, 2, 3, 5, 7] 列と正確に一致する部分集合**である（残りの4つは 最大・最後−直前・4.5 Å以下割合・増加割合）。同じ score_b.py には、生成系列に対してまったく同じ6種を計算する `gen6` もあり、定義は実系列・生成系列で共通している。前提確認として、g05_series の全11フレームから計算した統計量6種が k06b_out の保存値の該当列と、較正・テスト全108タンパク質×3レプリカで最大差 3.8e-6（float32 の丸めの範囲）で一致することを確かめた。覆う長さ 1.0 ns の統計量6種の条件は、この部分集合だけを使う条件であり、全部入り（10個全部）とは別条件である。

### 長さの呼び方（L01・L02・L08 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02・L08 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけの1フレーム、1.0 ns はフレーム 0〜10 の11フレーム全部）。起点フレーム10（1 ns）は変えず、ラベルは 90 ns先のまま。

覆う長さ 0 ns（1フレーム）では、統計量6種のうち 最初・平均・最小 は同じ値になり、標準偏差と 最後−最初 は 0、割合は「フレーム0が 3.5 Å以下かどうか」の 0/1 になる。実際、この長さの回復率は平均だけとほぼ一致した（全体 0.694 対 0.693）。

### 条件の一覧（90 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り（L08 と同じ条件。前提確認と比較用）。
- 切り取りの統計量6種: 静的特徴＋切り取りの統計量6種。覆う長さ 0.0〜1.0 ns の11通り（本測定）。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（G05・L02 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（L02・L08 と同じ、G147・G148・G162 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・各長さの平均だけ・統計量6種の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取りを numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC（学習済みモデルの予測から出した固定値）を、再標本化の重なり具合で重み付けして平均したもの。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

## 5. 読み取り

- **90 ns先では、統計量6種は必要な長さを縮めない。** 線に届く長さは 0.8 の線で平均だけより長く（0.4 ns 対 0.2 ns）、0.9 の線で同じ（0.4 ns）。短い切り取りでは平均以外の統計量が足を引っ張り、長い切り取りでは平均だけとほぼ同じ水準に戻る、という形である。
- 1 ns先（L39、0.1 ns 縮んだ）との違いは、予測幅で統計量6種の効き方が変わることを示す。90 ns先では分母の利得自体が小さく（全体 +0.0265）、フレーム0だけでも利得の 0.69 が戻るため、平均以外の統計量が付け加える余地が短い側では小さい、という読みと整合する。ただしこれは割合の話で、絶対値では戻る量そのものが小さい点は L08 と同じ留保がつく。
- 段については、増え幅最大の場所が全体（0.3→0.4 ns）と平均（0.1→0.2 ns）とタンパク質ごとの中央値（0.1→0.2 ns）でそろわず、曲がりも単調ではないため、特定の長さの段があるとは読まない。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、90 ns先）では、統計量6種を使った場合の回復率 0.8・0.9 に届く最小の覆う長さは、全体・平均とも 0.4 ns。平均だけ（L08、0.8 は 0.2 ns、0.9 は 0.4 ns）と比べて必要な長さは縮まなかった（0.8 の線ではむしろ 0.2 ns 長い）。統計量6種の回復率は短い側（0.1〜0.5 ns）で平均だけを下回り、0.6 ns 以後でほぼ並び、1.0 ns で上回る（全体 1.162）。増え幅最大は全体で 0.3→0.4 ns（+0.208）だが、段とは読まない。これで水素結合の形成の統計量6種の形は 1 ns先（L39）と 90 ns先（L40）がそろい、線に届く長さの向きは予測幅で逆だった（1 ns先では 0.1 ns 縮み、90 ns先では縮まなかった）。
- まだ分からないこと: 他の予測幅（5・10・30・50 ns先）での統計量6種の形。実測の費用に直したときの形。他の現象（解離、接触、塩橋）での曲がりは別の担当の L 系列で測られている。
