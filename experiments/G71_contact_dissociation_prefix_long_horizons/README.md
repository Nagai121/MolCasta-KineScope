# G71: 接触の解離で、長い予測幅でも短い切り取りで指導力が戻るか

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、もう一つの経路「短い実MDを安くする」方向。G06 は 1 ns 先だけでした（接触の解離で 0.1 ns の切り取りの平均だけ 0.919、0.5 ns で 0.945）。長い予測幅でも同じか確かめます。
- 状態: 完了。5つの予測幅すべてで、0.1 ns の切り取りの平均だけで回復率 0.5 を超えました。

## 1. 何を確かめる実験か

G02・G06 と同じ切り取り（実の 0〜1 ns の履歴の始めの短い部分だけを使う）を、接触の解離の長い予測幅で確かめます。G60（塩橋の形成）・G65（接触の形成）とおなじ読み方です。

読み方は先に固定しました。各予測幅で、回復率 0.5 を超える最小の切り取りを出します。3つの切り取りのどれでも 0.5 を超えなければ、その予測幅では「0.5 ns まででも届かない」と記録します。0.1 ns で 0.5 を超えれば、その予測幅では最小の切り取りは 0.1 ns です。

## 2. 条件

- 土台は資料Dの条件。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（抽出済みのキャッシュの段取り）。実行はローカルVMです（`~/workspace/.mt-venv` の Python、OMP_NUM_THREADS=2）。
- 接触の解離の定義（K50 と同じ）: 形成と同じ残基ペアの規則（Cα間 12 Å 以下、配列距離2以上）で、起点フレーム10の重原子の最小距離が 4.5 Å 以下（接触ができている状態）のペア。ラベルは予測先で 4.5 Å を超えること。静的特徴5個（起点の最小距離、Cα間距離、配列距離の log1p、残基 i の重原子の数、残基 j の重原子の数）。候補は学習 6,383件、テスト 2,915件。テストの陽性は 1 ns先 207件（7.1%）、5 ns先 211件（7.2%）、10 ns先 228件（7.8%）、30 ns先 246件（8.4%）、50 ns先 267件（9.2%）、90 ns先 294件（10.1%）。
- 切り取りの定義（G02・G06 と同じ、結果を見る前に固定）。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。
  - 0.1 ns → フレーム 0, 1（2フレーム）
  - 0.25 ns → フレーム 0, 1, 2（3フレーム、実際に覆う長さは 0.2 ns）
  - 0.5 ns → フレーム 0〜5（6フレーム）
  - 起点フレーム10（1 ns）は変えず、ラベルは予測先のまま。
- 条件の一覧（各予測幅とも同じ分け方）:
  - 静的のみ: 静的特徴だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
  - 切った平均だけ: 静的特徴＋切った履歴の平均だけ（主判断の条件）。
- 土台の利得は K50 の記録値です（1 ns +0.2142、5 ns +0.2506、10 ns +0.2022、30 ns +0.2368、50 ns +0.1606、90 ns +0.1864）。
- K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/`）を再利用しました。新しい軌道の取得や生成器の読み込みはしていません。

## 4. 読み取り

- **5つの予測幅すべてで、0.1 ns の切り取りの平均だけで回復率 0.5 を超えました。** 先に固定した読み方に沿うと、接触の解離では長い予測幅でも最小の切り取りは 0.1 ns です。1 ns先の 0.919 と同じく、長い予測幅でも 0.1 ns の切り取りだけで利得の大半が戻ります。
- 切り取りを長くしても回復率は単調には上がりません。5 ns先では 0.1 ns の 0.802 から 0.25 ns の 0.620 へ下がり、90 ns先では 0.1 ns の 0.935 が 0.25 ns の 0.861 へ下がって 0.5 ns で 0.930 へ戻ります。30 ns先では 3つの切り取りが 0.795〜0.827 とほぼ同じで、長くする意味はほとんどありません。
- 90 ns先の 0.1 ns は 0.935 と、1 ns先の 0.919 と同じくらい高く戻ります。90 ns先では 0.25 ns で 1.058、0.5 ns で 1.488 と実履歴を上回った水素結合の解離（G70）と違い、接触の解離では 0.25・0.5 ns でも実履歴を上回りません。
- 接触の形成（G65）では 10 ns先だけ 0.25 ns まで延び、50・90 ns先の 0.1 ns は 0.501・0.502 と線をわずかに超えただけでした。接触の解離では 5つの予測幅すべてで 0.1 ns が 0.578〜0.935 と線をしっかり超えており、解離のほうが短い切り取りで戻りやすい形です。塩橋の形成（G60）では 50 ns先が 0.5 ns まででも届かなかったのに対し、接触の解離では届かない予測幅はありません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離では、長い予測幅でも 0.1 ns の切り取りの平均だけで指導力の 0.5 以上が戻ります。短い実MDの経路は、接触の解離では予測幅によらず使えます。
- まだ分からないこと: なぜ 0.1 ns の切り取りでこれだけ戻るのか（解離の候補は起点で結んでいるため距離の動きが小さく、短い切り取りでも平均が 0〜1 ns の平均に近い、という G06 の読みはあります）。タンパク質が 2つしかないため、タンパク質ごとの形は分かりません。
