# K2-02: ペアの距離のゆらぎは、どれくらいの時間で忘れられるか

- 確かめること: 水素結合の形成の候補ペアの距離の時系列（100 ps 刻み 11 点）について、遅れ 1〜5（100〜500 ps）での距離の自己相関を測り、自己相関が落ちる時間と、L01 で見えた 0.6 ns の段が合うかどうかを確かめる。
- 状態: 完了。遅れ 1（100 ps）の時点で、自己相関はすでに 0.5 と 1/e の両方を下回っていた（全体のまとめで、主の見積もり −0.023、副の見積もり 0.077）。合成データでの較正に照らすと、真の遅れ 1 の自己相関は 0.1 前後（0.1〜0.2 の範囲）と読める。ゆらぎが忘れられる時間は 100 ps より短く、L01 の 0.6 ns の段とは合わない（少なくとも 6 倍速い）。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。L01 では、水素結合の形成 1 ns先で、切り取りの覆う長さが 0.6 ns のところで回復率が跳ねた（0.5 ns まで 0.65〜0.78、0.6 ns で 1.029）。この段が、ペアの距離のゆらぎが忘れられる時間と関係するかどうかを確かめる。

測るものは先に固定した。遅れ 1〜5（100〜500 ps）での距離の自己相関を、候補ペア全体でまとめた値。各遅れの自己相関と、自己相関が 0.5 と 1/e を下回る遅れを記録する。タンパク質ごと・レプリカごとの値も残す。

読み方は先に固定した。自己相関の落ちる時間が 0.6 ns の段（L01）と合うかどうかを、数値で述べる。11 点しかないので粗い測定であることは明記する。

## 2. 条件

- データ: 資料Dの条件の 6 タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A・1mix_A・2qt4_A）× 3 レプリカ。水素結合の形成の候補ペアの距離の時系列（100 ps 刻み 11 点）は、K08 の保存値（`~/workspace/kinescope/work/data_cache/` の `hist`）を使った。元の軌道は `~/workspace/gpt-model-check/data/trajectories/` の ATLAS データ。候補ペアは全部で 14,582 件で、標準偏差が 0 のペアは無かった。
- 主の見積もり: ペアごとに、そのペアの 11 点の平均と標準偏差（母標準偏差）で標準化し、遅れ k の自己相関を全ペア・全時刻の z[t] × z[t+k] の平均とする。
- 副の見積もり: 変動量（バリオグラム）から出す。ρ(k) = 1 − MSD(k) ÷ (2 × 分散)。MSD(k) は (d[t+k] − d[t])² の全ペア・全時刻の平均、分散はペアごとの分散（母分散）に 11/10 を掛けたもの（平均の推定による縮みへの補正）。差分を使うため、ペアの平均の推定誤差の影響を受けにくい。
- まとめる単位: 全体（全ペア）、タンパク質ごと（3 レプリカをまとめる）、レプリカごと（6 タンパク質をまとめる）、タンパク質×レプリカごと（数値は `results.json`）。
- 粗さと偏りの確認: 時系列が 11 点しかないため、どちらの見積もりも、真の自己相関が大きいときには下向きに偏る。真の遅れ 1 の自己相関 ρ を変えた AR(1) 過程（11 点、ペア数 14,582）を合成し、同じ見積もり方で測った値と実データの値を照合した（下の「較正」）。

## 3. 結果

### 全体の自己相関（14,582 ペア）

| 遅れ | 主の見積もり | 副の見積もり |
|---:|---:|---:|
| 1（100 ps） | −0.023 | 0.077 |
| 2（200 ps） | −0.071 | 0.040 |
| 3（300 ps） | −0.099 | 0.015 |
| 4（400 ps） | −0.113 | −0.002 |
| 5（500 ps） | −0.134 | −0.026 |

遅れ 1 の時点で、どちらの見積もりでも自己相関は 0.5 と 1/e（約 0.368）の両方を下回っていた。閾値を下回る遅れは、測れる一番短い遅れ（遅れ 1、100 ps）である。遅れ 0 の値 1.0 から遅れ 1 の値までを直線で補間した交差時刻は、主の見積もりで 0.5 に対して 0.049 ns、1/e に対して 0.062 ns、副の見積もりで 0.054 ns と 0.069 ns だが、これは形だけの計算で、実際に言えるのは「忘れられる時間は 100 ps より短い」までである。

### 較正（AR(1) の合成データ、遅れ 1 の測定値）

| 真の ρ（遅れ 1） | 主の見積もり | 副の見積もり |
|---:|---:|---:|
| 0.0 | −0.102 | −0.001 |
| 0.1 | −0.027 | 0.067 |
| 0.2 | 0.043 | 0.132 |
| 0.3 | 0.114 | 0.201 |
| 0.5 | 0.254 | 0.335 |
| 0.8 | 0.428 | 0.513 |

実データの測定値（主 −0.023、副 0.077）は、真の ρ が 0.1 の行と 0.2 の行の間にあり、0.1 に近い。真の遅れ 1 の自己相関は 0.1 前後（0.1〜0.2 の範囲）と読める。ρ が 0.5 なら測定値は主で 0.254・副で 0.335 になるはずで、実データとは大きく離れている。

### タンパク質ごと・レプリカごと（遅れ 1）

タンパク質ごとの副の見積もりは 0.021〜0.095（2qt4_A が 0.021、ほかは 0.074〜0.095）、主の見積もりは −0.079〜−0.005。レプリカごとの副の見積もりは R1 0.074・R2 0.079・R3 0.079、主の見積もりは −0.026〜−0.019。どのタンパク質・レプリカでも、遅れ 1 で 0.5 と 1/e を下回る形は同じだった。遅れ 2〜5 とタンパク質×レプリカごとの値は `results.json` にある。

## 4. 読み取り

先に固定した読み方に照らして、数値で述べる。ペアの距離のゆらぎが忘れられる時間は 100 ps より短い（遅れ 1 の自己相関は較正込みで 0.1 前後）。L01 の段は 0.6 ns で、こちらはその 6 分の 1 以下である。**自己相関の落ちる時間は 0.6 ns の段とは合わない。**

このため、L01 で 0.6 ns のところに段が出た理由は、距離のゆらぎの記憶の長さでは説明できない。100 ps 刻みの標本はほぼ独立に近いので、切り取りを長くすることは、主に独立な標本を多く平均することになる。段の理由は別のところにあるはずで、それはこの実験の範囲では決められない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 候補ペア全体でまとめた距離の自己相関は、遅れ 1（100 ps）で 0.1 前後まで落ちており、0.5 と 1/e を下回るのは測れる一番短い遅れである。ゆらぎが忘れられる時間は 100 ps より短く、L01 の 0.6 ns の段とは合わない。
- まだ分からないこと: 100 ps より短い時間での自己相関の形（このデータの刻みでは測れない）。ペアごとの忘れられる時間の分布（ペアごとに 11 点では推定が粗すぎて、全体のまとめでしか読めない）。較正は AR(1) の形を仮定しており、真の過程の形が違えば、ρ の読みは多少ずれる。ただし ρ（遅れ 1）が 0.5 以上なら測定値がはっきり正になることは、較正の形から言える。
