# G20: 閾値内割合は静的情報から当てられるか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめること: K21 では、実の割合（3.5 Å 以下の割合）だけを履歴の特徴として入れても回復率 0.857 だった（強い土台）。一方、平均は静的情報から当てられなかった（G01 の第2段で回復率 −0.09／0.13）。では、割合は静的情報から当てられるか。割合を静的情報から予測し、予測した割合だけを履歴の特徴として補正モデルに入れたときの回復率を測る。あわせて、割合そのものの複製間のばらつき（割合にとっての下限）も測る。
- 状態: 完了。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、1 ns先。割合は、0〜1 ns の履歴11フレームのうち 3.5 Å 以下のフレームの割合。

読み方は先に固定した。予測した割合の回復率が5割以上なら、割合は静的に届く担い手で、静的生成の路線が開ける。2割未満なら、割合も平均と同じく静的には届かない。

## 2. 条件

- 土台は資料Dそのまま。候補は学習4タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A）9,610件、テスト2タンパク質（1mix_A・2qt4_A）4,972件（陽性290件）。静的な特徴7つ、予測器は資料Dの HistGradientBoosting（max_iter=120、学習率 0.075、葉31、最小葉サンプル15、L2 0.02、種42）。静的のみ 0.3637、履歴全部入り 0.4815（利得 +0.1178）を再現した。
- 実の割合だけを入れた条件: AUPRC 0.4829、利得 +0.1192、回復率（全部入りの利得に対して）1.011。資料Dの条件では、割合だけで履歴の利得のほぼ全部を持つ（K21 の強い土台での 0.857 と同じ形）。
- 割合の予測: 学習タンパク質で割合を目的変数にして HistGradientBoostingRegressor（分類と同じ設定）を学習した。入力は (a) 静的な特徴7つ、(b) K40 の豊富な静的特徴99個。予測値は 0〜1 に切り取った。学習側の割合は、分類器の学習にも予測した値を使った（予測モデルを学習タンパク質に当てた値）。
- 割合の複製間のばらつき: 3複製すべてで候補になったペア 3,190件について、複製どうしの割合の差の標準偏差を測った。

## 3. 結果

割合そのもの（テスト）: 平均 0.060、標準偏差 0.164。

割合の複製間のばらつき（下限）: 複製どうしの差の標準偏差 0.066（3,190ペア、平均絶対差 0.019）。

割合の静的予測（テストでの誤差）:

| 予測の入力 | 偏り | 誤差の標準偏差 | 相関 |
|---|---|---|---|
| 静的な特徴7つ | −0.003 | 0.124 | 0.654 |
| 豊富な静的特徴99個 | −0.003 | 0.118 | 0.696 |

予測の誤差 0.118 は、複製間の下限 0.066 の約1.8倍。平均のとき（予測の誤差が下限の約1.9倍、K23・K40）と同じ形。

予測した割合を入れたときの AUPRC と回復率（1 ns先、テスト）:

| 条件 | AUPRC | 利得 | 回復率（全部入りに対して） |
|---|---|---|---|
| 静的のみ | 0.3637 | — | — |
| ＋実の割合 | 0.4829 | +0.1192 | 1.011 |
| ＋予測した割合（特徴7つ） | 0.3386 | −0.0251 | −0.213 |
| ＋予測した割合（特徴99個） | 0.3885 | +0.0248 | 0.211 |
| 履歴全部入り | 0.4815 | +0.1178 | 1.000 |

回復率のばらつき（テスト候補のリサンプリング 2,000回、予測は固定）: 特徴99個の回復率は中央値 0.213、95% の範囲は −0.055〜0.516。0を超える確率は 0.949、5割以上になる確率は 0.029、2割未満になる確率は 0.461。特徴7つの回復率は中央値 −0.204、95% の範囲は −0.587〜0.027 で、2割未満になる確率は 1.000。

## 4. 読み取り

先に固定した読み方に照らすと、予測した割合の回復率は最良でも 0.211 で、5割の線には遠く届かない（ブートストラップで5割以上になる確率は 0.029）。2割の線については、0.211 はわずかに上だが、ブートストラップでは2割未満になる確率が 0.461 と半々に近く、線の上にいるとは言い切れない。いずれにせよ、割合の担い手としての力の大半（約8割）は静的予測では残らない。割合も平均と同じく、静的情報からは大半が届かない、というのがこの測定の結論。静的生成の路線は、この担い手では開けない。

特徴7つからの予測は回復率が負（−0.213）で、入れるほうが静的のみより悪い。豊富な特徴99個からの予測はわずかに利く（+0.025）が、実の割合の利得 +0.119 とは桁が違う。

割合の予測の相関は 0.70 と平均の予測より見かけは良いが、これは割合が開始距離に強く結びついているためで、候補ごとの実現した値（どの複製かで変わる部分）は静的特徴に無い。誤差が下限の1.8倍という比も平均と同じで、壁の正体は平均のときと同じ「入力の状態の不足」とみるのが自然。

## 5. 判断できること・まだ分からないこと

- 判断できること: 割合は、それだけでは履歴の利得のほぼ全部を持つ強い担い手（回復率 1.011）だが、静的情報から予測すると回復率は 0.211 まで落ちる。平均に続いて、割合も静的には届かない担い手。静的に届く担い手は、これで平均・割合のどちらでも見つかっていない。
- まだ分からないこと: 割合以外の量（最小値、標準偏差など）が静的に届くかどうかは、この実験では測っていない。ただし K18 では実の履歴の中で1つの量を落としても利得はほぼ減らず、情報は量のあいだに分散していたため、別の1つの量だけが静的に届く可能性は高くないとみる。
