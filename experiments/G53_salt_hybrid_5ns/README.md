# G53: 塩橋の形成で、5 ns先の混合は足しになるか

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G19 では 1 ns先で、0.1 ns の切り取り平均に作り直した第11〜14案の生成平均を足すと、4案すべてで混合の回復率が切り取り平均だけより +0.05 以上上がりました（第11案 +0.190、第12案 +0.212、第13案 +0.108、第14案 +0.231）。5 ns先はまだ測っていません。5 ns先で同じ条件を測り、効き目がどこまで続くか確かめます。

読み方は実験前に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がる案があれば、塩橋の形成でも 5 ns先で混合が足しになることになります。どの案も +0.05 未満なら、塩橋の形成の混合は 1 ns先に限られることになります。

## データと条件

- 条件は K15 の広げた条件の塩橋の形成、5 ns先です。生成系列は G19 で作り直したもの（`experiments/G19_salt_prefix_plus_generated/gen/`、第11〜14案）をそのまま使い、G19 の `run_g19.py` を予測幅の添字 1（5 ns先）に変えた `run_g53.py` で測りました。学習58タンパク質 2,557件、テスト30タンパク質 1,170件。5 ns先の陽性はテストで129件です。静的特徴は5個、履歴は荷電ペアの距離の系列の6統計量（4.0 Å 以下だった割合）です。
- 0.1 ns の切り取りはフレーム [0,1]（2フレーム）で、平均はその2フレームの距離の平均です（G02 と同じ）。生成平均は、分岐平均の9点系列を9点で平均したものです（G13・G19 と同じ）。生成系列と実側の対応付けは、軌道ファイルごとに残基ペアが K15 のキャッシュと一致することを確認してから行いました。全条件は同じテスト候補 1,170件（陽性129件）で測っており、件数は条件によらずそろっています。
- 条件は次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、生成平均だけ、混合（切り取り平均＋生成平均の2列）。回復率は、その予測幅での実履歴の利得で割った値です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G11・G14・G17・G19・K09 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。
- 土台の検証: 静的のみ AUPRC 0.2513、全部入り 0.3301、実履歴の利得 +0.0788 は、K15 の記録（0.2513 → 0.3301、+0.079）と完全に一致しました。

## 結果

### 5 ns先（実履歴の利得 +0.0788）

| 条件 | AUPRC | 利得 | 回復率 |
|---|---:|---:|---:|
| 静的のみ | 0.2513 | — | — |
| 全部入り（実履歴） | 0.3301 | +0.0788 | 1.000 |
| 切り取り平均だけ | 0.3181 | +0.0668 | 0.847 |
| 生成平均だけ（第11案） | 0.2799 | +0.0287 | 0.364 |
| 生成平均だけ（第12案） | 0.2788 | +0.0275 | 0.349 |
| 生成平均だけ（第13案） | 0.2434 | −0.0078 | −0.100 |
| 生成平均だけ（第14案） | 0.2601 | +0.0088 | 0.111 |
| 混合（第11案） | 0.3350 | +0.0837 | 1.062 |
| 混合（第12案） | 0.3380 | +0.0867 | 1.100 |
| 混合（第13案） | 0.3123 | +0.0610 | 0.774 |
| 混合（第14案） | 0.3226 | +0.0713 | 0.905 |

混合と切り取り平均だけの差は、回復率で第11案 **+0.215**、第12案 **+0.253**、第13案 **−0.073**、第14案 **+0.057** です。

AUPRC はテストの合算です。AUC・Brier・Log Loss は `results.json` を参照。

### 2つの平均の関係（テスト側）

G19 の 1 ns先と同じ値です（生成系列が同じため）。切り取り平均と生成平均の相関は約0.58、生成平均と実の平均の相関は約0.73、生成平均と実の平均の差の標準偏差は約1.52 Å です。

## 結論

先に固定した読み方に沿うと、第11案（+0.215）、第12案（+0.253）、第14案（+0.057）が +0.05 以上上がったため、**塩橋の形成でも 5 ns先で混合が足しになる案があります**。第13案だけは −0.073 で、足しになりませんでした。

読みの注意点として、実履歴の利得の分母が小さい（+0.0788）ため、回復率の数値が大きく出ています。第12案の回復率 1.100 は全部入りを上回っていますが、AUPRC の絶対値で見ると混合が全部入りを上回る幅は +0.0079（0.3380 に対して 0.3301）で、回復率の見た目ほど大きな差ではありません。1 ns先の数値（利得の分母 +0.1440）と比べるときも、この分母の小ささに注意してください。

水素結合の 5 ns先（G26）では混合が −0.169 と足しにならなかったのに対し、塩橋の形成では 5 ns先でも 3案が線を超えました。混合の効き目の切れ目は、現象によって違います。
