# G65: 接触の形成で、長い予測幅でも短い切り取りで指導力が戻るか

## 仮説

H6（運動の生成そのものの問題）に関わる、短い実MDの経路の広がりの確認です。G03 では接触の形成で 0.1 ns の切り取りの平均だけが 1 ns先の利得の 0.432 しか戻らず、G07 では切り取りを 0.5 ns まで長くして 1 ns先の形を見ましたが、長い予測幅での形は空白でした。ここでは予測幅 5・10・30・50・90 ns で、切り取り 0.1・0.25・0.5 ns の平均だけの回復率を測ります。

読み方は実験前に固定しました（G60 と同じ）。各予測幅で、回復率 0.5 を超える最小の切り取りを出します。3つの切り取りのどれでも 0.5 を超えなければ、その予測幅では「0.5 ns まででも届かない」と記録します。

## データと条件

- 条件は資料Dの接触の形成です。接触形成の定義は、残基ペア i<j で Cα間 12 Å以下、配列距離2以上、距離は重原子ペアの最小値です。候補は起点（フレーム10、1 ns）で 4.5 Å超、ラベルは予測先で 4.5 Å以下です。静的特徴は5個、履歴は 0〜1 ns の11フレームの距離系列の6統計量（4.5 Å 以下だった割合）です。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A で候補 15,926件、テスト 1mix_A＋2qt4_A で候補 7,384件です。K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/`）を再利用しました。
- 切り取りの定義は G02・G03・G07 と同じです。軌道の保存間隔は 100 ps（0.1 ns）で、0.1 ns の切り取りはフレーム [0,1]（2フレーム）、0.25 ns はフレーム [0,1,2]（3フレーム、実際に覆う長さは 0.2 ns）、0.5 ns はフレーム [0〜5]（6フレーム）です。条件は「静的特徴＋切り取りの平均だけ」です（他の統計量は入れません）。起点フレーム10（1 ns）とラベルは変えていません。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 回復率は、切り取りの平均だけの条件の利得を、その予測幅での実履歴の利得で割った値です。利得はどちらも同じ条件・同じ予測幅の静的な特徴だけの条件との AUPRC の差です。
- 土台の利得の出所: K16 の記録値です（`experiments/K16_contact_channel/results.json` の static_only と base_hist の AUPRC の差）。1 ns +0.2271、5 ns +0.2322、10 ns +0.2030、30 ns +0.1518、50 ns +0.2034、90 ns +0.1850 です。
- 確認: 静的のみと全部入り（実履歴）は全予測幅で K16 の記録と一致しました（AUPRC の差は 0.00003 以下）。1 ns先の切り取りの平均だけも G03（0.1 ns で 0.432）と G07（0.25 ns で 0.512、0.5 ns で 0.773）の記録と一致しました。

## 判断

先に固定した読み方に沿うと、**5・30・50・90 ns先では最小の切り取りは 0.1 ns で、10 ns先だけは 0.25 ns です**。1 ns先では 0.1 ns の切り取りが 0.432 と 0.5 に届かなかったのと違い、長い予測幅では 0.1 ns の切り取りでも 0.5 を超える幅が 4つあります。

- 5 ns先では 0.1 ns で 0.641、30 ns先では 0.578 と 0.5 を超えます。30 ns先では 0.5 ns の切り取りで 1.008 と実履歴の利得を上回ります。
- 10 ns先だけは 0.1 ns で 0.434 と 0.5 に届かず、0.25 ns で 0.573 と超えます。1 ns先と同じく、10 ns先では 0.1 ns の切り取りが足りない形です。
- 50 ns先と 90 ns先の 0.1 ns の回復率は 0.501 と 0.502 で、0.5 の線をわずかに超えただけです。切り取りを 0.25 ns に長くすると 0.746 と 0.680 まで上がるため、0.1 ns で 0.5 を超えたとはいえ、余裕はほとんどありません。
- 切り取りを長くすると回復率はおおむね上がりますが、単調ではありません。5 ns先では 0.25 ns の 0.784 から 0.5 ns の 0.767 へわずかに下がり、50 ns先では 0.25 ns の 0.746 から 0.5 ns の 0.633 へ下がります。塩橋の形成（G60）では 10・90 ns先で 0.5 ns の切り取りが 0.5 を割り込んだのに対し、接触では 5つの予測幅すべてで 0.5 ns の切り取りが 0.5 を超えています。

## まだ分からないこと

- 10 ns先だけ 0.1 ns の切り取りが 0.5 に届かない理由は、この実験だけでは分かりません。1 ns先でも 0.1 ns は 0.432 と届かなかったため、短い予測幅で 0.1 ns の切り取りが足りない形は 1・10 ns先で共通していますが、5 ns先では 0.641 と超えているため、予測幅の長さだけでは説明できません。
- 50・90 ns先の 0.1 ns の回復率（0.501・0.502）は 0.5 の線をわずかに超えただけなので、別の seed や別の分け方では 0.5 を割り込む可能性があります。
