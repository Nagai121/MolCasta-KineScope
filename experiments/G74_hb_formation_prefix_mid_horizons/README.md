# G74: 水素結合の形成で、真ん中の予測幅でも短い切り取りで指導力が戻るか（資料Dの条件、水素結合の形成、5・10・30・50 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G02 は 1 ns先だけ、G03 は 90 ns先だけだったので、真ん中の予測幅（5・10・30・50 ns）での形が空白だった。ここを埋める。
- 状態: 完了。

## 1. 切り取りの定義（G02/G03 と同じ、結果を見る前に固定）

- 軌道の保存間隔は 100 ps（0.1 ns）。フレーム k は時刻 k*0.1 ns。
- 0.1 ns → フレーム 0, 1（2フレーム、覆う長さ 0.1 ns）
- 0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さは 0.2 ns。0.25 ns は 100 ps 刻みに合わない）
- 0.5 ns → フレーム 0〜5（6フレーム、覆う長さ 0.5 ns）
- 起点フレーム10（1 ns）は変えない。条件は「静的特徴＋切った平均だけ」（K21 の「平均だけ」と同じ形）。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（その予測幅での実履歴の利得）。

## 2. 土台の再現と利得の出所

- 土台は K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/`、18軌道）を再利用。資料Dの条件（学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件）。
- 土台の利得は K01 の記録値（`experiments/K01_time_degradation/results.json` の静的のみと全部入りの AUPRC の差）で、再計算でも一致した。1 ns +0.1178、5 ns +0.1155、10 ns +0.0829、30 ns +0.0626、50 ns +0.0739、90 ns +0.1211。
- 静的のみ・全部入りは全予測幅で K01 の記録と小数第4位まで一致した（1 ns先で静的のみ 0.3637、全部入り 0.4815。90 ns先で静的のみ 0.3035、全部入り 0.4246）。
- 1 ns先の切り取りの平均だけも G02 と一致した（0.1 ns 0.570、0.25 ns 0.647、0.5 ns 0.770）。90 ns先の 0.1 ns は 0.590 で G03 と一致した。
- 実行はローカルVMのみ。HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、seed 42）。途中で仮想マシンの再起動で1回止まったため、ログをファイルに残して再実行した（結果は変わらない）。

## 3. 結果（切り取りの平均だけの回復率）

| 予測幅 | 土台の利得 | 0.1 ns | 0.25 ns | 0.5 ns | 0.5 を超える最小の切り取り |
|---:|---:|---:|---:|---:|---|
| 1 ns | +0.1178 | 0.570 | 0.647 | 0.770 | 0.1 ns |
| 5 ns | +0.1155 | **0.846** | 1.029 | 1.037 | **0.1 ns** |
| 10 ns | +0.0829 | **0.771** | 0.975 | 1.229 | **0.1 ns** |
| 30 ns | +0.0626 | **0.979** | 1.053 | 1.138 | **0.1 ns** |
| 50 ns | +0.0739 | **0.745** | 1.004 | 1.266 | **0.1 ns** |
| 90 ns | +0.1211 | 0.590 | 0.825 | 0.658 | 0.1 ns |

参考の 0〜1 ns の平均だけの回復率は、1 ns 1.042、5 ns 1.190、10 ns 1.108、30 ns 1.258、50 ns 1.182、90 ns 0.772。

## 4. 読み取り（先に固定した読み方に沿う）

- 真ん中の予測幅 5・10・30・50 ns先では、0.1 ns の切り取りの平均だけで回復率 0.5 を超えた。最小の切り取りは 4つの予測幅すべてで 0.1 ns。0.5 ns まででも届かない予測幅はなかった。
- 1 ns先（0.570）や 90 ns先（0.590）と違い、真ん中の予測幅では 0.1 ns の切り取りだけで 0.745〜0.979 と、実履歴の利得の大半が戻る。5 ns先では 0.25 ns で 1.029 と実履歴を上回り、30・50 ns先でも 0.25 ns で 1.053・1.004 と実履歴を上回る。
- 切り取りを長くしても回復率は単調には上がらない。90 ns先では 0.25 ns の 0.825 から 0.5 ns の 0.658 へ下がる。5 ns先では 0.25 ns と 0.5 ns が 1.029・1.037 とほぼ同じで、0.25 ns より長くする意味はほとんどない。
- 30 ns先の利得は +0.0626 と 6つの予測幅の中で最も小さいため、回復率の分母が小さい点には注意が要る。ただし 0.1 ns の回復率 0.979 は、AUPRC では静的のみ 0.3639 から 0.4251 へ +0.0612 の上がりで、利得のほぼ全部にあたる量である。
- 0〜1 ns の平均だけの回復率は 90 ns先だけ 0.772 と 1 を下回るのに対し、真ん中の予測幅では 1.108〜1.258 と実履歴を上回る。90 ns先だけ形が違う。
