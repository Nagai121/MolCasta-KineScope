# K3-01: 側鎖の状態とずれの関係（強い土台、水素結合の形成）

## 問い

K3 系列の問いは「軌道が知っていて、静的構造が知らない、ペアの物理的な状態は何か」です。ずれ（0〜1 ns の平均距離の実測値から、静的構造だけの予測を引いたもの）をその主な現れとして扱います。ここでは、ペアの 2 つの残基とその隣の残基について、初期構造での側鎖の二面角（χ角）の状態が、ずれと関係するかを測ります。

読み方は実験前に固定しました。

- 相関の絶対値 0.3 以上を「関係あり」の目安にします（K2-03 と同じ）。
- 静的な予測にその量を足して、ずれのばらつきが 0.30 Å 以下になれば「ずれの大部分を説明できた」とします。下限は 0.249 Å です。
- 相関が高いだけでは正体とは言いません。原因の確認は後の手順で行います。

## 割り当て文の数値の訂正（統括からの連絡、2026-11-25）

割り当て文に書いた「ずれのばらつきは約 0.49 Å」は、資料D条件（K23）の値でした。K3 が使う強い土台（未見100タンパク質）では、記録の残差のばらつきは約 0.60 Å です（K44 のテスト側 0.6002 Å）。私の再現でもその値になりました（下の「ずれの再現」を参照）。判定の線（0.30 Å 以下、下限 0.249 Å）は先に固定した判断のまま変わりません。ただし下限 0.249 Å も資料D条件で測った値で、強い土台での測り直しは記録にありません。

## データと条件

- 強い土台（K06(b)）の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。水素結合の形成のペアです。
- ずれは K39・K42 の作り方です。実の平均（履歴10特徴の1列目、0〜1 ns の11フレームのドナー・アクセプター間距離の平均）を、静的な特徴5つ（本体の予測確率、起点距離、基礎記述子3個）から予測し、その差を取ります。予測は線形回帰と HistGradientBoosting 回帰（補正モデルと同じ設定）の2通りで、どちらも較正用の候補だけで当てはめ、テスト側の統計は使いません。
- χ角は、ATLAS の解析版の軌道から取った起点フレーム（フレーム10、1 ns の時点）の座標から計算します。静的な予測の入力は起点フレームなので、χ角も起点フレームで測るのが筋です（統括からの補足、2026-11-25）。距離はすべて、フレームごとの箱を軸ごとに扱う周期境界の最小イメージで測ります（K2-03 と同じ）。

## χ角の定義

- χ1 は N-CA-CB-X の二面角で、X は残基の種類で決まります（多くの残基で CG、Ser は OG、Cys は SG、Thr は OG1、Val・Ile は CG1）。χ2 は CA-CB-CG-Y、χ3 は CB-CG-CD-Z、χ4 は CG-CD-… の形で、残基の種類ごとに通常の定義を使います（下の表）。
- Gly と Ala には側鎖の二面角がありません。その χ は欠損として扱い、件数を記録します。χ を定義する原子のいずれかが欠けている場合も欠損です。
- 回転状態の区分は、角度 a（度、−180 < a ≤ 180）で次のように分けます：gauche+ は 0 < a ≤ 120、trans は a > 120 または a ≤ −120、gauche− は −120 < a ≤ 0。
- 測る残基は、ペアごとに6つです：供与体側の残基（D）、受容体側の残基（A）、D の配列上の前後の残基（Dm・Dp）、A の配列上の前後の残基（Am・Ap）。

|---|---|---|---|---|
| ARG | N-CA-CB-CG | CA-CB-CG-CD | CB-CG-CD-NE | CG-CD-NE-CZ |
| ASN | N-CA-CB-CG | CA-CB-CG-OD1 | — | — |
| ASP | N-CA-CB-CG | CA-CB-CG-OD1 | — | — |
| CYS | N-CA-CB-SG | — | — | — |
| GLN | N-CA-CB-CG | CA-CB-CG-CD | CB-CG-CD-OE1 | — |
| GLU | N-CA-CB-CG | CA-CB-CG-CD | CB-CG-CD-OE1 | — |
| HIS | N-CA-CB-CG | CA-CB-CG-ND1 | — | — |
| ILE | N-CA-CB-CG1 | CA-CB-CG1-CD1 | — | — |
| LEU | N-CA-CB-CG | CA-CB-CG-CD1 | — | — |
| LYS | N-CA-CB-CG | CA-CB-CG-CD | CB-CG-CD-CE | CG-CD-CE-NZ |
| MET | N-CA-CB-CG | CA-CB-CG-SD | CB-CG-SD-CE | — |

## ずれの再現

K39 の方法で作り直したところ、較正8タンパク質（13,808件）で当てはめ、テスト100タンパク質×3レプリカ（163,074件）で評価した残差は、線形回帰で R² 0.6262・標準偏差 0.6076 Å、HistGradientBoosting 回帰で R² 0.6352・標準偏差 0.6002 Å で、K39 の記録（`measure_results.json`）と小数第4位まで完全一致しました。強い土台でのずれのばらつきは約 0.60 Å です（割り当て文の 0.49 Å は資料D条件の値で、ここでは使いません）。

## 座標の取り直しの前提確認

χ角を取るために、108タンパク質（テスト100＋較正8）の ATLAS 解析版の軌道を、1タンパク質ずつ取り直しました。手元に残っていた29タンパク質は G05 の作業場所から読み、残りは取り直して処理後に消しました。取り直した座標から計算したドナー・アクセプター間距離が、K06(b) の保存値と一致することを、タンパク質ごとに全レプリカで確かめました（フレーム10の距離と 0〜10 フレームの平均の両方で、最大の差は 0.0 Å）。

## 結果

### 各量とずれの相関（起点フレーム、テスト163,074件）

χ角は角度なので、値そのものではなく sin・cos との相関を主に見ました。あわせて、sin・cos の両方で説明できる分（回帰の R）と、回転状態の区分ごとのずれの平均の違いも見ました。残りは GBM 回帰で作ったものを主に使い、線形回帰の残りでも同じ形になることを確かめました。6つの残基の位置 × χ1〜χ4 の24通りすべてで、相関の絶対値は 0.3 に遠く届きませんでした。

| 量 | 件数 | sin との相関 | cos との相関 | 両方での R | 区分ごとのずれの平均の最大の差 |
|---|---|---:|---:|---:|---:|
| 受容体側の残基 χ2 | 103,641 | +0.010 | −0.038 | 0.040 | 0.057 Å |
| 供与体側の残基 χ2 | 100,679 | +0.025 | +0.024 | 0.033 | 0.041 Å |
| 受容体側の残基 χ1 | 146,319 | +0.025 | +0.005 | 0.025 | 0.045 Å |
| 供与体側の残基 χ3 | 53,242 | −0.005 | −0.024 | 0.024 | 0.042 Å |
| 受容体側の残基 χ4 | 13,743 | −0.020 | −0.007 | 0.021 | 0.023 Å |
| 供与体側の残基 χ1 | 145,411 | +0.017 | +0.015 | 0.020 | 0.027 Å |

（上の表はいちばん大きい6通り。隣の残基の量はさらに小さく、最大でも両方での R が 0.021、区分の差が 0.039 Å でした。全24通りの数値は `correlations.csv` にあります。）

いちばん大きいのは受容体側の残基の χ2 の cos との相関 −0.038 で、区分ごとのずれの平均の差も 0.057 Å と小さいです。タンパク質ごとに見ても同じ形で、いちばん大きい3つの量のタンパク質ごとの相関の中央値は −0.039〜+0.028、相関の絶対値が 0.3 に届くタンパク質は 100 件中 0 件でした。線形回帰の残りでも、いちばん大きい相関は同じ受容体側の χ2 の cos（−0.037）でした。

χ角が定義できない割合（起点フレーム）：χ1 は供与体側で 10.8%、受容体側で 10.3%（主に Gly・Ala）。χ2 は 36〜41%、χ3 は 67〜74%、χ4 は 80〜92% が欠損で、χ が多い残基ほど定義できるペアが少なくなります。

### 静的な予測に χ角を足したときの、ずれのばらつきの変化

実の平均を予測する HistGradientBoosting 回帰（K39 と同じ設定、較正8タンパク質で当てはめ、テスト100タンパク質で評価）に、χ角を sin・cos にした量を足しました。静的な特徴5つだけでは、テストでの残りのばらつきは 0.6002 Å でした。

| 足した量 | 残りのばらつき | 静的な特徴だけとの差 |
|---|---:|---:|
| なし（静的な特徴5つだけ） | 0.6002 Å | — |
| χ角（6残基すべて、sin・cos） | 0.6004 Å | +0.0002 Å |
| χ角（供与体・受容体側だけ） | 0.5973 Å | −0.0029 Å |
| χ角（隣の残基だけ） | 0.6088 Å | +0.0086 Å |
| χ角（供与体側だけ） | 0.5988 Å | −0.0014 Å |
| χ角（受容体側だけ） | 0.5975 Å | −0.0027 Å |
| 回転状態の区分（供与体・受容体側、one-hot） | 0.5982 Å | −0.0020 Å |

χ角を足しても、残りのばらつきは 0.597〜0.609 Å の範囲で、静的な特徴だけの 0.6002 Å からほとんど動きません。0.30 Å の線には遠く届きません。回転状態の区分をそのまま入れた形でも同じでした（0.5982 Å）。

### 入れ替え対照

χ角の量を別のペアのものと入れ替えた場合、効果が消えることを確かめました。

- 相関の対照：テストのペアの χ角を全体で入れ替えると、全24通りでの相関の絶対値の最大は 0.012 まで下がりました（入れ替え前は 0.038）。
- ばらつきの対照：χ角を全部入れたモデル（較正側の χ角はそのまま）で、テスト側の χ角だけを入れ替えて評価すると、残りのばらつきは 0.6245 Å まで悪くなりました（全体での入れ替え。タンパク質の中での入れ替えでも 0.6240 Å）。較正側の χ角を入れ替えて当てはめ直した場合は 0.603 Å で、静的な特徴だけの 0.6002 Å とほぼ同じでした。

## 判定

先に固定した読み方に照らすと、答えは「側鎖の状態は、ずれの正体ではない」です。

- 相関は、24通りすべてで絶対値が 0.3 に届かず、最大でも 0.038 でした。タンパク質ごとでも 0.3 に届くものはありませんでした。
- 静的な予測に χ角を足しても、ずれのばらつきは 0.6002 Å から 0.5973 Å までしか下がらず、0.30 Å の線には遠く届きませんでした（下限は 0.249 Å）。
- 入れ替え対照では、相関の最大値は 0.012 まで下がり、ばらつきの側でも入れ替えると悪化しました。測った小さな相関（受容体側の χ2 の cos、−0.038）は、ペアと χ角の対応があっての値ではありますが、ずれの大きさ（0.60 Å）の説明にはなりません。

留保として、この測り方は χ角とずれの「一緒に動くか」と「足したときにばらつきが減るか」だけを見ています。χ角の状態がずれの成り立ちに関係しないことまでは言えません（たとえば他の量と組み合わさった関わりは、この測り方では拾えません）。先に固定した読み方の範囲では、側鎖の状態は候補として残りませんでした。
