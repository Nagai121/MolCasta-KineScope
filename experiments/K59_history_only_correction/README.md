# K59: 補正は、静的な特徴なしで履歴だけで利得が戻るか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。これまでの補正モデルは、静的な特徴と履歴の特徴を両方入れていました。静的な特徴を入れず、履歴の特徴だけで利得が戻るか確かめます。

読み方は実験前に固定しました。履歴だけで利得の8割以上が戻れば、履歴の特徴は静的な特徴なしで信号を持っています。戻らなければ、読み出しは静的な特徴との組み合わせが必要です。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、学習回数160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- 条件は3つです。静的な特徴だけの条件、静的な特徴＋実履歴の6統計量の条件、実履歴の6統計量だけの条件です。6統計量は、履歴10統計量のうち [最初、平均、ばらつき、最小、最後−最初、3.5 Å以下の割合] です。
- 利得は、評価する予測幅での静的な特徴だけの条件との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。参照する利得は、静的な特徴＋実履歴の6統計量の条件の利得です。戻り率は、履歴だけの条件の利得を、参照の利得で割った値です。
- 対照の確認: 静的な特徴だけの条件は K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。静的な特徴＋実履歴の6統計量の条件は、K12b の (a6) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。K06(b) の履歴10統計量の条件とは、6統計量と10統計量の違いだけの小さな差があります（1 ns先で AUPRC の差 0.0004、90 ns先で 0.0043）。

## 判断

先に固定した8割の線で見ると、**1 ns先だけが履歴だけで利得が戻ります（0.89）**。5 ns先では 0.68 と8割に届かず、10 ns先以降は急に落ちて、50・90 ns先では利得がほぼゼロかマイナスになります。90 ns先では、履歴だけの条件の AUPRC（0.4348）は、静的な特徴だけの条件（0.4418）だけでなく、凍結した本体だけ（0.4545）よりも低くなります。

つまり、履歴の特徴は、短い予測幅では静的な特徴なしでも信号を持っていますが、長い予測幅では信号を持ちません。長い予測幅では、読み出しは静的な特徴との組み合わせが必要です。1 ns先では平均が未来の距離に近いので、履歴の平均だけで予測がつきます。長い予測幅では、平均が低いのが「もともと近いから」なのか「近づいているから」なのかを、静的な特徴（もとの距離や凍結した本体の予測）がないと区別できない、という形です。
