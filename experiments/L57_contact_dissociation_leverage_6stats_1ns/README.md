# L57: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合を統計量6種で測る（資料Dの条件、接触の解離、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L21（接触の解離、1 ns先、切り取りの平均だけ）と同じ土台・同じ覆う長さで、統計量を平均だけから資料Dの6種に変えて曲がりを測る。
- 状態: 完了。統計量6種では、回復率は覆う長さ 0.2 ns で初めて 0.8 を超え（0.8923）、0.6 ns で 0.9 を超える（0.9378）。平均だけ（同じ実行で測り直し、L21 の記録と完全一致）と比べると、0.8・0.9 のどちらの線でも必要な長さは縮まなかった（平均だけではどちらも 0.1 ns）。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L21 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの統計量6種」を履歴の特徴量として資料Dの補正モデルに入れたときの 1 ns先の利得の回復率を測る。あわせて、同じ実行の中で平均だけの曲がりも測り直し、L21 の記録と一致するか確かめる。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの流儀で、3つの値（統合・1mix_A・2qt4_A）の回復率の最小から最大。テストは 2タンパク質だけなので区間は粗い。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、平均だけと比べて必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383行）、テスト 1mix_A＋2qt4_A 合算（2,915行、テスト陽性 207件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、種 42）で条件ごとに学習し直す。候補は、残基対の Cα 距離が 12.0 Å 以内で配列の隔たりが 2 以上、起点フレームで最小重原子間距離が 4.5 Å 以下（K50 の定義）。ラベルは、予測幅の先で最小重原子間距離が 4.5 Å を超えるかどうか。
- K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/` の 18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（24条件の学習で数分。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は L21〜L26 と同じく重い計算にはあたらないと判断した）。
- 特徴量の型は G71 と同じ作り方にそろえた（静的特徴を float64、切り取りの平均を float32、6統計量は float32）。L23〜L26 で、型の違いが覆う長さ 0.5 ns の回復率を G71 とずらすことが分かっているため。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0のみ、1.0 ns はフレーム 0〜10 の11フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先のまま。覆う長さ 1.0 ns の統計量6種は全部入りと同値になる。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_hist6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの統計量6種: 静的特徴＋切り取りの6統計量（最初・平均・標準偏差・最小・最後−最初・4.5 Å以下割合）。覆う長さ 0.0〜1.0 ns の11通り。
- 切り取りの平均だけ（照合用）: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。L21 の記録と照らす。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.2 ns**（統合 0.8923）。0.1 ns では 0.7001 と届かない。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.6 ns**（統合 0.9378）。0.2 ns では 0.8923 と線のすぐ下にとどまる。
3. **増え幅がいちばん大きい場所: 0.1→0.2 ns（統合 +0.1922）**。次に大きいのは 0.5→0.6 ns（+0.1900）で、曲がりは上下を繰り返し、1か所に段と呼べる跳ねはない。
4. 段の位置（0.1→0.2 ns）では、タンパク質ごとの増え分は 1mix_A が +0.1352（0.7045 → 0.8397）、2qt4_A が +0.3323（0.7041 → 1.0364）で、両方とも上がる。
5. **平均だけとの比べ方: 必要な長さは縮まなかった。** 0.8 の線は統計量6種で 0.2 ns、平均だけでは 0.1 ns。0.9 の線は統計量6種で 0.6 ns、平均だけでは 0.1 ns。どちらの線でも統計量6種のほうが長くかかる。

## 4. 読み取り

- **統計量6種にしても、短い切り取りでは平均だけに届かない。** 覆う長さ 0.1 ns では統計量6種の回復率が 0.7001 で、平均だけの 0.9188 を大きく下回る。0.2 ns で 0.8923 と上がるが、それでも平均だけの 0.1 ns の値には届かない。
- **曲がりは上下を繰り返す。** 0.2 ns で 0.8923 まで上がったあと 0.4 ns で 0.6892 まで下がり、0.6 ns で 0.9378、0.9 ns で 1.0269 とまた上がる。1か所に段と呼べる跳ねはない。
- 0.7 ns では回復率が 1.0001 と全部入りとほぼ同じになり、0.9 ns では 1.0269 と全部入りを超える。切り取りの統計量6種が、全部入りの6統計量と違う効き方をしている。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離の 1 ns先（資料D）では、統計量6種で回復率 0.8 に届く最小の覆う長さは 0.2 ns、0.9 に届く最小の覆う長さは 0.6 ns。平均だけ（0.8・0.9 とも 0.1 ns）と比べて、必要な長さは縮まなかった。増え幅がいちばん大きいのは 0.1→0.2 ns（+0.1922）で、1か所に段と呼べる跳ねはない。平均だけの曲がりは L21 の記録と完全一致した。
- まだ分からないこと: 短い切り取りで統計量6種が平均だけを下回る理由（統計量の数が増えて学習が不安定になるのか、短い区間では標準偏差や割合が意味を持たないのか）は、この測定だけでは切り分けられない。曲がりの上下が学習の揺れか本質かも、単一の学習 seed では切り分けられない。
