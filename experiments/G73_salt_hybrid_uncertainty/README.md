# G73: 塩橋の形成での混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。塩橋の形成では、G19 で 1 ns先に 4案すべてが +0.05 を超え（+0.190/+0.212/+0.108/+0.231）、G53 で 5 ns先に 3案が超え（第11案 +0.215、第12案 +0.253、第14案 +0.057）、G57 で 10 ns先に 2案が超え（第11案 +0.069、第14案 +0.090）ました。30 ns先ではどの案も届きませんでした（G58）。1・5・10・30 ns先 × 第11〜14案について、混合と切り取り平均だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G49・G59・G62・G67 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（1 ns の 4案、5 ns の 3案、10 ns の 2案）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの塩橋の形成で、K15 の広げた条件（88タンパク質）です。K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/`、起点の荷電原子間距離 4.0 Å 以下の候補、ラベルは予測幅で 4.0 Å より大きい）と、G19 で作り直した第11〜14案の生成系列（`experiments/G19_salt_prefix_plus_generated/gen/`、K17 と同じ作り方で塩橋の候補向けに作り直したもの）を使いました。学習 58タンパク質（2,557件）、テスト 30タンパク質（1,170件）。静的特徴は5個、履歴は荷電原子間距離の系列の6統計量（4.0 Å 以下だった割合）です。テストのタンパク質分けは `experiments/K15_saltbridge_expansion/split.json` の通りです（2hng_A のレプリカ3と 4cv4_A のレプリカ2は候補が 0件です）。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）で、平均はその2フレームの荷電原子間距離の平均です（G02・G19 と同じ）。生成平均は、G19 で作り直した分岐平均の9点系列の9点の平均です。対応付けは、生成系列の残基ペア（res_i・res_j）が K15 のキャッシュと一致することを確かめた上で、位置で対応付けました（G53 と同じ）。生成器のチェックポイントは読み込んでいません。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、生成平均だけ（第11〜14案）、混合（切り取り平均＋生成平均の2列、第11〜14案）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G19 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G49・G59・G62・G67・G23 と同じです。
- 再標本化の単位: タンパク質。テストは 30 タンパク質なので、30 タンパク質から復元抽出で 30 タンパク質を選び直す、ふつうのブートストラップです。2 タンパク質の土台（G49・G59・G62・G67）のような「取りうる組み合わせは3通りしかない」という粗さはありません。ブートストラップ分布が取る異なる値は 10,000通り（全16セルで 10,000）でした。区間は 2 タンパク質の土台よりは細かい、という留保を記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G19・G53・G57・G58 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: 1回の抽出につき行の集合を1回だけ作り、静的のみ・全部入り・切り取り平均だけの AUPRC は予測幅ごとに1回だけ測って4案で使い回しました。AUPRC の計算は sklearn の average_precision_score と同じ段取り（しきい値で区切って精度と再現率を取り、再現率の増え分で重み付けする）を numpy で書き直したもので、実際の予測確率で sklearn の値と 1e-12 まで一致することを確かめてから使いました。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

### 土台の再現

4つの予測幅すべてで、静的のみ・全部入り・切り取り平均だけ・生成平均だけ（第11〜14案）・混合（第11〜14案）の合算 AUPRC が G19・G53・G57・G58 の記録と小数第4位まで一致しました。実履歴の利得は、1 ns先 +0.1440、5 ns先 +0.0788、10 ns先 +0.0594、30 ns先 +0.0884 です。

### 4つの予測幅 × 第11〜14案の差とブートストラップ 95% 区間

太字は +0.05 を超えたセル（先に固定した読みの対象）です。

| 予測幅 | 第11案 | 第12案 | 第13案 | 第14案 |
|---|---:|---:|---:|---:|
| 1 ns | **+0.190 [−0.080, +0.949]** | **+0.212 [−0.108, +0.968]** | **+0.108 [−0.228, +0.644]** | **+0.231 [−0.046, +1.008]** |
| 5 ns | **+0.215 [−0.293, +1.229]** | **+0.253 [−0.027, +1.764]** | −0.073 [−0.925, +0.528] | **+0.057 [−0.439, +1.034]** |
| 10 ns | **+0.069 [−0.879, +1.361]** | +0.012 [−0.802, +1.126] | −0.394 [−2.327, +0.523] | **+0.090 [−0.664, +0.939]** |
| 30 ns | −0.311 [−0.766, −0.033] | −0.221 [−0.484, +0.034] | −0.132 [−0.476, +0.175] | −0.149 [−0.502, +0.099] |

テスト陽性は、1 ns先 93件、5 ns先 129件、10 ns先 131件、30 ns先 133件です。

### タンパク質ごとの差（回復率の差）

タンパク質ごとに差を測ると、どのセルも正と負が半々ほどに分かれます。1 ns先の第11案は 26タンパク質のうち正が 9、第12案は 11、第13案は 7、第14案は 14。5 ns先の第11案は 17、第12案は 12、第14案は 10。10 ns先の第11案は 16、第14案は 14。30 ns先の第11案は 13、第12案は 13、第13案は 15、第14案は 11 です（陽性が 0件のタンパク質は測れないため、1・5・30 ns先で 26タンパク質、10 ns先で 25タンパク質が対象です）。

タンパク質ごとの差の大きさも、セルによっては極端に振れます。1 ns先の第11案は最小 −152.00、最大 +6.09。第13案は最小 −180.00、最大 +0.92。10 ns先の第13案は最小 −37.98、最大 +25.53、第14案は最小 −41.86、最大 +9.77 です。これは、タンパク質ごとの実履歴の利得（回復率の分母）が 0 に近いタンパク質があり、回復率の割り算が爆発するためです。合算の区間が広いのも、同じ理由です（下の「読みの注意点」を参照）。

## 判断

先に固定した読み方に沿うと、+0.05 を超えた9セルのうち、**区間が 0 を含まないセルは1つもありません**。1 ns の4案、5 ns の3案、10 ns の2案の区間は、すべて 0 を含みます。

塩橋の形成で「混合が足しになる」と読めた 1・5・10 ns先のセルは、タンパク質単位の再標本化では向きが定まりません。区間が広いのは、タンパク質ごとの実履歴の利得が 0 に近いタンパク質があり、回復率の分母が標本によって大きく変わるためです（上のタンパク質ごとの差を参照）。タンパク質ごとの差も正と負が半々ほどに分かれ、どのセルもタンパク質の過半数で正にはなっていません（いちばん多い 5 ns先の第11案でも 26タンパク質のうち正が 17）。

+0.05 を超えなかったセルでは、30 ns先の第11案だけが区間も 0 を含まず負です（[−0.766, −0.033]）。30 ns先の第12〜14案の区間は 0 を含みます。

## 読みの注意点

- **テストは 30 タンパク質なので、区間は 2 タンパク質の土台よりは細かいものです。** ブートストラップ分布が取る異なる値は 10,000通り（全16セルで 10,000）で、区間は 3値の最小値〜最大値ではありません。ただし、区間の幅そのものは 2 タンパク質の土台より広くなりました（たとえば 5 ns先の第12案は [−0.027, +1.764]）。これは、タンパク質ごとの実履歴の利得が 0 に近いタンパク質があり、回復率の分母が標本によって大きく変わるためです。区間が細かい（取りうる値が多い）ことと、区間が狭いことは別です。
- テスト陽性が少ないことも、区間の広さに関わります（1 ns先で 93件、30タンパク質のうち 4タンパク質は陽性が 0件）。陽性が 0件のタンパク質は、タンパク質ごとの差が測れません（上の表では対象外です）。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約14分かかりました（ほかのスレッドの重いジョブと CPU の取り合いになっていたため。最初の実行は途中で止まり、やり直しました）。

## ファイル
