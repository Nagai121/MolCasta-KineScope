# G162: 塩橋の形成で、起点のフレームを入れるかどうかでの平均だけの回復率の差に、区間を付ける（K15 の広げた条件、塩橋の形成、1・5・10・30・50・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G154 で、フレーム [0..9] の 10 フレームの平均だけ（mean10）とフレーム [0..10] の 11 フレーム全部の平均だけ（mean11）の回復率の差が、1 ns先 −0.083、5 ns先 −0.283、10 ns先 −0.052、30 ns先 +0.098、50 ns先 +0.517、90 ns先 −0.195 でした。ここでは 6 予測幅すべてについて、その差のブートストラップ 95% 区間を出します（G147・G148 と同じ段取り）。
- 状態: 完了。回復率の差の区間が 0 を含まない予測幅はなく、6 予測幅すべてで区間が 0 を含みました。AUPRC の差の区間も 6 予測幅すべてで 0 を含みました。

## 1. 2 つの条件の定義（結果を見る前に固定）

- 軌道の保存間隔は 100 ps（0.1 ns）。フレーム k は時刻 k*0.1 ns。
- **mean10（フレーム [0..9] の 10 フレームの平均だけ）**: 実際に覆う長さは 0.9 ns で、起点フレーム 10 は入らない。G139 の「切り取り 1.0 ns の平均だけ」と同じ。
- **mean11（フレーム [0..10] の 11 フレーム全部の平均だけ）**: 0〜1 ns の履歴全部で、起点フレーム 10 が入る。実際に覆う長さは 1.0 ns。
- 平均だけの条件は、他の履歴統計量を入れずに平均の列だけを足す K21 の形。起点フレーム10（1 ns）は変えない。条件は「静的特徴＋平均だけ」。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（その予測幅での実履歴の利得）。回復率の差 = mean11 の回復率 − mean10 の回復率。AUPRC の差 = mean11 の AUPRC − mean10 の AUPRC。

## 2. 土台の再現と利得の出所

- 土台は K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/`、88タンパク質分）と `split.json` の分け方を再利用。K15 の広げた条件（学習58タンパク質で候補 2,557件、テスト30タンパク質で候補 1,170件、テスト陽性は幅ごとに93〜149件）。
- 塩橋形成の定義は、正側 LYS NZ / ARG NE・NH1・NH2、負側 ASP OD1・OD2 / GLU OE1・OE2 の荷電重原子間最小距離で、候補は起点（フレーム10、1 ns）で 4.0 Å超〜10.0 Å以下、配列距離2以上、ラベルは予測先で 4.0 Å以下。静的特徴5個。履歴閾値 4.0 Å。
- 土台の利得は K15 の記録値（`experiments/K15_saltbridge_expansion/results.json` の静的のみと全部入りの AUPRC の差）で、再計算でも一致した。1 ns +0.144、5 ns +0.079、10 ns +0.059、30 ns +0.088、50 ns +0.027、90 ns +0.060。
- モデルを学習し直した AUPRC は、G154 の記録と 6 予測幅すべてで小数第4位まで完全一致した（静的のみ・全部入り・mean10・mean11 のいずれも差は 0.0005 未満。コード内の assert で確認）。1 ns先で静的のみ 0.2402、全部入り 0.3842、mean10 0.3802、mean11 0.3682。90 ns先で静的のみ 0.2136、全部入り 0.2736、mean10 0.2529、mean11 0.2411。
- K15 の欠けについて: 2hng_A の R3 と 4cv4_A の R2 はキャッシュで候補が0件だったため、テスト側は約20件（約2%）欠けている（K15 の記録の通りで、K15・K19 の結果と結論には影響しないとされている）。G162 も同じキャッシュを使うため、同じ欠けを含む。
- 実行はローカルVMのみ。HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、seed 42）。実行時間は約4分（`~/workspace/mt-venv/bin/python`、sklearn 1.9.1、スレッド数は 1 に絞った）。

## 3. 区間の計算方法（結果を見る前に固定）

- 再標本化の単位はタンパク質。テストは 30 タンパク質（K15 の広げた条件のテスト分け）なので、2 タンパク質の土台（G49・G59・G62・G67）のような「取りうる組み合わせは3通りしかない」という粗さはない。30 タンパク質から復元抽出で 30 タンパク質を選び直す、ふつうのブートストラップである。区間は 2 タンパク質の土台よりは細かい、という留保を記録する（G73・G96・G147・G148 と同じ留保）。
- ブートストラップの回数と乱数 seed は結果を見る前に固定した: 10,000回、seed 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G73・G49・G59・G62・G67・G23・G147・G148 と同じである。
- 回復率の差の区間の計算では、各ブートストラップ標本の中で、静的のみ・全部入り・mean10・mean11 の AUPRC を測り直し、利得（全部入り − 静的のみ）と 2 つの回復率をその標本の中で計算し直してから差を取る。つまり回復率の分母の土台の利得は、標本ごとに測り直す（G147・G148 と同じ）。全体の利得で固定してはいない。
- AUPRC の計算は、sklearn の average_precision_score と同じ段取り（しきい値で区切って精度と再現率を取り、再現率の増え分で重み付けする）を numpy で書き直したもので、実際の予測確率で sklearn の値と 1e-12 まで一致することを確かめてから使った（コード内の assert で確認）。
- 候補ごとの予測確率は、ブートストラップの前に `test_predictions.npz` に保存した。
- タンパク質ごとの記録: そのタンパク質に陽性が1件もない予測幅では、AUPRC は定義されない。sklearn は警告を出して 0.0 を返すが、ここでは nan と記録する。陽性が0件のタンパク質は、1 ns先で 4/30、5 ns先で 4/30、10 ns先で 5/30、30 ns先で 3/30、50 ns先で 5/30、90 ns先で 5/30 だった。
- 10,000回の抽出はすべて異なる値だった（回復率の差・AUPRC の差とも 6 予測幅すべてで n_distinct = 10,000）。2 タンパク質の土台のような 3 通りだけの粗さはない。

## 5. 読み取り（先に固定した読み方に沿う）

- **区間の水準でも差があると言える予測幅はありません。** 回復率の差の区間が 0 を含まない予測幅は 1 つもなく、AUPRC の差の区間が 0 を含まない予測幅も 1 つもありません。G154 で点推定が大きく見えた 50 ns先（+0.517）も 5 ns先（−0.283）も、区間の水準では差があるとは言えません。
- **50 ns先の回復率の差の区間 [+0.517 の点推定に対して −5.607〜+4.840] は、土台の利得の小ささで大きく広がっています。** 50 ns先の土台の利得は +0.0274 と 6つの予測幅の中で最も小さく、標本の中で利得が 0 に近づくと回復率の差が大きく振れます。AUPRC の差で見ても、50 ns先は [−0.0060, +0.0370] と 0 を含みます。回復率の差 +0.517 は AUPRC の差では +0.0142 と小さく、回復率の大きさほど大きな違いではない点は G154 と同じ留保です。G147 の 30 ns先 [−2.308, +4.937] や G148 の 30 ns先 [−2.773, +5.570] と同じく、利得の小ささで回復率の区間が発散する形です。ただし G162 では、発散するのが回復率そのものではなく 2 つの回復率の差で、区間はさらに広くなっています（[−5.607, +4.840]）。
- 5 ns先・10 ns先・90 ns先の回復率の差の区間も、[−1.426, +0.180]、[−1.453, +0.674]、[−1.797, +0.663] と広く、点推定の −0.283・−0.052・−0.195 に対して区間が大きく広がっています。1 ns先の区間 [−0.800, +0.239] も、点推定の −0.083 に対して広いです。30 ns先だけが [−0.273, +0.355] と比較的狭く、点推定の +0.098 に対して区間も狭いです。
- AUPRC の差の区間は、回復率の差の区間よりはずっと狭く、6 予測幅すべてで幅が 0.04〜0.09 です。それでも 0 を含まない予測幅はありません。つまり、起点のフレームを入れるかどうかで平均だけの AUPRC が変わること自体が、タンパク質の水準では断定できません。

## 6. G147・G148（塩橋の解離の区間）との比較

- G147（塩橋の解離、切り取り 1.0 ns の平均だけの回復率の区間）では、回復率の区間が 0.5 を含まなかったのは 1 ns先と 10 ns先で、AUPRC の差の区間が 0 を含まなかったのは 1・5・10・50 ns先でした。G148（塩橋の解離、切り取り 1.0 ns の 6 統計量の回復率の区間）では、回復率の区間が 0.5 を含まなかったのは 1・5・10 ns先で、AUPRC の差の区間が 0 を含まなかったのは 1・5・10・50 ns先でした。
- G162（塩橋の形成、起点のフレームを入れるかどうかでの平均だけの回復率の差の区間）では、回復率の差の区間が 0 を含まない予測幅は 1 つもなく、AUPRC の差の区間が 0 を含まない予測幅も 1 つもありません。G147・G148 では「切り取りが利くかどうか」の区間が一部の予測幅で 0.5 や 0 を含みませんでしたが、G162 では「起点のフレームを入れるかどうかでの差」の区間がどの予測幅でも 0 を含みます。測っている量が違う（回復率そのものと、2 つの回復率の差）ため、直接の比較ではありませんが、起点のフレームの入れ方での差は、切り取りそのものの利きよりもタンパク質の水準では弱い、という読みができます。
- 50 ns先の区間の広がりは、G147・G148 と同じく土台の利得の小ささが原因です。G147 では 30 ns先と 90 ns先の回復率の区間が [−2.308, +4.937] と [−0.860, +3.140]、G148 では 30 ns先と 90 ns先が [−2.773, +5.570] と [−0.691, +2.847] と広がりました。G162 では 50 ns先の回復率の差の区間が [−5.607, +4.840] と、さらに広くなっています。

## 7. 起点のフレームを入れることの正当性について

- フレーム 10 の距離（履歴の最後の値）は、静的特徴の 0 列目にも入っている。K15 の抽出コードでは静的特徴の 0 列目は履歴の最後の値（フレーム 10 の距離）で、今回の再計算でも静的特徴の 0 列目と履歴の最後の値の差の最大値は学習側・テスト側とも 4.8e-07 Å だった（G154 の記録と同じ）。つまり mean11 の条件は、静的特徴にすでに入っているフレーム 10 の距離を、平均の形でもう一度（重み 1/11 で）入れる形になる。2 つの条件の比べは「新しい情報を足すかどうか」ではなく「平均の作り方をどうするか」の比べである。
- 起点のフレーム（フレーム 10）は予測時点そのものの構造なので、静的な入力の一部として入れるのは正当である。これは設計上の判断であって、実験の結果そのものではない。平均にフレーム 10 を入れるかどうかは、その判断の範囲の話である。
