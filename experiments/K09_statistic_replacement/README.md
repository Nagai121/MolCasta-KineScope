# K09: 統計量を1つずつ実系列の値に差し替える

## 仮説

H5/H6（特徴量の抽出と読み出し、運動の生成そのもの）の検証です。K07 で揺らぎの大きさは主因ではなく、K08 で平均の水準のずれも主因ではないことが分かりました。残る候補は、平均と組み合わさる個々の統計量の作られ方（最小値、3.5 Å 以下にいた割合など）です。そこで、生成系列から作った統計量を1つずつ実系列の統計量に差し替え、指導力がどこまで戻るかを測ります。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量（7個）、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算（候補は学習 9,610件、テスト 4,972件、合計 14,582件）。水素結合形成、起点 1 ns（フレーム10）、予測幅 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- モデルは条件ごとに学習し直す比較です（HistGradientBoosting、反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）。変えたのは履歴の6統計量のうち1つだけです。

### 系列の定義と対応付け

- 生成系列: K05 で作り直した第22案の経路（`experiments/K05_generated_quality/generated_series.npz`）の5点系列です。起点距離 d0（フレーム10、1 ns）＋前方4時点（+0.1、+0.3、+0.5、+1.0 ns）。保存済みの生成系列を使ったため、生成器のチェックポイントの読み込みは行っていません。
- 実系列（5点）: 土台の履歴11フレームからフレーム [0, 1, 3, 5, 10] を取ったものです。時刻は 0, 0.1, 0.3, 0.5, 1.0 ns で、起点までの履歴（後方）です。最後の点が起点距離 d0 です。
- 対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、K08 と同じく土台候補 14,582 件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は約 6e-7 Å でした。
- 6統計量は両系列に同じ定義で計算します: [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下だった割合]。
- 対照の確認: 静的のみと実履歴（11点）は土台と完全一致しました（1 ns先で静的のみ AUPRC 0.3637、実履歴 0.4815）。

### 時間の向きの違い（重要な留保）

- 生成系列は起点から先への前方系列、実系列の5点は起点までの後方（履歴）系列です。両者は起点距離 d0 を共有する1 ns幅の系列ですが、時間の向きが逆です。したがって「最初の値」は生成では d0、実ではフレーム0（0 ns）の距離であり、「最後−最初」も向きが逆の量です。統計量の差し替えは、向きの違う系列の間の値の置き換えとして行っています。
- この扱いは K06(a) の流儀と同じです（生成の前方系列の統計量を履歴特徴の位置に置く）。向きの違い自体の効果は本実験では分離していません。

### 条件

- 静的のみ（S）、生成5点（S+G5、回復率の基準）、実5点（S+H5、対照）、実履歴11点（参照）。
- 差し替え6条件: 生成の6統計量のうち1つだけを実5点の値に置き換えます。対象は 最小値、3.5 Å 以下割合、平均、標準偏差、最後−最初、最初 の6つです。学習側・テスト側の両方に同じ差し替えを適用し、条件ごとに学習し直します。
- 回復率 =（差し替え条件の AUPRC − 生成5点の AUPRC）÷（実5点の AUPRC − 生成5点の AUPRC）です。分母が小さい予測幅では回復率が不安定になるため、AUPRC の絶対値も併記します。

## 判断できること

読み方は実験前に固定したとおりに判定します。主に 1 ns先（分母 0.0828 で最も安定）で判断します。

- 平均の差し替えだけで回復率は 1.078 で、事前に固定した目安の 0.8 を超えました。平均の統計量が喪失の主な担い手という読みを支持します。平均だけを実系列の値に戻すと、生成5点の利得の不足分がほぼ完全に戻ります（AUPRC 0.3999 → 0.4891、実5点 0.4827 をやや上回ります）。
- 3.5 Å 以下割合の差し替えも回復率 0.804 で、目安の 0.8 にちょうど届きました。最小値は 0.510 で半分ほど、最初は 0.373、最後−最初は 0.298、標準偏差は 0.047 とほぼ回復しませんでした。
- 標準偏差の差し替えがほぼ何も戻さないことは、K07（揺らぎの大きさは主因ではない）と合います。生成系列の揺らぎの小ささは、この6統計量の読み出しの範囲では指導力の喪失の原因ではありません。
- K08 と合わせた読み: K08 では実系列の平均を生成側の平均に置き換えても残存率 0.779 が残りました。本実験では逆に、生成の平均を実平均に戻すと回復率 1.078 まで戻ります。つまり平均の統計量は情報の主な通り道で、生成器の平均の推定はそれなりに良い（順位を保つ）が、実平均との差が利得の不足分の大半を説明する、ということです。割合（3.5 Å 以下）の回復も、平均と強く結びついた量であることと整合します。

## まだ分からないこと

- 6統計量は互いに相関するため、単独差し替えで回復しないことは、その統計量が無関係であることの証明にはなりません。特に平均と 3.5 Å 以下割合、最小値は結びついており、どれか1つが「真の」担い手かは本実験だけでは分離できません。複数を同時に差し替える実験は本実験の範囲外で、次の実験の候補です。
- 30 ns・50 ns先の回復率は分母が小さい（50 ns先では 0.0192）ため不安定で、1 を大きく超える値が複数出ています。この幅の回復率は絶対値と合わせて読む必要があり、単独の数値として解釈できません。90 ns先では最小値の差し替えの回復率が 1.334 と高く、長幅では最小値の側も効く可能性がありますが、同じく分母が小さいため確証はありません。
- 生成系列と実系列は時間の向きが逆であるため（前節を参照）、差し替えた統計量の意味が向きによって変わる可能性があります。例えば「最初」は生成では起点距離、実では 0 ns の距離です。向きをそろえた比較（生成系列と実継続の前方系列）では結果が変わる可能性があります。
- 回復率が 1 を超える条件があります（平均の差し替えで 1 ns先 1.078 など）。生成の他の統計量と実の平均の組み合わせが、実系列そのものよりわずかに良く働く場合があることを示しますが、単一の学習 seed の結果であり、ばらつきの範囲は測っていません。

## コードと出力

- `run_experiments.py`: 本実験のコードです。土台のキャッシュ（候補・静的特徴・距離系列）と K05 の `generated_series.npz` を読み、生成5点と実5点の6統計量、6通りの差し替え、学習・評価を行います。
- `results.csv` / `results.json`: 全条件・全予測幅の全指標、および AUPRC の回復率です。
- 実行はこの仮想マシン上です（`~/workspace/mt-venv/bin/python`、sklearn 1.9.1）。
