# K2-122: K2-14 の問い（割合の前半と後半）を強い土台での水素結合の解離の 50 ns先で測る（強い土台、未見 100 タンパク質×3 レプリカ、水素結合の解離、50 ns先、割合だけ）

- 確かめる問い: 割合の前半と後半は、強い土台での解離では 1 ns先（K2-117）、5 ns先（K2-119）、90 ns先（K2-118）で測り終えた。ここでは割合の前半と後半を 50 ns先で測る。
- 状態: 完了。**前半 0.773 / 0.782 / 0.778、後半 0.509 / 0.525 / 0.518（合算 / タンパク質×レプリカごとの平均 / タンパク質ごとの平均、全部入りの利得に対する割合）と、読み方のどちらにも当てはまらなかった。** 分母を全部の割合の利得にしても、前半 0.894 / 0.895 / 0.886、後半 0.589 / 0.601 / 0.590 と、どちらにも当てはまらない。タンパク質ごとでは「今の状態」1、「続いている状態」5、どちらでもない 80、利得が小さく判定から外したもの 14 である。

## 1. 何を確かめる実験か

強い土台（未見 100 タンパク質×3 レプリカ）の条件で、水素結合の解離、50 ns先、割合だけ。割合は、ペアが境界（3.5 Å）より近い時間の割合である。静的な特徴量に、つぎのどれか 1 つを足した形で比べる。

- 前半（フレーム [0..4]）の割合
- 後半（フレーム [6..10]）の割合
- 前半と後半の両方（2 つの割合を並べたもの）
- 全部（フレーム [0..10]）の割合

読み方は結果を見る前に固定した（K2-01 と同じ）。

- 割合の分母は全部入りの利得（静的＋実履歴 10 特徴の利得）を主とし、あわせて全部の割合の利得に対する割合も記録する（分母の確認のため）。
- 後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。
- 合算とマクロ（タンパク質×レプリカごとの平均と、タンパク質ごとの平均の両方）で判定が分かれる場合は、両方を記録する。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録する。

## 2. 条件

- 土台は強い土台（K06(b) の条件、K75 の条件）。凍結した本体モデル T1I2006 + HistGradientBoosting の補正モデル（160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）。較正タンパク質 8つ（6,144件）で学習し、未見の100タンパク質×3レプリカ（76,342件、テスト陽性 16,110件）で評価する。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 50 ns先。
- 入力は K2-18 の `input_bundle.npz`（K75 のキャッシュの静的な特徴・履歴・ラベルと、軌道から取り直した 11 フレームの系列をまとめたもの。K2-18 のディレクトリに置いてある、コミット済みのファイル）をそのまま使った。ラベルは 6 つの予測幅すべて入っているため、50 ns先は HIDX=4 で読んだ。
- 実行前の確認：系列から計算した平均がキャッシュの history の 1 列目と、系列から計算した 3.5 Å 以下の割合が history の 7 列目と一致することを確かめた（較正・テストとも、平均は最大の差 1.43e-06 以下、割合は最大の差 2.71e-08）。強い土台の実履歴 10 特徴の並びは [最初, 平均, 標準偏差, 最小, 最大, 最後−最初, ?, 3.5 Å以下割合, 4.5 Å以下割合, ?] である（K2-112 で形成の側で確かめたものと同じ）。
- 実行はローカルVM（6 条件の学習で 2 分ほどで終わったため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 前半と後半の定義（K2-01 と同じ）

| 名前 | フレーム | 時刻の範囲 |

### 記録の訂正

実行スクリプトと results.json の `horizon_ns` が 5 になっていた（K2-119 のスクリプトを写したときの残り）。数値そのものは 50 ns先のものである（テスト陽性 16,110件、土台の再現が K75 の 50 ns先の対角の値と一致）。スクリプトと results.json の `horizon_ns` を 50 に直した。K2-48・K2-25 と同じ種類の記録の誤りである。

前半 0.773 / 0.782 / 0.778、後半 0.509 / 0.525 / 0.518 と、**合算でもマクロでも、読み方のどちらにも当てはまらなかった。** 分母を全部の割合の利得にしても、前半 0.894 / 0.895 / 0.886、後半 0.589 / 0.601 / 0.590 と、どちらにも当てはまらない。数値をそのまま記録する。

## 5. K2-117（1 ns先）・K2-119（5 ns先）・K2-118（90 ns先）との比較

| 予測幅 | 前半の割合（合算） | 後半の割合（合算） | 読み方 |
|---|---|---|---|
| 1 ns先（K2-117） | 0.720 | 0.668 | どちらでもない |
| 5 ns先（K2-119） | 0.706 | 0.680 | どちらでもない |
| 10 ns先（K2-120） | 0.849 | 0.654 | どちらでもない |

| 90 ns先（K2-118） | 0.781 | 0.458 | どちらでもない |

強い土台での解離の割合の前半と後半は、1・5・10・50・90 ns先のどれでもどちらにも当てはまらない。ただし、後半の割合は 1・5・10 ns先では 0.65〜0.68 だったのに対し、50 ns先では 0.509、90 ns先では 0.458 と、長い予測幅で下がっていく。前半の割合は 0.71〜0.85 で、10 ns先が 0.849 と最も大きい。タンパク質ごとの形の数え上げも、1 ns先（今の状態 7、続いている状態 10、どちらでもない 81、除外 2）・5 ns先（4 / 15 / 74 / 7）・10 ns先（3 / 18 / 69 / 10）・90 ns先（2 / 7 / 70 / 21）と比べ、50 ns先は「今の状態」1・「続いている状態」5・どちらでもない 80・除外 14 で、「続いている状態」に当てはまるタンパク質が最も少ない。
