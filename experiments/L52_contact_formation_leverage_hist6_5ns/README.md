# L52: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（統計量6種の形、資料Dの条件、接触の形成、5 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L16（平均だけの形）と同じ土台・同じ覆う長さで、切り取りの履歴の特徴量を平均だけから資料Dの6統計量に変えて、接触の形成の 5 ns先の曲がりを測る。
- 状態: 完了。統計量6種では、回復率 0.8 に届く最小の長さは覆う長さ 0.3 ns（平均だけは 0.8 ns）、0.9 に届く最小の長さは 0.4 ns（平均だけでは届かなかった）。増え幅がいちばん大きいのは 0→0.1 ns（+0.1735）だが、タンパク質ごとでは符号が分かれる。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L16 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの6統計量」を履歴の特徴量として資料Dの条件のモデルに入れたときの 5 ns先の利得の回復率を測る。同じ実行の中で平均だけの曲がりも測り直し、L16 の記録と一致するか確かめる。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、全体で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、全体・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

あわせて、平均だけと比べて必要な長さが縮んだか、届かなかった予測幅で届くようになったかを記録する。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 214件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 5 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（24条件の学習で約40〜60秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01・L16 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（5 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの6統計量: 静的特徴＋切り取りの6統計量（最初・平均・標準偏差・最小・最後−最初・4.5 Å以下の割合）。覆う長さ 0.0〜1.0 ns の11通り。覆う長さ 1.0 ns では全部入りと同じ条件になり、回復率は 1 になります。
- 切り取りの平均だけ（照合用）: L16 と同じ条件を測り直したもの。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns**（全体 0.8797）。平均だけ（L16）では 0.8 ns だったので、0.5 ns 縮みました。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.4 ns**（全体 0.9792）。平均だけでは 0.9 に届かなかった（最大 0.8491）ので、新たに届くようになりました。
3. **増え幅がいちばん大きい場所: 0→0.1 ns（+0.1735）**。次に大きいのは 0.1→0.2 ns（+0.1254）です。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1939（静的のみ 0.3480、全部入り 0.5419）、2qt4_A が +0.3140（静的のみ 0.1833、全部入り 0.4973）で、2qt4_A の利得のほうが大きい。

段の位置（0→0.1 ns）でのタンパク質ごとの回復率は、1mix_A が 0.2539 → 0.5128（+0.2589）、2qt4_A が 0.8942 → 0.7952（−0.0990）で、符号が分かれます。統合値の段は主に 1mix_A 側の形です。なお覆う長さ 0 ns では、6 種と平均だけは同じ条件に近く、回復率はどちらも 0.4876 で一致しました。

### 平均だけとの比較

- 平均だけ（L16）との比較: 0.8 の線は 0.8 ns → 0.3 ns に縮み、0.9 の線は「届かない」から 0.4 ns で届くようになりました。同じ長さで比べると、6 種の回復率は平均だけを全長さで上回ります（0.3 ns で 0.8797 対 0.7713、0.4 ns で 0.9792 対 0.7820 など）。
- 平均だけでは 0.2 ns 以降ほぼ平らで 1.0 ns に落ち込みがあったのに対し、6 種では 0.3 ns 以降 0.87〜1.01 の範囲で推移します。

## 4. 読み取り

- 接触の形成の 5 ns先では、統計量 6 種で必要な長さが大きく縮み、平均だけでは届かなかった 0.9 の線にも届きました。
- ただし増え幅最大の区間（0→0.1 ns）はタンパク質ごとで符号が分かれ、統合値の段をそのまま一般の形とは読めません。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
