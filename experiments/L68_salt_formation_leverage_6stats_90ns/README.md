# L68: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、90 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L32（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分のうち、形成はここまでです（L63〜L68）。
- 状態: 完了。形成の6つの予測幅で初めて、必要な長さが縮みました。0.9 の線に届く最小の長さは統計量6種で 0.2 ns、平均だけでは 0.8 ns でした（0.8 の線はどちらも 0 ns）。回復率も 0.2 ns 以降のほとんどの長さで平均だけを上回りました。

## 1. 何を確かめる実験か

L63 と同じ段取りで、予測幅だけを 90 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、90 ns先の陽性 149件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0 ns（全体 0.846）**。平均だけも 0 ns で、縮みは 0 でした。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.2 ns（全体 1.036）**。平均だけでは 0.8 ns で、**0.6 ns 分縮みました**。形成の担当分で初めての縮みです。
3. **増え幅がいちばん大きい場所: 0.1→0.2 ns（全体 +0.850、平均 +0.507）**。段の位置でのタンパク質ごとの増え分は中央値 +0.299、正だったのは 18タンパク質のうち 72% でした。ただし 0.1 ns の落ち込み（0.187）からの戻りでもあり、段というより谷の両側と読むほうが自然です。
4. 長さごとの回復率の差（6種 − 平均、全体）は、0.1 ns（−0.467）を除いて正で、0.5 ns で +0.744、1.0 ns で +0.541 でした。平均だけの曲がりが長い側で下がる（L32）のに対し、6種は水準を保ちます。L65（10 ns先）と同じ形です。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 形成の6つの予測幅を通すと、統計量6種が必要な長さを縮めたのは 90 ns先の 0.9 の線だけでした。1・5・30 ns先では長くなり、10 ns先と 50 ns先は読みの対象として差が出ませんでした（50 ns先は比率自体が読めません）。
- 長い予測幅（10 ns先と 90 ns先）では、平均だけの曲がりが長い覆う長さで下がる一方、6種は水準を保つ形が共通しています。
