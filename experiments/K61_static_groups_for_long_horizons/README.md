# K61: 長い予測幅で履歴の読み出しに要る静的な特徴はどれか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。K59 で、履歴だけの補正は 1 ns先では利得の 0.89 が戻りましたが、長い予測幅ではほぼゼロになりました。長い予測幅で、履歴の読み出しにどの静的な特徴が要るか確かめます。

読み方は実験前に固定しました。ある種類を落として長い予測幅の利得がはっきり落ちれば、その種類が長い予測幅の読み出しに要ります。どれを落としても落ちなければ、静的な特徴の種類ではなく組み合わせが要ります。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、学習回数160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- 静的な特徴5つは、K06(b) の作り方（`score_b.py`、tseries の `structural()`）から次の通りです。
  - 0: 凍結した本体 T1I2006 の予測確率（その他）
  - 1: 予測のもとの供与体・受容体間の距離（距離）
  - 2: 供与体の残基と受容体の残基の CA 間の距離（距離）
  - 3: 供与体が主鎖の N か側鎖の供与体か（種類）
  - 4: 受容体が主鎖の O か側鎖の受容体か（種類）
- 条件は4つで、どれも実履歴の10統計量を入れています。
  - full: 静的な特徴5つ全部＋実履歴（参照。K06(b) の実履歴の条件と同じ）
  - drop_dist: 距離の特徴（1・2）を落とした条件
  - drop_kind: 種類の特徴（3・4）を落とした条件
  - drop_frozen: 凍結した本体の予測確率（0）を落とした条件
- 利得は、評価する予測幅での静的な特徴だけの条件（5つ全部、履歴なし）との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。参照する利得は full の条件の利得です。保持率は、落とした条件の利得を full の利得で割った値です。
- 対照の確認: 静的な特徴だけの条件と full の条件は、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。

## 結果

### 利得（全体をまとめた値）

| 予測幅 | full | drop_dist | drop_kind | drop_frozen |
|---|---:|---:|---:|---:|
| 1 ns | +0.0702 | +0.0699 | +0.0699 | +0.0635 |
| 5 ns | +0.0514 | +0.0518 | +0.0515 | +0.0373 |
| 10 ns | +0.0376 | +0.0366 | +0.0360 | +0.0110 |
| 30 ns | +0.0363 | +0.0358 | +0.0388 | +0.0131 |
| 50 ns | +0.0354 | +0.0295 | +0.0333 | +0.0133 |
| 90 ns | +0.0265 | +0.0237 | +0.0266 | −0.0032 |

### 保持率（full の利得に対する割合、全体をまとめた値）

| 予測幅 | drop_dist | drop_kind | drop_frozen |
|---|---:|---:|---:|
| 1 ns | 1.00 | 0.99 | 0.90 |
| 5 ns | 1.01 | 1.00 | 0.72 |
| 10 ns | 0.97 | 0.96 | **0.29** |
| 30 ns | 0.99 | 1.07 | **0.36** |
| 50 ns | 0.83 | 0.94 | **0.38** |
| 90 ns | 0.89 | 1.00 | **−0.12** |

タンパク質ごとの平均でも形は同じです（drop_dist: 0.99 / 1.01 / 0.98 / 1.01 / 0.84 / 0.87、drop_kind: 0.98 / 1.01 / 0.93 / 1.06 / 0.96 / 1.01、drop_frozen: 0.90 / 0.75 / 0.36 / 0.43 / 0.40 / −0.04）。

90 ns先では、drop_frozen の AUPRC（0.4386）は静的な特徴だけの条件（0.4418）だけでなく、凍結した本体だけ（0.4545）よりも低くなります。

## 判断

先に固定した読み方で見ると、**長い予測幅の読み出しに要るのは、凍結した本体の予測確率**です。これを落とすと、10 ns先で保持率が 0.29、30 ns先で 0.36、50 ns先で 0.38、90 ns先では利得がマイナスになります。1 ns先では 0.90 とほとんど落ちず、5 ns先では 0.72 と途中まで持ちますが、10 ns先以降はっきり落ちます。

距離の特徴を落としても、利得はほとんど落ちません（保持率 0.83〜1.01）。種類の特徴を落としても、利得は落ちません（保持率 0.93〜1.07）。つまり、長い予測幅の読み出しは、距離や種類の特徴ではなく、凍結した本体の予測確率を土台として、履歴の統計量で修正する形になっています。凍結した本体の予測がないと、履歴の統計量だけでは長い予測幅の予測を置く場所がありません。これは K59 の結果（履歴だけでは長い予測幅で利得が戻らない）と合います。
