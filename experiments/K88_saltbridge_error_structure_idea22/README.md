# K88 塩橋の形成でも、案22の生成の平均の誤差の形は同じか（K15 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。塩橋の形成では、誤差の形は案22と第11〜14案で同じでした。(a) の境界の勾配と (c) の隔たりの効果は同じで、(b) の外れたペアでの誤差も両方式とも大きくなります。比だけ見ると案22 が 1.71 倍、第14案が 1.41 倍と開いていますが、裾の帯の誤差の大きさ自体はほぼ同じ（1.458 Å と 1.413 Å）で、比の開きは中心の帯（28件）の小ささによるものです。K84 のようなはっきりした分かれ方は出ませんでした。

## 1. 何を確かめる実験か

K76・K81・K84 で、解離と接触の形成では案22の誤差の形を確かめました。残る塩橋の形成でも同じか確かめます。

読み方は先に固定しました。案22でも誤差が境界の近くで大きくならず、外れたペアで大きければ、塩橋の形成でも誤差の形は生成方式によりません。形が違えば、誤差の形は生成方式によります。K84 では外れたペアでの誤差だけが分かれたので、塩橋の形成でも同じ分かれ方をするかも見ます。

## 2. 条件

- 対象は K14 の塩橋の形成の候補 367件です。K14 の探索は資料Dの元の6タンパク質だけを対象にしており、K15 の広げた条件の 3,727件のうち元の6タンパク質分が 367件です。367件はすべて与えられます。塩橋の代表ペア（起点で最小距離をとる荷電重原子ペア）は常に（正の窒素、負の酸素）のペアなので、すべてドナー・アクセプターのペアです。K81（塩橋の解離）と同じく、部分集合の制限はありません。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は案22の5点系列（起点＋0.1／0.3／0.5／1.0 ns）の平均です（K30・K35・K76 と同じ約束）。第11〜14案の生成の平均は、枝の平均の9点系列（起点＋8段）の平均です（K38・K48 と同じ約束）。
- 分け方：(a) 起点の距離の帯（境界付近 4.0〜5.0 Å と、それ以外 5.0 Å 超。細かく 0.5〜2.0 Å 刻みでも測る）、(b) 実の平均の全体の平均からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）。
- 対照として、K38 の対照（実の前向き5点最小系列の平均と実履歴の平均との差）と、K35 の対照（実の代表ペア系列の平均と実履歴の平均との差）も同じ分け方で測ります。
- ラベルとの関係も K38 と同じ測定をします。1 ns先のラベル（最小距離が 4.0 Å 以下になったか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べます。

## 3. 並べ替えの確認

K14 の塩の系列と K20 の系列の並べ替えは、タンパク質の順番で合わせました。K14 の探索は (1bgf_A, 1ifg_A, 1j8r_A, 2b0a_A, 1mix_A, 2qt4_A) の順番で処理していますが、K20 のファイルを名前順に並べると 1mix_A と 2b0a_A が入れ替わります。タンパク質の順番で K20 の元の6タンパク質分を並べたところ、K14 の `min` と K20 の `fwd5` は最大の差が 9.0e-07 Å で一致しました（float32 の丸めの範囲です）。K14 の `gen` の起点と K20 の `fwd5` の起点も最大の差が 8.8e-07 Å で一致しました。367行はすべてこの並べ替えで対応しています。

## 5. 読み取り

- **境界の近くで誤差が大きくなる勾配は、どちらの方式にもありません。** 境界付近（4.0〜5.0 Å）とそれ以外の比は、案22 が 0.92 倍、第14案が 0.89 倍、第11案が 0.89 倍です。細かい帯も、案22・第14案のどちらもほぼ平らです。K38 の第14案の測定（0.88 倍）と同じです。
- **外れたペアでの誤差は、どちらの方式でも大きくなります。** (b) では、実の平均が全体の平均（7.815 Å）から 1.0 Å 以上離れた候補（248件）で、案22の誤差は 1.458 Å、第14案の誤差は 1.413 Å になり、中心（0.25 未満）の 0.851 Å／0.999 Å に対して比は 1.71 倍／1.41 倍です。比だけ見ると案22の方が大きく開いていますが、裾の帯の誤差の大きさ自体はほぼ同じです（1.458 Å と 1.413 Å、差は 0.045 Å）。比の開きは中心の帯の誤差の違い（0.851 Å と 0.999 Å、差は 0.148 Å）によるもので、中心の帯は 28件しかありません。裾の帯の件数（248件）から見積もると、裾の誤差の標準偏差のばらつきは約 0.065 Å、中心の帯では約 0.11 Å で、どちらの差もばらつきの範囲に収まります。K84 では裾の誤差の標準偏差の差が 0.067 Å で件数が 4,968件あり、はっきりした分かれ方でした。ここでは件数が 367件と少なく、同じ分かれ方だとは言えません。
- **隔たりの効果は、どちらの方式でもほぼありません。** 21以上と 2〜5 の比は、案22 が 1.02 倍、第14案が 1.03 倍です。K38 の全 3,727件での第14案も 1.07 倍で、塩橋の形成では隔たりによるはっきりした並びはありません。対照の実の前向き系列ではこの比が 1.16〜1.17 倍と、生成の方式よりやや大きくなっています。
- **全体の誤差の大きさは、どちらの方式でもほぼ同じです。** 全体の誤差の標準偏差は、案22 が 1.293 Å、第14案が 1.291 Å、第11案が 1.285 Å です。全体のずれは、案22 が −0.436 Å に対して第14案が −0.287 Å と、案22の方がやや大きくなっています。対照の実の前向き系列の誤差の標準偏差は 1.126 Å で、生成の誤差の大きさの大部分は前向きと後ろ向きの違いから来ています（K38 と同じ）。
- **生成の平均が実の平均についていく傾きも、両方式で近くなっています。** 生成の平均を実の平均の線形の式で当てはめると、案22 の傾きは 0.557、第14案の傾きは 0.621 です。K84 では案22 の傾きが 0.837、第14案の傾きが 0.933 と開いていました。ここでは両方式とも生成の平均が中心に縮み、傾きは 0.56〜0.62 と近くなっています。K38 の全 3,727件での第14案の傾きは 0.585 でした。
- **裾の帯の内訳は、接触の形成と同じく両側に広がっています。** 裾の帯（248件）の実の平均は 3.08〜14.03 Å で、全体の平均より上が 128件、下が 120件です。生成の平均は、案22 が 3.96〜9.77 Å、第14案が 3.88〜10.18 Å です。誤差は、案22 が −5.52〜+2.83 Å、第14案が −5.48〜+3.27 Å と、両側に出ます。解離の場合（K67・K70・K72）では裾の帯の実の平均はすべて全体の平均より上で、誤差はすべて負の側に出ました。形成では裾の帯が両側に広がるため、誤差も両側に出ます。裾の帯の候補の起点の帯は、4.0〜5.0 Å が 37件、5.0 Å 超が 211件です。
- ラベルとの関係では、案22の誤差とラベルの相関が +0.213 で、縮み＋乱数の合成の +0.221 とほぼ同じ強さでした。K38 の第14案でも +0.151 に対して合成 +0.190 と同じでした。第14案の相関は +0.175 で、案22より弱くなっています。ただし陽性は 27件（7.4%）と少なく、ラベルとの関係の数値は不確かです。
- 生成の系列の質の確認では、案22の系列は実の前向き系列より静かでした（ペアごとの標準偏差 0.130 Å に対して実の最小系列は 0.959 Å、境界を越える回数は 0.003 回／ペアに対して実は 0.215 回／ペア）。K05・K54・K76・K81 と同じ静かさです。生成の平均は 7.380 Å で、実の最小系列の平均 7.713 Å よりやや短いです。

## 6. 判断できること・まだ分からないこと

- 判断できること: 先に固定した読み方では、案22の誤差は境界の近くで大きくならず（0.92 倍）、外れたペアで大きくなります（1.71 倍）。第11〜14案の誤差も、境界の近くで大きくならず（0.89 倍）、外れたペアで大きくなります（1.41 倍）。(a) と (c) は同じ形で、(b) も両方式とも外れたペアで大きくなる方向は同じです。比の開き（1.71 倍と 1.41 倍）は、裾の帯の誤差の大きさ自体がほぼ同じで、中心の帯が 28件と小さいため、はっきりした分かれ方だとは言えません。そのため、塩橋の形成では誤差の形は生成方式によらないと読めます。K84 の接触の形成では (b) だけがはっきり分かれましたが、塩橋の形成では同じ分かれ方は出ませんでした。
- 判断できること: 全体の誤差の大きさ、生成の平均が実の平均についていく傾き、ラベルとの関係も、両方式で近くなっています。K38 の全 3,727件での第14案の数値と、367件の部分集合での第14案の数値はほぼ同じで、部分集合は全体をよく表しています。
- まだ分からないこと: 対象は元の6タンパク質の 367件に限られ、K15 の広げた条件の全体（3,727件）ではありません。境界付近の帯は 41件、中心の帯は 28件、陽性は 27件と少なく、(b) の比の開きが本当にないのか、件数が少ないために見えていないのかは、まだ確かめていません。また生成器は水素結合の形成のペアだけで学習したものを流用しており、学習範囲の外への当てはめである点は変わりません。
