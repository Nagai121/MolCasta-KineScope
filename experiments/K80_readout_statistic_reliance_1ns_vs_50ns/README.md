# K80 1 ns先で学習した読み出しが 50 ns先で弱いのは、頼る統計量が違うからか（K06(b) の条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる読み出しの移し替え
- 状態: 完了。2つの読み出しが頼る統計量の組み合わせは違うが、1 ns先の読み出しが 50 ns先で最も頼るのは平均で、平均は 50 ns先の担い手でもあるため、先に固定した読み方の「担い手でない統計量に頼っている」という説明は成り立たなかった。弱さは別の理由による。

## 1. 何を確かめる実験か

K56 で、1 ns先で学習した読み出しを 50 ns先で使うと利得の戻り率は 0.608 と弱いことが分かりました。K79 で逆向き（50 ns先で学習した読み出しを 1 ns先・90 ns先で使う）は 1.026・1.330 と強いことも分かりました。K77 で、50 ns先の担い手は平均（0.933）と 3.5 Å以下割合（0.888）の両方だと分かり、50 ns先の指導力そのものに担い手がないわけではありません。では 2つの読み出しが頼る統計量が違うのか、1つずつ統計量を抜いて比べます。

読み方は先に固定しました。1 ns先の読み出しが 50 ns先では担い手でない統計量に頼っていれば、その違いが弱さの理由です。頼る統計量が同じなら、弱さは別の理由です。「頼る統計量」は、抜いたときに利得が大きく落ちる統計量（残存率が低いもの）で読みます。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A、候補 13,808件）で学習し、未見100タンパク質×3レプリカ（163,074件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`）をそのまま使いました。軌道の取り直しも、本体 T1I2006 の読み込みも、生成器のチェックポイントの読み込みも行っていません。距離は K06(b) の保存済み特徴量に含まれるもので、この実験では距離の計算をし直していません。
- 補正モデルの入力は、K56・K79 と同じ静的5特徴＋実履歴10特徴です。実履歴10特徴の並びは [最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å以下割合、4.5 Å以下割合、距離が増えたステップの割合] です。
- 抜く統計量は 6統計量（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下割合）で、列を落とす形（K18式）で学習し直しました。残りの履歴特徴（最大値、最後−1つ前、4.5 Å以下割合、増えたステップの割合）は全条件に残ります。つまり頼り方は、実履歴の特徴量全体の中で、その統計量の列が要るかどうかとして測っています。
- 学習・評価の組み合わせは 4通りです。(1,1) は 1 ns先で学習して 1 ns先で評価、(1,50) は 1 ns先で学習して 50 ns先で評価（K56 の弱さが出る条件）、(50,50) は 50 ns先で学習して 50 ns先で評価、(50,1) は 50 ns先で学習して 1 ns先で評価（K79 の逆向きの確認）です。静的な特徴だけの条件は、評価する予測幅で学習したもの（K56・K79 のやり方）を使い、利得の基準にしました。
- 利得は、評価する予測幅での静的な特徴だけの条件との AUPRC の差です。残存率は、統計量を抜いた条件の利得を、抜いていない条件（full）の利得で割った値で、タンパク質マクロ平均 AUPRC を主、全体まとめ（ミクロ）を従としました。失われる利得の割合（%）は 100×(1−残存率) です。

## 3. 結果

### 3.1 利得（full、抜く前の条件）

| 学習→評価 | 利得（マクロ／ミクロ） |
|---|---:|
| 1 ns → 1 ns | +0.0712 / +0.0702 |
| 1 ns → 50 ns | +0.0213 / +0.0216 |
| 50 ns → 50 ns | +0.0344 / +0.0354 |
| 50 ns → 1 ns | +0.0709 / +0.0720 |

1 ns先で学習して 50 ns先で評価する条件の利得は、同じ 50 ns先で学習した条件の利得の 0.618（マクロ）／0.608（ミクロ）で、K56 の 0.62／0.61 と一致します。50 ns先で学習して 1 ns先で評価する条件は 0.995／1.026 で、K79 の 0.996／1.026 と一致します。

### 3.2 統計量を1つ抜いたときの残存率（利得がどれだけ残るか、マクロ／ミクロ）

| 抜いた統計量 | 1 ns → 1 ns | 1 ns → 50 ns | 50 ns → 50 ns | 50 ns → 1 ns |
|---|---:|---:|---:|---:|
| 最初の値 | 0.996 / 0.993 | 1.087 / 1.069 | 0.957 / 0.937 | 0.988 / 0.987 |
| 平均 | 0.930 / 0.928 | **0.850 / 0.826** | 0.957 / 0.946 | 0.943 / 0.949 |
| 標準偏差 | 0.986 / 0.989 | 1.078 / 1.029 | 1.018 / 1.007 | 0.979 / 0.963 |
| 最小値 | 0.952 / 0.956 | 0.964 / 0.940 | 0.976 / 0.926 | 0.975 / 0.974 |
| 最後−最初 | 0.984 / 0.986 | 0.940 / 0.916 | **0.916 / 0.901** | 0.977 / 0.982 |
| 3.5 Å以下割合 | 0.983 / 0.984 | 1.003 / 0.991 | **0.919 / 0.881** | 0.953 / 0.940 |

失われる利得の割合（%、マクロ）で見ると、1 ns先で学習した読み出しは 1 ns先では平均が最大の 7.0%、50 ns先では平均が最大の 15.0% で、次が最後−最初の 6.0% です。50 ns先で学習した読み出しは 50 ns先では最後−最初が最大の 8.4%、次が割合の 8.1% で、平均は 4.3% にとどまります。1 ns先では平均が最大の 5.7% です。

### 3.3 対照の確認

- (1,1) と (50,50) の各統計量を抜いたときの失われる利得の割合は、K18 の表とマクロ・ミクロとも全統計量で一致しました（小数第4位まで、最大差は浮動小数点の丸めの範囲）。K18 はすでに学習した予測幅で評価する条件を全予測幅で測っており、K80 はその 1 ns先と 50 ns先の行を測り直した形ですが、食い違いはありません。
- (1,50) の戻り率は K56、(50,1) の戻り率は K79 と小数第4位まで一致しました（上記の 3.1 を参照）。

## 4. 読み取り

- **2つの読み出しが頼る統計量の組み合わせは違います。** 1 ns先で学習した読み出しは、1 ns先でも 50 ns先でも平均に最も頼ります（失われる利得は 1 ns先で 7.0%、50 ns先で 15.0%）。一方、50 ns先で学習した読み出しは 50 ns先では最後−最初（8.4%）と割合（8.1%）に最も頼り、平均は 4.3% にとどまります。1 ns先の読み出しは平均寄り、50 ns先の読み出しは最後−最初と割合寄りという組み合わせの違いがあります。
- **ただし、先に固定した読み方の1つ目の枝（担い手でない統計量に頼っているから弱い）は成り立ちません。** 1 ns先の読み出しが 50 ns先で最も頼るのは平均で、平均は K77 で 50 ns先の担い手だと分かっています（平均だけでも利得の 0.933 が戻る）。50 ns先で担い手でない統計量（K77 の単独条件でほとんど戻さない標準偏差 0.048、最初の値 0.456、最後−最初 0.466）は、1 ns先の読み出しが 50 ns先で頼る側にはなく、標準偏差と最初の値を抜くと移し替えた利得はむしろ大きくなります（残存率 1.078 と 1.087）。つまり 1 ns先の読み出しは、50 ns先でも担い手である平均に頼っており、頼る先の違いが弱さの理由だとは言えません。
- **どちらの読み出しでも、1つの統計量は必須ではありません。** 失われる利得は最大で 15.0%（1 ns先の読み出しを 50 ns先で評価したときの平均）で、他の統計量は 8.7% 以下です。K18 と同じく、統計量どうしで代わりが利くため、落とす実験だけでは頼り方を1つの統計量に決められません。組み合わせの違いは読めますが、弱さの原因を1つの統計量に帰すことはできません。
- 絶対量で見ると、頼り方の強さの違いはさらに小さくなります。1 ns先の読み出しを 50 ns先で評価したとき、平均を抜いて失われる利得は 15.0% × 0.0213 = 0.0032（AUPRC）で、50 ns先の読み出しで割合を抜いて失われる 8.1% × 0.0344 = 0.0028 と同程度です。違いは主に、どの統計量が一番上に来るかという組み合わせの側にあります。
- K21・K73・K77 の「入れる」実験と合わせると、50 ns先では平均と割合の両方が担える（K77: 平均 0.933、割合 0.888）一方で、読み出しの頼り方は学習した予測幅によって平均寄りか最後−最初・割合寄りかに分かれる、という絵になります。1 ns先で学習した読み出しが 50 ns先に移らない理由は、担い手の不在でも、担い手でない統計量への依存でもなく、この実験では見えない別の理由（たとえば、平均と割合の重みの付け方や、静的な特徴との組み合わせ方）によるものと考えられます。

## 5. 判断できること・まだ分からないこと

- 判断できること: 1 ns先の読み出しと 50 ns先の読み出しは、頼る統計量の組み合わせが違う（1 ns先の読み出しは平均寄り、50 ns先の読み出しは最後−最初・割合寄り）。しかし 1 ns先の読み出しが 50 ns先で最も頼る平均は 50 ns先の担い手でもあるため、先に固定した読み方の「担い手でない統計量に頼っているから弱い」という説明は成り立たない。弱さは別の理由による。1つの統計量はどちらの読み出しでも必須ではなく（最大の損失 15.0%）、統計量どうしで代わりが利く。
- まだ分からないこと: 1 ns先で学習した読み出しが 50 ns先に移らない理由の中身（平均と割合の重みの付け方の違いか、静的な特徴との組み合わせ方の違いかなど）。落とす実験では代わりが利くため、頼り方の違いをさらに切り分けるには、複数の統計量を同時に落とすか、重みの付け方を直接比べる段取りが要ります。
