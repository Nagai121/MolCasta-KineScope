# K48 塩橋でも、平均以外の統計量の誤差の形は水素結合・接触と同じか（K15 の広げた条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。1 ns先だけ接触と同じ形（4.0 Å 以下割合が担い手）で、それ以外の予測幅では3つの統計量の誤差では説明がつきませんでした。塩橋は水素結合・接触のどちらとも違う形です。

## 1. 何を確かめる実験か

水素結合（K33）と接触（K41）では、平均以外の統計量の誤差の形が違いました。塩橋でも同じ切り分けを測り、3現象の地図をそろえます。

読み方は先に固定しました。塩橋でも 1 ns先で割合が担い手なら、接触と同じ形です。3つまとめでしか落ちなければ、水素結合に近い形です。形が違えば、現象ごとに違います。

## 2. 条件

- 土台は K15 の広げた条件です。学習は58タンパク質（2,557件）、テストは30タンパク質（1,170件、陽性は予測幅ごとに 93〜149件）で、分け方は `experiments/K15_saltbridge_expansion/split.json` に凍結されているものです。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・4.0 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、4.0 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は K20 の第11〜14案（残基レベルの生成）で、生成の統計量は分岐平均の9点系列（起点＋8ステップ）から同じ定義で計算しました。第14案（実系列に最も近い）と第11案（最も静か）の両方で測り、2つの方式で形が変わらないかも確かめました。
- K41 と違い、生成系列があるのは全候補（3,727件）なので、測れる範囲の絞りはありません。テスト全体（1,170件）で測っています。
- 対照の確認: 静的のみと実履歴は、K15 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.2402、実履歴 0.3842）。

## 4. 読み取り

- **1 ns先は、接触と同じ形でした。** 4.0 Å 以下割合だけの置き換えで利得の 0.32（第11案では 0.27）まで落ち、標準偏差だけでは 0.95、最小値だけでは 0.94 とほとんど落ちません。3つまとめでは 0.49（第11案 0.38）が残ります。水素結合の 1 ns先（1つずつでは 0.89〜0.94 が残り、3つまとめで 0.65）とは違い、接触の 1 ns先（割合だけで 0.10、3つまとめで −0.22）に近い形です。塩橋の 1 ns先では、平均以外の統計量の誤差の担い手は 4.0 Å 以下割合です。
- **5 ns先では、3つの誤差では説明がつきません。** 3つまとめで 0.80（第11案 0.90）が残ります。水素結合では 5 ns先で 3つまとめが生成水準まで落ち（−0.06）、接触では 0.28 まで落ちたのに対し、塩橋ではほとんど落ちません。
- **10・30 ns先では、置き換えると利得が増えます。** 3つまとめの残存率は 1.50／1.17（第11案 1.49／1.04）で、実履歴の条件を上回ります。1つずつでも標準偏差・最小値の置き換えで利得が増える幅があります（10 ns先で標準偏差だけ 1.44、最小値だけ 1.35）。生成の系列は実系列より静かで滑らかなので、その統計量を当てたほうが、この2つの予測幅ではモデルが当たりやすくなる、という形です。土台の利得そのものが小さい幅（10 ns先 +0.059、30 ns先 +0.088）なので、残存率の細かい値では読めませんが、AUPRC そのものでも 3つまとめは実履歴を上回っており（10 ns先で 0.2924 対 0.2627、30 ns先で 0.2618 対 0.2466）、比の揺れだけの話ではありません。第11案と第14案で同じ向きに出る点も、方式の違いによるものではありません。
- **50 ns先は部分的な説明です。** 3つまとめで 0.57（第11案 0.53）が残り、水素結合の 0.72、接触の 0.74 と同じくらいの部分的な説明です。土台の利得そのものが最も小さい幅（+0.027）なので、細かい値では読めません。
- **90 ns先では、3つまとめで利得がほぼ消えます**（0.03、第11案 0.10）。水素結合（−0.23）・接触（0.08）と同じ結論ですが、担い手の形は違います。水素結合では標準偏差だけで利得が消えましたが、塩橋では標準偏差だけでは 0.68、最小値だけでは 0.52、割合だけでは 0.86 が残り、3つの組み合わせで消えます。
- 先に固定した読み方に照らすと、**塩橋は 1 ns先だけ接触と同じ形（割合が担い手）で、それ以外の予測幅では水素結合に近い形にもなりませんでした。** 5 ns先では3つの誤差では説明がつかず、10・30 ns先では置き換えると利得が増えます。平均以外の統計量の誤差の形は、塩橋は3現象の中で独自の形です。

## 5. 判断できること・まだ分からないこと

- 判断できること: 塩橋では、平均以外の3つの統計量の誤差が利得を落とすのは、1 ns先（割合の誤差が担い手）と 90 ns先（3つの組み合わせ）だけです。5・10・30 ns先では3つの誤差では説明がつかず、10・30 ns先では生成の統計量を当てたほうが利得が増えます。平均以外の統計量の誤差の形は現象ごとに違い、塩橋は水素結合・接触のどちらとも違う形です。
- まだ分からないこと: 10・30 ns先で生成の統計量を当てると利得が増える理由。実の標準偏差・最小値の揺れが、この2つの予測幅ではモデルにとって邪魔になっているのか、それとも生成の滑らかさがたまたま塩橋のラベルと合っているのかは、この実験だけでは分かりません。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
