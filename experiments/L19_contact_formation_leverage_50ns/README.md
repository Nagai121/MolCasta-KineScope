# L19: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の形成、50 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L01（水素結合の形成、1 ns先）と同じ曲がりの測り方で、接触の形成の 50 ns先を測る。
- 状態: 完了。回復率 0.8 にも 0.9 にも、どの長さでも届かない（最大は 0.9 ns の 0.7481）。増え幅がいちばん大きいのは 0.1→0.2 ns（+0.2452）だが、その前の 0→0.1 ns が −0.2460 の落ち込みで、段は落ち込みからの戻りである。フレーム 0 だけの回復率 0.7470 がほぼ最大。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの条件のモデルに入れたときの 50 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、統合・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 250件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 50 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（13条件の学習で約10〜50秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（50 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: なし**。最大でも 0.9 ns の 0.7481 で、0.8 には届きません。
2. **回復率 0.9 に届く最小の長さ: なし**。
3. **増え幅がいちばん大きい場所: 0.1→0.2 ns（+0.2452）**。ただし 0→0.1 ns の増え幅は −0.2460 で、0.1 ns に落ち込みがあります。0.1→0.2 ns の増え幅は、その落ち込みから 0 ns の水準（0.7470）へ戻る動きで、新しい情報の上乗せとしての段ではありません。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1497（静的のみ 0.3089、全部入り 0.4586）、2qt4_A が +0.3399（静的のみ 0.1789、全部入り 0.5188）で、2qt4_A の利得のほうが大きい。

段の位置（0.1→0.2 ns）でのタンパク質ごとの回復率は、1mix_A が 0.3931 → 0.7281（+0.3350）、2qt4_A が 0.6331 → 0.7906（+0.1575）で、どちらも正です。ただし両タンパク質とも 0 ns の値（1mix_A 0.7282、2qt4_A 0.7148）とほぼ同じ水準への戻りで、0.2 ns の値は 0 ns の値を 1mix_A で横ばい、2qt4_A で +0.0758 上回るだけです。

## 4. 読み取り

- 接触の形成の 50 ns先では、フレーム 0 だけ（覆う長さ 0 ns）の回復率 0.7470 がほぼ最大で、切り取りを長くしても統合値では上回りません。0.1 ns で 0.5010 まで落ちるのが特徴で、平均にフレーム 1 を混ぜると悪くなる形です。
- 曲がりは全長さで 0.50〜0.75 の範囲を行き来し、単調ではありません。平均だけでは 0.8 の線に届かない予測幅です。
- タンパク質ごとでは分かれ方が大きく、2qt4_A は 0.3 ns 以降 0.79〜1.03 の回復率がある一方、1mix_A は 0.39〜0.73 の範囲にとどまります。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
