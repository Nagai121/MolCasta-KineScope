# K68: 平均の担い手は、タンパク質ごとに違うか（資料Dの条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。どちらのテストタンパク質でも、平均だけで利得の 0.76〜1.45 が戻り、90 ns先を除く 5幅では両タンパク質とも 8割以上でした。90 ns先だけ両タンパク質そろって 0.8 をわずかに下回りました（1mix_A 0.764、2qt4_A 0.795）。担い手はタンパク質によらず同じです。

## 1. 何を確かめる実験か

これまで平均が担い手だと分かりましたが、タンパク質ごとに違うかは測っていません。テストのタンパク質ごと（1mix_A と 2qt4_A）に分けて確かめます。

読み方は先に固定しました。どちらのタンパク質でも平均だけで利得の8割以上が戻れば、担い手はタンパク質によらず同じです。タンパク質によって戻り方がはっきり違えば、担い手はタンパク質ごとに違います。「8割以上」は全幅または多くの幅での読みとし、1 ns先を主判断とします。

## 2. 方法

- 土台は資料Dの条件です。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算されています（抽出済みキャッシュ `~/workspace/kinescope/work/data_cache/` を使用）。
- 形成の候補は、起点でドナー・アクセプター重原子距離が 3.5 Å 超〜6.0 Å 以下です（K55 の記録と同じ）。
- 条件は3つです（分け方は K55 と同じ）。
  - 静的のみ: 静的7特徴だけ
  - 全部入り: 静的＋実履歴6統計量（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合）
  - 平均だけ: 静的＋履歴6統計量のうち平均1つだけ（他の統計量は入れない）
- 学習側は変えていません。学習は 4タンパク質の全候補のままで、変えるのは評価対象だけです（K57/K62 と同じ段取り）。テストをタンパク質ごとに分けて評価しました。学習側もタンパク質ごとに分けるやり方ではありません。
- 対照の確認: 全体まとめ（1mix_A＋2qt4_A）の値は、K55 の `results.json` の ALL と全幅・全条件・全4指標で完全に一致しました（最大の絶対差 0.0）。1 ns先で静的のみ 0.3637、全部入り 0.4815、利得 +0.1178 です。

## 5. 読み取り

- **どちらのタンパク質でも、平均だけで利得の大半が戻ります。** 1mix_A の戻り方は 0.764〜1.378、2qt4_A は 0.795〜1.448 で、90 ns先を除く 5幅では両タンパク質とも 8割以上です。1 ns先の主判断でも両方 8割以上（1mix_A 1.250、2qt4_A 0.894）です。先に固定した読み方に沿うと、担い手はタンパク質によらず同じです。
- **90 ns先だけ、両タンパク質そろって 8割をわずかに下回りました**（1mix_A 0.764、2qt4_A 0.795、全体まとめ 0.772）。片方のタンパク質だけが下がるのではなく両方そろって下がるため、90 ns先の弱まりはタンパク質の違いではなく、予測幅の違いによるものと考えられます。
- **利得の大きさはタンパク質によって違います。** 2qt4_A の利得は全予測幅で 1mix_A より大きく（1 ns先で +0.1937 対 +0.0870、90 ns先で +0.2094 対 +0.0891）、全体の利得は 2qt4_A の側に寄っています。ただし戻り方の形は両タンパク質で同じで、利得の大きさの違いは担い手の違いにはなっていません。
- K62 で見た幅Bのタンパク質の違い（2qt4_A の利得が負になる幅がある）とは対象が違います。K62 は幅B（4.5〜6.0 Å）だけに絞ったもので、ここでは全候補（幅A＋幅B）を対象にしています。K62 の値と混ぜないでください。

## 6. 判断できること・まだ分からないこと

- 判断できること: 資料Dの条件（水素結合の形成）では、平均が担い手であることはテストの 2タンパク質で共通です。90 ns先の弱まりも両タンパク質で共通で、タンパク質の違いによるものではありません。
- まだ分からないこと: テストは 2タンパク質しかないため、2つ以外のタンパク質でも担い手が平均かはこの実験だけでは分かりません。強い土台（K06(b)、未見100タンパク質）では平均が担い手であることは K21 で確かめ済みですが、タンパク質ごとの戻り方までは測っていません。
