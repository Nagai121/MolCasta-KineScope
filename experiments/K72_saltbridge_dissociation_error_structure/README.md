# K72 塩橋の解離でも、生成の平均の誤差の形は同じか（K53 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。2つの決め手では水素結合の解離と同じ形です（境界の近くで大きくならず、外れたペアで大きい）。ただし誤差の大きさの大部分は、生成そのものではなく前向きと後ろ向きの違いと、生成の平均がほぼ一定になってしまう系統的な不足で占められており、そこは塩橋の解離だけの特徴です。

## 1. 何を確かめる実験か

水素結合の解離（K67）と接触の解離（K70）では、生成の平均の誤差の形が分かりました。塩橋の解離でも同じ切り分けをします。

読み方は先に固定しました。塩橋の解離でも誤差が境界の近くで大きくならず、外れたペアで大きければ、水素結合の解離と同じ形です。境界に近づくほど誤差が大きくなる勾配があれば、接触の解離と同じ形です。どちらでもなければ、塩橋の解離は独自の形です。

## 2. 条件

- 対象は K53 の塩橋の解離の候補 1,095件（K15 の広げた条件）です。誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は K26・K30・K38・K67・K70 と同じ約束（分岐4本 × 起点＋8ステップの36値の平均）です。生成の系列は K65 の作り直し版（第11〜14案、残基レベルの生成方式）を使います。
- 分け方：(a) 起点の距離の帯（境界付近 3.0〜4.0 Å と、それ以外 3.0 Å 以下。細かく 0.5 Å 刻みでも測った）、(b) 実の平均の全体の平均（3.469 Å）からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K38・K67・K70 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K38・K67・K70 と同じ区切り）。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。
- 対照として、実の前向き5点系列（起点と +0.1／0.3／0.5／1.0 ns）の平均と実履歴の平均との差も同じ分け方で測りました（K38 の対照）。生成の平均の誤差のうち、どれだけが前向きと後ろ向きの違いによるものかを見るためです。
- ラベルとの関係も K38 と同じ測定をしました。1 ns先のラベル（最小距離が 4.0 Å を超えたか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べました。
- 注意点: 候補は 1,095件と少なく、起点の距離は 2.5〜3.0 Å に 979件と偏っています。境界付近の帯は 3.0〜3.5 Å が 70件、3.5〜4.0 Å が 45件と少なく、細かい数値は揺れを含みます。

## 4. 読み取り

- **境界の近くで誤差が大きくなる勾配はありません。** 境界付近（3.0〜4.0 Å）の誤差は 1.033 Å、それ以外は 1.074 Å で、比は 0.96 倍です。細かい帯も 1.074／0.979／1.104 Å とほぼ平らです。接触の解離（K70）では境界付近とそれ以外の比が 1.29 倍で、細かい帯が単調に増えました。塩橋の解離にその勾配はありません。
- **外れたペアで誤差が大きい形は、水素結合の解離と共通です。** (b) では、実の平均が全体の平均から 1.0 Å 以上離れた候補（156件）で誤差が 1.219 Å になり、中心（0.25 未満）の 0.338 Å に対して 3.61 倍です。水素結合の解離（K67）では同じ比が 6.63 倍、接触の解離（K70）では 2.79 倍でした。この帯の誤差はすべて負の側に出ます（全体のずれ −2.727 Å、平均絶対値も 2.727 Å）。この帯の実の平均は 4.47〜10.49 Å とすべて全体の平均より上にあり、生成の平均は 2.45〜4.07 Å の範囲に留まります。履歴の中で大きく離れたペアについて、生成の平均は起点の近くに留まったままで、実の平均についていけていません。
- **ただし、誤差の大きさの大部分は生成そのものの問題ではありません。** 対照の実の前向き5点系列でも、実履歴の平均との差の標準偏差は 1.003 Å と、生成の誤差（1.070 Å）のほとんどを占めます。塩橋の実の系列は前向きと後ろ向きで大きく違うため、前向きの系列の平均と後ろ向きの履歴の平均は、生成を使わなくても 1 Å ほどずれます。塩橋の形成（K38）でも同じで、対照の標準偏差は 1.291 Å と生成の 1.452 Å の大部分でした。裾の効果も、対照では中心の 1.98 倍と、生成の 3.61 倍より小さいものの、すでに出ています。生成はこの裾を大きくする側に働きますが、裾そのものは前向きと後ろ向きの違いから来ています。
- **生成の平均は、ほぼ一定になってしまっています。** 生成の平均の全体の平均は 2.835 Å で、ペア間のばらつきは 0.264 Å しかありません。実の平均のばらつきは 1.083 Å です。生成の平均を実の平均の線形の式で当てはめると傾きは 0.042 で、実の平均がどうであれ生成の平均はほぼ 2.7 Å のままです。塩橋の形成（K38）では同じ傾きが 0.585 でした。解離では起点の距離が 2.5〜3.0 Å に偏っているため、起点の近くに留まる生成の平均は、ペアごとの違いをほとんど出しません。中心の帯（0.25 未満）でも誤差の全体のずれが −0.527 Å と大きいのは、この系統的な不足のためです。水素結合の解離（K67）では中心の帯の全体のずれは −0.001 Å で、ここは塩橋の解離だけの特徴です。
- (c) では隔たりによるはっきりした並びはなく、2〜5 が 1.134 Å、6〜10 が 0.838 Å、11〜20 が 1.159 Å、21以上が 0.970 Å でした。水素結合の解離（K67）では 21以上が最も大きく、接触の解離（K70）では 21以上が 2〜5 の 1.40 倍でした。なお、塩橋の候補は隔たりが2以上と決まっているため、「隣り合う残基」の帯は 0件です（K35・K70 と同じ）。
- ラベルとの関係では、誤差とラベルの相関が −0.345 で、合成の −0.373 とほぼ同じ強さでした。解離したペアほど誤差が負の側に大きく、誤差がラベルを逆向きに予測します（AUC 0.250、裏返すと 0.750）。塩橋の形成（K38）でも、実際の誤差のラベルとの関係は合成よりやや弱く出ました（相関 +0.151 に対して合成 +0.190）。生成の平均は、陽性と陰性の平均の差が +0.121 Å と、実の平均の +0.960 Å に比べてほとんどありません。生成の平均は、解離するペアとしないペアをほとんど区別できていません。
- 方式の違いはどの分け方でも小さく、第11〜14案は同じ形でした。全体の誤差は、塩橋の形成（第14案の標準偏差 1.452 Å）より小さく、水素結合の解離（第14案の標準偏差 0.387 Å）や接触の解離（第14案の標準偏差 0.305 Å）よりずっと大きいです（第14案の標準偏差 1.070 Å）。全体のずれも −0.635 Å と、他の解離（−0.094 Å、−0.072 Å）よりずっと大きいです。

## 5. 判断できること・まだ分からないこと

- 判断できること: 先に固定した2つの決め手では、塩橋の解離は水素結合の解離と同じ形です。境界の近くで誤差が大きくならず（比 0.96 倍）、外れたペアで誤差が大きくなります（中心の 3.61 倍）。境界に近づくほど誤差が大きくなる勾配はなく、接触の解離の形ではありません。
- 判断できること: ただし誤差の大きさの大部分は、生成そのものではなく前向きと後ろ向きの違いで占められています（対照の標準偏差 1.003 Å に対して生成の 1.070 Å）。さらに生成の平均はほぼ一定（傾き 0.042）で、中心の帯でも −0.5 Å ほどの系統的な不足があります。この2点は、他の2つの解離にはない塩橋の解離だけの特徴です。
- まだ分からないこと: 候補は 1,095件と少なく、境界付近の帯は 70件と 45件しかありません。別のタンパク質の組み合わせでも同じ形になるかは、まだ確かめていません。また本実験は生成の平均の誤差の出方を測ったもので、誤差がモデルの予測にどれだけ響くかは K65 の置き換えの測定の話です。
