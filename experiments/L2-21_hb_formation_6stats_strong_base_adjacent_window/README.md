# L2-21: 区間を起点フレーム10の直前に置き直した測り直し（水素結合の形成、統計量6種、強い土台、予測幅 1/5/10/30/50/90 ns）

- 状態: 進行中。予測幅 1, 5, 10, 30, 50 ns まで完了。前提確認（長さ 1.0 ns の点で対応する L 実験の記録と一致すること）は、1 ns: すべて一致、5 ns: すべて一致、10 ns: すべて一致、30 ns: すべて一致、50 ns: すべて一致。回復率 0.8 に届く最小の長さ（全体）は、1 ns先は 0.8 が0.4 ns、0.9 が0.8 ns、5 ns先は 0.8 が0.7 ns、0.9 が0.8 ns、10 ns先は 0.8 が0.6 ns、0.9 が0.7 ns、30 ns先は 0.8 が0.6 ns、0.9 が0.9 ns、50 ns先は 0.8 が0.7 ns、0.9 が1.0 ns。

## 1. 何を確かめる実験か

L39〜L44・L40（形成）／L45〜L50（解離）と同じ土台・同じ候補・同じ予測器で、履歴の区間だけを置き直して、回復率の曲がりを測り直す。

L では区間は先頭から（フレーム 0〜k）で、短い長さでは起点フレーム10との間に時間の空きがあった。E01 で、この空きが回復率を水増ししていたことが分かっている（E01 の Protocol A は、区間を起点の直前に置く置き方）。ここでは区間を起点フレーム10の直前に置き、L と同じ読み方で測る。

## 2. 条件

- 土台: 強い土台（K06(b) の条件: 凍結した本体 + HistGradientBoosting の補正モデル（160回、学習率 0.065、葉15、葉あたり最少20、L2 0.15、種 20261121）。較正は8タンパク質、テストは未見100タンパク質×3レプリカ。
- 区間: 覆う長さ L ns の区間は、フレーム (10 − L/0.1) 〜 10 の L/0.1 + 1 フレーム。長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10。長さは 0〜1.0 ns の11通り。
- 統計量6種は資料Dの定義（最初・平均・標準偏差・最小・最後−最初・3.5 Å以下の割合）を、その区間のフレームで計算する。区間の「最初」は区間の先頭フレーム、「最後」は常にフレーム10。
- 条件は、静的のみ、全部入り（フレーム 0〜10 の6統計量、回復率の分母の参照）、区間の6統計量（11通り）、区間の平均だけ（11通り、平均だけの形との比較用）。
- 回復率 = (その長さの AUPRC − 静的のみ) / (全部入りの利得)。
- 読み方（L と同じ）: 回復率 0.8 と 0.9 に最初に達する長さ（全体とタンパク質ごとの平均の両方）、隣り合う長さの間の最大の増え幅、信頼区間はタンパク質単位のブートストラップ 10,000回（パーセンタイル法）。増え幅が最大の場所ではタンパク質ごとの値も記録する。
- 前提確認: 長さ 1.0 ns の点は区間がフレーム 0〜10 になり対応する L 実験と同じ条件になる。静的のみ・全部入りの AUPRC と、長さ 1.0 ns の回復率が記録と一致しなければ止める、と先に決めた。

## 4. 読み取り

- **長さ 0 の回復率は、全予測幅でちょうど 0.0000。**これは、起点フレーム10の距離が静的な特徴にすでに含まれているためで、フレーム10だけの統計量は静的な予測に何も足さない。L の長さ 0（フレーム0だけ）は、静的な特徴に含まれていないフレーム0の距離を持ち込んでいたため、回復率が 0 にならなかった。
- **1 ns先:** 0.8 に届く長さは L の 0.6 ns から 0.4 ns へ短くなった。
- **5 ns先:** 0.8 に届く長さは L の 0.5 ns から 0.7 ns へ長くなった。
- **10 ns先:** 0.8 に届く長さは L の 0.4 ns から 0.6 ns へ長くなった。
- **30 ns先:** 0.8 に届く長さは L の 0.4 ns から 0.6 ns へ長くなった。
- **50 ns先:** 0.8 に届く長さは L と同じ 0.7 ns だった。

## 5. 判断できること・まだ分からないこと

- 判断できること: 区間を起点の直前に置き直しても、短い区間で利得の大半が戻る形が残るかどうかは、上の表の通りである。長さ 0 の回復率がちょうど 0 になることは、起点の距離が静的な特徴に含まれていることの帰結である。
- まだ分からないこと: 予測幅によって置き直しの影響がどう変わるか、その理由は、この実験では分からない。
