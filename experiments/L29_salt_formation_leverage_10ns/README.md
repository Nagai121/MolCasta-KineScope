# L29: L01 の曲がりを塩橋の形成で測る（K15 の土台、10 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の形成（K15 の土台、全予測幅、L27〜L32）の 10 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。**統合値の回復率はフレーム0だけ（覆う長さ 0 ns）で 1.246 と最も高く、長くするほど下がって 1.0 ns で 0.341 でした。** 曲がりは右下がりで、「長くすると戻る」形ではありません。タンパク質ごとの平均は分母の利得が小さい（+0.0352）ため大きく振れます。

## 1. 何を確かめる実験か

L27 と同じ段取りで、予測幅だけを 10 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。テスト 1,170件、10 ns先の陽性 131件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.246）**。最初の長さの時点で線を超えており、その後は下がります。「届く最小の長さ」という読み方自体が、この右下がりの曲がりには合っていません。
2. **増え幅がいちばん大きい場所: 0.7→0.8 ns（全体 +0.164、平均 +0.660）**。ただしタンパク質ごとの増え分の中央値は −0.144 で、正だったのは 15タンパク質のうち 47% にとどまり、段とは読めません。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 10 ns先では、履歴の最初のフレームの距離だけ（実質、履歴の始まりの水準）で全部入りの利得を上回り、平均を取る範囲を広げるほど全体の AUPRC は下がります。G60 の平均だけの走査（10 ns先、0.1 ns で 0.868、0.5 ns で 0.526）や G139（フレーム [0..9] の切り取りで 0.393、本実験の覆う長さ 0.9 ns の 0.393 と一致）と同じ形です。
- ただし区間が広く、0 ns の 1.246 も確かな値とは言えません。判断できるのは「10 ns先では長い平均が短い平均より良いという形にはなっていない」というところまでです。
