# L02: L01 の曲がりを強い土台で測る（K06(b) の条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L01（資料Dの条件、テスト 2タンパク質）では、回復率が覆う長さ 0.6 ns で 0.770 から 1.029 へ跳ね、0.8 と 0.9 の線をどちらも 0.6 ns で初めて超える「段」が見えた。ただし段の大きさはタンパク質で違い（1mix_A 1.190、2qt4_A 0.850）、テストが 2タンパク質だけでは一般の形か決められなかった。ここでは土台を強い土台（未見100タンパク質×3レプリカ）に変えて同じ曲がりを測り、段が残るかを判定する。
- 状態: 完了。**強い土台では曲がりは滑らかで、0.6 ns の段は残らなかった。** 増え幅がいちばん大きいのは最初の 0→0.1 ns（全体 +0.192）で、0.5→0.6 ns の増え分（全体 +0.079）は 0.2→0.3 ns（+0.098）・0.7→0.8 ns（+0.094）・0.8→0.9 ns（+0.098）と同じ程度の大きさにすぎない。回復率 0.8 に届く最小の長さは全体で 0.7 ns、0.9 に届く最小の長さは全体で 0.8 ns（タンパク質ごとの平均では 0.9 ns）で、どちらも L01 の 0.6 ns より後ろにずれた。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として強い土台の補正モデルに入れたときの 1 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K06(b)（強い土台）と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、1 ns先の陽性 11,712件）で評価する。静的特徴は5個、履歴の要約値は10個（最初、平均、標準偏差、最小、最大、最後−最初、最後−直前、3.5 Å以下割合、4.5 Å以下割合、増加割合）。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 1 ns先。条件ごとに学習し直す。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`、タンパク質ごとの `r{r}_series`、11点×候補数）をそのまま使う。静的特徴と履歴の要約値は K06(b) の保存値（`~/workspace/k06b/run/k06b_out/`）を使う。実行はローカルVM（学習13条件で約20秒、ブートストラップ 10,000回で約6分半）。

| G05 全部の平均だけ | 0〜10 | 1.0 ns |
| G145 1.0 ns | 0〜9 | 0.9 ns |

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（G05 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（結果を見る前に固定、G147・G148・G162 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す、ふつうのブートストラップである（L01 のテスト 2タンパク質のような3通りしか取らない粗さはない）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取り（しきい値で区切って精度と再現率を取り、再現率の増え分で重み付けする）を numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC（学習済みモデルの予測から出した固定値）を、再標本化の重なり具合で重み付けして平均したもの。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

## 5. 読み取り

- **0.6 ns の段は、タンパク質を増やすと残らなかった。** 強い土台（100タンパク質）では、回復率は覆う長さに対して滑らかに上がる。増え分は最初の 0.1 ns（+0.192）が突出して大きく、あとは 0.2→0.3 ns・0.5→0.6 ns・0.7→0.8 ns・0.8→0.9 ns に +0.08〜+0.10 ずつ分散し、0.3→0.5 ns はほぼ平ら（+0.010、+0.015）。「0.6 ns まで来ると急に効く」という形ではなく、「最初の 0.1 ns で大きく戻り、その後は 0.9 ns まで緩やかに積み上がる」形である。
- 線に届く長さは L01 より後ろにずれた。0.8 の線は 0.7 ns、0.9 の線は全体で 0.8 ns（平均では 0.9 ns）。L01 の「0.6 ns で 0.8 と 0.9 を同時に超える」は、2タンパク質の土台での跳ねに引っ張られた読みだったと考えられる。
- ただし 0.5→0.6 ns の増え分は、タンパク質ごとの平均では +0.100 と、その前後の区間（0.4→0.5 ns で −0.008、0.6→0.7 ns で +0.039）よりは大きい。完全に均一な滑らかさではなく、0.6 ns のあたりに緩い膨らみは残っている。ただ L01 の +0.260 のような段とは別物で、線をまたぐ跳ねではない。
- フレーム0だけ（覆う長さ 0 ns）でも回復率 0.353（全体）が戻る点、0.1 ns で 0.545 まで上がる点は L01・G05 と同じで、短い切り取りの効き方の骨格は土台を変えても変わらない。
- 費用の側は L01 と同じくまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03（G04 の実測との対応付け）で行う。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、1 ns先）では、回復率 0.8 に届く最小の覆う長さは 0.7 ns、0.9 に届く最小の覆う長さは全体で 0.8 ns（タンパク質ごとの平均では 0.9 ns）。増え幅がいちばん大きいのは 0→0.1 ns（+0.192）で、L01 で見えた 0.6 ns の段は残らなかった。0.6 ns の段は、テスト 2タンパク質の土台に依存した形だったと判断できる。
- まだ分からないこと: 他の予測幅・他の現象でも曲がりが滑らかか。0.5→0.6 ns に残る緩い膨らみ（平均で +0.100）が何かは、この実験では切り分けていない。実測の費用に直したときの形（L03 の担当）。
