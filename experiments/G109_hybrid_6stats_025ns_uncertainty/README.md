# G109: 切り取り 0.25 ns の 6 個の統計量の混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。切り取り 0.25 ns の 6 個の統計量の混合で、G100・G102・G103・G104 で +0.05 を超えたのは次の10セルでした。

- G100（水素結合の形成、1・30 ns先）: 30 ns先の第13案 +0.106・第22案 +0.624
- G102（塩橋の形成、5・30 ns先）: 5 ns先の第12案 +0.122、30 ns先の第11案 +0.117・第12案 +0.167・第14案 +0.051
- G103（水素結合の解離、1・30 ns先）: 1 ns先の第11案 +0.051・第13案 +0.051
- G104（接触の形成、1・30 ns先）: 1 ns先の第13案 +0.062、30 ns先の第11案 +0.064

各現象について、混合と切り取り 0.25 ns の 6統計量だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G59・G62・G67 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（上の10セル）の区間が 0 を含むかどうかを見ます。

## データと条件

- 切り取りは 0.25 ns（フレーム [0,1,2]、実際には 0.2 ns を覆う）の 6 個の統計量です（G100・G102・G103・G104 と同じ）。6統計量は [最初のフレーム、平均、標準偏差、最小、最後−最初、しきい値以下だった割合] で、3フレームの系列から計算します。生成平均は、生成系列の平均です。なお、切り取りの平均だけの回復率も照合のために測り直しました（G100・G103・G104 は各実験の記録と一致しました。G102 も平均だけの切り取りを測りました）。
- 4つの現象で、データと条件はそれぞれ次の通りです（G100・G102・G103・G104 と同じ段取り）。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。生成器のチェックポイントは読み込んでいません。
  - 水素結合の形成（G100）: 資料Dの条件。実側は DocD キャッシュ（`~/workspace/kinescope/work/data_cache/`、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件、うち 1mix_A 3,101件・2qt4_A 1,871件））。生成平均は第11〜14案が K11（`experiments/K11_method_generality/series/`、4分岐×8点の平均）、第22案が K05 の生成系列（`experiments/K05_generated_quality/generated_series.npz`、5点系列の平均）です。しきい値は 3.5 Å、予測幅は 1 ns先と 30 ns先です。
  - 塩橋の形成（G102）: K15 の広げた条件。実側は K15 キャッシュ（`~/workspace/kinescope/work/k15_cache/`、学習 58 タンパク質（2,557件）、テスト 30 タンパク質（1,170件））。生成平均は第11〜14案が G19 で作り直した系列（`experiments/G19_salt_prefix_plus_generated/gen/`、4分岐×9点の平均）です。しきい値は 4.0 Å、予測幅は 5 ns先と 30 ns先です。学習とテストの分け方は K15 の `split.json` と同じです。
  - 水素結合の解離（G103）: 資料Dの条件。実側は K46 キャッシュ（`~/workspace/kinescope/work/data_cache_k46/`、学習 4,051件、テスト 2,080件、うち 1mix_A 1,415件・2qt4_A 665件）。生成平均は第11〜14案が K54 の残基レベル生成系列（`~/workspace/kinescope/work/k54_gen_residue/`、4分岐×9点の平均）、第22案が G18 で作り直した生成系列（`~/workspace/kinescope/work/g18_gen22/`、5点系列の平均）です。しきい値は 3.5 Å、予測幅は 1 ns先と 30 ns先です。対応付けは、K54 のファイルの並びそのままで、donor_atom・acceptor_atom が K46 キャッシュと一致することを確かめました。第22案は (軌道ID, ドナー原子, アクセプター原子) のキーで対応付けました。
  - 接触の形成（G104）: 資料Dの条件。実側は K13 キャッシュ（`~/workspace/kinescope/work/k13_cache/`、学習 15,926件、テスト 7,384件、うち 1mix_A 5,012件・2qt4_A 2,372件）。生成平均は第11〜14案が K17（`~/workspace/k17/out/`、4分岐×9点の平均）です。しきい値は 4.5 Å、予測幅は 1 ns先と 30 ns先です。K17 の保存した実側（X, hist, y）が K13 キャッシュと配列単位で一致することを確かめてから位置で結合しました。
- 条件は現象ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り 0.25 ns の 6統計量だけ、切り取り 0.25 ns の平均だけ、生成平均だけ（第11〜14案と第22案、ただし塩橋と接触は第11〜14案だけ）、混合（切り取り 0.25 ns の 6統計量＋生成平均、別々の特徴量として 7列。第11〜14案と第22案、ただし塩橋と接触は第11〜14案だけ）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り 0.25 ns の 6統計量だけの回復率です。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G100・G102・G103・G104 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。
- 第22案についての留保（G100・G103 と同じ）: 第22案は生成器が学習した範囲（形成の候補だけ）の外への当てはめです。解離の候補に対する生成平均として使うのは、生成器の学習範囲の外への当てはめになります。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67 と同じです。
- 再標本化の単位: タンパク質。塩橋だけはテストが 30 タンパク質あるため、タンパク質単位の真の再標本化を行いました（G73・G96 と同じ）。それ以外の 3 現象はテストが 1mix_A と 2qt4_A の 2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り 0.25 ns の 6統計量だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions_<現象>.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G100・G102・G103・G104 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions_<現象>.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: 2 タンパク質の現象では、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。塩橋では、1回の抽出につき行の集合を1回だけ作り、静的のみ・全部入り・切り取り 0.25 ns の 6統計量だけの AUPRC は予測幅ごとに1回だけ測って4案で使い回します。AUPRC の計算には sklearn と同じ段取りの numpy 版（ap_fast、しきい値で区切って精度と再現率を測る）を使い、実際の予測確率で sklearn の値と 1e-12 まで一致することを確かめてから使いました（G73・G96 と同じ。今回の実測の最大誤差は 1.11e-16 でした）。
- 塩橋のセルは土台の利得が小さい（5 ns先 +0.0788、30 ns先 +0.0884）ため、回復率の差だけでは読みを誤ります。塩橋については、混合と切り取り 0.25 ns の 6統計量だけの AUPRC の差の絶対値も記録します（点推定、タンパク質ごとの値、ブートストラップ 95% 区間）。AUPRC の差の区間は、ほかの 3 現象についても同じやり方で出しました。

## 結果

## 判断

先に固定した読み方に沿うと、+0.05 を超えた10セルのうち、**区間が 0 を含まないのは4セル**で、**0 を含むのは6セル**です。

- 水素結合の形成の 30 ns先の第13案 [+0.056, +0.120] と第22案 [+0.524, +0.761] は、いずれも 0 を含みません。2タンパク質とも差が正です。第22案の AUPRC の差の絶対値も +0.0390（区間 [+0.0276, +0.0682]）と 0 を含みません。第13案は AUPRC の差の絶対値で +0.0066 と小さいです。30 ns先の利得が +0.0626 と小さいため、回復率の差は AUPRC の小さな差でも大きく出る点に注意が要ります（G105 の README と同じ留保）。
- 水素結合の解離の 1 ns先の第13案 [+0.038, +0.052] は 0 を含みません。2タンパク質とも差が正です。AUPRC の差の絶対値も +0.0091（区間 [+0.0045, +0.0163]）と 0 を含みません。第11案 [+0.025, +0.140] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で −0.025、2qt4_A で +0.140）。AUPRC の差の区間 [−0.0030, +0.0441] も 0 を含みます。なお、第11案と第13案の点推定はいずれも +0.051 と線のすぐ上で、区間の形だけが違います。
- 接触の形成の 30 ns先の第11案 [+0.045, +0.119] は 0 を含みません。2タンパク質とも差が正です。AUPRC の差の絶対値も +0.0097（区間 [+0.0057, +0.0236]）と 0 を含みません。1 ns先の第13案 [−0.069, +0.146] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で +0.146、2qt4_A で −0.069）。AUPRC の差の区間 [−0.0236, +0.0256] も 0 を含みます。
- 塩橋の形成の +0.05 を超えた4セル（5 ns先の第12案、30 ns先の第11・12・14案）は、**すべて区間が 0 を含みます**。AUPRC の差の絶対値の区間もすべて 0 を含みます。0.1 ns の切り取り（G73・G96）と同じく、塩橋の混合の「足し」はタンパク質の水準では言えません。

+0.05 を超えなかったセルでは、水素結合の形成の 1 ns先の第13案 [−0.177, −0.164] と第14案 [−0.212, −0.062] は区間も 0 を含まず負です。水素結合の解離の 1 ns先の第22案 [−0.039, −0.023]、30 ns先の第13案 [−0.044, −0.016]・第14案 [−0.130, −0.043]・第22案 [−0.198, −0.019] は区間も 0 を含まず負です。接触の形成の 30 ns先の第13案 [−0.120, −0.083] は区間も 0 を含まず負です。

## 読みの注意点

- **2 タンパク質の現象（水素結合の形成・解離、接触の形成）では、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・案ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- **塩橋では、タンパク質ごとの回復率の差は土台の利得が小さいタンパク質で大きく振れます。** 30 ns先の第12案はタンパク質ごとの回復率の差が最小 −99.713、最大 +5.361 です。回復率の差の読みは、AUPRC の差の絶対値と併せて見るべきです（G96 と同じ留保）。
- **塩橋のテストには、その予測幅で陽性が 0 件のタンパク質があります**（5 ns先は 1pch_A・2ftx_A・2qt4_A・6fc0_B の4つ、30 ns先は 1pch_A・1uha_A・2qt4_A の3つ）。そのタンパク質の AUPRC は sklearn の慣習で 0.0 になり、実履歴の利得も 0 になるため、タンパク質ごとの回復率は 0/0 で定義されません（`results.json` の `per_protein` には NaN として入っています。なお、30 ns先では 4ytw_C も利得が 0 で回復率が NaN です）。合算のブートストラップには影響しません（再標本化した集合には必ず陽性が入るため、区間はすべて有限です）。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約8分でした。
