# K16: 接触形成での担い手の切り分け

## 仮説

H5（特徴量の抽出と読み出し）と H7（実軌道が持つ追加の観測情報）に関わる検証です。K13 で、接触形成の実履歴の指導力は水素結合より大きい（AUPRC の差で +0.152〜+0.232）ことが分かりました。水素結合でやった担い手の切り分け（K09 の統計量の差し替え、K03 の履歴の入れ替え）を、接触でも行います。

読み方は実験前に固定しました。接触でも平均の統計量が主で、別の候補の履歴では崩れるなら、担い手の形は水素結合と共通ということになります。違う統計量が主だったり、別の候補の履歴でも残ったりすれば、現象ごとに担い手が違うことになります。

## データと条件

- 資料Dの条件（K13 と同じ土台）です。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（接触の候補 15,926件）、テスト 1mix_A と 2qt4_A の合算（7,384件、陽性 214〜257件）。接触形成は、残基ペアの最小重原子間距離で、候補は起点（フレーム10、1 ns）で 4.5 Å 超、ラベルは予測先で 4.5 Å 以下です。静的特徴は5個、履歴は 0〜1 ns の11フレームから作る6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.5 Å 以下だった割合）です。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で、条件ごとに学習し直します（パート2は K03 と同じく学習は実履歴のまま、テストだけ差し替えます）。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- 距離系列は K13 の抽出済みキャッシュ（`~/workspace/kinescope/work/k13_cache/`）を使いました。抽出の時点で、距離はフレームごとの箱を軸ごとに扱う周期境界で計算されています。
- 土台の再現確認: 静的のみと実履歴ありの AUPRC が、K13 の値と全6予測幅で小数第4位まで一致しました（差 0.0）。

## パート1: 統計量の差し替え（K09 との違い）

接触には生成側の条件が無いので、K09 の「生成の統計量をその候補自身の実の値に戻す」という差し替えはできません。代わりに、実系列の6統計量を土台に、統計量を1つずつ「学習側全体の平均値（定数）」に差し替えました。定数にすると、その統計量は候補ごとの情報を持たなくなります。指導力がどれだけ落ちるかで、その統計量が指導力をどれだけ担っているかを測ります。

K09 と違う点は3つです。

1. 差し替えの向きが逆です。K09 は生成の統計量に実の値を入れて「情報を足す」実験（その統計量だけでどこまで戻るか＝足りるかを見る）でした。本実験は実の統計量を定数にして「情報を引く」実験（その統計量が要るかを見る）です。
2. 差し替える値は、その候補自身の値ではなく、学習側全体の平均です（最初の値 7.3326、平均 7.4030、標準偏差 0.3820、最小値 6.7613、最後−最初 0.0367、4.5 Å以下の割合 0.0278）。定数は学習側だけで決め、テスト側の情報は使っていません。
3. 差し替えは学習側・テスト側の両方に当て、条件ごとに学習し直す点は K09 と同じです。

残存率 =（差し替え条件の AUPRC − 静的のみ）÷（実履歴の AUPRC − 静的のみ）で、指導力のうちどれだけ残ったかを示します。

## パート2: 履歴の入れ替え（K03 と同じ段取り）

学習は実履歴のまま、テストの履歴（11フレームの距離系列）だけを差し替えて評価しました。

- 別ペアへの差し替え: 同じタンパク質・同じ複製の中で、テスト候補の履歴を別の候補の履歴にランダムに入れ替えます（seed は K03 と同じ 123）。
- 別複製への差し替え: 同じ残基ペア（res_i, res_j）の履歴を別の複製（R1←R2、R2←R3、R3←R1）から持ってきます。同じペアが別複製でも候補になっている場合だけ差し替えでき、差し替えできたのはテスト 7,384件中 6,646件（90.0%）で、残りは元の履歴のままです。差し替えできた候補だけに絞った評価も行いました。

## 判断できること

読み方は実験前に固定したとおりに判定します。結果は2つのパートで分かれました。

- **履歴の入れ替えの側は、水素結合と共通です。** 別ペアの履歴に差し替えると、指導力は消えるだけではなく、静的のみより大きく悪くなりました（1 ns先で AUPRC 0.5669 → 0.0543、残存率は全幅で −1.04〜−1.65）。モデルは履歴を強く信用していて、違うペアの履歴は誤った情報として働きます。一方、別複製の同じペアの履歴では指導力の大半が残りました（残存率 0.875〜1.093）。差し替えできた候補だけに絞っても、1 ns先の低下は約0.035 で、水素結合（K03、約0.034）とほぼ同じです。指導力は「そのペア自身の履歴」であることに依存し、複製が違ってもペアが同じなら大半が保たれる、という形は2現象で共通しています。
- **統計量の側は、水素結合と形が違います。** どの統計量を1つ定数にしても、指導力はほとんど落ちませんでした。平均を定数にしても残存率は 0.90〜1.05 で、他の5つもすべて 0.88〜1.08 の範囲です。つまり接触では、単独で指導力を担っている統計量はありません。情報は複数の統計量に重なって入っていて、1つを消しても残りで補えます。水素結合で見えた「平均が主な通り道」という形（K09 で、生成の平均を実の値に戻すだけで不足分がほぼ戻った）は、接触では確認できませんでした。
- ただし、この2現象の統計量の比較は、実験の向きが違う点に注意が必要です。K09 は「足す」実験（その統計量だけで足りるか）で、本実験のパート1は「引く」実験（その統計量が要るか）です。水素結合で平均が「足りる」ことと、接触で平均が「要らない」ことは、統計量どうしが互いに重なった情報を持てば両立します。現象ごとに担い手が違う、とまで言えるのは、「接触では単独の統計量に指導力が集中していない」という本実験の範囲の読みまでです。水素結合で同じ「引く」実験をしたときも同じ形になるかは、まだ分かりません。

## まだ分からないこと

- 接触で、統計量を複数同時に定数にすると指導力がどう落ちるかは試していません。情報がどの組み合わせに分散しているかは、同時差し替えをしないと分かりません。
- 水素結合で同じ「引く」実験（統計量を1つずつ定数にする）をした場合に、平均を引くと指導力が消えるのか、接触と同じく残るのかは分かりません。2現象の統計量の担い手を同じ物差しで比べるには、この実験が要ります。
- 残存率が 1 を超える条件が複数あります（単独差し替えで AUPRC が土台をわずかに上回る）。単一の学習 seed の結果であり、ばらつきの範囲は測っていません。

## コードと出力

- `run_experiments.py`: 本実験のコードです。K13 のキャッシュを読み、土台の再現確認、パート1の差し替え6条件、パート2の入れ替え2条件と絞った評価を行います。途中結果を `results_partial.json` に条件ごとに書き出します。
- `results.csv` / `results.json`: 全条件・全予測幅の全指標、残存率、定数の値、K13 との照合結果です。
- 実行はこの仮想マシン上です（Colab は使っていません）。
