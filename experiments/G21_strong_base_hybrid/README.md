# G21: 強い土台で、混合は足しになるか（K06(b) の条件、水素結合の形成、1 ns先）

- 確かめること: G11（資料D、弱い土台）では、0.1 ns の切り取り平均に生成平均を足すと回復率が 0.570 → 0.756 と +0.186 上がった。強い土台（K06(b)、凍結した本体モデル＋補正モデル）でも同じか。G05 で強い土台の切り取り平均だけでは回復率 0.545／0.553 だった。ここに生成した平均（K06(b) の生成特徴量のうち平均）を足し、同じ補正モデルで測る。
- 状態: 完了。混合の回復率は 0.462／0.490 で、切り取り平均だけ（0.545／0.553）より −0.083／−0.062 下がった。強い土台では、生成平均を足すと逆に下がる。

## 1. 何を確かめる実験か

条件は K06(b) の水素結合の形成、1 ns先。系列は G05 で作り直したもの（11点系列）を使う。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、混合は強い土台でも足しになる。+0.05 未満なら、混合の効き目は弱い土台（資料D）に限られる。

## 2. 条件

- 土台は K06(b)／G05 と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）。較正8タンパク質で学習し、未見の100タンパク質×3レプリカ（163,074件、1 ns先の陽性 11,712件）で評価する。静的特徴は5個。
- 切り取り平均: G05 で作り直した11点系列の始めの2フレーム（0、0.1 ns）の平均。G05 と同じ定義。
- 生成平均: K06(b) の保存データの生成6特徴量（`r{r}_gen6`）のうち平均の列。第22案の生成5点系列（起点＋0.1／0.3／0.5／1.0 ns先）の平均。検証として、生成平均と実の 0〜1 ns の平均の相関はテストで 0.786 で、K43 の記録と一致した。
- 注意: 生成系列は起点から先への前方系列で、切り取りは起点までの後方履歴の始めの部分。平均は向きに依らない量なので、向きの違いは平均の定義に影響しない（G11 と同じ留保）。
- 条件: 静的のみ／履歴全部入り（参照）／実の平均だけ（参照）／切り取り平均だけ／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る。実履歴の利得は全体 +0.0702、macro +0.0712。

## 3. 結果

土台の再現: 静的のみ 0.4591／0.4539、全部入り 0.5293／0.5251、切り取り平均だけ 0.4974／0.4933（回復率 0.545／0.553）で、K06(b) と G05 の記録と小数第4位まで一致した。

| 条件 | AUPRC（全体） | AUPRC（macro） | 回復率（全体） | 回復率（macro） |
|---|---|---:|---:|---:|
| 静的のみ | 0.4591 | 0.4539 | — | — |
| 履歴全部入り | 0.5293 | 0.5251 | 1.000 | 1.000 |
| 実の平均だけ | 0.5275 | 0.5221 | 0.975 | 0.957 |
| 切り取り平均だけ | 0.4974 | 0.4933 | 0.545 | 0.553 |
| 生成平均だけ | 0.4568 | 0.4520 | −0.032 | −0.027 |
| 混合 | 0.4915 | 0.4888 | 0.462 | 0.490 |

混合 − 切り取り平均だけ: 全体 −0.083、macro −0.062。

切り取り平均と生成平均の関係（テスト、163,074件）: 相関 0.637、生成平均 − 切り取り平均は平均 −0.280 Å・標準偏差 0.958 Å。生成平均と実の 0〜1 ns の平均の相関は 0.786、切り取り平均と実の平均の相関は 0.908。

## 4. 読み取り

先に固定した読み方に照らすと、混合の回復率は切り取り平均だけより +0.05 以上上がるどころか、−0.083／−0.062 と下がった。混合の効き目は弱い土台（資料D）に限られ、強い土台では生成平均を足すと逆効果になる、というのがこの測定の結論。G11（弱い土台、+0.186）とは正反対の結果。

理由として考えられるのは、強い土台では凍結モデルの確率そのものが構造の豊富な関数であり、生成平均は大半が静的情報から予測できる量（K39 で静的特徴への当てはめの R² が 0.97、K43 で静的予測と相関 0.97）なので、補正モデルにとって新しい情報にならず、生成平均のばらつきと短いほうへの偏りが雑音として働くこと。弱い土台（静的特徴7つ、凍結モデルなし）では同じ生成平均がまだ静的に無い分を持っていたため、G11 では足しになった。これは読み取りで、仕組みそのものを直接測ったわけではない。

生成平均だけの条件は回復率 −0.032／−0.027 と静的のみよりわずかに悪く、K06(b)・K34（強い土台では生成特徴量は再学習しても何も足さない）と一致する。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、0.1 ns の切り取り平均に生成平均を足しても指導力は戻らず、回復率は 0.545／0.553 から 0.462／0.490 へ下がる。混合が足しになるのは弱い土台（資料D、G11）のときだけ。強い土台での回復の経路は、短い実MDの切り取りそのもの（G05）であって、生成平均の混合ではない。
- まだ分からないこと: 弱い土台と強い土台のあいだの、どの水準から生成平均が足しにならなくなるか。生成平均以外の生成した量（割合など）を足した場合も同じか。
