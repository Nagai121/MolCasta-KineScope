# G21: 強い土台で、混合は足しになるか（K06(b) の条件、水素結合の形成、1 ns先）

- 確かめること: G11（資料D、弱い土台）では、0.1 ns の切り取り平均に生成平均を足すと回復率が 0.570 → 0.756 と +0.186 上がった。強い土台（K06(b)、凍結した本体モデル＋補正モデル）でも同じか。G05 で強い土台の切り取り平均だけでは回復率 0.545／0.553 だった。ここに生成した平均（K06(b) の生成特徴量のうち平均）を足し、同じ補正モデルで測る。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は K06(b) の水素結合の形成、1 ns先。系列は G05 で作り直したもの（11点系列）を使う。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、混合は強い土台でも足しになる。+0.05 未満なら、混合の効き目は弱い土台（資料D）に限られる。
