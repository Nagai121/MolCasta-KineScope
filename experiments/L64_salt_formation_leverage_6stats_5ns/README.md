# L64: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、5 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L28（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）の 5 ns先です。
- 状態: 完了。統計量6種の回復率（全体）は全長さで平均だけを下回りました。0.8 の線に届く最小の長さは 0.3 ns（平均だけは 0.1 ns）、0.9 の線は 0.9 ns（平均だけは 0.2 ns）で、必要な長さは縮みませんでした。

## 1. 何を確かめる実験か

L63 と同じ段取りで、予測幅だけを 5 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、5 ns先の陽性 129件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns（全体 0.874）**。ただし 0.5〜0.8 ns では再び線を下回り、持続しません。平均では 0 ns（0.843）。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.9 ns（全体 1.127）**。平均では 0.1 ns（1.320）ですが、平均の数値は安定していません。
3. **増え幅がいちばん大きい場所: 0.8→0.9 ns（全体 +0.480、平均 +3.064）**。段の位置でのタンパク質ごとの増え分は中央値 +0.468、正だったのは 19タンパク質のうち 74% でした。
4. **平均だけとの比較: 必要な長さは縮みませんでした。** 0.8 の線は平均だけの 0.1 ns に対して 0.3 ns、0.9 の線は 0.2 ns に対して 0.9 ns と、どちらも長くなりました。長さごとの回復率の差（6種 − 平均、全体）は全長さで負で、最も大きいのは 0.1 ns の −0.549 でした。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 19タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 5 ns先でも、統計量を増やすことは短い切り取りの助けになっていません。平均だけの曲がりが高い水準（0.85〜1.29）にあるのに対し、6種は 0.30〜1.13 で上下し、全体に下回ります。
- L63（1 ns先）と合わせると、形成側では統計量6種は平均だけより必要な長さが長い、という形が続いています。
