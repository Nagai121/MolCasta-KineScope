# L66: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、30 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L30（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）の 30 ns先です。
- 状態: 完了。平均だけではいちばん読みやすい曲がりだった予測幅（L30）ですが、統計量6種では回復率が低めに推移し、0.8 の線は 0.3 ns、0.9 の線は 0.6 ns で、平均だけ（どちらも 0.1 ns）より長くなりました。

## 1. 何を確かめる実験か

L63 と同じ段取りで、予測幅だけを 30 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、30 ns先の陽性 133件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

静的のみ AUPRC 0.1582、全部入り 0.2466、利得 全体 +0.0884／平均 +0.0965 で、L30 の記録と 5e-4 以内で一致しました。同じ実行で測り直した平均だけの回復率は、L30 の results.json の値と全長さで完全一致しました（最大の差 0.0）。統計量6種の 1.0 ns の回復率は 1.000 でした（`premise_check.json`）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns（全体 0.857）**。平均では 0 ns（1.148）。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.6 ns（全体 1.110）**。平均では 0 ns。
3. **増え幅がいちばん大きい場所: 全体では 0.4→0.5 ns（+0.374）**。段の位置でのタンパク質ごとの増え分は中央値 +0.086、正だったのは 20タンパク質のうち 50% で、段とは読めません。
4. **平均だけとの比較: 必要な長さは縮みませんでした。** 0.8 の線は平均だけの 0.1 ns に対して 0.3 ns、0.9 の線は 0.1 ns に対して 0.6 ns でした。長さごとの差（6種 − 平均、全体）は 0.1〜0.5 ns で −0.10〜−0.59 と負が続き、0.6 ns でだけ +0.188 と正でした。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 20タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 平均だけでは 0.1 ns でほぼ天井に達した予測幅でも、統計量6種では立ち上がりが遅く、ばらつきも残ります。形成側では、予測幅によらず6種が平均だけを上回らない形が続いています（L63〜L66）。
- 0 ns では両形の回復率が一致しました（0.625）。フレームが1つだけのとき、6種はその値から決まる量だけになるためです。
