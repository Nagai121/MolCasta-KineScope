# G09: 塩橋の解離で、短い切り取りがどこまで指導力を戻すか（K15 の広げた条件、塩橋の解離、1 ns先）

## 問い

G06 で、水素結合の解離と接触の解離では 0.1 ns の切り取りの平均だけで利得の 0.532 と 0.919 が戻りました。残りのセルである塩橋の解離でも同じか確かめます。

## 条件

- 土台は K15 の広げた条件（K53 と同じ）です。ATLAS 解析版、学習58タンパク質・テスト30タンパク質、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 塩橋の解離の候補（K53 と同じ）: 正側（LYS の NZ、ARG の NE/NH1/NH2）と負側（ASP の OD1/OD2、GLU の OE1/OE2）の荷電重原子ペアの最小距離が、起点で 4.0 Å 以下（塩橋ができている状態）で配列距離2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å を超えること。候補は学習 735件、テスト 360件（テストの陽性は 1 ns先で 101件、陽性率 28.1%）。静的特徴は5個、履歴の閾値は 4.0 Å です。
- 切り取りの定義（G02・G06 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。0.1 ns → フレーム 0, 1（2フレーム）、0.5 ns → フレーム 0〜5（6フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。
- 条件の一覧（1 ns先が主判断、他の予測幅は参考）:
  - 静的のみ: 静的特徴だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
  - 平均だけ（0〜1 ns）: 静的特徴＋0〜1 ns の平均だけ。
  - 切った平均だけ（主判断の条件）: 静的特徴＋切った履歴の平均だけ。
  - 切った6統計量（参考）: 切った履歴の6統計量全部。

## 結果

### 土台の再現

静的のみと全部入りが、K53 の記録と全予測幅で小数第4位まで完全一致しました。1 ns先で静的のみ AUPRC 0.3734、全部入り 0.5522、利得 +0.1788 です。平均だけ（0〜1 ns）も K53 と一致しました（AUPRC 0.5382、回復率 0.921）。

### (a) 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差、テスト側

| 切る長さ | テスト | 学習 |
|---|---:|---:|
| 0.1 ns | 1.150 Å | 1.065 Å |
| 0.5 ns | 0.531 Å | 0.541 Å |

切った平均と 0〜1 ns の平均の差の平均は、0.1 ns で +0.319 Å、0.5 ns で +0.220 Å でした。始めの短い部分の平均のほうが 0〜1 ns の平均より大きい向きです。参考: 水素結合の解離（G06）では 0.1 ns で 0.297 Å、接触の解離では 0.249 Å、水素結合の形成（G02）では 0.396 Å で、塩橋の解離の 1.150 Å はこれらよりはっきり大きく、2フレームの平均は 0〜1 ns の平均から大きく外れます。

### (b) 1 ns先の利得の回復率（主判断）

| 条件 | AUPRC | 回復率 |
|---|---:|---:|
| 静的のみ | 0.3734 | ― |
| 全部入り | 0.5522 | 1.000 |
| 平均だけ（0〜1 ns） | 0.5382 | 0.921 |
| 切った平均だけ 0.1 ns | 0.4973 | **0.693** |
| 切った平均だけ 0.5 ns | 0.5434 | **0.951** |
| 切った6統計量 0.1 ns | 0.4745 | 0.566 |
| 切った6統計量 0.5 ns | 0.5495 | 0.985 |

1 ns先の他の指標も、切った平均だけの条件で静的のみより改善しました（0.1 ns: AUC 0.5771 → 0.7119、Brier 0.2309 → 0.1919、Log Loss 0.7509 → 0.6714。0.5 ns: AUC 0.7780、Brier 0.1716、Log Loss 0.5865）。他の予測幅の回復率も参考値として results.json にあります（0.1 ns の平均だけ: 5 ns先 0.918、10 ns先 0.605、30 ns先 1.815、50 ns先 0.578、90 ns先 1.060。30 ns先の 1.815 は利得そのものが小さい幅（+0.0633）で比率が振れやすいためで、K53 の 1.381 と同じ扱いです）。

## 読み取り

- **0.1 ns の切り取りの平均だけで、利得の 0.693 が戻りました。** 先に固定した読み方に沿うと、解離は3現象とも短い実MDの路線でいけます（水素結合の解離 0.532、接触の解離 0.919、塩橋の解離 0.693）。0.5 ns まで伸ばすと 0.951 まで戻ります。
- 残りのばらつきが 1.150 Å と大きいのに回復率が 0.693 と高い点は、回復率が「切った平均が 0〜1 ns の平均にどれだけ近いか」だけで決まらないことを示しています。2フレームの平均は 0〜1 ns の平均から大きく外れても、それ自体が解離の向きについての情報をそれなりに持っています。水素結合の形成（G02、残りのばらつき 0.396 Å で回復率 0.570）と比べると、残りのばらつきと回復率の関係は現象ごとに違います。
- 切った6統計量を全部入れる条件は、0.1 ns で 0.566 と平均だけ（0.693）より悪く、0.5 ns でも 0.985 と平均だけ（0.951）とほぼ同じでした。接触の解離（G06）と同じ形で、短い切り取りでは平均だけを使う方が6統計量全部より良いか、同じくらいです。短い切り取りから作った他の統計量は、解離の候補ではほとんど変化がなく、むしろ読み出しを乱す側に働きます。
- ただしテストは 360件と小さく、1 ns先の陽性も 101件なので、回復率の揺れは形成（4,972件）より大きい条件です。単一の学習 seed の結果でもあります。

## 注意点

- K15 の欠け（2hng_A の R3 と 4cv4_A の R2 は、記録された箱が全フレームで 0 のため候補が0件）は、K53 と同じ扱いです。解離では1レプリカあたり平均約4件なので、欠けは約8件（テストの約2%）程度と見込まれ、結果と結論には影響しません。
- 実行はこの仮想マシン上です（`~/workspace/mt-venv` の Python）。1回目の実行はサービスの再起動で途中で止まりましたが、途中結果として残っていた4条件の値は、2回目の実行の値と完全に一致しました（静的のみ 0.3734、全部入り 0.5522、平均だけ 0.5382、0.1 ns の平均だけ 0.4973、すべて 1 ns先）。
