# G83: 水素結合の形成での混合の差に、残りの予測幅の区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。水素結合の形成では、G17・G37・G34 で 10 ns先の混合の差が −0.104/+0.001/−0.073、G39・G46・G38 で 50 ns先が +0.371/+0.288/+0.030、G14・G41・G30 で 90 ns先が +0.015/−0.072/+0.098 でした。10・50・90 ns先 × 切り取り 0.1/0.25/0.5 ns について、混合と切り取り平均だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G23・G49・G59 と同じやり方）。1・5・30 ns先は G49・G59・G23 で区間を付け済みです。

読み方は実験前に固定しました。+0.05 を超えたセル（10 ns先は無し、50 ns先の 0.1 ns と 0.25 ns、90 ns先の 0.5 ns）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの水素結合の形成です。G17・G37・G34・G39・G46・G38・G14・G41・G30 と同じ段取りで、資料Dのキャッシュ（`~/workspace/kinescope/work/data_cache/`、起点距離 3.5〜6.0 Å の候補、ラベルは予測幅で 3.5 Å 以下）と、第22案の生成系列（`experiments/K05_generated_quality/generated_series.npz`、5点前方系列 [起点距離 d0, +0.1, +0.3, +0.5, +1.0 ns]）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件、うち 1mix_A 3,101件・2qt4_A 1,871件）。静的特徴は7個、履歴はドナー・アクセプター距離の系列の6統計量（3.5 Å 以下だった割合）です。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）、0.25 ns（フレーム [0,1,2]、3フレーム）、0.5 ns（フレーム [0..5]、6フレーム）で、平均はそのフレームの距離の平均です（G02 と同じ）。生成平均は、生成5点系列の平均です。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、形成の候補 14,582件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å でした。生成器のチェックポイントは読み込んでいません。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ（0.1/0.25/0.5 ns）、生成平均だけ、混合（切り取り平均＋生成平均の2列、0.1/0.25/0.5 ns）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G11 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（3,101件）と 2qt4_A（1,871件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G17・G37・G34・G39・G46・G38・G14・G41・G30 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

### 土台の再現

3つの予測幅すべてで、静的のみ・全部入り・切り取り平均だけ（0.1/0.25/0.5 ns）・生成平均だけ・混合（0.1/0.25/0.5 ns）の合算 AUPRC が G17・G37・G34・G39・G46・G38・G14・G41・G30 の記録と小数第4位まで一致しました。実履歴の利得は、10 ns先 +0.0829、50 ns先 +0.0739、90 ns先 +0.1211 です。

### 3つの予測幅 × 3つの切り取りの差とブートストラップ 95% 区間

太字は +0.05 を超えたセル（先に固定した読みの対象）です。

| 予測幅 | 切り取り 0.1 ns | 切り取り 0.25 ns | 切り取り 0.5 ns |
|---|---:|---:|---:|
| 10 ns | −0.104 [−0.122, −0.035] | +0.001 [−0.180, +0.262] | −0.073 [−0.221, +0.164] |
| 50 ns | **+0.371 [+0.235, +0.872]** | **+0.288 [+0.236, +0.580]** | +0.030 [+0.014, +0.205] |
| 90 ns | +0.015 [+0.015, +0.076] | −0.071 [−0.115, −0.057] | **+0.098 [+0.061, +0.203]** |

テスト陽性は、10 ns先 325件、50 ns先 325件、90 ns先 335件です。

### タンパク質ごとの差（回復率の差）

| 予測幅 | | 切り取り 0.1 ns | 切り取り 0.25 ns | 切り取り 0.5 ns |
|---|---|---:|---:|---:|
| 10 ns | 1mix_A | −0.122 | −0.180 | −0.221 |
| | 2qt4_A | −0.035 | +0.262 | +0.164 |
| 50 ns | 1mix_A | +0.872 | +0.580 | +0.205 |
| | 2qt4_A | +0.235 | +0.236 | +0.014 |
| 90 ns | 1mix_A | +0.076 | −0.115 | +0.061 |
| | 2qt4_A | +0.029 | −0.057 | +0.203 |

10 ns先の 0.25 ns と 0.5 ns では、2タンパク質で差の向きが食い違います（1mix_A で負、2qt4_A で正）。50 ns先では 3つの切り取りすべてで 2タンパク質とも差が正です。90 ns先では 0.1 ns と 0.5 ns で 2タンパク質とも差が正、0.25 ns で 2タンパク質とも差が負です。

## 判断

先に固定した読み方に沿うと、+0.05 を超えた3セルの区間は、**すべて 0 を含みません**。

- 50 ns先の 0.1 ns [+0.235, +0.872] と 0.25 ns [+0.236, +0.580] は、どちらも 0 を含みません。2タンパク質とも差が正です。ただし 0.1 ns の区間は幅が広く（1mix_A +0.872 に対し 2qt4_A +0.235）、上がりの大きさはタンパク質で違います。
- 90 ns先の 0.5 ns [+0.061, +0.203] も 0 を含みません。2タンパク質とも差が正（1mix_A +0.061、2qt4_A +0.203）です。

+0.05 を超えなかったセルでは、10 ns先の 0.1 ns [−0.122, −0.035] と 90 ns先の 0.25 ns [−0.115, −0.057] は区間も 0 を含まず負で、2タンパク質とも差が負です。10 ns先の 0.25 ns と 0.5 ns の区間は 0 を含み、タンパク質ごとの差の向きが食い違います。50 ns先の 0.5 ns [+0.014, +0.205] と 90 ns先の 0.1 ns [+0.015, +0.076] は区間が 0 を含まず正ですが、点推定が +0.05 に届いていません。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・切り取りごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約3分でした（最初の実行は生成系列の場所の指定が違っていて失敗し、直してやり直しました）。
