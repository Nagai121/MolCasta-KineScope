# K2-164: K2-15 の問い（漂い）を割合で測る（塩橋の解離、90 ns先）

- 状態: 完了。全部の割合＋漂いは 0.5113 で、全部の割合だけ（0.5289）を 0.0175 下回り、先に固定した読み方では「漂いは足しにならない」。

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。K2-15 の問い（漂い）を割合で測ります。漂いは、前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）で、割合はペアの荷電重原子間の最小距離が塩橋の閾値（4.0 Å）以下の時間の割合です。

読み方は K2-15 と同じく先に固定しました。全部の割合＋漂いが全部の割合だけを AUPRC で +0.01 以上上回れば「漂いが足しになる」、そうでなければ「足しにならない」とします。

## データと条件

- K15 の条件（58 タンパク質で学習、30 タンパク質でテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、塩橋の解離、90 ns先、割合だけです。学習 735件、テスト 360件、テスト陽性 160件です。キャッシュは `~/workspace/kinescope/work/k53_cache/`（塩橋の解離の候補ごとの荷電重原子間の最小距離の 11 フレーム系列）を使っています。静的特徴は 5 個です。
- 実行はローカルの仮想マシンで行いました（9 条件の学習で約 6 秒。K2 系列では重い計算は Colab に逃がす決め事がありますが、この規模は重い計算にはあたらないと判断しました）。sklearn の学習はスレッド数を 1 に絞りました。

### 条件の一覧（90 ns先）

- 静的のみ: 静的特徴 5 個だけ（土台の照合用）。
- 全部入り: 静的特徴＋全部の 6 個の統計量（0〜1 ns の 11 フレーム）。6 個の統計量は [最初, 平均, 標準偏差, 最小, 最後−最初, 4.0 Å 以下だった割合]。利得の分母（全部入りの利得）の参照。
- 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の平均。K53 の mean_only との照合用。
- 前半の割合だけ: 静的特徴＋前半（フレーム [0..4]、0〜0.4 ns）の 4.0 Å以下割合（K2-143 との照合用）。
- 後半の割合だけ: 静的特徴＋後半（フレーム [6..10]、0.6〜1.0 ns）の 4.0 Å以下割合（K2-143 との照合用）。
- 前半と後半の両方（割合だけ）: 静的特徴＋前半の割合＋後半の割合（K2-143 との照合用）。
- 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の 4.0 Å以下割合。(b) の比較対象。
- 漂いだけ: 静的特徴＋漂い（前半の割合 − 後半の割合）だけ。(a) の比較対象。
- 全部の割合＋漂い: 静的特徴＋全部の割合＋漂い。(c) の比較対象。

フレーム 5（0.5 ns）は前半にも後半にも入らない設計です。K2-01 と同じ分け方で、前半と後半をきれいに分けるためです。

## 判断

先に固定した読み方に沿うと、**(c) 全部の割合＋漂い 0.5113 − (b) 全部の割合だけ 0.5289 = −0.0175 < +0.01 なので、「漂いは足しにならない」** です。

平均の漂いでも、塩橋の解離の 30 ns先では漂いが足しになりませんでした（K2-58、−0.0290）。90 ns先の平均の漂いが足しになるかどうかは、この実験だけでは決められません。漂いだけの利得は +0.0206（全部入りの利得に対する割合 0.354）で、漂いだけでも正の利得がありますが、全部の割合に足しても上乗せにはならず、むしろ悪くなりました。(c) は前半と後半の両方（0.5154）もわずかに下回ります。

## 読みの注意点

- 90 ns先では 2 つのテストタンパク質（1uha_A、1pch_A）に陽性が 1 件もありません。そのタンパク質の AUPRC は sklearn の慣例で 1.0、AUC は定義されません。合算の数値には影響しません。
- 90 ns先の土台の利得は +0.0582 と小さいため、割合は小さな AUPRC の差で大きく動きます。
