# G167: 接触の形成で、起点のフレームを入れるかどうかでの平均だけの回復率の差に、区間を付ける

## 仮説

G149 では、フレーム [0..9] の 10 フレームの平均だけ（mean10）とフレーム [0..10] の 11 フレーム全部の平均だけ（mean11）の回復率の差が、1 ns先 −0.206、5 ns先 −0.091、10 ns先 +0.005、30 ns先 −0.088、50 ns先 −0.093、90 ns先 −0.092 でした。ここでは 6 予測幅すべてについて、その差のブートストラップ 95% 区間を出します（G162・G163・G164 と同じ段取り）。

読み方は先に固定しました。回復率の差の区間が 0 を含むかどうかを、予測幅ごとに見ます。1 ns先は差が −0.206 と大きく、区間とあわせて記録します。

## やり方

- 再標本化の単位はタンパク質です。ただし土台は D 条件でテストが 2 タンパク質（1mix_A と 2qt4_A）だけなので、ブートストラップの取りうる組み合わせは 3通りしかありません（1mix_A だけを 2 回、2qt4_A だけを 2 回、1回ずつ）。**区間は 3 つの値の最小値と最大値の形で粗くなります。**G49・G59・G62・G67 と同じ粗さです。ブートストラップの値は 6 予測幅すべてで 3 通りだけでした（`n_distinct_boot_values` が 3）。
- ブートストラップの回数と乱数 seed は結果を見る前に固定しました。10,000回、seed 42。区間はパーセンタイル法（2.5%点と 97.5%点）です。G73・G49・G59・G62・G67・G23・G147・G148・G162・G163・G164 と同じです。
- G149 と同じ段取りでモデルを学習し直しました（同じ種・同じ条件で決定的なため、合算の AUPRC は記録と一致するはずで、一致を確認しました）。候補ごとの予測確率を保存し、そこからブートストラップしました。モデルを学習し直した AUPRC は、6 予測幅すべてで G149 の記録と小数第4位まで一致しました（静的のみ・全部入り・mean10・mean11 のすべて）。
- 回復率の差の定義は、(mean11 の回復率) − (mean10 の回復率) です。各ブートストラップ標本の中でも、静的のみ・全部入り・mean10・mean11 の AUPRC を測り直し、利得（全部入り − 静的のみ）と 2 つの回復率をその標本の中で計算し直しました。つまり回復率の分母の土台の利得は、標本ごとに測り直す（G147・G148 と同じ）。AUPRC の差（mean11 − mean10）の区間も同じ段取りで出しました。
- 計算の工夫：1回の抽出で 2 タンパク質を復元抽出し、その行の集合について、6つの予測幅 ×（静的のみ・全部入り・mean10・mean11）の AUPRC を測りました。AUPRC の計算は sklearn の average_precision_score と同じ段取り（しきい値で区切って精度と再現率を取り、再現率の増え分で重み付けする）を numpy で書き直したもので、実際の予測確率で sklearn の値と 1e-12 まで一致することを確かめてから使いました。抽出の乱数 seed は G23 と同じ 42 です。

**回復率の差の区間は、10 ns先を除く 5 予測幅で 0 を含みません。**AUPRC の差の区間も、10 ns先を除く 5 予測幅で 0 を含みません。10 ns先だけが、回復率の差の区間 [−0.135, +0.066] と AUPRC の差の区間 [−0.0342, +0.0101] の両方で 0 を含みます。

タンパク質ごとの回復率の差は、10 ns先を除く 5 予測幅で 2 タンパク質とも負です（1 ns先：1mix_A −0.274、2qt4_A −0.016。5 ns先：−0.073、−0.110。30 ns先：−0.083、−0.122。50 ns先：−0.019、−0.194。90 ns先：−0.079、−0.123）。10 ns先だけが、1mix_A +0.066 と 2qt4_A −0.135 で符号が分かれています。区間の下限と上限は、1mix_A だけの値と 2qt4_A だけの値のどちらかです（例えば 1 ns先の区間 [−0.274, −0.016] は、下限が 1mix_A だけの −0.274、上限が 2qt4_A だけの −0.016 です）。合算の点推定は、その 2 つの値の間にあります。

## 結論

先に固定した読み方に沿うと、**回復率の差の区間は 10 ns先を除く 5 予測幅で 0 を含みません。**接触の形成では、起点のフレームを入れると平均だけの回復率が下がる方向で、1・5・30・50・90 ns先で 2 タンパク質とも負です。10 ns先だけは、タンパク質ごとに符号が分かれ、区間が 0 を含みます。

ただし区間は 3 つの値の最小値と最大値の形で粗いです。**2 タンパク質だけの区間なので、区間が 0 を含まないことは、タンパク質の水準で確かだとは言えません。**区間が 0 を含まないのは、2 タンパク質の差がたまたま同じ向きだっただけかもしれません。30 タンパク質の土台（G162・G163・G164）とは、区間の細かさが違います。その点を踏まえて読んでください。
