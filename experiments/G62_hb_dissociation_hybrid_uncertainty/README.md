# G62: 水素結合の解離での混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G18 では水素結合の解離の 1 ns先で混合の差が −0.052、G44 では 30 ns先で +0.086、G50 では 50 ns先で +0.015、G54 では 90 ns先で −0.206 でした。4つの予測幅について、タンパク質単位の再標本化によるブートストラップ 95% 区間（G49・G59 と同じやり方）を出します。

読み方は実験前に固定しました。30 ns先の +0.086 の区間が 0 を含むかどうかと、4つの区間どうしの重なりを見ます。

## データと条件

- 条件は資料Dの水素結合の解離です。G18・G44・G50・G54 と同じ段取りで、K46 のキャッシュ（`~/workspace/kinescope/work/data_cache_k46/`、起点距離 3.5 Å 以下の候補、ラベルは予測幅で 3.5 Å より大きい）と、作り直した第22案の生成系列（`~/workspace/kinescope/work/g18_gen22/`、G18 の gen_g18.py で解離の候補向けに作り直したもの、20,713ペア）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（4,051件）、テスト 1mix_A＋2qt4_A（2,080件、うち 1mix_A 1,415件・2qt4_A 665件）。静的特徴は7個、履歴はドナー・アクセプター距離の系列の6統計量（3.5 Å 以下だった割合）です。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）で、平均はその2フレームの距離の平均です（G02・G06・G18 と同じ）。生成平均は、作り直した生成5点系列 [起点距離 d0（フレーム10）, +0.1, +0.3, +0.5, +1.0 ns] の平均です。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、解離の候補 6,131件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 2.81e-07 Å、テスト側 2.56e-07 Å でした。
- 生成器のチェックポイント .pt ファイルは読み込んでいません（保存済みの作り直し済み生成系列を使いました）。作り直した生成系列は、形成の候補だけで学習した生成器を解離の候補に当てはめたもので、学習した範囲の外への当てはめです（G18 と同じ留保）。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、生成平均だけ、混合（切り取り平均＋生成平均の2列）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G18 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G49・G59・G23 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（1,415件）と 2qt4_A（665件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G18・G44・G50・G54 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

### 土台の再現

4つの予測幅すべてで、静的のみ・全部入り・切り取り平均だけ・生成平均だけ・混合の合算 AUPRC が G18・G44・G50・G54 の記録と小数第4位まで一致しました。実履歴の利得は、1 ns先 +0.1785、30 ns先 +0.1322、50 ns先 +0.1142、90 ns先 +0.0679 です。

### 4つの予測幅の差とブートストラップ 95% 区間

| 予測幅 | 切り取り平均だけ | 混合 | 差（点推定） | 95% 区間 | 0 を含むか |
|---|---:|---:|---:|---|---|
| 1 ns | 0.532 | 0.480 | −0.052 | [−0.119, +0.053] | 含む |
| 30 ns | 0.586 | 0.672 | +0.086 | [+0.024, +0.295] | 含まない |
| 50 ns | 0.563 | 0.578 | +0.015 | [+0.004, +0.114] | 含まない |
| 90 ns | 0.709 | 0.503 | −0.206 | [−0.365, −0.067] | 含まない |

テスト陽性は、1 ns先 311件、30 ns先 368件、50 ns先 362件、90 ns先 413件です。

### タンパク質ごとの差（回復率の差）

| 予測幅 | 1mix_A だけ | 2qt4_A だけ | 合算 |
|---|---:|---:|---:|
| 1 ns | −0.119 | +0.053 | −0.052 |
| 30 ns | +0.295 | +0.024 | +0.086 |
| 50 ns | +0.004 | +0.114 | +0.015 |
| 90 ns | −0.365 | −0.067 | −0.206 |

1 ns先だけ、2タンパク質で差の向きが食い違います（1mix_A で −0.119、2qt4_A で +0.053）。30 ns先と 50 ns先では2タンパク質とも差が正、90 ns先では2タンパク質とも差が負です。

### 区間の重なり

- 1 ns の区間 [−0.119, +0.053] は、30 ns・50 ns・90 ns の区間のすべてと重なります。
- 30 ns の区間 [+0.024, +0.295] と 50 ns の区間 [+0.004, +0.114] は重なります。
- 30 ns の区間と 90 ns の区間 [−0.365, −0.067] は**重なりません**（30 ns の下限 +0.024 が、90 ns の上限 −0.067 より大きい）。
- 50 ns の区間と 90 ns の区間は**重なりません**（50 ns の下限 +0.004 が、90 ns の上限 −0.067 より大きい）。

## 判断

先に固定した読み方に沿うと、**30 ns先の +0.086 の区間は 0 を含みません**。30 ns先では、2タンパク質とも差が正（1mix_A +0.295、2qt4_A +0.024）で、区間 [+0.024, +0.295] は 0 を含みません。解離の混合で、差が 0 を含まない区間で正になった予測幅は、30 ns先と 50 ns先（区間 [+0.004, +0.114]、ただし下限は 0 に近い）です。

4つの区間どうしの重なりでは、30 ns先と 50 ns先の区間は 90 ns先の区間と重なりません。90 ns先の大きな下がり（−0.206）は、30・50 ns先の上がりとは区間が分かれています。1 ns先の区間は 0 を含み、他のすべての区間と重なるため、1 ns先の −0.052 は向きが定まらない位置づけです。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」と「重なる／重ならない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- 50 ns先の区間の下限 +0.004 は 0 に近く、1mix_A だけの差も +0.004 とほぼ 0 です。50 ns先の「正」は、2qt4_A（+0.114）に引っ張られた面が大きいです。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約36秒かかりました。
