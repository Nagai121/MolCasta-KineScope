# K2-16: K2-06 の漂いの問いを水素結合の形成の長い予測幅（30 ns先）で測る（資料Dの条件）

- 確かめる問い: 指導力の正体を探る K2 系列。K2-06（1 ns先）では、履歴の漂い（前半の平均 − 後半の平均）は全部の平均の上に足しにならなかった（全部の平均＋漂い 0.4834 は全部の平均だけ 0.4865 を −0.0031 下回る）。長い予測幅では平均の担い手が変わるため（K2-05 の 30 ns先では前半 1.201・後半 0.577 と前半がはっきり大きい）、漂いの役割も変わるかもしれない。ここでは K2-06 と同じ形を 30 ns先で測る。
- 状態: 完了。先に固定した読み方に沿い、**漂いは足しにならない**。全部の平均＋漂い (c) の AUPRC 0.4412 は、全部の平均だけ (b) の 0.4426 を −0.0014 下回った（+0.01 の線に届かない）。漂いだけ (a) の利得は負で、単独では利得を持たない。

## 1. 何を確かめる実験か

資料Dの条件（水素結合の形成、30 ns先）で、静的な特徴量に足す履歴の情報を「漂いだけ」「全部の平均だけ」「全部の平均＋漂い」の3通りに変え、全部の平均の上に漂いが足しになるかを測る。K2-06（1 ns先）と同じ形で、予測幅だけを長くした。

背景は K2-05 の結果である。30 ns先では、前半（フレーム [0..4]）の平均だけの割合が 1.201、後半（フレーム [6..10]）だけでは 0.577 と、前半がはっきり大きい。1 ns先（K2-01）では前半 0.784・後半 0.738 とほぼ並んでいたのと形が違う。長い予測幅では履歴の前のほうの平均がより大きく効く。漂い（前半と後半の平均の差）が、その前半の大きさの影かどうかを切り分けるのがこの実験の狙いである。

読み方は結果を見る前に固定した（K2-06 と同じ）。

- (c) 全部の平均＋漂いが (b) 全部の平均だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) 漂いだけの利得も記録し、全部入りの利得に対する割合もあわせて記録する。
- K2-06（1 ns先）の結果との比較も記録する。K2-06 では漂いは足しにならなかった（−0.0031）。K2-15（水素結合の解離、1 ns先）では漂いは足しになった（+0.0232）という記録も引用する。

割合の分母は全部入りの利得（静的＋履歴 6 統計量の利得）を主とし、あわせて全部の平均の利得に対する割合も記録する（分母の確認のため）。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（テスト陽性 345件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 30 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は7個。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の18軌道分の距離系列）を再利用した。距離はフレームごとの箱を軸ごとに扱って計算済み。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（7条件の学習で約15秒。学習が数件だけの小さい計算のため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 漂いの定義（結果を見る前に固定）

| 名前 | 定義 |
|---|---|
| 漂い | 前半の平均 − 後半の平均。前半はフレーム [0..4]（0〜0.4 ns）の距離の平均、後半はフレーム [6..10]（0.6〜1.0 ns）の距離の平均 |
| 符号 | 漂いが正なら「前半のほうが距離が大きい」（履歴のなかで距離が縮む方向に動いた）、負なら「後半のほうが距離が大きい」（距離が開く方向に動いた）という意味 |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である。** K2-01・K2-06 と同じ分け方で、前半と後半をきれいに分けるためである。

### 条件の一覧（30 ns先）

- 静的のみ: 静的特徴7個だけ（土台の照合用）。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。割合の分母（全部入りの利得）の参照。
- (a) 漂いだけ: 静的特徴＋漂い。
- (b) 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の距離の平均。
- (c) 全部の平均＋漂い: 静的特徴＋全部の平均＋漂い。
- 前半と後半の両方: 静的特徴＋前半の平均＋後半の平均（K2-01・K2-06 と同じ形での比較用。K2-05 にはこの形はない）。
- 前半の平均だけ: 静的特徴＋前半の平均だけ（K2-05 の 30 ns先の記録との照合用）。

## 4. 先に固定した読み方への答え

- **漂いは足しにならない。**(c) の AUPRC 0.4412 は (b) の 0.4426 を −0.0014 下回り、+0.01 の線に届かなかった。AUC でも (c) が 0.8971 と (b) の 0.8979 をわずかに下回った。
- (a) 漂いだけの利得は −0.0047 で、全部入りの利得に対する割合は −0.075。30 ns先では漂いだけでは利得を持たず、静的のみをわずかに下回る。1 ns先（K2-06）では漂いだけの利得は +0.0272（割合 0.231）とわずかながら正だったのと形が違う。
- K2-06 の「前半と後半の両方」（1 ns先、AUPRC 0.4902、割合 1.074）と比べると、30 ns先の「前半と後半の両方」は AUPRC 0.4231、割合 0.946 と、全部の平均（0.4426、割合 1.258）も全部入りも下回る。30 ns先では、前半と後半を分けて入れること自体が、1 ns先のような上積みにならない。

## 5. 読み取り

- **30 ns先でも、漂いは全部の平均の上に足しにならない。** (c) と (b) の差は −0.0014 とほぼ 0 で、+0.01 の線には遠い。1 ns先（K2-06、−0.0031）と同じ読みである。長い予測幅で前半のほうが大きく効く形（K2-05 の 30 ns先で前半 1.201・後半 0.577）は、漂いの情報では説明できない。
- 漂いだけの利得が 30 ns先では負（−0.075）になるのは、1 ns先（+0.231）とは違う形である。30 ns先では、前半と後半の平均の差そのものは、静的のみに比べても予測に役立たない。ただし土台の利得が +0.0626 と小さく、テストが2タンパク質だけ（陽性 345件）のため、漂いだけの利得の符号そのものが一般の形かは、この実験だけでは決められない。
- 30 ns先では「前半と後半の両方」（0.4231）が前半の平均だけ（0.4390）も下回る。1 ns先では両方を入れたほうが全部の平均も上回った（0.4902）のと向きが逆である。30 ns先では、履歴の後半の平均を別に入れることが、むしろ予測をわずかに悪くする形である。ただし差は AUPRC で −0.0159 と小さく、タンパク質ごとでは 2qt4_A だけを見ると両方（0.4333）が前半だけ（0.4343）とほぼ並ぶ。1mix_A だけを見ると両方（0.4255）が前半だけ（0.4486）を −0.0231 下回る。タンパク質ごとの形も分かれるため、一般の形かはこの実験だけでは決められない。
- 形成と解離の違いも記録しておく。K2-15（水素結合の解離、1 ns先）では、漂いは全部の平均の上に足しになった（(c) 0.5923 は (b) 0.5691 を +0.0232 上回り、+0.01 の線を超えた）。形成では 1 ns先（K2-06、−0.0031）も 30 ns先（K2-16、−0.0014）も漂いは足しにならない。漂いの役割は、形成と解離で違う。解離では履歴のなかでの距離の動き（縮むか開くか）が、平均の水準の上に情報を足すが、形成では足さない形である。

## 6. 判断できること・まだ分からないこと

- 判断できること: 資料Dの条件・水素結合の形成・30 ns先では、履歴の漂い（前半の平均 − 後半の平均）は、全部の平均の上に足しにならない（AUPRC の差 −0.0014）。漂いだけの利得も負（−0.0047）で、単独では利得を持たない。1 ns先（K2-06）と同じ読みである。
- まだ分からないこと: 漂いの符号（縮む方向か開く方向か）で分けたときの形（今回は符号を分けて測っていない）。90 ns先での形（K2-05 の 90 ns先では前半 0.903・後半 0.750 と前半が大きいが、漂いがそこでも足しにならないかは測っていない）。ほかの現象（接触の形成など）でも漂いが足しにならないかは測っていない。タンパク質ごとに (c) − (b) の符号が分かれる（1mix_A −0.0075、2qt4_A +0.0190）点も、テストが 2 タンパク質だけのため一般の形かは決められない。
