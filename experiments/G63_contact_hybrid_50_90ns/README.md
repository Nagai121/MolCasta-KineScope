# G63: 接触の形成で、50 ns先と 90 ns先の混合は足しになるか（資料Dの条件、接触の形成、50 ns先・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDと生成の混合の続き。接触の形成の混合で、残っている予測幅 50 ns先と 90 ns先を埋める。
- 状態: 完了。50 ns先では第14案だけが +0.05 を超えた（+0.058、余裕は小さい）。90 ns先ではどの案も超えなかった。予測幅で並べると、+0.05 を超えた案の数は 1 ns先で 3 案、5 ns先で 1 案、10 ns先で 1 案、30 ns先で 0 案、50 ns先で 1 案、90 ns先で 0 案。

## 1. 何を確かめる実験か

資料Dの条件（接触の形成）で、50 ns先と 90 ns先について、0.1 ns の切り取り平均に K17 の残基レベル生成平均（第11〜14案）を別々の特徴量として足した混合を測る。比較のため、切り取り平均だけと生成平均だけの条件も同じ土台で測る。参照は実履歴の利得で、50 ns先は +0.203（静的のみ 0.2604、全部入り 0.4638）、90 ns先は +0.185（静的のみ 0.2872、全部入り 0.4722）、どちらも K16 と同じ。回復率は実履歴の利得に対する比で測る。

生成平均は、案ごとの branch-mean 9点系列を 9点で平均したもの（K17・G36・G42・G55 と同じ）。実側は K13 のキャッシュで、K17 のファイルに保存された実側と配列単位で一致することを確かめてから位置で結合する。

読み方は先に固定した。これまでと同じく、混合の回復率が切り取り平均だけより +0.05 を超える案の数で見る。これまでの結果は、+0.05 を超えた案の数が 1 ns先で 4 案中 3 案、5 ns先で 1 案（G36、第11案 +0.057）、10 ns先で 1 案（G42、第13案 +0.053）、30 ns先で 0 案（G55）。

## 2. 条件

- 土台は資料Dの条件。ATLAS 6タンパク質×3レプリカ、学習4タンパク質（15,926件）・テスト2タンパク質（1mix_A＋2qt4_A、7,384件、50 ns先の陽性 250件、90 ns先の陽性 257件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 接触の形成の候補（K13 と同じ）: 残基ペアの最小重原子間距離が起点で 4.5 Å より大きいもの。ラベルは予測先で最小距離が 4.5 Å 以下になること。静的特徴は5個、履歴の閾値は 4.5 Å。
- 切り取りの定義（G02 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。0.1 ns → フレーム 0, 1（2フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 50 ns先（フレーム510）と 90 ns先（フレーム910）のまま。

### 条件の一覧

- 静的のみ: 静的特徴だけ。
- 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、閾値 4.5 Å）。
- 切り取り平均だけ: 静的特徴＋0.1 ns の切り取り平均（フレーム [0,1]）。
- 生成平均だけ（第11〜14案）: 静的特徴＋案ごとの生成平均。
- 混合（第11〜14案）: 静的特徴＋切り取り平均＋案ごとの生成平均。

## 4. 読み取り

- **50 ns先では第14案だけが +0.05 を超え（+0.058）、90 ns先ではどの案も超えなかった。** 予測幅で並べると、+0.05 を超えた案の数は 1 ns先で 3 案、5 ns先で 1 案、10 ns先で 1 案、30 ns先で 0 案、50 ns先で 1 案、90 ns先で 0 案。長い予測幅では混合の足しはほぼ消え、50 ns先の第14案だけが例外として残る形。
- 50 ns先の第14案も、+0.058 と線のすぐ上で、AUPRC の差は +0.0119 と小さい。線を超えた余裕は大きくない。
- 接触の形成では、生成平均は切り取り平均と相関 0.93、0〜1 ns の平均と相関 0.963 と、実の平均に非常に近い。生成系列が起点の近くからほとんど動かないためで、切り取り平均に足しても新しい情報は少ない。混合の差が小さいことと合う。
- 切り取り平均だけの回復率は 50 ns先で 0.501、90 ns先で 0.502 と、長い予測幅では利得の半分ほどしか戻らない。塩橋の形成の 10 ns先（0.868）とは対照的で、接触の形成では短い切り取りの情報が長い予測幅では薄れる。

## 5. 判断できること・まだ分からないこと

- 判断できること: 50 ns先では第14案だけが +0.05 を超え、90 ns先ではどの案も超えなかった。これで接触の形成の混合は 1・5・10・30・50・90 ns先のすべてが埋まった。
- まだ分からないこと: 50 ns先の第14案の +0.058 は線のすぐ上で、テストの揺れで向きが変わる可能性は残る。単一の学習 seed の結果でもある。テストは 2タンパク質だけなので、タンパク質ごとの偏りは分けられない。
