# K31 塩橋でも「平均だけ」で指導力の大半が戻るか（K15 の広げた条件）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H7（実軌道が持つ追加の観測情報）に関わる担い手の特定
- 状態: 完了。平均だけでは 1・5 ns先で 0.88〜0.89 と8割を超えますが、10 ns先以降は 0.34〜1.10 と大きく振れ、全予測幅を通して安定して8割を超える単独の量はありませんでした。

## 1. 何を確かめる実験か

水素結合では平均だけで利得の 0.87〜1.08 が戻り（K21）、接触では平均だけで 0.65〜0.71 にとどまりました（K27）。塩橋についても同じ分け方で測り、3現象の担い手の形をそろえます。

読み方は先に固定しました。平均だけで利得の8割以上が戻れば、担い手の形は水素結合と共通です。平均だけでは戻らず、どれも単独では戻らなければ、塩橋の指導力は接触と同じく統計量に分散していることになります。

## 2. 条件

- 土台は K15 の広げた条件です。ATLAS 解析版、起点フレーム10（1 ns）、予測幅 1/5/10/30/50/90 ns。学習は元の4タンパク質＋追加54（58タンパク質、候補 2,557件）、テストは元の2＋追加28（30タンパク質、候補 1,170件、陽性は予測幅ごとに 93〜149件）で、分け方は `experiments/K15_saltbridge_expansion/split.json` に凍結されているものです。
- 塩橋形成は荷電重原子ペアの最小距離で、正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2 です。候補は起点で最小距離が 4.0 Å 超〜10.0 Å 以下、配列距離が2以上の残基ペアで、ラベルは予測先で最小距離が 4.0 Å 以下になることです。静的特徴は5個です。
- 距離系列は K15 の抽出済みキャッシュ（`~/workspace/kinescope/work/k15_cache/`）を使いました。抽出の時点で、距離はフレームごとの箱を軸ごとに扱う周期境界で計算されています。
- 履歴の6統計量は K15 と同じ定義で、実軌道の11フレーム（0〜1 ns）の系列から作る「最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下だった割合」です。条件は静的5特徴に次の量だけを足したものです（分け方は K21・K27 と同じ）。
  - 平均だけ
  - 最小値だけ
  - 4.0 Å 以下割合だけ（塩橋の閾値以下の割合）
  - 形の統計量だけ: 標準偏差と最後−最初の2つ（位置を表す統計量は入れない）
  - 全部入り: 6統計量全部で、K15 の実履歴条件そのものです。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で、条件ごとに学習し直しました。指標は AUC、AUPRC、Brier、Log Loss です。戻り方は「その条件の利得÷全部入りの利得」で、利得は静的のみに対する AUPRC の改善です。
- 対照の確認: 静的のみと全部入りは、全予測幅で K15 の記録と完全に一致しました（差 0.0。1 ns先で静的のみ 0.2402、全部入り 0.3842）。

## 4. 読み取り

- **平均だけでは、1・5 ns先では 0.88〜0.89 と8割を超えますが、10 ns先以降は 0.34〜1.10 と大きく振れます。** 全予測幅を通して安定して8割を超える単独の量はありません。水素結合（K21、平均だけで全幅 0.87〜1.08）のような安定した形にはなりませんでした。
- どの統計量も、幅によって 0.25〜1.5 の範囲で振れます。形だけでも 10 ns先で 1.523、50 ns先で −0.580 まで出るなど、1つだけの条件の比率が大きく揺れています。これは K15 でも指摘されている塩橋の揺れの大きさと地続きで、全部入りの利得そのものが小さい幅（特に 50 ns先の +0.027）では比率が振れやすいためです。
- 先に固定した読み方に照らすと、どちらの枝にもきれいには当たりません。短い予測幅（1・5 ns先）だけ見れば平均だけで8割を超え、水素結合に近い形です。しかし 10 ns先以降は平均だけでは 0.34〜1.10 と安定せず、最小値や割合も幅ごとに主役が入れ替わります。結論としては、**塩橋では単独の担い手を全幅で決めるだけの安定さがなく、接触寄り（分散）の読みに近いが、候補数の少なさによる揺れと現象の性質の切り分けはできない**、という形です。
- 注意点: 単一の学習 seed の結果で、ばらつきの範囲は測っていません。テストの陽性が 93〜149件と少なく、AUPRC の揺れは水素結合・接触より大きいです。K19（塩橋での統計量の落としと履歴の入れ替え）では、1つ落としても利得はほとんど減らず、担い手は統計量の間に分散しているという結果が出ています。本実験の揺れと合わせると、塩橋の担い手は「分散している」という大まかな読みまでが確かで、それ以上はこの候補数では決められません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 塩橋では、平均だけが全予測幅を通して担い手になることはありませんでした。短い予測幅では平均だけで8割を超えますが、長い予測幅では振れが大きく、単独で安定して担える量は見つかりませんでした。3現象の中では、接触寄りの分散した形に近いです。
- まだ分からないこと: 揺れの大きさが候補数の問題なのか、塩橋そのものの性質（水が介在する確率的な現象など）なのか。テスト側のタンパク質をさらに広げれば、幅ごとの戻り方のばらつきが収まるかどうか。
