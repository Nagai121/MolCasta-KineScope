# L32: L01 の曲がりを塩橋の形成で測る（K15 の土台、90 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の形成（K15 の土台、全予測幅、L27〜L32）の 90 ns先で、形成の担当分はここまでです。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は 0.459〜1.014 の範囲で上下し、長さに対する傾向は見えませんでした。フレーム0だけでも 0.846 あり、長い切り取りが短い切り取りを上回る形にはなっていません。

## 1. 何を確かめる実験か

L27 と同じ段取りで、予測幅だけを 90 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。テスト 1,170件、90 ns先の陽性 149件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0 ns（全体 0.846、平均 0.898）**。
2. **回復率 0.9 に届く最小の長さ: 全体では覆う長さ 0.8 ns（1.014）**。平均ではどの長さでも 0.9 に届きませんでした（最大は 1.0 ns の 0.892）。0.8 ns の全体の値は前後（0.7 ns で 0.746、0.9 ns で 0.654）から浮いた単発の値で、持続する形ではありません。
3. **増え幅がいちばん大きい場所: 全体では 0.7→0.8 ns（+0.268）**、平均では 0.3→0.4 ns（+0.257）。全体の段の位置でのタンパク質ごとの増え分は中央値 +0.018、正だったのは 18タンパク質のうち 50% で、段とは読めません。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 90 ns先でも、回復率は長さに対して伸びず、0.5〜1.0 の範囲を上下します。G60 の走査（覆う長さに直すと 0.1 ns で 0.654、0.2 ns で 0.801、0.5 ns で 0.465）と 3点とも点推定が一致しました。
- 塩橋の形成の 6つの予測幅を通して、曲がりに共通するのは「フレーム0や 0.1 ns の時点で利得のかなりの部分が戻っている」ことと「それより長くしても単調には伸びない」ことです。読みやすい形だったのは 30 ns先（L30、0.1 ns で上がって高い水準で平ら）だけで、50 ns先（L31）は分母が小さくて読めませんでした。
