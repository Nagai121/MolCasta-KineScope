# K27 接触でも「平均だけ」で指導力の大半が戻るか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H7（実軌道が持つ追加の観測情報）に関わる担い手の特定
- 状態: 完了。平均だけでは利得の 0.65〜0.71 しか戻らず（30 ns先を除く）、水素結合のような「平均が担い手」という形にはなりませんでした。単独で最も戻るのは 4.5 Å 以下割合で、短い予測幅では 0.87〜0.96 に届きます。

## 1. 何を確かめる実験か

水素結合では、強い土台で平均だけを入れると利得の 0.87〜1.08 が戻りました（K21）。一方で接触では、統計量を1つ外しても利得がほぼ減りませんでした（K16）。本実験は接触について「1つだけ入れる」側を測ります。

読み方は先に固定しました。平均だけで利得の大半（8割以上）が戻れば、担い手の形は水素結合と共通です。どれも単独では戻らず、外しても減らないのであれば、接触の指導力は統計量の組み合わせに分散していることになります。

## 2. 条件

- 土台は K13/K16 と完全に同じ資料Dの条件です。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（接触の候補 15,926件）、テスト 1mix_A と 2qt4_A の合算（7,384件）。接触形成は残基ペアの最小重原子間距離で、候補は起点（フレーム10、1 ns）で 4.5 Å 超、ラベルは予測先で 4.5 Å 以下です。
- 距離系列は K13 の抽出済みキャッシュ（`~/workspace/kinescope/work/k13_cache/`）を使いました。抽出の時点で、距離はフレームごとの箱を軸ごとに扱う周期境界で計算されています。
- 履歴の6統計量は K16 と同じ定義で、実軌道の11フレーム（0〜1 ns）の系列から作る「最初の値、平均、標準偏差、最小値、最後−最初、4.5 Å 以下だった割合」です。条件は静的5特徴に次の量だけを足したものです（分け方は K21 と同じ）。
  - 平均だけ
  - 最小値だけ
  - 4.5 Å 以下割合だけ（接触の閾値以下の割合）
  - 形の統計量だけ: 標準偏差と最後−最初の2つ（位置を表す統計量は入れない）
  - 全部入り: 6統計量全部で、K16 の実履歴条件そのものです。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で、条件ごとに学習し直しました。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。戻り方は「その条件の利得÷全部入りの利得」で、利得は静的のみに対する AUPRC の改善です。
- 対照の確認: 静的のみと全部入りは、全予測幅で K16 の記録と完全に一致しました（差 0.0。1 ns先で静的のみ 0.3398、全部入り 0.5669）。

## 4. 読み取り

- **平均だけでは、利得の大半は戻りませんでした。** 戻り方は 30 ns先（0.990）を除いて 0.65〜0.71 で、先に固定した目安の8割に届きません。水素結合（K21、平均だけで 0.87〜1.08）とは形が違います。
- **単独で最も戻るのは、平均ではなく 4.5 Å 以下割合でした。** 1〜30 ns先では 0.87〜1.08 と8割を超えますが、50 ns先で 0.776、90 ns先で 0.717 と、長い予測幅では8割を切ります。全予測幅を通して8割を超える単独の量はありません。
- 形だけでも 0.51〜0.79 が戻ります。水素結合（0.39〜0.55）より形の側の戻り方が大きく、接触では位置以外の情報の重みが相対的に大きいです。
- K16（1つ外しても減らない）と合わせると、接触の指導力は統計量の組み合わせに分散している、という読みになります。ただし分散の仕方は一様ではなく、閾値以下の割合が頭1つ抜けていて、平均・最小値・形がそれぞれ半分以上を単独で担える、という重なりの大きい分散です。先に固定した読み方の2つ目の枝（どれも単独では戻らない）は、割合の短い予測幅での戻り方（0.92〜0.96）についてはそのままでは当たらず、正確には「平均は担い手ではなく、単独で全幅を通して担える量はない」という形でした。
- 注意点: 30 ns先は全部入りの利得そのものが最も小さい（+0.152）ため、戻り方の比率が大きく振れやすいです（割合だけの 1.084 など）。また単一の学習 seed の結果で、ばらつきの範囲は測っていません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触では、担い手の形は水素結合と違います。平均は担い手ではなく、単独で最も近いのは閾値以下の割合で、それも長い予測幅では8割を切ります。接触の指導力は、複数の統計量に重なって分散しています。
- まだ分からないこと: 組み合わせの中のどこまでが要るか（2つ・3つの組み合わせでの戻り方）。また、閾値以下の割合が強い理由が、接触の定義そのもの（閾値で決まる現象だから）なのか、履歴の状態の表れなのかは、この実験だけでは分かれません。
