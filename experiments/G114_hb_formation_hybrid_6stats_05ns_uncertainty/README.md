# G114: 切り取り 0.5 ns の 6 個の統計量の混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。切り取り 0.5 ns の 6 個の統計量の混合で、G105・G110 で +0.05 を超えたのは次のセルでした。

- G105（水素結合の形成、1・30 ns先）: 1 ns先の第12案 +0.071、30 ns先の第11案 +0.098・第12案 +0.165・第22案 +0.252
- G110（水素結合の形成、5・10・50・90 ns先）: 5 ns先の第11案 +0.137・第14案 +0.069、10 ns先の第11案 +0.321・第12案 +0.301・第22案 +0.158、50 ns先の第11案 +0.073・第13案 +0.082・第14案 +0.157・第22案 +0.094、90 ns先の第13案 +0.098

各予測幅について、混合と切り取り 0.5 ns の 6統計量だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G59・G62・G67・G109 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセルの区間が 0 を含むかどうかを見ます。

注記: 割り当て文では対象を「全部で 15セル」としていますが、列挙されたセルを数え直すと 14セルです（G105 の 4セル＋G110 の 10セル）。列挙された 14セルを対象としました。15セルめに当たるセルは、割り当て文の列挙にも G105・G110 の記録にもありません。

- 状態: 完了。+0.05 を超えた 14セルのうち、区間が 0 を含まないのは 6セル（1 ns先の第12案、30 ns先の第12案、5 ns先の第11案、10 ns先の第11案、50 ns先の第14案、90 ns先の第13案）で、0 を含むのは 8セルです。

## データと条件

- 切り取りは 0.5 ns（フレーム [0,1,2,3,4,5]、覆う長さ 0.5 ns）の 6 個の統計量です（G105・G110 と同じ）。6統計量は [最初のフレーム、平均、標準偏差、最小、最後−最初、しきい値以下だった割合] で、6フレームの系列から計算します。生成平均は、生成系列の平均です。
- 水素結合の形成（G105・G110）: 資料Dの条件。実側は DocD キャッシュ（`~/workspace/kinescope/work/data_cache/`、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件、うち 1mix_A 3,101件・2qt4_A 1,871件））。生成平均は第11〜14案が K11（`experiments/K11_method_generality/series/`、4分岐×8点の平均）、第22案が K05 の生成系列（`experiments/K05_generated_quality/generated_series.npz`、5点系列の平均）です。しきい値は 3.5 Å、予測幅は 1・5・10・30・50・90 ns先です。
- 条件は次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り 0.5 ns の 6統計量だけ、切り取り 0.5 ns の平均だけ（参考）、生成平均だけ（第11〜14案と第22案）、混合（切り取り 0.5 ns の 6統計量＋生成平均、別々の特徴量として 7列。第11〜14案と第22案）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り 0.5 ns の 6統計量だけの回復率です。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。生成器のチェックポイントは読み込んでいません。
- 注記: フレーム [0,1,2] は実際には 0.2 ns を覆う。0.25 ns という呼び名は 100 ps 刻みに合わないため、フレーム [0,1,2] の覆う長さは 0.2 ns になる（G100・G105・G110 の記録にも同じ注記がある）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67・G109 と同じです。
- 再標本化の単位: タンパク質。テストが 1mix_A と 2qt4_A の 2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り 0.5 ns の 6統計量だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions_hb_formation.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G105・G110 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions_hb_formation.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: 2 タンパク質の現象では、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。
- 土台の利得が小さい予測幅（10 ns先 +0.0829、50 ns先 +0.0739、30 ns先 +0.0626）では回復率の差だけでは読みを誤るため、混合と切り取り 0.5 ns の 6統計量だけの AUPRC の差の絶対値も記録します（点推定、タンパク質ごとの値、ブートストラップ 95% 区間）。G109 と同じです。

## 判断

先に固定した読み方に沿うと、+0.05 を超えた 14セルのうち、**区間が 0 を含まないのは 6セル**で、**0 を含むのは 8セル**です。

- 区間が 0 を含まない 6セル: 1 ns先の第12案 [+0.067, +0.074]、30 ns先の第12案 [+0.068, +0.206]、5 ns先の第11案 [+0.044, +0.193]、10 ns先の第11案 [+0.197, +0.442]、50 ns先の第14案 [+0.097, +0.248]、90 ns先の第13案 [+0.057, +0.113]。いずれも 2タンパク質とも差が正です。AUPRC の差の区間も 0 を含みません（1 ns先の第12案 +0.0084 [+0.0065, +0.0130]、30 ns先の第12案 +0.0103 [+0.0061, +0.0109]、5 ns先の第11案 +0.0159 [+0.0081, +0.0173]、10 ns先の第11案 +0.0266 [+0.0252, +0.0301]、50 ns先の第14案 +0.0116 [+0.0085, +0.0180]、90 ns先の第13案 +0.0118 [+0.0100, +0.0119]）。ただし AUPRC の差の絶対値は 6セルとも +0.009〜+0.027 と小さいです。10 ns先の第11案は回復率の差で +0.321 と最も大きいですが、AUPRC の差は +0.0266 です。
- 区間が 0 を含む 8セル: 30 ns先の第11案 [−0.095, +0.198]・第22案 [−0.085, +0.595]、5 ns先の第14案 [−0.024, +0.169]、10 ns先の第12案 [−0.082, +0.660]・第22案 [−0.010, +0.361]、50 ns先の第11案 [−0.049, +0.270]・第13案 [−0.009, +0.134]・第22案 [−0.025, +0.149]。いずれもタンパク質ごとの差の向きが食い違います。AUPRC の差の区間もすべて 0 を含みます。30 ns先の第22案は点推定が +0.252 と大きいですが、2qt4_A だけの +0.595 と 1mix_A の −0.085 の平均で、区間は [−0.085, +0.595] と 0 を含みます。10 ns先の第12案も点推定 +0.301 に対し、1mix_A で +0.660、2qt4_A で −0.082 と向きが食い違います。
- +0.05 を超えなかったセルでは、5 ns先の第13案 [−0.177, −0.037] と 90 ns先の第11案 [−0.160, −0.018] は区間も 0 を含まず負です。50 ns先の第12案は点推定 +0.048 と線のすぐ下ですが、区間は [+0.007, +0.048] と 0 を含みません（2タンパク質とも差が正で、1mix_A +0.007、2qt4_A +0.040）。ただし +0.05 の線には届いていないため、先に固定した読みの対象ではありません。

## 読みの注意点

- **テストは 2 タンパク質だけなので、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・案ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- **土台の利得が小さい予測幅では、回復率の差は AUPRC の小さな差でも大きく出ます。** 30 ns先の利得は +0.0626、50 ns先は +0.0739、10 ns先は +0.0829 です。区間が 0 を含まない 6セルでも、AUPRC の差は +0.0084〜+0.0266 と小さいです。回復率の差の区間と AUPRC の差の区間は、+0.05 を超えた 14セルすべてで 0 を含むかどうかの答えが一致しました。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約3分でした。
