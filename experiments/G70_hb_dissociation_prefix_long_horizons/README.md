# G70: 解離で、長い予測幅でも短い切り取りで指導力が戻るか（資料Dの条件、水素結合の解離、5・10・30・50・90 ns先）

- 確かめること: G06 は 1 ns 先だけだったので、長い予測幅での形が空白だった。切り取りの平均だけの回復率を長い予測幅で測る。
- 状態: 完了。回復率 0.5 を超える最小の切り取りは、5・10・30・50・90 ns先のすべてで 0.1 ns。解離では長い予測幅でも短い切り取りで指導力の半分以上が戻る。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の解離。予測幅は 5・10・30・50・90 ns、切り取りは 0.1・0.25・0.5 ns で、平均だけの回復率を測る。土台の利得は K46 の各予測幅の記録値。

読み方は先に固定した。G60 と同じく、各予測幅で回復率 0.5 を超える最小の切り取りを出す。

## 2. 条件

- 土台は資料Dの条件（水素結合の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 4,051件・テスト 2,080件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴7個。キャッシュは `~/workspace/kinescope/work/data_cache_k46/`（解離の候補）。
- 切り取りは 0.1 ns = フレーム [0,1]、0.25 ns = フレーム [0,1,2]、0.5 ns = フレーム [0,1,2,3,4,5] で、平均だけを入れる。
- 条件: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取りの平均だけ（0.1・0.25・0.5 ns）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。土台の静的のみ・全部入りの AUPRC は、K46 の記録値と小数第4位まで一致することを各予測幅で確かめた。
- 注意: K46 のキャッシュの `hist` は (11, n) の並びで保存されているため、読み込み時に転置して (n, 11) に直した。G61 の読み込みも同じ扱いだった。

## 4. 読み取り

先に固定した読み方に照らすと、回復率 0.5 を超える最小の切り取りは、5・10・30・50・90 ns先のすべてで 0.1 ns。解離では長い予測幅でも短い切り取りで指導力の半分以上が戻る。1 ns先の 0.1 ns は 0.532（G18）だったのに対し、長い予測幅では 0.553〜0.709 と、1 ns先よりむしろ高い。

90 ns先では 0.25 ns の切り取りが 1.058、0.5 ns の切り取りが 1.488 と実履歴を上回る。90 ns先の利得そのものが +0.0679 と小さいため、比率としては当てにしにくいが、絶対値でも 0.5 ns の切り取りの AUPRC 0.6128 が全部入り 0.5797 を上回っている。解離の 90 ns先では、0〜1 ns の履歴全部より短い切り取りの平均だけの方が良いという、ほかの幅にはない形。

50 ns先だけ、0.25 ns（0.556）が 0.1 ns（0.563）をわずかに下回る。差は 0.007 と小さく、切り取りの長さに対してほぼ横ばい。ほかの4つの幅では切り取りが長くなるほど回復率は上がる。

形成（G02・L01）では 1 ns先の 0.1 ns が 0.570、0.5 ns が 0.770 と、切り取りが長くなるほど回復率が上がる。解離では 1 ns先の 0.1 ns が 0.532 と形成とほぼ同じ水準で、長い予測幅でも 0.1 ns で 0.55〜0.71 と、短い切り取りの効き目は形成より解離の方が予測幅に強い。

## 5. 判断できること・まだ分からないこと

- 判断できること: 解離では、予測幅 5・10・30・50・90 ns先のすべてで、0.1 ns の切り取りの平均だけで回復率 0.5 を超える。長い予測幅でも短い切り取りで指導力の半分以上が戻る。90 ns先では 0.25・0.5 ns の切り取りが実履歴を上回る。
- まだ分からないこと: 90 ns先で短い切り取りが全部入りを上回る理由。解離の 6 統計量の切り取りでも同じ形か（形成の G66 との比較）。強い土台（K06(b)）の解離でも同じ形か。
