# K87: 接触の解離でも、読み出しは予測幅をまたいで使えるか（K50 の条件）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。水素結合の解離では、読み出しは予測幅をまたいで使えました（K75: 1 ns先→90 ns先で 1.04、逆で 0.93、6×6 の表全体で 0.87〜1.09）。接触の解離でも同じか確かめます。

読み方は実験前に固定しました。両方向の回復率が 0.8 以上なら、接触の解離でも読み出しは予測幅をまたいで使えます。片方だけ弱ければ、水素結合の 1 ns先→50 ns先の弱さ（K56）と同じ形か、凍結した本体の予測を抜いた条件でも測って確かめます。

## データと条件

- K50 の条件です。弱い土台（資料D）で、ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383件）、テスト 1mix_A と 2qt4_A の合算（2,915件）、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（K50 の取り出し時に適用済みで、ここでは K50 のキャッシュをそのまま使いました）。
- 接触の解離: 候補は起点フレーム10の重原子の最小距離が 4.5 Å 以下（接触ができている状態）の残基ペアで、ラベルは予測先のフレームで最小距離が 4.5 Å を超えることです。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、残基 i と j の重原子の数）、履歴は6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.5 Å 以下だった割合）です。
- 条件は次の通りです。特徴量は予測幅によらないため、ある予測幅で学習した補正モデルを、すべての予測幅のラベルで評価し、6×6 の表を作りました。利得は、同じ学習予測幅で学習した静的な特徴だけの条件との AUPRC の差で、テスト2タンパク質をまとめた値と、タンパク質ごとの平均の両方を見ます。戻り率は、別の予測幅で学習した利得を、同じ予測幅で学習した利得で割った値です。
- 確認: 同じ予測幅で学習・評価した条件は、K50 の記録とすべての予測幅で完全に一致しました（AUPRC の差 0.0。1 ns先で静的のみ 0.3105、全部入り 0.5246）。

## 判断

先に固定した8割の線で見ると、**片方だけ弱く、両方向には移りません**。1 ns先で学習した補正は 90 ns先で利得の 0.58 しか戻らず、8割を下回りました。逆向きは 1.07 で問題ありません。6×6 の表を見ると、弱さは 90 ns先への移し替えに集まっています（1 ns先から 0.58、5 ns先から 0.73、50 ns先から 0.60）。10 ns先・30 ns先からは 0.84・0.87 と戻ります。

## 片方だけ弱いので、確かめたこと

### 水素結合の 1 ns先→50 ns先の弱さと同じ形か

形は同じ仲間です。K56 では、50 ns先への移し替えがどの学習予測幅からも弱くなりました。K87 では、90 ns先への移し替えが弱いところがあります。違う点は、弱い予測幅が 50 ns先ではなく 90 ns先であることと、すべての学習予測幅から弱いわけではないことです（10 ns先・30 ns先からは戻ります）。

### 弱さの原因は、履歴の読み出しではなく静的な特徴だけの条件にあります

弱い土台（K50 の条件）には凍結した本体の予測が無いため、凍結した予測を抜く確かめは当てはまりません。その代わりに、静的な特徴だけの条件が予測幅をまたいでどう移るかを同じ表で確かめました。

- 90 ns先で学習した静的な条件は、**すべての評価予測幅でいちばん弱い**静的な条件です（1 ns先 0.2438、5 ns先 0.2429、10 ns先 0.2240、30 ns先 0.2503、50 ns先 0.2504、90 ns先 0.2886）。90 ns先のラベルはばらつきが大きく、静的な条件の学習がうまくいかない形です。
- 逆に、1 ns先で学習した静的な条件は 90 ns先でも強く、AUPRC 0.3517 で、90 ns先で学習した静的な条件（0.2886）を上回ります。
- 利得は「履歴の条件 − 静的な条件」なので、1 ns先→90 ns先では、移し替えの利得が小さく見えるのと、参照の利得が大きく見えるのが重なっています。移し替えの履歴の条件そのものは、90 ns先で AUPRC 0.4588 と、同じ予測幅で学習した履歴の条件（0.4750）と比べて 0.016 しか落ちていません。
- 静的な条件を同じものにそろえて測り直すと、1 ns先→90 ns先の戻り率は **0.91** になります（履歴の条件 0.4588 − 90 ns先で学習した静的な条件 0.2886 を、参照の利得 0.1864 で割った値）。逆に、90 ns先→1 ns先は同じそろえ方で 0.76 になります。

つまり、**履歴の読み出しそのものは両方向によく移ります**。利得の比で見た 0.58 は、静的な条件の移り方が予測幅で大きく違うために歪んだ値です。90 ns先で学習した静的な条件が弱いことが、参照の利得を大きくし、移し替えの利得を小さくしています。
