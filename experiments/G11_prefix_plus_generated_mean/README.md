# G11: 切り取りに生成した平均を足すと、指導力はさらに戻るか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G02 で 0.1 ns の切り取り平均だけでは回復率 0.570 だった。ここに第22案の生成平均を足すと、指導力はさらに戻るか。
- 状態: 完了。混合の回復率は 0.756 で、切り取り平均だけより +0.186 上がり、先に固定した +0.05 の線を超えた。生成した量は短い実MDの上でもまだ足しになる。

## 1. 何を確かめる実験か

0.1 ns の切り取り平均だけでは回復率 0.570 でした（G02）。ここに第22案の生成平均（K06(a) の生成 6特徴量のうち平均だけ）を追加し、同じ補正モデルで測ります。比較のため、切り取り平均だけ（0.570 の再現）と生成平均だけの条件も同じ土台で測ります。

読み方は先に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がれば、生成した量は短い実MDの上でもまだ足しになります。+0.05 未満なら、生成した量は短い実MDの上では足しにならず、生成器の路線は寄与の面では閉じたことになります。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。距離はフレームごとの箱を軸ごとに扱う（K01 の抽出コードと同じ段取り）。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の 18軌道分の距離系列）を再利用しました。新しい軌道の取得や生成器の読み込みはしていません。実行はローカルVM（`~/workspace/mt-venv` の Python）。

### 切り取りの定義（G02 と同じ、結果を見る前に固定）

軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。0.1 ns の切り取りはフレーム 0, 1（2フレーム）で、実際に覆う長さは 0.1 ns。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 生成平均の出所

- K05 の `generated_series.npz`（第22案の5点系列）を使いました。生成器のチェックポイント .pt ファイルは読み込んでいません。
- 生成5点 = [起点距離 d0（フレーム10、1 ns）, +0.1, +0.3, +0.5, +1.0 ns] の前方系列。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、K09 と同じく土台候補 14,582 件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å でした。
- 生成平均はこの5点系列の平均です。K06(a) の生成条件（生成6特徴量）のうち平均の列だけを使う形です。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（K09 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。参照。
- 切り取り平均だけ（prefix_mean_0.1ns）: 静的特徴＋切り取り平均だけ。G02 の再現。
- 生成平均だけ（gen_mean_only）: 静的特徴＋生成平均だけ。
- 混合（mixed）: 静的特徴＋切り取り平均＋生成平均（2列）。

回復率 =（その条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.1178）で測ります。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、形成の記録と小数第4位まで完全一致しました。切り取り平均だけは AUPRC 0.4308、回復率 0.570 で、G02 の値と小数第4位まで一致しました。

### 1 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.3637 | 0.9056 | 0.0432 | 0.1494 | 0.000 |
| 全部入り（実履歴） | 0.4815 | 0.9352 | 0.0395 | 0.1344 | 1.000 |
| 切り取り平均だけ | 0.4308 | 0.9243 | 0.0406 | 0.1385 | 0.570 |
| 生成平均だけ | 0.3746 | 0.9129 | 0.0430 | 0.1466 | 0.093 |
| 混合（切り取り平均＋生成平均） | 0.4528 | 0.9305 | 0.0398 | 0.1354 | 0.756 |

混合の回復率は 0.756 で、切り取り平均だけ（0.570）より **+0.186** 上がり、先に固定した +0.05 の線を超えました。生成平均だけでは回復率は 0.093 とほとんど戻りませんが、切り取り平均と組み合わせると大きく上がります。

### 切り取り平均と生成平均の関係

| 量 | 学習側（9,610件） | テスト側（4,972件） |
|---|---:|---:|
| 切り取り平均と生成平均の相関 | 0.715 | 0.728 |
| 生成平均 − 切り取り平均の平均 | −0.188 Å | −0.155 Å |
| 生成平均 − 切り取り平均の差の標準偏差 | 0.712 Å | 0.706 Å |
| 生成平均 − 0〜1 ns の平均の平均 | −0.168 Å | −0.129 Å |
| 生成平均 − 0〜1 ns の平均の差の標準偏差 | 0.487 Å | 0.474 Å |
| 生成平均と 0〜1 ns の平均の相関 | 0.832 | 0.845 |
| 切り取り平均と 0〜1 ns の平均の相関 | 0.912 | 0.926 |

K08 の値との照合: 生成平均 − 実平均は、学習側とテスト側を合わせると候補平均 −0.155 Å、差の標準偏差 約0.48 Å、相関 0.836 になり、K08 の記録（−0.155 Å、約0.48 Å、0.836）と一致します。テスト側だけでは平均 −0.129 Å、相関 0.845 とやや違いますが、学習側と合わせると K08 の値になります。

## 4. 読み取り

- **混合の回復率は 0.756 で、切り取り平均だけより +0.186 上がりました。** 先に固定した読み方に沿うと、生成した量は短い実MDの上でもまだ足しになります。生成器の路線は寄与の面では閉じていません。
- 生成平均だけでは回復率は 0.093 とほとんど戻りません。生成平均単体では指導力をほとんど持たないのに、切り取り平均と組み合わせると +0.186 も上がるのは、生成平均が切り取り平均には無い情報を補っているためです。切り取り平均は始めの 0.1 ns の情報しか持たず、生成平均は起点から先の 1 ns までの前方系列の平均で、時間の向きも覆う範囲も違います。2つの平均は相関 0.728 と完全には重ならず、差の標準偏差は 0.706 Å と大きいため、組み合わせると 0〜1 ns の平均に近づく向きに働きます。
- ただし混合でも回復率は 0.756 で、0〜1 ns の平均だけの 1.042 には届きません。生成平均を足しても、0〜1 ns の平均そのものには及びません。
- 0.5 ns の切り取り平均だけの回復率は 0.770（G02）で、混合（0.756）とほぼ同じです。0.1 ns の切り取りに生成平均を足すと、0.5 ns の切り取りとほぼ同じ水準まで戻る、という読みもできます。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.1 ns の切り取り平均に第22案の生成平均を足すと、1 ns先の利得の回復率は 0.570 から 0.756 へ +0.186 上がります。生成した量は短い実MDの上でもまだ足しになるため、生成器の路線は寄与の面では閉じていません。
- まだ分からないこと: 生成平均が補っている情報が、時間の向きの違いによるものか、覆う範囲の違いによるものか（切り取りは始めの 0.1 ns、生成は起点から先の 1 ns）。生成平均の代わりに、切り取りを 0.5 ns まで伸ばすのとどちらが効率的か（0.5 ns の切り取り平均だけでも 0.770 で、混合とほぼ同じ）。強い土台（K06(b)）でも同じ形か。
