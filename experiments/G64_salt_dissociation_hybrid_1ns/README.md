# G64: 塩橋の解離の混合（K15 の広げた条件、1 ns先）

## 状態

**前提確認で、生成系列が解離の候補とそろわないことが分かり、止まっています。** 割り当ての注意点に沿い、無理に進めず記録して止めました。この記録は、その前提確認の結果です。

## もともとの設計

塩橋の解離で混合を初めて測る予定でした。条件は K15 の広げた条件、1 ns先で、0.1 ns の切り取り平均に、G19 で作り直した第11〜14案の生成平均を足します。土台の利得は K15・K53 の記録の値（+0.1788）を使うはずでした。読み方は形成と同じで、混合の回復率が切り取り平均だけより +0.05 以上上がる案があるかどうかで見ます。

## 前提確認の結果

G19 で作り直した生成系列は、塩橋の**形成**の候補（K15 のキャッシュの残基ペア）について作ったものです。解離の候補（K53 のキャッシュ）と残基ペア（res_i, res_j）の一致で数えた結果は次のとおりです。

| 範囲 | 解離の候補 | うち G19 の生成系列と一致 | 一致率 |
|---|---:|---:|---:|
| 学習（58タンパク質） | 735件 | 0件 | 0% |
| テスト（30タンパク質） | 360件 | 0件 | 0% |

1件も一致しませんでした。これは偶然ではなく、候補の作り方から決まっています。形成の候補は起点で離れているペア（荷電ペアの最小距離が 4.0 Å より大きく 10.0 Å 以下）で、解離の候補は起点で結合しているペア（最小距離が 4.0 Å 以下）です。同じ起点では、1つのペアが両方に入ることはありません。実際、解離の候補の起点距離の例は 2.69〜3.09 Å で、形成の候補は 4.14〜9.95 Å でした。

## 進めるには何が要るか

解離の候補について、生成系列を作り直す必要があります。作り方自体は G19 の `g19_build.py` と同じで、変えるのは候補の集合だけです（候補を K53 のキャッシュから取り、荷電原子ペアの最小距離の系列を作る）。生成そのもの（弾性モードと局所ゆらぎ）はタンパク質ごとに共通なので、作り直しの規模は G19 のときと同じ88タンパク質×3レプリカですが、計算量は候補が少ない分だけ軽いです。作り直すかどうかは、統括の判断をお願いします。
