# G118: 接触の形成で、0.5 ns の切り取りの 6 統計量に生成した平均を足した混合の差に、区間を付ける

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDと生成の混合の続き。G107 では 0.5 ns の切り取りの 6 統計量に生成平均を足すと、30 ns先で第11案（+0.074）と第12案（+0.070）が +0.05 を超えた。G113 では 5 ns先で第13案（+0.060）、50 ns先で第11案（+0.064）、90 ns先で第11案（+0.061）と第14案（+0.083）が +0.05 を超えた。+0.05 を超えた 6 セルについて、混合と 0.5 ns の切り取りの 6 統計量だけの差のブートストラップ 95% 区間を出す。
- 状態: 完了。6 セルのうち 4 セル（5 ns先の第13案、50 ns先の第11案、90 ns先の第11・14案）の区間は 0 を含まなかった。30 ns先の第11・12案の区間は 0 を含んだ。

## 1. 何を確かめる実験か

資料Dの条件（接触の形成、5・30・50・90 ns先）で、0.5 ns の切り取りの 6 統計量に K17 の残基レベル生成平均（第11〜14案）を別々の特徴量として足した混合と、0.5 ns の切り取りの 6 統計量だけの差（mixed_minus_prefix、回復率の差）に、タンパク質単位の再標本化によるブートストラップ 95% 区間を付ける（G49・G59・G62・G67 と同じやり方）。対象は G107・G113 で +0.05 を超えた 6 セル（30 ns先の第11・12案、5 ns先の第13案、50 ns先の第11案、90 ns先の第11・14案）。回復率の分母は、その予測幅での実履歴の利得。

読み方は先に固定した。これらのセルの区間が 0 を含むかどうかを見る。

## 2. 条件

- 土台は資料Dの条件。ATLAS 6タンパク質×3レプリカ、学習4タンパク質（15,926件）・テスト2タンパク質（1mix_A＋2qt4_A、7,384件。陽性は 5 ns先 214件、30 ns先 247件、50 ns先 250件、90 ns先 257件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 接触の形成の候補（K13 と同じ）: 残基ペアの最小重原子間距離が起点で 4.5 Å より大きいもの。ラベルは予測先で最小距離が 4.5 Å 以下になること。静的特徴は5個、履歴の閾値は 4.5 Å。
- 切り取りは 0.5 ns（フレーム [0,1,2,3,4,5]、6フレーム、0〜0.5 ns を覆う）。G107・G113 と同じ。
- ブートストラップは結果を見る前に固定した: 10,000回、seed 42、パーセンタイル法（G49・G59・G62・G23・G67 と同じ）。再標本化の単位はタンパク質。

### 区間の粗さについての留保

テストのタンパク質は 1mix_A と 2qt4_A の 2つだけなので、タンパク質単位の再標本化で取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかない。そのためブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になる。区間は粗い。計算の工夫として、3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行った。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になる（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42。

## 3. 結果

## 4. 読み取り

- **6 セルのうち 4 セルの区間は 0 を含まなかった**（5 ns先の第13案、50 ns先の第11案、90 ns先の第11・14案）。この 4 セルでは、混合の足しはテストの 2 タンパク質のどちらで見てもプラス側で、タンパク質の水準でも 0 を含まない。5 ns先の第13案は両タンパク質で +0.069・+0.066 とそろっており、50 ns先の第11案も +0.052・+0.077 とそろっている。
- **30 ns先の第11・12案の区間は 0 を含んだ。** タンパク質ごとに見ると、1mix_A では +0.156・+0.131 と大きいが、2qt4_A では −0.124・−0.090 と負で、合算のプラスは 1mix_A だけが引っ張っている形。30 ns先の 2 案は、タンパク質の水準では足しがあるとは言えない。
- 90 ns先の第11・14案は区間が 0 を含まないが、タンパク質ごとに見ると 2qt4_A（+0.179・+0.245）が大きく、1mix_A（+0.025・+0.037）は小さい。区間が 0 を含まないのは、2 タンパク質のどちらもプラス側だからで、大きさはタンパク質で違う。
- 30 ns先の第13案（+0.046、線のすぐ下）の区間も [−0.078, +0.078] と 0 を含んだ。

## 5. 判断できること・まだ分からないこと

- 判断できること: 5 ns先の第13案、50 ns先の第11案、90 ns先の第11・14案の 4 セルでは、混合の足しはタンパク質の水準でも 0 を含まない。30 ns先の第11・12案は、合算では +0.05 を超えたが、タンパク質の水準では 0 を含む。
- まだ分からないこと: テストは 2 タンパク質だけなので、区間は 3 通りの組み合わせの最小値〜最大値でしかなく、粗い。2 タンパク質のどちらか一方だけが引っ張る形（30 ns先の 1mix_A、90 ns先の 2qt4_A）が、他のタンパク質でも同じかどうかは分からない。
