# K73 90 ns先の担い手は、強い土台でも割合か（K06(b) の条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。強い土台では、90 ns先で平均だけ 0.910、3.5 Å以下割合だけ 0.886 と両方が利得の8割以上を戻しました。K71（弱い土台）では割合だけが残ったのと違い、強い土台では平均と割合の両方が担えます。担い手の名前は土台によって違います。

## 1. 何を確かめる実験か

K71 で、弱い土台（資料Dの条件）では 90 ns先の担い手は 3.5 Å以下割合（回復率 0.973）で、平均だけは 0.772 と8割に届きませんでした。強い土台（K06(b) の条件）でも同じか、1つの統計量だけを入れた条件で切り分けます。

読み方は先に固定しました。強い土台でも 3.5 Å以下割合だけで利得の8割以上が戻れば、90 ns先の担い手は土台によらず割合です。平均が担い手になれば、土台によって担い手が違います。両方とも8割以上に戻る場合は、その旨を正直に記録します（「割合だけが担い手」ではなく「平均と割合の両方が担える」という読みになります）。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A）で学習し、未見100タンパク質×3レプリカ（163,074件、学習 13,808件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`）をそのまま使いました。軌道の取り直しも、本体 T1I2006 の読み込みも、生成器のチェックポイントの読み込みも行っていません。
- 補正モデルの入力は、静的5特徴（本体の予測確率、起点距離、基礎記述子3個）に履歴の量を足す形です。実履歴10特徴の並びは [最初の値、平均、標準偏差、最小値、最大値、最後−最初、最後−1つ前、3.5 Å以下割合、4.5 Å以下割合、距離が増えたステップの割合] で、6統計量はそのうちの [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下割合] です。
- 条件は9つで、静的特徴に次の履歴の量を足したものです。
  - 静的のみ: 履歴なし
  - real6: 6統計量すべて（K71 の「全部入り」に対応。K73 の回復率の主たる参照）
  - full: 実履歴10特徴すべて（K06(b) の実履歴条件そのもの。K21 の参照）
  - 最初の値だけ / 平均だけ / 標準偏差だけ / 最小値だけ / 最後−最初だけ / 3.5 Å以下割合だけ: その列だけ
- 利得 =（参照条件の AUPRC − 静的のみ）、各条件の回復率 =（その条件の AUPRC − 静的のみ）÷ 利得で測りました。回復率は real6 を参照にしたものを主、full を参照にしたものを従としました。評価はタンパク質マクロ平均 AUPRC を主、全体まとめ（ミクロ）を従としました。
- 測った予測幅は 90 ns先（主判断）と 1 ns先（参考）の2幅です。
- 対照の確認: 静的のみと full は、90 ns先と 1 ns先の両方で K06(b)・K12・K21 の記録と全4指標で完全に一致しました（最大差 0.0、1 ns先で静的のみ マクロ AUPRC 0.4539、full 0.5251、90 ns先で静的のみ 0.4357、full 0.4630）。

## 3. 結果

90 ns先（主判断）の利得と、各条件の回復率です。real6 の利得はマクロ +0.0318（静的のみ 0.4357、real6 0.4675）、full の利得はマクロ +0.0273（full 0.4630）で、6統計量だけのほうが 10特徴よりわずかに大きいです。利得が小さいわけではないため、回復率の分母が小さいことによる振れの心配はありません。

## 4. 読み取り

- **強い土台では、90 ns先で平均だけ 0.910 と割合だけ 0.886 の両方が、real6 の利得の8割以上を戻しました。** 先に固定した読み方の3つ目の枝に当たり、担い手は「平均と割合の両方が担える」という読みになります。full を参照にしても平均 1.060、割合 1.032 と両方8割以上で、読みは変わりません。
- K71（弱い土台）との違いです。弱い土台では 90 ns先で平均だけ 0.772 と8割に届かず、割合だけ 0.973 が残りました。強い土台では平均が 0.910 まで戻り、割合と並びます。担い手の名前は土台によって違います。90 ns先の割合の働きは土台によらず強い（弱い土台 0.973、強い土台 0.886）一方で、平均の働きは土台によって変わります（弱い土台 0.772、強い土台 0.910）。
- K21 との照合です。full を参照にした回復率は、平均 1.060/1.084、割合 1.032/1.069、最小値 0.546/0.491、最初の値 0.632/0.693、最後−最初 0.599/0.608、標準偏差 0.082/0.133 と、K21 の 90 ns先の行（平均 1.060/1.084、割合 1.032/1.069、最小値 0.546/0.491）と完全に一致しました。K21 はすでに強い土台の 90 ns先を測っており、K73 はその値を K71 と同じ 6統計量の分け方・real6 参照で測り直したものですが、食い違いはありません。K21 の「形だけ」（標準偏差＋最後−最初の2列）の 0.553/0.589 は、K73 の標準偏差だけ 0.082/0.133 と最後−最初だけ 0.599/0.608 を合わせた形と整合します。
- 参照の違いについてです。K21 の参照は 10特徴の full（利得 +0.0273）で、K73 の主たる参照は 6統計量の real6（利得 +0.0318）です。90 ns先では real6 のほうが full より利得が大きく、回復率で 1.165 倍の関係になります（K21 の表でも real6 は 1.165/1.162 でした）。1 ns先では real6 と full の利得はほぼ同じ（+0.0707 対 +0.0712）です。参照をどちらにしても、90 ns先で平均と割合の両方が8割以上という読みは変わりません。
- 他の統計量です。最小値だけ 0.469、最初の値だけ 0.543、最後−最初だけ 0.514 と半分ほどを戻し、標準偏差だけは 0.071 とほとんど戻しません。標準偏差が 90 ns先でも何も戻さないことは、K07（揺らぎの大きさは主因ではない）と合います。
- 1 ns先の参考値です。real6 参照で平均だけ 0.965、割合だけ 0.864 と両方8割以上で、強い土台の 1 ns先では平均と割合の両方が担い手です。K12 の差し替え実験（平均 0.933、割合 0.799）とも同じ形です。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、90 ns先の指導力は平均だけでも割合だけでもほぼ担えます（回復率 0.910 と 0.886、full 参照では 1.060 と 1.032）。弱い土台では割合だけが残ったのと違い、担い手の名前は土台によって違います。90 ns先の割合の働きは土台によらず強い一方で、平均の働きは土台によって変わります。
- まだ分からないこと: 平均と割合の情報の重なりの内訳（割合の利得のうち、平均と相関する分がどれだけか）。また、強い土台で平均が 90 ns先でも担い手として残る理由（本体の予測が平均の情報をどう補うか）は、この実験だけでは分かりません。
