# K51 生成器は、学習したタンパク質では平均の誤差が小さいか（資料Dの条件、水素結合）

## 問い

K43 で、生成の平均は静的な予測にほぼ沿うことが分かりました。生成器がその静的な対応を学習で覚えたものか、それとも汎化したものかを確かめます。

## 段取り（進行中）

- 生成器の学習に使われた8タンパク質（teacher：1u84_A、4u5h_G、5hub_A、1x6j_A、2y1y_A、1krn_A、2y4x_B、4xqm_A）と、学習に使われていないタンパク質（資料Dの6タンパク質）で、生成の平均の誤差（実の平均との差の標準偏差と平均）を比べます。
- 生成の系列は K05 と同じやり方で、保存した生成器（`~/workspace/k06b/gen22/generator.pt`、weights_only で読み込み）から作ります。候補は資料Dの定義にそろえます（起点 1 ns、起点距離 3.5 Å 超 6.0 Å 以下、残基が異なるドナー・アクセプター対）。
- 実の平均は 11点の履歴系列（0〜1 ns）の平均で、K08・K23 と同じ定義です。生成の平均は起点＋生成した4点の5点の平均で、K23 と同じ定義です。

## 途中経過

- 2026-11-23 20時台：teacher 8タンパク質のうち 1u84_A、4u5h_G、5hub_A の 9軌道分ができました（1u84_A は各 386・372・376件、4u5h_G は各 434・436・432件、5hub_A は各 444・451・442件）。残り 5タンパク質（1x6j_A、2y1y_A、1krn_A、2y4x_B、4xqm_A）は取得・生成中です。5hub_A の取得に約5分かかり、ATLAS の取得が律速になっています。
