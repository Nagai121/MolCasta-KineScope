# K51 生成器は、学習したタンパク質では平均の誤差が小さいか（資料Dの条件、水素結合）

## 問い

K43 で、生成の平均は静的な予測にほぼ沿うことが分かりました。生成器がその静的な対応を学習で覚えたものか、それとも汎化したものかを確かめます。

## 段取り

- 生成器の学習に使われた8タンパク質（teacher：1u84_A、4u5h_G、5hub_A、1x6j_A、2y1y_A、1krn_A、2y4x_B、4xqm_A）と、学習に使われていないタンパク質（資料Dの6タンパク質）で、生成の平均の誤差（実の平均との差の平均と標準偏差）を比べます。
- 生成の系列は K05 と同じやり方で、保存した生成器（`~/workspace/k06b/gen22/generator.pt`、weights_only で読み込み）から作ります。候補は資料Dの定義にそろえます（起点 1 ns、起点距離 3.5 Å 超 6.0 Å 以下、残基が異なるドナー・アクセプター対）。
- 実の平均は 11点の履歴系列（0〜1 ns）の平均で、K08・K23 と同じ定義です。生成の平均は起点＋生成した4点の5点の平均で、K23 と同じ定義です。
- 比較の相手（学習に使われていない資料Dの6タンパク質）は、K05 の生成系列と K08 のキャッシュから取ります（作り直しはしません）。

## 結果

生成の平均の誤差（生成の平均 − 実の平均）：

| 群 | 件数 | 平均 | 標準偏差 | 平均絶対誤差 |
|---|---|---|---|---|
| teacher 8タンパク質 | 11,028 | −0.211 Å | 0.574 Å | 0.369 Å |
| 未学習（資料Dの6タンパク質） | 14,582 | −0.155 Å | 0.483 Å | 0.317 Å |

タンパク質ごと（誤差の標準偏差）：teacher は 1u84_A 0.736、4u5h_G 0.482、5hub_A 0.592、1x6j_A 0.618、2y1y_A 0.590、1krn_A 0.508、2y4x_B 0.587、4xqm_A 0.466。未学習は 1bgf_A 0.518、1ifg_A 0.516、1j8r_A 0.451、2b0a_A 0.480、1mix_A 0.518、2qt4_A 0.388。未学習側は K23 の値（−0.155 / 0.483）と一致します。

## 結論

あらかじめ決めた読み方は「teacher の誤差がはっきり小さければ、覚えた成分がある。同じくらいなら、生成器は静的な対応を汎化している」でした。**結果はそのどちらでもなく、teacher の誤差のほうが大きい**（標準偏差の比 1.19、平均の絶対値も大きい）ので、覚えた成分があるとは言えません。生成器は学習したタンパク質でうまくなるのではなく、静的な対応を汎化している、という読みになります。

ただし注意点があります。teacher 側の実の平均のばらつき自体が少し大きい（標準偏差 0.949 Å に対し未学習は 0.880 Å、比 1.08）ので、誤差の差の一部はタンパク質の組み合わせの違いによるものです。ばらつきの差を差し引いても、teacher が小さいという方向にはなりません。このばらつきの数値は `k51_results.json` の `real_mean_spread` に記録してあり、`k51_realmean_spread.py` で計算し直せます。teacher の軌道は生成器の学習データそのものなので、起点 1 ns の設定が学習行と重なる可能性はありますが、それは誤差を小さくする方向の偏りであり、結果の向きを変えません。

## 取得の経緯

- 2y1y_A と 2y4x_B は、1回目の ATLAS の取得で途中で止まりました（2y1y_A は 22,000,169 バイトのうち 21,989,808 バイト、2y4x_B は 21,526,738 バイトのうち 21,513,536 バイトで、残り約1万バイトのところで切れました）。K15 のキャッシュにもこの2タンパク質はありませんでした。
- やり直しでは2つとも最後まで取れました（2y1y_A は約19分、2y4x_B は約13分）。続きから再開するやり方（HTTP の Range 指定で残りを取る）は、取得の仕組み（`minitopol/atlas/client.py` の `AtlasClient.download`、URL は `https://www.dsimb.inserm.fr/ATLAS/api/ATLAS/analysis/<タンパク質>`）を調べるところまで用意しましたが、やり直しが通ったので使いませんでした。
- ほかのタンパク質の取得時間は、1u84_A が約45秒、4u5h_G が約11秒、5hub_A が約5分、1x6j_A が約18分、1krn_A が約5分、4xqm_A が約6分で、タンパク質ごとに大きく違いました。1x6j_A は途中で止まったように見えましたが、実際はゆっくり進んでいて、途中で止めたあとに終わっていたことが分かりました。
