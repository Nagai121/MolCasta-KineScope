# K32: 水の環境の履歴を測れるかどうかの確認

実験ではなく、確認です。K25 では変換済み軌道に水が含まれていないため、水の環境の履歴は測れませんでした。水の座標がどこかにあるかを確かめました。

## 結論
- 変換済み軌道（MiniTopol A変換）には水はありません。18軌道すべてで残基名は20種類の標準アミノ酸だけで、変換の定義として溶媒残基（HOH/SOL/WAT）と水素が落とされます。
- ATLAS の完全形式（total）の軌道には水があります。K25 の6タンパク質分はすべて手元に残っており、新たなダウンロードは要りません。2qt4_A の R1 で確かめたところ、水は 4,479残基（13,437原子、酸素 OW が 4,479個）で、タンパク質の重原子は 674個と変換済み軌道の原子数と一致します。イオンも Na 14個、Cl 19個あります。
- フレームの対応も取れます。完全形式は 10 ps間隔・10,001フレーム、解析版は 100 ps間隔・1,001フレームで、解析版のフレーム k は完全形式のフレーム 10k に対応します。2qt4_A の R1 で確かめたところ、起点のフレームは座標が完全に一致し（Kabsch RMSD 約 7e-15 Å）、1 ns先のフレーム（解析版 10、完全形式 100）も箱のベクトルが完全に一致し、Cα間の距離行列の中央値の差は 0.0006 Å でした。
- したがって、K25 と同じ条件で水の環境の履歴を足す実験に進めます。MiniTopol の変換を通さず、完全形式の軌道ファイルを直接読む段取りになります。2026-11-16 に Echizen が、水の特徴量については例外として軌道ファイルを直接扱ってよいと明言した記録があり、この進め方はその例外の範囲です。

## (a) 変換済み軌道に水はあるか
- `~/workspace/gpt-model-check/data/trajectories/` の18軌道（6タンパク質×3レプリカ）の `atoms.parquet` の `residue_name` 列をすべて読みました。どの軌道にも水（SOL/WAT/HOH）やイオンはなく、残基名は20種類の標準アミノ酸だけでした。原子数は 1bgf_A が 1,019、1ifg_A が 1,112、1j8r_A が 1,605、1mix_A が 1,680、2b0a_A が 1,487、2qt4_A が 674（2qt4_A は16種類のアミノ酸）です。K25 の記録（残基名は20種類の標準アミノ酸だけ）と一致します。
- 変換コード（`~/workspace/minitopol-explore/src/minitopol/converter.py` の `convert` 関数）でも確認しました。残す原子は「元素が H/D/T でなく、残基名が溶媒残基名（HOH/SOL/WAT）に含まれないもの」で、定義として水と水素は落とされます。変換済み軌道の `manifest.json` にも `solvent_resnames: ["HOH", "SOL", "WAT"]` と記録されています。`system_conditions.json` の水モデルは null で、メタ情報としても水の情報は残っていません。
- つまり、完全形式で取り込んでも MiniTopol の変換を通る限り水の座標は残らないため、変換済み軌道から水の特徴量は作れません。

## (b) ATLAS の元の軌道で水は取れるか
- 2026-11-16 の部分取得分が手元に残っていました。`~/workspace/rod-survival-exp/atlas-ws/storage/sources/ATLAS/` にある完全形式（total）の展開済みファイルで、K25 の6タンパク質すべてに 3レプリカ分の TPR と XTC があります（1bgf_A 6.3 GB、1ifg_A 6.6 GB、1j8r_A 7.1 GB、2b0a_A 4.0 GB、1mix_A 5.1 GB、2qt4_A 3.7 GB）。ダウンロードの記録（`atlas_total_download4.log`）でも、6タンパク質分は取得済み（downloaded / skipped）になっています。新たなダウンロードは要りません。
- MiniTopol の AtlasClient のコード（`~/workspace/minitopol-explore/src/minitopol/atlas/client.py`）でも、取得できる種類は `KINDS = ("analysis", "protein", "total")` で、`download(workspace, dataset, kind="total")` が ATLAS の `https://www.dsimb.inserm.fr/ATLAS/api/ATLAS/total/{dataset}` から取ってくる作りです。足りない分があれば同じ段取りで取れます。
- 2qt4_A の R1（`2qt4_A_prod_R1.tpr` + `2qt4_A_prod_R1.xtc`、約1.2 GB）を MDAnalysis 2.11.0 で実際に読みました。原子 14,739個、残基 4,607個のうち、水 SOL が 4,479残基・13,437原子（酸素 OW が 4,479個、水素 HW1/HW2 を含む）、イオンが Na 14個・Cl 19個、タンパク質原子が 1,269個（重原子 674個で、変換済み軌道の 674個と一致）でした。フレーム数は 10,001、間隔は 10.0 ps です。
- 1 ns先のフレーム（完全形式のフレーム 100）で、タンパク質の重原子から 3.5 Å 以内にある水は 242個、5 Å 以内は 563個でした。水の環境を数えるだけの水は十分にあります。

## フレームの対応（解析版と完全形式）
- 解析版のフレーム k（時刻 100k ps）は、完全形式のフレーム 10k（時刻 10×10k ps）に対応します。履歴 0〜1 ns の11フレーム（解析版 0〜10）は完全形式の 0, 10, 20, ..., 100 です。起点フレーム（解析版 10、1 ns）は完全形式のフレーム 100 です。
- 対応の確認（2qt4_A の R1、タンパク質の重原子 674個）:
  - フレーム 0 どうしは Kabsch RMSD が約 7e-15 Å で完全に一致しました。
  - 解析版フレーム 10 と完全形式フレーム 100 は、箱のベクトルが完全に一致しました（[43.975758, 47.653576, 69.354706]）。Cα間の距離行列の差は中央値 0.0006 Å で、±10フレームずらした対応（90・110）では中央値 0.33・0.37 Å とはっきり悪くなりました。対応は 10k で正しいです。
  - ただし距離行列の差の大きいペアが 149/4,465件（1 Å超）あり、これは完全形式の XTC が原子ごとに箱をまたいで巻き込まれた座標で保存されているためのものです。解析版と完全形式で箱の扱いが違うため、水との距離は K25 と同じくフレームごとの箱で最小イメージ（軸ごとの箱）で計算する必要があります。座標をそのまま引き算してはいけません。
- なお、解析版フレーム 10 と完全形式フレーム 100 の Kabsch RMSD は 10.6 Å と大きく見えますが、これは上記の箱をまたいだ巻き込みによるもので、内部の距離行列の中央値は 0.0006 Å です。設定が違うわけではありません。

## 水の環境の履歴を足す実験に進めるか
進めます。段取りは次のとおりです。
- 対象: K25 と同じ6タンパク質×3レプリカ。完全形式のファイルはすべて手元にあり、新たな取得は要りません。1タンパク質あたり約4〜7 GB、合計約34 GB がすでにあります。
- 読み方: MiniTopol の変換は通さず、完全形式の TPR + XTC を MDAnalysis で直接読みます。履歴に使うのは完全形式のフレーム 0, 10, ..., 100（解析版の 0〜10 に対応）だけです。10,001フレーム全部を読む必要はありません。
- 水の環境特徴量の案（2通り）:
  1. 近くの水の数の系列: 候補ペアのドナー原子・アクセプター原子から 3.5 Å 以内にある水の酸素（OW）の数をフレームごとに数え、11フレームの系列を6統計量（最初の値、平均、標準偏差、最小値、最後−最初、1個以上いた割合）に集計します。ドナー側とアクセプター側で2組です。
  2. 橋渡し水の数と最も近い水までの距離の系列: ドナー原子とアクセプター原子の両方から 3.5 Å 以内にある水（橋渡し水）の数をフレームごとに数えた系列と、ドナー・アクセプターそれぞれから最も近い水までの距離の系列を、同じ6統計量に集計します。
- 計算の重さの見込み: 水の酸素は1レプリカあたり約4,500〜1万個程度で、候補は1レプリカあたり約600〜1,000件、使うフレームは11個だけです。候補ごとにドナー・アクセプターの数個の原子と水の酸素との距離を数えるだけなので、ベクトル化すれば1レプリカあたり数分程度の見込みです。重いのは 1.1〜1.8 GB の XTC を開く読み込みで、18レプリカ分でもローカルで回る見込みです。Colab は要りません。
- 注意: 水の座標は箱をまたいで巻き込まれているため、距離は必ずフレームごとの箱で最小イメージで計算すること。候補ペアの同定（ドナー残基・アクセプター残基）は K25 と同じく解析版の候補を使い、水の特徴量だけを完全形式から足すこと。
