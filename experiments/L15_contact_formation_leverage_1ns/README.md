# L15: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L01（水素結合の形成、1 ns先）と同じ曲がりの測り方で、接触の形成の 1 ns先を測る。
- 状態: 完了。回復率 0.8 と 0.9 に届く最小の長さはどちらも覆う長さ 0.9 ns（統合値）。増え幅がいちばん大きいのは 0.4→0.5 ns（+0.1619）。曲がりは単調ではなく、0.9 ns で最大（0.9150）になったあと 1.0 ns で 0.7092 まで下がる。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの条件のモデルに入れたときの 1 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、統合・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 219件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（13条件の学習で約10〜50秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3398、全部入り 0.5669、利得 +0.2271 で、K27 の記録と小数第4位まで完全一致した。学習・テストの件数も土台の再現のときと同じ（学習 9,610件・テスト 7,384件、テスト陽性 219件）。覆う長さ 1.0 ns の平均だけの AUPRC も、K27 の only_mean の記録と小数第4位まで完全一致した。
G07 の記録との照合では、覆う長さ 0.2 ns（G07 の「0.25 ns」）の回復率 0.5120 が G07 の 0.512 と、覆う長さ 0.5 ns の 0.7734 が G07 の 0.773 と一致しました。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.9 ns**（統合値 0.9150）。0.5 ns で 0.7734、0.7 ns で 0.7827 と線の手前まで来るが、届くのは 0.9 ns が初めてです。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.9 ns**（統合値 0.9150）。0.8 の線と同じ長さで初めて届きます。
3. **増え幅がいちばん大きい場所: 0.4→0.5 ns（+0.1619）**。次に大きいのは 0.8→0.9 ns（+0.1532）で、近い大きさの増え幅が 2 か所あります。0.9→1.0 ns では −0.2058 と大きく下がります。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1761（静的のみ 0.3950、全部入り 0.5710）、2qt4_A が +0.3407（静的のみ 0.2194、全部入り 0.5601）で、2qt4_A の利得のほうが大きい。

段の位置（0.4→0.5 ns）でのタンパク質ごとの回復率は、1mix_A が 0.5487 → 0.7616（+0.2129）、2qt4_A が 0.6837 → 0.7886（+0.1049）で、どちらも正の増え幅です。統合値の段は、片方のタンパク質だけに引っ張られたものではありません。ただし 0.8→0.9 ns の増え幅（+0.1532）も近い大きさで、そちらは 1mix_A +0.2514（0.6688 → 0.9202）、2qt4_A −0.0529（0.9239 → 0.8710）と符号が分かれます。

## 4. 読み取り

- 接触の形成の 1 ns先では、曲がりは L01（水素結合の形成、1 ns先）のような「0.6 ns の段」にはならず、増え幅の大きい場所が 0.4→0.5 ns と 0.8→0.9 ns の 2 か所に分かれました。線に届く長さも 0.9 ns と、L01 の 0.6 ns より後ろです。
- 1.0 ns（全部の平均）で回復率が 0.7092 まで下がるのは、K27 の only_mean の AUPRC（0.5008）が 0.9 ns の切り取り（0.5476）を下回るためで、切り取りを長くすると単調に良くなるわけではありません。G07 の接触の切り取りの走査でも、0.5 ns の平均の回復率 0.773 が記録されており、今回の 0.5 ns の値（0.7734）と一致します。
- フレーム 0 だけ（覆う長さ 0 ns）でも回復率 0.4288 が戻ります。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
