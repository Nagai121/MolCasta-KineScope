# 実験の記録の約束

実験は1つずつディレクトリを作って記録します（例: experiments/K01_time_degradation/）。
各ディレクトリには、その実験の記録ファイル（README.md）と、実行したコードと、結果のファイルを置きます。

記録ファイルには、最低限つぎの項目を書きます。

- 何の仮説を確かめる実験か（仮説の番号）
- 使ったデータと軌道（出所、タンパク質、複製、時刻の範囲）
- 比較の条件のうち、どこを変えたか（変えていない条件も主なものは書く）
- 予測器を固定した比較か、学習し直した比較か
- 指導力がどれだけ変わったか（指標と数値、基準の条件を明記する）
- その結果から判断できることと、まだ分からないこと
- コードと出力の保存先

注意すること:

- 同じ条件で比べた結果と、モデルやデータの集合が違う参考比較は、はっきり分けて書きます。
- 未来の情報の混入、評価と学習の集合の重なり、候補の集合の不一致、予測の起点のずれは、結論を無効にするので避けます。疑いがある場合は、その旨を記録に残します。
- うまくいかなかった実験も成果として残します。途中でやめた場合は、やめた理由を書きます。
- 大きなデータファイルはリポジトリに入れず、GitHub Release の添付ファイルに置いて、記録から場所が分かるようにします。
