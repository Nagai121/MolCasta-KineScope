# L27: L01 の曲がりを塩橋の形成で測る（K15 の土台、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる L 系列の続き。短い実 MD の覆う長さに対して回復率がどう伸びるかの曲がりを、塩橋の形成（K15 の土台、全予測幅）で測る割り当て（L27〜L32）の 1 ns先。
- 状態: 完了。**曲がりは単調ではなく、回復率は長さに対して 0.55〜0.97 の範囲で上下しました。** 先に固定した読み方をそのまま当てると、0.8 と 0.9 の線に届く最小の長さはどちらも統合値で 0.3 ns ですが、0.4 ns では 0.545 まで落ちるため、線に届いた状態が続くわけではありません。増え幅がいちばん大きい場所（0.2→0.3 ns、統合 +0.347）も、タンパク質ごとの増え分の中央値は 0.000 で、正だったのは 18タンパク質のうち 33% にとどまり、タンパク質一般の段とは読めません。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を始めの短い部分だけに切り、覆う長さを L01・L02 と同じ 11通り（0〜1.0 ns、0.1 ns 刻み）に変えて、各長さで「切り取りの平均だけ」を履歴の特徴量として入れたときの利得の回復率を測ります。長さの定義は L01・L02 にそのまま合わせました（覆う長さ L ns の切り取りはフレーム 0〜(L/0.1)、0 ns はフレーム0だけ、1.0 ns は 11フレーム全部）。

読み方は先に固定しました（L02 と同じ）。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の条件です。学習 58タンパク質・テスト 30タンパク質、静的特徴 5個、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15、L2 0.02、種 42）を条件ごとに学習し直します。塩橋の候補の定義は K15 の記録に合わせています（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。データは K15 のキャッシュ（学習 2,557件、テスト 1,170件、1 ns先の陽性 93件）を使います。
- 条件は、静的のみ、全部入り（静的＋履歴 6統計量：最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合）、切り取りの平均だけ（静的＋切り取りの平均）11通りです。
- 回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。全体とタンパク質ごとの平均の両方で測ります。
- 実行はローカルで、学習と評価に約30秒、ブートストラップ 10,000回に約60秒でした（この規模では Colab に出すまでもありません）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns（全体 0.963）**。タンパク質ごとの平均では 0.4 ns（0.801）。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.3 ns（全体 0.963）**。タンパク質ごとの平均では 0.5 ns（0.964）。ただし 0.3 ns の次（0.4 ns）では全体が 0.545 まで落ち、線を超えた状態は続きません。機械的に読むと 0.3 ns ですが、曲がりの形としては「届いた」とは言いにくい値です。
3. **増え幅がいちばん大きい場所: 0.2→0.3 ns（全体 +0.347、平均 +0.294）**。次に大きいのは 0.6→0.7 ns（全体 +0.238、平均 +0.284）ですが、0.3→0.4 ns では全体で −0.418 と大きく戻します。
4. 段の位置（0.2→0.3 ns）のタンパク質ごとの増え分は、中央値 0.000 [25%点 −0.147、75%点 +0.419] で、正だったのは 18タンパク質のうち 33%、+0.1 以上は 28% でした。最大 +196.8 は全部入りの利得がごく小さいタンパク質で比率が大きく振れたもので、統合値の跳ねは少数のタンパク質に引っ張られています。タンパク質ごとの回復率が定義できたのは、全部入りの利得が正だった 18タンパク質です（残り 12タンパク質は利得が 0 以下か AUPRC が定義できませんでした）。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 塩橋の形成・1 ns先では、回復率は覆う長さに対して単調に伸びず、0 ns の時点ですでに 0.571（全体）あり、その後は 0.55〜0.97 の範囲を上下します。水素結合の形成（L01・L02）で見えた「長くすると積み上がる」形にはなっていません。
- 区間が広いため、長さの間の差のほとんどは揺れの範囲です。この土台（テスト 1,170件・陽性 93件）では、1 ns先の曲がりの細かい形は決められません。
- 判断できるのは、「フレーム 0 だけでも利得の半分強は戻る」「0.3 ns 前後と 0.7〜1.0 ns で高い値が出るが、持続する形ではない」という大まかなところまでです。
