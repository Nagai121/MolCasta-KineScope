# L04: L02 の曲がりを予測幅 5 ns で測る（K06(b) の条件、水素結合の形成、5 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L02（強い土台、予測幅 1 ns）では、回復率は覆う長さに対して滑らかに上がり、L01 で見えた 0.6 ns の段は残らなかった。ここでは L02 と同じ方法・同じ土台で予測幅だけを 5 ns に変え、曲がりの形（線に届く長さと段の有無）が予測幅でどう変わるかを測る。
- 状態: 完了。**5 ns先でも増え幅がいちばん大きいのは最初の 0→0.1 ns（全体 +0.204）で、段と呼べる跳ねは他にない。** ただし曲がりは L02 ほど滑らかではなく、0.5 ns 以後は下がって上がるを繰り返す（全体で 0.816 → 0.781 → 0.860 → 0.821 → 0.888 → 0.882）。回復率 0.8 に届く最小の長さは 0.5 ns と L02（0.7 ns）より前へずれた一方、0.9 には 1.0 ns までのどの長さでも届かなかった（最大は 0.9 ns の 0.888）。平均だけの条件の天井そのものが 1 ns先より低い（覆う長さ 1.0 ns で 0.882、L02 は 0.975）。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として強い土台の補正モデルに入れたときの 5 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。方法は L02 とまったく同じで、ラベルの予測幅だけが違う。

読み方は先に固定した（L02 と同じ）。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K06(b)（強い土台）と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、5 ns先の陽性 12,567件）で評価する。静的特徴は5個、履歴の要約値は10個（最初、平均、標準偏差、最小、最大、最後−最初、最後−直前、3.5 Å以下割合、4.5 Å以下割合、増加割合）。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 5 ns先。条件ごとに学習し直す。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`、タンパク質ごとの `r{r}_series`、11点×候補数）をそのまま使う。静的特徴と履歴の要約値は K06(b) の保存値（`~/workspace/k06b/run/k06b_out/`）を使う。実行はローカルVM（L02 のコードとデータがこの仮想マシン上にあり、計算量も軽いため。学習13条件で約31秒、ブートストラップ 10,000回で約16分）。
- 実行の経緯: 最初の実行は仮想マシンの再起動でブートストラップ 8,000/10,000回 のところで止まったため、最初から回し直した。学習は種が固定されていて決定的であり、土台の再現の照合は両方の実行で同じく全項目一致した。最終結果は回し直した実行のものである。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う。

| 覆う長さ | フレーム | フレーム数 |
|---|---|---:|
| 0 ns | 0 | 1 |
| 0.1 ns | 0, 1 | 2 |
| 0.2 ns | 0〜2 | 3 |
| 0.3 ns | 0〜3 | 4 |
| 0.4 ns | 0〜4 | 5 |
| 0.5 ns | 0〜5 | 6 |
| 0.6 ns | 0〜6 | 7 |
| 0.7 ns | 0〜7 | 8 |
| 0.8 ns | 0〜8 | 9 |
| 0.9 ns | 0〜9 | 10 |
| 1.0 ns | 0〜10 | 11 |

覆う長さ 0 ns はフレーム0だけ、つまり履歴の最初のフレームの距離そのもの（平均を取っても値は同じ）。起点フレーム10（1 ns）は変えず、ラベルは 5 ns先。

G 系列の呼び方との対応は L02 と同じ。G81 の「0.25 ns」の切り取りはフレーム [0,1,2] で、L01・L02・L04 の覆う長さ 0.2 ns と同じ条件である。G145 の「1.0 ns」（フレーム [0..9]）は覆う長さ 0.9 ns にあたり、覆う長さ 1.0 ns（11フレーム全部の平均、G05・G81 の「全部の平均だけ」）とは違う。

### 条件の一覧（5 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（G05・L02 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（結果を見る前に固定、L02 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取りを numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った（L02 で直した、選ばれなかったタンパク質だけの同点グループで重みが 0 になり NaN が伝わる問題への対処を含む）。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC を再標本化の重なり具合で重み付けして平均したもの。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.5 ns**（全体 0.816、タンパク質ごとの平均 0.830）。ただし 0.6 ns で 0.781 と線の下へ戻るため、届いたまま保たれるのは 0.9 ns 以後ではなく、0.5 ns の到達は一度きりの形である（0.7 ns で 0.860 と再び超え、0.8 ns で 0.821、0.9 ns で 0.888、1.0 ns で 0.882 と、0.6 ns を除いて 0.5 ns 以後はおおむね線の上にいる）。
2. **回復率 0.9 に届く最小の長さ: なし。** 0〜1.0 ns のどの長さでも届かず、最大は 0.9 ns の全体 0.888（平均 0.877）。95% 区間の上限は 0.9 ns で 0.953 と 0.9 をまたぐが、点推定では届かない。
3. **増え幅がいちばん大きい場所: 0→0.1 ns（全体 +0.204、タンパク質ごとの平均 +0.215）**。次に大きいのは 0.2→0.3 ns（全体 +0.143）。それ以外は +0.10 以下で、負の区間も3つある（全体で 0.3→0.4 ns −0.017、0.5→0.6 ns −0.035、0.7→0.8 ns −0.039）。**1か所に段と呼べる跳ねはなく、最初の 0.1 ns の伸びが突出している点は L02 と同じだが、L02 のような単調な上がり方ではなく、0.5 ns 以後は上下しながら緩やかに上がる形である。**
4. 95% 区間は全体で幅 0.13〜0.16 ほど。隣り合う長さの区間は大きく重なっており、0.5 ns 以後の上下は区間の重なりの範囲内である。

## 5. 読み取り

- **5 ns先でも、段は最初の 0.1 ns にある。** 増え幅最大は 0→0.1 ns（全体 +0.204）で、L01 の 0.6 ns のような途中の跳ねはない。予測幅を変えても「最初の 0.1 ns で大きく戻る」という骨格は変わらない。
- 0.8 の線は 1 ns先より早く（0.5 ns）届くが、0.9 の線は 1.0 ns まで伸ばしても届かない。5 ns先では全部入りの利得自体が小さく（+0.0514）、その中で平均だけでは取り戻せない部分（要約値10個のうち平均以外の成分）の割合が 1 ns先より大きい、という形である。
- 0.5 ns 以後の上下（0.816 → 0.781 → 0.860 → 0.821 → 0.888 → 0.882）は、区間の重なりから見て測定の揺れの範囲で、長さの間の実質的な差とは読めない。0.5 ns を過ぎると、平均だけの条件はおおむね 0.78〜0.89 の範囲に頭打ちになる。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、5 ns先）では、回復率 0.8 に届く最小の覆う長さは 0.5 ns、0.9 には 1.0 ns までのどの長さでも届かない（最大 0.888）。増え幅がいちばん大きいのは 0→0.1 ns（+0.204）で、途中に段と呼べる跳ねはない。
- まだ分からないこと: さらに長い予測幅（10〜90 ns、L05〜L08 の担当）で天井がどう下がるか。0.5 ns 以後の頭打ちが平均以外の要約値の寄与の増大によるものかは、この実験では切り分けていない。実測の費用に直したときの形（L03 の流儀の換算は L04 にはまだしていない）。
