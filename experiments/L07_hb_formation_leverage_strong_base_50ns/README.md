# L07: L02 の曲がりを予測幅 50 ns で測る（K06(b) の条件、水素結合の形成、50 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L02（強い土台、1 ns先）では、回復率は覆う長さに対して滑らかに上がり、L01（資料Dの条件）で見えた 0.6 ns の段は残らなかった。L04（5 ns先）・L05（10 ns先）でも段はなかった。ここでは L02 と同じ方法・同じ土台で、予測幅だけを 50 ns に変えて同じ曲がりを測り、線（0.8 / 0.9）に届く長さと段の有無が予測幅でどう変わるかを見る。
- 状態: 完了。**50 ns先でも段はなかった。増え幅がいちばん大きいのは 0.1→0.2 ns（全体 +0.124、タンパク質ごとの平均 +0.147）で、1 ns先・10 ns先で最大だった 0→0.1 ns（全体 +0.117）とほぼ同じ大きさであり、突出した跳ねではない。** 回復率 0.8 に届く最小の長さは全体で 0.7 ns（平均では 0.6 ns）、0.9 に届く最小の長さは全体で 0.9 ns（平均では 0.8 ns）。曲がりは 1 ns先より緩やかに上がり、覆う長さ 1.0 ns でも全体 0.906 と、平均だけの条件が全部入りを上回ることはなかった。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として強い土台の補正モデルに入れたときの 50 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。

読み方は L02 と同じで、先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K06(b)（強い土台）と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、50 ns先の陽性 12,819件）で評価する。静的特徴は5個、履歴の要約値は10個（最初、平均、標準偏差、最小、最大、最後−最初、最後−直前、3.5 Å以下割合、4.5 Å以下割合、増加割合）。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 50 ns先（ラベルの列の添字 4。予測幅の並びは [1, 5, 10, 30, 50, 90] ns）。条件ごとに学習し直す。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`、タンパク質ごとの `r{r}_series`、11点×候補数）をそのまま使う。静的特徴と履歴の要約値は K06(b) の保存値（`~/workspace/k06b/run/k06b_out/`）を使う。実行はローカルVM（学習13条件で約40秒、ブートストラップ 10,000回で約16分。sklearn はスレッド数1、OMP_NUM_THREADS=1 など。L06 と並行して回したため L05 のときより少し時間がかかった）。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う。

| 覆う長さ | フレーム | フレーム数 |
|---|---:|---:|
| 0 ns | 0 | 1 |
| 0.1 ns | 0, 1 | 2 |
| 0.2 ns | 0〜2 | 3 |
| 0.3 ns | 0〜3 | 4 |
| 0.4 ns | 0〜4 | 5 |
| 0.5 ns | 0〜5 | 6 |
| 0.6 ns | 0〜6 | 7 |
| 0.7 ns | 0〜7 | 8 |
| 0.8 ns | 0〜8 | 9 |
| 0.9 ns | 0〜9 | 10 |
| 1.0 ns | 0〜10 | 11 |

覆う長さ 0 ns はフレーム0だけ、つまり履歴の最初のフレームの距離そのもの（平均を取っても値は同じ）。起点フレーム10（1 ns）は変えず、ラベルは 50 ns先のまま。

G 系列の呼び方との対応は L02 と同じ。G145 の「1.0 ns」の切り取りはフレーム [0..9] で、L 系列の覆う長さ 1.0 ns（フレーム 0〜10、11フレーム全部の平均）とは違う。覆う長さ 1.0 ns は G81 の「全部の平均だけ（mean_only_full）」と同じ条件である。

| G 系列の名前 | フレーム | L01・L02・L07 の覆う長さ |
|---|---|---|
| G81 0.1 ns | 0, 1 | 0.1 ns |
| G81 0.5 ns | 0〜5 | 0.5 ns |
| G81 全部の平均だけ | 0〜10 | 1.0 ns |

### 条件の一覧（50 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（G05・L02 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（L02 と同じ、G147・G148・G162 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取りを numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC（学習済みモデルの予測から出した固定値）を、再標本化の重なり具合で重み付けして平均したもの。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

## 5. 読み取り

- **50 ns先でも、回復率は短い切り取りで大きく戻り、特定の長さの段はない。** フレーム0だけで利得の 0.41（全体）、0.2 ns で 0.65 が戻り、あとは +0.02〜+0.09 の増え分が 1.0 ns の 0.906 まで積み上がる。増え分は始めの 0.2 ns（0→0.1 ns と 0.1→0.2 ns）に集まるが、どちらか一方への集中ではない。
- 線に届く長さ（全体で 0.8 は 0.7 ns、0.9 は 0.9 ns）は 1 ns先とほぼ同じで、10 ns先（0.4 ns / 0.6 ns）よりは遅い。予測幅が長いほど短い切り取りで戻りやすい、という単調な関係ではない。
- 平均だけの条件の天井は 50 ns先で低く、覆う長さ 1.0 ns でも全体 0.906 にとどまる。1 ns先・10 ns先で見えた「平均だけで全部入りを上回る」形は 50 ns先にはない。履歴の要約値10個のうち平均以外のものが担う分が、50 ns先では相対的に大きいと読める。
- 費用の側はまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03 の担当（L01・L02 の曲がりについて実施済み）。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、50 ns先）では、回復率 0.8 に届く最小の覆う長さは全体で 0.7 ns（平均 0.6 ns）、0.9 に届く最小の覆う長さは全体で 0.9 ns（平均 0.8 ns）。増え幅がいちばん大きいのは 0.1→0.2 ns（全体 +0.124）で 0→0.1 ns とほぼ並び、段はない。平均だけの回復率は 1 を超えず、天井は覆う長さ 1.0 ns で全体 0.906。
- まだ分からないこと: 残る予測幅（30 ns は L06、90 ns は L08 の担当）で線に届く長さと増え幅最大の場所がどうなるか。統計量6種を使った場合に必要な長さが縮むか（L39・L40 の担当）。実測の費用に直したときの形。
