# G43: 塩橋の形成で、切り取りを 0.75 ns まで延ばすとどうなるか（K15 の条件、塩橋の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDの経路の続き。G27 では 0.5 ns の 6 統計量が 0.716 で、8 割の線に届かなかった。切り取りを 0.75 ns まで延ばし、平均だけと 6 統計量の両方を入れる。
- 状態: 完了。0.75 ns の 6 統計量の回復率は 0.511 で、8 割の線には届かなかった。ただし、同じ長さの平均だけは 0.901 と、0〜1 ns の平均だけ（0.889）を上回った。6 統計量は長さに対してまた上下し、0.25 ns の 0.334 に続いて 0.75 ns でも落ち込む。

## 1. 何を確かめる実験か

K15 の条件（塩橋の形成、1 ns先）で、切り取りを 0.75 ns（フレーム [0〜7]、実際に覆う長さは 0.7 ns）まで延ばし、平均だけと 6 統計量の両方を補正モデルに入れる。0.1 / 0.25 / 0.5 ns の条件もあわせて測り、G27 と合うかで手順の正しさを確かめる。参照は実履歴の利得で、+0.1440（K15 と一致）。回復率は実履歴の利得に対する比で測る。

6 統計量の定義は K15/K53 と同じ（閾値 4.0 Å）: [最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合] を切り取りのフレームで計算する。

判定は先に固定した。0.75 ns の 6 統計量が 0.8 以上になれば、切り取りを延ばせば塩橋の形成でも短い実MDの道が立つことになる。0.8 未満なら、0.75 ns まで延ばしても 8 割には届かないことになる。

## 2. 条件

- 土台は K15 の条件。ATLAS 解析版、学習58タンパク質（2,557件）・テスト30タンパク質（1,170件、1 ns先の陽性 93件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 塩橋の形成の候補（K15 と同じ）: 正側（LYS の NZ、ARG の NE/NH1/NH2）と負側（ASP の OD1/OD2、GLU の OE1/OE2）の荷電重原子ペアの最小距離が、起点で 4.0 Å より大きく（塩橋ができていない状態）で配列距離2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å 以下になること。静的特徴は5個、履歴の閾値は 4.0 Å。
- 切り取りの定義（G02/G03 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。0.1 ns → フレーム 0, 1（2フレーム）、0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さ 0.2 ns）、0.5 ns → フレーム 0〜5（6フレーム）、0.75 ns → フレーム 0〜7（8フレーム、覆う長さ 0.7 ns）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴だけ。
- 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
- 平均だけ（0〜1 ns）: 静的特徴＋0〜1 ns の平均だけ。
- 切った平均だけ: 静的特徴＋切った履歴の平均だけ（0.1 / 0.25 / 0.5 / 0.75 ns）。
- 切った6統計量: 静的特徴＋切った履歴の6統計量全部（0.1 / 0.25 / 0.5 / 0.75 ns）。

## 3. 結果

### 土台の再現

静的のみと全部入りが、K15 の記録と小数第4位まで完全一致した。1 ns先で静的のみ AUPRC 0.2402、全部入り 0.3842、利得 +0.1440。0.1 / 0.25 / 0.5 ns の条件も G27 と完全一致した（0.1 ns の平均だけは AUPRC 0.3333・回復率 0.647、0.25 ns の 6 統計量は AUPRC 0.2883・回復率 0.334、0.5 ns の 6 統計量は AUPRC 0.3434・回復率 0.716）。

## 4. 読み取り

- **0.75 ns の 6 統計量の回復率は 0.511 で、先に固定した 8 割の線には届かなかった。** 0.75 ns まで延ばしても 8 割には届かない。
- 平均だけと 6 統計量では、長さに対する形がまったく違う。平均だけは 0.647 → 0.616 → 0.659 → 0.901 と、0.5 ns までは横ばいだったのが 0.75 ns で大きく上がる。0.75 ns の平均だけは、0〜1 ns の平均だけ（0.889）をも上回る。切り取りの平均が 0〜1 ns の平均に近づく（残りのばらつき 0.393 Å）と、平均だけでほぼ全部の利得が戻る。
- 6 統計量は 0.685 → 0.334 → 0.716 → 0.511 と、長さに対して上下する。0.25 ns の落ち込みに続いて、0.75 ns でも落ち込む。同じ長さの平均だけとの差は、0.1 ns で +0.038、0.25 ns で −0.282、0.5 ns で +0.057、0.75 ns で −0.390 と、0.75 ns で最も大きい。統計量を足すと、0.25 ns と 0.75 ns では読み出しを乱す側に働く。
- 0.75 ns の平均だけが 0.901 と高い一方で、6 統計量が 0.511 と低い点は、塩橋の形成では平均以外の統計量が、切り取りが長くなっても利得の足しにならないことを示している。0〜1 ns の平均だけが 0.889 と、全部入り（1.000）に届かない分の利得は、平均以外の統計量ではなく、履歴の後半の情報そのものにある、という見立てが自然。確かめの計算はしていない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.75 ns の 6 統計量でも 8 割には届かない（0.511）。一方で、0.75 ns の平均だけは 0.901 と、0〜1 ns の平均だけ（0.889）を上回る。塩橋の形成では、切り取りを延ばす道は平均だけのほうにあり、6 統計量のほうにはない。
- まだ分からないこと: 6 統計量が 0.25 ns と 0.75 ns で落ち込み、0.1 ns と 0.5 ns で上がる上下の理由は、この実験では測っていない。テストは 1,170件、1 ns先の陽性は 93件と小さく、単一の学習 seed の結果でもある。0.75 ns の平均だけが 0.901 と 0〜1 ns の平均だけを上回ったのが、履歴の後半の情報によるものか、テストの揺れかも分けられていない。
