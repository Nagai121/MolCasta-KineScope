# L67: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、50 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L31（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）の 50 ns先です。
- 状態: 完了。ただし平均だけの L31 と同じく、土台の利得が +0.0274 と小さく、回復率の比率は読めませんでした。先に固定した読み方を機械的に当てた結果は併記しますが、結論には使いません。

## 1. 何を確かめる実験か

L63 と同じ段取りで、予測幅だけを 50 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、50 ns先の陽性 137件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

### 先に固定した読み方への答え（機械的な適用の結果）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.218）。平均だけも 0 ns で、縮みは 0 という機械的な結果になりますが、下記のとおり読みには使いません。
2. 増え幅がいちばん大きい場所: 0.1→0.2 ns（全体 +0.651）。タンパク質ごとの増え分は中央値 +0.347、正だったのは 15タンパク質のうち 67% でした。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 分母の利得（全体 +0.0274）が小さすぎるため、回復率の点推定（1.15〜2.36 など）も区間（上限が +5.4〜+17.3）も意味を持ちません。曲がりの読みはしません。L31 の平均だけと同じ結論です。
- AUPRC の水準で見ると、統計量6種の条件（全体 0.245〜0.294）は全部入り（0.2569）の周辺から上にかけて分布し、平均だけの条件（全体 0.226〜0.261）よりは高い位置にあります。ただし利得自体が小さい予測幅なので、この差を回復率の言葉では表せません。
