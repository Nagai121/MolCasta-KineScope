# K2-156: K2-15 の問い（漂い）を割合で測る（K15 の条件、塩橋の解離、1 ns先、割合だけ）

- 確かめる問い: 漂いは、前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）である。割合は、ペアの荷電重原子間の最小距離が塩橋の閾値（4.0 Å）以下の時間の割合である。平均の漂いの地図は 1 ns先で 6 通りすべて埋まっているが、割合の漂いはまだどの予測幅でも測っていない。塩橋の解離の 1 ns先では、平均の漂いは足しにならなかった（K2-39、−0.0169）。ここでは、同じ問いを割合の漂いの形で 1 ns先で測る。
- 状態: 完了。**全部の割合＋漂いは 0.5748 で、全部の割合だけ（0.5570）を +0.0179 上回り、「漂いは足しになる」になった。** 塩橋の解離では、平均の漂いの形でも割合の漂いの形でも、漂いが足しになるのは 1 ns先が初めてである。

## 1. 何を確かめる実験か

K15 の条件で、塩橋の解離、1 ns先、割合だけ。漂いは前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）である。静的な特徴量に、つぎのどれか 1 つを足した形で比べる。

- (a) 漂いだけ
- (b) 全部の割合だけ（フレーム [0..10] の 4.0 Å以下割合）
- (c) 全部の割合＋漂い

読み方は結果を見る前に固定した（K2-06・K2-15 と同じ）。

- (c) 全部の割合＋漂いが (b) 全部の割合だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、そうでなければ「足しにならない」と記録する。
- (a) 漂いだけの利得も、全部入りの利得に対する割合とあわせて記録する。

## 2. 条件

- 土台は K15 の条件（58 タンパク質×3 レプリカで学習、30 タンパク質×3 レプリカでテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、塩橋の解離、1 ns先、割合だけ。静的な特徴量は 5 個である。学習・テストのタンパク質の分け方は K15 の split.json に従う。
- 入力は K53 のキャッシュ（`~/workspace/kinescope/work/k53_cache/`、塩橋の解離の候補ごとの荷電重原子間の最小距離の系列）を再利用した。履歴は (n, 11) で保存されているため、転置はしない（K46 のキャッシュとは違う）。
- 実行はローカルVM（5 条件の学習で 1 分ほどで終わったため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 前半と後半の定義（K2-01 と同じ）

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3734、全部入り（6 個の統計量）0.5522、利得 +0.1788 で、塩橋の解離の 1 ns先の記録と小数第4位まで一致した。テスト 360件・陽性 101件も一致した。全部の割合だけは AUPRC 0.5570 で、K2-138 と小数第4位まで一致した。results.json と実行スクリプトの horizon_ns は 1 である。

| 条件 | AUPRC | 利得 | 割合（対 全部入りの利得） |
|---|---:|---:|---:|
| 静的のみ | 0.3734 | ― | ― |
| 全部入り（6 個の統計量） | 0.5522 | +0.1788 | 1.000 |

### 漂いの足し（(c) − (b) の AUPRC の差）

**+0.0179 で、「漂いは足しになる」になった。** 先に固定した +0.01 の線を上回った。全部の割合だけでも全部入り（0.5522）を上回る利得があるうえで、漂いを足すとさらに上がった。(c) は全部入りも上回った（0.5748 対 0.5522）。

### タンパク質ごと（テスト 30 タンパク質）

漂いの足しのタンパク質ごとの差（(c) − (b) の AUPRC）は、値が決まる 27 タンパク質のうち +0.01 以上が 7 タンパク質、0 未満が 8 タンパク質、中央値は 0.000 で、範囲は −0.2000〜+0.5000 である。値が決まらないタンパク質は 3 つ（1uha_A、1pch_A、2hng_A、陽性が 0 件のため）である。合算の +0.0179 は、タンパク質ごとでは方向が割れており、中央値 0.000 とは食い違っている。タンパク質あたりの候補数は 1〜30件と少なく、タンパク質ごとの AUPRC はばらつきが大きい点に注意が必要である。なお、results.json のタンパク質ごとの記録では、AUPRC が決まらない 3 タンパク質（1uha_A・1pch_A・2hng_A）の AUPRC・利得・割合と (c)−(b) の差を空欄（null）にした。どれも陽性が 0 件のためである。あわせて、全部入りの利得が 0 の 2 タンパク質（4ytw_C・6in7_A）の利得の割合（ratio_vs_full6_gain）も空欄（null）にした。初版では NaN が入っていて、ファイル単体では値があるように見えたため、2026-11-25 に直した。

## 4. 先に固定した読み方への答え

全部の割合＋漂いが全部の割合だけを AUPRC で +0.0179 上回ったため、**「漂いは足しになる」** である。

## 5. 平均の漂い（K2-39）との比較

| 漂いの形・予測幅 | (c) − (b) の AUPRC の差 | 読み方 |
|---|---|---|
| 平均の漂い、1 ns先（K2-39） | −0.0169 | 足しにならない |
| 割合の漂い、1 ns先（K2-156） | +0.0179 | 足しになる |

平均の漂いの形では足しにならなかった（K2-39、−0.0169）のに対し、割合の漂いの形では足しになった（+0.0179）。塩橋の解離の漂いの地図では、平均の形ではどの予測幅でも足しにならなかった（1 ns先 −0.0169、10 ns先 −0.0057、30 ns先 −0.0290、50 ns先 +0.0032、90 ns先 +0.0047）ため、割合の形での 1 ns先の「足しになる」は初めての形である。ただし合算の +0.0179 は +0.01 の線をわずかに上回っただけで、タンパク質ごとの中央値は 0.000 と食い違っているため、読みには留保がつく。
