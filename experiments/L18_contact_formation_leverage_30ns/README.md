# L18: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の形成、30 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L01（水素結合の形成、1 ns先）と同じ曲がりの測り方で、接触の形成の 30 ns先を測る。
- 状態: 完了。回復率 0.8 に届く最小の長さは覆う長さ 0.2 ns、0.9 に届く最小の長さは 0.4 ns（統合値）。増え幅がいちばん大きいのは 0.1→0.2 ns（+0.2611）で、全予測幅の中でいちばん大きい段。回復率は 0.5 ns で 1.0076 と 1 を超え、0.9 ns で最大 1.0785。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの条件のモデルに入れたときの 30 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、統合・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 247件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 30 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（13条件の学習で約10〜50秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（30 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.2 ns**（統合値 0.8390）。全予測幅の中でいちばん早い到達です。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.4 ns**（統合値 0.9792）。
3. **増え幅がいちばん大きい場所: 0.1→0.2 ns（+0.2611）**。L15〜L20 の中でいちばん大きい増え幅です。次に大きいのは 0.7→0.8 ns（+0.1569）です。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1277（静的のみ 0.3137、全部入り 0.4415）、2qt4_A が +0.1982（静的のみ 0.2591、全部入り 0.4573）で、2qt4_A の利得のほうが大きい。

段の位置（0.1→0.2 ns）でのタンパク質ごとの回復率は、1mix_A が 0.5871 → 0.9540（+0.3669）、2qt4_A が 0.5030 → 0.4497（−0.0533）で、符号が分かれます。統合値の段は主に 1mix_A 側の跳ねです。

## 4. 読み取り

- 接触の形成の 30 ns先は、全予測幅の中で曲がりの形がいちばん L01（水素結合の形成、1 ns先）に近く、短い長さで大きく戻ります。0.2 ns で 0.8 の線、0.4 ns で 0.9 の線を超え、0.5 ns 以降は 0.90〜1.08 の範囲で推移します。回復率が 1 を超えるのは、分母が全部入り（6 個の統計量）の利得 +0.1518 で、平均だけの条件がそれを上回るためです（K27 の only_mean の回復率は 0.9905）。
- ただし段（0.1→0.2 ns、+0.2611）はタンパク質ごとでは 1mix_A だけの形で、2qt4_A では同じ区間がわずかに負です。L01 の 0.6 ns の段が 1mix_A で大きく 2qt4_A で小さかったのと同じ注意が要ります。
- フレーム 0 だけでも回復率 0.4996 が戻ります。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
