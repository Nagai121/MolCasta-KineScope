# K2-147: 割合の漂いが全部の割合の上に足しになるか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめる問い: K2-15 の問い（漂い）を割合の形で測る。平均の漂いの地図は 1 ns先で 6 通りすべて埋まっているが、割合の漂いはまだどの予測幅でも測っていない。K2-06 では平均の漂いを測った（(a) 漂いだけの利得 +0.0272、割合 0.231、(c) 全部の平均＋漂いが (b) 全部の平均だけを −0.0031 下回り「漂いは足しにならない」）。ここでは同じ問いを割合の形で測る。
- 状態: 完了。先に固定した読み方に沿い、**漂いは足しにならない**。全部の割合＋漂い (c) の AUPRC 0.4702 は、全部の割合だけ (b) の 0.4829 を −0.0126 下回った（+0.01 の線に届かない）。漂いだけ (a) の利得は全部入りの利得の 0.327 で、平均の漂い（0.231）よりわずかに大きいが、単独では利得の 3 割ほどしか持たない。

## 1. 何を確かめる実験か

資料Dの条件（水素結合の形成、1 ns先）で、静的な特徴量に足す履歴の情報を「漂いだけ」「全部の割合だけ」「全部の割合＋漂い」の3通りに変え、全部の割合の上に漂いが足しになるかを測る。

背景は K2-61 の結果である。1 ns先では割合の前半だけの割合が 0.881、後半だけでは 0.560 で、前半と後半の両方を入れると 1.042 になり、全部の割合（1.012）も全部入りも上回った。平均の形でも同じく、前半と後半の両方を入れると全部の平均を上回った（K2-01、1.074 対 1.042）。平均の形では、この上積みが漂い（前半の平均 − 後半の平均）の情報によるものかを K2-06 で測り、「漂いは足しにならない」と出た（(c) − (b) = −0.0031）。ここでは割合の形でも同じ問いを測る。

読み方は結果を見る前に固定した。

- (c) 全部の割合＋漂いが (b) 全部の割合だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) 漂いだけの利得も記録し、全部入りの利得に対する割合もあわせて記録する。
- K2-61 の「前半と後半の両方」（割合 1.042）と (c) の結果の関係も記録する。(c) は (b) の上に漂いを足した形で、K2-61 の「前半と後半の両方」は前半と後半の割合を 2 つ入れた形。2 つの条件の AUPRC の差も記録する。

割合の分母は全部入りの利得（静的＋履歴 6 統計量の利得）を主とし、あわせて全部の割合の利得に対する割合も記録する（分母の確認のため）。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（テスト陽性 290件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は7個。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の18軌道分の距離系列）を再利用した。距離はフレームごとの箱を軸ごとに扱って計算済み。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（6条件の学習で約17秒）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 漂いの定義（結果を見る前に固定）

| 名前 | 定義 |
|---|---|
| 割合 | ペアの距離が 3.5 Å 以下だったフレームの数 ÷ その区間のフレーム数（前半・後半は 5、全部は 11）。境界は K71 と同じ 3.5 Å |
| 漂い | 前半の割合 − 後半の割合。前半はフレーム [0..4]（0〜0.4 ns）の 3.5 Å以下割合、後半はフレーム [6..10]（0.6〜1.0 ns）の 3.5 Å以下割合 |
| 符号 | **符号の意味は平均の漂い（K2-06：前半の平均 − 後半の平均）とは逆であることに注意する。** 平均の漂いが正なら「前半のほうが距離が大きい」（履歴のなかで距離が縮む方向に動いた）だが、割合の漂いが正なら「前半のほうが 3.5 Å 以下だった割合が大きい」（履歴のなかで距離が開く方向に動いた）である。割合は距離が小さいほど大きくなるため、符号の向きが平均の漂いと逆になる |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である。** K2-01 と同じ分け方で、前半と後半をきれいに分けるためである。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ（土台の照合用）。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。割合の分母（全部入りの利得）の参照。
- (a) 漂いだけ: 静的特徴＋漂い（前半の割合 − 後半の割合）。
- (b) 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の距離の 3.5 Å以下割合。
- (c) 全部の割合＋漂い: 静的特徴＋全部の割合＋漂い。
- 前半と後半の両方: 静的特徴＋前半の割合＋後半の割合（K2-61 との直接比較のための照合用）。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、K2-61 の記録と小数第4位まで完全一致した。全部の割合だけも AUPRC 0.4829（利得 +0.1192）で、K2-61 の記録と一致した。前半と後半の両方も AUPRC 0.4864（利得 +0.1227）で、K2-61 の記録と一致した。学習・テストの件数も土台の再現のときと同じ（学習 9,610件・テスト 4,972件）。

照らした記録は `experiments/K2-61_hb_formation_half_fraction_1ns/results.json` で、K71 の 1 ns先の記録（`experiments/K71_90ns_carrier/results.json` の conditions の static_only / full_hist6 / only_frac_le3.5 の `"1"`）とも同じ値である。

**割り当て文の数値の食い違い（統括の訂正で直された）**: 割り当て文の初版には「土台の再現は水素結合の形成の 1 ns先の記録（K2-14：静的のみ 0.3398、全部入り 0.5669、全部の割合 0.5578）と照らしてください」と書かれていたが、この数値は水素結合の形成のものではない。静的のみ 0.3398・全部入り 0.5669・全部の割合 0.5578 は接触の形成の 1 ns先の値（K2-123 の記録）である。K2-14 は水素結合の形成の 90 ns先の実験で、静的のみ 0.3035・全部入り 0.4246・全部の割合 0.4213 である。正しい水素結合の形成の 1 ns先の土台の値は K2-61 の記録（静的のみ 0.3637、全部入り 0.4815、全部の割合 0.4829）で、統括の訂正で K2-61 の値に直された。土台の再現は訂正後の K2-61 の値と照らした。

## 4. 先に固定した読み方への答え

- **漂いは足しにならない。**(c) の AUPRC 0.4702 は (b) の 0.4829 を −0.0126 下回り、+0.01 の線に届かなかった。AUC では (c) が 0.9294 と (b) の 0.9271 をわずかに上回ったが、読み方で固定した指標は AUPRC であり、判定は AUPRC で行う。Log Loss では (c) が 0.1336 と (b) の 0.1343 をわずかに下回ったが、同じく判定は AUPRC で行う。
- (a) 漂いだけの利得は +0.0385 で、全部入りの利得に対する割合は 0.327。漂いだけでもわずかな利得はあるが、全部の割合の利得（+0.1192）の 3 割ほどでしかない。平均の漂い（K2-06：利得 +0.0272、割合 0.231）よりわずかに大きい。
- K2-61 の「前半と後半の両方」（AUPRC 0.4864、割合 1.042）と (c)（AUPRC 0.4702、割合 0.904）の差は −0.0162 で、(c) のほうが低い。前半と後半の両方を入れたときの上積みは、漂いを 1 つの量として足した形では再現できなかった。

## 5. 読み取り

- **K2-61 の「前半と後半の両方」の上積みは、割合の漂いの情報では説明できない。** 全部の割合の上に漂いを足しても AUPRC は上がらず、むしろ −0.0126 下がった。漂いだけでも利得は +0.0385 と小さい。履歴の「動き」そのものは、割合の形でも指導力の担い手ではない。
- 平均の形（K2-06）でも割合の形でも、漂いは足しにならない。ただし (c) − (b) の差は、平均の形では −0.0031 だったのに対し、割合の形では −0.0126 と大きく負に出た。割合の漂いを足すと、平均の漂いを足すときより AUPRC が下がる。割合の漂いは、前半と後半の割合の差という 1 つの量に、2 つの時間帯の割合の水準の情報が打ち消し合う形で入るため、全部の割合の上に足すとノイズとして働くと考えられる。
- 前半と後半の両方を入れたときの上積み（全部の割合に対して +0.0035、全部入りに対して +0.0049 の AUPRC）は、漂いではなく、前半と後半の割合を別々の量として入れたことで、モデルが 2 つの時間帯の 3.5 Å以下割合の水準を別々に使えたことによると考えられる。つまり効いているのは「動き」ではなく、2 つの時間帯それぞれの「水準」である。K2-06 の読み取り（平均の形でも同じ）と同じ形である。
- ただし (c) と (b) の差は −0.0126、(c) と「前半と後半の両方」の差は −0.0162 と、どちらも小さい。テストが2タンパク質だけ（陽性 290件）のため、この差が一般の形かは、この実験だけでは決められない。タンパク質ごとでは (c) − (b) の符号が分かれる（1mix_A −0.0101、2qt4_A +0.0056）点も留保として記録する。
- 漂いだけの利得が 0.327 と、平均の漂いの 0.231 より大きいのは、割合の漂いが「前半に 3.5 Å 以下だった時間の割合が後半よりどれだけ多いか」という、水素結合の形成に直接つながる量の変化を表すためと考えられる。ただしそれでも利得の 3 割ほどでしかなく、全部の割合（1.012）の担い手にはならない。

## 6. 判断できること・まだ分からないこと

- 判断できること: 資料Dの条件・水素結合の形成・1 ns先では、履歴の割合の漂い（前半の割合 − 後半の割合）は、全部の割合の上に足しにならない（AUPRC の差 −0.0126）。漂いだけの利得も全部入りの利得の 0.327 と小さい。K2-61 の「前半と後半の両方」の上積みは、漂いを 1 つの量として足した形では再現できなかった。
- まだ分からないこと: 漂いの符号（前半の割合が大きいか後半の割合が大きいか）で分けたときの形（今回は符号を分けて測っていない）。長い予測幅での形（K2-05・K2-21 で前半のほうが大きい形が強まったが、割合の漂いがそこでも足しにならないかは測っていない）。ほかの現象（接触の形成など）でも割合の漂いが足しにならないかは測っていない。
