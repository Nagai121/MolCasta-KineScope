# K55: 平均の指導力は、起点の距離の幅によって違うか（資料Dの条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。境界に近い幅Aでは平均だけで利得の 0.86〜1.57 が戻りましたが、境界から離れた幅Bでは利得そのものが小さく、戻り方は 0.28〜3.24 と大きく振れました。担い手は幅によって違う、という読みになります（幅Bでは平均だけで8割が安定して戻るとは言えません）。

## 1. 何を確かめる実験か

これまで平均が担い手だと分かりましたが、指導力が起点の距離の幅によって違うかは測っていません。候補を起点の距離で分けて確かめます。

読み方は先に固定しました。どちらの幅でも平均だけで利得の8割以上が戻れば、担い手は幅によらず同じです。幅によって戻り方がはっきり違えば、担い手は幅によって違います。「8割以上」は全幅または多くの幅での読みとし、1 ns先を主判断とします。

## 2. 幅の分け方と条件（結果を見る前に固定）

- 土台は資料Dの条件です。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算されています（抽出済みキャッシュ `~/workspace/kinescope/work/data_cache/` を使用）。
- 形成の候補は、起点でドナー・アクセプター重原子距離が 3.5 Å 超〜6.0 Å 以下です（`experiments/base_reproduction/extract.py` の77行目。資料Dのコードのこの再現では上限が 6.0 Å になっています）。起点距離の分布は、学習側で四分位数が 4.43 / 5.05 / 5.59 Å でした。
- 幅の分け方は起点フレーム10の距離（静的特徴の起点距離）によります。境界の値は下側を含まず上側を含む形です。
  - 幅A: 3.5 < d <= 4.5 Å（境界に近い候補）
  - 幅B: 4.5 < d <= 6.0 Å（境界から離れた候補）
- 幅A・幅Bで全候補を覆います。6.0 Å超の候補は、抽出の時点で候補に入っていないため 0件です（対象外として別に数えるものはありません）。
- 各幅について、学習とテストの両方をその幅の候補だけに絞って学習し直し、評価しました。全体で学習して幅ごとに評価したのではありません。
- 条件は各幅で3つです（分け方は K21/K27 と同じ）。
  - 静的のみ: 静的7特徴だけ
  - 全部入り: 静的＋実履歴6統計量（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合）
  - 平均だけ: 静的＋履歴6統計量のうち平均1つだけ（他の統計量は入れない）
- 対照の確認: 幅を分けずに全部（ALL）で測った静的のみと全部入りは、全予測幅で土台の記録と完全に一致しました（1 ns先で静的のみ 0.3637、全部入り 0.4815、利得 +0.1178）。平均だけの条件も ALL では 1 ns先 0.4865 で、全部入りをわずかに上回りました。

## 5. 読み取り

- **幅Aでは、平均だけで利得の 0.86〜1.57 が戻りました。** 先に固定した目安の8割を全予測幅で超えています。境界に近い候補では、担い手は平均です。利得そのものも +0.064〜+0.182 と大きく、全体の利得（+0.063〜+0.121）の大半は幅Aの候補から来ています。
- **幅Bでは、利得そのものが小さく、戻り方は安定しません。** 利得は +0.007〜+0.051 で、戻り方は 0.28〜3.24 と大きく振れます。8割を超えたのは 6幅中3幅（1 ns先 1.822、10 ns先 1.003、50 ns先 3.241）だけです。ただし戻り方が1を大きく超える幅（50 ns先 3.241 など）は、利得そのものが +0.0148 と小さいために平均だけの方が全部入りを上回っただけで、比率の意味は薄いです。90 ns先では戻り方は 0.281 と小さく、平均だけでは利得の3割も戻りません。
- 幅Bの戻り方の振れは、陽性が少ないこと（1 ns先で28件）と利得が小さいことの両方が原因です。幅Bで「平均が担い手ではない」と断定するだけの材料も、「平均が担い手だ」と言うだけの材料もありません。言えるのは、幅Bでは実履歴の指導力そのものが小さく、平均だけの戻り方を安定して測れない、ということです。
- 幅Aと幅Bで指導力の大きさがはっきり違う点も、結果の一部です。利得は幅Aで +0.064〜+0.182、幅Bで +0.007〜+0.051 で、境界に近い候補の方が実履歴の利得が大きいです。全体の利得は、主に幅Aの候補が担っています。

## 6. 判断できること・まだ分からないこと

- 判断できること: 境界に近い幅Aでは、担い手は平均です（全予測幅で8割以上）。境界から離れた幅Bでは、利得そのものが小さく、平均だけの戻り方は安定しません。事前に固定した読み方に沿うと、担い手は幅によって違う、という読みになります。少なくとも「どちらの幅でも平均だけで8割以上が戻る」にはなりませんでした。
- まだ分からないこと: 幅Bで平均が担い手かどうかは、この規模（陽性 28〜72件）では決められません。幅Bの候補を増やす（タンパク質を広げる）か、幅Bの中でさらに細かく分けるかしないと、戻り方の振れが陽性の少なさによるものか、担い手の違いによるものかは分かりません。また、なぜ境界に近い候補の方が利得が大きいのか（平均距離が境界に近いほど未来の成否を決める情報が多いのか）も、この実験だけでは分かりません。
