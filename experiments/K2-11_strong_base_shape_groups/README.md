# K2-11: K2-07 のタンパク質ごとの形の違いは、何で決まっているか

- 確かめること: K2-07 では、強い土台の 100 タンパク質のうち、「今の状態」の形が 11、「続いている状態」が 18、どちらでもないが 63、利得が小さく判定から外したものが 8 だった。何がこの分かれ方を決めているのかを見る。
- 状態: 完了。4 つの量のうち、(d) テストの候補数だけが先に固定した線を超えた。「続いている状態」の中央値 1,314 件と「どちらでもない」の中央値 1,778 件の差は 464.5 件で、プールした標準偏差 408.7 件の 1.14 倍だった。ほかの 3 つの量では、グループの中央値の差はプールした標準偏差の 0.58 倍までで、線に届かなかった。先に固定した読み方に照らして、(d) テストの候補数で分かれると記録する。ただし (d) はタンパク質の性質ではなく候補数の多寡で、少ない候補数ではタンパク質ごとの AUPRC がぶれやすく、割合が極端な形に出やすい。物理的な量の (a)・(b)・(c) では分かれなかった。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-07 では、強い土台（テスト 100 タンパク質）で履歴の前半と後半の平均だけの利得を測ったところ、合算ではどちらの読み方にも当てはまらなかったが、タンパク質ごとでは形が分かれた。「今の状態」の形が 11 タンパク質、「続いている状態」が 18 タンパク質、どちらでもないが 63 タンパク質、利得が 0.01 以下で判定から外したものが 8 タンパク質だった。ここでは、何がこの分かれ方を決めているのかを、タンパク質ごとの量で比べる。

新しい学習は要らない。`experiments/K2-07_hb_formation_half_means_strong_base/results.json` のタンパク質ごとの記録を使って、次の量を 3 つのグループ（今の状態／続いている状態／どちらでもない）ごとに比べた。

- (a) ペアの距離の履歴内でのばらつきの大きさ（11 フレームでの標準偏差を、タンパク質の候補で平均したもの）
- (b) 平均の残り（静的に予測できない部分）の大きさ（タンパク質の候補での残りの標準偏差）
- (c) 全部入りの利得の大きさ（タンパク質ごとの全部入りの AUPRC から静的のみの AUPRC を引いたもの）
- (d) テストの候補数

読み方は先に固定した。グループごとの中央値を比べ、どれかの量でグループの中央値がプールした標準偏差の 1 倍以上離れていれば「その量で分かれる」と記録し、なければ「この 4 つの量では分かれない」と記録する。

## 2. 条件

- 強い土台（K06(b) の条件）。水素結合の形成、1 ns先。テスト 100 タンパク質 × 3 レプリカ（163,074件）。
- グループの作り方（K2-07 の読み方と同じ。分母はそのタンパク質の全部入りの利得）:「今の状態」は後半の割合 0.8 以上かつ前半の割合 0.5 以下、「続いている状態」は前半も後半も 0.8 以上、それ以外が「どちらでもない」。全部入りの利得が 0.01 以下の 8 タンパク質は判定から外す。グループは K2-07 の `per_protein_fractions` から作り直し、数が 11 / 18 / 63 / 8 になることを確かめた（K2-07 の `per_protein_shapes` の記録と一致）。
- (a) と (d) は G05 の系列（`~/workspace/kinescope/work/g05_series/`、11 フレームの距離の系列）から出した。(a) はペアごとの 11 フレームでの標準偏差（母標準偏差）をタンパク質の候補で平均したもの、(d) は系列の候補数を 3 レプリカで合計したもの。
- (b) は K39 の形で作った。残り = 実の平均 − 静的な予測。静的な予測は K39 と同じ GBM（160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）を、K39 と同じ較正タンパク質（8 つ、13,808件）の静的特徴 5 個で当てはめたもの。新しいモデルではなく、K39 の当てはめの再現である。合算での R² が 0.6352、残りの標準偏差が 0.6002 Å と、K39 の記録（R² 0.6352、残り 0.6002 Å）と小数第 4 位まで一致することを確かめてから使った。タンパク質ごとの (b) は、そのタンパク質の候補での残りの標準偏差（母標準偏差）。
- (c) は K2-07 のタンパク質ごとの AUPRC で、全部入り − 静的のみ。
- プールした標準偏差は、比べる 92 タンパク質（判定外の 8 を除く）での標準偏差（ddof=1）。グループの中央値の差を、この標準偏差で割った倍率で比べた。
- 計算はこの仮想マシンで行った（GBM の当てはめ 1 件と集計だけで、軽い計算である）。

## 4. 読み取り

先に固定した読み方に照らすと、4 つの量のうち (d) テストの候補数だけが線を超えた。「続いている状態」の中央値 1,314 件と「どちらでもない」の中央値 1,778 件の差は 464.5 件で、プールした標準偏差 408.7 件の 1.14 倍だった。**テストの候補数で分かれる**と記録する。ほかの 3 つの量では、グループの中央値の差はプールした標準偏差の 0.58 倍までで、線に届かなかった。

ただし (d) の分かれ方は、タンパク質の性質そのものではない。候補数が少ないタンパク質では、タンパク質ごとの AUPRC の推定がぶれやすく、前半・後半の割合（そのタンパク質の全部入りの利得に対する割合）もぶれやすい。割合がぶれると、「前半も後半も 8 割以上」という極端な形に出やすくなる。実際、「続いている状態」のタンパク質は候補数が少ないほうに寄っており、全部入りの利得も「どちらでもない」より小さい（中央値 0.0592 対 0.0830）。候補数の少なさと利得の小ささが重なって、割合のぶれを大きくしていると読める。「今の状態」のほうは候補数の中央値が 1,672 件と「どちらでもない」の 1,778 件と近く、候補数では分かれなかった（倍率 0.26）。

物理的な量の (a)・(b)・(c) では、グループの中央値はほとんど離れなかった。履歴内での距離のばらつき、平均の残りの大きさ、全部入りの利得の大きさは、この 3 つの形の違いを説明しない。

## 5. 判断できること・まだ分からないこと

- 判断できること: この 4 つの量では、(d) テストの候補数だけが先に固定した線を超えた。物理的な量の (a)・(b)・(c) では分かれなかった。「続いている状態」の形は、候補数が少なく利得が小さいタンパク質に寄っている。
- まだ分からないこと: (d) の分かれ方が候補数の少なさによる割合のぶれなのか、それとも候補数の少ないタンパク質に本当に「続いている状態」が多いのか。この実験だけでは区別できない。候補数を揃えたうえでの再分類（たとえば候補数をそろえて割合を測り直す）や、割合のぶれの大きさの見積もりが必要である。形の違いを決める物理的な量がほかにあるかどうかも、まだ分からない。
