# K86: 塩橋の解離で、読み出しは予測時刻のあいだで移るか（K53 の条件）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。水素結合の解離では、読み出しは予測時刻のあいだで移りました（K75：1 ns先→90 ns先の戻り率 1.04、90 ns先→1 ns先 0.93）。塩橋の解離でも同じか確かめます。

## データと条件

- K53 の条件です。K15 の広げた集合（ATLAS 解析版、学習58タンパク質・テスト30タンパク質、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直し）で、塩橋の解離の候補（起点フレーム10の最小距離が 4.0 Å 以下、配列距離2以上、ラベルは予測先のフレームで最小距離が 4.0 Å を超えること）を使います。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 入力データは K53 のキャッシュ（`~/workspace/kinescope/work/k53_cache/`、88タンパク質×3レプリカ、264ファイル）をそのまま使います。静的5特徴と履歴の11点系列があり、履歴6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å以下だった割合）は K53 と同じ式で作ります。
- 候補数：学習 735件、テスト 360件。テストの陽性数：1 ns先 101件（28.1%）、90 ns先 160件（44.4%）。
- 条件は2つです。静的のみ（静的5特徴だけ）と全部入り（静的＋実履歴6統計量）で、予測幅ごとに学習し直します。特徴量は予測幅によらないため、ある予測幅で学習したモデルをすべての予測幅のラベルで評価し、6×6 の表を作ります。
- 利得は、同じ学習予測幅で学習した静的な特徴だけの条件との AUPRC の差で、テスト30タンパク質をまとめた値（全体）と、タンパク質ごとの平均（タンパク質ごとに 3レプリカをまとめて AUPRC を取り、両方のクラスがあるタンパク質だけで平均）の両方を見ます。戻り率は、別の予測幅で学習した利得を、同じ予測幅で学習した利得で割った値です。

## 読み方（先に固定）

- 両方向の回復率（1 ns先で学習→90 ns先で評価、90 ns先で学習→1 ns先で評価）が 0.8 以上なら、塩橋の解離でも読み出しは予測時刻のあいだで移ります。
- 片方だけ弱ければ、その理由を確かめます。
- テストの候補数が 360件と少なく、タンパク質ごとの候補数も 1〜27件と少ないため、タンパク質ごとの平均はばらつきが大きくなります。ばらつきが大きい場合はそのまま記録します。

## 対照の確認

同じ予測幅で学習して評価した利得が、K53 の記録値（1 ns先 +0.1788、90 ns先 +0.0582）と一致することを確認します。

## ファイル

- `k86_run.py`：予測幅をまたいだ学習・評価（6×6 の表）、利得と戻り率の計算
- `k86_results.json` / `k86_results.csv`：全条件の指標と、利得・戻り率のまとめ
