# K86: 塩橋の解離で、読み出しは予測時刻のあいだで移るか（K53 の条件）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。水素結合の解離では、読み出しは予測時刻のあいだで移りました（K75：1 ns先→90 ns先の戻り率 1.04、90 ns先→1 ns先 0.93）。塩橋の解離でも同じか確かめます。

## データと条件

- K53 の条件です。K15 の広げた集合（ATLAS 解析版、学習58タンパク質・テスト30タンパク質、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直し）で、塩橋の解離の候補（起点フレーム10の最小距離が 4.0 Å 以下、配列距離2以上、ラベルは予測先のフレームで最小距離が 4.0 Å を超えること）を使います。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 入力データは K53 のキャッシュ（`~/workspace/kinescope/work/k53_cache/`、88タンパク質×3レプリカ、264ファイル）をそのまま使います。静的5特徴と履歴の11点系列があり、履歴6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å以下だった割合）は K53 と同じ式で作ります。
- 候補数：学習 735件、テスト 360件。テストの陽性数：1 ns先 101件（28.1%）、90 ns先 160件（44.4%）。
- 条件は2つです。静的のみ（静的5特徴だけ）と全部入り（静的＋実履歴6統計量）で、予測幅ごとに学習し直します。特徴量は予測幅によらないため、ある予測幅で学習したモデルをすべての予測幅のラベルで評価し、6×6 の表を作ります。
- 利得は、評価する予測幅で学習した静的な特徴だけの条件との AUPRC の差です（K56 と同じ測り方。静的な参照は、学習した予測幅ではなく評価する予測幅で学習したものを使います）。テスト30タンパク質をまとめた値（全体）と、タンパク質ごとの平均（タンパク質ごとに 3レプリカをまとめて AUPRC を取り、両方のクラスがあるタンパク質だけで平均）の両方を見ます。戻り率は、別の予測幅で学習した利得を、同じ予測幅で学習した利得で割った値です。

## 読み方（先に固定）

- 両方向の回復率（1 ns先で学習→90 ns先で評価、90 ns先で学習→1 ns先で評価）が 0.8 以上なら、塩橋の解離でも読み出しは予測時刻のあいだで移ります。
- 片方だけ弱ければ、その理由を確かめます。
- テストの候補数が 360件と少なく、タンパク質ごとの候補数も 1〜27件と少ないため、タンパク質ごとの平均はばらつきが大きくなります。ばらつきが大きい場合はそのまま記録します。

## 対照の確認

同じ予測幅で学習して評価した利得が、K53 の記録値（1 ns先 +0.1788、90 ns先 +0.0582）と一致することを確認しました。実際の値は 1 ns先 +0.1788、90 ns先 +0.0582 で、差は 1e-5 程度（丸めの範囲）でした。全予測幅の利得も K53 と一致しました（5 ns先 +0.1139、10 ns先 +0.1781、30 ns先 +0.0633、50 ns先 +0.1302）。

## 測り方の訂正（記録）

最初の実行では、利得の静的な参照に「学習した予測幅で学習した静的な補正」を使っていました（K75 と同じ測り方）。統括からの確認で、K56 と同じ測り方（静的な参照は評価する予測幅で学習したもの）に直して実行し直しました。この記録の数値はすべて訂正後のものです。

## 結果

### 主判断：1 ns先⇔90 ns先の移し替え（全体をまとめた値）

|---|---|---:|---:|
| 1 ns先で学習 → 90 ns先で評価 | +0.0520 | +0.0582 | **0.894** |
| 90 ns先で学習 → 1 ns先で評価 | +0.0601 | +0.1788 | **0.336** |

タンパク質ごとの平均では、1 ns先→90 ns先の戻り率は −0.037（移し替えた利得 −0.0013、同じ予測幅の利得 +0.0343）、90 ns先→1 ns先は 0.668（移し替えた利得 +0.0766、同じ予測幅の利得 +0.1148）でした。

### 絶対値で見た移し替え（全体をまとめた値、AUPRC）

| モデル | 1 ns先で評価 | 90 ns先で評価 |

| 静的のみ（1 ns先で学習） | 0.3734 | 0.4961 |

## 結論

**先に固定した読み方に沿うと、塩橋の解離の読み出しは両方向には移りません。片方だけ弱い非対称な結果でした。** 1 ns先→90 ns先は戻り率 0.894 で 8割の線を超えましたが、90 ns先→1 ns先は 0.336 でした。

ただし、1 ns先→90 ns先の戻り率 0.894 は、分母の 90 ns先の利得（+0.0582）が小さいため比率として不安定です（ブートストラップの 95%区間は −1.87〜3.23）。絶対値で見ると、1 ns先で学習した読み出しは 90 ns先で 0.5343 と、90 ns先で学習したものとほぼ同じ水準です。逆に 90 ns先→1 ns先の戻り率 0.336 は、ブートストラップで 0.8 以上になる割合が 2.8% しかなく、8割を下回ることはほぼ確かです（95%区間 −0.26〜0.82）。

## 90 ns先→1 ns先が弱い理由（確かめたこと）

### （1）ラベルが別々の出来事で、入れ子になっていない

解離は揺れ戻ります。テスト 360件で、1 ns先で解離していた 101件のうち 90 ns先でも解離していたのは 63.4%（37件は 90 ns先では結び直していた）で、90 ns先で解離していた 160件のうち 1 ns先でも解離していたのは 40.0%（96件は遅れて解離したもの）でした。学習側も同じ形です（62%／37%）。「90 ns先のラベル」は「1 ns先のラベル」を含むのではなく、重なりは 4 割程度の別々の出来事です。

### （2）非対称さは平均の読み出しにはない。平均以外の統計量にある

平均だけの条件では、両方向とも 0.62〜0.73 と中程度に戻りました（全体：1 ns先→90 ns先 0.621、90 ns先→1 ns先 0.729）。一方、全部入りでは 90 ns先で学習したものが 1 ns先で 0.4335 と、平均だけで学習したもの（0.4935）より大きく悪くなります。90 ns先で学習したとき、平均以外の統計量（標準偏差・最小値・最後−最初・4.0 Å以下割合）の使い方が 1 ns先では邪魔をしています。逆に 1 ns先で学習したときは、平均以外の統計量が 90 ns先で少し助けになります（0.5343 対 平均だけの 0.5201）。

### （3）静的な読み出しにも同じ非対称さがある

90 ns先で学習した静的な補正は 1 ns先で 0.3160 と、1 ns先で学習したもの（0.3734）より大きく悪くなります。逆に 1 ns先で学習した静的な補正は、90 ns先で 0.4961 と、90 ns先で学習したもの（0.4824）よりむしろ良くなります。予測の相関も低く、静的な補正の 1 ns先版と 90 ns先版の相関は 0.31、全部入りの 2 版の相関は 0.56 でした。90 ns先のラベルは、90 ns先までの熱的な揺れで起点の情報が薄まるため、順位づけの教師信号として弱く、そこで学習したモデルはノイズの多い順位を覚えます。

## 不確かさの注意点

- テストが 360件と少ないため、90 ns先まわりの利得は小さく、ブートストラップ（テスト候補の復元抽出、2000回）の 95%区間は 0 を含みます。移し替えた利得は 1 ns先→90 ns先 +0.0520（区間 −0.023〜+0.126）、90 ns先→1 ns先 +0.0601（区間 −0.029〜+0.159）で、どちらも正である確率は約 9 割です。同じ予測幅の利得も、90 ns先は +0.0582（区間 −0.011〜+0.134）と 0 を含み、1 ns先は +0.1788（区間 +0.093〜+0.262）と確かです。
- タンパク質ごとの平均は、候補数がタンパク質あたり 1〜27件と少ないため振れが大きく、比率としては使えません。特に 1 ns先→90 ns先のタンパク質平均の移し替えた利得は −0.0013 とほぼ 0 で、全体の +0.0520 は候補数の多いタンパク質に集中しています。タンパク質ごとの平均の値はそのまま記録してあります。
- 水素結合の解離（K75、強い土台）では両方向とも 1.04／0.93 ときれいに移りました。塩橋の解離との違いが、土台の強さによるものか、現象によるものか、テストの件数（76,342件 対 360件）によるものかは、この実験だけでは切り分けられません。
