# GA309 静的力応答と生成MDの組み合わせ

GA304 all-8の静的残差とGA305 residual-ridgeの生成MD残差を、共通静的基準に対して加法で組み合わせた。係数81点を選定3配列で比較し、0.525を固定した。選定相関0.547043。GA301から使っている確認8配列9,843組で、同じ候補においてGA305の0.550534から0.580911、誤差SDは0.446856 Åから0.435609 Å。確認パネルは今回の係数選定に使っていないが、過去から継続使用しており独立した新規確認ではない。目標0.700は未達。推論用入力は静的起点のみで、生成MDは100 ps×2。観測履歴は教師および評価だけに使用した。

GA304 all-8.ubjとGA305のbaselines.npz・residual-ridge.npzを各実験の元ディレクトリに置き、GA305と同じMiniTopolワークスペースでpython -m t2i.ga309を実行する。
