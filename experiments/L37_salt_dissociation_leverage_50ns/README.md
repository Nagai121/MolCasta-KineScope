# L37: L01 の曲がりを塩橋の解離で測る（K15 の土台、50 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 50 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は 0 ns の 0.388 から緩やかに上がり、0.5 ns で 0.893、その後は 0.72〜0.89 でほぼ平らでした。0.9 の線には統合値ではどの長さでも届きませんでした（最大 0.893）。タンパク質ごとの平均は分母の利得が小さく（+0.0305）、読みの対象にできません。

## 1. 何を確かめる実験か

L33 と同じ段取りで、予測幅だけを 50 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、50 ns先の陽性 166件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.4863、全部入り 0.6165、利得 全体 +0.1302／平均 +0.0305 で、K2-82 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G69 の平均だけの走査と一致しました（覆う長さに直して 0.1 ns で 0.578、0.2 ns で 0.553、0.5 ns で 0.893）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.5 ns（全体 0.893）**。0.4 ns では 0.796 と線のすぐ下でした。
2. **回復率 0.9 に届く最小の長さ: 統合値ではどの長さでも届きませんでした**（最大は 0.5 ns の 0.893）。平均では 0.7 ns で 0.941 ですが、平均の数値は上記のとおり安定していません。
3. **増え幅がいちばん大きい場所: 全体では 0.3→0.4 ns（+0.330）**。段の位置でのタンパク質ごとの増え分は中央値 +0.146、正だったのは 15タンパク質のうち 53% で、段と呼べるほどの揃い方ではありません。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 50 ns先は、解離の 6つの予測幅の中で回復率がいちばん低く出た予測幅です。短い切り取りでは利得の半分ほどしか戻らず、0.5 ns あたりで 0.89 まで上がって頭打ちになります。
- 区間は全体で幅 0.65〜1.3 と広く、0.4〜1.0 ns の間の順序は決められません。「0.5 ns まででほぼ頭打ち」という大まかな形が言える範囲です。
