# G61: 解離で、5 ns 先と 10 ns 先の混合は足しになるか（資料Dの条件、水素結合の解離、5 ns先・10 ns先）

- 確かめること: 解離の混合は、1 ns先 −0.052、30 ns先 +0.086、50 ns先 +0.015、90 ns先 −0.206 と測ってきた。5 ns先と 10 ns先が残っている。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は水素結合の解離、5 ns先と 10 ns先。0.1 ns（フレーム [0,1]）の切り取り平均だけと、作り直した第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。候補は解離の 6,131件すべて。土台の利得は 5 ns先 +0.1757、10 ns先 +0.1478（K46 と同じ）。

読み方はこれまでと同じで先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、その予測幅では解離でも混合が足しになることになる。+0.05 未満なら、その予測幅では混合は足しにならないことになる。
