# K62: 2qt4_A を除くと、遠い幅の戻り方は安定するか（K55・K57・K60 の続き）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。2qt4_A を除いても、遠い幅（4.5〜6.0 Å）の平均だけの回復率はばらついたまま（1 ns先 0.972、5 ns先 −0.501、10 ns先 0.647、30 ns先 0.445、50 ns先 1.182、90 ns先 −0.230）で、全予測幅で8割以上にはなりませんでした。ばらつきは 2qt4_A 1つのせいではなく、遠い幅では平均の担い手がそもそも安定しません。

## 1. 何を確かめる実験か

K60 で、遠い幅での平均の戻り方のばらつきを引っ張るタンパク質は 2qt4_A でした。2qt4_A を除くと戻り方が安定するか確かめます。

読み方は先に固定しました。2qt4_A を除いて回復率が全予測幅で8割以上になれば、ばらつきは 2qt4_A 1つのせいです。ばらついたままなら、遠い幅では平均の担い手がそもそも安定しません。ここで「ばらついたまま」とは、回復率が 0.8 を下回る幅がある、または 1 を大きく超える（1.5 以上など）幅がある、という読みとします（この定義は、2qt4_A を除いた値を計算する前に固定しました。1mix_A だけの回復率は K60 の値そのものになるはずで、照合で確認しました）。

## 2. 方法（2qt4_A を除いた条件の定義）

- K55 のデータで、評価対象を 1mix_A だけに絞りました。学習側は変えていません。学習は K55 の幅ごとの学習集合（学習4タンパク質をその幅だけに絞ったもの）のままで、変えるのは評価対象だけです。
- K55 は集計済みの指標だけを保存しており、タンパク質ごとの予測確率は残っていなかったため、K57 と同じやり方で再計算しました（`run_k62.py`）。キャッシュ、モデル（HistGradientBoosting、反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）、幅の分け方（A: 3.5 < d ≤ 4.5 Å、B: 4.5 < d ≤ 6.0 Å、学習とテストの両方をその幅だけに絞って学習し直す）、条件（静的のみ、静的＋実履歴6統計量、静的＋平均だけ）は K55・K57 とまったく同じです。
- 対照の確認: 再計算の全体まとめ（1mix_A＋2qt4_A）の値は、K55 の `results.json` と全幅・全条件で小数第4位まで完全に一致しました（最大の絶対差 0.0）。1mix_A だけの回復率も、K57 のタンパク質ごとの値と全幅・全条件で完全に一致しました（最大の絶対差 0.0）。再計算は正しく、以下の 1mix_A だけの値は K55 のモデルそのものの内訳です。
- 2qt4_A を除いた後はテストが 1mix_A だけになるため、「全体まとめ」と「タンパク質ごとの平均」は同じ値になります（1タンパク質しかないため）。この実験の「回復率」は、1mix_A だけの回復率そのものです。
- 参考として、幅Aでも 2qt4_A を除いた条件（1mix_A だけ）を同じやり方で測り、幅Bの結果と並べました。

## 3. 候補数と陽性数（1mix_A だけ）

| 幅 | テスト候補数 | テスト陽性数（1/5/10/30/50/90 ns） |
|---|---:|---|
| A: 3.5〜4.5 Å | 863 | 182 / 184 / 193 / 200 / 186 / 187 |
| B: 4.5〜6.0 Å | 2,238 | 22 / 35 / 52 / 51 / 47 / 55 |

幅Bの 1mix_A だけの陽性は 1 ns先で22件しかなく、AUPRC と回復率は振れやすくなります。テストが1タンパク質だけのため、値は参考値です。

## 4. 結果

回復率は「平均だけの利得÷全部入りの利得」です。利得は全部入りの AUPRC − 静的のみの AUPRC です。

### 4.1 遠い幅（B: 4.5〜6.0 Å）: 2qt4_A を除いた後（1mix_A だけ）と K55 の全体まとめとの比較

| 予測幅 | 利得（1mix_A だけ） | 回復率（1mix_A だけ） | 回復率（K55 の全体まとめ） |
|---:|---:|---:|---:|
| 1 ns | +0.0318 | 0.972 | 1.822 |
| 5 ns | −0.0086 | −0.501 | 0.649 |
| 10 ns | +0.0661 | 0.647 | 1.003 |
| 30 ns | +0.0459 | 0.445 | 0.575 |
| 50 ns | +0.0557 | 1.182 | 3.241 |
| 90 ns | +0.0442 | −0.230 | 0.281 |

1mix_A だけの AUPRC は、静的のみ 0.0295 / 0.0922 / 0.0814 / 0.0477 / 0.0514 / 0.1306、全部入り 0.0613 / 0.0836 / 0.1475 / 0.0936 / 0.1071 / 0.1748、平均だけ 0.0604 / 0.0966 / 0.1242 / 0.0682 / 0.1172 / 0.1205 です（1/5/10/30/50/90 ns の順）。

### 4.2 近い幅（A: 3.5〜4.5 Å）の参考値: 2qt4_A を除いた後（1mix_A だけ）

| 予測幅 | 利得（1mix_A だけ） | 回復率（1mix_A だけ） | 回復率（K55 の全体まとめ） |
|---:|---:|---:|---:|
| 1 ns | +0.1232 | 0.948 | 0.918 |
| 5 ns | +0.1392 | 1.218 | 1.021 |
| 10 ns | +0.0533 | 0.974 | 1.150 |
| 30 ns | +0.0709 | 0.704 | 0.864 |
| 50 ns | +0.0101 | 3.949 | 1.572 |
| 90 ns | +0.0632 | 1.170 | 0.919 |

幅A 50 ns先の 1mix_A の回復率 3.949 は、分母の利得が +0.0101 と小さいために大きくなったもので、比率としての意味は薄いです（K57 の記録と同じ）。

## 5. 読み取り

- **2qt4_A を除いても、遠い幅の回復率はばらついたままです。** 1mix_A だけの回復率は 0.972、−0.501、0.647、0.445、1.182、−0.230 で、8割を下回る幅が 4幅あります（5 ns先、10 ns先、30 ns先、90 ns先）。先に固定した読み方に沿うと、ばらつきは 2qt4_A 1つのせいではなく、遠い幅では平均の担い手がそもそも安定しません。
- **1mix_A だけでも、利得の向きが幅によって違います。** 5 ns先では利得そのものが −0.0086 と負で、実履歴が静的のみを下回ります。この幅の回復率 −0.501 は、分母が負のため比率としての意味がありません。90 ns先でも平均だけの方が全部入りを下回り（回復率 −0.230）、平均だけでは担えない幅です。
- **幅Aとの対照:** 幅Aでは 1mix_A だけの回復率は 0.704〜3.949 で、50 ns先の 3.949 を除けば 0.704〜1.218 と、全体まとめ（0.864〜1.572）とよく合います。2qt4_A を除いても幅Aの担い手の形は変わりません。遠い幅だけが、1タンパク質に絞っても安定しません。
- **留保:** テストが 1mix_A だけのため、1タンパク質の性質と遠い幅の性質を分けられません。幅Bの 1mix_A だけの陽性は 22〜55件と少なく、AUPRC の小さな揺れが回復率の大きな振れになります。遠い幅の担い手を決めるには、テストのタンパク質を広げる必要があります。

## 6. 判断できること・まだ分からないこと

- 判断できること: 遠い幅での平均の戻り方のばらつきは、2qt4_A 1つのせいではありません。2qt4_A を除いても回復率は全予測幅で8割以上にはならず、遠い幅では平均の担い手がそもそも安定しません。事前に固定した読み方に沿うと、後者の枝に当たります。
- まだ分からないこと: 遠い幅で平均が担い手でないのか、1mix_A という1タンパク質の性質なのかは、この実験だけでは分かりません。テストが1タンパク質だけのため、タンパク質の違いと幅の違いを分けられません。幅Bのタンパク質を広げて、利得の向きと回復率がタンパク質によって本当に違うのかを確かめる必要があります。
