# G18: 水素結合の解離で、混合は足しになるか（資料Dの条件、水素結合の解離、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。形成では G11 で、0.1 ns の切り取り平均に第22案の生成平均を足すと回復率が 0.570 から 0.756 へ +0.186 上がった。解離でも同じか確かめるはずだった。
- 状態: 完了。Echizen の判断で選択肢 (a) の作り直しを進め、測定まで終わった。作り直した生成系列で測ると、混合は解離では足しにならなかった（第7節）。

## 1. 何を確かめるはずだったか

0.1 ns の切り取り平均だけでは、水素結合の解離の回復率は 0.532 でした（G06）。ここに第22案の生成平均（K06(a) の生成 6特徴量のうち平均だけ）を足し、同じ補正モデルで測るはずでした。比較のため、切り取り平均だけ（0.532 の再現）と生成平均だけの条件も同じ土台で測る段取りでした。

読み方は先に固定していました。混合の回復率が切り取り平均だけより +0.05 以上上がれば、混合は解離でも足しになる。+0.05 未満なら、混合の効き目は形成に限られる。

## 2. 前提確認の結果（測定はしていない）

第22案の生成系列（K05 の `generated_series.npz`、5点前方系列）が、解離の候補（K46 のキャッシュ、6,131件）を覆っているか確かめました（`check_coverage.py`、`coverage.json`）。結果は次の通りです。

| 量 | 値 |
|---|---:|
| 生成系列の行数 | 14,582件 |
| 生成系列の起点距離の範囲 | 3.500052〜5.999837 Å |
| 生成系列のうち起点距離 3.5 Å 以下の行数 | 0件 |
| 解離の候補の総数 | 6,131件（学習 4,051件、テスト 2,080件） |
| 解離の候補のうち生成系列に対応するもの | **0件**（18軌道すべてで 0件） |
| 解離の候補の起点（フレーム10）距離の最大値 | 3.499848 Å（すべて 3.5 Å 以下） |

生成系列のペアは起点距離が 3.5〜6.0 Å の形成候補だけで、解離の候補は起点距離が 3.5 Å 以下です。距離の範囲が重ならないため、対応が取れないのは原子番号の付け方の違いではなく、集合そのものが重なっていないことが原因です。

## 3. なぜ重ならないか（作りの側の理由）

K54 の記録に、同じ結論がすでにあります。第22案の候補選び（`tseries/rod.py` の `expand()`）は、起点の距離が 3.5 Å より大きいペアだけを残す作りで、解離の候補（起点 3.5 Å 以下）はそもそも生成の対象に入りません。生成器の学習に使われた教師も形成の候補だけです。生成器の作りそのものが形成の範囲に限られています。

K54 では、絞りの1行だけを変えて生成し直す試みもしましたが、生成器を学習した範囲の外に当てはめる方法のため、正式な測定にはしませんでした。そのため、残基レベルの生成方式（第11〜14案）に変えて測り直しています。

## 4. しなかったこと

- 生成器のチェックポイント `.pt` ファイルは、Echizen の「生成系列を作り直す」という判断を受け、weights_only で読み込み、読み込む前に generator.json に記録されたハッシュ（SHA-256）と照合する段取りで作り直しを進めています（K05・K74 と同じ決め事）。新しい外部のコードやデータは使いません。使うのは承認済みのチェックポイントと、K46 のキャッシュなどの既存のデータだけです。
- 第22案の代わりに別の生成方式の平均を入れて測る、という置き換えもしませんでした。生成方式を変えるのは仕様の判断になるため、統括の判断を待ちます。

## 5. 進め方の選択肢（Echizen の判断で (a) に決まった）

- (a) 第22案の生成系列を解離の候補向けに作り直す。生成器のチェックポイントの読み込みと、学習した範囲の外への当てはめの判断が要ります。K54 が正式な測定にしなかったのと同じ問題があります。→ Echizen の判断はこの (a) でした。チェックポイントは weights_only で読み込み、読み込む前に generator.json に記録されたハッシュと照合する、K05・K74 と同じ決め事で進めました（第7節）。
- (b) G18 を残基レベルの生成平均（第11〜14案）で測り直す。K54 の保存済み系列（`~/workspace/kinescope/work/k54_gen_residue/`、18軌道分）があり、解離の候補 6,131件を全件覆っていることを確かめました（軌道ごとの件数とドナー・アクセプター原子の組み合わせが、K46 のキャッシュとすべて一致）。接触の形成の G13 が、第22案ではなく K17 の残基レベル生成平均で混合を測ったのと同じ前例です。ただし生成方式が変わるため、G18 として測るか、別の番号の実験にするかは統括の判断が要ります。

## 7. 作り直しと測定（2026-11-24）

### 7.1 作り直しの段取り

Echizen の判断で選択肢 (a) を進めました。決め事は次の通りです。

- 生成器のチェックポイント（`~/workspace/k06b/gen22/generator.pt`、261,929 バイト）は weights_only で読み込み、読み込む前に generator.json に記録されたハッシュ（SHA-256）と照合しました。ハッシュは `d35b5d92043fc62479a52c2468a8ae50e56d5442846af0f1d8df2ecfd3e88a05` で、記録値と一致しました。合わなければ止める作りです（`gen_g18.py` の `load_generator`）。
- 新しい外部のコードやデータは使いません。使ったのは承認済みのチェックポイントと、K46 のキャッシュなどの既存のデータだけです。生成のコードは K54 の `gen_k54.py` と同じ段取りで、出力先だけを `~/workspace/kinescope/work/g18_gen22/` に変えました。
- 候補選びの絞りは、起点の距離が 3.5 Å より大きいペアだけを残す作りから、すべての残基をまたぐドナー・アクセプターのペアを残す作り（`expand_all`）に変えました。変えたのはその1行だけで、それ以外の下流（方向の特徴量、局所の場所、弾性モード、記述子、ネットワーク、拘束）は同じコードで同じ入力です。
- タンパク質ごとに区切って進め、途中経過をこまめに commit しました（`gen_summary.json`）。
- 生成にかかった時間は、18軌道で合計約 100秒でした（1軌道あたり約 2〜15秒）。

**範囲の外への当てはめについての明記:** 解離の候補は起点距離 3.5 Å 以下で、生成器が学習した範囲（形成の候補だけ）の外への当てはめになります。生成器の学習に使われた教師は形成の候補だけで、解離の候補は学習した範囲の外です。そのため、以下の測定結果は「学習した範囲の外に当てはめた生成平均」の寄与を測ったものとして読む必要があります。

### 7.3 測定の結果（1 ns先）

土台の再現は完全一致しました（静的のみ AUPRC 0.4160、全部入り 0.5945、利得 +0.1785）。切り取り平均だけは AUPRC 0.5109、回復率 0.532 で G06 と一致しました。

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.4160 | 0.8606 | 0.1025 | 0.3058 | 0.000 |
| 全部入り（実履歴） | 0.5945 | 0.9082 | 0.0862 | 0.2675 | 1.000 |
| 切り取り平均だけ（0.1 ns） | 0.5109 | 0.8787 | 0.0969 | 0.2946 | **0.532** |
| 生成平均だけ | 0.4046 | 0.8584 | 0.1047 | 0.3082 | **−0.064** |
| 混合（切り取り平均＋生成平均） | 0.5016 | 0.8798 | 0.0972 | 0.2975 | **0.480** |

混合の回復率は 0.480 で、切り取り平均だけより **−0.052** 下がり、先に固定した +0.05 の線に届きませんでした。

**判定は、混合の効き目は形成に限られます。** 解離では、生成平均を足しても指導力は戻らず、むしろ切り取り平均だけより少し下がりました。生成平均だけでは回復率 −0.064 と静的のみより悪く、生成平均単体では解離の指導力をほとんど持っていません。

### 7.4 切り取り平均と生成平均の関係

テスト側（学習側も併記）の値です。

| 量 | テスト側 | 学習側 |
|---|---:|---:|
| 切り取り平均と生成平均の相関 | 0.683 | 0.733 |
| 生成平均と 0〜1 ns の平均の相関 | 0.801 | 0.826 |
| 切り取り平均と 0〜1 ns の平均の相関 | 0.937 | 0.931 |
| 生成平均 − 切り取り平均（平均） | −0.081 Å | −0.093 Å |
| 生成平均 − 切り取り平均（差の標準偏差） | 0.593 Å | 0.542 Å |
| 生成平均 − 0〜1 ns の平均（平均） | −0.051 Å | −0.056 Å |
| 生成平均 − 0〜1 ns の平均（差の標準偏差） | 0.395 Å | 0.378 Å |
| 切り取り平均 − 0〜1 ns の平均（差の標準偏差） | 0.297 Å | 0.290 Å |

形成の G11 では、切り取り平均と生成平均の相関は 0.728、差の標準偏差は 0.706 Å でした。解離では相関は 0.683 と少し低く、差の標準偏差は 0.593 Å と少し小さいものの、2つの平均が完全には重ならない点は形成と同じ形です。にもかかわらず、解離では混合が足しにならなかったため、2つの平均の食い違いそのものが手がかりになる、という形成での読み（G15）は解離には当てはまりません。

### 7.5 留保

- 生成平均は学習した範囲の外への当てはめです（第7.2節の明記）。生成平均だけの回復率が −0.064 と静的のみを下回ったのは、生成器が解離の候補の範囲を学習していないことの表れかもしれません。混合が足しにならなかった理由が、混合の仕組みそのものなのか、範囲の外への当てはめなのかは、この実験だけでは分けられません。
- G23 の結果では、形成の 1 ns先の混合の差 +0.186 はブートストラップの 95% 区間が 0 を含み、揺れでした。解離の混合の差 −0.052 も、タンパク質が2つしかないため、区間の粗さは同じです。ただし解離では差の向きそのものが負で、+0.05 の線には遠く届きません。
- 生成系列は実の前方系列より静かで、境界をほとんどまたぎません（第7.2節）。解離のラベルは起点で結んでいるペアが 3.5 Å を超えることなので、境界をまたぐ回数の少なさが生成平均の情報の弱さと結びついている可能性がありますが、この実験だけでは確かめられていません。
