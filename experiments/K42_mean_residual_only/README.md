# K42: 指導力は「静的な特徴では予測できない平均の分」だけで説明できるか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。K39 で、実の平均のうち静的な特徴で予測できる分は 63% で、残りの分（残差）がラベルと関わることが分かりました。指導力そのものが、この残差の分だけで説明できるか確かめます。

読み方は実験前に固定しました。残差だけを足した条件で利得の8割以上が戻れば、指導力は「静的な特徴では予測できない平均の分」そのものです。戻らなければ、他の統計量にも指導力が残っています。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的補正との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。
- 静的な特徴に、実の平均の残差だけを足した条件で補正モデルを学習します。残差は K39 と同じ方法で、実の平均を静的な特徴から予測したときの差です。予測は線形回帰と HistGradientBoosting 回帰の2通りで、どちらも較正用の候補だけで当てはめ、テスト側の統計は使いません。残差の標準偏差は、較正側で線形 0.61 Å、GBM 0.60 Å、テスト側で線形 0.61 Å、GBM 0.60 Å でした。
- 参照として、静的な特徴だけの条件、実履歴全部の条件、静的な特徴に実の平均そのものを足した条件（K21 の平均だけの条件の再検証）も測りました。
- 対照の確認: 静的な特徴だけの条件と実履歴全部の条件は、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。

## 判断

先に固定した読み方に照らすと、答えは「ほとんどは残差の分だが、全部ではない」です。残差だけを足した条件で利得の 0.68〜0.94（テスト全体）、0.70〜0.92（タンパク質ごとの平均）が戻りました。8割の線を超えるのは 1 ns先（GBM で 0.80）、30 ns先（0.80〜0.84）、90 ns先（0.90〜0.94）で、5 ns先（0.72〜0.80）、10 ns先（0.73）、50 ns先（0.68〜0.70）では下回ります。指導力の大半は「静的な特徴では予測できない平均の分」にありますが、2〜3割は他の統計量に残っています。

参考までに、平均そのものを足した条件は利得の 0.88〜1.08 が戻り、実履歴とほぼ同じです（K21 の 0.87〜1.08 と一致）。平均と残差の差は、静的な特徴で予測できる分の平均が持つ情報か、モデルが平均をそのまま使うときの使いやすさの分です。情報としては、静的な特徴と残差を合わせれば平均と同じ情報を持ちますが、補正モデルは平均そのもののほうが使いやすい、という形です。
