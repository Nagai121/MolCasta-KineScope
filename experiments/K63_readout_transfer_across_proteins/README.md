# K63: あるタンパク質で学習した読み出しは、別のタンパク質でも使えるか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。これまでの補正モデルは、複数のタンパク質で学習していました。あるタンパク質だけで学習した読み出しが、別のタンパク質でも使えるか確かめます。

読み方は実験前に固定しました。別のタンパク質でも利得の8割以上が戻れば、平均の読み出しはタンパク質によらず同じです。戻らなければ、読み出しはタンパク質ごとに違います。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、学習回数160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付けます。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- 1mix_A と 2qt4_A は、弱い土台のテストタンパク質で、K06(b) の108タンパク質には入っていません。そのため、K06(b) と同じ作り方でこの2タンパク質の特徴量（静的な特徴5つ＋実履歴10統計量＋ラベル）を `extract_features.py` で取り出しました。K06(b) の `score_b.py` と同じ枠（0〜1 nsの11点の系列、同じ凍結モデル、同じ履歴10統計量の式、同じ静的な特徴の列）で、生成軌道の特徴量だけを省いています。ATLAS からのダウンロードが遅かったため、手元にあった変換済み軌道（GPT の作業で使った MiniTopol 変換済み zarr、K29 で弱い土台のデータと一致を確認済み）をレジストリの配置に写して使い、ダウンロードを省きました。
- 取り出した特徴量の確認: 候補数は 1mix_A が 3,101件、2qt4_A が 1,871件で、合計 4,972件は弱い土台のテスト候補数と一致します。レプリカごとに候補を突き合わせたところ、弱い土台のデータと全候補が一致し、最初のフレームの距離の差は最大で約 1e-6 Å、11点の平均の差も約 1e-6 Å、ラベルの一致は全予測幅・全レプリカで 1.0000 でした。
- 条件は次の通りです。利得は、同じ学習タンパク質で学習した静的な特徴だけの条件との AUPRC の差で、評価するタンパク質の3レプリカをまとめた値です。
  - 移し替えA: 1mix_A だけで学習し、2qt4_A で評価
  - 移し替えB: 2qt4_A だけで学習し、1mix_A で評価
  - 参照（指示通り）: 両方のタンパク質で学習し、評価するタンパク質で評価
  - きれいな参照: K06(b) の較正用8タンパク質で学習し、評価するタンパク質で評価（評価するタンパク質は較正用に入っていないので、完全に未知のタンパク質への評価です）
  - 参考: 両方のタンパク質で学習したモデルを、K06(b) の100タンパク質のテストで評価
- 対照の確認: 較正用8タンパク質で学習したモデルを100タンパク質のテストで評価すると、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。
- 注意点: 1タンパク質だけの学習では候補数が 1,871〜3,101件と少なく、早期停止が働かないため（10,000件を超えると働きます）、学習回数は160回まわります（較正用8タンパク質では78回で止まります）。陽性の数も少なく、1mix_A で 204〜251件、2qt4_A で 80〜94件です。

### なぜこの数字が読めないか

**指示通りの参照（両方で学習）は、評価するタンパク質の候補を学習に含んでいるため、使えません。**両方で学習したモデルの AUPRC は、評価するタンパク質で 0.96〜0.98 と、未知のタンパク質への評価（0.35〜0.53）とはかけ離れて高くなります。静的な特徴だけの条件でも 0.75〜0.86 まで上がります。つまり、両方で学習の利得（+0.12〜+0.23）は、学習で見た候補への当てはまりの良さを含んでおり、分母として使えません。戻り率（0.06〜1.29）は、この膨らんだ分母に引っ張られています。

**1タンパク質だけの学習では、静的な特徴だけの条件そのものが別のタンパク質で崩れます。**1タンパク質で学習した静的な特徴だけの条件の AUPRC は、別のタンパク質では全予測幅で凍結した本体だけの値を下回ります（例：2qt4_A で学習して 1mix_A の 5 ns先で評価すると 0.3060、凍結した本体だけは 0.4755。1mix_A で学習して 2qt4_A の 90 ns先で評価すると 0.2312、凍結した本体だけは 0.4267）。較正用8タンパク質で学習した静的な特徴だけの条件も、凍結した本体だけを下回ることが多いですが、下がり方は小さいです。つまり、移し替えの利得は、履歴の信号だけでなく、崩れた土台の分も含んでいます。5 ns先で移し替えの利得が大きく見える（+0.1994、+0.1477）のは、土台の崩れが大きいためです。

**タンパク質ごとの参照の利得そのものが、予測幅によってほぼゼロになります。**較正用8タンパク質で学習したモデルの 1mix_A での利得は、10 ns先で +0.0006 とほぼゼロです。そのため、戻り率は 100.59 と爆発し、比率として読めません。

## 判断

先に固定した8割の線で、移し替えが安定して8割以上戻るとは言えません。ただし、その理由は「読み出しがタンパク質ごとに違う」という証拠ではなく、この段取りの限界です。指示通りの参照は学習で見た候補への評価のため分母として使えず、きれいな参照では 1mix_A の 10 ns先の利得がほぼゼロで比率が読めず、移し替えの利得自体も土台の崩れを含んでいます。1タンパク質だけの学習では候補数が少なく、モデルがそのタンパク質に過剰に合ってしまい、静的な特徴だけの条件すら別のタンパク質では凍結した本体だけを下回ります。

一方で、2タンパク質で学習したモデルは、未知の100タンパク質で較正用8タンパク質の利得の 0.68〜1.08 を保ちます。読み出しは、2タンパク質以上で学習すればタンパク質を越えて使える形です。1タンパク質だけの学習では、この問いには答えられません。
