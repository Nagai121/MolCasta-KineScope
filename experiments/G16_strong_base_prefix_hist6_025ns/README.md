# G16: 強い土台で、0.25 ns の切り取りの 6 統計量はどうなるか（K06(b) の条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDの経路の続き。G12 では 0.1 ns の 6 統計量が平均だけより悪く（回復率全体 0.446 に対して平均だけ 0.545）、0.5 ns では良くなった（0.768 に対して 0.695）。そのあいだの 0.25 ns ではどうか。
- 状態: 完了。0.25 ns の 6 統計量の回復率は全体 0.649、タンパク質ごとの平均 0.664 と、同じ長さの平均だけ（0.573 / 0.588）より良く、G05 の 0.1 ns の平均だけ（0.545 / 0.553）も上回った。0.1 ns での悪化は切り取りの短さの問題で、切り取りの長さで 6 統計量の効き目が変わる境目は 0.1 ns と 0.25 ns のあいだにある。

## 1. 何を確かめる実験か

G05 で作り直した 11点系列（`~/workspace/kinescope/work/g05_series/`）を使い、0.25 ns の切り取り（フレーム 0, 1, 2）の 6 統計量を補正モデルに入れ、1 ns先の利得の回復率を測る。比較のため、0.25 ns の平均だけも同じ土台で測る。参照は実履歴の利得で、全体（pooled）+0.0702、タンパク質ごとの平均（macro）+0.0712。回復率は両方で測る。

6 統計量の定義は G02/G12 と同じ（資料Dの D6 と同じ）: [最初、平均、標準偏差、最小、最後−最初、3.5 Å以下割合] を切り取りのフレームで計算する。0.25 ns は 100 ps 刻みに合わないため、実際に覆う長さは 0.2 ns になる。

判定は先に固定した。0.25 ns の 6 統計量で回復率が平均だけ（G05 の 0.1 ns は全体 0.545、タンパク質ごとの平均 0.553）を上回れば、0.1 ns での悪化は切り取りの短さの問題。平均だけを下回れば、強い土台では短い切り取りの 6 統計量は一貫して足しにならないことになる。同じ長さの 0.25 ns の平均だけとの比べもあわせて見る。

## 2. 条件

- 土台は K06(b) と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、1 ns先の陽性 11,712件）で評価する。静的特徴は5個。履歴の要約値は10個。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 1 ns先。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個。参照条件。
- 平均だけ（mean_only_full）: 静的特徴＋0〜1 ns の平均だけ。参照条件。
- 切った平均だけ（prefix_mean_0.1/0.25/0.5ns）: 静的特徴＋切った履歴の平均だけ。0.1 ns と 0.5 ns は G05/G12 の再現、0.25 ns が今回の条件。
- 切った6統計量（prefix_hist6_0.1/0.25/0.5ns）: 静的特徴＋切った履歴の6統計量。0.1 ns と 0.5 ns は G12 の再現、0.25 ns が今回の条件。

## 3. 結果

### 土台と 0.1 ns / 0.5 ns の再現

1 ns先で静的のみ AUPRC は全体 0.4591、タンパク質ごとの平均 0.4539。全部入りは全体 0.5293、タンパク質ごとの平均 0.5251。利得は全体 +0.0702、タンパク質ごとの平均 +0.0712 で、k06b_results.json の記録と小数第4位まで完全一致した。0.1 ns と 0.5 ns の条件も G05/G12 と完全一致した（0.1 ns の平均だけは全体 0.4974、0.1 ns の 6 統計量は全体 0.4904、0.5 ns の平均だけは全体 0.5079、0.5 ns の 6 統計量は全体 0.5130）。

## 4. 読み取り

- **0.25 ns の 6 統計量の回復率は全体 0.649、タンパク質ごとの平均 0.664 と、G05 の 0.1 ns の平均だけ（0.545 / 0.553）を上回った。** 先に固定した読み方に沿うと、0.1 ns での悪化は切り取りの短さの問題。同じ長さの 0.25 ns の平均だけ（0.573 / 0.588）との比べでも、6統計量は +0.076 / +0.076 良い。
- 切り取りの長さごとの 6 統計量と平均だけの差は、0.1 ns で −0.099 / −0.085、0.25 ns で +0.076 / +0.076、0.5 ns で +0.073 / +0.065 と、0.1 ns と 0.25 ns のあいだで向きが変わる。境目は 0.1 ns と 0.25 ns のあいだ（フレーム 2つと 3つのあいだ）にある。フレームが 3つあれば、標準偏差や最小、3.5 Å以下割合が平均とは別の情報を持ち始める、という見立てが自然。確かめの計算はしていない。
- 平均だけの回復率は、切る長さが 0.1 ns → 0.25 ns → 0.5 ns と伸びても 0.545 → 0.573 → 0.695 と緩やかにしか上がらないのに対して、6統計量は 0.446 → 0.649 → 0.768 と大きく上がる。平均は短い切り取りでもほぼ決まるが、平均以外の統計量は切り取りの長さに敏感、という形。
- 0.25 ns の 6 統計量の回復率（0.649 / 0.664）は、0.5 ns の平均だけ（0.695 / 0.686）には届かない。統計量を足しても、切り取りを長くすることの代わりにはならない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、0.25 ns の切り取りの 6 統計量は平均だけより良く、0.1 ns での悪化は切り取りの短さの問題。6統計量が足しになるかどうかの境目は 0.1 ns と 0.25 ns のあいだ。
- まだ分からないこと: 境目がフレーム数（2つと3つ）によるものか、覆う長さ（0.1 ns と 0.2 ns）によるものかは、この実験では分けられない。0.25 ns の 6統計量のうち、どの統計量が効いているかも測っていない。
