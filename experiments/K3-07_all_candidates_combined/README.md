# K3-07: 候補の量を全部合わせた場合に、ずれをどこまで説明できるか

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる系列 K3（問いは「軌道が知っていて、静的構造が知らない、ペアの物理的な状態は何か」）の1件。K3-01〜K3-06 で測った候補の量は、単独ではすべてずれの正体の候補から外れた。ここでは、その6つの実験の量を全部合わせると、ずれをどこまで説明できるかを測る。
- 状態: 完了。**全部合わせても、ずれのばらつきは 0.600 Å から 0.563 Å までしか減らず、判定の線（0.30 Å）には遠く届かなかった。** 減りの中心はペアの間の水（K3-05）で、残りのグループの寄与はどれも小さい。K3-02 のフレーム0の量をさらに足しても 0.547 Å だった。合わせたときの減りは入れ替え対照では消えたので、減り自体は量とペアの正しい対応によるものだが、大きさは「ずれの大部分」とは言えない。

## 1. 何を確かめる実験か

強い土台（K06(b)、水素結合の形成、較正8タンパク質の候補 13,808件で当てはめ、未見100タンパク質×3レプリカの候補 163,074件で評価）のペアについて、K3-01〜K3-06 で測った候補の量を全部、静的な予測（静的特徴5個から実の平均を予測する HistGradientBoosting 回帰、K39・K42 と同じ作り方）に足して当てはめ直し、ずれのばらつき（テスト側の残差の標準偏差）がどれだけ減るかを測る。

判定は先に固定した。

1. 全量を足してずれのばらつきが 0.30 Å 以下になれば、「候補の組み合わせでずれの大部分を説明できた」と記録する（下限は 0.249 Å。ただしこの下限は資料D条件で K23 が測った複製間のばらつきで、強い土台での測り直しは記録にない。K3-01〜K3-06 の各記録と同じ留保）。
2. 0.30 Å に届かない場合は、数値をそのまま記録し、どのグループがどれだけばらつきを減らしたか（追加と除外の両方から）を報告する。
3. 相関だけでは正体とは言わない（この実験では相関は測り直さない。各実験の記録を参照）。

## 2. 条件と使う量

- ずれと当てはめの形は K3-01〜K3-06 と共通。実の平均は履歴11フレーム（フレーム0〜10）のドナー・アクセプター間距離の平均で、静的な予測は静的特徴5個（本体 T1I2006 の予測確率、起点距離、基礎記述子3個）から実の平均を予測したもの。当てはめは HistGradientBoosting 回帰（反復160回、学習率 0.065、葉 15、葉あたり最小 20、L2 0.15、種 20261121）で、較正用の候補だけで当てはめ、テスト側の統計は使わない。
- 使う量は、各実験が保存したペアごとの値をそのまま使う（再計算はしていない）。ほとんどは起点フレーム（フレーム10）のものだが、ペアの間の水（K3-05）は測った量すべてを使う指定のため、最初の 0.1 ns の量も含む。量の使い方（角度の sin/cos 化、欠損の扱い）は各実験でその量を足したときの測り方に合わせた。（訂正、2026-11-26: はじめ「使う量はすべて起点フレームのもの」と書いていたが、K3-05 の量のうち最初の 0.1 ns のものも含むのが正しい。数値と結論は変わらない。）

### 前提の確認

- 土台だけの再現: テスト側のずれのばらつきは GBM で 0.6002 Å（R² 0.6352）、線形で 0.6076 Å（R² 0.6262）で、K39・K3-01 の記録と小数第4位まで完全一致した（数値そのものも一致）。
- 行の対応: 組み立てたテスト側のずれと各量を、K3-01 の `test_pairs.npz`、K3-03・K3-04 の `analysis_data.npz`、K3-06 の `candidates.npz` の保存値と突き合わせた。ずれは K3-01・K3-06 の保存値と差 0.0、K3-03・K3-04 とは float32 の丸めの範囲（最大 4.5×10⁻⁷）。各量も最大の差 3.0×10⁻⁸ 以下で一致し、タンパク質の並びも一致した。
- グループごとの追加の照合: グループごとに全部足した結果は、各実験の元の記録とすべて差 0.0 で一致した（下の表の「元の記録」の列）。追加枠（K3-02 フレーム0だけを足した形）も K3-02 のフレーム0の記録 0.5829 Å と差 0.0 で一致した。量の組み立てと当てはめの形が各実験と同じであることが確かめられた。

- 1グループずつ抜いたときの増え分の合計は +0.0361 Å で、全量の減り（−0.0370 Å）とほぼ一致する。寄与の内訳は、追加の見方でも除外の見方でも、ペアの間の水（K3-05）が突出して大きく（約 −0.021〜−0.022 Å）、次が χ 角（K3-01、除外で +0.0067 Å）で、残りの4グループはどちらで見ても 0.003 Å 以下である。

- 入れ替え対照: 全量を入れ替えると、較正側を入れ替えて当てはめ直した形では 0.6019 Å と土台だけ（0.6002 Å）とほぼ同じに戻り、評価側だけ入れ替えた形では 0.6277 Å と土台より悪くなった。全量を足したときの減りは、量とペアの正しい対応があってのものである。

## 4. 判定

先に固定した判定に照らすと、答えは次のとおりです。

- **全量を足しても、ずれのばらつきは 0.6002 Å から 0.5632 Å までしか減らず、0.30 Å の線には届かなかった。** 分散で見ても減りは 11.9% で、「候補の組み合わせでずれの大部分を説明できた」とは言えない。フレーム0の追加枠まで足しても 0.5472 Å（分散で 16.9% の減り）で、結論は変わらない。
- どのグループがどれだけ減らしたか: 追加と除外の両方で、ペアの間の水（K3-05）が最大（約 0.021 Å）で、全体の減りの6割ほどを担う。次に χ 角（K3-01）が除外の見方で 0.0067 Å、水素結合の数（K3-02 フレーム10）とエネルギー（K3-06）が 0.002〜0.004 Å、電場（K3-03）と背骨の φ/ψ（K3-04）は 0.001 Å 台で、背骨は単独ではむしろ増やす向きだった。
- つまり、**K3-01〜K3-06 の候補は、合わせてもずれの正体ではない**。候補同士の組み合わせで初めて出てくる大きな説明力も無かった（合わせた減りは、単独の減りの合計とほぼ同じ大きさ）。各候補に弱い関係があること自体は入れ替え対照で裏付けられたが、ずれのばらつき 0.60 Å の大部分は、この6つの候補の外にある。

## 5. 読みの注意点

- この実験で合わせたのは、各実験が起点フレーム（フレーム10）で測った量である（K3-05 は測った量すべての指定により、フレーム0・1の量も含む）。フレーム0の量を体系的に足すことはしていない（追加枠は K3-02 のフレーム0だけ）。K3-06 のフレーム0のエネルギー（単独で 0.5468 Å まで減った分）など、フレーム0の量同士の組み合わせは測っていない。
- 量の使い方は各実験の形に合わせた。χ 角は供与体・受容体側だけ（K3-01 の指定どおり。隣の残基の χ 角は入れていない）、エネルギーは記録した10個（主の6つだけの形では元の記録で 0.5963 Å で、10個の形とほぼ同じ）。
- 当てはめは GBM のみ（各実験で線形ではほぼ減らなかったため、全量の形でも GBM で測った）。較正側で当てはめてテスト側で評価する分け方は守っている。
- 相関は測り直していない。組み合わせた量同士の関わり（たとえば特定の条件でのみ効く形）は、GBM の当てはめで拾える範囲では上の結果に含まれているが、それ以外の形までは言えない。
