# GA841 新規8配列での固定確認

ATLASの未取得配列から長さ8層・固定ハッシュ順で採用。選定時の全ローカル配列（既存確認パネルを含む）とUniProtが重ならず、長さ比0.65以上の比較で大域配列同一性39%未満を条件にした。候補の予測精度は選定に使っていない。全8配列についてMiniTopolで3レプリカ各1,001フレームを取得済み。

この確認ではGA821の重みを固定。注目指標はR1の先頭起点（フレーム49）、全8配列の6 Å候補をまとめたペアの残差Pearson相関。0.700が判定線。凍結静的参照を観測平均と予測平均の双方から引く。GA348:GA821読み出しは65:35で固定。Amber 8分岐とCHARMM 2分岐を100 ps生成する。新しい読み出しは両力場の先頭2分岐・25 psまでを利用する。
