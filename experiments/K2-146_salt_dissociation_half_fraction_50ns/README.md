# K2-146: K2-14 の問い（割合の前半と後半）を塩橋の解離の 50 ns先で測る

- 状態: 完了。前半の割合だけの利得は全部入りの 0.575、後半だけが 0.255 で、先に固定した読み方のどちらにも当てはまらなかった。前半のほうが後半より大きい。

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。塩橋の解離の割合の前半と後半は 1・5・90 ns先（K2-138・K2-142・K2-143）で測り終えました。50 ns先ではどうなるかを見ます。

割合は、ペアの荷電重原子間の最小距離が塩橋の閾値（4.0 Å）以下の時間の割合で、6 個の統計量のうちの「4.0 Å 以下だった割合」と同じ定義です。

読み方は K2-01 と同じく先に固定しました。割合の分母は全部入りの利得を主とし、あわせて全部の割合の利得に対する割合も記録します。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録します。

- 後半の利得が全部入りの 8 割以上で、前半が 5 割以下なら「今の状態が効いている」。
- 前半も後半も 8 割以上なら「続いている状態が効いている」。
- どちらでもなければ、数値をそのまま記録する。

## データと条件

- K15 の条件（58 タンパク質で学習、30 タンパク質でテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、塩橋の解離、50 ns先、割合だけです。学習 735件、テスト 360件、テスト陽性 166件です。キャッシュは `~/workspace/kinescope/work/k53_cache/`（塩橋の解離の候補ごとの荷電重原子間の最小距離の 11 フレーム系列）を使っています。静的特徴は 5 個です。
- 実行はローカルの仮想マシンで行いました（7 条件の学習で約 19 秒。K2 系列では重い計算は Colab に逃がす決め事がありますが、この規模は重い計算にはあたらないと判断しました）。sklearn の学習はスレッド数を 1 に絞りました。

### 条件の一覧（50 ns先）

- 静的のみ: 静的特徴 5 個だけ（土台の照合用）。
- 全部入り: 静的特徴＋全部の 6 個の統計量（0〜1 ns の 11 フレーム）。6 個の統計量は [最初, 平均, 標準偏差, 最小, 最後−最初, 4.0 Å 以下だった割合]（K15 の D6 と同じ定義）。割合の分母（全部入りの利得）の参照。
- 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の平均。K53 の mean_only との照合用。
- 前半の割合だけ: 静的特徴＋前半（フレーム [0..4]、0〜0.4 ns）の 4.0 Å以下割合。
- 後半の割合だけ: 静的特徴＋後半（フレーム [6..10]、0.6〜1.0 ns）の 4.0 Å以下割合。
- 前半と後半の両方（割合だけ）: 静的特徴＋前半の割合＋後半の割合。
- 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の 4.0 Å以下割合。

フレーム 5（0.5 ns）は前半にも後半にも入らない設計です。K2-01 と同じ分け方で、前半と後半をきれいに分けるためです。

## 判断

先に固定した読み方に沿うと、**前半 0.575、後半 0.255（全部入りの利得に対する割合）で、先に固定した読み方のどちらにも当てはまらず、数値をそのまま記録します**。

分母を全部の割合の利得にしても、前半 0.744、後半 0.330 で、どちらにも当てはまらず、判定は変わりません。

塩橋の解離の割合の系列では、1 ns先（K2-138、前半 0.716・後半 0.818）、5 ns先（K2-142、前半 0.817・後半 0.642）、90 ns先（K2-143、前半 0.558・後半 0.966）はいずれもどちらにも当てはまらず、50 ns先もどちらにも当てはまりませんでした。90 ns先では後半が 0.966 と 8 割を超えていますが、前半が 0.558 と 5 割を超えているため「今の状態」にはなりません。

## 読みの注意点

- 50 ns先では 3 つのテストタンパク質（2qt4_A、1uha_A、2hng_A）に陽性が 1 件もありません。そのタンパク質の AUPRC は sklearn の慣例で 1.0、AUC は定義されません。合算の数値には影響しません。
- 全部の割合だけは 0.5869（利得 +0.1006、割合 0.773）で、塩橋の解離の 50 ns先では初めて測った値です。全部の平均だけ（0.5845）とほぼ同じ値です。
