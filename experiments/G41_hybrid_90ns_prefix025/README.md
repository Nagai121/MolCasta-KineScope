# G41: 90 ns 先で、0.25 ns の切り取りに生成した平均を足すとどうなるか（資料Dの条件、水素結合の形成、90 ns先）

- 確かめること: G14 では 0.1 ns の切り取りで混合が +0.015、G30 では 0.5 ns の切り取りで +0.098 だった。そのあいだの 0.25 ns の切り取りで測る。
- 状態: 完了。混合の回復率は 0.754 で、切り取り平均だけ（0.825）より −0.071 下がった。90 ns 先では、0.25 ns の切り取りで混合は足しにならない。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、90 ns先。0.25 ns（フレーム [0,1,2]）の切り取り平均だけと、第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.1211（G14・G30 と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、90 ns 先でも 0.25 ns の切り取りで混合が足しになることになる。+0.05 未満なら、90 ns 先では 0.25 ns の切り取りで混合は足しにならないことになる。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（90 ns先の陽性 335件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 90 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。
- K01 のキャッシュ（18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。
- 生成平均の出所: K05 の `generated_series.npz`（第22案の5点系列）。生成5点 = [起点距離 d0（フレーム10、1 ns）、+0.1、+0.3、+0.5、+1.0 ns] の前方系列。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は G11 と同じ水準（1e-06 Å 未満）だった。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列。両者は起点距離 d0 を共有するが時間の向きが逆（K09 と同じ留保）。平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しない（平均の列だけを使うため）。
- 条件: 静的のみ／履歴全部入り（参照）／切り取り平均だけ（0.25 ns）／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.1211）。

## 3. 結果

### 土台の再現

90 ns先で静的のみ AUPRC 0.3035、全部入り 0.4246、利得 +0.1211 で、G10・G14・G30 の記録と小数第4位まで完全一致した。切り取り平均だけは AUPRC 0.4034、回復率 0.825 で、G10 の値と一致した。

### 90 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.3035 | 0.8507 | 0.0538 | 0.1926 | 0.000 |
| 全部入り（実履歴） | 0.4246 | 0.8985 | 0.0486 | 0.1697 | 1.000 |
| 切り取り平均だけ（0.25 ns） | 0.4034 | 0.8824 | 0.0495 | 0.1751 | 0.825 |
| 生成平均だけ | 0.3356 | 0.8607 | 0.0524 | 0.1881 | 0.265 |
| 混合（切り取り平均＋生成平均） | 0.3948 | 0.8899 | 0.0496 | 0.1731 | 0.754 |

混合の回復率は 0.754 で、切り取り平均だけ（0.825）より **−0.071** 下がり、先に固定した +0.05 の線には届かなかった。

### 切り取り平均と生成平均の関係（テスト側）

生成平均 − 切り取り平均は平均 −0.156 Å・標準偏差 0.663 Å、相関 0.750。生成平均と 0〜1 ns の平均の相関は 0.844、切り取り平均と 0〜1 ns の平均の相関は 0.950。

### 90 ns先の切り取りの長さごとの混合の上がり幅

| 切り取りの長さ | 切り取り平均だけ | 混合 | 混合 − 切り取り |
|---|---:|---:|---:|
| 0.1 ns（G14） | 0.590 | 0.604 | +0.015 |
| 0.25 ns（この実験） | 0.825 | 0.754 | −0.071 |
| 0.5 ns（G30） | 0.658 | 0.756 | +0.098 |

## 4. 読み取り

先に固定した読み方に照らすと、混合の回復率は切り取り平均だけより −0.071 下がったため、90 ns 先では 0.25 ns の切り取りで混合は足しにならない、というのがこの測定の結論。

90 ns先の形は、切り取りの長さに対して単調ではない。切り取り平均だけの回復率は 0.1 ns で 0.590、0.25 ns で 0.825、0.5 ns で 0.658 と、0.25 ns が一番高い。一方、混合の回復率は 0.604、0.754、0.756 と、0.25 ns と 0.5 ns でほぼ同じ。混合の上がり幅が 0.25 ns でマイナスになるのは、切り取り平均だけが 0.25 ns でとびぬけて良いためで、生成平均を足してもそれを超えられない。AUPRC の絶対値で見ると、混合が切り取り平均だけを下回る幅は −0.0086（0.3948 に対して 0.4034）と小さい。

## 5. 判断できること・まだ分からないこと

- 判断できること: 90 ns先では、切り取りを 0.1 ns から 0.25 ns に伸ばしても混合は足しにならず、0.5 ns まで伸ばしてようやく +0.098 と線を超える。混合の効き目は切り取りの長さとともに単調に大きくなるのではなく、0.25 ns では切り取り平均だけがとびぬけて良いため、混合の上がり幅がマイナスになる。
- まだ分からないこと: 0.25 ns の切り取り平均だけが 90 ns先でとびぬけて良い理由（0.5 ns より良いのはなぜか）。5 ns先の混合の効き目（0.1 ns・0.25 ns・0.5 ns の切り取りとも未測定）。強い土台（K06(b)）の 90 ns先でも同じ形か。
