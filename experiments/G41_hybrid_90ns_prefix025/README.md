# G41: 90 ns 先で、0.25 ns の切り取りに生成した平均を足すとどうなるか（資料Dの条件、水素結合の形成、90 ns先）

- 確かめること: G14 では 0.1 ns の切り取りで混合が +0.015、G30 では 0.5 ns の切り取りで +0.098 だった。そのあいだの 0.25 ns の切り取りで測る。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、90 ns先。0.25 ns（フレーム [0,1,2]）の切り取り平均だけと、第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.1211（G14・G30 と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、90 ns 先でも 0.25 ns の切り取りで混合が足しになることになる。+0.05 未満なら、90 ns 先では 0.25 ns の切り取りで混合は足しにならないことになる。
