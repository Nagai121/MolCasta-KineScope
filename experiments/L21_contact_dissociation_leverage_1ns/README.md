# L21: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の解離、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L01（水素結合の形成、1 ns先、資料D）と同じ曲がりの測り方を、接触の解離の 1 ns先で測る。
- 状態: 完了。回復率は覆う長さ 0.1 ns で初めて 0.8 と 0.9 の両方を超え（0.9188）、0.7 ns で最大（1.0137）になったあと、1.0 ns では 0.9017 と少し下がる。増え幅がいちばん大きいのは最初の 0→0.1 ns（+0.3723）で、他に段と呼べる跳ねはない。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの補正モデルに入れたときの 1 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの流儀で、3つの値（統合・1mix_A・2qt4_A）の回復率の最小から最大。テストは 2タンパク質だけなので区間は粗い。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383行）、テスト 1mix_A＋2qt4_A 合算（2,915行、テスト陽性 207件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、種 42）で条件ごとに学習し直す。候補は、残基対の Cα 距離が 12.0 Å 以内で配列の隔たりが 2 以上、起点フレームで最小重原子間距離が 4.5 Å 以下（K50 の定義）。ラベルは、予測幅の先で最小重原子間距離が 4.5 Å を超えるかどうか。
- K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/` の 18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う。

| 覆う長さ | フレーム | フレーム数 |
|---|---|---:|
| 0 ns | 0 | 1 |
| 0.1 ns | 0, 1 | 2 |
| 0.2 ns | 0〜2 | 3 |
| 0.3 ns | 0〜3 | 4 |
| 0.4 ns | 0〜4 | 5 |
| 0.5 ns | 0〜5 | 6 |
| 0.6 ns | 0〜6 | 7 |
| 0.7 ns | 0〜7 | 8 |
| 0.8 ns | 0〜8 | 9 |
| 0.9 ns | 0〜9 | 10 |
| 1.0 ns | 0〜10 | 11 |

覆う長さ 0 ns はフレーム0だけ、つまり履歴の最初のフレームの距離そのもの（平均を取っても値は同じ）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先のまま。

G71 の呼び方との対応は次の通り。G71 の 0.1 ns（フレーム 0, 1）= 覆う長さ 0.1 ns、G71 の 0.25 ns（フレーム 0〜2）= 覆う長さ 0.2 ns、G71 の 0.5 ns（フレーム 0〜5）= 覆う長さ 0.5 ns。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_hist6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 土台の再現

1 ns先で静的のみ AUPRC は全体 0.3105、全部入りは全体 0.5246、利得は +0.2142 で、G71・G140 の記録と小数第4位まで完全一致した。G71 と重なる長さの回復率も 5e-3 以内で一致した（覆う長さ 0.1 ns で 0.9188、0.2 ns で 0.9056、0.5 ns で 0.9448）。土台の再現に問題はない。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.1 ns**（統合 0.9188）。0 ns では 0.5465 と届かない。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.1 ns**（統合 0.9188）。0.8 と同じ長さで初めて届く。
3. **増え幅がいちばん大きい場所: 0→0.1 ns（統合 +0.3723）**。次に大きいのは 0.4→0.5 ns（+0.0801）で、0→0.1 ns の増え分が突出して大きい。**0.1 ns より後ろに段と呼べる跳ねはない。**
4. 段の位置（0→0.1 ns）では、タンパク質ごとの増え分は 1mix_A が +0.3766（0.5627 → 0.9393）、2qt4_A が +0.2906（0.5471 → 0.8377）で、両方とも大きく上がる。

## 4. 読み取り

- **最初の 0.1 ns で利得の9割が戻る。** 回復率は覆う長さ 0 ns で 0.5465、0.1 ns で 0.9188 と、最初の 0.1 ns（フレーム0からフレーム1を足す）で +0.3723 跳ねる。その後は 0.86〜1.01 の範囲で上下し、0.1 ns より後ろに段と呼べる跳ねはない。
- **0.8 と 0.9 の線にはどちらも 0.1 ns で届く。** L01（水素結合の形成、1 ns先）では 0.6 ns だったが、接触の解離の 1 ns先では 0.1 ns で両方を超える。短い切り取りの効き方が現象で違う。
- 0.7 ns で回復率が 1.0137 と最大になり、その後 1.0 ns では 0.9017 と少し下がる。頂点のあとでわずかに下がる形は L01・L02 と共通する。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離の 1 ns先（資料D）では、回復率 0.8 に届く最小の覆う長さは 0.1 ns、0.9 に届く最小の覆う長さも 0.1 ns。増え幅がいちばん大きいのは 0→0.1 ns（+0.3723）で、0.1 ns より後ろに段と呼べる跳ねはない。
- まだ分からないこと: 他の予測幅でも曲がりが同じ形か。実測の費用に直したときの形（L03 の担当）。
