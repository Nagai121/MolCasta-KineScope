# E04: 公開 SOTA 生成モデル MDGen（`atlas.ckpt`）に対する静的冗長性・指導力診断

- **確かめる仮説**: キネスコ Finding 4「単一構造からの生成軌道は静的説明率 $R^2 \approx 0.96$ の静的冗長性に陥り、下流指導力がゼロになる」（K39・K43）が、実際の公開 SOTA 全原子生成 MD モデルである **MDGen**（Jing et al., NeurIPS 2024, 公式 `atlas.ckpt`）にも当てはまるか。
- **状態**: 完了（2026-11-26）。
- **リーク回避プロトコル（重要）**: キネスコの未見 100 タンパク質のうち **88 本が MDGen の学習分割 `splits/atlas_train.csv` に含まれている**ことを発見したため、E04 では MDGen 公式の厳密な未見テスト分割 `splits/atlas_test.csv` から選んだ 25 タンパク質（`L = 46..134` 残基, 学習重複 0 件, `N = 11,285` HB 形成候補ペア）のみで評価した。
- **入力・実行条件**: ATLAS R1 の単一静的フレーム `10` のみを入力（全 25 タンパク質で `d0_err = 0.0000 Å`, `fail = 0`）。MDGen により 250 フレーム（`100 ns` @ 400 ps/frame）の全原子（`atom14`）軌道を生成（`RTX 4060 Ti` 平均 **40.1 秒/タンパク質**）。100% 公開 20 特徴量（`static20`）＋ 5-fold タンパク質 CV で評価。
- **コード・結果**: [fetch_e04_assets.py](./fetch_e04_assets.py) / [run_e04_mdgen.py](./run_e04_mdgen.py) → [e04_mdgen_results.json](./e04_mdgen_results.json)

## 判断できることと、まだ分からないこと
- **棄却**: Finding 4 の「生成 MD は汎用的に静的 $R^2 \approx 0.96$ で指導力ゼロ」は実 SOTA の MDGen には当てはまらない（$R^2 = 0.59 \to 0.49$、5〜90 ns で `55–78%` 回復）。
- **確立（2 レジーム分離）**: 同じ約 40–55 秒/タンパク質の GPU 予算で、**短期・局所平衡オフセット（0–1 ns）では陰溶媒物理（E03, `r = +0.520`, 1 ns 回復 `58.2%`）が MDGen（`r = +0.266`, 1 ns 回復 `-5.2〜+24.6%`）を大きく上回る**一方、**長期（5–90 ns）では MDGen の 100 ns 生成が本物の非冗長指導力（`55.0–77.8%`）を発揮する**。
- **未解決**: 同一 25 タンパク質（`atlas_test.csv`）上での E03（陰溶媒 100 ps）と E04（MDGen）の直接結合（ハイブリッド）で 1〜90 ns の全ホライズンが同時にさらに伸びるか。
