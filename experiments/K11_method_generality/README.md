# K11 生成方式の一般性 ― 第22案以外の方式でも喪失の形は同じか

- 確かめる仮説: H6（運動の生成そのものの問題）
- 状態: 完了。系統の違う3系統（物理積分の第2案、弾性モード・揺らぎの第11〜14案、ロタマーの第8案）を、K05 と同じ候補で作り直して実軌道と直接比べた。
- 読み方は先に固定したとおりです。他の系統でも「静かで、平均が寄っている」形が共通なら喪失の形は方式によらない一般的なもの、系統ごとに形が違うなら喪失の仕組みは方式ごとに違う、と読みます。結論は第4節のとおり、形の一部は共通で、一部は系統ごとに違いました。

## 1. 実現可能性の確認（どの方式が作り直せるか）

参照元ブランチ `research/tseries-models-and-results-20261121`（MolCasta-InternalResearch、読み取り専用）の機構実験の実装を確認しました。生成系列そのものは保存されていませんが（K05 の記録と同じ事情です）、次の方式は保存済みの実装だけで作り直せます。学習済みの重みが要るのは第21〜25案だけで、今回の対象はいずれも学習なしの仕組みです。

| 方式 | 系統 | 実装 | 作り直しに要るもの |
|---|---|---|---|
| 第2案 | 物理積分（全重原子の Langevin 積分） | `tseries/hb_heavy_dynamics.py` | 実装のみ。チェックポイントなし |
| 第11〜14案 | 弾性モード・揺らぎ | `tseries/hb_elastic_paths.py` | 実装のみ。第11案=低周波モード、第12案=応答の強いモードに絞ったもの、第13案=局所の異方性揺動、第14案=第11案＋速い局所運動 |
| 第8案 | 側鎖ロタマーの遷移 | `tseries/hb_rotamer_paths.py` | 実装のみ。スクリーン実験で最良だった案（機構実験でも単独で実装あり） |

元の実装は、生成した距離をその場で8個の要約特徴に変換して系列を捨てる作りです。そのため、積分や経路の計算そのものは元のコードのまま使い、距離系列を取り出す部分だけをつなぎコード（`k11_generate.py`）で追加しました。第2案は元の記録間隔（40ステップ中5ステップごと、3レプリカ）、第11〜14案は元の分岐数（4本・8点）、第8案は元の回転経路（各8点）をそのまま使っています。乱数の種は元の実行コードに合わせて `[506166, レプリカ, 起点]` とし、起点は K05 と同じフレーム10（1 ns）に固定しました。

対象にしなかった方式: 第3・5案（多重解像度）、第4・16〜20案（局所の力学）、第6・7・9・10案（主鎖の内部座標）、第21・23・24・25案（学習型で、第22案と同じ共有生成器の別の出力）です。いずれも実装は参照元にあり、作り直し自体は可能と見ていますが、今回の3系統で系統間の対比は取れたため、まずここまでで記録します。スクリーン実験の軽い近似の系統は、今回も対象にしていません（機構実験の実装で統一しました）。

## 2. 測定の条件

- 候補は K05 と完全に同じ14,582件です（資料Dの6タンパク質×3レプリカ、起点1 ns、起点の距離が3.5〜6.0 Å のドナー・アクセプター重原子ペア）。K05 の保存系列（`generated_series.npz`）の候補表を使い、軌道ごとに候補の原子番号と起点距離が一致することを確認しました。起点距離の再計算との誤差は全軌道で 0.0 Å でした。
- 距離の計算は、シミュレーションの箱を軸ごとに扱う参照元の実装（`tseries.data.cell` で箱を取り、`_mic` で最小イメージを取る）を使いました。箱を x 方向だけの数値として扱うことはしていません。
- 比べる量は K05 とそろえました。平均距離の実との差（ペアごとに平均を取ってから実の5点系列と比べた差）、ペアごとの標準偏差、3.5 Å 以下にいた割合、一度でも3.5 Å 以下になったペアの割合、境界をまたぐ回数、3.5 Å 以下にいた滞在の長さです。あわせて増分の標準偏差と1つ遅れの自己相関も出しました。
- 系列の形は方式ごとに元の分岐構造のままです。第22案と実軌道は起点＋4点の5点系列（分岐1本）、第2案は起点＋8点（3レプリカ）、第11〜14案は起点＋8点（4分岐）、第8案は起点＋8点（端点原子の回転経路ごと。経路のあるペアは全体の46.1%で、残りは元の実装でも端点が動かないため距離が起点のまま一定になります）。点数と分岐数が違うため、境界をまたぐ回数と滞在の長さは1区間あたり・点の単位で読み、絶対値の単純比較はしていません。
- 第2〜20案の生成ステップには実際の時間（ns）が割り当てられていないため、時刻の対応づけはしていません。比べているのは系列の形です。
- 計算はこの仮想マシンの CPU で足りました（18軌道で合計約2分半）。生成した系列は `series/` に軌道ごとの npz で保存しました。

## 4. 読み取り（先に固定した読み方に沿って）

形は、共通する部分と系統ごとに違う部分に分かれました。

共通していたのは次の3点で、測った全系統に当てはまります。

1. **系列がなめらかです。** 1つ遅れの自己相関は全方式で正（+0.07〜+0.66）で、実軌道の5点系列（−0.17、11点でも −0.02）とは符号から違います。実軌道の細かい出入り（行って戻る動き）が、どの生成方式にもありません。
2. **境界をまたぐ回数が少ないです。** 1区間あたりで実軌道の 0.056 に対して、第2案 0.004、第11案 0.002、第13案 0.024、第14案 0.028、第8案 0.013、第22案 0.014 です。一番近い第14案でも実軌道の半分です。
3. **平均が起点から動きません。** 実軌道の +0.136 Å の離れる動きがどの方式にもなく、第22案以外は起点距離の平均のままです。

系統ごとに違ったのは、変動の大きさです。

- 弾性モードの系統（第11・12案）は第22案よりさらに静かです（ペア内標準偏差 0.045・0.038 Å、実軌道の約7分の1）。
- 物理積分の第2案も静かです（0.097 Å）。積分そのものは全原子を動かしていますが、記録される候補ペアの距離は少しずつなめらかにしか動きません。
- 局所揺動の系統（第13・14案）は変動が実軌道の半分ほどあり（0.179・0.206 Å）、境界をまたぐ回数と滞在の長さも実軌道に一番近いです。それでも自己相関の符号と平均の動きのなさは共通しています。
- ロタマーの第8案は、経路のあるペアでは変動が実軌道より大きいです（0.632 Å）。「静か」という形ではありません。ただし動きは1回のなめらかな回転なので、境界をまたぐのは経路ごとに多くて1回ほどで、下に入ると長く留まります（滞在 3.77 点）。変動の大きさではなく、動きの形（なめらかで、往復しない）が実軌道と違う、という点では他と共通します。

まとめると、K05 で第22案について見えた「静かで、平均が寄っている」という形のうち、「静か（変動が小さい）」は方式によらないとは言えませんでした。第8案と第13・14案は変動の大きさでは実軌道に近いか、それを超えます。一方で「なめらかで境界を往復せず、平均が起点から動かない」という形は、物理積分・弾性モード・揺らぎ・ロタマー・学習型補正（第22案）の全系統で共通でした。喪失の形のうち少なくともこの部分は、特定の生成方式の癖ではなく、単一構造から作る生成に共通する形だという読みを支持します。

## 5. 判断できること・まだ分からないこと

- 判断できること: 喪失の形は方式ごとに全部違うわけでも、全部同じわけでもありません。変動の大きさは系統ごとに大きく違いますが、時間のなめらかさ（正の自己相関、境界をまたぐ回数の少なさ、入ると長く留まる）と、平均距離が起点から離れる動きの欠如は、測った全系統で共通でした。
- まだ分からないこと: 今回測っていない系統（第3・5案、第4・16〜20案、第6・7・9・10案、第21・23・24・25案）でも同じ形かは未測定です。また、スクリーン実験の軽い近似の系統でも形が同じかは見ていません。生成ステップに実時間が割り当てられていないため、「なめらかさ」が時間の刻みの粗さによるものか、生成の仕組みそのものによるものかは、この測定だけでは分けられません。
- 予測との関係: 今回は予測を介さない測定です。第13・14案や第8案のように変動の形が実軌道に近い方式でも、元の実験では指導力が出ていません（資料B）。変動の大きさだけが喪失の理由ではないことは、そのことからも言えます。
