# G10: 水素結合の形成 90 ns先で、切り取りを長くすればどこまで戻るか

## 仮説

H6（運動の生成そのものの問題）に関わる、短い実MDの経路の確認です。G03 では、0.1 ns の切り取りの平均だけでも、水素結合の形成で 90 ns先の利得の 0.590 が戻りました。切り取りを長くすればどこまで戻るか確かめます。

読み方は実験前に固定しました。0.5 ns の 6 統計量で回復率 8 割以上なら、長い予測幅の形成も短い切り取りで十分にまかなえます。0.5 ns でも 5 割未満なら、長い予測幅では切り取りをもっと長くするか別の手立てが要ることになります。

## データと条件

- 条件は資料Dの水素結合の形成、90 ns先です。G02・G03 と同じ K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/`）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件、90 ns先の陽性 335件）。静的特徴は7個、履歴はドナー・アクセプター距離の系列の6統計量（3.5 Å 以下だった割合）です。
- 切り取りは 0.25 ns（フレーム [0,1,2]）と 0.5 ns（フレーム [0〜5]）の2つで、それぞれ平均だけと 6 統計量の両方を入れました。6 統計量は切り取ったフレームで計算します（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下だった割合。最後は切り取りの最後のフレーム）。G02・G07 と同じ段取りです。
- 参照の利得は実履歴の利得 +0.1211（静的のみ 0.3035 → 全部入り 0.4246、G03）です。回復率は、条件の利得を実履歴の利得で割った値です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（K01 の取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 確認: 静的のみ 0.3035・全部入り 0.4246 で G03 の記録と一致しました（AUPRC の差は 0.00005 以下）。

## 結果

| 条件 | AUPRC | 利得 | 回復率 |
|---|---:|---:|---:|
| 静的のみ | 0.3035 | — | — |
| 全部入り（実履歴 0〜1 ns） | 0.4246 | +0.1211 | 1.000 |
| 0.1 ns の平均だけ（G03） | 0.3749 | +0.0714 | 0.590 |
| 0.25 ns の平均だけ | 0.4034 | +0.1000 | 0.825 |
| 0.25 ns の 6 統計量 | 0.3796 | +0.0762 | 0.629 |
| 0.5 ns の平均だけ | 0.3832 | +0.0798 | 0.658 |
| 0.5 ns の 6 統計量 | 0.4073 | +0.1039 | **0.858** |

AUPRC はテストの合算です。AUC・Brier・Log Loss も全条件で改善しました（詳しくは `results.json` を参照）。

参考として、切り取りの平均と 0〜1 ns の平均との残りのばらつき（テスト側の標準偏差）は、0.25 ns が 0.319 Å、0.5 ns が 0.188 Å でした。

## 判断

先に固定した8割の線で見ると、**長い予測幅の形成も短い切り取りで十分にまかなえます**。0.5 ns の 6 統計量で回復率は 0.858 と8割を超えました。0.25 ns の平均だけでも 0.825 と8割を超えています。

ただし、長さによる伸びはきれいな単調ではありません。平均だけでは 0.1 ns の 0.590 から 0.25 ns の 0.825 まで上がったあと、0.5 ns では 0.658 に下がります。6 統計量も 0.25 ns では平均だけを下回ります（0.629 に対して 0.825）。90 ns先の利得そのものが小さく（+0.1211）、テストの陽性も 335件と少ないため、回復率の揺れが大きく出やすい条件です。AUPRC の絶対値で見ると、切り取りの4条件は 0.3796〜0.4073 の狭い範囲にあり、長さや統計量の数による差は小さいです。確かなのは、0.5 ns の 6 統計量が 0.858 と8割を超えたことで、長い予測幅でも短い切り取りで利得の大半が戻る形です。
