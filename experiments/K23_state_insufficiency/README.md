# K23 生成器の平均の誤差は、状態の不足で決まる下限に近いか

## 問い

Echizen からの問いです。生成器の入力は削られた表現（局所の特徴だけで、溶媒の配置や速度の情報が無い）なので、ペアごとの平均距離を決めきれず、誤差が実質ランダムになっているのではないか。もしそうなら、生成器の誤差は「実の平均そのものがレプリカ間で揺れる幅」（ランダム性の下限）に近いはずです。3つの誤差を同じ候補で並べて比べます。

## 対象と定義

- 資料Dの条件（6タンパク質×3レプリカ、水素結合形成の候補、K05/K08 と同じ 14,582 件。学習 9,610 件、テスト 4,972 件）。
- 実の平均は、K08 と同じく実履歴11点（0〜1 ns）の平均。生成の平均も K08 と同じく、K05 の生成系列5点（起点＋0.1/0.3/0.5/1.0 ns）の平均。
- 測るもの1（下限）：同じタンパク質の同じ原子ペアについて、実の平均がレプリカ間でどれだけ違うか。3レプリカ全てで候補になっているペア 3,190 組について、レプリカ間差（3通り）の標準偏差と、ペアごとのレプリカ間標準偏差を測った。
- 測るもの2（生成器の誤差）：生成の平均 − 実の平均（K08 の測定の再計算）。
- 測るもの3（静的な予測の誤差）：学習タンパク質で、静的特徴7個（起点の距離を含む）から実の平均を予測するモデル（HistGradientBoostingRegressor、文書Dの条件）を作り、テストタンパク質での残差の標準偏差を測った。参考に Ridge 回帰と、起点の距離そのものを予測値とする場合も測った。

## 結果

| 誤差 | 標準偏差 (Å) | 備考 |
|---|---|---|
| レプリカ間差（実の平均、下限） | 0.249 | ペアごとのレプリカ間標準偏差は平均 0.097、中央値 0.063 |
| 生成器の誤差（全候補） | 0.483 | 平均 −0.155、実平均との相関 0.836 |
| 生成器の誤差（テスト側のみ） | 0.474 | 平均 −0.129 |
| 静的な予測の残差（テスト側） | 0.492 | R² 0.691。Ridge では 0.487、起点の距離そのままでは 0.489 |

- 測るもの2は K08 の記録（平均 −0.155、標準偏差 約0.48、相関 0.836）と一致しました。
- 生成器の誤差は下限の 1.94 倍で、先に固定した「1.5倍以内なら下限に近い」という範囲には入りませんでした。
- 静的な予測の残差は生成器の誤差とほぼ同じ（テスト側同士で 1.04 倍）で、ずっと小さいとは言えませんでした。しかも静的特徴7個を使ったモデルは、起点の距離そのままの場合（0.489）とほとんど変わらず、平均を決める情報は起点の距離以外からはほぼ得られていません。
- 実の平均そのものの標準偏差はテスト側で 0.885 Å あり、静的な予測はその分散の約7割を説明しますが、残りの約 0.49 Å は構造からは決まりません。一方で同じペアの実の平均はレプリカ間ではよくそろいます（レプリカ間差 0.249 Å）。つまりペアの平均は「その系の状態」には安定に結びついているのに、今の静的な表現からは読み取れない、という形です。

## 結論

- 先に固定した読み方のうち、3番目に当たります。静的な特徴からの予測の誤差も生成器の誤差と同じくらいで、どちらもレプリカ間のばらつきよりずっと大きい。したがって、ペアの平均は今の静的な表現では決まらず、溶媒の配置など入力に無い状態が容疑になります。
- 生成器だけが情報を取り出せていない、という読み（2番目）は支持されません。実の平均を直接の目標にして学習したモデルでも、誤差は生成器と同じ水準でした。
- 生成器が下限に近い、という読み（1番目）も支持されません。誤差は下限の約2倍あります。ただし静的な予測も同じ約2倍のところで止まっているので、この開きは「生成器の作り方の失敗」というより「入力に無い状態の分」と読むのが自然です。
- 注意点が2つあります。1つ目は、生成器の誤差は前方5点の平均と後方11点の平均の差なので、向きと点数の違いが一部混ざっています。ただし測るもの3は後方の平均そのものを目標にしており、結論はそちらでも同じ形です。2つ目は、下限を測った 3,190 組は3レプリカ全てで候補になったペアに限られ、候補の総数（レプリカをまたいだ distinct なペア 6,670 組）の一部です。レプリカは同じ初期構造から始まるため、履歴の初めの部分はレプリカ間で似ており、下限は「同じ起点構造から始めた場合」の値です。これは生成器の置かれた条件（起点構造だけが与えられる）と同じ条件です。
