# K2-06: 履歴の「動き」自体が指導力を担うか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめる問い: 指導力の正体を探る K2 系列。K2-01 で、前半と後半の両方を入れると割合 1.074 で全部の平均（1.042）も全部入りも上回った。この上積みは、前半と後半の平均の差（漂い）の情報が入ったからかもしれない。ここでは漂いを 1 つの特徴量として切り出し、全部の平均の上に足しになるかを測る。
- 状態: 完了。先に固定した読み方に沿い、**漂いは足しにならない**。全部の平均＋漂い (c) の AUPRC 0.4834 は、全部の平均だけ (b) の 0.4865 を −0.0031 下回った（+0.01 の線に届かない）。漂いだけ (a) の利得は全部入りの利得の 0.231 で、単独ではわずかな利得しか持たない。

## 1. 何を確かめる実験か

資料Dの条件（水素結合の形成、1 ns先）で、静的な特徴量に足す履歴の情報を「漂いだけ」「全部の平均だけ」「全部の平均＋漂い」の3通りに変え、全部の平均の上に漂いが足しになるかを測る。

背景は K2-01 の結果である。前半（フレーム [0..4]）の平均だけの割合は 0.784、後半（フレーム [6..10]）だけでは 0.738 で、どちらも単独で利得の7〜8割を持った。前半と後半の両方を入れると割合は 1.074 になり、全部の平均（1.042）も全部入り（6 統計量）も上回った。平均を1つにまとめるより前半と後半に分けたほうがわずかに良いのは、前半と後半の平均の差（履歴のなかでの距離の動き）の情報が入ったからかもしれない。その切り分けがこの実験の狙いである。

読み方は結果を見る前に固定した。

- (c) 全部の平均＋漂いが (b) 全部の平均だけを AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) 漂いだけの利得も記録し、全部入りの利得に対する割合もあわせて記録する。
- K2-01 の「前半と後半の両方」（割合 1.074）と (c) の結果の関係も記録する。(c) は (b) の上に漂いを足した形で、K2-01 の「前半と後半の両方」は前半と後半の平均を 2 つ入れた形。2 つの条件の AUPRC の差も記録する。

割合の分母は全部入りの利得（静的＋履歴 6 統計量の利得）を主とし、あわせて全部の平均の利得に対する割合も記録する（分母の確認のため）。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（テスト陽性 290件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴は7個。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の18軌道分の距離系列）を再利用した。距離はフレームごとの箱を軸ごとに扱って計算済み。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（6条件の学習で約12秒）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 漂いの定義（結果を見る前に固定）

| 名前 | 定義 |
|---|---|
| 漂い | 前半の平均 − 後半の平均。前半はフレーム [0..4]（0〜0.4 ns）の距離の平均、後半はフレーム [6..10]（0.6〜1.0 ns）の距離の平均 |
| 符号 | 漂いが正なら「前半のほうが距離が大きい」（履歴のなかで距離が縮む方向に動いた）、負なら「後半のほうが距離が大きい」（距離が開く方向に動いた）という意味 |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である。** K2-01 と同じ分け方で、前半と後半をきれいに分けるためである。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ（土台の照合用）。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。割合の分母（全部入りの利得）の参照。
- (a) 漂いだけ: 静的特徴＋漂い。
- (b) 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の距離の平均。
- (c) 全部の平均＋漂い: 静的特徴＋全部の平均＋漂い。
- 前半と後半の両方: 静的特徴＋前半の平均＋後半の平均（K2-01 との直接比較のための照合用）。

## 4. 先に固定した読み方への答え

- **漂いは足しにならない。**(c) の AUPRC 0.4834 は (b) の 0.4865 を −0.0031 下回り、+0.01 の線に届かなかった。AUC では (c) が 0.9345 と (b) の 0.9324 をわずかに上回ったが、読み方で固定した指標は AUPRC であり、判定は AUPRC で行う。
- (a) 漂いだけの利得は +0.0272 で、全部入りの利得に対する割合は 0.231。漂いだけでもわずかな利得はあるが、全部の平均の利得（+0.1228）の 2 割ほどでしかない。
- K2-01 の「前半と後半の両方」（AUPRC 0.4902、割合 1.074）と (c)（AUPRC 0.4834、割合 1.016）の差は −0.0069 で、(c) のほうが低い。前半と後半の両方を入れたときの上積みは、漂いを 1 つの量として足した形では再現できなかった。

## 5. 読み取り

- **K2-01 の「前半と後半の両方」の上積みは、漂いの情報では説明できない。** 全部の平均の上に漂いを足しても AUPRC は上がらず、むしろ −0.0031 下がった。漂いだけでも利得は +0.0272 と小さい。履歴の「動き」そのものは、指導力の担い手ではない。
- 前半と後半の両方を入れたときの上積み（全部の平均に対して +0.0037、全部入りに対して +0.0087 の AUPRC）は、漂いではなく、前半と後半の平均を別々の量として入れたことで、モデルが 2 つの時間帯の距離の水準を別々に使えたことによると考えられる。つまり効いているのは「動き」ではなく、2 つの時間帯それぞれの「水準」である。K2-01 の読み取り（効いているのは並びそのものではなく、履歴の各時間帯での距離の水準がそれぞれ持つ、ペアごとの情報）と合う形である。
- ただし (c) と (b) の差は −0.0031、(c) と「前半と後半の両方」の差は −0.0069 と、どちらも小さい。テストが2タンパク質だけ（陽性 290件）のため、この差が一般の形かは、この実験だけでは決められない。漂いが「足しにならない」ことは、2 タンパク質でそろって負に出た点では、合算だけの偶然ではなさそうである。
- 漂いだけの利得が 0.231 と小さいのは、漂いが前半と後半の平均の差であり、2 つの平均それぞれが持つ水準の情報が差を取ることで打ち消し合うためと考えられる。平均そのものが担い手であること（K09・K12・K2-01）と、差が担い手でないことは、両立する。

## 6. 判断できること・まだ分からないこと

- 判断できること: 資料Dの条件・水素結合の形成・1 ns先では、履歴の漂い（前半の平均 − 後半の平均）は、全部の平均の上に足しにならない（AUPRC の差 −0.0031）。漂いだけの利得も全部入りの利得の 0.231 と小さい。K2-01 の「前半と後半の両方」の上積みは、漂いを 1 つの量として足した形では再現できなかった。
- まだ分からないこと: 漂いの符号（縮む方向か開く方向か）で分けたときの形（今回は符号を分けて測っていない）。長い予測幅での形（K2-05 で前半のほうが大きい形が強まったが、漂いがそこでも足しにならないかは測っていない）。ほかの現象（接触の形成など）でも漂いが足しにならないかは測っていない。
