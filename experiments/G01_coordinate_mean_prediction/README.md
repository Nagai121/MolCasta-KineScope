# G01 原子の座標そのものから学習すると、ペアの平均距離を複製の下限の水準まで当てられるか（資料Dの条件、水素結合の形成）

## 登録の経緯

指導力を回復できる生成アルゴリズムの作成と実証への移行（Echizen の決定）に伴う最初の一手です。生成アルゴリズムの系統の実験番号は K ではなく G を使うという Echizen の指示により、G01 として登録しました。

## 問い

K23・K40 で、ペアの平均距離は手作りの静的な特徴量からは残差 0.47〜0.49 Å までしか当たらず、複製間の下限 0.249 Å に届きませんでした。では、特徴量を手で作らず、起点のフレームの原子座標と原子の種類そのものから学習させれば、ペアごとの成分を持てるでしょうか。

## 対象と条件

- 資料Dの条件（6タンパク質×3レプリカ、水素結合形成の候補、K05/K08/K23/K40 と同じ 14,582 件。学習 9,610 件、テスト 4,972 件）。目的変数は実の平均＝11点の履歴系列（0〜1 ns）の平均です。
- 入力は起点（1 ns、フレーム10）の座標だけです。候補ペアのドナー原子・アクセプター原子のどちらかから 10 Å 以内にある原子（周期境界は軸ごとに処理）を集め、各原子について、ドナーとアクセプターからの相対位置と距離、元素（C/N/O/S）、ドナー・アクセプター自身かどうか、同じ残基かどうか、を入力にします。雲の大きさは平均174原子、最大310原子でした。
- モデルは、原子ごとの小さなネットワークで符号化し、平均と最大で集約して平均距離を出す形です。座標は、ペアの軸と雲の重心方向から決まる向きにそろえてから入れます（化学の情報を使わない、幾何だけの前処理）。2つの形を測りました。(A) 元素のみ、(B) 元素＋原子名の埋め込み。
- 学習は学習タンパク質4つの中で行い、早期終了の判定には学習候補の15%を内部の検証に回しました。第2段で使う学習側の予測は、学習タンパク質を1つずつ抜いた4つのモデルによる予測（未学習のタンパク質への予測）です。テスト側の予測は4タンパク質すべてで学習したモデル2つの平均です。
- 第2段は資料Dの補正モデル（HistGradientBoosting、資料Dの設定）に、予測した平均だけを履歴の特徴として入れた条件で、1 ns先の利得の回復率を測りました。学習側には上の未学習予測を使っています。

## 結果

### 第1段: テストでの予測の残りのばらつき

| 条件 | 残差の標準偏差 (Å) | 備考 |
|---|---:|---|
| 複製間の下限（K23） | 0.249 | |
| 豊かな静的特徴99個（K40） | 0.4698 | |
| 座標からの学習 (B) 原子名つき | 0.4739 | 相関 0.845、R² 0.713 |
| 座標からの学習 (A) 元素のみ | 0.4784 | 相関 0.841、R² 0.704 |
| 生成器（第22案）の誤差（K08） | 0.483 | |
| 起点の距離をそのまま予測値にする | 0.4891 | 今回再計算し、K40 の値と一致 |
| 静的特徴7個（HistGBR） | 0.4921 | 今回再計算し、K23・K40 の値と一致 |

タンパク質ごとでは、(B) で 1mix_A が 0.503、2qt4_A が 0.420 でした。学習タンパク質を1つずつ抜いたモデルでも結果は同じ水準でした（テスト残差 0.480〜0.487）。

### 第2段: 予測した平均だけを入れたときの利得（1 ns先、AUPRC）

| 条件 | AUPRC | 利得 | 回復率（実の6統計量の利得に対して） |

静的のみと実の6統計量の値は土台の再現と一致しました。他の予測幅でも、予測の平均の条件は静的のみとほぼ同じか下でした（results.json に全幅の値があります）。

## 結論

- 先に固定した読み方に沿うと、後者です。第1段の残差は 0.474〜0.478 Å で、0.45 Å 以上の側にとどまりました。座標そのものから学習しても、手作りの特徴量（7個でも99個でも）と同じ壁で止まります。表現の作り方の問題ではなく、ペアごとの成分は起点の構造の中には、この規模とモデル系統では取り出せる形で入っていない、という読みが強まりました。
- 第2段の回復率は −0.09 と 0.13 で、実証の線（5割）に遠く届きません。予測した平均は静的な特徴量とほぼ同じ情報しか持たないため、補正モデルに入れても利得は戻りませんでした。(A) では静的のみより下がっており、重なった情報がかえって邪魔をしています。
- 残る経路は、入力に構造以外の状態を含める形（溶媒の配置など。ただし変換済み軌道には水が含まれず、今回は入力に入れられていません）と、短い実MDそのものを安くする形です。どちらに進むかは統括側の判断です。

## 注意点

- 測ったのは1つのモデル系統（原子の雲を集約する形）です。より大きなモデルや、もっと多くの学習タンパク質では結果が変わる可能性は残ります。ただし、手作り特徴の2系統と合わせて、3つの表現の系統がすべて 0.47〜0.49 Å にそろって止まっています。
- 起点のフレームは履歴の最後のフレームでもあるため、起点の距離そのものは入力に含まれます。これは静的な特徴量の条件（K23・K40）と同じで、比べ方としてそろえてあります。
- 実行はこの仮想マシンの CPU で行いました（Colab は使っていません）。途中でサービスの再起動により1回中断しましたが、学習タンパク質を1つずつ抜く学習は折ごとに保存していたため、完了していた3つ分を失わずに再開できました。
