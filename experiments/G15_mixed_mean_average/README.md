# G15: 混合の効き目は2つの推定の誤差の打ち消し合いか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G11 で切り取り平均と生成平均を別々の特徴量として入れると回復率 0.756 になった。単純な平均を1つの特徴量として入れたら、同じくらい戻るか。
- 状態: 完了。単純な平均だけの回復率は 0.435 で、先に固定した 0.70 の線に届かなかった。効き目の大半は誤差の打ち消し合いではない。モデルは2つの推定の食い違いそのものを手がかりにしている。

## 1. 何を確かめる実験か

G11 では切り取り平均と生成平均の 2つを別々の特徴量として入れ、回復率 0.756 でした。こんどは 2つの平均の単純な平均を 1つの特徴量として入れ、同じ補正モデルで測ります。比較のため、G11 の混合（0.756）と切り取り平均だけ（0.570）を同じコードで再計算して照合します。

読み方は先に固定しました。単純な平均だけで回復率 0.70 以上なら、効き目の大半は 2つの推定の誤差の打ち消し合いです。0.70 未満なら、モデルは 2つの推定の食い違いそのものを手がかりにしていることになります。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。距離はフレームごとの箱を軸ごとに扱う（K01 の抽出コードと同じ段取り）。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の 18軌道分の距離系列）を再利用しました。新しい軌道の取得や生成器の読み込みはしていません。実行はローカルVM（`~/workspace/mt-venv` の Python）。

### 切り取りの定義（G02/G11 と同じ、結果を見る前に固定）

軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。0.1 ns の切り取りはフレーム 0, 1（2フレーム）で、実際に覆う長さは 0.1 ns。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 生成平均の出所

- K05 の `generated_series.npz`（第22案の5点系列）を使いました。生成器のチェックポイント .pt ファイルは読み込んでいません。
- 生成5点 = [起点距離 d0（フレーム10、1 ns）, +0.1, +0.3, +0.5, +1.0 ns] の前方系列。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、K09 と同じく土台候補 14,582 件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å でした。
- 生成平均はこの5点系列の平均です。K06(a) の生成条件（生成6特徴量）のうち平均の列だけを使う形です。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（K09 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。参照。
- 切り取り平均だけ（prefix_mean_0.1ns）: 静的特徴＋切り取り平均だけ。G02/G11 の再現。
- 生成平均だけ（gen_mean_only）: 静的特徴＋生成平均だけ。G11 の再現。
- 混合（mixed）: 静的特徴＋切り取り平均＋生成平均（2列）。G11 の再現。
- 単純な平均（avg_mean）: 静的特徴＋(切り取り平均＋生成平均)/2（1列）。主条件。
- 差（diff_mean、参考）: 静的特徴＋(切り取り平均 − 生成平均)（1列）。

回復率 =（その条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.1178）で測ります。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、形成の記録と小数第4位まで完全一致しました。切り取り平均だけは AUPRC 0.4308、回復率 0.570、生成平均だけは AUPRC 0.3746、回復率 0.093、混合は AUPRC 0.4528、回復率 0.756 で、G11 の値と小数第4位まで一致しました。

### 1 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.3637 | 0.9056 | 0.0432 | 0.1494 | 0.000 |
| 全部入り（実履歴） | 0.4815 | 0.9352 | 0.0395 | 0.1344 | 1.000 |
| 切り取り平均だけ | 0.4308 | 0.9243 | 0.0406 | 0.1385 | 0.570 |
| 生成平均だけ | 0.3746 | 0.9129 | 0.0430 | 0.1466 | 0.093 |
| 混合（切り取り平均＋生成平均） | 0.4528 | 0.9305 | 0.0398 | 0.1354 | 0.756 |
| 単純な平均（2つの平均の平均） | 0.4149 | 0.9234 | 0.0409 | 0.1396 | 0.435 |
| 差（切り取り平均 − 生成平均、参考） | 0.4047 | 0.9229 | 0.0417 | 0.1404 | 0.348 |

単純な平均だけの回復率は 0.435 で、先に固定した 0.70 の線に届きませんでした。混合（0.756）との差は −0.321 で、切り取り平均だけ（0.570）よりも 0.135 低いです。差だけの条件も回復率 0.348 と、単独では利得の3分の1ほどしか戻しません。

### 特徴量の誤差（0〜1 ns の実平均との差）

| 量 | 学習側（9,610件） | テスト側（4,972件） |
|---|---:|---:|
| 切り取り平均の誤差の標準偏差 | 0.421 Å | 0.396 Å |
| 生成平均の誤差の標準偏差 | 0.487 Å | 0.474 Å |
| 単純な平均の誤差の標準偏差 | 0.284 Å | 0.257 Å |
| 単純な平均の誤差の平均 | −0.074 Å | −0.052 Å |
| 単純な平均と実平均の相関 | 0.947 | 0.957 |

単純な平均は、0〜1 ns の実平均への誤差が 0.257 Å（テスト側）と、切り取り平均だけ（0.396 Å）や生成平均だけ（0.474 Å）より小さく、実平均との相関も 0.957 と最も高いです。つまり特徴量の水準では誤差の打ち消し合いは起きています。にもかかわらず、回復率は 0.435 と切り取り平均だけ（0.570）より低く、混合（0.756）に遠く及びません。

## 4. 読み取り

- **単純な平均だけの回復率は 0.435 で、先に固定した 0.70 の線に届きませんでした。** 先に固定した読み方に沿うと、効き目の大半は 2つの推定の誤差の打ち消し合いではありません。モデルは 2つの推定の食い違いそのものを手がかりにしていることになります。
- 単純な平均は実平均への誤差が最も小さい（0.257 Å）にもかかわらず、指導力は切り取り平均だけより低い、という逆転があります。平均の値をより正確に当てることと、指導力を戻すことは同じではありません。切り取り平均の誤差にはラベルと関わる成分があり、生成平均と平均を取るとその成分が薄まってしまう、という読みができます。
- 混合では 2つの平均を別々の列として入れるため、モデルは 2つの推定の水準と、その食い違いの両方を使えます。差だけの条件も回復率 0.348 と単独で利得の3分の1ほどを持つため、食い違いそのものにも情報があります。ただし差だけでは 0.348 にとどまり、混合の 0.756 には届かないので、食い違いだけが担い手というわけでもありません。水準と食い違いの両方が要る、という形です。
- G14（90 ns先）では混合の効き目が 0.604 と切り取り平均だけ（0.590）とほぼ同じでしたが、1 ns先では混合が +0.186 も上がります。混合の効き目が短い予測幅に限られる、という G14 の読みと合わせて、1 ns先での混合の効き目は 2つの推定の食い違いを使う形だと言えます。

## 5. 判断できること・まだ分からないこと

- 判断できること: 2つの平均の単純な平均を1つの特徴量として入れても、回復率は 0.435 と混合の 0.756 に遠く及びません。G11 の混合の効き目は、2つの推定の誤差が打ち消し合って平均の値が正確になることだけでは説明できません。モデルは 2つの推定の食い違いそのものを手がかりにしています。
- まだ分からないこと: 食い違いのうち、どの成分がラベルと関わっているか（生成平均の誤差の向きとラベルの関係は K29 で測られていて、誤差の向きでは生成の失敗は説明できない、という記録がある）。切り取り平均と生成平均の重みを変えた平均（例えば生成平均の重みを小さくする）ではどこまで戻るか。強い土台（K06(b)）でも同じ形か。
