# K54 水素結合の解離でも、平均以外の統計量の誤差の形は同じか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。作り直し済み。残基レベルの生成方式（第11〜14案）で測り直しました。第14案では、標準偏差の誤差が全予測幅で最大の担い手で、3つまとめでは利得がさらに落ちます。第11案では1つずつの置き換えはほとんど利得を落とさず、生成の仕方で結果が変わります。形成（K33）とは形が違います。

## 1. 何を確かめる実験か

形成では、平均以外の統計量の誤差の形を水素結合（K33）・接触（K41）・塩橋（K48）で測りました。解離の側でも同じ切り分けをします。

読み方は先に固定しました。解離でも 3つまとめで利得が落ち、1つずつでは落ちなければ、形成と同じ形です。1つだけで落ちれば、その統計量が担い手です。

## 2. 条件

- 土台は K46 の水素結合の解離の条件（資料D）です。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（4,051件）、テストは 1mix_A＋2qt4_A 合算（2,080件、陽性は予測幅ごとに 311〜413件）で、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・3.5 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、3.5 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は残基レベルの生成方式（第11〜14案、K11/K17/K20 の手順）です。詳しくは第4節です。
- 実の統計量は起点までの11フレームの履歴（0〜1 ns）から、生成の統計量は起点からの分岐平均の9点系列（起点＋8ステップ）から計算しています。後ろ向きと前向きの違いは、K33 と同じ作りです。
- 対照の確認: 静的のみと実履歴は、K46 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.4160、実履歴 0.5945）。

## 3. 第22案では測れなかった理由（作り直しの経緯）

- 最初に第22案（K06(a) の生成器）で測ろうとしましたが、そのままでは解離の候補に使えません。第22案の候補選び（`tseries/rod.py` の `expand()`）は、起点の距離が 3.5 Å より大きいペアだけを残す作りで、解離の候補（起点 3.5 Å 以下）はそもそも生成の対象に入りません。生成器の学習に使われた教師も形成の候補だけです。生成器の作りそのものが形成の範囲に限られています。
- そのため、絞りの1行だけを変えて生成し直す試みもしました（結果は `results_idea22_superseded.json` などに残してあります）。その試みでは、解離でも標準偏差の誤差だけで全予測幅で利得がほぼ消える結果が出ましたが、生成器を学習した範囲の外に当てはめる方法のため、正式な測定にはしませんでした。
- 作り直しでは、K14・K20 で使った残基レベルの生成方式（第11〜14案）に変えました。こちらは起点の距離の制限がなく、解離の候補にもそのまま使えます。以下の結果はこの方式での測定です。

## 6. 読み取り

- **第14案では、標準偏差の誤差が全予測幅で最大の担い手です。** 残存率は 0.34 / 0.62 / 0.61 / 0.60 / 0.43 / 0.75 で、最小値だけ（0.81〜1.00）と割合だけ（0.65〜0.95）よりはるかに落ちます。3つまとめでは 0.14 / 0.27 / 0.45 / 0.44 / 0.11 / −0.14 と、標準偏差だけよりもさらに落ちます。つまり、標準偏差が最大の担い手ですが、3つ合わせた誤差が利得をさらに削ります。
- **第11案では、1つずつの置き換えはほとんど利得を落としません。** 標準偏差だけの残存率は 0.77〜1.06、最小値だけは 0.95〜1.06、割合だけは 0.65〜0.96 です。3つまとめでも 0.30〜0.80 が残り、1 ns先では 0.80 です。生成の仕方で、誤差の出方が変わります。
- **形成（K33）とは形が違います。** 形成では 1 ns先で1つずつは 0.89〜0.94 が残り、3つまとめで 0.65 が残りました。50 ns先でも 3つまとめで 0.72 が残りました。解離では第14案の 3つまとめが 1 ns先 0.14、50 ns先 0.11 まで落ちます。90 ns先は、形成では標準偏差だけで利得が消えましたが（−0.35）、解離では第14案の標準偏差だけでは 0.75 が残り、3つまとめで −0.14 まで落ちます。
- 第11案と第14案で標準偏差の置き換えの効き方が違う理由を、統計量そのものの性質で確かめました。実の履歴の標準偏差はペアごとに大きく違い（平均 0.176 Å、ペア間のばらつき 0.266 Å）、実の平均とも強く結びついています（相関 0.770）。第14案の生成の標準偏差は平均 0.085 Å、ペア間のばらつき 0.033 Å で、実の標準偏差との相関は 0.267 しかありません。ペアごとの情報が薄く、実とあまり結びつかない値を当てると、モデルが誤った信号で予測を崩します。第11案の生成の標準偏差は平均 0.011 Å、ペア間のばらつき 0.017 Å で、ほぼ一定の値です。ほぼ一定の値を当てると「標準偏差の情報がない」のと同じになり、モデルは他の特徴量で予測するので、利得はあまり落ちません。つまり、生成の標準偏差が「小さいこと」そのものより、「ペアごとの違いを実と結びつけて出せていないこと」が利得を削ります。
- なお、6統計量すべてを生成の値にした条件は、両案ともほとんどの予測幅で静的のみを下回りました（第14案 −0.36〜+0.13、第11案 −0.77〜+0.11）。生成の統計量を当てると、静的のみより悪くなります。
- 先に固定した読み方に照らすと、**解離では「1つだけで落ちれば、その統計量が担い手です」の側で、第14案では担い手は標準偏差です。** ただし第11案では1つだけでは落ちず、生成の仕方に依存します。形成と同じ形ではありません。

## 7. 判断できること・まだ分からないこと

- 判断できること: 水素結合の解離では、実の系列に最も近い生成方式（第14案）では、平均以外の統計量の誤差の最大の担い手は標準偏差で、全予測幅で成り立ちます。形成とは形が違います。3つまとめでは利得がさらに落ちるので、標準偏差だけですべてを説明できるわけではありません。
- 判断できること: 誤差の出方は生成の仕方に依存します。最も静かな第11案では、1つずつの置き換えは利得をほとんど落としません。生成の標準偏差が実と結びついていないことが、利得を削る理由の1つです（第6節の相関の確認）。
- まだ分からないこと: 第14案の標準偏差の誤差が利得を削るのは、生成の揺れが実の揺れとペアごとに結びついていないためなのか、それとも分岐平均で揺れが半分になるためなのかは、この実験だけでは分けられません。分岐ごとの系列で統計量を作れば、分岐平均より実に近づくはずですが、その場合の置き換えの評価はまだしていません。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
