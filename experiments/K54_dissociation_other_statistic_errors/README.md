# K54 水素結合の解離でも、平均以外の統計量の誤差の形は同じか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。解離では形成と形が違いました。標準偏差の誤差だけで、全予測幅で利得がほぼ消えます。担い手は標準偏差です。

## 1. 何を確かめる実験か

形成では、平均以外の統計量の誤差の形を水素結合（K33）・接触（K41）・塩橋（K48）で測りました。解離の側でも同じ切り分けをします。

読み方は先に固定しました。解離でも 3つまとめで利得が落ち、1つずつでは落ちなければ、形成と同じ形です。1つだけで落ちれば、その統計量が担い手です。

## 2. 条件

- 土台は K46 の水素結合の解離の条件（資料D）です。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（4,051件）、テストは 1mix_A＋2qt4_A 合算（2,080件、陽性は予測幅ごとに 311〜413件）で、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・3.5 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、3.5 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は K06(a) の第22案です。ただし、解離の候補に対する生成系列はどこにも残っていなかったため、保存した生成器から作り直しました（第3節）。
- 実の統計量は起点までの11フレームの履歴（0〜1 ns）から、生成の統計量は起点からの5点系列（起点＋0.1／0.3／0.5／1.0 ns）から計算しています。後ろ向きと前向きの違いは、K33 と同じ作りです。
- 対照の確認: 静的のみと実履歴は、K46 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.4160、実履歴 0.5945）。

## 3. 生成系列の作り直し（記録）

- 使った生成器は `~/workspace/k06b/gen22/generator.pt`（261,929 バイト）です。SHA-256 を計算したところ `d35b5d92043fc62479a52c2468a8ae50e56d5442846af0f1d8df2ecfd3e88a05` で、参照元の `generator.json`（`research/tseries-models-and-results-20261121` ブランチ、`research/tseries-exploration-20261121/runs/hb_single_structure/trajectory_mechanistic/ideas_21_25/generator.json`）の記録と完全に一致しました。読み込みは K05 と同じやり方で、重みだけ読み込む形（`torch.load(..., weights_only=True)`）です。実行コードは `gen_k54.py`（K05 の `gen22_adapter.py` と同じ手順）で、出力は `~/workspace/kinescope/work/k54_gen22/` に置きました（`/tmp` ではなく、消えない場所です）。
- 作り直す途中で分かったこと: 参照元の候補選び（`tseries/rod.py` の `expand()`）は、起点の距離が 3.5 Å より大きいペアだけを残す作りで、解離の候補（起点 3.5 Å 以下）はそもそも生成の対象に入りません。最初の作り直しでは、K05 と同じ 14,582件（形成の候補だけ）ができ、解離の候補が1件も合いませんでした。この絞りは形成の研究の候補の定義であって、生成の仕組み（弾性モード＋学習した補正）そのものではありません。そこで `expand` だけを、絞りの1行を変えたもの（残基の違うドナー・アクセプターの組はすべて残す。ラベルの決め方は変えない）に置き換えて、18軌道すべてを作り直しました。置き換え以外は K05 と同じ手順です。置き換えた関数は `gen_k54.py` の中に写してあり、変えた行は明記してあります。
- 注意点: 生成器の学習に使われた教師の行も、同じ候補選びで作られているため、生成器は形成のペアだけを見て学習しています。解離の候補に当てはめるのは、学習した範囲の外への当てはめです。生成系列の質を確かめてから置き換えの評価をしました（次項）。
- 検証: 局所座標から復元した起点距離と候補表の距離の最大誤差は、軌道ごとに 0.9〜1.1e-6 Å でした（K05 のときは約1.3e-6 Å）。生成したペアの総数は 20,713件（形成 14,582件＋解離 6,131件）で、解離の候補 6,131件はすべて生成したペアの中にありました。

## 6. 読み取り

- **解離では、標準偏差の誤差だけで、全予測幅で利得がほぼ消えます。** 残存率は 1 ns先 0.28、5 ns先 0.15、10 ns先 0.33、30 ns先 0.03、50 ns先 0.13、90 ns先 −0.37 です。最小値だけでは 0.92〜1.11、割合だけでは 0.67〜0.98 とほとんど落ちません。3つまとめでは 0.14、−0.24、0.05、−0.22、−0.18、−1.03 と、利得が消えるか逆に下回ります。
- **形成（K33）とは形が違います。** 形成では 1 ns先で1つずつは 0.89〜0.94 が残り、3つまとめで 0.65 が残りました。5 ns先でも標準偏差だけでは 0.74 が残り、標準偏差だけで利得が消えたのは 90 ns先（−0.35）だけでした。解離では、90 ns先だけでなく全予測幅で標準偏差だけで利得が消えます。50 ns先も、形成では 3つまとめで 0.72 が残ったのに対し、解離では −0.18 まで落ちます。
- 先に固定した読み方に照らすと、**解離では「1つだけで落ちれば、その統計量が担い手です」の側で、担い手は標準偏差です。** 形成と同じ形ではありません。
- なお、6統計量すべてを生成の値にした条件は、全予測幅で静的のみを下回りました（残存率 −0.33〜−1.24）。生成の統計量を当てると、静的のみより悪くなります。形成の K33 では生成の条件はほぼ静的のみ並み（残存率 −0.09〜+0.02）だったのに対し、解離でははっきり悪化します。
- 解釈の手がかり: 解離の候補は結んでいるペアで、実の履歴の標準偏差は「結んだ状態での揺れの大きさ」を表します。生成の系列は実より静かなので、標準偏差を生成の値に置き換えると「揺れが小さい＝安定している」という誤った信号になり、解離の予測が崩れます。最小値や割合は、解離の候補ではほとんど変化がないため（K46 の記録のとおり、割合は 11フレームすべて 3.5 Å 以下のペアが大半）、置き換えても利得は落ちません。

## 7. 判断できること・まだ分からないこと

- 判断できること: 水素結合の解離では、平均以外の統計量の誤差の担い手は標準偏差で、全予測幅で成り立ちます。形成とは形が違います。3つまとめでも利得は消えますが、それは標準偏差1つの誤差でほぼ説明がつきます。
- まだ分からないこと: 標準偏差の誤差が利得を消すのは、生成器が結んだペアの揺れを小さく出しすぎるためなのか、それとも生成器の外への当てはめ（第3節の注意点）によるものなのかは、この実験だけでは分けられません。結んだペアの揺れを正しく出す生成器があれば、標準偏差の置き換えでも利得が残るかもしれません。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
