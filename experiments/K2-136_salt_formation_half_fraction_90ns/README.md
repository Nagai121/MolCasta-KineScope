# K2-136: K2-14 の問い（割合の前半と後半）を塩橋の形成の 90 ns先で測る

- 状態: 完了。前半の割合だけの利得は全部入りの 0.418、後半だけが 0.444 で、先に固定した読み方のどちらにも当てはまらなかった。前半と後半はほぼ同じ大きさ。

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。塩橋の形成の割合の前半と後半は、まだどの予測幅でも測っていません。ここでは同じ問いを割合の形で 90 ns先で測ります。

割合は、ペアの荷電重原子間の最小距離が塩橋の閾値（4.0 Å）以下の時間の割合で、6 個の統計量のうちの「4.0 Å 以下だった割合」と同じ定義です。

読み方は K2-01 と同じく先に固定しました。割合の分母は全部入りの利得を主とし、あわせて全部の割合の利得に対する割合も記録します。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録します。

- 後半の利得が全部入りの 8 割以上で、前半が 5 割以下なら「今の状態が効いている」。
- 前半も後半も 8 割以上なら「続いている状態が効いている」。
- どちらでもなければ、数値をそのまま記録する。

## データと条件

- K15 の条件（58 タンパク質で学習、30 タンパク質でテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、塩橋の形成、90 ns先、割合だけです。学習 2,557件、テスト 1,170件、テスト陽性 149件です。キャッシュは `~/workspace/kinescope/work/k15_cache/`（塩橋の候補ごとの荷電重原子間の最小距離の 11 フレーム系列）を使っています。静的特徴は 5 個です。
- 実行はローカルの仮想マシンで行いました（7 条件の学習で約 16 秒。K2 系列では重い計算は Colab に逃がす決め事がありますが、この規模は重い計算にはあたらないと判断しました）。sklearn の学習はスレッド数を 1 に絞りました。

### 条件の一覧（90 ns先）

- 静的のみ: 静的特徴 5 個だけ（土台の照合用）。
- 全部入り: 静的特徴＋全部の 6 個の統計量（0〜1 ns の 11 フレーム）。6 個の統計量は [最初, 平均, 標準偏差, 最小, 最後−最初, 4.0 Å 以下だった割合]（K15 の D6 と同じ定義）。割合の分母（全部入りの利得）の参照。
- 全部の平均だけ: 静的特徴＋全部（フレーム [0..10]）の平均。K2-29 の mean_full との照合用。
- 前半の割合だけ: 静的特徴＋前半（フレーム [0..4]、0〜0.4 ns）の 4.0 Å以下割合。
- 後半の割合だけ: 静的特徴＋後半（フレーム [6..10]、0.6〜1.0 ns）の 4.0 Å以下割合。
- 前半と後半の両方（割合だけ）: 静的特徴＋前半の割合＋後半の割合。
- 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の 4.0 Å以下割合。

フレーム 5（0.5 ns）は前半にも後半にも入らない設計です。K2-01 と同じ分け方で、前半と後半をきれいに分けるためです。

## 判断

先に固定した読み方に沿うと、**前半 0.418、後半 0.444（全部入りの利得に対する割合）で、先に固定した読み方のどちらにも当てはまらず、数値をそのまま記録します**。

分母を全部の割合の利得にしても、前半 0.454、後半 0.483 で、どちらにも当てはまらず、判定は変わりません。

平均だけの系列（K2-29）では、90 ns先は前半 0.662、後半 0.537 でどちらにも当てはまらず、割合の形でも平均の形でも、90 ns先の塩橋の形成では読み方は当てはまりませんでした。ただし、平均だけの形では前半も後半も 5 割を超えていましたが、割合の形では前半も後半も 5 割を下回りました。

## 読みの注意点

- 90 ns先の土台の利得は +0.0601 と小さいため、割合は小さな AUPRC の差で大きく動きます。
- 90 ns先では 5 つのテストタンパク質（2qt4_A、1uha_A、1pch_A、6in7_A、6fc0_B）に陽性が 1 件もありません。そのタンパク質の AUPRC は sklearn の慣例で 1.0、AUC は定義されません。合算の数値には影響しません。
- 全部の割合だけは 0.2688（利得 +0.0552、割合 0.919）で、塩橋の形成では初めて測った値です。前半と後半の両方（0.2653、割合 0.861）とほぼ同じ値で、両方を入れても全部の割合を上回りません。
