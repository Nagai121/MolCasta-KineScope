# K85: 塩橋の形成で、読み出しは予測時刻のあいだで移るか（K15 の条件）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。K56・K79・K80・K82 は水素結合の形成で、1 ns先で学習した読み出しを 50 ns先で使うと利得の戻り率が 0.608 と弱く、逆向きは 1.026 と強い、という向きによる違いがありました。K82 では、凍結した本体の予測を抜くと 1 ns先→50 ns先の弱さが消える（0.608 → 0.936）ことが分かりました。K83 では接触の形成で両方向とも 0.8 以上（1→50 で 0.960、50→1 で 1.082）でした。塩橋の形成でも同じ確かめをします。

読み方は実験前に固定しました。両方向の回復率が 0.8 以上なら、塩橋の形成でも読み出しは予測時刻のあいだで移ります。片方だけ弱ければ、水素結合の 1 ns先→50 ns先の弱さと同じ形か確かめます。塩橋には凍結した本体の予測がないため、K82 の「凍結した本体の予測を抜く」条件は当てはまりません。弱さの理由として、担い手の統計量の違い（K31: 塩橋の形成では平均だけでは 0.34〜1.10 と幅ごとに振れる）との関係にも触れます。

## データと条件

- K15 の条件（塩橋の形成、広げた集合）です。学習58タンパク質（候補 2,557件）、テスト30タンパク質（候補 1,170件）、集合は K15 の `split.json` で凍結済みです。起点はフレーム10（1 ns）、履歴は 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直します。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 塩橋形成: 正側は LYS の NZ、ARG の NE/NH1/NH2、負側は ASP の OD1/OD2、GLU の OE1/OE2 で、距離は荷電重原子ペアの最小値です。候補は起点で最小距離が 4.0 Å 超〜10.0 Å 以下で、配列距離が2以上の残基ペアです。ラベルは予測先で最小距離が 4.0 Å 以下になることです。静的特徴は5個（起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）。履歴の閾値は 4.0 Å です。履歴は 0〜1 ns の11フレームから作る6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下だった割合）です。
- 2hng_A の R3 と 4cv4_A の R2 は箱が全フレームで 0 のため候補が0件で、テスト側は約20件（約2%）欠けています（K15 の記録と同じ）。K15・K19 の結果と結論には影響しないとされています。
- 塩橋の形成では凍結した本体の予測はありません（K15 の条件は静的5特徴＋履歴6統計量）。そのため K82 の「凍結した本体の予測を抜く」条件は塩橋には当てはまりません。
- 距離系列は K15 の抽出済みキャッシュ（`~/workspace/kinescope/work/k15_cache/` の `*_salt.npz`）を使いました。実行はこの仮想マシン上です（`~/workspace/.mt-venv` の Python を使用）。

## 方法（K56 と同じ）

- 特徴量は予測時刻によらないので、ある予測時刻で学習したモデルを、そのまま別の予測時刻のラベルに対して評価できます。静的な特徴だけの条件も、同じ容量で予測時刻ごとに学習して評価しました。
- 利得は、評価する予測時刻での静的な特徴だけの条件との AUPRC の差です。比べる静的な補正は、評価する予測時刻で学習したものを使います（学習した予測時刻の静的な補正との差ではありません。統括からの確認どおり、K56 と同じ測り方です）。
- 参照する利得は、評価する予測時刻で学習した条件の利得です。戻り率（回復率）は、移し替えた利得を、評価する予測時刻で学習した利得で割った値です。
- 主な条件は 1 ns先で学習→90 ns先で評価、90 ns先で学習→1 ns先で評価の2方向です。参考として全組み合わせ（6×6）も測りました。
- 陽性の数が少ないため（テストの陽性は予測幅ごとに 93〜149件）、全体をまとめた値（pooled）とタンパク質ごとの平均（macro）の両方を記録します。macro は、その予測幅で陽性と陰性の両方があるタンパク質だけの平均で、使ったタンパク質の数も記録します。

## 判断できること

先に固定した読み方に沿うと、**塩橋の形成では、読み出しが予測時刻のあいだで移るかは、まとめ方によって答えが変わります**。1 ns先→90 ns先は全体まとめでもタンパク質ごとの平均でも 0.8 以上（1.327 / 1.662）で、移ります。90 ns先→1 ns先は、全体まとめでは 0.304 と 0.8 を大きく下回りますが、タンパク質ごとの平均では 0.863 と 0.8 以上です。

- 全体まとめ（K56・K83 の主たるまとめ方）で読むと、90 ns先→1 ns先は弱く、水素結合の 1 ns先→50 ns先の弱さ（0.608）と同じ向きの非対称さがあります。ただし向きが逆で、水素結合では短い予測幅で学習した読み出しが長い予測幅で弱かったのに対し、塩橋では長い予測幅で学習した読み出しが短い予測幅で弱い、という形です。
- タンパク質ごとの平均で読むと、両方向とも 0.8 以上で、塩橋の形成でも読み出しは予測時刻のあいだで移る、ということになります。
- 2つのまとめ方の食い違いの内訳を確かめるため、1 ns先でのタンパク質ごとの AUPRC を比べました（`check_drivers.py`）。90 ns先で学習した読み出しは、1 ns先で学習した読み出しと比べて、タンパク質によって大きく振れます。たとえば 1u6t_A では 0.642 → 0.160、2hu9_A では 0.761 → 0.146 と大きく落ちる一方、1y0n_A では 0.655 → 0.762、3jtz_A では 0.591 → 0.927 と上がります。タンパク質ごとの平均では上がる分と下がる分が打ち消し合って 0.863 になりますが、全体まとめでは候補や陽性の多いタンパク質の寄与が大きく、落ちる側に引っ張られて 0.304 になります。陽性がタンパク質あたり 0〜9件と少ないため、1タンパク質の振れが全体まとめに大きく響きます。
- 塩橋には凍結した本体の予測がないため、K82 の説明（凍結した本体の予測への頼り方の違い）は塩橋には当てはまりません。水素結合の弱さと同じ形かは、この実験だけでは決められません。
- 担い手の統計量の違い（K31: 塩橋の形成では平均だけでは 1・5 ns先で 0.88〜0.89 と8割を超えるが、10 ns先以降は 0.34〜1.10 と大きく振れ、単独で安定して担える量はない）との関係も、この実験だけでは決められません。90 ns先で学習した読み出しが 1 ns先で弱いのは、K31 で 90 ns先の平均だけの回復率が 0.459 と低いことと向きは合いますが、因果までは言えません。
- 全組み合わせの表も、全体まとめとタンパク質ごとの平均の両方で 0.1〜2.9 と大きく振れます。塩橋の利得そのものが小さい幅（50 ns先の +0.0274 など）では、分母が小さいため回復率が振れやすい点に注意が必要です。たとえば 50 ns先への移し替えは、90 ns先で学習した読み出しで 2.082 と 1 を大きく超えますが、これは参照の利得が小さいためで、移し替えた利得（+0.0570）が参照（+0.0274）を上回ったためです。

## まだ分からないこと

- 90 ns先→1 ns先の弱さが、全体まとめの側の振れなのか、タンパク質ごとの平均の側の振れなのかは、この実験だけでは分かりません。陽性がタンパク質あたり 0〜9件と少ないため、どちらのまとめ方も1タンパク質の振れに弱いです。候補数をさらに増やすか、別の種で繰り返す必要があります。
- 90 ns先で学習した読み出しが、1u6t_A や 2hu9_A で大きく落ちる理由も、この実験だけでは分かりません。頼る統計量の違い（K80 のような切り分け）を塩橋で測れば、理由が見えるかもしれません。

## コードと出力

- `run_k85.py`: K15 のキャッシュを読み、土台の再現確認、静的のみと実履歴の各予測時刻での学習・評価、全組み合わせの利得と回復率（全体まとめとタンパク質ごとの平均の両方）の計算を行います。途中結果を `results_partial.json` に書き出します。
- `check_drivers.py`: 1 ns先でのタンパク質ごとの AUPRC を、静的のみ・1 ns先で学習した実履歴・90 ns先で学習した実履歴の3条件で比べ、全体まとめとタンパク質ごとの平均の食い違いの内訳を確かめるための確認コードです。
- `results.csv` / `results.json`: 全条件・全予測幅の全指標、利得と回復率のまとめ、K15 との照合結果です。
