# K22: 生成の失敗は平均の誤差の大きさで説明できるか（強い土台、水素結合）

## 仮説

H6（運動の生成そのものの問題）に関わる検証です。K08 と K11b の測定では、生成側の平均の誤差（生成の平均 − 実の平均）は、候補全体の平均では −0.155 Å と小さい一方、候補ごとのばらつきが標準偏差で約 0.48 Å あり、誤差の主成分は系統的なずれではなく候補ごとのばらつきでした。では、実系列に生成側と同じ大きさの平均の誤差を人為的に乗せると、指導力は生成側の水準まで落ちるのでしょうか。それが成り立てば、生成の失敗は平均の誤差の大きさだけで説明がつき、生成器への要求は「候補ごとの平均の誤差をどれだけ小さくするか」という量的な条件になります。

読み方は実験前に固定しました。誤差を乗せた実履歴の利得が生成条件（K06(b) の生成6特徴・生成8特徴）の水準まで落ちれば、生成の失敗は平均の誤差の大きさで説明がつきます。利得が生成条件よりずっと上に残れば、平均の誤差だけでは説明できず、他の統計量か、誤差の構造（誤差が候補の状態や未来とどう関わるか）も違っていることになります。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的補正との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。
- 系列の再抽出: K06(b) の保存データには履歴の統計量10個しか残っておらず、系列全体の平行移動で変わる「3.5 Å以下だった割合」「4.5 Å以下だった割合」は統計量からは復元できません。そこで、K06(b) の score_b.py と同じ手順（フレームごとの箱を軸ごとに扱う周期境界、0〜1 ns の11フレーム）で、108タンパク質すべての候補の距離系列を ATLAS から再抽出しました。再計算した統計量10個が K06(b) の保存値と全タンパク質で完全に一致（最大の差 0.0）することを確認してから使っています。軌跡の置き場は、同じ108タンパク質を持つ K15 のワークスペース（読み取りのみ）を使い、足りない分は新規に取得しました。K15 側の複製に箱がゼロで壊れているものが2タンパク質分（2hng_A の第3レプリカ、4cv4_A の第2レプリカ）あり、その2つは新規取得の側で抽出しています。
- 加工の方法: 候補ごとに、その候補の実系列全体を平行移動して、平均が「実の平均 − 0.155 Å ＋ 候補ごとに引いた乱数（標準偏差 0.48 Å）」になるようにします。平行移動なので系列の形（標準偏差、増減のパターン）は変わりません。変わるのは水準に依存する統計量（最初の値、平均、最小値、最大値、閾値以下だった割合）だけです。乱数は候補ごとに独立に引き、学習側とテスト側の両方に当てます。乱数の種を変えて3回（seed 101、202、303）行い、結果のばらつきも記録します。実際に当たった誤差は、平均 −0.153〜−0.161 Å、標準偏差 0.478〜0.486 Å で、狙った大きさと一致しました。
- 補正モデルは条件ごとに学習し直します。参照の両端として、全部入りの実履歴条件と生成条件（生成6特徴・生成8特徴）、静的補正は K06(b) の結果（k06b_results.json）から引用します。

## 判断

先に固定した読み方に照らすと、答えは「平均の誤差の大きさだけでは説明できない」です。生成側と同じ大きさの平均の誤差を、候補ごとに独立な乱数として実系列に乗せても、指導力は全予測幅で生成条件よりずっと上に残りました（最も差が小さい 90 ns先でも +0.0151 対 約 −0.001〜−0.002）。生成条件の利得がほぼゼロであるのに対し、誤差を乗せた実履歴は実履歴の利得の4〜6割を保ちます。

同時に、平均の誤差が無関係なわけでもありません。同じ大きさの誤差を乗せるだけで、実履歴の利得の4〜6割が失われました。平均の正確さは指導力の大きな部分を占めます（K23 の測定でも、生成器の平均の誤差 0.483 は複製どうしの自然なばらつき 0.249 の約2倍でした）。ただし、生成側の失敗を全部は説明しません。残りの差は、誤差の構造か、平均以外の統計量のどちらか（あるいは両方）にあります。今回の加工では誤差を候補ごとに独立な乱数として与えたので、実際の生成の誤差が候補の状態や未来と関わって偏っている場合は、その分は再現できていません。また、生成系列は変動の大きさ自体が実系列よりずっと小さいことが K05 と K11 で分かっており、平均以外の統計量が違うこととも整合します。

生成器への要求として言えるのは、候補ごとの平均の誤差を小さくすることは必要だが、それだけでは足りない、というところまでです。平均の誤差を実系列並みの水準まで下げても、他の統計量や誤差の構造が違えば指導力は戻らない可能性があります。

- `results.json` / `results.csv`: 全条件の指標と、参照条件（K06(b)）の引用値、実際に当たった誤差の統計。
