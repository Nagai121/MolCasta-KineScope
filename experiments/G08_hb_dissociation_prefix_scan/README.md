# G08: 水素結合の解離で、切り取りの長さを細かく見る

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、もう一つの経路「短い実MDを安くする」方向。G06 では水素結合の解離で、0.1 ns 平均の回復率が 0.532 と 5割の線ぎりぎりだった。0.25 ns の切り取りでどこまで戻るか確かめる。
- 状態: 完了。0.25 ns の 6統計量で回復率 0.747 と、6割の線を超えた。0.25 ns の切り取りが実用的な選択肢になる。

## 1. 何を確かめる実験か

G06 と同じ切り取り（実の 0〜1 ns の履歴の始めの短い部分だけを使う）を、水素結合の解離（資料Dの条件、1 ns先）で、0.25 ns の切り取りについて確かめる。

読み方は先に固定した。0.25 ns の 6統計量で回復率 6割以上なら、その切り取りが実用的な選択肢になる。0.25 ns で 5割未満なら、解離では 0.5 ns まで伸ばすのが要ることになる。

## 2. 条件

- 土台は資料Dの条件。水素結合の解離（K46 のキャッシュ）。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（抽出済みのキャッシュの段取り）。
- 解離の候補の定義（K46 と同じ）: 形成と同じドナー・アクセプターの規則で、起点フレーム10の距離が 3.5 Å 以下（水素結合ができている状態）のペア。ラベルは予測先で 3.5 Å を超えること。静的特徴7個。履歴の閾値は 3.5 Å。候補は学習 4,051件、テスト 2,080件。テストの陽性は 1 ns先で 311件（陽性率 15.0%）。
- 切り取りの定義（G02/G06 と同じ、結果を見る前に固定）。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。
  - 0.25 ns → フレーム 0, 1, 2（3フレーム、実際に覆う長さは 0.2 ns）
  - 起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。
- 条件の一覧（1 ns先）:
  - 静的のみ: 静的特徴だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
  - 平均だけ: 静的特徴＋0〜1 ns の平均だけ。
  - 切った平均だけ: 静的特徴＋切った履歴の平均だけ（フレーム 0, 1, 2）。
  - 切った6統計量: 切った履歴の6統計量全部を入れる。
- K46 のキャッシュ（`~/workspace/kinescope/work/data_cache_k46/`）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（`~/workspace/mt-venv` の Python）。

## 3. 結果

### 土台の再現

静的のみと全部入りが K46 の記録と小数第4位まで完全一致した。

- 静的のみ AUPRC 0.4160、全部入り 0.5945、利得 +0.1785。平均だけは 0.5691、回復率 0.858 で K46 の値と一致する。

### 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差、テスト側

| 切る長さ | 残りのばらつき（テスト） | 残りのばらつき（学習） |
|---|---:|---:|
| 0.1 ns（G06） | 0.297 Å | 0.290 Å |
| 0.25 ns | 0.252 Å | 0.234 Å |
| 0.5 ns（G06） | 0.163 Å | 0.143 Å |

切った平均と 0〜1 ns の平均の差の平均は、0.25 ns でテスト +0.02 Å、学習 +0.02 Å で、始めの短い部分の平均のほうがわずかに大きい（G06 と同じ向き）。

### 1 ns先の利得の回復率（0.1 ns・0.25 ns・0.5 ns の比較）

| 切る長さ | AUPRC（平均だけ） | 回復率（平均だけ） | AUPRC（6統計量） | 回復率（6統計量） |
|---|---:|---:|---:|---:|
| 0.1 ns（G06） | 0.5109 | **0.532** | 0.5213 | **0.590** |
| 0.25 ns | 0.5183 | **0.573** | 0.5493 | **0.747** |
| 0.5 ns（G06） | 0.5211 | **0.589** | 0.5539 | **0.772** |
| 0〜1 ns（全部の平均） | 0.5691 | 0.858 | 0.5945 | 1.000 |

静的のみは AUPRC 0.4160。0.25 ns の他の指標も、静的のみより改善した（平均だけ: AUC 0.8606→0.8800、Brier 0.1025→0.0967、Log Loss 0.3058→0.2956。6統計量: AUC 0.8606→0.8928、Brier 0.1025→0.0925、Log Loss 0.3058→0.2854）。詳しくは `results.csv` / `results.json` を参照。

## 4. 読み取り

- **0.25 ns の 6統計量で回復率 0.747 と、先に固定した6割の線を超えた。** 0.25 ns の切り取りが実用的な選択肢になる。0.25 ns で 5割未満なら 0.5 ns まで伸ばすのが要る、という枝には当たらなかった。
- 平均だけでも 0.25 ns で 0.573 と、0.1 ns の 0.532 から 0.5 ns の 0.589 のあいだに素直に入る。平均だけの回復率は切る長さにあまり敏感ではなく、0.1 ns から 0.5 ns まで 0.53〜0.59 の範囲にとどまる。
- 6統計量の方は切る長さに敏感で、0.1 ns の 0.590 から 0.25 ns の 0.747 へ大きく上がり、0.5 ns の 0.772 にほぼ届く。0.25 ns で 6統計量が平均だけより 0.17 上回るのは、G06 の 0.1 ns（0.590 対 0.532、差 0.06）や 0.5 ns（0.772 対 0.589、差 0.18）と比べても大きい。短い切り取りでは平均以外の統計量（特に 3.5 Å以下割合や最小値）が、フレームが 2個から 3個に増えたことで働き始める形。
- 残りのばらつきの側から見ても、0.25 ns の 0.252 Å は 0.1 ns の 0.297 Å から 0.5 ns の 0.163 Å のあいだに素直に入る。複製の下限 0.249 Å とほぼ同じ水準で、0.25 ns の切り取りの平均は 0〜1 ns の平均にかなり近い。

## 5. 判断できること・まだ分からないこと

- 判断できること: 水素結合の解離では、0.25 ns の切り取りの 6統計量で利得の 0.747 が戻り、実用的な選択肢になる。平均だけでも 0.573 と 5割の線を超える。解離では 0.5 ns まで伸ばさなくても、0.25 ns の切り取りで十分な回復率が得られる。
- まだ分からないこと: 強い土台（K06(b)）でも解離で同じ形か（G05 は形成の強い土台の確かめ）。短い実MDを実際に回すときの計算量と平衡化の扱いは、この実験では測っていない。塩橋の解離でも同じか（K53 の条件では陽性が少ない）。
