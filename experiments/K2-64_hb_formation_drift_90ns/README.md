# K2-64: 水素結合の形成の漂いを 90 ns先で測る

- 確かめる問い: K2-06 の漂いの問い（履歴の漂いが全部の平均の上に足しになるか）を、水素結合の形成の 90 ns先で測る。
- 状態: 完了。全部の平均＋漂いは 0.4007 で、全部の平均だけ 0.3970 を +0.0037 上回ったが、先に固定した +0.01 の線に届かず、「漂いは足しにならない」になる。

## 1. 何を確かめる実験か

K2 系列（指導力の正体を探る系列）の割り当て。K2-06（1 ns先）では漂いは全部の平均の上に足しにならなかった（全部の平均＋漂い 0.4834 は全部の平均だけ 0.4865 を −0.0031 下回る）。K2-16（30 ns先）でも足しにならなかった（全部の平均＋漂い 0.4412 は全部の平均だけ 0.4426 を −0.0014 下回る）。ここでは 90 ns先で同じ問いを測る。

条件は資料Dの条件（6 タンパク質×3 レプリカ、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し、学習 4／テスト 1mix_A＋2qt4_A）で、水素結合の形成、90 ns先、平均だけ。

### 漂いの定義（結果を見る前に固定）

- 漂い = 前半の平均 − 後半の平均。前半はフレーム [0..4]（0〜0.4 ns）の距離の平均、後半はフレーム [6..10]（0.6〜1.0 ns）の距離の平均。フレーム 5（0.5 ns）は前半にも後半にも入らない（K2-01 と同じ設計）。
- 漂いが正なら「前半のほうが距離が大きい」（履歴のなかで距離が縮む方向に動いた）、負なら「後半のほうが距離が大きい」（距離が開く方向に動いた）という意味。

### 比べる条件（静的特徴7個に、つぎのどれかを足す）

- 静的のみ: 静的特徴だけ（土台の照合用）。
- 全部の 6 個の統計量: 静的＋履歴 6 統計量（全部入り、土台の照合用）。
- (a) 漂いだけ: 静的＋漂いだけ。
- (b) 全部の平均だけ: 静的＋全部（フレーム [0..10]）の距離の平均だけ。
- (c) 全部の平均＋漂い: 静的＋全部の平均＋漂い。
- 前半と後半の両方: 静的＋前半の平均＋後半の平均の両方（(c) との比較用）。
- 前半の平均だけ: 静的＋前半の平均だけ（K2-05 の 90 ns先の記録との照合用）。

### 読み方（結果を見る前に固定、K2-06 と同じ）

- (c) が (b) を AUPRC で +0.01 以上上回れば「漂いは足しになる」、未満なら「足しにならない」。
- (a) の利得（漂いだけの利得）も記録し、全部入りの利得に対する割合もあわせて記録する。
- (c) と前半と後半の両方の AUPRC の差も記録する。

### 土台の再現

静的のみと全部の 6 個の統計量の AUPRC が、K2-05・K2-14 の 90 ns先の記録（静的のみ 0.3035、全部入り 0.4246、利得 +0.1211、テスト 4,972件・陽性 335件）と一致することを確かめる。全部の平均は K2-05 の 90 ns先の記録（0.3970）、前半の平均だけも K2-05 の 90 ns先の記録（0.4129）と照らす。

### 注意

90 ns先では平均そのものより割合が効くため、(b) の利得が小さいことにも注意して、AUPRC の差も記録する。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成、学習4タンパク質・9,610件、テスト2タンパク質・4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 水素結合の形成の候補（K01 と同じ）: 起点で水素結合を作っていない残基ペア。ラベルは予測先で水素結合ができていること。静的特徴は7個、割合の境界は 3.5 Å。
- sklearn の学習はスレッド数を 1 に絞って実行した（OMP_NUM_THREADS=1 など）。

## 3. 結果

### 土台の再現

学習し直したモデルの合算 AUPRC は、K2-05・K2-14 の 90 ns先の記録と小数第4位まで完全一致した（静的のみ 0.3035、全部の 6 個の統計量 0.4246、テスト 4,972件・陽性 335件）。全部の平均も K2-05 の 90 ns先の記録（0.3970）、前半の平均だけも K2-05 の 90 ns先の記録（0.4129）と一致した。

### 漂いの結果（90 ns先、合算）

| 条件 | AUPRC | 利得（静的のみとの差） | 全部入りの利得に対する割合 | 全部の平均の利得に対する割合 |
|---|---:|---:|---:|---:|
| 静的のみ | 0.3035 | — | — | — |
| (a) 漂いだけ | 0.3422 | +0.0387 | 0.320 | 0.414 |
| (b) 全部の平均だけ | 0.3970 | +0.0935 | 0.772 | 1.000 |
| (c) 全部の平均＋漂い | 0.4007 | +0.0972 | 0.803 | 1.040 |
| 前半と後半の両方 | 0.3940 | +0.0905 | 0.747 | 0.968 |
| 前半の平均だけ | 0.4129 | +0.1094 | 0.903 | 1.170 |
| 全部の 6 個の統計量 | 0.4246 | +0.1211 | 1.000 | 1.295 |

- 読み方は「漂いは足しにならない」。**(c) − (b) = +0.0037** で、先に固定した +0.01 の線に届かない。(c) − 前半と後半の両方 = +0.0067 でもある。
- (a) 漂いだけの利得は +0.0387 で、全部入りの利得に対する割合は 0.320 である。漂いだけでも利得はあるが、全部の平均の上に足すとほとんど増えない。
- (b) の利得は +0.0935 と小さく、全部入りの利得に対する割合は 0.772 である。90 ns先では平均そのものより割合が効く（K2-14 では全部の割合だけの利得が全部入りの 0.973）ため、(b) の土台が小さい点に注意が要る。
- 前半の平均だけ（0.4129）は (c)（0.4007）も (b)（0.3970）も上回る。90 ns先では、前半の平均だけのほうが全部の平均＋漂いより利得が大きい。

### タンパク質ごと

| タンパク質 | (c) − (b) の AUPRC の差 |
|---|---:|
| 1mix_A | +0.0155 |
| 2qt4_A | −0.0206 |

タンパク質ごとでは向きが逆で、1mix_A だけを見ると +0.0155 と +0.01 の線を超えるが、2qt4_A だけを見ると −0.0206 と下回る。合算の +0.0037 は、2 タンパク質の打ち消し合いの結果である。

## 4. 読み取り

- **先に固定した読み方では「漂いは足しにならない」。** (c) − (b) は +0.0037 で、+0.01 の線に届かない。1 ns先（K2-06、−0.0031）・30 ns先（K2-16、−0.0014）に続いて、90 ns先でも漂いは足しにならなかった。
- **漂いだけの利得があるのに、全部の平均の上には足しにならない。** (a) の利得は +0.0387（全部入りの 0.320）だが、(c) は (b) を +0.0037 しか上回らない。漂いの情報は、全部の平均のなかにすでにほぼ入っている形である。
- **タンパク質ごとでは向きが逆である。** 1mix_A だけを見ると +0.0155 と線を超えるが、2qt4_A だけを見ると −0.0206 と下回る。合算の読み方は、2 タンパク質の土台では粗い。
- **90 ns先では平均そのものの土台が小さい。** (b) の利得は +0.0935（全部入りの 0.772）で、前半の平均だけ（0.903）のほうが大きい。漂いの問いを平均の土台で測ること自体、90 ns先では限界がある。

## 5. 判断できること・まだ分からないこと

- 判断できること: 水素結合の形成の 90 ns先では、漂いは全部の平均の上に足しにならない（(c) − (b) = +0.0037）。漂いの地図は、水素結合の形成では 1・30・90 ns先のすべてで「足しにならない」になった。
- まだ分からないこと: 漂いだけの利得（+0.0387、全部入りの 0.320）が何の情報かは、この実験だけでは分からない。タンパク質ごとで向きが逆になるのも、2 タンパク質の土台では決められない。単一の学習 seed の結果でもある。
