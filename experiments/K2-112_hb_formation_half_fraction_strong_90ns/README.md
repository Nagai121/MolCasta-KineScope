# K2-112: K2-14 の問い（割合の前半と後半）を強い土台での水素結合の形成の 90 ns先で測る（強い土台、未見 100 タンパク質×3 レプリカ、水素結合の形成、90 ns先、割合だけ）

- 確かめる問い: K2-14 は資料Dの条件（テスト 2 タンパク質）で、割合の前半と後半を測った。90 ns先では前半 0.816・後半 0.676 と、どちらにも当てはまらなかった。強い土台での平均の前半と後半は、90 ns先（K2-80）では前半 0.960 / 0.925、後半 0.757 / 0.722（合算 / タンパク質ごとの平均、全部入りの利得に対する割合）と、どちらにも当てはまらなかった。資料Dの条件では 90 ns先で割合が効くことが分かっている（K71：割合だけの利得は全部入りの 0.973、平均だけは 0.772）。強い土台でも割合の前半と後半がどうなるかを見る。
- 状態: 完了。**前半 0.710 / 0.683、後半 0.575 / 0.540（合算 / タンパク質ごとの平均、全部入りの利得に対する割合）と、読み方のどちらにも当てはまらなかった。** 分母を全部の割合の利得にしても、前半 0.664 / 0.662、後半 0.537 / 0.524 と、どちらにも当てはまらない。タンパク質ごとでは「今の状態」7、「続いている状態」9、どちらでもない 56、利得が小さく判定から外したもの 28 である。

## 1. 何を確かめる実験か

強い土台（未見 100 タンパク質×3 レプリカ）の条件で、水素結合の形成、90 ns先、割合だけ。割合は、ペアが境界（3.5 Å）より近い時間の割合である。静的な特徴量に、つぎのどれか 1 つを足した形で比べる。

- 前半（フレーム [0..4]）の割合
- 後半（フレーム [6..10]）の割合
- 前半と後半の両方（2 つの割合を並べたもの）
- 全部（フレーム [0..10]）の割合

読み方は結果を見る前に固定した（K2-01 と同じ）。

- 割合の分母は全部入りの利得（静的＋実履歴 10 特徴の利得）を主とし、あわせて全部の割合の利得に対する割合も記録する（分母の確認のため）。
- 後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。
- 合算とタンパク質ごとの平均で判定が分かれる場合は、両方を記録する。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録する。

## 2. 条件

- 土台は強い土台（G81・G86・G141 の土台、K06(b) の条件）。凍結した本体モデル T1I2006 + HistGradientBoosting の補正モデル（160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）。較正タンパク質 8つ（13,808行）で学習し、未見の100タンパク質×3レプリカ（163,074行、テスト陽性 13,068件）で評価する。起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 90 ns先。
- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`）をそのまま使った。作り直した系列から導いた要約値は保存値と 1e-05 Å 未満で一致することが G05 で 108タンパク質すべてで確かめてある。
- 実行はローカルVM（6 条件の学習で 2 分ほどで終わったため、Colab には逃がしていない）。
- sklearn の学習はスレッド数を1に絞った（OMP_NUM_THREADS=1 など）。

### 前半と後半の定義（K2-01 と同じ）

| 名前 | フレーム | 時刻の範囲 |
|---|---|---|
| 前半 | [0..4] | 0〜0.4 ns |
| 後半 | [6..10] | 0.6〜1.0 ns |
| 全部 | [0..10] | 0〜1.0 ns |

**フレーム 5（0.5 ns）は前半にも後半にも入らない設計である**（K2-01 と同じ）。

### 実行の記録（やり直し）

最初の実行は、実行前の確認で止まった。保存された実履歴 10 特徴の列 [5] が 3.5 Å 以下の割合だと思って照合したが、最大の差が較正 13.9、テスト 20.7 と大きく、照合に失敗した。原因は列の並びの取り違えで、強い土台の実履歴 10 特徴は [最初, 平均, 標準偏差, 最小, 最大, 最後−最初, ?, 3.5 Å以下割合, 4.5 Å以下割合, ?] の並びである。1a62_A で確かめたところ、3.5 Å 以下の割合は列 7 で、系列から計算した割合と最大の差 2.71e-08 で一致した。スクリプトを列 7 に直して実行し直したところ、実行前の確認は最大の差 0.00e+00 で通り、以下の結果を得た。列の並びの記録はスクリプトの注釈にも残してある。

## 3. 結果

### 土台の再現

90 ns先で静的のみ AUPRC 0.4418 / 0.4357（合算 / タンパク質ごとの平均）、全部入り 0.4683 / 0.4630、利得 +0.0265 / +0.0273 で、k06b_results.json の記録と小数第4位まで一致した。テスト陽性も 13,068件で一致した。results.json と実行スクリプトの horizon_ns は 90 である。

### 条件ごとの AUPRC と利得と割合（テスト合算 / タンパク質ごとの平均、90 ns先）

| 条件 | AUPRC（合算） | AUPRC（マクロ） | 利得（合算） | 割合（対 全部入りの利得、合算 / マクロ） | 割合（対 全部の割合の利得、合算 / マクロ） |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.4418 | 0.4357 | ― | ― | ― |
| 全部入り（10 特徴） | 0.4683 | 0.4630 | +0.0265 | 1.000 / 1.000 | 0.935 / 0.969 |
| 前半の割合だけ | 0.4606 | 0.4543 | +0.0188 | 0.710 / 0.683 | 0.664 / 0.662 |
| 後半の割合だけ | 0.4570 | 0.4504 | +0.0152 | 0.575 / 0.540 | 0.537 / 0.524 |

### タンパク質ごと（テスト 100 タンパク質）

タンパク質ごとの形の数え上げ（全部入りの利得が 0.01 を超えるものだけを分類、K2-07 と同じ）：**「今の状態」7、「続いている状態」9、どちらでもない 56、利得が小さく判定から外したもの 28** である。タンパク質ごとの割合の中央値は、前半 0.621、後半 0.276（対 全部入りの利得）で、後半の中央値は合算の 0.575 よりずっと小さい。タンパク質ごとの割合の平均は、前半 −27.68、後半 +2.46 と、利得の小さいタンパク質で割合が大きくぶれるため、平均はあてにならない（K2-80 でも同じ形であった）。

## 4. 先に固定した読み方への答え

前半 0.710 / 0.683、後半 0.575 / 0.540 と、**合算でもタンパク質ごとの平均でも、読み方のどちらにも当てはまらなかった。** 分母を全部の割合の利得にしても、前半 0.664 / 0.662、後半 0.537 / 0.524 と、どちらにも当てはまらない。数値をそのまま記録する。

| 形・土台 | 前半の割合（合算 / マクロ） | 後半の割合（合算 / マクロ） | 読み方 |

強い土台でも資料Dの条件でも、90 ns先の割合の前半と後半はどちらにも当てはまらない。ただし、強い土台では全部の割合だけの利得が全部入りを上回った（1.069 / 1.032）のに対し、資料Dの条件では全部の割合だけは 0.4213 と全部入り（0.4246）をわずかに下回った。資料Dの条件で 90 ns先の割合が効く（K71：割合だけの利得は全部入りの 0.973）という形は、強い土台では全部の割合だけの利得が 1.069 と、さらに強く出た。**前半と後半に分けると、どちらの土台でもどちらにも当てはまらない。**
