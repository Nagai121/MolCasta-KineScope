# G36: 接触の形成で、5 ns 先の混合は足しになるか（資料Dの条件、接触の形成、5 ns先）

- 確かめること: 接触の混合は 1 ns 先では 0.1 ns の切り取りで第11〜13案が +0.070〜+0.097 だったが、5 ns 先はまだ測っていない。
- 状態: 完了。第11案だけが混合の上がり幅 +0.057 で +0.05 の線を超え、第12〜14案は下回った（+0.019／−0.035／−0.007）。先に固定した読み方に照らすと、接触の混合は 5 ns 先でも足しになる案があるが、効き目は弱く、案によって違う。

## 1. 何を確かめる実験か

条件は資料Dの接触の形成、5 ns先。0.1 ns（フレーム [0,1]）の切り取り平均だけと、K17 の残基レベル生成平均（第11〜14案）を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.2322（K13 の 5 ns先と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がる案があれば、接触の混合は 5 ns 先でも足しになることになる。どの案も +0.05 未満なら、接触の混合は 1 ns 先に限られることになる。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 15,926件・テスト 7,384件（5 ns先の陽性 214件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 5 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。
- 実履歴側は K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の `{protein}_R{rep}_contact.npz`、静的特徴5個・11フレームの履歴・ラベル）を使い、生成平均側は K17 の出力（`~/workspace/k17/out/{protein}_R{rep}.npz` の `gen11`〜`gen14`、残基レベルの生成系列の分岐平均・9点系列の平均）を使った。K17 のファイルに保存されている実履歴側が K13 のキャッシュと配列として完全一致することを、実行時に確かめてから位置で対応付けた。生成器のチェックポイントの読み込みや、新しい軌道の取得・生成はしていない。
- 接触の履歴6統計量は bound 4.5 Å（1 ns先の G13 と同じ）。切り取り平均はフレーム [0,1]（0.1 ns）の平均。
- 条件: 静的のみ／履歴全部入り（参照）／切り取り平均だけ（0.1 ns）／生成平均だけ（第11〜14案）／混合（切り取り平均＋生成平均、第11〜14案）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.2322）。

## 4. 読み取り

先に固定した読み方に照らすと、第11案だけが +0.057 で +0.05 の線を超えたため、接触の混合は 5 ns 先でも足しになる案がある、というのがこの測定の結論。ただし第11案の +0.057 は線をわずかに超えただけで、第12案は +0.019、第13案は −0.035、第14案は −0.007 と、他の3案はすべて下回った。1 ns先では第11〜13案が +0.070〜+0.097 とそろって線を超えたのに対し、5 ns先では効き目は第11案に限られ、弱くなっている。

生成平均だけでは 4案すべてがマイナス（−0.054〜−0.092）で、生成平均そのものは 5 ns先のラベルを単独では当てられない。それでも第11案の混合が切り取り平均だけを上回るのは、生成平均が切り取り平均の誤差を少しだけ打ち消す向きに働くためとみる。AUPRC の絶対値で見ると、第11案の混合の上がり幅は +0.0132（0.4490 に対して 0.4358）と小さい。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の混合は 5 ns 先でも第11案だけが +0.05 の線を超え、1 ns 先に限られるわけではない。ただし効き目は弱く（+0.057）、第12〜14案では出ない。接触の混合の効き目は予測幅が伸びると弱まり、案によって違う。
- まだ分からないこと: 第11案だけが 5 ns 先でも効く理由。第12・13案が 1 ns 先では効いたのに 5 ns 先では効かない理由。0.5 ns の切り取りにすれば 5 ns 先の混合が強まるか（水素結合の G30・G32 のように）。
