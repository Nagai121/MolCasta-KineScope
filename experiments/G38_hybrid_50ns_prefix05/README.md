# G38: 50 ns 先で、0.5 ns の切り取りに生成した平均を足すとどうなるか（資料Dの条件、水素結合の形成、50 ns先）

- 確かめること: G32 では 30 ns 先で +0.475、G30 では 90 ns 先で +0.098 だったが、そのあいだの 50 ns 先はまだ測っていない。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、50 ns先。0.5 ns（フレーム [0〜5]）の切り取り平均だけと、第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.0739（K06(a) の 50 ns先と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、50 ns 先でも切り取りを長くすれば混合が足しになることになる。+0.05 未満なら、50 ns 先では切り取りを長くしても混合は足しにならないことになる。
