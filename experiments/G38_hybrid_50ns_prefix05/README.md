# G38: 50 ns 先で、0.5 ns の切り取りに生成した平均を足すとどうなるか（資料Dの条件、水素結合の形成、50 ns先）

- 確かめること: G32 では 30 ns 先で +0.475、G30 では 90 ns 先で +0.098 だったが、そのあいだの 50 ns 先はまだ測っていない。
- 状態: 完了。混合の回復率は 1.296 で、切り取り平均だけ（1.266）より +0.030 しか上がらなかった。50 ns 先では、切り取りを長くしても混合は足しにならない。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、50 ns先。0.5 ns（フレーム [0〜5]）の切り取り平均だけと、第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.0739（K06(a) の 50 ns先と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、50 ns 先でも切り取りを長くすれば混合が足しになることになる。+0.05 未満なら、50 ns 先では切り取りを長くしても混合は足しにならないことになる。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（50 ns先の陽性 325件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 50 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。
- K01 のキャッシュ（18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。
- 生成平均の出所: K05 の `generated_series.npz`（第22案の5点系列）。生成5点 = [起点距離 d0（フレーム10、1 ns）、+0.1、+0.3、+0.5、+1.0 ns] の前方系列。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は G11 と同じ水準（1e-06 Å 未満）だった。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列。両者は起点距離 d0 を共有するが時間の向きが逆（K09 と同じ留保）。平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しない（平均の列だけを使うため）。
- 条件: 静的のみ／履歴全部入り（参照）／切り取り平均だけ（0.5 ns）／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.0739）。

## 3. 結果

### 土台の再現

50 ns先で静的のみ AUPRC 0.3342、全部入り 0.4081、利得 +0.0739 で、K06(a) の記録と小数第4位まで完全一致した。

### 50 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.3342 | 0.8613 | 0.0522 | 0.1854 | 0.000 |
| 全部入り（実履歴） | 0.4081 | 0.8969 | 0.0488 | 0.1703 | 1.000 |
| 切り取り平均だけ（0.5 ns） | 0.4278 | 0.8904 | 0.0480 | 0.1689 | 1.266 |

## 4. 読み取り

先に固定した読み方に照らすと、混合の回復率は切り取り平均だけより +0.030 しか上がらなかったため、50 ns 先では切り取りを長くしても混合は足しにならない、というのがこの測定の結論。

50 ns先の形は、30 ns先・90 ns先とは逆向きで目を引く。30 ns先と 90 ns先では、切り取りを 0.1 ns から 0.5 ns に伸ばすと混合の上がり幅が大きくなった（+0.489→+0.475 でほぼ同じ／+0.015→+0.098）が、50 ns先では 0.1 ns の切り取りで +0.371 あった上がり幅が、0.5 ns の切り取りでは +0.030 まで縮んだ（G39）。理由として自然なのは、0.5 ns の切り取り平均だけですでに回復率 1.266 と全部入りを大きく上回っており、生成平均が足す余地がほとんど残っていないこと。0.1 ns の切り取りだけでは回復率 0.745 と全部入りに届かないため、生成平均の足しが大きく出る。50 ns先では、混合の価値は切り取りが短いときにあり、切り取りを長くすると切り取り平均だけで十分になる。

生成平均だけでも 50 ns先では回復率 0.435 と、1 ns先の 0.093、30 ns先の 0.294 より強い。生成平均が持つ情報は予測幅が長いほど相対的に強くなるが、切り取り平均がさらに強いため、混合の上がり幅としては出てこない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 50 ns先では、0.1 ns の切り取りに生成平均を足すと +0.371 と大きく上がる（G39）が、0.5 ns の切り取りに足しても +0.030 とほとんど上がらない。切り取りを長くすれば混合が足しになる、という絵は 50 ns先では成り立たない。混合の効き目は予測幅ごとに違い、切り取りの長さとの組み合わせでも変わる。
- まだ分からないこと: 5 ns先の混合の効き目（0.1 ns・0.5 ns の切り取りとも未測定）。50 ns先で 0.25 ns の切り取りにすれば混合の上がり幅がどうなるか。強い土台（K06(b)）の 50 ns先でも同じ形か。
