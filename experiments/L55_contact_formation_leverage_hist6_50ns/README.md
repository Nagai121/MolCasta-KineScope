# L55: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（統計量6種の形、資料Dの条件、接触の形成、50 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の実験。L19（平均だけの形）と同じ土台・同じ覆う長さで、切り取りの履歴の特徴量を平均だけから資料Dの6統計量に変えて、接触の形成の 50 ns先の曲がりを測る。
- 状態: 完了。統計量6種では、回復率 0.8 に届く最小の長さは覆う長さ 0.1 ns、0.9 に届く最小の長さは 0.3 ns。平均だけ（L19）ではどちらにも届かなかった予測幅で、L51〜L56 の中でいちばん早く 0.8 に届く。増え幅がいちばん大きいのは 0.6→0.7 ns（+0.1553）。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L19 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの6統計量」を履歴の特徴量として資料Dの条件のモデルに入れたときの 50 ns先の利得の回復率を測る。同じ実行の中で平均だけの曲がりも測り直し、L19 の記録と一致するか確かめる。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、全体で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの条件の流儀で、全体・1mix_A・2qt4_A の3つの回復率の最小値〜最大値とする。
4. 段らしい場所があれば、その前後でタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録する）。

あわせて、平均だけと比べて必要な長さが縮んだか、届かなかった予測幅で届くようになったかを記録する。

## 2. 条件

- 土台は資料Dの条件（接触の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 7,384件（テスト陽性 250件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 50 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。候補と距離の定義は G 系列の接触の形成の記録に合わせた（残基ペアの最小重原子間距離、接触の閾値 4.5 Å）。
- K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/` の接触の形成の候補ごとの最小重原子間距離の 11 フレーム系列）を再利用した。実行はローカルVM（24条件の学習で約40〜60秒。L 系列では重い計算は Colab に逃がす決め事があるが、この規模は重い計算にはあたらないと判断した）。sklearn の学習はスレッド数を 1 に絞った。

### 長さの呼び方（L01・L19 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の全部）。

### 条件の一覧（50 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの6統計量: 静的特徴＋切り取りの6統計量（最初・平均・標準偏差・最小・最後−最初・4.5 Å以下の割合）。覆う長さ 0.0〜1.0 ns の11通り。覆う長さ 1.0 ns では全部入りと同じ条件になり、回復率は 1 になります。
- 切り取りの平均だけ（照合用）: L19 と同じ条件を測り直したもの。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.1 ns**（全体 0.8103）。平均だけ（L19）では 0.8 に届かなかった（最大 0.7481）ので、新たに届くようになりました。L51〜L56 の中でいちばん早い到達です。覆う長さ 0 ns でも 0.7965 と線のすぐ下にあります。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.3 ns**（全体 0.9512）。平均だけでは届かなかった線です。
3. **増え幅がいちばん大きい場所: 0.6→0.7 ns（+0.1553）**。次に大きいのは 0.4→0.5 ns（+0.1543）です。増え幅は中ほど以降に分散し、負の区間も 3 つあります。

### タンパク質ごとの値

タンパク質ごとの回復率は、そのタンパク質の中での全部入りの利得を分母にして出した。全部入りの利得は 1mix_A が +0.1497（静的のみ 0.3089、全部入り 0.4586）、2qt4_A が +0.3399（静的のみ 0.1789、全部入り 0.5188）で、2qt4_A の利得のほうが大きい。

段の位置（0.6→0.7 ns）でのタンパク質ごとの回復率は、1mix_A が 0.8355 → 0.9887（+0.1532）、2qt4_A が 0.8680 → 0.8986（+0.0306）で、どちらも正です。大きさは 1mix_A のほうが大きいですが、符号は一致します。

### 平均だけとの比較

- 平均だけ（L19）との比較: 平均だけではフレーム 0 だけの 0.7470 がほぼ最大で、0.1 ns に落ち込み（0.5010）があり、どの長さでも 0.8 に届きませんでした。6 種では、その落ち込みが消え（0.1 ns で 0.8103）、0.3 ns で 0.9 の線にも届きました。平均だけの 0.1 ns の落ち込みは、フレーム 1 を平均に混ぜることの悪さで、6 種では標準偏差や最小などがそれを補う形です。
- 同じ長さで比べると、6 種の回復率は平均だけを全長さで上回ります（0.5 ns で 1.0043 対 0.6333、0.8 ns で 0.9953 対 0.6739 など）。

## 4. 読み取り

- 接触の形成の 50 ns先は、平均だけと 6 種で曲がりの形が最も大きく変わった予測幅です。平均だけでは「長くしても戻らない」形でしたが、6 種では 0.1 ns で 8 割、0.3 ns で 9 割が戻ります。
- ただし 6 種でも曲がりは単調ではなく、0.5 ns で 1.0043、0.6 ns で 0.8344、0.7 ns で 0.9897 と上下します。線への到達は早い一方、水準は長さごとに振れます。

## 5. 読みの注意点

- テストは 2タンパク質だけの土台なので、区間（3値の最小〜最大）は粗く、タンパク質ごとの分かれ方が一般の形かは、この実験だけでは決められません。
- 実測の費用への換算はしていません。分母はシミュレーションの長さ（ns）です。
