# G72: 解離で、6 個の統計量の切り取りでも長い予測幅での回復率を測る（資料Dの条件、水素結合の解離、5・10・30・50・90 ns先）

- 確かめること: G70 は平均だけの切り取りで長い予測幅を測った（0.5 を超える最小の切り取りは全予測幅で 0.1 ns）。6 個の統計量を入れた切り取りではどうか。
- 状態: 完了。全体で見た回復率 0.5 を超える最小の切り取りは、5・10・30・50 ns先で 0.1 ns、90 ns先で 0.25 ns。タンパク質ごとの平均では全体と同じ形だが、1つ1つで見ると 5 ns先の 2qt4_A（0.1 ns で 0.498）、30 ns先の 1mix_A（0.1 ns で 0.454）、50 ns先の 2qt4_A（0.25 ns で 0.277）は 0.5 に届かず、90 ns先の 1mix_A の 0.1 ns は −0.985 と負になる。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の解離。予測幅は 5・10・30・50・90 ns、切り取りは 0.1・0.25・0.5 ns で、6 個の統計量を入れたときの回復率を測る。土台の利得は K46 の各予測幅の記録値。

読み方は先に固定した。各予測幅で、回復率 0.5 を超える最小の切り取りを出す。タンパク質ごとの回復率も記録する。

## 2. 条件

- 土台は資料Dの条件（水素結合の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 4,051件・テスト 2,080件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴7個。キャッシュは `~/workspace/kinescope/work/data_cache_k46/`（解離の候補）。
- 6 統計量の定義は G48 と同じ形で、境界は解離の 3.5 Å：[最初, 平均, 標準偏差, 最小, 最後−最初, 3.5 Å以下割合] を切り取りのフレームで計算する。切り取りは 0.1 ns = フレーム [0,1]、0.25 ns = フレーム [0,1,2]、0.5 ns = フレーム [0,1,2,3,4,5]。
- 条件: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取りの 6 統計量（0.1・0.25・0.5 ns）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。土台の静的のみ・全部入りの AUPRC は、K46 の記録値と小数第4位まで一致することを各予測幅で確かめた。
- タンパク質ごとの回復率の定義は G48・G66 と同じ：テストのタンパク質それぞれ（3レプリカを合算）について、静的のみ・全部入り・切り取りの AUPRC を出し、回復率 =（切り取り − 静的のみ）÷（全部入り − 静的のみ）で、そのタンパク質自身の利得を分母にする。陽性が 0件・全件のタンパク質と、利得の絶対値が 0.01 以下のタンパク質は回復率を出さない。解離のテストは 1mix_A と 2qt4_A の 2タンパク質だけなので、タンパク質ごとの表は 2行になる。平均と中央値の両方を出すが、2タンパク質しかないため平均は 2つの値の平均にすぎない点に注意する。
- 注意: K46 のキャッシュの `hist` は (11, n) の並びで保存されているため、読み込み時に転置して (n, 11) に直した（G70 と同じ）。

## 4. 読み取り

先に固定した読み方に照らすと、全体で見た回復率 0.5 を超える最小の切り取りは、5・10・30・50 ns先で 0.1 ns、90 ns先で 0.25 ns。タンパク質ごとの平均では、5・10・30・50 ns先で 0.1 ns、90 ns先で 0.25 ns と、全体と同じ形になる。ただし1つ1つで見ると、5 ns先の 2qt4_A（0.1 ns で 0.498）、30 ns先の 1mix_A（0.1 ns で 0.454）、50 ns先の 2qt4_A（0.25 ns で 0.277）は 0.5 に届かず、90 ns先の 1mix_A の 0.1 ns は −0.985 と負になる。解離では 6 統計量の切り取りでも、90 ns先を除いて 0.1 ns で 0.5 を超える。平均だけ（G70）では 90 ns先でも 0.1 ns で 0.709 と線を超えたのに対し、6 統計量では 90 ns先の 0.1 ns が 0.183 まで落ち込む。90 ns先の短い切り取りでは、6 統計量の側の情報（標準偏差・最小・3.5 Å以下割合など）が平均だけの邪魔をする形。

90 ns先の 0.1 ns だけは、タンパク質ごとに見ても 1mix_A が −0.985、2qt4_A が +0.429 と向きが違う。全体の 0.183 は 1mix_A の落ち込みに引っ張られている。90 ns先の 0.25 ns では 1mix_A が 1.330、2qt4_A が 0.671 と両方とも 0.5 を超えるため、90 ns先では 0.25 ns まで延ばせば 6 統計量でも戻る。

## 5. 判断できること・まだ分からないこと

- 判断できること: 解離では、6 統計量の切り取りでも 5・10・30・50 ns先で 0.1 ns が 0.5 を超え、90 ns先では 0.25 ns が要る。全体とタンパク質ごとの平均は全予測幅で一致する。90 ns先の 0.1 ns だけは 6 統計量が平均だけより大きく弱く、タンパク質によって向きも違う。
- まだ分からないこと: 90 ns先の 0.1 ns で 6 統計量が弱くなる理由と、1mix_A で −0.985 まで落ち込む理由。解離の 1 ns先（G40・G43 の形成との比較）の 6 統計量と長い予測幅での形が同じ原因か。
