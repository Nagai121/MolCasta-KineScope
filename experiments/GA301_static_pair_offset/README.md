# GA301 静的構造からペアごとの過去平均距離を予測

KineScope Issue #1を受け、起点だけを入力し、同じ原子ペアの起点前1 nsの実測平均を教師とする。GA01〜GA300（InternalResearchの静的生成探索）に続く、24条件を含む実験。判定基準は誤差の標準偏差0.30 Å以下、続いて強い本体の未見100配列×3レプリカで指導力50%以上。評価前に受領した基準を用いた。

## 条件と既存実験からの変更

- 水素結合形成の6 Å ROD候補、凍結T1I2007。学習20、検証3、評価8配列。すべてR1。学習は各配列1起点、検証は各3起点、評価は6配列×3起点と2配列×2起点。候補数は10,222／4,820／9,843。配列IDで分割し、評価側はモデル選定に使わない。このパネルは既存T2Iでも使用済みで、完全に新規の外部データではない。KineScope資料Dの1mix_A・2qt4_A、1 ns固定起点とは異なる。
- 教師は過去100〜1,000 psの各100 psの距離10点と起点距離1点の単純平均。分子座標から距離特徴を計算するのは起点構造のみ。ATLAS実履歴は教師と評価値の作成に使う。生成MD、座標の時系列、予測起点以降のMDを入力しない。
- 起点距離、凍結確率、元素、3構造特徴をRidge基準とした。学習ペアの残差は配列を1つずつ外して計算。評価側は学習20配列で固定したRidgeを用いた。構造特徴、静的な仮想接近・迂回、原子周辺の応答特徴を拡張候補として、4入力×深さ3×直接または残差学習の24条件をXGBoost CUDAで学習しCPUで評価。検証で誤差の標準偏差が最小の1条件を確定。
- 報告する残差相関は「予測平均−Ridge対照」と「実測平均−Ridge対照」の評価候補全体のPearson相関。予測誤差SDとは異なる。

## 実測

| 評価8配列 | 誤差SD Å | RMSE Å | 対照からの残差相関 |
| --- | ---: | ---: | ---: |
| 起点距離 | 0.560505 | 0.579942 | −0.03045 |
| 静的Ridge | 0.533715 | 0.533925 | 定義不可 |
| 選定した combined-4-residual | 0.504069 | 0.504214 | 0.33278 |

選定モデルの検証SDは0.607058 Å。評価側では基準Ridgeから0.02965 Å改善したが、第1段の0.30 Åを満たさない。第2段の未見100配列×3レプリカは未実施で、指導力の回復率は未測定。既報G01の0.4739 ÅやK23のレプリカ間差0.249 Åとは本評価条件が異なる。特徴を増やしたときの残差予測の手掛かりを測った事前比較として扱う。

## 再現

InternalResearch 3991c68808c9b59bede62409332f4602128094f0 の research/tseries-exploration-20261121 を作業フォルダにし、ga_static_offset.py を t2i/ に置く。既存のMiniTopol ATLAS・凍結T1重み・依存関係を用意し、python -m t2i.ga_static_offset を実行する。24個の学習済みUBJ、Ridge係数、評価側の候補ID・観測値・予測値と実測JSONを保存した。

## 残差予測の目標

次のGA探索では、同じ候補ペアについて、静的基準を引いた予測平均と実測平均のPearson相関 **0.500以上** を目標とする。GA301の評価値は0.33278。比較では静的基準、ペア整列、評価集合を揃え、探索に使った検証配列と最終評価配列を分ける。評価条件を変更する場合は変更点を明記する。既存の誤差SD 0.30 Å以下と指導力回復率50%以上も別指標として記録する。
