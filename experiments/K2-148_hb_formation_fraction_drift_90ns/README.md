# K2-148: K2-15 の問い（漂い）を割合で測る（水素結合の形成、90 ns先）

- 確かめること: 資料Dの条件で、水素結合の形成の 90 ns先で、割合の漂い（前半の割合 − 後半の割合）が足しになるかどうかを測る。平均の漂いの地図は 90 ns先で 6 通りすべて埋まっているが、割合の漂いはまだどの予測幅でも測っていない。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-15 の問い（漂い）を、割合で測る。漂いは、前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）である。割合は、ペアの距離が水素結合の閾値（3.5 Å）以下の時間の割合で、6 個の統計量のうちの「3.5 Å 以下だった割合」と同じ定義である。平均の漂いでは、90 ns先の水素結合の形成は K2-68・K2-85 の系列で測り終えている。ここでは、割合の漂いを 90 ns先で測る。

比べる条件は K2-15 と同じく先に固定した。静的な特徴量に、つぎのどれか 1 つを足した形で比べる：全部（フレーム [0..10]）の割合だけ、全部の割合＋漂い。土台の再現は水素結合の形成の 90 ns先の記録（K2-14・K71）と照らす。

読み方は K2-15 と同じく先に固定した。全部の割合＋漂いが全部の割合だけを AUPRC で +0.01 以上上回れば「漂いが足しになる」、そうでなければ「足しにならない」とする。タンパク質ごとの (c)−(b) の差も記録する。
