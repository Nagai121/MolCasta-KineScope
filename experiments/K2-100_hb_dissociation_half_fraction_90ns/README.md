# K2-100: K2-14 の問い（割合の前半と後半）を水素結合の解離の 90 ns先で測る

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。形成では割合の前半と後半を測り終えました（K2-14、90 ns先は前半 0.816・後半 0.676）。解離では割合の形はまだ測っていません。ここでは解離の 90 ns先で割合の形の前半と後半を測ります。

割合は、ペアが境界（3.5 Å）より近い時間の割合です。解離の候補は起点で 3.5 Å 以下のペアで、ラベルは 90 ns先で 3.5 Å を超えたかどうかです。割合の境界は形成と同じ 3.5 Å です。

読み方は K2-01 と同じく先に固定しました。割合の分母は全部入りの利得を主とし、あわせて全部の割合の利得に対する割合も記録します。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録します。

- 後半の利得が全部入りの 8 割以上で、前半が 5 割以下なら「今の状態が効いている」。
- 前半も後半も 8 割以上なら「続いている状態が効いている」。
- どちらでもなければ、数値をそのまま記録する。

## データと条件

- 資料Dの条件（水素結合の解離、90 ns先）です。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（4,051件）、テスト 1mix_A＋2qt4_A（2,080件、テスト陽性 413件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最少 15件、L2 0.02、seed 42）を条件ごとに学習し直しました。キャッシュは `~/workspace/kinescope/work/data_cache_k46/`（解離の候補ごとの距離系列）を使っています。静的特徴は 7 個です。
- 実行はローカルの仮想マシンで行いました（6 条件の学習で約 13 秒。K2 系列では重い計算は Colab に逃がす決め事がありますが、この規模は重い計算にはあたらないと判断しました）。sklearn の学習はスレッド数を 1 に絞りました。

### 条件の一覧（90 ns先）

- 静的のみ: 静的特徴 7 個だけ（土台の照合用）。
- 全部入り: 静的特徴＋実履歴 6 統計量（0〜1 ns の 11 フレーム）。6 個の統計量は [最初, 平均, 標準偏差, 最小, 最後−最初, 3.5 Å 以下の割合]（資料Dの D6 と同じ定義）。割合の分母（全部入りの利得）の参照。
- 前半の割合だけ: 静的特徴＋前半（フレーム [0..4]、0〜0.4 ns）の 3.5 Å以下割合。
- 後半の割合だけ: 静的特徴＋後半（フレーム [6..10]、0.6〜1.0 ns）の 3.5 Å以下割合。
- 前半と後半の両方（割合だけ）: 静的特徴＋前半の割合＋後半の割合。
- 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の 3.5 Å以下割合。

フレーム 5（0.5 ns）は前半にも後半にも入らない設計です。K2-01 と同じ分け方で、前半と後半をきれいに分けるためです。

## 判断

先に固定した読み方に沿うと、**前半 1.307、後半 0.909（全部入りの利得に対する割合）で、前半も後半も 8 割以上なので、「続いている状態が効いている」と記録します**。

ただし、**分母を全部の割合の利得にすると、前半 1.048、後半 0.728 で、後半が 8 割を下回るため、どちらにも当てはまらず、数値をそのまま記録します**。判定が分母で変わります。90 ns先の形成（K2-05）でも同じことが起きていました（分母を全部の平均の利得にすると「続いている状態」に当てはまる）。

90 ns先の形成（K2-14）では前半 0.816・後半 0.676 と、どちらにも当てはまりませんでした。解離の 90 ns先では、前半も後半も全部入りを上回ります（前半 1.307、後半 0.909）。形成と解離で形が違います。

## 読みの注意点

- 90 ns先は土台の利得が小さい（+0.0679）ため、割合の読みは大きく出やすく、AUPRC の差の絶対値と併せて見るべきです。AUPRC の差の絶対値では、前半と全部入りの差は +0.0208、後半と全部入りの差は −0.0062 です。
- 判定が分母で変わります。分母を全部入りの利得にすると「続いている状態が効いている」ですが、分母を全部の割合の利得にするとどちらにも当てはまりません。分母を全部の割合の利得にすると、後半は 0.728 と 8 割を下回ります。
- タンパク質ごとの割合は、タンパク質ごとの利得が小さいと不安定になります。2 タンパク質の土台では一般の形かは決められません。
