# L63: L01 の曲がりを塩橋の形成で測る（統計量6種、K15 の土台、1 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L27（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）に変えた曲がりです。塩橋の統計量6種の担当分（形成 L63〜L68、解離 L69〜L74）の最初です。
- 状態: 完了。統計量6種の回復率（全体）は平均だけより中間の長さで低く出ることが多く、0.8 と 0.9 の線に届く最小の長さはどちらも 0.8 ns で、平均だけ（0.3 ns）より長くなりました。必要な長さは縮みませんでした。

## 1. 何を確かめる実験か

覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で、その範囲の距離系列から計算した統計量6種を入れたときの回復率を測ります。覆う長さ 1.0 ns の6種は全部入りと同一の特徴量なので、回復率は 1.0 になります。読み方は先に固定しました。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の形成側（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 2,557件、テスト 1,170件、1 ns先の陽性 93件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.8 ns（全体 0.921）**。平均では 0.5 ns（1.015）。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.8 ns（全体 0.921）**。平均では 0.5 ns。
3. **増え幅がいちばん大きい場所: 0.7→0.8 ns（全体 +0.410、平均 +0.589）**。段の位置でのタンパク質ごとの増え分は中央値 +0.319、正だったのは 18タンパク質のうち 67% でした。ただし最大値は +32.0 と、利得の小さいタンパク質の跳ねが混じっています。
4. **平均だけとの比較: 必要な長さは縮みませんでした。** 0.8 の線も 0.9 の線も、平均だけでは 0.3 ns で届いたのに対し、統計量6種では 0.8 ns が必要で、0.5 ns 分長くなりました。長さごとの回復率の差（6種 − 平均、全体）は 0.3 ns で −0.391、0.7 ns で −0.390 と、中間の長さで6種が大きく下回ります。0 ns では両者は一致します（フレームが1つだけだと6種はその値の決まった変換になるため）。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 1 ns先の形成では、短い切り取りに統計量を増やすことは助けにならず、むしろ中間の長さで平均だけより悪くなりました。候補数が少ない（テスト 1,170件）中で特徴量を増やした分、学習が不安定になっている形と読めます。
- 平均だけの曲がり自体も 0.3 ns で 0.963 のあと 0.4 ns で 0.545 に落ちる振動があり（L27）、6種の曲がりの振動もその範囲内です。区間は広く、長さの順序は決められません。
