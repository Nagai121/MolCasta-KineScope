# GA392 後続起点を74学習配列へ拡張

GA386の後続24配列に50配列を追加。追加分は149・249の2起点、AmberとCHARMMを各2分岐で生成した。保存した距離キャッシュは200件。読み出しのCUDA学習は74配列の先頭41,376ペアと後続82,987ペアを使用し、推論はCPUで実施した。

検証3配列・9起点・4,820候補で選んだ設定は、後続学習の重み4倍、40エポック、GA348への固定混合35%。残差Pearson相関は全体0.615994、先頭0.667649、後続0.600755。従来のGA386は順に0.615022、0.666611、0.600048。GA392の確認パネルは未採点。

再現するには生成キャッシュとlane別マニフェストを作業フォルダのruns/ga392に配置し、既存のGA365とGA385の学習キャッシュおよびGA360の検証キャッシュを用意する。生成はpython -m t2i.ga392にlane番号0〜2を渡す。読み出しはpython -m t2i.ga392_readoutを実行する。
