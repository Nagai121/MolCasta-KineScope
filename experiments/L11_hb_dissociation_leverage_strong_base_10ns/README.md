# L11: L01 の曲がりを強い土台で測る（K75 の条件、水素結合の解離、10 ns先）

- 確かめること: 「短い実MDを安くする」経路の L 系列の続き。L02（水素結合の形成、強い土台、1 ns先）と同じ方法で、水素結合の解離の 10 ns先で、短い実MDの覆う長さに対して回復率がどう伸びるかを測る。L01（資料Dの条件、テスト 2タンパク質）で見えた覆う長さ 0.6 ns の段が、強い土台（未見100タンパク質×3レプリカ）でも残るかを判定する。
- 状態: 完了。**曲がりは滑らかで、0.6 ns の段は残らなかった。** 増え幅がいちばん大きいのは最初の 0→0.1 ns（全体 +0.234）で、0.5→0.6 ns の増え分は +0.049 にすぎない。回復率 0.8 に届く最小の長さは 0.2 ns、0.9 に届く最小の長さは 0.3 ns（全体・平均とも）と、6 つの予測幅の中で最も早い。回復率は 0.5 ns 以後 1 を超え、全部の平均だけが要約値10個の全部入りを上回る。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として強い土台の補正モデルに入れたときの 10 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。

読み方は先に固定した（L02 と同じ）。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は水素結合の解離の強い土台（K75・K2-18 と同じ）。HistGradientBoosting の補正モデル（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）を較正タンパク質（6,144候補）で学習し、未見の100タンパク質×3レプリカ（76,342候補、10 ns先の陽性 14861件）で評価する。静的特徴は5個、履歴の要約値は10個（最初、平均、標準偏差、最小、最大、最後−最初、最後−直前、3.5 Å以下割合、4.5 Å以下割合、増加割合）。
- 入力は K2-18 の input_bundle.npz（静的特徴・履歴の要約値・11フレームの距離系列・ラベル）を使う。特徴量は K2-18 の系統（K75・K2-77・K2-84）と同じく float64 にそろえて sklearn に渡した。float32 のままだと 90 ns先の全部の平均だけの条件で分割が変わり AUPRC が 0.0018 ずれることを予備測定で確認したためである。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 10 ns先。条件ごとに学習し直す。
- 実行はこの仮想マシン（学習13条件とブートストラップ 10,000回）。途中結果を保存して再開できる形にし、実際にサービスの再起動で一度止まったあと、保存済みの途中結果から再開して完了した。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけ、1.0 ns はフレーム 0〜10 の11フレーム全部）。G 系列の「1.0 ns」の切り取り（フレーム [0..9]）とは違い、L01・L02 の覆う長さ 1.0 ns は11フレーム全部の平均である。起点フレーム10（1 ns）は変えず、ラベルは 10 ns先のまま。

### 条件の一覧（10 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro、100タンパク質）の両方で測る（L02 と同じまとめ方）。K75 の記録との照合用に、タンパク質×レプリカ（300群）の平均も併せて出す。

## 3. ブートストラップの段取り（結果を見る前に固定、L02 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取りを numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC を再標本化の重なり具合で重み付けして平均したもの。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

## 4. 結果

### 土台の再現

10 ns先で静的のみ AUPRC は全体 0.5730、タンパク質ごとの平均 0.5930、タンパク質×レプリカの平均 0.6007。全部入りは全体 0.6502、タンパク質ごとの平均 0.6628、タンパク質×レプリカの平均 0.6692。利得は全体 +0.0771、タンパク質ごとの平均 +0.0698 で、K75 の対角の記録（静的 0.5730／0.6007、全部入り 0.6502／0.6692、全体とタンパク質×レプリカの平均）と 5e-4 以内で一致した。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.2 ns**（全体・タンパク質ごとの平均とも）。

## 5. 読み取り

- **0.6 ns の段は残らなかった。** 最初の 0.1 ns の増え分（+0.234）が突出して大きく、あとは +0.02〜+0.10 の範囲で分散する。
- 10 ns先は解離の中で切り取りが最も早く効く予測幅で、0.2 ns で 0.8、0.3 ns で 0.9 に届く。0.5 ns 以後は回復率が 1 を超える（全部の平均だけが全部入りを上回る）ため、10 ns先の解離では「全部入りの利得」に対する回復率という読み方自体が天井に当たっている。K2-77 で測った全部の平均だけの回復率 1.098 とも一致する形である。
- フレーム0だけでも 0.528 が戻る。0.1 ns で 0.762 まで跳ねる上がり方は、L09（1 ns先）の +0.099 と比べても大きい。
- 費用の側は L01・L02 と同じくまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03 の形（G04 の実測との対応付け）で行う。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の解離、10 ns先）では、回復率 0.8 に届く最小の覆う長さは 0.2 ns、0.9 に届く最小の覆う長さは全体で 0.3 ns（タンパク質ごとの平均では 0.3 ns）。増え幅がいちばん大きいのは 0.0→0.1 ns（全体 +0.234）で、L01 で見えた 0.6 ns の段は残らなかった。水素結合の解離の強い土台では、6 つの予測幅すべてで段は残らなかった（L09〜L14）。
- まだ分からないこと: 実測の費用に直したときの形（L03 の形の換算を解離にも当てるかどうか）。曲がりの細かい上下（区間が重なる範囲のもの）が何かは、この実験では切り分けていない。
