# K34 生成の特徴量で補正モデルを学習し直すと、どこまで戻るか（強い土台、水素結合）

## 問い

弱い土台では、生成の特徴量で学習し直しても利得は実履歴の約4割しか戻りませんでした（K10）。強い土台ではどうなるか。読み出しの不一致がどれだけの割合を占めるかを確かめます。

## 前提の確認（先に書きます）

指示された条件「補正モデルを生成の特徴量（8特徴）で学習し直し、生成の特徴量で評価する」は、K06(b) で既に測られていました。K06(b) の集計コード（`eval_b.py`）は条件ごとに補正モデルを学習し直す形で、生成8特徴と生成6特徴の条件は、較正8タンパク質の生成特徴量で学習し、評価100タンパク質の生成特徴量で評価したものです。今回は、保存済みの特徴量ファイル（K06(b) の 108タンパク質分）から同じ条件を再実行し、記録値と完全に一致すること（最大差 0.0）を確認しました。学習と評価のタンパク質が重ならないことも確認しました（較正8と評価100、共通 0 件）。

そのため K34 では、指示の条件の再検証に加えて、K10 の対応のうち強い土台で欠けていた交差条件も測りました。実履歴で学習したモデルを生成特徴量にそのまま当てる条件で、これが読み出しの不一致の大きさを直接測ります。生成8特徴は実履歴10特徴と形が違うため当てられません。そこで6統計量の形をそろえました。生成6特徴は「最初・平均・標準偏差・最小値・最後−最初・3.5 Å以下の割合」で、実履歴10特徴のうち同じ6列（0、1、2、3、5、7番目）と定義が一致します。交差条件（frozen6）は実履歴の6列で学習し、生成6特徴で評価します。対照として、実履歴の6列で学習し実履歴の6列で評価する条件（history6）も測りました。

## 対象と条件

- 土台は K06(b) と同じ（凍結した T1I2006＋補正モデル、HistGradientBoosting 160本・学習率0.065・葉15・葉あたり最小20件・L2 0.15）。較正8タンパク質で学習し、未見の100タンパク質×3複製（163,074件）で評価します。
- 利得は、静的補正を基準にしたタンパク質平均（macro）の AUPRC の改善で測り、実履歴の利得に対する回復率も出します。

実履歴の利得に対する回復率：生成8は −0.08〜+0.04、生成6は −0.11〜+0.01 で、全予測幅でほぼ 0 か負でした。交差 frozen6 は −0.52〜−2.98 で、静的補正をも下回りました。対照の history6 は 0.97〜1.17 で、実履歴の利得のほぼ全部を保ちました。

改善したタンパク質の数（静的補正と比べて、100件中）：1 ns先で実履歴 95件、生成8は 40件、交差 frozen6 は 7件。90 ns先で実履歴 78件、生成8は 44件、交差 frozen6 は 2件でした。

## 結論

- 先に固定した読み方に沿うと、後者の側です。学習し直しても利得は実履歴の5割には遠く及ばず、ほぼ 0% でした。生成の特徴量自体に情報が足りていません。
- 読み出しの不一致も、強い土台で大きく出ました。実履歴で学習したモデルを生成特徴量に当てると、静的補正をも下回ります（1 ns先で回復率 −0.77、90 ns先で −2.98）。弱い土台の K10 でも交差条件は崩れましたが、強い土台では学習し直した条件（生成8・生成6）が 0% なのに対して交差条件はさらに悪い、という形です。読み出しのずれはありますが、読み出しを直しても取り戻すものがない、というのが強い土台での結論です。
- 対照の history6 が実履歴の利得のほぼ全部を保ったことから、6統計量という読み出しの形そのものは問題ではありません。実履歴の6統計量には情報があり、生成の6統計量にはそれが無い、という対比です。
- 弱い土台との対比：K10 では生成側で学習し直すと利得の約41% まで戻りましたが、強い土台では 0% 前後でした。弱い土台で生成が見せた改善は、強い土台では静的特徴に吸収される平均距離のずれの分だった、という K06(b) の読みと一致します。
