# K2-116: K2-14 の問い（割合の前半と後半）を強い土台での水素結合の形成の 50 ns先で測る

- 確かめること: 強い土台（未見 100 タンパク質×3 レプリカ）の条件で、水素結合の形成の割合（ペアが境界 3.5 Å より近い時間の割合）の前半と後半がどう違うかを、50 ns先で測る。割合の前半と後半は 1・5・10・90 ns先（K2-111・K2-113・K2-114・K2-112）で測り終えた。50 ns先ではどうなるかを見る。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-14 の問い（割合の前半と後半）を、強い土台での水素結合の形成で測る。合算の前半・後半は、1 ns先（K2-111）は 0.619・0.698、5 ns先（K2-113）は 0.687・0.437、10 ns先（K2-114）は 0.695・0.545、90 ns先（K2-112）は 0.710・0.575 で、どれもどちらにも当てはまらなかった。50 ns先の平均の前半と後半（K2-76）は前半 0.730・後半 0.581（合算）で、どちらにも当てはまらなかった。ここでは、割合の形で 50 ns先を測る。

比べる条件は K2-112 と同じく先に固定した。静的な特徴量に、つぎのどれか 1 つを足した形で比べる：前半（フレーム [0..4]）の割合、後半（フレーム [6..10]）の割合、前半と後半の両方、全部（フレーム [0..10]）の割合。土台の再現は強い土台の水素結合の形成の 50 ns先の記録（k06b）と照らす。

読み方は K2-01 と同じく先に固定した。後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。合算とマクロで判定が分かれる場合は、両方を記録する。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録する。タンパク質ごとの形の数え上げ（「今の状態」・「続いている状態」・どちらでもない・利得が小さく判定から外したもの）も K2-07 と同じく記録する。
