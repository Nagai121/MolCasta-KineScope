# L24: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、接触の解離、30 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L01（水素結合の形成、1 ns先、資料D）と同じ曲がりの測り方を、接触の解離の 30 ns先で測る。
- 状態: 完了。回復率は覆う長さ 0.3 ns で初めて 0.8 を超え（0.8061）が、0.9 にはどの長さでも届かない（最大は 0.7 ns の 0.8946）。増え幅がいちばん大きいのは最初の 0→0.1 ns（+0.0700）で、曲がりはほぼ平らに上がる。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの補正モデルに入れたときの 30 ns先の利得の回復率を測る。

読み方は先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間は資料Dの流儀で、3つの値（統合・1mix_A・2qt4_A）の回復率の最小から最大。テストは 2タンパク質だけなので区間は粗い。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383行）、テスト 1mix_A＋2qt4_A 合算（2,915行、テスト陽性 246件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 30 ns先、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、種 42）で条件ごとに学習し直す。候補は、残基対の Cα 距離が 12.0 Å 以内で配列の隔たりが 2 以上、起点フレームで最小重原子間距離が 4.5 Å 以下（K50 の定義）。ラベルは、予測幅の先で最小重原子間距離が 4.5 Å を超えるかどうか。
- K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/` の 18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う。

| 覆う長さ | フレーム | フレーム数 |
|---|---|---:|
| 0 ns | 0 | 1 |
| 0.1 ns | 0, 1 | 2 |
| 0.2 ns | 0〜2 | 3 |
| 0.3 ns | 0〜3 | 4 |
| 0.4 ns | 0〜4 | 5 |
| 0.5 ns | 0〜5 | 6 |
| 0.6 ns | 0〜6 | 7 |
| 0.7 ns | 0〜7 | 8 |
| 0.8 ns | 0〜8 | 9 |
| 0.9 ns | 0〜9 | 10 |
| 1.0 ns | 0〜10 | 11 |

覆う長さ 0 ns はフレーム0だけ、つまり履歴の最初のフレームの距離そのもの（平均を取っても値は同じ）。起点フレーム10（1 ns）は変えず、ラベルは 30 ns先のまま。

G71 の呼び方との対応は次の通り。G71 の 0.1 ns（フレーム 0, 1）= 覆う長さ 0.1 ns、G71 の 0.25 ns（フレーム 0〜2）= 覆う長さ 0.2 ns、G71 の 0.5 ns（フレーム 0〜5）= 覆う長さ 0.5 ns。

### 条件の一覧（30 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_hist6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、境界 4.5 Å）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

### 作り直しの経緯

最初の実行では、静的特徴をキャッシュの型のまま使い、切り取りの平均も型を変えずに並べたところ、土台の再現（静的のみ・全部入り）は G71・G140 と合ったが、覆う長さ 0.5 ns の回復率が G71 と合わなかった（0.7839 に対して G71 は 0.8275）。原因は入力の型の違いで、G71 は静的特徴を float64 にそろえ、切り取りの平均を float32 に落としてから並べている。統括が両方の作り方で測り直したところ、L の作り方では 0.7839 と最初の実行の値を再現し、G71 の作り方では全予測幅で G71 の記録と一致した。スレッド数の違い（1 と 2）では結果は変わらなかった。この実行では入力の作り方を G71 と同じにして回し直した。L21・L22 は、作り方を変えても照合した 3 つの長さの値は変わらなかったため、そのままの結果を使っている。

## 3. 結果

### 土台の再現

30 ns先で静的のみ AUPRC は全体 0.2756、全部入りは全体 0.5124、利得は +0.2368 で、G71・G140 の記録と小数第4位まで完全一致した。G71 と重なる長さの回復率も 5e-3 以内で一致した（覆う長さ 0.1 ns で 0.7964、0.2 ns で 0.7953、0.5 ns で 0.8275）。土台の再現に問題はない。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.3 ns**（統合 0.8061）。0.2 ns では 0.7953 と線のすぐ下にとどまる。
2. **回復率 0.9 に届く最小の長さ: どの長さでも届かない。** 統合値の最大は 0.7 ns の 0.8946 で、0.9 の線のすぐ下にとどまる。
3. **増え幅がいちばん大きい場所: 0→0.1 ns（統合 +0.0700）**。次に大きいのは 0.6→0.7 ns（+0.0502）で、増え分は全体に小さく、曲がりはほぼ平らに上がる。**1か所に段と呼べる跳ねはない。**
4. 段の位置（0→0.1 ns）では、タンパク質ごとの増え分は 1mix_A が +0.0432（0.7184 → 0.7616）、2qt4_A が +0.3213（0.7754 → 1.0967）で、両方とも上がる。ただし 2qt4_A の値は分母の利得（+0.1346）が小さいために大きく出る。

## 4. 読み取り

- **0.8 の線には 0.3 ns、0.9 にはどの長さでも届かない。** 統合値の回復率は 0 ns で 0.7264 とすでに高く、0.3 ns で 0.8061 と 0.8 を超えるが、その後は 0.83〜0.89 の範囲にとどまり、最大でも 0.7 ns の 0.8946 で 0.9 の線のすぐ下である。
- **曲がりはほぼ平らに上がる。** 増え分は最大でも +0.0700（0→0.1 ns）で、他は +0.05 以下か負である。L01 の 0.6 ns のような段はなく、長さを伸ばしても回復率はほとんど変わらない。
- **2qt4_A の回復率は分母が小さいために大きく出る。** 2qt4_A の全部入りの利得は +0.1346 と 1mix_A（+0.2534）の半分ほどで、回復率は 0.1 ns 以降 1.0 を超えたままである。タンパク質ごとの値は分母の大きさとあわせて読む必要がある。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離の 30 ns先（資料D）では、回復率 0.8 に届く最小の覆う長さは 0.3 ns、0.9 にはどの長さでも届かない。増え幅がいちばん大きいのは 0→0.1 ns（+0.0700）で、1か所に段と呼べる跳ねはない。フレーム0だけでも回復率は 0.7264 と利得の7割が戻る。
- まだ分からないこと: 曲がりの平らさが学習の揺れか、長さの効き方の本質かは、単一の学習 seed の結果では切り分けられない。実測の費用に直したときの形（L03 の担当）。
