# G13: 接触の形成で、切り取りに生成した平均を足すとどうなるか（資料Dの条件、接触の形成、1 ns先）

## 問い

G11 では水素結合の形成で、0.1 ns の切り取り平均に第22案の生成平均を足すと、回復率が 0.570 から 0.756 へ +0.186 上がりました。接触の形成でも同じか確かめます。接触では 0.1 ns の切り取り平均だけの回復率は 0.432（G03）と、水素結合より低い条件です。

## 条件

- 土台は資料Dの条件（接触の形成）です。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 15,926件・テスト 7,384件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直しました。
- 生成平均の出所: K17 の残基レベルの生成系列（第11〜14案）で、分岐平均の9点系列の平均です。K17 の予測で使った6統計量のうち平均の列だけを使う形です。実側は K13 のキャッシュ（静的5特徴、11点の履歴、ラベル）で、K17 の保存値と配列単位で一致することを、実行時に全軌道で確認しています。生成器のチェックポイントは読み込んでいません。新しい軌道の取得もしていません。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離を共有しますが時間の向きが逆です（G11 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません。
- 切り取りの定義（G02・G03 と同じ）: 0.1 ns の切り取りはフレーム 0, 1（2フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。
- 条件の一覧（1 ns先）:
  - 静的のみ: 静的特徴5個だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、閾値 4.5 Å）。
  - 切り取り平均だけ: 静的特徴＋0.1 ns の切り取り平均だけ。
  - 生成平均だけ: 静的特徴＋第11〜14案の生成平均だけ（案ごとに1条件）。
  - 混合: 静的特徴＋切り取り平均＋生成平均（2列、案ごとに1条件）。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.2271）で測ります。

## 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3398、全部入り 0.5669、利得 +0.2271 で、K16・K13 の記録と小数第4位まで完全一致しました。切り取り平均だけは AUPRC 0.4379、回復率 0.432 で、G03 の値と一致しました。

## 読み取り

- **混合の回復率は、第11〜13案で +0.070〜+0.097 上がり、先に固定した +0.05 の線を超えました。** 第14案だけが −0.001 と上がりませんでした。先に固定した読み方に沿うと、混合は接触でも足しになります。混合の効き目は水素結合に限られません。ただし上がり幅は水素結合の +0.186 より小さく、3案で +0.07〜+0.10 の水準です。
- 生成平均だけでは回復率は 0.057 以下とほとんど戻りません（K17 の結果と一致）。生成平均単体では指導力をほとんど持たないのに、切り取り平均と組み合わせると上がるのは、G11 の水素結合と同じ形です。
- 混合の水準（0.502〜0.529）は、切り取りを 0.25 ns まで伸ばしたときの平均だけの回復率（0.512、G07）とほぼ同じで、0.5 ns まで伸ばしたとき（0.773）には届きません。0.1 ns の切り取りに生成平均を足すことは、切り取りを 0.25 ns まで伸ばすこととほぼ同じだけの足しになります。
- 第14案だけが上がらなかった理由は、この実験だけでは分かりません。4つの案の生成平均は分布の上ではほぼ同じなのに、混合の結果だけが違います。生成平均の小さな残りの部分の違いが効いているはずですが、どの成分が効いているかは未測定です。

## 注意点

- 単一の学習 seed の結果です。テストは 7,384件、1 ns先の陽性は 219件（陽性率 3.0%）と陽性が少ない条件で、回復率の揺れは水素結合の形成（4,972件、陽性率が高め）より大きい可能性があります。
- GC シリーズ（Codex 側の補佐実験、別ブランチ）とは土台が違い、数値は直接比べられません。
