# K2-121: K2-14 の問い（割合の前半と後半）を強い土台での水素結合の解離の 30 ns先で測る

- 確かめること: 強い土台（未見 100 タンパク質×3 レプリカ）の条件で、水素結合の解離の割合（ペアが境界 3.5 Å より近い時間の割合）の前半と後半がどう違うかを、30 ns先で測る。割合の前半と後半は 1・5・90 ns先（K2-117・K2-119・K2-118）で測り終えた。30 ns先ではどうなるかを見る。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-14 の問い（割合の前半と後半）を、強い土台での水素結合の解離で測る。合算の前半・後半は、1 ns先（K2-117）は 0.720・0.668、5 ns先（K2-119）は 0.706・0.680、90 ns先（K2-118）は 0.781・0.458 で、どれもどちらにも当てはまらなかった。30 ns先の平均の前半と後半（K2-81）は前半 0.770・後半 0.716（合算）で、どちらにも当てはまらなかった。ここでは、割合の形で 30 ns先を測る。

比べる条件は K2-118 と同じく先に固定した。静的な特徴量に、つぎのどれか 1 つを足した形で比べる：前半（フレーム [0..4]）の割合、後半（フレーム [6..10]）の割合、前半と後半の両方、全部（フレーム [0..10]）の割合。土台の再現は強い土台の水素結合の解離の 30 ns先の記録（K75 の対角）と照らす。

読み方は K2-01 と同じく先に固定した。後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。合算とマクロで判定が分かれる場合は、両方を記録する。分母を全部の割合の利得にしても判定が変わる場合は、両方を記録する。タンパク質ごとの形の数え上げ（「今の状態」・「続いている状態」・どちらでもない・利得が小さく判定から外したもの）も K2-07 と同じく記録する。
