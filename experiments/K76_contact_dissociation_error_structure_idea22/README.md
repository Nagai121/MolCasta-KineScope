# K76 接触の解離でも、案22の生成の平均の誤差の形は同じか（K50 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。案22でも、誤差の形は残基レベルの生成方式（第11〜14案）と同じです。境界に近づくほど誤差が大きくなり、外れたペアで誤差が大きくなります。誤差の形は生成方式によりません。

## 1. 何を確かめる実験か

K70 で、接触の解離の誤差の形は残基レベルの生成方式で測りました。案22でも同じか確かめます。

読み方は先に固定しました。案22でも誤差が境界に近づくほど大きく、外れたペアで大きければ、生成方式によらず同じ形です。形が違えば、誤差の形は生成方式によります。

## 2. 条件

- 対象は K50 の接触の解離の候補のうち、案22に与えられるもの（3,164件）です。案22の特徴量は（ドナー、アクセプター）の原子ペアにしか定義されていないため、候補の代表原子ペア（起点で最小距離をとる重原子ペア）がドナー・アクセプターのペアである候補だけが与えられます。K50 の候補 9,298件のうち 3,164件（34.0%）が該当しました。K35 の接触の形成では同じ割合が 21% でした。結果はこの部分集合についてのもので、接触の解離全体についてのものではありません。
- 生成の系列は、K05 の再生成と K54 の最初の試行と同じ案22のパイプラインで、この実験のために作り直しました。起点の距離による選別（形成の研究の候補定義）を使わず、代表原子ペアを直接与えています。下流（方向の特徴量、局所の場、弾性モード、特徴量、ネットワーク、拘束）は K54 の最初の試行と同じコードと入力です。生成器は保存されたもので、ハッシュを記録と照合してから使いました（SHA-256 `d35b5d92...e88a05`、記録と一致）。生成器は水素結合の形成のペアだけで学習したものなので、接触の解離の代表ペアに使うのは学習範囲の外です。この点は注意として残します。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は案22の5点系列（起点＋0.1／0.3／0.5／1.0 ns）の平均です（K30・K35 の案22の平均と同じ約束）。
- 分け方：(a) 起点の距離の帯（境界付近 3.5〜4.5 Å と、それ以外 3.5 Å 以下。細かく 0.5 Å 刻みでも測った）、(b) 実の平均の全体の平均（この部分集合では 3.338 Å）からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K67・K70 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K67・K70 と同じ区切り）。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。
- 対照として、実の前向き5点系列（起点と +0.1／0.3／0.5／1.0 ns の最小距離）の平均と実履歴の平均との差も同じ分け方で測りました（K38 の対照）。生成の平均の誤差のうち、どれだけが前向きと後ろ向きの違いによるものかを見るためです。
- 同じ候補での比較として、K58 の残基レベルの第14案と第11案の誤差も、この 3,164件の部分集合に限って同じ分け方で測りました。生成方式の違いを、候補の違いと分けずに比べるためです。
- ラベルとの関係も K35・K70 と同じ測定をしました。1 ns先のラベル（最小距離が 4.5 Å を超えたか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べました。
- 注意点: 対象は部分集合（3,164件）で、起点の距離は 2.5〜3.5 Å に偏っています。2.5 Å 以下の帯は 3件しかなく、測れていません。

## 4. 読み取り

- **境界に近づくほど誤差が大きい形は、案22でも出ました。** 境界付近（3.5〜4.5 Å）の誤差は 0.302 Å、それ以外は 0.271 Å で、比は 1.11 倍です。細かい帯では一番上の帯（4.0〜4.5 Å）が 0.341 Å と最大で、3.0〜3.5 Å の 0.254 Å から単調に増えています。K70（候補全体、第14案）では同じ比が 1.29 倍でした。比が小さいのは主に部分集合のせいで、同じ部分集合での第14案の比は 1.20 倍で、案22の 1.11 倍とほぼ同じです。細かい帯の形も両者で同じです。
- **外れたペアで誤差が大きい形も、案22でも出ました。** (b) では、実の平均が全体の平均から 1.0 Å 以上離れた候補（126件）で誤差が 0.579 Å になり、中心（0.25 未満）の 0.232 Å に対して 2.50 倍です。K70 では同じ比が 2.79 倍、同じ部分集合での第14案では 2.61 倍でした。この帯の誤差はほぼ負の側に出ます（全体のずれ −0.541 Å、平均絶対値 0.553 Å）。この帯の実の平均は 4.34〜6.10 Å とすべて全体の平均より上にあり、生成の平均は 2.67〜4.86 Å の範囲に留まります。この帯の候補の起点の帯は、4.0〜4.5 Å が 88件と多くを占めます（2.5〜3.0 Å が 8件、3.0〜3.5 Å が 8件、3.5〜4.0 Å が 22件）。K70 ではこの帯の実の平均は 2.00〜7.57 Å と全体の平均の上下両方に広がっていましたが、この部分集合では上だけに出ました。与えられる候補が水素結合に近いペアに偏っているためです。
- **誤差の大きさ自体も、生成方式によらずほぼ同じです。** 全体の誤差の標準偏差は、案22 が 0.281 Å、第14案が 0.276 Å、第11案が 0.279 Å で、全体のずれも −0.060／−0.062／−0.056 Å と同じです。隔たりの効果も、21以上と 2〜5 の比が案22 で 1.42 倍、第14案で 1.39 倍、第11案で 1.41 倍、K70（候補全体）で 1.40 倍と、どれも同じです。
- **対照の実の前向き系列でも、同じ形がすでに出ています。** 対照の誤差の標準偏差は 0.213 Å で、生成の 0.281 Å より小さいものの、裾と中心の比は 2.84 倍、境界付近とそれ以外の比は 1.24 倍、隔たりの比は 1.85 倍と、生成の誤差と同じ形です。誤差の形の大部分は、前向きと後ろ向きの違いから来ています。
- ラベルとの関係では、誤差とラベルの相関が −0.199 で、縮み＋乱数の合成の −0.160 より強く出ました。K70・K35 と同じで、実際の誤差は縮みと乱数だけでは説明しきれません。第14案（同じ部分集合）でも −0.228 と同じ向きに出ました。生成の平均は、陽性と陰性の平均の差が +0.618 Å と、実の平均の +0.898 Å に比べて小さいものの、解離するペアとしないペアをある程度区別できています。
- 生成の系列の質の確認では、案22の系列は実の前向き系列より静かでした（ペアごとの標準偏差 0.068 Å に対して実の最小系列は 0.194 Å、境界を越える回数は 0.010 回／ペアに対して実は 0.136 回／ペア）。K05・K54 と同じ静かさです。生成の平均は 3.278 Å で、実の最小系列の平均 3.333 Å よりやや短いです。

## 5. 判断できること・まだ分からないこと

- 判断できること: 先に固定した読み方では、案22でも誤差が境界に近づくほど大きく（細かい帯で一番上の帯が最大）、外れたペアで大きくなります（中心の 2.50 倍）。誤差の形は生成方式によらず同じです。全体の誤差の大きさ、隔たりの効果、ラベルとの関係も、残基レベルの生成方式と同じです。
- 判断できること: 境界付近とそれ以外の比が K70 の 1.29 倍より小さい（1.11 倍）のは、主に部分集合のせいです。同じ部分集合での第14案の比は 1.20 倍で、案22とほぼ同じでした。
- まだ分からないこと: 対象は与えられる候補（3,164件）に限られ、与えられない候補（6,134件）で同じ形になるかは、案22では測れていません。また生成器は水素結合の形成のペアだけで学習したものを流用しており、学習範囲の外への当てはめである点は変わりません。
