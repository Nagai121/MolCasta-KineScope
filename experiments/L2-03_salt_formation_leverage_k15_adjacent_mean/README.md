# L2-03: L27〜L32 の曲がりを、区間を起点の直前に置き直して測り直す（塩橋の形成、平均だけ、K15 の土台）

- 確かめる仮説: L 系列の全面改訂（L2 系列）。L01〜L74 は履歴として先頭からの区間 [0..k] を起点フレーム10と組にしていたため、短い長さでは区間の終わりと起点の間に時間の空きがあった。E01 の測定で、この空きが回復率を水増ししていたことが分かった。ここでは区間を起点フレーム10の直前に置き直し（E01 の Protocol A と同じ置き方）、土台・候補・予測器の設定・読み方を対応する L 実験（L27・L28・L29・L30・L31・L32、塩橋の形成・平均だけ・K15 の土台）と完全に同じにして、6予測幅すべてで測り直す。
- 状態: 完了。**区間を起点の直前に置き直すと、短い側の回復率は L より大きく下がり、0.8 の線に届く長さは 1・5・30・50 ns先で後ろにずれ、10・90 ns先では全体の読みで届かなくなった。0.9 の線は 5・30 ns先で後ろにずれ、1・10・90 ns先では全体の読みで届かなくなった。** ただし長さ 0（フレーム10だけ）の回復率は全予測幅でちょうど 0 で、L の長さ 0（フレーム0だけ）の 0.57〜1.25 は、静的な特徴にないフレーム0の距離の持ち込みだったと分かった。K15 の土台ではテストが 30タンパク質しかなく、区間が広く、曲がりの細かい形は決められない。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、起点フレーム10の直前の短い区間だけに切って使う。区間の長さを L と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「区間の平均だけ」を履歴の特徴量として K15 の土台の補正モデルに入れたときの、6予測幅（1/5/10/30/50/90 ns先）それぞれの利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。

読み方は L と同一で、先に固定した。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の条件。学習 58タンパク質・テスト 30タンパク質、静的特徴 5個、HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15、L2 0.02、種 42）を条件ごとに学習し直す。塩橋の候補の定義は K15 の記録に合わせている（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上、ラベルは 4.0 Å以下）。データは K15 のキャッシュ（学習 2,557件、テスト 1,170件）を使う。全部入りは静的＋履歴 6統計量（最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合）。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、条件ごとに学習し直す。
- 実行はローカルVM（sklearn はスレッド数1。学習は全予測幅で13条件×6予測幅＝78条件、約1分半。第1段階の前提確認込みで約100秒。ブートストラップ 10,000回は予測幅1つあたり約8〜9秒、6予測幅で約1分）。Colab は使っていない（割り当て文では Colab の CPU セッションを基本とされていたが、ローカルで回る軽さだったため）。

### 留保（この土台の読みにくさ）

- **テストが 30タンパク質しかないため、区間が広い。** 強い土台（100タンパク質）とは区間の細かさが違う。ブートストラップの区間は全体でも幅が 1〜10 を超えることがあり（特に 50 ns先）、長さの間の差のほとんどは揺れの範囲である。
- **50 ns先は土台の利得が小さい**（全体 +0.0274）。分母が小さいため回復率の値が大きく振れ、0.5 ns で 0.900、0.6 ns で −0.398、0.7 ns で 0.888 と上下する。50 ns先の「0.8・0.9 の線に届く長さ 0.5 ns」は、この振れの中での一度きりの到達で、持続する形ではない。
- タンパク質ごとの平均（macro）の利得も小さい（5 ns先 +0.0313、10 ns先 +0.0352）ため、macro の回復率は 1 を大きく超えることがあり（5 ns先の 1.0 ns で 2.289、10 ns先の 0.3 ns で 1.61 など）、macro の読みは全体の読みの添え物として扱う。

### 長さの呼び方（L と同じフレーム数、区間だけ起点の直前）

長さは「覆う長さ」で統一し、フレーム数は L01・L02 と同じ（覆う長さ L ns は L/0.1＋1 フレーム）。ただし区間は起点フレーム10の直前で、L の先頭からの区間 [0..(L/0.1)] とは置き方が違う。E01 の Protocol A と同じ置き方である。

|---|---|---|
| 0 ns | 10 | 1 |
| 0.1 ns | 9, 10 | 2 |
| 0.2 ns | 8〜10 | 3 |
| 0.3 ns | 7〜10 | 4 |
| 0.4 ns | 6〜10 | 5 |
| 0.5 ns | 5〜10 | 6 |

覆う長さ 0 ns はフレーム10だけ、つまり起点の距離そのもの（平均を取っても値は同じ）。覆う長さ 1.0 ns はフレーム 0〜10 の11フレーム全部で、L の同じ長さと同一条件になる（前提確認の点）。

### 条件の一覧（6予測幅すべて）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値6個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 区間の平均だけ: 静的特徴＋区間の平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（L27 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質ごとの AUPRC の平均。

## 3. ブートストラップの段取り（結果を見る前に固定、L27 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの30タンパク質から復元抽出で30タンパク質を選び直す、ふつうのブートストラップである。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。測っているのはテスト集合の取り方による揺れで、学習の揺れではない。
- 全体の AUPRC の計算は sklearn の average_precision_score と同じ段取り（しきい値で区切って精度と再現率を取り、再現率の増え分で重み付けする）を numpy で書き直したものを使い、実際の予測確率で全条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。タンパク質ごとの平均の標本内での値は、タンパク質ごとの AUPRC（学習済みモデルの予測から出した固定値）を、再標本化の重なり具合で重み付けして平均したもの。
- 標本内の実履歴の利得が 0 以下になった抽出は、L27 と同じく区間の計算から除いた。件数は予測幅ごとに次の通り（10,000回中）。全体：1 ns先 53回、5 ns先 122回、10 ns先 272回、30 ns先 0回、50 ns先 1,457回、90 ns先 339回。平均：1 ns先 109回、5 ns先 2,063回、10 ns先 2,480回、30 ns先 0回、50 ns先 299回、90 ns先 54回。50 ns先の全体で 1,457回（14.6%）も利得が 0 以下になるのは、分母の利得（+0.0274）が小さいためである。

## 8. 読み取り

- **区間を起点の直前に置き直すと、短い側の回復率は L より大きく下がった。** L の短い側の回復率のうち、フレーム0の距離の持ち込みにあたる分（長さ 0 で 0.57〜1.25、0.1 ns で 0.52〜0.73 の下がり）が消え、0.8・0.9 の線に届く長さは後ろにずれるか、全体の読みでは届かなくなった。E01 で示された「起点との間の時間の空きによる水増し」が、L の曲がりの短い側に確かに入っていた。塩橋の形成では L の長さ 0 の回復率が 1 を超える予測幅もあり（10 ns先 1.246、50 ns先 1.130）、水増しの大きさは水素結合の形成（0.34〜0.69）より大きい。
- **曲がりの形は、L と同じく単調ではなく、区間が広いため細かい形は決められない。** 増え幅最大の区間は予測幅ごとに 0→0.1 ns・0.1→0.2 ns・0.2→0.3 ns・0.6→0.7 ns・0.7→0.8 ns に散らばり、1か所の跳ねで線をまたぐ形ではない。50 ns先の 0.6→0.7 ns の +1.286 は大きいが、直前の 0.5→0.6 ns が −1.298 の落ち込みで、その戻りの面が大きく、分母の利得が小さいための振れである。
- **長さ 0 の回復率が全予測幅でちょうど 0 になったのは、静的な特徴に起点の距離が含まれているためである。** フレーム10だけの平均は、静的な特徴の1番目と全く同じ値になるので、モデルは何も足されない。逆に L の長さ 0（フレーム0だけ）の 0.57〜1.25 は、静的な特徴にないフレーム0の距離が持ち込まれた分だったと分かった。
- 30 ns先は、0.8 の線に 0.6 ns、0.9 の線に 1.0 ns で届く。曲がりは 0.1 ns で 0.407 まで上がり、その後は 0.29〜0.55 の範囲で横ばいになり、0.6 ns 以後で 0.8 を超える。区間は重なっており、細かい形は決められない。
- 10・90 ns先は全体の読みで 0.8 の線に届かない。10 ns先の全体の最大は 0.601（0.7 ns）、90 ns先の全体の最大は 0.748（0.8 ns）である。

## 9. 判断できること・まだ分からないこと

- 判断できること: 塩橋の形成・平均だけ・K15 の土台で、区間を起点の直前に置き直すと、0.8 に届く最小の長さは全体で 1 ns先 1.0 ns、5 ns先 0.4 ns、10 ns先 届かず、30 ns先 0.6 ns、50 ns先 0.5 ns、90 ns先 届かず。0.9 に届く最小の長さは全体で 1 ns先 届かず、5 ns先 0.4 ns、10 ns先 届かず、30 ns先 1.0 ns、50 ns先 0.5 ns、90 ns先 届かず。L と比べると、0.8 の線は 1・5・30・50 ns先で後ろにずれ、10・90 ns先は全体の読みで届かなくなった。0.9 の線は 5・30 ns先で後ろにずれ、1・10・90 ns先は全体の読みで届かなくなった。L の短い側の回復率には、フレーム0の距離の持ち込みによる水増しが入っていた。
- まだ分からないこと: 50 ns先の曲がりの形は、分母の利得が小さく区間が広いため、この土台では決められない。塩橋の解離（L2-04）でも同じ向きのずれが出るか。統計量6種の形でも同じか。
