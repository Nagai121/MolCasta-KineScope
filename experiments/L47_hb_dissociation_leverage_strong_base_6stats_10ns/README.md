# L47: 統計量6種で L11 の曲がりを強い土台で測る（K75 の条件、水素結合の解離、10 ns先）

- 確かめること: 「短い実MDを安くする」経路の L 系列の続き。L11（水素結合の解離、強い土台、10 ns先）では、履歴は切り取りの平均だけを使った。ここでは履歴の要約を平均だけではなく統計量6種（実験Dの定義、L39・L40 と同じ）に広げ、同じ土台・同じ長さの定義で曲がりを測り直して、必要な長さが縮むかを見る。平均だけの曲がりも同じ実行の中で測り直し、L11 の記録と一致するか確かめる。
- 状態: 完了。**統計量6種では、必要な長さは縮まなかった。** 回復率 0.8 に届く最小の長さは全体では 0.2 ns で平均だけと同じ（タンパク質ごとの平均では 0.3 ns と長くなった）、0.9 に届く最小の長さは全体・平均とも 0.5 ns で、平均だけ（0.3 ns）より 0.2 ns 長くなった。同じ長さでの差（6種 − 平均だけ）は、0 ns（+0.005）を除くすべての長さで負（−0.027〜−0.125）で、10 ns先では平均以外の要約値は足しにならなかった。増え幅がいちばん大きい場所は 0→0.1 ns（全体 +0.150）。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02・L11 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの統計量6種」を履歴の特徴量として強い土台の補正モデルに入れたときの 10 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。比較のために、L11 とまったく同じ作り方の「切り取りの平均だけ」の条件も同じ実行で学習し直し、回復率を並べる。

読み方は先に固定した（L11・L39 と同じ）。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、統合値（全体、pooled）で読む（タンパク質ごとの平均（macro）も併記する）。L11（平均だけ）の答えと比べて、縮んだかどうかを明記する。
2. 段の判定は、隣り合う長さの間の回復率の増え幅がいちばん大きい場所と、その大きさで読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は水素結合の解離の強い土台（K75・K2-18 と同じ）。HistGradientBoosting の補正モデル（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）を較正タンパク質（6,144候補）で学習し、未見の100タンパク質×3レプリカ（76,342候補、10 ns先の陽性 14861件）で評価する。静的特徴は5個、履歴の要約値は10個。
- 入力は K2-18 の input_bundle.npz（静的特徴・履歴の要約値・11フレームの距離系列・ラベル）を使う。静的特徴と系列は K2-18 の系統（K75・K2-77・K2-84）と同じく float64 にそろえて使い、統計量6種のブロックだけは実験Dの作り方どおり float32 に落としてから並べた。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 10 ns先。条件ごとに学習し直す。
- 実行はこの仮想マシン（学習24条件とブートストラップ 10,000回）。途中結果を保存して再開できる形にした。

### 統計量6種の定義（実験Dの定義どおり、L39・L40 と同じ）

統計量6種は、実験D（固定した 1 ns 履歴の実験）の `features_from_history` の定義をそのまま使う。出典は MolCasta-InternalResearch ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py` で、並びは次の通り。

1. 最初の値（系列の最初のフレームの距離）
2. 平均
3. 標準偏差（ddof=0、numpy の `std` の既定）
4. 最小値
5. 最後−最初（系列の最後のフレーム − 最初のフレーム）
6. 閾値以下だった割合（閾値は水素結合の境界 3.5 Å。同スクリプトの `THRESH["hb"] = 3.5` で、割合は `(series <= bound).mean`）

値は float32 に落とす（同スクリプトの作り方どおり）。切り取りへの適用は、同じ式を切り取りの部分系列（フレーム 0〜k）にそのまま適用する。「最後」は切り取りの最後のフレーム、「割合」は切り取りの中での割合になる。覆う長さ 0 ns（1フレーム）では標準偏差と最後−最初は 0 になり、割合は「最初の値が 3.5 Å以下かどうか」の 0/1 になる。

### K75 の履歴特徴10個との関係

K75 の履歴特徴10個は、同じ11フレームから次の式で再現できる（下の premise で全数照合した）。

| 位置 | K75 の要約値10個 | 実験Dの6種に入るか |
|---:|---|---|
| 0 | 最初 | 入る（1番目） |
| 1 | 平均 | 入る（2番目） |
| 2 | 標準偏差 | 入る（3番目） |
| 3 | 最小 | 入る（4番目） |
| 4 | 最大 | 入らない |
| 5 | 最後−最初 | 入る（5番目） |
| 6 | 最後−直前 | 入らない |
| 7 | 3.5 Å以下割合 | 入る（6番目） |
| 8 | 4.5 Å以下割合 | 入らない |
| 9 | 増加割合（隣り合うフレームで増えた割合） | 入らない |

つまり実験Dの6種は K75 の10個の部分集合で、10個は6種に「最大、最後−直前、4.5 Å以下割合、増加割合」の4つを足した拡張である。したがって全部入り（11フレーム全部の要約値10個）は6種の上位集合で、覆う長さ 1.0 ns の6種の条件は、全部入りから4特徴を落とした条件にあたる。

### 長さの呼び方（L01・L02・L11 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02・L11 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけの1フレーム、1.0 ns はフレーム 0〜10 の11フレーム全部）。起点フレーム10（1 ns）は変えず、ラベルは 10 ns先のまま。G 系列の「1.0 ns」の切り取り（フレーム [0..9]）とは違う。

### 条件の一覧（10 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。L11 とまったく同じ作り方（premise の照合と比較用）。
- 切り取りの統計量6種: 静的特徴＋切り取りの統計量6種。覆う長さ 0.0〜1.0 ns の11通り（主役）。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro、100タンパク質）の両方で測る（L11 と同じまとめ方）。K75 の記録との照合用に、タンパク質×レプリカ（300群）の平均も併せて出す。

## 3. ブートストラップの段取り（結果を見る前に固定、L11・L39 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・各長さの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。6種と平均だけの両方の系列を、同じ抽出で測っている。
- 全体の AUPRC の計算は L11 と同じ numpy 実装（sklearn の average_precision_score と同じ段取り）を使い、実際の予測確率で全24条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は全体 0 件、平均 0 件）。

## 5. 読み取り

- **10 ns先は、6件の中で唯一、6種が平均だけを一貫して下回った予測幅である。** 差は 0.1 ns 以後のすべての長さで負で、0.9 ns で −0.125 と最も大きい。
- 背景として、10 ns先は平均だけの曲がり自体が 0.5 ns 以後 1 を超える予測幅で（全部の平均だけが全部入りを上回る）、平均だけがすでに天井の上にある。そこへ要約値を足しても上には伸びず、学習の側の不利だけが出た形と読める。ただし、この実験では切り分けていない。
- 線に届く長さで見ても、0.9 の線は 0.3→0.5 ns と長くなった。必要な長さの読みでも、6種は 10 ns先では不利である。
- 費用の側は L11 と同じくまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03 の形（G04 の実測との対応付け）で行う。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の解離、10 ns先）で履歴に統計量6種を使うと、回復率 0.8 に届く最小の覆う長さは 0.2 ns、0.9 に届く最小の覆う長さは全体で 0.5 ns（タンパク質ごとの平均では 0.5 ns）。平均だけ（L11）では 0.8 が 0.2 ns、0.9 が全体 0.3 ns（平均 0.3 ns）だった。増え幅がいちばん大きいのは 0.0→0.1 ns（全体 +0.150）。
- まだ分からないこと: 6種のうちどの要約値が押し上げ（または押し下げ）を担っているかは、この実験では切り分けていない。実測の費用に直したときの形（L03 の形の換算を解離にも当てるかどうか）。
