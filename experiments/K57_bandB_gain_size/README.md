# K57: 遠い幅での平均の戻り方のばらつきは、利得の小ささのせいか（K55 の再解析）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。幅Bの全体まとめの戻り方の振れは、2タンパク質の利得の向きが食い違うことによるものでした。1mix_A では幅Bでも利得は全幅でほぼ正ですが、2qt4_A では 6幅中4幅で利得が負（実履歴が静的のみを下回る）です。全体まとめの利得はこの2つの平均で、戻り方は分母が小さいために振れます。利得が大きいほど戻り方の 1 からのずれが小さいことも確かめられました（12セルで Spearman −0.699）。

## 1. 何を確かめる実験か

K55 で、近い幅（3.5〜4.5 Å）では平均だけで利得の8割以上が全予測幅で戻りましたが、遠い幅（4.5〜6.0 Å）では予測幅によって 0.28〜3.24 とばらつきました。このばらつきが、遠い幅の利得そのものが小さいせいか確かめます。

読み方は先に固定しました。遠い幅の利得が小さく、全体まとめでは回復率が安定すれば、ばらつきはタンパク質ごとの平均のせいです。全体まとめでもばらつけば、遠い幅では平均の担い手が安定しません。ここで「全体まとめでは回復率が安定する」とは、タンパク質ごとの回復率のばらつき（2タンパク質の範囲）が全体まとめの回復率の振れより大きい、またはタンパク質ごとの平均（マクロ平均）が全体まとめと大きく違う、という読みとします（この定義は、タンパク質ごとの値を計算する前に固定しました。全体まとめの値は K55 の既知の値ですが、タンパク質ごとの値はこの実験で初めて測るものです）。タンパク質が2つしかないため、強い結論は出せない点は留保します。

## 2. 方法（K55 のデータの使い方）

- K55 は集計済みの指標だけを保存しており、タンパク質ごとの予測確率は残っていませんでした。そのため、K55 のコードを流用して再計算しました（`run_k57.py`）。キャッシュ、モデル（HistGradientBoosting、反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）、幅の分け方（A: 3.5 < d ≤ 4.5 Å、B: 4.5 < d ≤ 6.0 Å、学習とテストの両方をその幅だけに絞って学習し直す）、条件（静的のみ、静的＋実履歴6統計量、静的＋平均だけ）は K55 とまったく同じです。
- 再計算の全体まとめの値は、K55 の `results.json` と全幅・全条件で小数第4位まで完全に一致しました（例: 幅B 1 ns先で静的のみ 0.0388、全部入り 0.0460、平均だけ 0.0520）。再計算は正しく、以下のタンパク質ごとの値は K55 のモデルそのものの内訳です。
- タンパク質ごとの評価は、幅ごとに学習し直したモデル（K55 と同じもの）で、テストの 1mix_A と 2qt4_A を別々に評価したものです。全体まとめ（pooled）は 2タンパク質を合算した K55 の値そのものです。タンパク質ごとの回復率は、タンパク質ごとの利得で割ったもので、マクロ平均は 2タンパク質の回復率の単純平均、範囲は 2タンパク質の回復率の差です。
- 利得の大きさと戻り方のずれの関係は、12セル（2幅×6予測幅）で、利得と「戻り方の 1 からのずれの絶対値」の Spearman の順位相関で測りました。

## 5. 読み取り

- **幅Bでは、2タンパク質の利得の向きが食い違います。** 1mix_A では幅Bの利得は 5 ns先の −0.0086 を除いて全幅で正（+0.032〜+0.066）ですが、2qt4_A では 6幅中4幅で利得が負（−0.096〜−0.004）で、実履歴が静的のみを下回ります。全体まとめの利得（+0.007〜+0.051）は、正のタンパク質と負のタンパク質の平均で、どちらのタンパク質の指導力でもありません。幅Bの「指導力」はタンパク質によって向きが違う、ということです。
- **全体まとめの戻り方の振れは、タンパク質ごとの違いによるものです。** 先に固定した読み方に沿うと、幅Bではタンパク質ごとの回復率のマクロ平均が全体まとめと大きく違います（差は 6幅中5幅で 0.5 を超え、1 ns先 1.016、5 ns先 0.848、10 ns先 1.226、30 ns先 9.899、50 ns先 2.969。90 ns先だけ 0.067 と小さい）。タンパク質ごとの回復率の範囲も、30 ns先では 19.538 と全体まとめの回復率の振れ（全幅で 3.241 − 0.281 = 2.960）を大きく上回ります。したがって、全体まとめの戻り方の振れはタンパク質ごとの平均のせい、という読みになります。
- **ただし、これは幅Bの担い手が安定しているという意味ではありません。** タンパク質ごとに分けても、どちらのタンパク質でも回復率は安定しません。1mix_A だけでも幅Bの回復率は −0.501〜1.182、2qt4_A だけでも −19.093〜0.926 と振れます。さらに、利得が 0 に近いセルでは回復率は比率として読めません（2qt4_A 30 ns先の −19.093、1mix_A 幅A 50 ns先の 3.949）。全体まとめの数値がタンパク質の違いで振れる、というのが正確な読みで、幅Bの平均の担い手を肯定する材料にはなりません。
- **幅Aでは、タンパク質ごとの回復率は全体まとめとよく合います。** マクロ平均と全体まとめの差は 50 ns先（1.037）を除いて 0.04 以下で、タンパク質ごとの範囲の中央値は 0.444 と、全体まとめの回復率の振れ（1.572 − 0.864 = 0.708）より小さいです。50 ns先だけは 1mix_A の利得が +0.0101 と小さく、回復率が 3.949 まで膨らんだためで、利得の小ささによる比率の振れは幅Aでも起きます。
- **利得の小ささと戻り方の振れは、量として結びついています。** 利得が大きいほど戻り方は 1 に近い（Spearman −0.699）ため、幅Bの戻り方の振れの少なくとも一部は、利得そのものが小さいことによる比率の不安定さです。利得が小さいセルでは、AUPRC の小さな揺れが回復率の大きな振れになります。

## 6. 判断できること・まだ分からないこと

- 判断できること: 幅Bの全体まとめの戻り方の振れは、タンパク質ごとの平均のせいです。2タンパク質の利得の向きが食い違っており（1mix_A はほぼ正、2qt4_A は 6幅中4幅で負）、全体まとめはその平均に過ぎません。事前に固定した読み方に沿うと、ばらつきはタンパク質ごとの平均のせい、という結論になります。利得が大きいほど戻り方は 1 に近い、という関係も量として確かめられました。
- まだ分からないこと: 幅Bで平均が担い手かどうかは、タンパク質ごとに分けても決められません。2タンパク質しかないため、タンパク質ごとの違いが本当にタンパク質の性質によるものか、陽性の少なさ（幅Bの 2qt4_A は 1 ns先で陽性6件）による揺れかは分かりません。幅Bのタンパク質を広げて、利得の向きがタンパク質によって本当に違うのかを確かめる必要があります。また、なぜ 2qt4_A では幅Bで実履歴が静的のみを下回るのかも、この実験だけでは分かりません。
