# K2-42: K2-13 の問い（塩橋の解離の前半と後半、平均だけ）を 5 ns先で測る

- 確かめること: 塩橋の解離の前半と後半の平均の利得を、5 ns先で測る。1・30・90 ns先は測り終えた。5 ns先で前半と後半の形がどうなるかを見る。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-13 では、塩橋の解離の 1 ns先で、前半（フレーム [0..4]）の平均だけの利得は全部入りの 0.803、後半（フレーム [6..10]）だけでは 0.921 だった。先に固定した読み方では「続いている状態が効いている」に当てはまった。30 ns先（K2-24）では前半 1.416・後半 0.347 と、長い予測幅では前半が大きくなる形で、1 ns先の「続いている状態」の形は崩れた。90 ns先（K2-33）では前半 0.661・後半 0.537 だった。ここでは、同じ問いを 5 ns先で測る。1・30・90 ns先は測り終えた。5 ns先で前半と後半の形がどうなるかを見る。

比べる条件は K2-13 と同じく先に固定した。静的な特徴量に、つぎのどれか 1 つを足した形で比べる：前半（フレーム [0..4]）の平均、後半（フレーム [6..10]）の平均、前半と後半の両方、全部（フレーム [0..10]）の平均。土台の再現は K15 の広げた条件の解離の記録（K53）の 5 ns先と照らす。塩橋の解離は土台の利得が小さく、テストも 360件と小さいため、回復率の読みには留保がつく。AUPRC の差もあわせて記録する。

読み方は K2-01 と同じく先に固定した。後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。
