# K74 生成器の補正を、ペアの平均距離を直接当てる目的で学習し直すと誤差は減るか（資料Dの条件、水素結合）

## 問い

これまで生成器は座標の軌道を当てる目的で学習していました。目的を変えると平均の誤差が減るか、できる範囲で確かめます。

## 段取り（進行中）

- 案22の補正の仕組みを使い、目的を「ペアの平均距離を直接当てる」に変えて学習し直し、生成の平均の誤差（平均・ばらつき・相関）を実の平均と比べます。
- 参照は K08 の生成の平均の誤差（平均 −0.155 Å、ばらつき 0.483 Å）です。
- 学習に使うタンパク質は生成器の教師8タンパク質（1u84_A、4u5h_G、5hub_A、1x6j_A、2y1y_A、1krn_A、2y4x_B、4xqm_A）です。

## 読み方（先に固定）

- 平均の誤差のばらつきが複製間のばらつき 0.249 Å より小さくなれば、目的がボトルネックです。
- 0.48 Å 付近のままなら、入力の情報がボトルネックです。
