# L28: L01 の曲がりを塩橋の形成で測る（K15 の土台、5 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の形成（K15 の土台、全予測幅、L27〜L32）の 5 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値では回復率は短い長さで早く上がり、0.1 ns で 0.847、0.3 ns で 1.293（全部入りを上回る値）まで出ますが、その後は 0.85〜1.16 の範囲で上下し、単調な伸びではありません。タンパク質ごとの平均は分母の利得が小さい（+0.0313）ため大きく振れ、区間も非常に広く、読みの主には使えません。

## 1. 何を確かめる実験か

L27 と同じ段取りで、予測幅だけを 5 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。テスト 1,170件、5 ns先の陽性 129件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.1 ns（全体 0.847）**。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.2 ns（全体 0.935）**。ただしその後も値は上下し、0.5 ns で 0.899、1.0 ns で 0.876 と線の前後を行き来します。「届いた長さ」として固定できる形ではありません。
3. **増え幅がいちばん大きい場所: 0.2→0.3 ns（全体 +0.358、平均 +1.190）**。
4. 段の位置（0.2→0.3 ns）のタンパク質ごとの増え分は、中央値 +0.250 [−0.418, +0.574]、正だったのは 19タンパク質のうち 63%、+0.1 以上は 58% でした。L27（1 ns先）よりはタンパク質側の裏づけがありますが、ばらつきは大きく（最小 −5.23、最大 +7.69）、段と呼べるほどの揃い方ではありません。タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 19タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 5 ns先では、統合値の回復率は短い切り取りで早く上がります（フレーム0だけで 0.628、0.1 ns で 0.847）。これは G60 の平均だけの切り取り走査（5 ns先で 0.1 ns の回復率 0.847）とも一致する形です。
- ただし曲がりは単調ではなく、0.3 ns の 1.293 を頂点に上下します。区間も広く、「どの長さまでで十分か」をこの土台で細かく決めることはできません。
- 平均の読みが大きく振れるのは、分母（平均の利得 +0.0313）が小さいためで、統合値と平均で分母の大きさが違うことが効いています。
