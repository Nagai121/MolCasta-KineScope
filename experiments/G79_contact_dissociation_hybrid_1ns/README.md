# G79: 接触の解離で、混合は足しになるか（D 条件、接触の解離、1 ns先）

## 仮説

形成では、0.1 ns の切り取り平均に生成平均を足すと回復率が上がりました（水素結合の形成 G11 で +0.186、接触の形成 G13 で +0.070〜+0.097、塩橋の形成 G19 で +0.108〜+0.231）。解離でも同じか確かめます。接触の解離は、G06 で 0.1 ns の切り取り平均だけの回復率が 0.919 と高い現象です。ここに G18 で作り直した方法22の生成平均を別々の特徴量として足します。

読み方は形成と同じく先に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がれば、混合は接触の解離でも足しになる。+0.05 未満なら、混合の効き目は形成に限られる（水素結合の解離の G18・G61 と同じ形）。

## 前提確認：G18 の生成系列は接触の解離の候補とそろうか

G64 の塩橋の解離と同じ確認を先にしました。G18 の生成系列は、水素結合の解離の候補向けに方法22を作り直したもので、起点 6.0 Å 以下の残基をまたぐドナー・アクセプターのペア全部（18軌道で 20,713件）です。接触の解離の候補は残基ペアなので、原子のペアを残基のペアに直して数えました（`count_overlap.py`）。原子から残基への対応は atoms.parquet の residue_index で、K46 のキャッシュの donor_res・acceptor_res と 466件すべて一致することを確かめています。

| 量 | 値 |
|---|---:|
| 学習の候補 | 6,383件（4タンパク質×3レプリカ） |
| 学習の候補のうち生成系列に対応するもの | 4,489件（70%） |
| テストの候補 | 2,915件（2タンパク質×3レプリカ） |
| テストの候補のうち生成系列に対応するもの | 2,226件（76%） |
| テストの陽性（1 ns先） | 207件のうち対応するもの 105件（51%） |

G64 の塩橋の解離（0件）とは違い、対応する候補が十分にあるので、**対応する候補だけに限って測定を進めました**。対応しない候補（約24〜30%）は、起点 6.0 Å 以内にドナー・アクセプターのペアを持たない残基ペアで、疎水性の接触が多いと見られます。対応する候補の陽性率（105 / 2,226 = 4.7%）は全体（207 / 2,915 = 7.1%）より低く、対応しない候補のほうが解離しやすい向きです。そのため、ここでの測定は「生成平均が存在する候補」での話で、接触の解離全体への一般化にはこの偏りがあります。

生成平均の作り方：1つの残基ペアに生成ペアが複数ある場合（中央値は1つ、最大で10つ）、その残基ペアの生成系列は、生成ペアの4点系列の点ごとの最小値としました。候補の距離が重原子ペアの最小値で定義されるのと同じ考え方です。ただし生成系列はドナー・アクセプターのペアだけを覆うため、生成の最小値は、重原子全部で取った場合の最小値より大きめに出る向きがあります。

## データと条件

- 条件は D 条件の接触の解離です。K50 のキャッシュ（`~/workspace/kinescope/work/k50_cache/`）と D 条件の分割（学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A・2qt4_A、各3レプリカ）を使いました。測定は対応する候補だけ（学習 4,489件、テスト 2,226件、テストの陽性 105件）です。
- 切り取りは 0.1 ns（フレーム [0,1]）の平均です。条件は静的特徴（5個）に、切り取り平均・生成平均・その両方を足したものです。6統計量の閾値は 4.5 Å です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 土台の検証：候補全体での静的のみ・全部入りは K50 の記録と一致しました（静的 0.3105 / 全部入り 0.5246 / 利得 +0.2142）。切り取り 0.1 ns の回復率も G06 と一致しました（0.919）。対応する候補だけでの土台は別に測り直しています（下の表）。

## 結果（1 ns先、対応する候補だけ）

| 条件 | AUPRC | 利得 | 回復率 |
|---|---:|---:|---:|
| 静的のみ | 0.2879 | ― | ― |
| 全部入り | 0.4567 | +0.1688 | 1.000 |
| 切り取り平均だけ 0.1 ns | 0.4689 | +0.1809 | **1.072** |
| 生成平均だけ | 0.2901 | +0.0022 | 0.013 |
| 混合（切り取り平均＋生成平均） | 0.4622 | +0.1742 | **1.032** |

混合の回復率と切り取り平均だけの回復率の差は **−0.040** で、先に固定した +0.05 の線に届きませんでした。

### 2つの平均の関係（テスト側、対応する候補だけ）

切り取り平均と生成平均の相関は 0.572、生成平均と実の平均の相関は 0.657、切り取り平均と実の平均の相関は 0.905 です。生成平均と実の平均の差の標準偏差は 0.634 Å、生成平均の平均は 3.786 Å で、実の平均 3.473 Å より約 0.31 Å 大きい向きです。

## 結論

先に固定した読み方に沿うと、**接触の解離では混合は足しになりませんでした**（混合と切り取り平均だけの差 −0.040）。生成平均だけの回復率は 0.013 とほぼ 0 で、生成平均は接触の解離の予測に情報を足していません。切り取り平均だけの回復率が 1.072 と全部入りを上回っている点もあり、接触の解離では 0.1 ns の切り取り平均だけで実履歴の利得をほぼ使い切っています。混合の効き目は形成に限られる形で、水素結合の解離の G18・G61 と同じです。

ただし測定の範囲は、生成平均が存在する候補（テストの 76%）に限られます。対応しない候補については、この測定では何も言えません。

## 実行の注意点

sklearn の学習はスレッド数を 1 に絞って動かしました（`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1`）。この仮想マシンでは既定のスレッド数だと OpenMP のスレッドが CPU を取り合ってほとんど進みません。実行ログは `~/workspace/kinescope/work/g79_run.log` です。原子から残基への対応に使った atoms.parquet は、MiniTopol-A-converted-18-trajectories.zip から /tmp/g79_atoms に取り出したものです（/tmp は一時置き場で、記録には残していません）。
