# K29: 生成の平均の誤差は、ラベルや未来と関わって出ているか（強い土台、水素結合）

## 仮説

H6（運動の生成そのものの問題）に関わる検証です。K28 で、縮み＋乱数の組み合わせでも利得は実履歴の 0.46〜0.62 が残り、生成条件の水準には届きませんでした。残る候補は、生成の平均の誤差が、候補の状態や未来と関わった出方をしていることです。誤差そのものの向きを測ります。

読み方は実験前に固定しました。生成の誤差がラベルや未来の距離と関わっており、合成の平均の誤差にはその関わりが無ければ、生成の失敗の仕組みは「誤差がラベルに関わる成分をちょうど消している」ことです。生成の誤差にも合成と同じくらいの関わりしか無ければ、誤差の向きでは説明できません。

## データと条件

- K05／K08 と同じ候補（資料D、候補 14,582件）です。候補ごとに、実の平均（実履歴11フレームの平均）と生成の平均（第22案の5点系列の平均）、誤差（生成の平均 − 実の平均）、6予測幅のラベル、未来の距離を使います。
- 未来の距離は、キャッシュにはラベルしか残っていなかったので、GPTベースの全軌跡（1001フレーム）から直接読み直しました。予測の起点は1 ns（フレーム10）で、未来の距離はフレーム 20/60/110/310/510/910（起点から 1/5/10/30/50/90 ns後）のドナー・アクセプター間距離です。距離は K13 と同じ周期境界の計算です。確認として、フレーム0とフレーム10の距離はキャッシュの履歴と完全に一致（差 0.0）し、未来の距離が 3.5 Å 以下かどうかは全候補・全予測幅でラベルと完全に一致（一致率 1.0000）しました。
- 合成の平均の誤差は K28 と同じ式（生成の平均 = 1.3829 ＋ 0.697 × 実の平均 ＋ 独立な乱数、残差の標準偏差 0.4028、種 101/202/303）で作り、3つの種の平均で比べます。
- 相関はすべてピアソンの相関係数です。ラベルとの関係は、相関に加えて、陽性と陰性の候補での誤差の平均の差と、誤差でラベルを予測する AUC も見ます。

生成の平均は、ラベルの信号を実の平均とほぼ同じだけ持っています（相関は全予測幅で実と実質同じ、陽性と陰性の差は実の約8割）。合成の平均は、生成の平均より信号が弱いです。K28 で利得の 0.46〜0.62 が残った合成の平均より、生成の平均のほうがラベルの信号を多く持っている、という結果です。

### (b) 誤差と実の平均のずれの関係

実の平均が全体の平均からどれだけ離れているか（ずれ）と、誤差の関係です。

- 誤差とずれの相関（符号付き）: 生成 −0.552、合成 −0.552。両者は一致します（線形の縮みから決まる値です）。
- 誤差の大きさとずれの大きさの相関: 生成 0.439、合成 0.242。生成の誤差は、ずれの大きい候補（情報を持っている候補）ほど大きくなります。線形の縮み＋独立な乱数では表せない、誤差の出方の違いがここにあります。

未来の距離との相関は、生成のほうが合成よりやや弱いです。未来の距離から実の平均を引いた変化との相関は、1 ns先だけ生成のほうが目立って大きく（+0.167 対 +0.048）、長い予測幅では小さくなります。

## 判断

先に固定した読み方に照らすと、答えは「誤差の向きでは説明できない」です。生成の誤差はラベルや未来の距離と関わっていますが、その関わりは合成の誤差より弱いです。先に固定した仕組み（誤差がラベルに関わる成分をちょうど消している）なら、生成の誤差のほうが合成よりラベルと強く関わるはずでしたが、実際は逆でした。さらに、生成の平均そのものはラベルの信号を実の平均とほぼ同じだけ持っており、合成の平均よりも多く持っています。平均の誤差がラベルの信号を消している、という形ではありません。

残っている違いは2つです。1つは (b) の大きさの側で、生成の誤差は情報を持っている候補ほど大きくなります（0.439 対 0.242）。もう1つは (c) の変化の側で、1 ns先の未来の変化との相関が生成のほうが大きい（+0.167 対 +0.048）ことです。ただし、どちらも平均のラベルの信号そのものは壊していません。

平均については、誤差の大きさ（K22）、縮み（K24）、その組み合わせ（K28）、向き（本実験）と4通りに切り分けても、生成の失敗は説明できません。生成の平均はラベルの信号を持っているのに、生成の特徴量全体では指導力が出ない理由は、平均以外の統計量（生成系列の変動の大きさは実系列よりずっと小さいことが K05 と K11 で分かっています）か、強い土台での読み出しの側にあると考えられます。なお、K21 では実の平均だけでも利得の 0.87〜1.08 が戻ることが分かっており、生成の平均がこれだけ信号を持っているのに生成条件で利得が出ない点は、平均以外の統計量が邪魔をしている可能性を示唆していますが、本実験の範囲では確かめていません。
