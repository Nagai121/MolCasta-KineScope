# K70 接触の解離でも、生成の平均の誤差の形は同じか（K50 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。外れたペアで誤差が大きい形は水素結合の解離と共通ですが、接触の解離では境界に近づくほど誤差が大きくなる勾配もあり、そこは違います。

## 1. 何を確かめる実験か

水素結合の解離では、生成の平均の誤差が境界の近くで大きくならず、実の平均が全体の平均から外れたペアで大きいことが分かりました（K67）。接触の解離でも同じか確かめます。

読み方は先に固定しました。接触の解離でも誤差が境界の近くで大きくならず、外れたペアで大きければ、水素結合の解離と同じ形です。境界の近くで大きければ、接触の解離は違います。

## 2. 条件

- 対象は K50 の接触の解離の候補 9,298件（資料Dの条件）です。誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は K26・K30・K67 と同じ約束（分岐4本 × 起点＋8ステップの36値の平均）です。生成の系列は K58 の作り直し版（第11〜14案、残基レベルの生成方式）を使います。K35 と違い、作れた候補だけの部分集合ではなく、解離の候補すべてが対象です。
- 分け方：(a) 起点の距離の帯（境界付近 3.5〜4.5 Å と、それ以外 3.5 Å 以下。細かく 0.5 Å 刻みでも測った）、(b) 実の平均の全体の平均（3.646 Å）からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K67 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K67 と同じ区切り）。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。
- ラベルとの関係も K35 と同じ測定をしました。1 ns先のラベル（最小距離が 4.5 Å を超えたか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べました。

## 4. 読み取り

- **外れたペアで誤差が大きい形は、水素結合の解離と共通です。** (b) では、実の平均が全体の平均から 1.0 Å 以上離れた候補（316件）で誤差が 0.668 Å になり、中心（0.25 未満）の 0.239 Å に対して 2.79 倍です。水素結合の解離（K67）では同じ比が 6.63 倍、接触の形成（K35）では 1.46 倍でした。この帯の誤差はほぼ負の側に出ます（全体のずれ −0.841 Å、平均絶対値 0.847 Å）。この帯の実の平均は 2.00〜7.57 Å で、生成の平均は 1.87〜4.57 Å の範囲に留まります。履歴の中で大きく離れたペアについて、生成の平均は起点の近くに留まったままで、実の平均についていけていません。
- **ただし、境界に近づくほど誤差が大きくなる勾配もあり、そこは水素結合の解離と違います。** 境界付近（3.5〜4.5 Å）の誤差は 0.334 Å、それ以外は 0.259 Å で、比は 1.29 倍です。細かい帯では誤差が起点の距離とともに単調に増え、2.5〜3.0 Å の 0.260 Å から 4.0〜4.5 Å の 0.369 Å まで上がります。水素結合の解離（K67）では境界付近とそれ以外の比は 1.11 倍で、最も誤差が大きいのは真ん中の 2.5〜3.0 Å の帯でした。接触の形成（K35）では境界付近とそれ以外の比は 0.87 倍で、細かい帯もほぼ平らでした。接触の解離だけが、境界に近づくほど誤差が大きくなる形です。
- **誤差の大きさは、ペアが実際にどれだけ動いたかで決まる、という読みは共通です。** 細かい帯の誤差の標準偏差は、実の平均の群内標準偏差とほぼ同じ大きさです（2.5〜3.0 Å: 誤差 0.260 Å に対して実の平均の広がり 0.270 Å、3.0〜3.5 Å: 0.258 Å に対して 0.282 Å、3.5〜4.0 Å: 0.307 Å に対して 0.334 Å、4.0〜4.5 Å: 0.369 Å に対して 0.392 Å）。接触の解離では、起点が境界に近いペアほど履歴の中でよく動くため、誤差も境界に近づくほど大きくなります。水素結合の解離では、動きの大きいペアが真ん中の帯に集まっていたため、誤差の山が真ん中に出ました。境界そのものが誤差を生むのではなく、その帯のペアがどれだけ動くかが効いています。
- (c) では隔たり 21以上の候補で誤差が 0.350 Å と最も大きく、2〜5 の 0.251 Å に対して 1.40 倍です。接触の形成（K35）では同じ比が 1.45 倍、水素結合の解離（K67）では 2.10 倍でした。なお、接触の候補は隔たりが2以上と決まっているため、「隣り合う残基」の帯は 0件です（K35 と同じ）。
- ラベルとの関係では、誤差とラベルの相関が −0.265 で、合成の −0.188 より強く出ました。解離したペアほど誤差が負の側に大きく、誤差がラベルを逆向きに予測します（AUC 0.296、裏返すと 0.704）。接触の形成（K35）でも、実際の誤差のラベルとの関係は合成より強く出ました（相関 +0.170 に対して合成 +0.089）。符号は逆ですが、接触では形成・解離とも、誤差のラベルとの関係が縮みだけでは説明できない強さで出ます。なお、解離の陽性率は 8.0% で、形成の 1.3% よりずっと高く、相関の数値は形成より安定しています。
- 方式の違いはどの分け方でも小さく、第11〜14案は同じ形でした。全体の誤差は、接触の形成（第22案の標準偏差 0.435 Å）や水素結合の解離（第14案の標準偏差 0.387 Å）より小さく（第14案の標準偏差 0.305 Å）、全体のずれも小さいです（−0.072 Å）。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離でも、外れたペアで誤差が大きい形は水素結合の解離と共通です（中心の 2.79 倍）。ただし境界に近づくほど誤差が大きくなる勾配もあり、そこは水素結合の解離とも接触の形成とも違います。先に固定した読み方に照らすと、裾の形は共通で、境界の形は接触の解離だけのものです。
- 判断できること: 誤差の大きさは、その帯のペアが履歴の中で実際にどれだけ動いたかで決まります。細かい帯の誤差は、実の平均の広がりとほぼ同じ大きさです。
- まだ分からないこと: 1.0 Å 以上外れた帯は 316件と少なく、その多くが起点 4.0〜4.5 Å の帯から来ています（210件）。別のタンパク質の組み合わせでも同じ形になるかは、まだ確かめていません。また本実験は生成の平均の誤差の出方を測ったもので、誤差がモデルの予測にどれだけ響くかは K58 の置き換えの測定の話です。
