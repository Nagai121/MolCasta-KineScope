# G04: 短い実MDの計算量は本当に安いか

- 確かめること: G02 で、0.1 ns の切り取りだけでも指導力の 0.570 が戻ると分かった。ただし G02 は実の履歴を切っただけで、短い実MDを実際に回す計算量は測っていない。この実験では、GROMACS で短い実MDを 0.1 ns と 1 ns で実際に回し、かかった実時間を測る。準備と平衡化の時間もあわせて測る。
- 状態: 進行中。

## 1. 何を確かめる実験か

資料Dのテストタンパク質のうち1つ（1mix_A、206残基）で、GROMACS による短い実MDを 0.1 ns と 1 ns で実行し、かかった実時間を測る。準備（トポロジー作成・箱・水・イオン・エネルギー最小化）と平衡化（NVT 100 ps・NPT 100 ps）にかかる時間もあわせて測り、0.1 ns の実行全体が 1 ns の実行全体の何分の1になるか出す。

読み方は先に固定した。0.1 ns の実行が 1 ns の実行の 3分の1 以下の時間で終われば、短い実MDの経路は計算量の面でも成り立つ。3分の1 を超えるようなら、固定の準備時間が大きく、短くするだけでは安くならない。その場合は、どこに時間がかかっているかも記録する。
