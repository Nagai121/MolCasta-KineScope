# K67 水素結合の解離でも、生成の平均の誤差の形は同じか（K46 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。解離でも、誤差は外れたペアで大きく、境界の近くで特に大きくなる形ではありません。形成（K30）と同じ形ですが、裾の外れ方は解離のほうがずっと極端です。

## 1. 何を確かめる実験か

形成では、生成の平均の誤差が境界の近くで大きくならず、実の平均が全体の平均から外れたペアで大きいことが分かりました（K30）。解離でも同じか確かめます。

読み方は先に固定しました。解離でも誤差が境界の近くで大きくならず、外れたペアで大きければ、形成と同じ形です。境界の近くで大きければ、解離は違います。

## 2. 条件

- 対象は K46 の水素結合の解離の候補 6,131件（資料Dの条件）です。誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は K26・K30 と同じ約束（分岐4本 × 起点＋8ステップの36値の平均）です。生成の系列は K54 の作り直し版（第11〜14案、残基レベルの生成方式）を使います。第22案は形成だけの方式のため測りません。
- 分け方：(a) 起点の距離の帯（境界付近 3.0〜3.5 Å と、それ以外 3.0 Å 以下。細かく 0.5 Å 刻みでも測った）、(b) 実の平均の全体の平均（2.830 Å）からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30 と同じ区切り）。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。

## 4. 読み取り

- **境界の近くで誤差が特に大きくなる形ではありません。** 境界付近（3.0〜3.5 Å）の誤差は 0.414 Å、それ以外は 0.372 Å で、比は 1.11 倍と小さいです。形成（K30）では境界付近がむしろやや小さく（0.451 Å に対してそれ以外 0.494 Å、比 0.91 倍）でしたが、解離でも境界が誤差の山ではありません。細かい帯で最も誤差が大きいのは境界ではなく 2.5〜3.0 Å（0.578 Å）で、2.0〜2.5 Å は 0.076 Å と最も小さいです。
- **誤差は、ペアが実際にどれだけ動いたかで決まります。** 細かい帯の誤差の標準偏差は、実の平均の群内標準偏差とほぼ同じ大きさです（2.0〜2.5 Å: 誤差 0.076 Å に対して実の平均の広がり 0.039 Å、2.5〜3.0 Å: 0.578 Å に対して 0.570 Å、3.0〜3.5 Å: 0.414 Å に対して 0.432 Å）。2.0〜2.5 Å のペアは強く結ばれたまま動かず、生成の平均もよく合います。2.5〜3.0 Å の帯は、動かないペアから大きく離れるペアまで混ざっているため（実の平均の範囲 2.63〜7.91 Å）、誤差が大きくなります。起点が境界に近いかどうかではなく、そのペアが履歴の中で実際に動いたかどうかが効いています。
- **外れたペアで誤差が大きい形は、形成と同じですが、解離のほうがずっと極端です。** (b) では、実の平均が全体の平均から 1.0 Å 以上離れた候補（227件）で誤差が 1.041 Å になり、中心（0.25 未満）の 0.157 Å に対して 6.63 倍です。形成（K30）では同じ比が 2.24 倍でした。さらに解離では、この帯の誤差がすべて負の側に出ます（全体のずれ −1.550 Å、平均絶対値も 1.550 Å）。この帯の実の平均は 3.83〜9.57 Å とすべて全体の平均より上にあり、生成の平均は 2.53〜3.69 Å の範囲に留まります。つまり、履歴の中で大きく離れたペアについて、生成の平均は起点の近くに留まったままで、実の平均についていけていません。この帯のペアは起点の距離では 2.5〜3.0 Å が 92件、3.0〜3.5 Å が 134件で、2.0〜2.5 Å は 1件だけです。
- (c) では隔たり 21以上の候補で誤差が 0.555 Å と最も大きく、隣り合う残基の 0.264 Å に対して 2.10 倍です。形成（K30）では同じ比が 1.26 倍でした。解離でも隔たりの効果が強く出ます。
- 方式の違いはどの分け方でも小さく、第11〜14案は同じ形でした。全体の誤差の大きさも解離のほうが形成よりやや小さく（第14案の標準偏差 0.387 Å、形成の第22案は 0.483 Å）、全体のずれも小さいです（−0.094 Å、形成は −0.155 Å）。全体の数値だけ見ると解離のほうが誤差は小さいですが、裾の外れ方は解離のほうがはるかに極端で、全体の数値では見えません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 解離でも、生成の平均の誤差は境界の近くで特に大きくならず、外れたペアで大きくなります。先に固定した読み方に照らすと、形成と同じ形です。ただし裾の外れ方は解離のほうがずっと極端で（中心の 6.6 倍、形成は 2.2 倍）、しかも誤差がすべて負の側に出ます。生成の平均は、履歴の中で大きく離れたペアについていけていません。
- 判断できること: 誤差の大きさは、起点が境界に近いかどうかではなく、そのペアが履歴の中で実際に動いたかどうかで決まります。細かい帯の誤差は、実の平均の広がりとほぼ同じ大きさです。
- まだ分からないこと: 1.0 Å 以上外れた帯は 227件と少なく、その多くが 2.5〜3.5 Å の起点から来ています。別のタンパク質の組み合わせでも同じ形になるかは、まだ確かめていません。また本実験は生成の平均の誤差の出方を測ったもので、誤差がモデルの予測にどれだけ響くかは K54 の置き換えの測定の話です。
