# GA332 拡張した静的予測を確認

GA321と同じ確認8配列、先頭起点、3,586ペア。動的出力は同じものを再利用し、GA318とGA330の静的予測を半々に混合。選定側で決めた係数だけを実行。相関はGA321 0.674013、GA332 0.675531、誤差SD 0.410034 Å。タンパク質単位2,000回再標本化による相関の記述的区間は0.641315–0.706857、同じ再標本でのGA321との差は−0.001271～+0.003458。点推定の0.700は未達。
別の予約8配列4,167ペアでは相関0.596249、誤差SD 0.440546 Å。条件と係数はその配列の成績を見る前に固定した。配列再標本化区間0.554247–0.625034。従来パネルの点推定0.675531を一般化できない。
