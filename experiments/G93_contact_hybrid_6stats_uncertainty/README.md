# G93: 接触の形成の混合で、切り取りを 6 個の統計量にした場合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G84・G87 では、切り取り 0.1 ns の 6 個の統計量に生成平均を足した混合の差が +0.05 を超えたのは、1 ns先の第13案 +0.073・第14案 +0.096、5 ns先の第11案 +0.067、50 ns先の第14案 +0.071 の4セルでした。1・5・50 ns先 × 第11〜14案について、混合と切り取り 6統計量だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G59・G62・G67 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（1 ns先の第13・14案、5 ns先の第11案、50 ns先の第14案）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの接触の形成です。G84・G87 と同じ段取りで、実側は K13 キャッシュ（`~/workspace/kinescope/work/k13_cache/`、候補は最小距離が 4.5 Å 以下の残基ペア、ラベルは予測幅で 4.5 Å 以下）と、生成平均は K17 の残基レベル生成系列（第11〜14案）の分岐平均の9点系列を 9点で平均したものを使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（15,926件）、テスト 1mix_A＋2qt4_A（7,384件、うち 1mix_A 5,012件・2qt4_A 2,372件）。静的特徴は5個、履歴は残基間最小距離の系列の6統計量（4.5 Å 以下だった割合）です。対応付けは位置で取っており、K17 のファイルに保存された実側（X、hist、y）が K13 キャッシュと配列単位で一致することを確かめました。生成器のチェックポイントは読み込んでいません。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）の 6 個の統計量です（G84・G87 と同じ）。6統計量は [最初のフレーム、平均、標準偏差、最小、最後−最初、4.5 Å 以下だった割合] で、2フレームの系列から計算します。生成平均は、生成系列の平均です。なお、切り取りの平均だけの回復率も照合のために測り直しました（1 ns先 0.4379、5 ns先 0.4358、50 ns先 0.3623、G13・G36・G63 の記録と一致しました）。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り 6統計量だけ、生成平均だけ（第11〜14案）、混合（切り取り 6統計量＋生成平均、別々の特徴量として 7列。第11〜14案）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り 6統計量だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G84・G87 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（5,012件）と 2qt4_A（2,372件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り 6統計量だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G84・G87 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 結果

3つの予測幅すべてで、静的のみ・全部入り・切り取り 6統計量だけ・切り取りの平均だけ・生成平均だけ（第11〜14案）・混合（第11〜14案）の合算 AUPRC が G84・G87 の記録と小数第4位まで一致しました。実履歴の利得は、1 ns先 +0.2271、5 ns先 +0.2322、50 ns先 +0.2034 です。

| 5 ns | **+0.067 [+0.067, +0.079]** | −0.050 [−0.144, +0.002] | −0.004 [−0.041, +0.015] | +0.036 [−0.062, +0.094] |
| 50 ns | +0.030 [+0.013, +0.167] | +0.007 [+0.002, +0.013] | +0.006 [−0.022, +0.095] | **+0.071 [+0.071, +0.179]** |

## 判断

先に固定した読み方に沿うと、+0.05 を超えた4セルのうち、**区間が 0 を含まないのは3セル**で、**0 を含むのは 1 ns先の第13案だけ**です。

- 1 ns先の第13案の区間 [−0.092, +0.164] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で +0.164、2qt4_A で −0.092）。1 ns先の +0.073 は、2タンパク質で向きが定まらない位置づけです。
- 1 ns先の第14案 [+0.034, +0.107]、5 ns先の第11案 [+0.067, +0.079]、50 ns先の第14案 [+0.071, +0.179] は、いずれも 0 を含みません。2タンパク質とも差が正です。ただし 5 ns先の第11案と 50 ns先の第14案は、区間の下限が点推定とほぼ同じ値（+0.067、+0.071）で、区間は点推定の真上だけに広がっています。2タンパク質のうち小さい方の差が点推定とほぼ同じ値で、もう一方の差だけが大きいためです（5 ns先の第11案は 1mix_A で +0.068、2qt4_A で +0.079。50 ns先の第14案は 1mix_A で +0.078、2qt4_A で +0.179）。

+0.05 を超えなかったセルでは、1 ns先の第12案の区間 [−0.061, −0.044] は 0 を含まず負で、2タンパク質とも差が負です。50 ns先の第11案の区間 [+0.013, +0.167] と第12案の区間 [+0.002, +0.013] は 0 を含まず正ですが、点推定が +0.030・+0.007 と +0.05 の線には届きません。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・案ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約4分でした。
