# L70: L01 の曲がりを塩橋の解離で測る（統計量6種、K15 の土台、5 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L34（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（解離 L69〜L74）の 5 ns先です。
- 状態: 完了。平均だけと同じく、フレーム0の時点で両方の線に届いていて、その後は高い水準で推移しました。必要な長さの縮みは 0 です。統計量6種の回復率は中間から長い長さで 1 を超え、0.8 ns で 1.385 まで上がりました。

## 1. 何を確かめる実験か

L69 と同じ段取りで、予測幅だけを 5 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、5 ns先の陽性 139件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

### 先に固定した読み方への答え

1. **回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 0.922）**。平均だけも 0 ns で、**縮みは 0** でした。平均（タンパク質平均）ではどちらも 0.4 ns でした。
2. **増え幅がいちばん大きい場所: 全体では 0.3→0.4 ns（+0.354）**。段の位置でのタンパク質ごとの増え分は中央値 +0.182、正だったのは 15タンパク質のうち 60% で、段とは読めません。
3. 長さごとの回復率の差（6種 − 平均、全体）は、短い側で負（0.1 ns で −0.234）、0.4 ns 以降はほぼ正で、0.9 ns で +0.360 でした。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 5 ns先は、平均だけでもフレーム0で線に届く予測幅で（L34）、読みの主眼では差が出ませんでした。
- 点推定では、統計量6種の条件が 0.4〜0.9 ns で全部入りを上回ります（最大 0.8 ns で AUPRC 0.6218、全部入り 0.5780）。短い範囲の6種が全範囲の6種より良いという形で、区間は広いため水準の記録にとどめます。
