# GA321 スケールした静的モデルと2力場の確認

選定3配列の先頭起点で固定した推定式を、従来の確認8配列・先頭起点3,586ペアに適用。GA312と同じ候補でPearson相関0.674013、誤差SD 0.411060 Å。GA312は0.637262、GA305は0.576715。個別配列は0.599326～0.757345。0.700の判定はプール相関であり未達。

推論入力は単一の静的起点。Amber14/OBC2 100 ps×8（4 fs）、CHARMM36_2024/GBn2 100 ps×2（2 fs）とGA318 all-8を固定して使用。融合の学習・選定には確認ペアの履歴を使っていないが、比較先は継続確認パネル。元のGA305全22起点9,843ペアとは区別する。別にCA数で層化したGA確認パネルを予約した。予約に使った情報は構造ファイルの可用性とCA数であり、相関は未確認の時点で固定した。
