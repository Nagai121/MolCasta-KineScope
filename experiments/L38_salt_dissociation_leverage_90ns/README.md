# L38: L01 の曲がりを塩橋の解離で測る（K15 の土台、90 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 90 ns先で、解離の担当分はここまでです。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は 0.312〜1.410 の範囲で大きく上下し、分母の利得も小さい（全体 +0.0582）ため、曲がりの形は決められませんでした。先に固定した読み方を機械的に当てた結果は併記しますが、結論には使いません。

## 1. 何を確かめる実験か

L33 と同じ段取りで、予測幅だけを 90 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、90 ns先の陽性 160件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.4824、全部入り 0.5405、利得 全体 +0.0582／平均 +0.0343 で、K2-33 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G69 の平均だけの走査と一致しました（覆う長さに直して 0.1 ns で 1.060、0.2 ns で 0.312、0.5 ns で 0.996）。

### 先に固定した読み方への答え（機械的な適用の結果）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0.1 ns（全体 1.060）。ただし次の 0.2 ns では 0.312 まで落ち、持続しません。
2. 増え幅がいちばん大きい場所: 全体では 0.6→0.7 ns（+0.496）、平均では 0.3→0.4 ns（+0.893）。全体の段の位置でのタンパク質ごとの増え分は中央値 +0.038、正だったのは 18タンパク質のうち 50% で、段とは読めません。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 90 ns先では、分母の利得（+0.0582）が小さく、回復率の点推定も長さごとに大きく上下するため、曲がりの形は決められません。形成の 50 ns先（L31）と同じ事情です。
- AUPRC の水準としては、切り取りの平均を入れた条件（全体 0.50〜0.56）が静的のみ（0.4824）と全部入り（0.5405）の周辺にあり、長さに対する傾向は見えません。
- 解離の 6つの予測幅を通すと、読みやすいのは利得の大きい 1 ns先（L33）と 10 ns先（L35）で、30 ns先（L36）は平均だけが全部入り以上という形、50 ns先（L37）は 0.5 ns で頭打ち、90 ns先は形が決められない、という結果でした。
