# L34: L01 の曲がりを塩橋の解離で測る（K15 の土台、5 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 5 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率はフレーム0だけ（覆う長さ 0 ns）ですでに 0.922 あり、全長さを通して 0.71〜1.30 の高い水準でほぼ平らでした。長くしても大きくは変わりません。

## 1. 何を確かめる実験か

L33 と同じ段取りで、予測幅だけを 5 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、5 ns先の陽性 139件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.4641、全部入り 0.5780、利得 全体 +0.1139／平均 +0.0787 で、K2-42 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G69 の平均だけの走査と一致しました（覆う長さに直して 0.1 ns で 0.918、0.2 ns で 0.712、0.5 ns で 0.912）。

### 先に固定した読み方への答え

1. **回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 0.922）**。平均では 0.8 が 0.5 ns（0.849）、0.9 が 0.6 ns（1.435）です。
2. **増え幅がいちばん大きい場所: 0.5→0.6 ns（全体 +0.301、平均 +0.587）**。段の位置でのタンパク質ごとの増え分は中央値 +0.086、正だったのは 15タンパク質のうち 53% で、段と呼べる揃い方ではありません。曲がり全体が高い水準で平らなため、この読みは実質的には意味を持ちません。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 5 ns先では、履歴の最初のフレームの距離だけで利得の 9割強が戻り、平均の範囲を広げても水準は変わりません。1 ns先（L33）の「緩やかに積み上がる」形とも違い、最初から高い形です。
- 区間が広いため、0.6 ns や 0.8 ns の高い値（1.213、1.299）が本当に頂点かどうかは決められません。言えるのは「短い切り取りでほぼ戻り、長くしても悪くはならない」という大まかな形までです。
