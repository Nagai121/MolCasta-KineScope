# G52: 塩橋の解離で、0.25 ns の切り取りはどうなるか（K53 の条件、塩橋の解離、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDの経路の続き。G09 では 0.1 ns の切り取りの平均だけが 0.693、0.5 ns の切り取りの平均だけが 0.951 だった。そのあいだの 0.25 ns の切り取りはまだ測っていない。0.25 ns の切り取りの平均だけと 6 統計量の両方を入れる。
- 状態: 完了。0.25 ns の 6 統計量の回復率は 0.652 で、0.8 の線には届かず、0.5 未満でもない。先に固定した読み方に沿うと、部分的にしか戻らない。平均だけは 0.716 と、6 統計量よりやや良い。

## 1. 何を確かめる実験か

K53 の条件（塩橋の解離、1 ns先）で、0.25 ns（フレーム [0,1,2]、実際に覆う長さは 0.2 ns）の切り取りの平均だけと 6 統計量の両方を補正モデルに入れる。0.1 ns と 0.5 ns の条件もあわせて測り、G09 と合うかで手順の正しさを確かめる。参照は実履歴の利得で、+0.1788（K53 と一致）。回復率は実履歴の利得に対する比で測る。

6 統計量の定義は K53 と同じ（閾値 4.0 Å）: [最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合] を切り取りのフレームで計算する。

判定は先に固定した。0.25 ns の 6 統計量が 0.8 以上になれば、塩橋の解離でも 0.25 ns の切り取りで短い実MDの道が立つことになる。0.5 未満なら、0.25 ns の切り取りでは足りないことになる。そのあいだなら、部分的にしか戻らないことになる。

## 2. 条件

- 土台は K53 の条件。ATLAS 解析版、学習58タンパク質（735件）・テスト30タンパク質（360件、1 ns先の陽性 101件、陽性率 28.1%）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 塩橋の解離の候補（K53 と同じ）: 正側（LYS の NZ、ARG の NE/NH1/NH2）と負側（ASP の OD1/OD2、GLU の OE1/OE2）の荷電重原子ペアの最小距離が、起点で 4.0 Å 以下（塩橋ができている状態）で配列距離2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å を超えること。静的特徴は5個、履歴の閾値は 4.0 Å。
- 切り取りの定義（G02/G09 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。0.1 ns → フレーム 0, 1（2フレーム）、0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さ 0.2 ns）、0.5 ns → フレーム 0〜5（6フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴だけ。
- 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
- 平均だけ（0〜1 ns）: 静的特徴＋0〜1 ns の平均だけ。
- 切った平均だけ: 静的特徴＋切った履歴の平均だけ（0.1 / 0.25 / 0.5 ns）。
- 切った6統計量: 静的特徴＋切った履歴の6統計量全部（0.1 / 0.25 / 0.5 ns）。

## 3. 結果

### 土台の再現

静的のみと全部入りが、K53 の記録と小数第4位まで完全一致した。1 ns先で静的のみ AUPRC 0.3734、全部入り 0.5522、利得 +0.1788。0.1 ns と 0.5 ns の条件も G09 と完全一致した（0.1 ns の平均だけは AUPRC 0.4973・回復率 0.693、0.1 ns の 6 統計量は AUPRC 0.4745・回復率 0.566、0.5 ns の平均だけは AUPRC 0.5434・回復率 0.951、0.5 ns の 6 統計量は AUPRC 0.5495・回復率 0.985）。

## 4. 読み取り

- **0.25 ns の 6 統計量の回復率は 0.652 で、0.8 の線には届かず、0.5 未満でもない。** 先に固定した読み方に沿うと、部分的にしか戻らない。0.25 ns の切り取りで短い実MDの道が立つ、とは言えない。
- 平均だけと 6 統計量では、どちらも長さに対して単調に上がる。平均だけは 0.693 → 0.716 → 0.951、6 統計量は 0.566 → 0.652 → 0.985。塩橋の形成（G27/G43）の 6 統計量の上下（0.685 → 0.334 → 0.716 → 0.511）とは対照的で、解離では切り取りを長くすれば 6 統計量も素直に良くなる。
- どの長さでも、平均だけのほうが 6 統計量より良いか、ほぼ同じ（0.1 ns では 0.693 に対して 0.566、0.25 ns では 0.716 に対して 0.652、0.5 ns では 0.951 に対して 0.985 とほぼ同じ）。G09 の読み取りにもあるとおり、短い切り取りから作った他の統計量は、解離の候補ではほとんど変化がなく、むしろ読み出しを乱す側に働く。0.25 ns でも同じ形。
- 0〜1 ns の平均だけの回復率は 0.921 と、塩橋の形成（0.889）より高い。解離では平均が利得の大半を持つ。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.25 ns の 6 統計量は 0.652 と部分的にしか戻らない。平均だけは 0.716 と、6 統計量よりやや良い。解離では 6 統計量も長さに対して単調に上がる。
- まだ分からないこと: テストは 360件と小さく、1 ns先の陽性も 101件なので、回復率の揺れは形成（1,170件）より大きい条件。単一の学習 seed の結果でもある。0.25 ns の 6 統計量と平均だけの差（−0.064）が、統計量の性質によるものか、テストの揺れかは、この測定だけでは分けられない。
