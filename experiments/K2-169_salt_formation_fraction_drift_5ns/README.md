# K2-169: K2-15 の問い（漂い）を割合で測る（塩橋の形成、5 ns先）

- 状態: 完了。全部の割合＋漂いは 0.3140 で、全部の割合だけ（0.3148）を 0.0008 下回り、先に固定した読み方では「漂いは足しにならない」。差はほぼゼロです。

## 仮説

H7（実軌道が持つ追加の観測情報）に関わる検証で、K2 系列（指導力の正体を探る系列）の一つです。K2-15 の問い（漂い）を割合で測ります。漂いは、前半の割合から後半の割合を引いたもの（前半の割合 − 後半の割合）で、割合はペアの荷電重原子間の最小距離が塩橋の閾値（4.0 Å）以下の時間の割合です。

読み方は K2-15 と同じく先に固定しました。全部の割合＋漂いが全部の割合だけを AUPRC で +0.01 以上上回れば「漂いが足しになる」、そうでなければ「足しにならない」とします。

## データと条件

- K15 の条件（58 タンパク質で学習、30 タンパク質でテスト、起点 1 ns、履歴 0〜1 ns、HistGBM を条件ごとに学習し直し）で、塩橋の形成、5 ns先、割合だけです。学習 2,557件、テスト 1,170件、テスト陽性 129件です。キャッシュは `~/workspace/kinescope/work/k15_cache/`（塩橋の形成の候補ごとの荷電重原子間の最小距離の 11 フレーム系列）を使っています。静的特徴は 5 個です。
- 実行はローカルの仮想マシンで行いました（8 条件の学習で約 7 秒。K2 系列では重い計算は Colab に逃がす決め事がありますが、この規模は重い計算にはあたらないと判断しました）。sklearn の学習はスレッド数を 1 に絞りました。

### 条件の一覧（5 ns先）

- 静的のみ: 静的特徴 5 個だけ（土台の照合用）。
- 全部入り: 静的特徴＋全部の 6 個の統計量（0〜1 ns の 11 フレーム）。6 個の統計量は [最初, 平均, 標準偏差, 最小, 最後−最初, 4.0 Å 以下だった割合]。利得の分母（全部入りの利得）の参照。
- 前半の割合だけ: 静的特徴＋前半（フレーム [0..4]、0〜0.4 ns）の 4.0 Å以下割合（K2-139 との照合用）。
- 後半の割合だけ: 静的特徴＋後半（フレーム [6..10]、0.6〜1.0 ns）の 4.0 Å以下割合（K2-139 との照合用）。
- 前半と後半の両方（割合だけ）: 静的特徴＋前半の割合＋後半の割合（K2-139 との照合用）。
- 全部の割合だけ: 静的特徴＋全部（フレーム [0..10]）の 4.0 Å以下割合。(b) の比較対象。
- 漂いだけ: 静的特徴＋漂い（前半の割合 − 後半の割合）だけ。(a) の比較対象。
- 全部の割合＋漂い: 静的特徴＋全部の割合＋漂い。(c) の比較対象。

フレーム 5（0.5 ns）は前半にも後半にも入らない設計です。K2-01 と同じ分け方で、前半と後半をきれいに分けるためです。5 ns先には塩橋の形成の平均だけの記録がないため、全部の平均だけの条件は入れていません（K2-141 と同じ扱い）。

### タンパク質ごとの差 (c)−(b)

30タンパク質のうち、差が +0.01 以上のものが 10、0 未満のものが 13、ちょうど 0 のものが 5、0 以上 +0.01 未満のものが 2 です。差が大きいタンパク質は 3pkz_A +0.2232、6jpt_A +0.1549、1l9l_A +0.1196 で、差が小さい（負の方向に大きい）タンパク質は 3bwu_D −0.5000、1u6t_A −0.2571、2hu9_A −0.1548、3l9a_X −0.1250 です。タンパク質ごとに符号が大きく分かれました。なお、results.json のタンパク質ごとの記録では、AUC が決まらない 4 タンパク質（2qt4_A・2ftx_A・1pch_A・6fc0_B）の AUC を空欄（null）にした。どれも陽性が 0 件のためである。初版では NaN が入っていて、ファイル単体では値があるように見えたため、2026-11-25 に直した。

## 判断

先に固定した読み方に沿うと、**(c) 全部の割合＋漂い 0.3140 − (b) 全部の割合だけ 0.3148 = −0.0008 < +0.01 なので、「漂いは足しにならない」** です。差はほぼゼロで、漂いを足しても何も変わりません。

平均の漂いでも、塩橋の形成の 5 ns先では漂いが足しになるかどうかは、この実験だけでは決められません（5 ns先の平均の漂いの記録は、この実験の時点ではまだありません）。漂いだけの利得は +0.0637（全部入りの利得に対する割合 0.808）で、漂いだけでも全部の割合（0.3148）とほぼ同じ AUPRC がありますが、全部の割合に足しても上乗せにはなりませんでした。(c) は前半と後半の両方（0.3051）を上回ります。

## 読みの注意点

- 5 ns先では 4 つのテストタンパク質（2qt4_A、2ftx_A、1pch_A、6fc0_B）に陽性が 1 件もありません。そのタンパク質の AUPRC は sklearn の慣例で 1.0、AUC は定義されません。合算の数値には影響しません。
- タンパク質ごとの候補数が 8〜92件と少なく、タンパク質ごとの AUPRC の差は大きく振れます（3bwu_D −0.5000 など）。タンパク質ごとの差の読みは粗いものとして扱ってください。
