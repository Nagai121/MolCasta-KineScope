# L2-32: 区間を起点フレーム10の直前に置き直した測り直し（接触の解離、統計量6種、資料Dの条件、予測幅 1/5/10/30/50/90 ns）

- 状態: 完了。前提確認（長さ 1.0 ns の点で L57〜L62 の記録と一致すること）は、6つの予測幅すべてで一致した（静的のみ・全部入りの AUPRC と利得が、表示した範囲で記録値と完全に同じ）。区間を起点の直前に置くと、0.1 ns の回復率は 0.35〜0.53 になり、L の同じ長さ（0.66〜0.94）より全予測幅で低くなった。回復率 0.8 に届く長さは、90 ns先で 0.9 ns（L では 0.1 ns）と大きく伸びた一方、50 ns先では 0.5 ns（L では 0.7 ns）と短くなり、予測幅によって向きが違った。長さ 0（フレーム10だけ）の回復率は全予測幅でちょうど 0 で、L の長さ 0（フレーム0だけ）の 0.55〜0.79 とは対照的だった。接触の解離でも、静的な特徴に起点フレームの距離が含まれているため、フレーム10だけの統計量は静的な予測に何も足さない。

## 1. 何を確かめる実験か

L57〜L62（接触の解離、統計量6種、資料Dの条件）と同じ土台・同じ候補・同じ予測器で、履歴の区間だけを置き直して、回復率の曲がりを測り直す。

L では区間は先頭から（フレーム 0〜k）で、短い長さでは起点フレーム10との間に時間の空きがあった。E01 で、この空きが回復率を水増ししていたことが分かっている（E01 の Protocol A は、区間を起点の直前に置く置き方）。ここでは区間を起点フレーム10の直前に置き、L と同じ読み方で測る。

## 2. 条件

- 土台: 資料Dの条件（K50 のキャッシュ）。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（6,383件）、テストは 1mix_A と 2qt4_A（候補 2,915件）。予測器は L57〜L62 と同じ HistGradientBoosting（120回、学習率 0.075、葉31、最小葉15、L2 0.02、種 42）で、条件ごとに学習し直す。特徴量の型も L57〜L62（G71）と同じ作り方（静的特徴は float64、区間の平均と6統計量は float32）にそろえた。型の違いが回復率をずらすことが L23〜L26 で分かっているためである。
- 区間: 覆う長さ L ns の区間は、フレーム (10 − L/0.1) 〜 10 の L/0.1 + 1 フレーム。長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10。長さは 0〜1.0 ns の11通り。
- 統計量6種は資料Dの定義（最初・平均・標準偏差・最小・最後−最初・4.5 Å以下の割合）を、その区間のフレームで計算する。区間の「最初」は区間の先頭フレーム、「最後」は常にフレーム10。
- 条件は、静的のみ、全部入り（フレーム 0〜10 の6統計量、回復率の分母の参照）、区間の6統計量（11通り）、区間の平均だけ（11通り、平均だけの形との比較用）。
- 回復率 = (その長さの AUPRC − 静的のみ) / (全部入りの利得)。
- 読み方（L と同じ）: 回復率 0.8 と 0.9 に最初に達する長さ（全体）、隣り合う長さの間の最大の増え幅、信頼区間は全体・1mix_A・2qt4_A の3値の最小〜最大。増え幅が最大の場所ではタンパク質ごとの値も記録する（タンパク質ごとの回復率は全長さで記録）。
- 前提確認: 長さ 1.0 ns の点は区間がフレーム 0〜10 になり L と同じ条件になる。静的のみ・全部入りの AUPRC と利得が L57〜L62 の記録と 5e-4 以内で一致しなければ止める、と先に決めた。結果は6つの予測幅すべてで、表示した小数第6位まで記録値と一致した。

## 4. 読み取り

- **長さ 0 の意味が、L と L2 で違う。** L の長さ 0（フレーム0だけ）の回復率は 0.55〜0.79 あったが、これは「履歴なし」ではなく、静的な特徴に含まれていないフレーム0の距離を持ち込んだ値である。L2 の長さ 0（フレーム10だけ）は、起点の距離が静的な特徴にすでに含まれているため、回復率はちょうど 0 になる。L2-31（接触の形成）でも同じ形だった。
- **短い長さの回復率は、置き直しで大きく下がった。** 0.1 ns の回復率は L の 0.66〜0.94 から 0.35〜0.53 になった。とくに 90 ns先では、L の 0.1 ns の 0.9378 に対して置き直しでは 0.3801 で、0.8 と 0.9 の両方の線に届く長さが 0.1 ns から 0.9 ns に伸びた。L の短い長さの高い回復率は、起点から離れた区間（フレーム0の距離の持ち込みを含む）による部分が大きかった。
- **必要な長さの向きは予測幅によって違う。** 0.8 の線では、1 ns先・5 ns先・30 ns先で L より長くなり（0.2→0.4 ns、0.2→0.3 ns、0.2→0.3 ns）、10 ns先で同じ（0.3 ns）、50 ns先で短くなった（0.7→0.5 ns）。90 ns先の伸び（0.1→0.9 ns）が突出している。
- **平均だけとの比較（同じ実行）:** 統計量6種は、5 ns先・10 ns先・30 ns先では平均だけより短い長さで線に届くか、平均だけでは届かない線に届いた。例外は 1 ns先で、0.8 の線も 0.9 の線も平均だけのほうが短かった（0.3 ns / 0.5 ns に対して統計量6種は 0.4 ns / 0.7 ns）。50 ns先は 0.8 の線で統計量6種が短く（0.5 ns 対 0.7 ns）、0.9 の線は同じ 0.8 ns。90 ns先は 0.8 の線が同じ 0.9 ns で、0.9 の線は統計量6種だけが届いた。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離（資料Dの条件）では、区間を起点の直前に置き直すと、短い区間の回復率は L の記録よりかなり低く、0.1 ns では利得の 0.35〜0.53 にとどまる。0.8 の線に届く長さは 0.3〜0.9 ns で、90 ns先では 0.9 ns が必要だった。L の記録（とくに長さ 0 と短い長さ）は、フレーム0の距離の持ち込みと区間の置き方の両方で押し上げられていた。
- まだ分からないこと: 90 ns先でだけ必要長さが突出して伸びる理由は、この実験では分からない。資料Dの条件はテストが2タンパク質だけなので、区間は3値の最小〜最大で粗く、短い長さではタンパク質ごとの値が大きく分かれる。
