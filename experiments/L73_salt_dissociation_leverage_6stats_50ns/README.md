# L73: L01 の曲がりを塩橋の解離で測る（統計量6種、K15 の土台、50 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L37（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（解離 L69〜L74）の 50 ns先です。
- 状態: 完了。平均だけでは届かなかった 0.9 の線に、統計量6種では 0.7 ns で届きました。0.8 の線は平均だけの 0.5 ns に対して 0.6 ns と、わずかに長くなりました。回復率そのものは長さごとに平均だけと上下が入れ替わり、一様な優劣はありません。

## 1. 何を確かめる実験か

L69 と同じ段取りで、予測幅だけを 50 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、50 ns先の陽性 166件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現と平均だけの照合

静的のみ AUPRC 0.4863、全部入り 0.6165、利得 全体 +0.1302／平均 +0.0305 で、L37 の記録と 5e-4 以内で一致しました。同じ実行で測り直した平均だけの回復率は、L37 の results.json の値と全長さで完全一致しました（最大の差 0.0）。統計量6種の 1.0 ns の回復率は 1.000 でした（`premise_check.json`）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.6 ns（全体 0.821）**。平均だけでは 0.5 ns で、0.1 ns 分長くなりました。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.7 ns（全体 0.934）**。平均だけではどの長さでも届かなかった（最大 0.893、L37）ため、縮み幅は定義できませんが、届かなかった線に届いたという違いはあります。
3. **増え幅がいちばん大きい場所: 全体では 0.9→1.0 ns（+0.299）**。ただし 1.0 ns の条件は全部入りと同一の特徴量で回復率が 1.0 になることが決まっているため、この増え分は段ではありません。内側の区間では 0.5→0.6 ns の +0.201 が最大です。タンパク質ごとの増え分（0.9→1.0 ns）は中央値 +0.069 でした。
4. 長さごとの回復率の差（6種 − 平均、全体）は −0.273〜+0.246 の範囲で正負が入れ替わり、一様な優劣はありません。
5. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 50 ns先は平均だけでは頭打ちだった予測幅（L37）で、統計量6種では 0.7 ns で 0.934 まで上がりました。ただし 0.8 ns 以降は再び下がるため、「0.7 ns で届く」は1点の到達として記録します。
- 区間は全体で幅 0.65〜1.32 と広く、0.4〜1.0 ns の間の順序は決められません。
