# G39: 50 ns先で、0.1 ns の切り取りに生成した平均を足すとどうなるか

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G17 では 0.1 ns の切り取りで 1・10・30・90 ns先を測りましたが、50 ns先はまだ測っていません。K56 で 1 ns から 50 ns への読み出しの移しが弱い（0.608）こともあり、50 ns先は気になるところです。ここで 0.1 ns の切り取りの混合を 50 ns先で測ります。

読み方は実験前に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がれば、50 ns先でも 0.1 ns の切り取りで混合が足しになることになります。+0.05 未満なら、50 ns先では 0.1 ns の切り取りで混合は足しにならないことになります。

## データと条件

- 条件は資料Dの水素結合の形成、50 ns先です。G11・G14・G17 と同じ段取りで、K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/`）と K05 の生成系列（`experiments/K05_generated_quality/generated_series.npz`、第22案の5点系列）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（9,610件）、テスト 1mix_A＋2qt4_A（4,972件、50 ns先の陽性 325件）。静的特徴は7個、履歴はドナー・アクセプター距離の系列の6統計量（3.5 Å 以下だった割合）です。
- 0.1 ns の切り取りはフレーム [0,1]（2フレーム）で、平均はその2フレームの距離の平均です（G02 と同じ）。生成平均は、生成5点系列 [起点距離 d0（フレーム10）, +0.1, +0.3, +0.5, +1.0 ns] の平均です。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、土台候補 14,582件と 100% 対応しました。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å でした（G11・G14・G17 と同じ値）。
- 条件は次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、生成平均だけ、混合（切り取り平均＋生成平均の2列）。回復率は、その予測幅での実履歴の利得で割った値です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G11・G14・G17・K09 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。
- 50 ns先の参照の利得は、この実験で同じ土台で測りました（静的のみ 0.3342 → 全部入り 0.4081、利得 +0.0739）。

## 結果

| 条件 | AUPRC | 利得 | 回復率 |
|---|---:|---:|---:|
| 静的のみ | 0.3342 | — | — |
| 全部入り（実履歴） | 0.4081 | +0.0739 | 1.000 |
| 切り取り平均だけ（0.1 ns） | 0.3893 | +0.0551 | 0.745 |
| 生成平均だけ | 0.3663 | +0.0322 | 0.435 |
| 混合（切り取り平均＋生成平均） | 0.4167 | +0.0825 | 1.116 |

AUPRC はテストの合算です。AUC・Brier・Log Loss は `results.json` を参照。

混合と切り取り平均だけの差は、回復率で **+0.371**（AUPRC で +0.0274）です。

## 判断

先に固定した +0.05 の線で見ると、**50 ns先でも 0.1 ns の切り取りで混合は足しになります**。混合の回復率は切り取り平均だけより +0.371 上がり、実履歴の全部入りも上回ります（混合 0.4167 に対して全部入り 0.4081）。

50 ns先は、30 ns先（+0.489、G17）に続く、長い予測幅での大きな混合の上がり幅です。0.1 ns の切り取りでの混合の差を予測幅で並べると、1 ns先 +0.186（G11）、5 ns先 −0.169（G26）、10 ns先 −0.104（G17）、30 ns先 +0.489（G17）、50 ns先 +0.371（この実験）、90 ns先 +0.015（G14）で、効き目は予測幅とともに単調に衰えるのではなく、5・10 ns先で下がり、30・50 ns先で大きく上がる形です。K56 の読み出しの移しが 1 ns から 50 ns で弱い（0.608）ことと、ここでの混合の上がり幅が大きいことは、別の向きの話です。読み出しの移しは 1 ns で学習した補正を 50 ns に持っていくときの話で、ここでは 50 ns で学習し直した補正の中での混合の寄与を測っています。

生成平均だけでも回復率が 0.435 と、他の予測幅より高くなっています（1 ns先 0.093、10 ns先 0.246、30 ns先 0.294、90 ns先 0.265）。50 ns先では生成平均だけでも利得の4割ほど戻る点は、混合の上がり幅が大きいことと合わせて、50 ns先では生成平均が実の平均と違う情報を補う形になっていることを示しています。ただし、なぜ 5・10 ns先では下がり、30・50 ns先では上がるのかは、ここからは分かりません。

## 注意点

- 50 ns先の利得そのものが小さめ（+0.0739）で、テストの陽性も 325件と少ないため、回復率の揺れには注意が要ります。ただし混合と切り取り平均だけの AUPRC の差は +0.0274 と、回復率の見た目ほど小さくはありません。
- 実行は約20秒で終わりました。
