# K2-22: K2-08 の問い（平均の残りが前半と後半で続くか）を塩橋の形成で測る

- 確かめること: K2-08（水素結合の形成）と K2-17（接触の形成）では残りの平均の前半・後半の相関が +0.70 前後だった。塩橋の形成では担い手が分散している（K31）ため、残りの続き方も違うかもしれない。
- 状態: 完了。残りの平均の前半・後半の相関は、GBM の残りで合算のピアソン +0.641・スピアマン +0.619、線形の残りで +0.659・+0.645 だった。先に固定した読み方（絶対値 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」）に照らして、塩橋の形成でも、指導力を運ぶずれは前半から後半へ続いている。水素結合の形成（K2-08、GBM で +0.703）と接触の形成（K2-17、+0.719）よりやや弱いが、0.5 の線は超えた。3 つの現象で残りの平均の続き方は共通している。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-08 では、履歴の平均のうち静的な特徴量で予測できない部分（残りの平均）を作り、その残りが履歴の前半と後半で同じペアの値として続くかどうかを見た。水素結合の形成では合算ピアソン +0.703（GBM の残り）、接触の形成（K2-17）では +0.719 と、どちらも先に固定した 0.5 の線を超えた。ここでは、同じ問いを塩橋の形成で測る。塩橋の形成では担い手が分散している（K31）ため、残りの続き方も違うかもしれない。

測るものは K2-08 と同じく先に固定した。K15 の広げた条件のデータで、K2-08 と同じ形で残りの平均を出す（前半と後半の平均ごとに、K39 と同じ設定の GBM で静的な予測を作る）。前半（フレーム [0..4]）の平均の残りと、後半（フレーム [6..10]）の平均の残りの相関（ピアソンとスピアマン、合算とテスト 30 タンパク質ごと）を測る。比較のため、生の平均の前半・後半の相関も同じ形で記録する。

読み方は K2-08 と同じく先に固定した。相関の絶対値が 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」、0.3 未満なら「続いていない」と記録する。0.3 以上 0.5 未満の場合は、そのどちらでもない（中間）として数値をそのまま記録する。読み方の判定は合算の相関で行う。

## 2. 条件

- K15 の広げた条件。塩橋の形成の候補ペア。学習は 58 タンパク質（元の 4 ＋追加 54、2,557件）、テストは 30 タンパク質（元の 2 ＋追加 28、1,170件）。タンパク質の分け方は K15 の `split.json` の凍結した集合。起点はフレーム 10（1 ns）、履歴は 0〜1 ns の 11 フレーム。距離は荷電重原子ペアの最小値で、境界は 4.0 Å。候補は起点で最小距離が 4.0 Å 超〜10.0 Å 以下で、配列距離が 2 以上の残基ペア。
- 前半の平均は履歴フレーム [0..4] の最小距離の平均、後半の平均はフレーム [6..10] の平均（フレーム 5 は除く。K2-01・K2-08 と同じ分け方）。テストでの半分の平均は、前半 7.731 Å、後半 7.658 Å、全部の平均は 7.698 Å と、前半から後半へ 0.07 Å 縮む向きに動く（水素結合の形成では前半 5.079 Å から後半 5.016 Å へ 0.06 Å 縮んだ）。
- 静的な予測は、塩橋の静的な特徴量（X の 5 列: 起点の最小距離、Cα間距離、配列距離の log1p、正側が ARG か、負側が GLU か）から各半分の平均を予測したもの。線形回帰と HistGradientBoosting 回帰（K39 と同じ設定: 160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）の 2 通りで、どちらも学習側の候補だけで当てはめ、テスト側の統計は使わない。残りの平均 = 半分の平均 − 静的な予測。
- 予測は半分ごとに当てはめ直した。形成の候補は原点に向けて距離が縮む向きに動くため、前半と後半では平均の水準が系統的に違う。全部の平均に対する予測をそのまま当てはめると、その水準の違いが残りに混ざるためである。
- K2-08 のスクリプトと同じ形で、X は保存されたままの型で sklearn に渡した（K15 の保存値は (N, 11) の向きで、転置は要らない）。sklearn の学習はスレッド数を 1 に絞って、この仮想マシンで実行した（半分の平均に対する回帰 4 件だけで、軽い計算である）。
- 注意: 2hng_A の R3 と 4cv4_A の R2 はキャッシュで候補が 0 件（K15 の記録どおり）。0 件のファイルは読み飛ばした。
- 当てはまり: 前半は線形で R² が学習 0.413・テスト 0.404、GBM で学習 0.576・テスト 0.386。後半は線形で学習 0.675・テスト 0.682、GBM で学習 0.758・テスト 0.662。テストでの残りの平均の標準偏差は、前半が線形 2.024 Å・GBM 2.055 Å、後半が線形 1.140 Å・GBM 1.176 Å。塩橋の平均は静的に予測しにくく、特に前半は残りが大きい（水素結合の前半の残り 0.642 Å、接触の 0.509 Å と比べ、塩橋は 2.05 Å）。前半では GBM のテストの R²（0.386）が線形（0.404）を下回り、学習の R²（0.576）からも大きく落ちる。学習が 2,557件と少ないため、GBM が学習側に寄りすぎている。残りの相関は GBM と線形でほぼ同じ（+0.641 対 +0.659）なので、結論には影響しない。

## 3. 結果

### 残りの平均の前半・後半の相関

| 残りの作り方 | 合算（ピアソン / スピアマン） | タンパク質ごとのピアソン（中央値 / 範囲） |
|---|---:|---:|
| GBM | +0.641 / +0.619 | +0.703 / [+0.272, +0.868] |
| 線形 | +0.659 / +0.645 | +0.714 / [+0.392, +0.890] |

### 比較：生の平均の前半・後半の相関

| | 合算（ピアソン / スピアマン） | タンパク質ごとのピアソン（中央値 / 範囲） |
|---|---:|---:|
| 生の平均 | +0.809 / +0.836 | +0.822 / [+0.665, +0.930] |

生の平均の前半・後半の相関は +0.809 と高いが、これはペアごとの水準（静的な特徴量で決まる部分）が両半分に共通に入るためである。静的な予測を引いた残りでも、相関は合算で +0.64（GBM）・+0.66（線形）と高く、タンパク質ごとの中央値も +0.70（GBM）・+0.71（線形）と 0.5 を上回る。タンパク質ごとの範囲は GBM で [+0.272, +0.868] と広く、1 タンパク質だけが 0.3 を下回る。タンパク質ごとの候補数は平均で約 39 件と少ないため、タンパク質ごとの相関はぶれやすい。タンパク質ごとの相関は `results.csv` に全部載せてある。

## 4. 読み取り

先に固定した読み方（判定は合算の相関で行う）に照らすと、残りの平均の前半・後半の相関は、GBM・線形のどちらでも、ピアソンでもスピアマンでも、絶対値が 0.5 を上回った。**指導力を運ぶずれは前半から後半へ続いている。** 水素結合の形成（K2-08、GBM で +0.703）と接触の形成（K2-17、+0.719）よりやや弱いが、0.5 の線は超えた。3 つの現象で、残りの平均の前半・後半の続き方は共通している。

塩橋の形成では、残りそのものの大きさがほかの現象よりずっと大きい。前半の残りの標準偏差は 2.05 Å で、水素結合の 0.64 Å、接触の 0.51 Å の 3〜4 倍である。塩橋の候補は起点で 4.0 Å 超〜10.0 Å 以下と幅が広く、平均の水準も 7.7 Å と大きい。静的に予測しにくい分、残りは大きくなるが、その残りの前半・後半の続き方はほかの現象と同じくらい強い。つまり、残りの平均が前半から後半へ続くのは、現象をまたいで共通の形である。

## 5. 判断できること・まだ分からないこと

- 判断できること: 塩橋の形成でも、残りの平均は前半と後半で続いている（合算の相関は +0.64〜+0.66）。指導力を運ぶペアごとのずれは、前半から後半へ続く。担い手が分散している（K31）にもかかわらず、残りの平均そのものの続き方は水素結合・接触と同じくらい強い。塩橋の平均は静的に予測しにくく、前半の残りの標準偏差は 2.05 Å と、ほかの現象の 3〜4 倍大きい。
- まだ分からないこと: ペアごとのずれが何の影なのか（水素結合では K2-03 の 4 つの候補で説明できなかった。塩橋ではまだ試していない）。ずれが窓の外でも続くのか。ずれが指導力にどう効くのか（この実験は相関だけを見ており、予測への寄与までは測っていない）。
