# G05: 短い実MDの切り取りは、強い土台でも指導力を戻すか（K06(b) の条件、水素結合の形成）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDを安くする方向の続き。G02 は弱い土台（資料D）で、0.1 ns の切り取りでも回復率 0.570 と5割を超えた。強い土台（K06(b)、凍結した本体モデル＋補正モデル）でも同じか確かめる。
- 状態: 完了。0.1 ns の切り取りで回復率が全体 0.545、タンパク質ごとの平均 0.553 と、どちらも5割を超えた。強い土台でも短い実MDの経路が使える。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切る長さは 0.1 ns と 0.5 ns の2通り。2つの量を測る。

- (a) 切った履歴の平均と 0〜1 ns の平均との残りのばらつき。参照は複製の下限 0.249 Å（実の平均のレプリカ間差の標準偏差）と、生成器の平均の誤差 0.483 Å。
- (b) 切った平均だけを履歴の特徴として強い土台の補正モデルに入れたときの 1 ns先の利得の回復率。参照は実履歴の利得で、全体（pooled）+0.0702、タンパク質ごとの平均（macro）+0.0712。回復率は両方で測る。

読み方は先に固定した。0.1 ns の切り取りで回復率が5割以上なら、強い土台でも短い実MDの経路が使える。5割に届かなければ、強い土台では短い切り取りでは足りない。

## 2. 条件

- 土台は K06(b) と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、1 ns先の陽性 11,712件）で評価する。静的特徴は5個。履歴の要約値は10個（最初、平均、標準偏差、最小、最大、最後−最初、最後−直前、3.5 Å以下割合、4.5 Å以下割合、増加割合）。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 1 ns先。

### 切り取りの定義（G02 と同じ、結果を見る前に固定）

軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。

| 切る長さ | フレーム | 実際に覆う長さ |
|---|---|---|
| 0.1 ns | 0, 1（2フレーム） | 0.1 ns |
| 0.5 ns | 0〜5（6フレーム） | 0.5 ns |

起点フレーム10（1 ns）は変えず、ラベルは 1 ns先のまま。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個。参照条件。
- 平均だけ（mean_only_full）: 静的特徴＋0〜1 ns の平均だけ。K21 の「平均だけ」と同じ形。参照条件。
- 切った平均だけ（prefix_mean_0.1/0.5ns）: 静的特徴＋切った履歴の平均だけ。
- 凍結モデルのみ（frozen_only）: 補正モデルなし、本体モデル T1I2006 の出力だけ。参考。

### 系列の作り直し

K06(b) の保存データには履歴の要約値しかなく、切り取りの平均を出すための生の11点系列が残っていなかった。そこで系列を作り直した（`build_series.py`）。保存されている候補の原子ペア（`r{r}_pair` の最初の2列）と軌道から、フレーム 0〜10 の距離を score_b.py と同じ段取り（フレームごとの箱を軸ごとに扱う）で計算した。作り直した系列から導いた要約値が保存値と一致するか、108タンパク質すべてで確かめてあり、どれも差は 1e-05 Å 未満だった（2回目の実行分の29タンパク質では最大 2.9e-06 Å。float32 の丸めの範囲）。

軌道の出所は、108タンパク質のうち 80タンパク質が k15_atlas のコピー、26タンパク質は3レプリカとも Registry からの取り直し、4cv4_A と 2hng_A は箱が0のレプリカ（4cv4_A の R2、2hng_A の R3）だけ Registry からの取り直し。k15_atlas のコピーが不完全で、26タンパク質は軌道そのものがなく、4cv4_A の R2 と 2hng_A の R3 は最初の11フレームの箱がすべて0になっていた（変換の問題で、Registry のコピーでは 4cv4_A の箱は3レプリカとも有効だった）。使えない場合は Registry から取り直すようにしてある（`build_series.py`）。取り直した軌道は `~/workspace/kinescope/work/g05_atlas_workspace/` に残してある。系列そのものは `~/workspace/kinescope/work/g05_series/` に、タンパク質ごとの `r1_series`・`r2_series`・`r3_series`（11点×候補数）として保存してある。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC は全体 0.4591、タンパク質ごとの平均 0.4539。全部入りは全体 0.5293、タンパク質ごとの平均 0.5251。利得は全体 +0.0702、タンパク質ごとの平均 +0.0712 で、k06b_results.json の記録と小数第4位まで完全一致した。平均だけ（0〜1 ns）は全体 0.5275、タンパク質ごとの平均 0.5221、回復率は全体 0.975、タンパク質ごとの平均 0.957 で、K21 の値（タンパク質ごとの平均 0.957）と一致する。

### (a) 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差

| 切る長さ | テスト（163,074件） | 較正（13,808件） |
|---|---:|---:|
| 0.1 ns | 0.538 Å | 0.503 Å |
| 0.5 ns | 0.261 Å | 0.261 Å |

参照と比べると、複製の下限 0.249 Å、生成器の平均の誤差 0.483 Å に対して、0.1 ns の切り取りの 0.538 Å は生成器の誤差より大きく、0.5 ns の切り取りの 0.261 Å は複製の下限に近い水準まで下がる。切った平均と 0〜1 ns の平均の差の平均は、0.1 ns でテスト +0.058 Å、0.5 ns で +0.043 Å（始めの短い部分の平均のほうが 0〜1 ns の平均よりわずかに大きい。距離が 0〜1 ns のあいだにわずかに伸びる向きで、G02 と同じ）。

### (b) 1 ns先の利得の回復率（平均だけの条件）

| 切る長さ | AUPRC（全体） | AUPRC（タンパク質ごとの平均） | 回復率（全体） | 回復率（タンパク質ごとの平均） |
|---|---:|---:|---:|---:|
| 0.1 ns | 0.4974 | 0.4933 | 0.545 | 0.553 |
| 0.5 ns | 0.5079 | 0.5027 | 0.695 | 0.686 |
| 0〜1 ns（全部の平均） | 0.5275 | 0.5221 | 0.975 | 0.957 |

静的のみは AUPRC 全体 0.4591、タンパク質ごとの平均 0.4539。切る長さが長くなるほど回復率は単調に上がる。参考までに、凍結モデルのみ（補正モデルなし）は全体 0.4929、タンパク質ごとの平均 0.4859 で、0.1 ns の切り取りの条件（全体 0.4974）よりわずかに低い。

## 4. 読み取り

- **0.1 ns の切り取りで回復率が全体 0.545、タンパク質ごとの平均 0.553 と、どちらも5割を超えた。** 先に固定した読み方に沿うと、強い土台でも短い実MDの経路が使える。0.5 ns まで伸ばすと 0.695 / 0.686 まで戻る。
- 弱い土台（G02）の結果と比べると、0.1 ns で 0.570 → 0.545（全体）、0.5 ns で 0.770 → 0.695 と、強い土台のほうがやや低いが、形は同じ。強い土台では実履歴の利得そのものが小さい（+0.0702 に対して弱い土台は +0.1178）ため、回復率の分母が小さく、同じ AUPRC の差でも回復率は動きやすい点には注意が要る。0.1 ns の切り取りの AUPRC の差は、弱い土台で +0.0671、強い土台で +0.0383。
- 残りのばらつきの側から見ると、0.1 ns の切り取りの 0.538 Å は生成器の平均の誤差（0.483 Å）より大きく、G02 の 0.396 Å より大きい。それでも回復率は 0.545 と5割を超えた。ばらつきが 0.30 Å の線を下回らなくても、回復率は5割を超えうる。0.5 ns の切り取りの 0.261 Å は複製の下限（0.249 Å）に近い水準で、回復率は 0.695 まで上がる。
- 平均だけの条件（0〜1 ns）は回復率 0.975 / 0.957 と、実履歴の利得のほぼ全部を平均だけで説明できる（K21 と同じ）。短い切り取りでも担い手は平均のまま。切る長さを伸ばすほど平均が 0〜1 ns の平均に近づき、回復率も上がる、という素直な関係。
- ただしこれは「実の始めの短い部分」をそのまま使った場合の話で、短い実MDを実際に回す計算量や、始めの 0.1 ns が安定するまでの平衡化の扱いは、この実験では測っていない。実MDを短く回す運用上の段取りは別の問い。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台でも、0.1 ns の実の履歴だけ（10分の1 の計算量）で、1 ns先の指導力の 0.545 / 0.553 が戻る。0.5 ns では 0.695 / 0.686 まで戻る。
- まだ分からないこと: 0.1 ns よりさらに短い切り取り（フレーム0だけ、つまり起点の距離そのもの）ではどこまで戻るか。短い実MDを実際に回すときの計算量と平衡化の扱い。他の現象（接触・塩橋）や、1 ns先以外の予測幅でも同じ形か。
