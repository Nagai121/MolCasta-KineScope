# K19: 塩橋形成での担い手の切り分け

## 仮説
H5（特徴量の抽出と読み出し）と H7（実軌道が持つ追加の観測情報）に関わる検証です。K15 で塩橋形成の指導力がはっきり出ました（1 ns先で AUPRC の差 +0.144）。水素結合と接触でやった担い手の切り分けを、塩橋でも行います。

読み方は実験前に固定しました。塩橋でも平均が主で、別の候補の履歴では崩れるなら、担い手の形は3現象で共通ということになります。違う統計量が主だったり、別の候補の履歴でも残ったりすれば、塩橋だけ担い手が違うことになります。

## データと条件
- 土台は K15 と完全に同じです。塩橋形成、学習58タンパク質（候補 2,557件）、テスト30タンパク質（候補 1,170件、陽性は幅ごとに 93〜149件）。起点はフレーム10（1 ns）、履歴は 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直します（パート2は K03 と同じく学習は実履歴のまま、テストだけ差し替えます）。
- 塩橋の定義は K13/K15 と同じ（資料Dの `fixed_1ns_history_3phen_6h.py`）。静的特徴は5個、履歴は6統計量（最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下だった割合）です。
- 距離系列は K15 の抽出済みキャッシュ（`~/workspace/kinescope/work/k15_cache/`、`*_salt.npz`、X・hist・y・res_i・res_j）を使いました。距離は抽出の時点でフレームごとの箱を軸ごとに扱う周期境界で計算されています。
- 土台の再現確認: 静的のみと実履歴ありの AUPRC が、K15 の値と全6予測幅で小数第4位まで一致しました（差 0.0）。

## パート1: 統計量の差し替え・落とし
K09・K16・K18 の段取りとの対応は次のとおりです。
- 塩橋には生成側の条件が無いので、K09 の「生成の統計量を実の値に戻す」という差し替えはできません。代わりに K16・K18 と同じ「引く」実験を2つの形で行いました。
  - (a) 列を落とす（K18 の定義）: 6統計量のうち1列を入力から除きます。
  - (b) 定数にする（K16 の定義）: その統計量を学習側全体の平均値で置き換えます。定数は学習側だけで決め、テスト側の情報は使っていません。定数（学習側の平均）: 最初の値 7.6954、平均 7.6903、標準偏差 1.1993、最小値 5.7810、最後−最初 −0.2780、4.0 Å以下割合 0.0615。
- (a) と (b) は全条件・全予測幅で AUPRC が小数第4位まで一致しました（最大差 0.0）。定数の列は勾配ブースティングの分割に使えないため、落とすことと数学的に等しく、一致は当然です。以下では両者をまとめて「落とす」として読みます。
- 残存率 =（条件の AUPRC − 静的のみ）÷（実履歴の AUPRC − 静的のみ）です。

## パート2: 履歴の入れ替え（K03・K16 と同じ段取り）
学習は実履歴のまま、テストの履歴（11フレームの距離系列）だけを差し替えて評価しました。
- 別ペアへの差し替え: 同じタンパク質・同じ複製の中で、テスト候補の履歴を別の候補の履歴にランダムに入れ替えます（seed は K03 と同じ 123）。
- 別複製への差し替え: 同じ残基ペア（res_i, res_j）の履歴を別の複製（R1←R2、R2←R3、R3←R1）から持ってきます。同じペアが別複製でも候補になっている場合だけ差し替えでき、差し替えできたのはテスト 1,170件中 740件（63.2%）で、残りは元の履歴のままです。差し替えできた候補だけに絞った評価も行いました。

## 判断できること
読み方は実験前に固定したとおりに判定します。結果は2つのパートで分かれました。
- **履歴の入れ替えの側は、水素結合・接触と共通です。** 別ペアの履歴に差し替えると、指導力は消えるだけではなく、静的のみより大きく悪くなりました（1 ns先で AUPRC 0.3842 → 0.1118、残存率は全幅で負）。モデルは履歴を強く信用していて、違うペアの履歴は誤った情報として働きます。一方、別複製の同じペアの履歴では指導力の大半が残りました（1 ns先の残存率 0.905）。差し替えできた候補だけに絞っても、1 ns先の低下は約0.026 で、水素結合（K03、約0.034）・接触（K16、約0.035）とほぼ同じです。指導力は「そのペア自身の履歴」であることに依存し、複製が違ってもペアが同じなら大半が保たれる、という形は3現象で共通しています。
- **統計量の側は、単独で担う統計量はありません。** どの統計量を1つ落としても、指導力はほとんど落ちませんでした。1 ns先で最も減ったのは平均で、残存率 0.762（利得の約24%を失う）ですが、それでも大半が残ります。最小値を落とすと 1 ns先ではむしろ 1.095 と上がりました。つまり塩橋でも、K16 の接触と同じく、情報は複数の統計量に重なって入っていて、1つを消しても残りで補えます。
- ただし、この「平均が主ではない」という読みは、「引く」実験（必要さ）の範囲のものです。K09・K12 の水素結合の「平均だけで戻る」は「足す」実験（十分さ）で、向きが違います。強い土台の水素結合で同じ「引く」実験をした K18 でも、平均を落としても利得は最大で約7%しか減らず、平均は必要ではありませんでした。つまり「引く」実験の物差しでは、水素結合（K18）・接触（K16）・塩橋（本実験）の3現象すべてが「単独で担う統計量はない」という同じ形です。塩橋だけ担い手が違う、という結論にはなりません。塩橋で K09 式の「足す」実験をするには生成系列が必要で、塩橋には生成系列がありません（K14）。

## まだ分からないこと
- 統計量を複数同時に落とすと指導力がどう落ちるかは試していません。情報がどの組み合わせに分散しているかは、同時差し替えをしないと分かりません。
- 50 ns先の残存率は振れが大きく（平均を落とすと 0.393、最小値を落とすと 1.322）、幅ごとの細かい値は1条件の揺れと区別しにくいです。土台の指導力自体が 50 ns先では +0.027 と最小です。
- 残存率が 1 を超える条件が複数あります（単独差し替えで AUPRC が土台をわずかに上回る）。単一の学習 seed の結果であり、ばらつきの範囲は測っていません。
