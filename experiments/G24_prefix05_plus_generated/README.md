# G24: 0.5 ns の切り取りに生成した平均を足すと、さらに戻るか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめること: G11 では 0.1 ns の切り取りで混合が +0.186 だったが、切り取りを長くすると生成した量の足しが消えるかもしれない。0.5 ns（フレーム [0〜5]）の切り取り平均だけでは回復率 0.770 だった（G02）。ここに第22案の生成平均を足し、同じ補正モデルで測る。
- 状態: 完了。混合の回復率は 1.015 で、切り取り平均だけ（0.770）より +0.245 上がった。切り取りを 0.5 ns まで伸ばしても、生成した量の足しは消えない。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、1 ns先。0.5 ns の切り取りはフレーム 0〜5（6フレーム）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、混合は切り取りを長くしても足しになる。+0.05 未満なら、生成した量の寄与は切り取りが短いときに限られる。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。
- K01 のキャッシュ（18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。
- 生成平均の出所: K05 の `generated_series.npz`（第22案の5点系列）。生成5点 = [起点距離 d0（フレーム10、1 ns）、+0.1、+0.3、+0.5、+1.0 ns] の前方系列。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）。検証として、生成5点の最初の点と履歴の最終フレーム（起点距離）の最大誤差は、学習側 5.56e-07 Å、テスト側 6.08e-07 Å だった。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列。両者は起点距離 d0 を共有するが時間の向きが逆（K09 と同じ留保）。平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しない（平均の列だけを使うため）。
- 条件: 静的のみ／履歴全部入り（参照）／切り取り平均だけ（0.5 ns）／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.1178）。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、形成の記録と小数第4位まで完全一致した。切り取り平均だけは AUPRC 0.4544、回復率 0.770 で、G02 の値と小数第4位まで一致した。

### 1 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.3637 | 0.9056 | 0.0432 | 0.1494 | 0.000 |
| 全部入り（実履歴） | 0.4815 | 0.9352 | 0.0395 | 0.1344 | 1.000 |
| 切り取り平均だけ（0.5 ns） | 0.4544 | 0.9311 | 0.0394 | 0.1344 | 0.770 |
| 生成平均だけ | 0.3746 | 0.9129 | 0.0430 | 0.1466 | 0.093 |
| 混合（切り取り平均＋生成平均） | 0.4833 | 0.9353 | 0.0387 | 0.1326 | 1.015 |

混合の回復率は 1.015 で、切り取り平均だけ（0.770）より **+0.245** 上がり、先に固定した +0.05 の線を超えた。0.1 ns のときの +0.186 よりも上がり幅は大きい。

## 4. 読み取り

- **混合の回復率は 1.015 で、切り取り平均だけより +0.245 上がった。** 先に固定した読み方に沿うと、混合は切り取りを 0.5 ns まで伸ばしても足しになる。切り取りを長くすると生成した量の足しが消える、という予想は外れた。
- 0.1 ns のときの上がり幅 +0.186 より、0.5 ns の +0.245 のほうが大きい。生成平均だけでは回復率は 0.093 とほとんど戻らないのに、切り取り平均と組み合わせると大きく上がる点は G11 と同じ形。
- 切り取り平均と生成平均は、同じペアの「起点のまわりの代表的な距離」を別の時間の窓から見積もった2つの量で、相関は 0.780 と完全には重ならず、差の標準偏差は 0.603 Å と大きい。切り取り平均は後方 0〜0.5 ns、生成平均は前方 0〜1 ns を覆い、誤差が一部独立なため、組み合わせると 0〜1 ns の平均への近づき方が良くなるとみるのが自然。混合の回復率が全部入りの 1.000 をわずかに上回った（1.015）のは、その組み合わせが実履歴の6統計量とほぼ同等の情報を持った、という読みもできる。ただし 1.015 と 1.000 の差は小さく、混合が実履歴を上回ったと断定するものではない。
- 0.5 ns の切り取り平均だけでも 0.770 と、混合（1.015）と比べれば下だが、切り取りを伸ばすだけでも回復率は上がる。混合の利点は、切り取りを 0.5 ns まで伸ばすのとほぼ同じ水準（0.770）に、0.1 ns の切り取り（G11 の 0.756）でも到達していた点にある。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.5 ns の切り取り平均に第22案の生成平均を足すと、1 ns先の利得の回復率は 0.770 から 1.015 へ +0.245 上がる。生成した量の寄与は切り取りが短いときに限られず、切り取りを長くしても残る。
- まだ分からないこと: 生成平均が補っているのが、時間の向きの違いによるものか、覆う範囲の違いによるものか。混合が全部入りをわずかに上回ったことの再現性。強い土台（K06(b)）では G21 で混合が逆効果だったため、この形が強い土台で成り立つかは別途の問い。
