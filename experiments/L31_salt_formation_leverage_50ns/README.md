# L31: L01 の曲がりを塩橋の形成で測る（K15 の土台、50 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の形成（K15 の土台、全予測幅、L27〜L32）の 50 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。**この予測幅では土台の利得自体が小さく（全体 +0.0274）、回復率の比率が大きく振れるため、曲がりの形は読めません。** 回復率（全体）は −0.135〜+1.130 の範囲を上下し、95% 区間はたとえば 0.1 ns で [−8.222, +1.073] と、比率として意味をなさない広さです。先に固定した読み方を機械的に当てた結果も併記しますが、結論には使いません。

## 1. 何を確かめる実験か

L27 と同じ段取りで、予測幅だけを 50 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。テスト 1,170件、50 ns先の陽性 137件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.2295、全部入り 0.2569、利得 全体 +0.0274／平均 +0.0413 で、K2-141 の記録と 5e-4 以内で一致しました（`premise_check.json`）。この利得 +0.0274 は、塩橋の形成の 6つの予測幅の中で最小です。

### 先に固定した読み方への答え（機械的な適用の結果）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.130）。ただし次の 0.1 ns では −0.126 まで落ち、意味のある読みではありません。
2. 増え幅がいちばん大きい場所: 全体では 0.2→0.3 ns（+0.852）、平均では 0.7→0.8 ns（+0.372）。全体の段の位置でのタンパク質ごとの増え分は中央値 0.000 で、正だったのは 15タンパク質のうち 47% でした。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 50 ns先では、分母の利得（+0.0274）が AUPRC の揺れに対して小さすぎて、回復率の曲がりは測れません。G60 の走査でも 50 ns先の回復率は −0.126〜+0.476 と振れており、同じ事情です。
- AUPRC そのものを見ると、切り取りの平均を入れても静的のみ（0.2295）と全部入り（0.2569）の間の範囲で上下するだけで、長さに対する傾向は見えません。
- この予測幅については「曲がりは決められない」が結論です。他の予測幅の結果と並べるときも、50 ns先だけは分母の小ささを断ったうえで扱う必要があります。
