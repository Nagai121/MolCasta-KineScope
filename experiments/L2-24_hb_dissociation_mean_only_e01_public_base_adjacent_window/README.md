# L2-24: 区間を起点フレーム10の直前に置き直した測り直し（水素結合の解離、平均だけ、E01の公開土台、予測幅 1/5/10/30/50/90 ns）

- 状態: 進行中。予測幅 1, 5 ns まで完了。前提確認（長さ 1.0 ns の点でE01 の記録と一致すること）は、1 ns: すべて一致、5 ns: 回復率が許容幅を超えたが、判断により受け入れて測定を続けた。回復率 0.8 に届く最小の長さ（全体）は、1 ns先は 0.8 が0.5 ns、0.9 が0.8 ns、5 ns先は 0.8 が0.5 ns、0.9 が0.8 ns。

## 1. 何を確かめる実験か

E01 の Protocol A と同じ土台・同じ候補・同じ評価方法で、長さを 0, 0.1, …, 1.0 ns の11点すべてに広げて、平均だけの回復率の曲がりを測る。

L では区間は先頭から（フレーム 0〜k）で、短い長さでは起点フレーム10との間に時間の空きがあった。E01 で、この空きが回復率を水増ししていたことが分かっている（E01 の Protocol A は、区間を起点の直前に置く置き方）。ここでは区間を起点フレーム10の直前に置き、L と同じ読み方で測る。

## 2. 条件

- 土台: E01 の公開土台（static20: 公開特徴量20個のみ、凍結モデルなし）。予測器は HistGradientBoosting（160回、学習率 0.06、葉31、葉あたり最少25、L2 0.15、種 20261126）で、タンパク質で分ける5分割の交差検証で、検証の外に出した予測で測る。
- 区間: 覆う長さ L ns の区間は、フレーム (10 − L/0.1) 〜 10 の L/0.1 + 1 フレーム。長さ 0 はフレーム10だけ、0.1 ns はフレーム 9〜10、1.0 ns はフレーム 0〜10。長さは 0〜1.0 ns の11通り。
- 条件は、static20、full（static20 + フレーム 0〜10 の統計量6種、回復率の分母の参照）、区間の平均だけ（11通り）。
- 回復率 = (その長さの AUPRC − 静的のみ) / (全部入りの利得)。
- 読み方（L と同じ）: 回復率 0.8 と 0.9 に最初に達する長さ（全体とタンパク質ごとの平均の両方）、隣り合う長さの間の最大の増え幅、信頼区間はタンパク質単位のブートストラップ 10,000回（パーセンタイル法）。増え幅が最大の場所ではタンパク質ごとの値も記録する。
- 前提確認: 長さ 1.0 ns の点は区間がフレーム 0〜10 になりE01と同じ条件になる。静的のみ・全部入りの AUPRC と、長さ 1.0 ns の回復率が記録と一致しなければ止める、と先に決めた。

## 4. 読み取り

- **長さ 0 の回復率は、終わっている予測幅（1 ns先、5 ns先）ではちょうど 0.0000。**これは、起点フレーム10の距離が静的な特徴にすでに含まれているためで、フレーム10だけの統計量は静的な予測に何も足さない。L の長さ 0（フレーム0だけ）は、静的な特徴に含まれていないフレーム0の距離を持ち込んでいたため、回復率が 0 にならなかった。
- **1 ns先:** 回復率 0.8 に届く最小の長さは0.5 ns。
- **5 ns先:** 回復率 0.8 に届く最小の長さは0.5 ns。

## 5. 判断できること・まだ分からないこと

- 判断できること: 区間を起点の直前に置き直しても、短い区間で利得の大半が戻る形が残るかどうかは、上の表の通りである。長さ 0 の回復率がちょうど 0 になることは、起点の距離が静的な特徴に含まれていることの帰結である（終わっている予測幅で確認）。
- まだ分からないこと: 予測幅によって置き直しの影響がどう変わるか、その理由は、この実験では分からない。
