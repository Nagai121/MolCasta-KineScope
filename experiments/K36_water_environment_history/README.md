# K36: 実履歴に水の環境の履歴を足すと指導力が増えるか

## 仮説

H7（実軌道が持つ追加の観測情報）の残りです。K25 では残基の環境の履歴を足しても利得はほぼ増えませんでしたが、水の環境は変換済み軌道に水が無いため測れていませんでした。K32 で完全形式（total）の軌道に水があり、フレームの対応が取れることが確かめられたので、水の環境の履歴を足す実験を行います。

読み方は実験前に固定しました。水の環境の履歴を足して利得がはっきり増えれば、水の環境にも担い手があることになります。利得がほぼ増えなければ、実履歴の追加情報はペア自身の系列の中にあることになります。補助の目安として、増分が土台の利得（1 ns先で +0.1178）の1割（約0.012）未満なら「ほぼ増えない」と読むことにしました。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。水素結合形成、起点1 ns、履歴0〜1 ns（11フレーム）、予測幅1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。モデルは条件ごとに学習し直す比較です。
- 条件は6つです。
  - 静的のみ: 静的特徴7個
  - 土台 D6: 静的＋ペア自身の履歴6統計量
  - 履歴＋水A: 静的＋ペア自身の履歴6統計量＋水の環境（案A、16特徴量）
  - 履歴＋水B: 静的＋ペア自身の履歴6統計量＋水の環境（案B、16特徴量）
  - 履歴＋水AB: 静的＋ペア自身の履歴6統計量＋水の環境（案A＋案B、32特徴量）
  - 水ABのみ: 静的＋水の環境（案A＋案B）のみ（参考条件）
- 静的のみと土台 D6 は土台の記録と全予測幅・全指標で完全に一致しました（最大の絶対差 0.0）。

## 水の環境の履歴特徴量の定義（結果を見る前に固定した）

定義は、結果を見る前にこの形に固定しました。途中で定義を変えて測り直すことはしていません。

- 水の読み方: ATLAS の完全形式（total）の TPR + XTC を MDAnalysis で直接読みます（MiniTopol の変換は通しません。2026-11-16 に Echizen が明言した例外の範囲です）。完全形式のファイルは `~/workspace/rod-survival-exp/atlas-ws/storage/sources/ATLAS/` の `{タンパク質}-total/` にあり、K25 の6タンパク質すべてに 3レプリカ分が手元にあります（新たなダウンロードは要りません）。使うフレームは完全形式の 0, 10, ..., 100（解析版の 0〜10、履歴 0〜1 ns に対応）の11個だけです。
- 候補の同定（ドナー原子・アクセプター原子）は base_reproduction のキャッシュと同一です。変換済み軌道の原子並びと完全形式のタンパク質重原子の並びは一致することを確認済みです（2qt4_A R1: 名前・残基番号が一致、フレーム0 の RMSD 0.0）。
- 水は SOL 残基の酸素 OW です。水の酸素の数は 1bgf_A が 7,708個、1ifg_A が 8,042個、1j8r_A が 8,295個、2b0a_A が 9,312個、1mix_A が 12,213個、2qt4_A が 4,479個でした。
- 距離はフレームごとの箱で最小イメージ（直交箱、軸ごとの箱長）で計算しています。完全形式の XTC は原子ごとに箱をまたいで巻き込まれた座標で保存されているため、座標をそのまま引いてはいけません。ドナー・アクセプターの中点は、最小イメージで補正した差分（アクセプター − ドナー）から求めています。
- 系列は候補ごと、11フレーム分です。
  - 案A「近くの水の数の系列」: ドナー原子から 3.5 Å 以内にある OW の数（nd35_d）、ドナー原子から 5.0 Å 以内（nd50_d）、アクセプター原子から 3.5 Å 以内（nd35_a）、アクセプター原子から 5.0 Å 以内（nd50_a）の4系列。
  - 案B「橋渡し水と最も近い水」: ドナー原子とアクセプター原子の両方から 3.5 Å 以内にある OW の数（nbridge）、ドナー原子から最も近い OW までの距離（dmin_d）、アクセプター原子から最も近い OW までの距離（dmin_a）、ドナー・アクセプターの中点から最も近い OW までの距離（dmin_mid）の4系列。
- 要約は系列ごとに4量（平均、標準偏差、最小値、最後−最初）です。水Aは 4系列 × 4 = 16特徴量、水Bは 4系列 × 4 = 16特徴量、水ABは 32特徴量です。欠損値はありません。
- 系列の水準（全候補・全フレームの平均）: nd35_d は 0.72〜1.02個、nd35_a は 1.01〜1.55個、nbridge は 0.04〜0.11個、dmin_d の平均は 3.6〜4.0 Å でした。橋渡し水はめったにいません（1フレームあたり平均 0.1個未満）。

## sanity check

- 起点フレーム（完全形式フレーム100）で、タンパク質の重原子から 3.5 Å 以内にある水の数は、2qt4_A R1 で 242個となり、K32 の値と一致しました。他のレプリカでも 238〜635個の範囲で、タンパク質の大きさに応じた値でした。
- 抽出の計算時間は 18レプリカで合計 1,218秒（約20分）でした。1レプリカあたり 27〜216秒で、1mix_A（水 12,213個）が 183〜216秒と最も重く、2qt4_A（水 4,479個）は 33〜83秒でした。

## 判断できること

- 主判断の 1 ns先では、案Aと案Bを合わせた条件（履歴＋水AB）の増分は +0.0266 で、土台の利得 +0.1178 の約23%にあたり、先に固定した目安（利得の1割、約0.012）をはっきり超えます。1 ns先だけを見れば、水の環境にも担い手がある、という読みになります。AUC は 0.9352 → 0.9354 とほぼ変わらず、Brier は 0.0395 → 0.0384 とわずかに改善しました。
- ただし、増分は予測幅ごとに符号が一定しません。履歴＋水AB の増分は 5 ns先 −0.0029、10 ns先 −0.0084、50 ns先 −0.0087 と負になり、30 ns先 +0.0336、90 ns先 +0.0180 と正です。案Aだけでは 1 ns先の増分は +0.0042 で目安を下回り、案Bだけでは +0.0143 と目安をわずかに超える程度です。水ABのみの条件にも利得らしい利得はありません（1 ns先 +0.0188、他の幅では負か +0.037 まで）。
- 先に固定した読み方に沿うと、1 ns先の主判断では「水の環境にも担い手がある」となりますが、幅をまたいで一貫した上乗せとは読めません。単一の種での結果でもあり、水の環境が安定した担い手だと結論づけるには、別の種や別の土台での再確認が必要です。残基の環境（K25）の「ほぼ増えない」と比べると、水の環境のほうが 1 ns先では増分が大きい、という違いはあります。

## まだ分からないこと

- 水の環境の増分が 1 ns先と 30 ns先で大きく、5・10・50 ns先で負になる理由は、この実験だけでは分かりません。ノイズか、幅ごとの性質の違いかは区別できません。
- 橋渡し水は 1フレームあたり平均 0.1個未満とめったにいないため、案Bの橋渡し水の数の系列はほとんど情報を持っていない可能性があります。案Aと案Bのどちらが効いているかの切り分けは、増分の形だけではできません。
- 水の環境の定義は今回の1通り（近くの水の数と最も近い水までの距離）だけです。別の切り方（水の滞在時間、配向、水素結合ネットワークなど）で情報が出る可能性は残ります。
