# K47: 生の系列をそのまま入れると、統計量より利得が戻るか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。これまでの履歴の特徴量は、系列を6つの統計量にまとめたものでした。生の系列（11点の距離そのもの）を補正モデルに直接入れると、統計量より利得が戻るか確かめます。

読み方は実験前に固定しました。生の系列で利得が6統計量よりはっきり増えれば、統計量へのまとめで情報が落ちています。利得が変わらなければ、6統計量で十分です。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的補正との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。
- 静的な特徴に実の系列の11点の距離をそのまま足した条件で補正モデルを学習します。系列はフレーム 0〜10 の順番そのまま（起点はフレーム10）で、K22 のキャッシュから取ります。系列の平均が実履歴10特徴の平均の列と一致することを確認しました（差 1e-5 未満）。
- 参照として、静的な特徴だけの条件、実履歴全部の条件、6統計量の条件（静的な特徴＋実履歴の [最初、平均、標準偏差、最小値、最後−最初、3.5 Å 以下割合]）も測りました。
- 対照の確認: 静的な特徴だけの条件と実履歴全部の条件は、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。6統計量の条件は、K34 と K37 の記録とほぼ同じ回復率になりました（0.97〜1.16、K34/K37 では 0.97〜1.17）。

## 結果（実履歴の利得に対する回復率）

| 予測幅 | 生の系列11点 | 6統計量 |
|---|---:|---:|
| 1 ns | 0.936 | 1.006 |
| 5 ns | 0.916 | 0.978 |
| 10 ns | 0.905 | 1.041 |
| 30 ns | 1.027 | 1.057 |
| 50 ns | 0.742 | 0.972 |
| 90 ns | 0.830 | 1.162 |

タンパク質ごとの平均で見ても形は同じです（生の系列: 0.73〜1.02、6統計量: 0.97〜1.17）。

利得（AUPRC、静的補正との差）で見ると、生の系列は 1 ns先 +0.0657、5 ns先 +0.0471、10 ns先 +0.0341、30 ns先 +0.0373、50 ns先 +0.0263、90 ns先 +0.0220 で、6統計量（+0.0706 / +0.0503 / +0.0392 / +0.0384 / +0.0345 / +0.0307）より全予測幅でわずかに低くなります。50 ns先の差が最も大きく（回復率 0.74 対 0.97）、それ以外は 0.03〜0.23 の差です。

## 判断

先に固定した読み方に照らすと、答えは「6統計量で十分」です。生の系列をそのまま入れても、利得は6統計量よりはっきり増えません。むしろ全予測幅でわずかに下がります。統計量へのまとめで情報は落ちていません。補正モデルは、系列の点そのものより、平均・標準偏差・最小値などのまとめられた特徴量のほうが使いやすい、という形です。
