# G78: 水素結合の形成で、6 個の統計量の切り取りでも長い予測幅での回復率を測る（資料Dの条件、水素結合の形成、5・10・30・50・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる。G74 は平均だけの切り取りで真ん中の予測幅を測り、0.5 を超える最小の切り取りは 5・10・30・50 ns先のすべてで 0.1 ns だった。ここでは同じ予測幅・切り取りで、6 個の統計量を入れたときの回復率を測る。
- 状態: 完了。

## 1. 切り取りの定義（G02/G74 と同じ、結果を見る前に固定）

- 軌道の保存間隔は 100 ps（0.1 ns）。フレーム k は時刻 k*0.1 ns。
- 0.1 ns → フレーム 0, 1（2フレーム、覆う長さ 0.1 ns）
- 0.25 ns → フレーム 0, 1, 2（3フレーム、覆う長さは 0.2 ns。0.25 ns は 100 ps 刻みに合わない）
- 0.5 ns → フレーム 0〜5（6フレーム、覆う長さ 0.5 ns）
- 起点フレーム10（1 ns）は変えない。条件は「静的特徴＋切った 6 統計量」（G02 の「6統計量」と同じ形）。6 統計量は [最初の値, 平均, 標準偏差, 最小値, 最後−最初, 3.5 Å以下割合] で、切り取りのフレームだけで計算する。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（その予測幅での実履歴の利得）。

## 2. 土台の再現と利得の出所

- 土台は K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/`、18軌道）を再利用。資料Dの条件（学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件）。
- 土台の利得は K01・資料Dの記録値で、再計算でも一致した。1 ns +0.1178、5 ns +0.1155、10 ns +0.0829、30 ns +0.0626、50 ns +0.0739、90 ns +0.1211。
- 静的のみ・全部入りは全予測幅で K01・G74 の記録と小数第4位まで一致した（1 ns先で静的のみ 0.3637、全部入り 0.4815。90 ns先で静的のみ 0.3035、全部入り 0.4246）。
- 1 ns先の 6 統計量の切り取りも G02 と一致した（0.1 ns 0.583、0.25 ns 0.700、0.5 ns 0.803）。
- 実行はローカルVMのみ。HistGradientBoosting（120回、学習率 0.075、葉 31、葉あたり最小 15件、L2 0.02、seed 42）、`~/workspace/mt-venv/bin/python`、OMP_NUM_THREADS=2。最初の実行は既定の python3 に scikit-learn が入っていなかったため失敗し、mt-venv で実行し直した（結果は変わらない）。

## 6. 読み取り（先に固定した読み方に沿う）

- 6 統計量の切り取りで、回復率 0.5 を超える最小の切り取りは、5・30・90 ns先で 0.1 ns、10・50 ns先で 0.25 ns。0.5 ns まででも届かない予測幅はなかった。タンパク質ごとの平均でも同じ形。
- 切り取りを長くしても回復率は単調には上がらない。10 ns先では 0.25 ns の 0.816 から 0.5 ns の 0.464 へ下がり、5 ns先では 0.25 ns の 1.051 から 0.5 ns の 0.969 へわずかに下がる。30 ns先では 0.5 ns で 1.319、5 ns先では 0.25 ns で 1.051 と実履歴を上回るセルがある（AUPRC の絶対値でも、30 ns先の 0.5 ns は 0.4464 で全部入り 0.4264 を上回る）。
- 10 ns先と 50 ns先の 0.1 ns の弱さは、タンパク質ごとの食い違いが大きい。10 ns先の 0.5 ns の落ち込みは 1mix_A 側（0.002）だけのもので、2qt4_A 側は 0.976 と高い。50 ns先の 0.1 ns も 1mix_A 側が −0.098 と負で、2qt4_A 側は 0.782 と高い。合算の弱さは 1mix_A 側が引っ張っている形だが、テストは 2タンパク質しかないため、タンパク質の性質によるものか揺れかは決められない。
- 30 ns先の利得は +0.0626 と 6つの予測幅の中で最も小さいため、回復率の分母が小さい点には注意が要る。ただし 0.5 ns の 1.319 は、AUPRC では静的のみ 0.3639 から 0.4464 へ +0.0825 の上がりで、利得 +0.0626 を上回る量である。
- 他の現象と比べると、水素結合の形成では 6 統計量が平均だけより弱い幅がある点が目立つ。接触の形成（G75）では 6 統計量は平均だけ（G65）と同等か上回り、最小の切り取りの形も同じ（10 ns先だけ 0.25 ns）だった。水素結合の解離（G72）でも 6 統計量の最小の切り取りは 90 ns先を除いて 0.1 ns で、平均だけ（G70）とほぼ同じ形だった。水素結合の形成だけ、6 統計量にすると 10・50 ns先で 0.25 ns まで延びる。
