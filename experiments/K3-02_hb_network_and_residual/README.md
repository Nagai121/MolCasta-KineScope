# K3-02: ペアの周りの水素結合のつながり方と、ずれの関係

- 確かめること: K3 系列（軌道が知っていて静的構造が知らない、ペアの物理的な状態は何か）の1つ。水素結合の形成では、ずれ（0〜1 ns の平均距離の実測値から、静的な特徴だけの予測を引いたもの）が指導力の中心である（K39・K42・K44）。ここでは強い土台のペアについて、初期構造でペアの2つの残基が相手以外とすでに作っている水素結合のつながり方が、ずれと関係するかを測る。
- 状態: 進行中（登録のみ）。

## 量の定義と読み方（結果を見る前に固定）

- ずれは K39・K42 の作り方で作る。実の平均は K06(b) の履歴特徴の2列目（0〜1 ns の11フレームの平均距離）、静的な予測は静的特徴5個から実の平均を予測したもので、較正8タンパク質（13,808候補）だけで当てはめ、未見100タンパク質×3レプリカ（163,074候補）で評価する。当てはめは HistGradientBoosting 回帰（160回、学習率 0.065、葉 15、葉あたり最小 20、L2 0.15、種 20261121）を主とし、線形回帰を照合に使う。
- 水素結合の数え方は、初期構造（履歴のフレーム0）で測る。完全形式（total）の軌道を MDAnalysis で直接読む（K36 と同じ例外の範囲）。水素結合の判定は、土台の候補生成（tseries の prepare）と同じドナー原子・アクセプター原子の組について、重原子間の距離が 3.5 Å以下であることとする。水は SOL の酸素（OW）をドナー兼アクセプターとする。
- 取る量（候補ごと）: (1) ドナー側の残基が相手以外と作っている水素結合の数（出す向き・受ける向き・合計）、(2) アクセプター側の残基について同じ3つ、(3) 相手の種類ごとの数（主鎖・側鎖・水。相手の原子が主鎖のドナー／アクセプターなら主鎖、側鎖なら側鎖、水の酸素なら水）、(4) 競合の数（ペア自身のドナー原子が相手以外へ出している水素結合と、ペア自身のアクセプター原子が相手以外から受けている水素結合の合計）。
- K25 で除外した「残基の環境」は、近くの残基との距離系列の要約であり、ここで測る量とは別である。ここで測るのは、ペアの2残基が相手以外とすでに作っている水素結合に限った数である。
- 読み方: 各量とずれの相関（ピアソンとスピアマン、テスト全体）で、絶対値 0.3 以上を「関係あり」の目安にする（K2-03 と同じ）。静的な予測に量を足して当てはめ直したとき、テストでのずれのばらつき（標準偏差）が 0.30 Å以下になれば「ずれの大部分を説明できた」とする（下限は複製間のばらつき 0.249 Å）。対照として、量を別のペアの値と入れ替えた（タンパク質×レプリカの中で無作為に並べ替えた）場合に、ばらつきの減りが消えることも確かめる。相関が高いだけでは正体とは言わない。
