# K3-02: ペアの周りの水素結合のつながり方と、ずれの関係

- 確かめる仮説: H7（実軌道が持つ追加の観測情報）に関わる系列 K3（問いは「軌道が知っていて、静的構造が知らない、ペアの物理的な状態は何か」）の1件。ずれ（0〜1 ns の平均距離の実測値から、静的構造だけの予測を引いたもの）を指導力の主な現れとして、その正体の候補として「ペアの2つの残基が、相手以外とすでに作っている水素結合のつながり方」を測る。
- 状態: 起点フレーム（フレーム10）での測り直し中。初期構造（フレーム0）で測った結果は出ている：11の量のどれも、ずれとの相関は目安の 0.3 に届かなかった（最も強いのは、ペア自身のドナー原子・アクセプター原子を直接使う競合の数で +0.171）。静的な予測に11の量すべてを足しても、ずれのばらつきは 0.600 Å から 0.583 Å までしか減らず、0.30 Å の線には遠く届かない。フレーム0の結果だけを見れば、ペアの周りの水素結合のつながり方はずれの正体ではない。競合の数と水である相手の数には弱い正の関係があり、別のペアの値と入れ替える対照では全部足したときの減りが消えるので、小さいが本物の関係ではある。統括の補足（2026-11-25）で、静的な予測の入力は起点フレーム（フレーム10）なので候補の量もまず起点フレームで測ることになり、フレーム10での測り直しを進めている。フレーム0の結果は後の手順での比較用に残す。

## 1. 何を確かめる実験か

強い土台（K06(b)、水素結合の形成、較正8タンパク質の候補 13,808件で当てはめ、未見100タンパク質×3レプリカの候補 163,074件で評価）のペアについて、初期構造（履歴のフレーム0）で、ペアの2つの残基が相手以外と作っている水素結合の数、その相手の種類（主鎖・側鎖・水）、ペア自身の原子を直接使う競合の数を取り、ずれとの関係を測る。

K25 で除外した「残基の環境」は、近くの残基との距離系列の要約であり、ここで測る量とは別のものである。ここで測るのは、ペアの2残基が相手以外とすでに作っている水素結合に限った数である。

判定は先に固定した。

1. 相関の絶対値 0.3 以上を「関係あり」の目安にする（K2-03 と同じ）。
2. 静的な予測に量を足して当てはめ直したとき、ずれのばらつき（テスト側の標準偏差）が 0.30 Å 以下になれば「ずれの大部分を説明できた」とする。下限は 0.249 Å。
3. 対照として、量を別のペアの値と入れ替えた（タンパク質×レプリカの中で無作為に並べ替えた）場合に、ばらつきの減りが消えることも確かめる。個別の量の入れ替え対照は、相関の絶対値が 0.3 以上になった量についてだけ行う（今回は該当なし）。
4. 相関が高いだけでは正体とは言わない。原因の確認は後の手順で行う。

## 2. 条件

- ずれは K39・K42 と同じ作り方。実の平均は K06(b) の履歴特徴のうち平均距離（0〜1 ns の11フレームの平均）で、静的な予測は静的特徴5個だけから実の平均を予測したもの。当てはめは較正8タンパク質の候補だけ、評価は未見100タンパク質×3レプリカ。当てはめは HistGradientBoosting 回帰（160回、学習率 0.065、葉 15、葉あたり最小 20、L2 0.15、種 20261121）を主とし、線形回帰を照合に使う。再現の確認: テスト側のずれのばらつきは GBM で 0.6002 Å（R² 0.6352）、線形で 0.6076 Å（R² 0.6262）で、K39・K42 の記録（0.6002 Å、0.6076 Å）と一致した。
- 割り当て文の訂正（2026-11-25、統括からの連絡）: 割り当て文に書いた「ずれのばらつきは約 0.49 Å」は資料D条件の値で、強い土台では約 0.60 Å が正しい値である（上の再現値と一致）。判定の線（0.30 Å 以下）は先に固定した判断のまま変わらない。ただし下限の 0.249 Å も資料D条件で測った複製間のばらつきで、強い土台での測り直しは記録にない。
- 水素結合の数え方は初期構造（履歴のフレーム0）で測る。完全形式（total）の軌道を MDAnalysis で直接読む（K36 と同じ例外の範囲）。水素結合の判定は、土台の候補生成（tseries の prepare）と同じドナー原子・アクセプター原子の組（主鎖 N（PRO を除く）と側鎖の N・O をドナー、主鎖 O・OXT と側鎖の O をアクセプターとする）について、重原子間の距離が 3.5 Å 以下で、最小イメージで測り、残基が異なることとする。水は SOL の酸素（OW）をドナー兼アクセプターとする。水同士の水素結合は数えない。
- 量（候補ごと、すべてフレーム0）:
  - n_out_donor_res / n_in_donor_res: ドナー側の残基が、相手の残基以外を相手として、ドナーになっている水素結合の数 / アクセプターになっている水素結合の数
  - n_out_acceptor_res / n_in_acceptor_res: アクセプター側の残基について同じ2つ
  - n_hb_total: 上の4つの合計
  - n_partner_backbone / n_partner_sidechain / n_partner_water: 上の4つに数えた水素結合について、相手側の原子の種類ごとの数（主鎖の原子なら主鎖、側鎖の原子なら側鎖、水の酸素なら水）
  - n_competing: ペア自身のドナー原子が相手以外へ出している水素結合と、ペア自身のアクセプター原子が相手以外から受けている水素結合の合計
  - n_hb_donor_res_total / n_hb_acceptor_res_total: 各残基について、相手以外との水素結合の合計（n_out と n_in の和）
  - このほかに、確認用としてフレーム0のペア距離と、その距離が 3.5 Å 以下かどうかも記録した（量としては使わない）。
- 原子の対応: 変換済み軌道は重原子だけが元の順序で並んだものであるため、完全形式のタンパク質原子のうち水素でないものの順序（heavy_rank）で対応付けた。
- 対応の確認（前提）: 完全形式から計算したペア距離と、K06(b) に保存された履歴の距離（フレーム0は履歴の1列目、フレーム10は候補の起点距離）を突き合わせた。108タンパク質×3レプリカすべてで、フレーム0の最大の差は 0.0020 Å 以内、フレーム10（完全形式のフレーム100）では 0.0038 Å 以内、ペア原子の元素の確認もすべて通り、前提は全項目通過した（premise_check.json）。
- 完全形式の軌道は手元に無かったため、ATLAS から取り直した。zip は1タンパク質あたり 0.5〜7.6 GB あるため、HTTP の範囲リクエストで目次と TPR の全体、XTC は先頭だけ（原則 48 MB 分の展開量、フレーム0と100を含む）を取り、数え終わったタンパク質から取得ファイルは消した。4 GB を超える zip（ZIP64 形式、1lsl_A の 7.6 GB など）は目次と中央目録の読み方を ZIP64 に対応させて取った。取得はこのマシンから41タンパク質、Colab（無料枠の T4）から67タンパク質を分担した。
- 測る位置についての訂正（2026-11-25、統括からの補足）: 静的な予測の入力は起点フレーム（フレーム10、1 ns の時点）なので、候補の量はまず起点フレームで測る。最初に登録した実験は初期構造（履歴のフレーム0）で測ったが、その結果は後の手順での比較用に残し、同じ完全形式の軌道のフレーム100（起点フレームにあたる）で、同じ数え方で11の量を数え直す。フレーム0の数とフレーム10の数で、ずれとの関係を別々に見る。

### 量の水準（テスト全体の平均）

ペアの2残基は、相手以外と平均 18.1 本の水素結合を作っている（相手が水のものが 8.9 本、主鎖のものが 8.1 本、側鎖のものが 1.1 本）。競合の数は平均 5.3 本。どの量も候補によってよくばらつく（n_hb_total の標準偏差 5.3、最大 38）。

## 3. 結果

### 相関（テスト全体、163,074件）

| 量 | Pearson（GBM のずれ） | Spearman（GBM のずれ） | Pearson（線形のずれ） |
|---|---:|---:|---:|
| n_out_donor_res | +0.080 | +0.018 | +0.087 |
| n_in_donor_res | −0.006 | −0.014 | −0.016 |
| n_out_acceptor_res | −0.009 | −0.031 | −0.008 |
| n_in_acceptor_res | +0.079 | +0.041 | +0.066 |
| n_hb_total | +0.083 | +0.035 | +0.075 |
| n_partner_backbone | −0.081 | −0.077 | −0.076 |
| n_partner_sidechain | −0.042 | −0.038 | −0.038 |
| n_partner_water | +0.140 | +0.087 | +0.128 |
| n_competing | +0.171 | +0.154 | +0.173 |
| n_hb_donor_res_total | +0.057 | +0.015 | +0.055 |
| n_hb_acceptor_res_total | +0.063 | +0.035 | +0.053 |

最も強い競合の数でも +0.171 で、目安の 0.3 には届かない。次に強い相手が水の数（+0.140）までで、残りはすべて絶対値 0.09 以下。向きは、競合や水との水素結合が多いペアほど、実の平均が静的な予測より長い（ずれが正）という向きである。

タンパク質ごと（レプリカをまとめて Pearson）に見ても、絶対値 0.3 以上になったのは競合の数で1タンパク質（0.303）だけであり、ほかの量では 0 件だった。競合の数のタンパク質ごとの相関の平均は +0.172 で、全体の値とそろっている。

静的な特徴だけでは 0.6002 Å。

### 対照（別のペアの値と入れ替え）

11の量すべてを、タンパク質×レプリカの中でまとめて並べ替えて足し直すと、ばらつきは 0.6009 Å となり、静的な特徴だけの 0.6002 Å とほぼ同じに戻った。全部足したときの小さい減りは、並べ替えで消える種類のものであることは確かめられた。個別の量の入れ替え対照は、先に固定した決めにより、相関の絶対値が 0.3 以上になった量だけを対象とし、今回は該当する量が無かったため行っていない。

## 4. 読み取り

- **初期構造（フレーム0）で測る限り、ペアの周りの水素結合のつながり方はずれの正体ではない。** 相関は最も強くても +0.171 で目安の 0.3 に届かず、11の量すべてを足してもばらつきは 0.600 Å から 0.583 Å までしか減らない。判定の線（0.30 Å）との差は大きい。起点フレーム（フレーム10）での測り直しは進行中。
- **弱い正の関係は本物である。** 競合の数と相手が水の数で相関の向きがそろい（GBM のずれでも線形のずれでもほぼ同じ値）、タンパク質ごとの平均でも同じ向きで、全部足したときの減りは入れ替え対照で消えた。ペア自身の原子がすでにほかに使われているペア、周りに水との水素結合が多いペアは、静的な予測が思うより平均距離が少し長い、という程度の関係である。
- 全部足したときの減りの大部分は、競合の数と相手が水の数で担われている（この2つだけで、単独で足した場合の減りの大半になる）。ただしその大きさは、ずれのばらつき 0.60 Å に対して 0.017 Å でしかない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 初期構造でペアの2残基が相手以外と作っている水素結合の数・相手の種類・競合の数は、ずれと弱い関係（相関は最大 +0.17）を持つが、ずれの大部分を説明しない。K25 の残基の環境、K36/K49 の水の環境に続いて、水素結合のつながり方に限った量でも、フレーム0で測る限りは、ずれの正体の候補からは外れる形になった。
- まだ分からないこと: ずれの正体そのものは、この実験では分からない。起点フレーム（フレーム10）での測り直しを進めており、その結果が出るまでは、フレーム10で測れば違う結果になる可能性は残る（K3-06 はフレーム10で測り直すとフレーム0にあった弱い信号が見られなくなったと記録しており、逆向きの変化もありうる）。また、水素結合の有無だけを数えており、結合の強さや角度、水素結合の相手同士のつながり（2つ先のつながり方）は測っていない。弱い正の関係がなぜあるのかも測っていない。
