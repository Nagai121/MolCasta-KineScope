# K26 他の生成方式の平均の誤差も、入力の情報の下限に張り付いているか

## 問い

K23 で、第22案の生成器の平均の誤差（標準偏差 0.483 Å）が、静的な特徴からの予測の残差（0.492 Å）とほぼ同じで、レプリカ間のばらつき（0.249 Å）の約2倍であることが分かった。他の生成方式（第2案、第8案、第11〜14案）でも同じかを、同じ候補・同じ物差しで測る。

## 対象と定義

- 候補は K23 と同じ 14,582 件（資料Dの条件、水素結合形成）。実の平均は K23 と同じく実履歴11点（0〜1 ns）の平均。
- 生成の平均は、K11 で再生成した各方式の系列を使い、K11 の約束どおり「分岐×（起点＋ステップ）」のブロック全体の平均とした。第2案は複製3本×8ステップ、第11〜14案は分岐4本×8ステップ、第8案は供与体側・受容体側のロタマー経路を分岐として扱った。第22案とその弾性のみの系列は K05 の保存系列から同じ約束で計算し直した。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、平均（全体のずれ）と標準偏差と相関を出した。

## 結果

| 方式 | 誤差の平均 (Å) | 誤差の標準偏差 (Å) | 実平均との相関 |
|---|---|---|---|
| 第22案 | −0.155 | 0.483 | 0.836 |
| 第22案（弾性のみ） | −0.117 | 0.501 | 0.822 |
| 第2案（物理積分） | −0.114 | 0.505 | 0.819 |
| 第11案 | −0.115 | 0.501 | 0.822 |
| 第12案 | −0.116 | 0.502 | 0.822 |
| 第13案 | −0.109 | 0.504 | 0.819 |
| 第14案 | −0.106 | 0.503 | 0.820 |
| 第8案（ロタマー） | −0.014 | 0.523 | 0.808 |

K23 の物差し：レプリカ間差の標準偏差 0.249 Å、静的な特徴からの予測の残差 0.492 Å。第22案の値は K23 の記録（0.483）と一致した。

- どの方式も誤差の標準偏差は 0.48〜0.52 Å の狭い範囲にあり、静的な予測の残差（0.492）と同じ水準で、レプリカ間のばらつき（0.249）の約2倍です。方式の間の差（最大で 0.04 Åほど）は、下限との開き（約 0.25 Å）に比べて小さいです。
- 全体のずれは、第22案が −0.155 Å と最も大きく、弾性系と物理積分は −0.11 Å 前後、第8案はほぼ 0 でした。ただし誤差の大きさ（標準偏差）はずれの大きさとは別で、どの方式もほぼ同じでした。
- 第11案と第22案の弾性のみの系列は、誤差の標準偏差が小数点以下まで一致しました（0.501）。どちらも弾性モードの粗い経路そのものであるためで、当然の結果です。
- 第8案には注意点があります。ロタマー経路が1本でもある候補は全体の 46.1% しかなく、その部分では誤差の標準偏差は 0.705 Å と全方式で最も大きいです。経路が無い候補（53.9%）では生成の平均は起点の距離そのものになり、誤差の標準偏差は 0.284 Å と小さく出ます（この部分はもともと履歴の平均が起点の距離からあまり動かない候補に偏っています。全候補で「実の平均 − 起点の距離」の標準偏差は 0.501 Å です）。合算の 0.523 Å は、この2つの部分が混ざった値です。

## 結論

- 先に固定した読み方に沿うと、「どの方式も 0.49 前後に張り付いている」側になりました。入力の情報の不足が共通の原因という読みが強くなります。
- 方式ごとの出来の差は、全体のずれ（第22案の −0.155 Å など）には残っていますが、候補ごとの誤差の大きさでは、どの方式も静的な予測と同じ水準から抜け出ていません。
- 第8案だけは合算の見かけと中身が違います。実際に動かしている候補では最も誤差が大きく、合算が他方式並みに見えるのは、動かしていない候補の分が混ざっているためです。
