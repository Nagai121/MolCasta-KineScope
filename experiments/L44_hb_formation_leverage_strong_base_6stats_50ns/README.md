# L44: 統計量6種で L01 の曲がりを強い土台で測る（K06(b) の条件、水素結合の形成、50 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の続き。L39（強い土台、未見100タンパク質×3レプリカ、1 ns先）、L41（同、5 ns先）、L42（同、10 ns先）、L43（同、30 ns先）、L40（同、90 ns先）では、履歴の要約を切り取りの平均だけから統計量6種（実験Dの定義）に広げて曲がりを測った。ここでは同じ土台・同じ長さの定義で予測幅 50 ns の曲がりを測り、平均だけの場合（L07、50 ns先）と比べて必要な長さが縮むかを見る。これで水素結合の形成・強い土台の統計量6種の曲がりは全予測幅（1・5・10・30・50・90 ns先）がそろう。
- 状態: 完了。**統計量6種では、必要な長さは縮まなかった。** 回復率 0.8 に届く最小の長さは全体では 0.7 ns で、平均だけと同じ（タンパク質ごとの平均では 0.7 ns で、平均だけの 0.6 ns より 0.1 ns 長い）。0.9 に届く最小の長さは全体では 0.9 ns で、平均だけと同じ（タンパク質ごとの平均では 0.9 ns で、平均だけの 0.8 ns より 0.1 ns 長い）。曲がりは 0.1〜0.3 ns でほぼ平ら（全体 0.494 → 0.505 → 0.513）で、0.4 ns で 0.687 に上がり、その後緩やかに上がって 1.0 ns の 0.972 が頂点になる。同じ長さでの差は短い側で大きく負け（0.3 ns で全体 −0.186）、6種が上回るのは 0.6・0.9・1.0 ns だけだった。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを L01・L02 と同じ11通り（覆う長さ 0〜1.0 ns、0.1 ns 刻み）に変え、各長さで「切り取りの統計量6種」を履歴の特徴量として強い土台の補正モデルに入れたときの 50 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。比較のために、L07 とまったく同じ作り方の「切り取りの平均だけ」の条件も同じ実行で学習し直し、回復率を並べる。

読み方は先に固定した（L39 と同じ）。

1. 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを、全体（pooled）で読む（タンパク質ごとの平均（macro）も併記する）。平均だけ（L07）の答え（0.8 は全体 0.7 ns／平均 0.6 ns、0.9 は全体 0.9 ns／平均 0.8 ns）と比べて、必要な長さが縮んだかどうかを明記する。
2. 増え幅が最大の区間の場所と大きさを読む。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）で付ける。各標本の中でも静的のみ・全部入り・各長さの AUPRC を測り直し、利得と回復率をその標本の中で計算し直す。
4. 段の前後ではタンパク質ごとの値も記録する。

- 系列は G05 で作り直したもの（`~/workspace/kinescope/work/g05_series/`、タンパク質ごとの `r{r}_series`、11点×候補数）をそのまま使う。静的特徴と履歴の要約値10個は K06(b) の保存値（`~/workspace/k06b/run/k06b_out/`）を使う。実行はローカルVM（統計量の照合と学習24条件で約1分、ブートストラップ 10,000回込みで全体約21分）。

### 統計量6種の定義（実験Dの定義どおり、L39・L40 で確認済み）

統計量6種は、実験D（固定した 1 ns 履歴の実験）の `features_from_history` の定義をそのまま使う。出典は MolCasta-InternalResearch ブランチ `research/fixed-1ns-3phen-6h-20261121` の `GPT遊び場/ATLAS-実軌道-2026-11-19/fixed_1ns_history_3phen_6h.py` で、並びは次の通り。

1. 最初の値（系列の最初のフレームの距離）
2. 平均
3. 標準偏差（ddof=0、numpy の `std` の既定）
4. 最小値
5. 最後−最初（系列の最後のフレーム − 最初のフレーム）
6. 閾値以下だった割合（閾値は水素結合の形成の境界 3.5 Å。同スクリプトの `THRESH["hb"] = 3.5` で、割合は `(series <= bound).mean`）

値は float32 に落とす（同スクリプトの作り方どおり）。切り取りへの適用は、同じ式を切り取りの部分系列（フレーム 0〜k）にそのまま適用する。「最後」は切り取りの最後のフレーム、「割合」は切り取りの中での割合になる。覆う長さ 0 ns（1フレーム）では標準偏差と最後−最初は 0 になり、割合は「最初の値が 3.5 Å以下かどうか」の 0/1 になる。

### K06(b) の履歴特徴10個との関係

K06(b) の全部入りの履歴特徴10個は、同じ g05_series の11フレームから次の式で再現できる（下の premise で全数照合した）。

| 位置 | K06(b) の要約値10個 | 実験Dの6種に入るか |
|---:|---|---|
| 0 | 最初 | 入る（1番目） |
| 1 | 平均 | 入る（2番目） |
| 2 | 標準偏差 | 入る（3番目） |
| 3 | 最小 | 入る（4番目） |
| 4 | 最大 | 入らない |
| 5 | 最後−最初 | 入る（5番目） |
| 6 | 最後−直前 | 入らない |
| 7 | 3.5 Å以下割合 | 入る（6番目） |
| 8 | 4.5 Å以下割合 | 入らない |
| 9 | 増加割合（隣り合うフレームで増えた割合） | 入らない |

つまり実験Dの6種は K06(b) の10個の部分集合で、10個は6種に「最大、最後−直前、4.5 Å以下割合、増加割合」の4つを足した拡張である。したがって全部入り（11フレーム全部の要約値10個）は6種の上位集合で、覆う長さ 1.0 ns の6種の条件は、全部入りから4特徴を落とした条件にあたる。

### 長さの呼び方（L01・L02 と同じ、結果を見る前に固定）

長さは「覆う長さ」で統一し、定義は L01・L02 にそのまま合わせた。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う（0 ns はフレーム0だけの1フレーム、1.0 ns はフレーム 0〜10 の11フレーム全部）。起点フレーム10（1 ns）は変えず、ラベルは 50 ns先のまま。G 系列の呼び方との対応も L02 と同じで、L44 の覆う長さ 1.0 ns は G05 の「全部」側の定義（11フレーム全部）であり、G145 の「1.0 ns」（フレーム [0..9]）とは違う。

### 条件の一覧（50 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。L07 とまったく同じ作り方（premise の照合と比較用）。
- 切り取りの統計量6種: 静的特徴＋切り取りの統計量6種。覆う長さ 0.0〜1.0 ns の11通り（主役）。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。全体（pooled）とタンパク質ごとの平均（macro）の両方で測る（L02・L39 と同じまとめ方）。macro の AUPRC は、陽性が0件でも全部でもないタンパク質（100タンパク質すべてが該当）ごとの AUPRC の平均。

## 3. ブートストラップの段取り（結果を見る前に固定、L39 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストの100タンパク質から復元抽出で100タンパク質を選び直す。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・各長さの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直した。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化している。6種と平均だけの両方の系列を、同じ抽出で測っている。
- 全体の AUPRC の計算は L02 と同じ numpy 実装（sklearn の average_precision_score と同じ段取り）を使い、実際の予測確率で全24条件について sklearn の値と 1e-9 未満まで一致することを確かめてから使った。
- 10,000回の抽出すべてで、標本内の実履歴の利得は全体でもタンパク質ごとの平均でも 0 以下にならなかった（回復率が定義できない抽出は 0 件）。

## 5. 読み取り

- **統計量6種を使っても、50 ns先で必要な長さは縮まらなかった（全体の読みでは 0.8 の線も 0.9 の線も平均だけと同じ、タンパク質ごとの平均ではどちらも 0.1 ns 長い）。** これで統計量6種の曲がりは全予測幅がそろい、必要な長さが縮んだのは 1 ns先（L39、どちらの線も 0.1 ns）と 5 ns先（L41、0.9 の線だけ到達可能に）だけで、残りの予測幅では同じか長くなった。統計量6種にしても必要な長さは一様には縮まない、という形で地図が閉じた。
- 50 ns先の6種の曲がりで一番目立つのは、短い側の平らさである。0.1〜0.3 ns の増え分はほぼ 0 で、平均だけが同じ区間で +0.24（全体）上がるのと対照的である。6種のうちどの要約値がこの平らさを担っているかは、この実験では切り分けていない。
- 増え幅最大の区間（0.3→0.4 ns）は全体とタンパク質ごとの平均でそろったが、その手前が平らな区間であることと合わせて、段というより「遅れて上がり始める」形と読むのが自然である。
- 費用の側は L07 と同じくまだ何も言えない。分母はシミュレーションの長さ（ns）で、実測の費用への換算は L03 の形（G04 の実測との対応付け）で行う。

## 6. 判断できること・まだ分からないこと

- 判断できること: 強い土台（未見100タンパク質×3レプリカ、水素結合の形成、50 ns先）で履歴に統計量6種を使うと、回復率 0.8 に届く最小の覆う長さは全体で 0.7 ns（平均だけ 0.7 ns と同じ）、0.9 に届く最小の覆う長さは全体で 0.9 ns（平均だけ 0.9 ns と同じ）で、全体の読みでは必要な長さは縮まなかった。タンパク質ごとの平均ではどちらの線でも平均だけより 0.1 ns 長い。増え幅がいちばん大きいのは全体・平均とも 0.3→0.4 ns（全体 +0.174）だが、手前の 0.1〜0.3 ns が平らな区間である。同じ長さの差は 0.2〜0.3 ns で全体 −0.144〜−0.186 と大きく負け、上回るのは 0.6・0.9・1.0 ns だけだった。
- まだ分からないこと: 0.1〜0.3 ns で6種が平らになる理由と、6種のうちどの要約値が担っているかは、この実験では切り分けていない。統計量6種の形の地図は本実験で全予測幅がそろったため、残る問いは要約値ごとの切り分けになる。
