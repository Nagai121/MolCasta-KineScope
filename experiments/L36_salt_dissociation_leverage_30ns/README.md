# L36: L01 の曲がりを塩橋の解離で測る（K15 の土台、30 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 30 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。点推定では、切り取りの平均だけの条件が全長さで全部入り（6統計量）を上回りました（回復率 1.000〜1.815）。ただし分母の利得が小さく（全体 +0.0633、平均 +0.0156）、ブートストラップでは全体で 1,116回、平均で 3,535回（10,000回中）の抽出で利得が 0 以下になり、区間は非常に広いため、比率の大きさ自体は確かには読めません。AUPRC で見れば、どの長さの平均だけの条件も全部入りと同等以上です。

## 1. 何を確かめる実験か

L33 と同じ段取りで、予測幅だけを 30 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、30 ns先の陽性 149件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.4799、全部入り 0.5432、利得 全体 +0.0633／平均 +0.0156 で、K2-24 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G69 の平均だけの走査と一致しました（覆う長さに直して 0.1 ns で 1.815、0.2 ns で 1.626、0.5 ns で 1.435）。

### 先に固定した読み方への答え（機械的な適用の結果）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.108）。全長さで点推定は 1.000 以上です。
2. 増え幅がいちばん大きい場所: 0→0.1 ns（全体 +0.708、平均 +2.399）。段の位置でのタンパク質ごとの増え分は中央値 +0.319、正だったのは 15タンパク質のうち 60% でした。
3. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 30 ns先では、平均だけの条件が 6統計量の全部入りを全長さで上回るという点推定の形になりました。30 ns先は G69 の走査でも回復率が 1 を大きく超えた予測幅で、同じ結果の再現です。
- ただし比率の区間は非常に広く（全体でも上限が +3.6〜+13.3）、「どれだけ上回るか」は決められません。確かなのは AUPRC の水準として、平均だけの条件（全体 0.543〜0.595）が全部入り（0.5432）と同等以上であることまでです。
- 平均の利得（+0.0156）が特に小さいため、平均の回復率は読みの対象にできません。
