# G77: 接触の解離で、6 個の統計量の切り取りでも長い予測幅での回復率を測る（資料Dの条件、接触の解離、5・10・30・50・90 ns先）

- 確かめること: G71 は平均だけの切り取りで長い予測幅を測った（0.5 を超える最小の切り取りは 5・10・30・50・90 ns先のすべてで 0.1 ns）。6 個の統計量を入れた切り取りではどうか。
- 状態: 完了。全体で見た回復率 0.5 を超える最小の切り取りは、5・10・30・50・90 ns先のすべてで 0.1 ns。タンパク質ごとの平均でも同じ形。平均だけ（G71）と同じ形。

## 1. 何を確かめる実験か

条件は資料Dの接触の解離。予測幅は 5・10・30・50・90 ns、切り取りは 0.1・0.25・0.5 ns で、6 個の統計量を入れたときの回復率を測る。土台の利得は K16・K50 の各予測幅の記録値。

読み方は先に固定した。各予測幅で、回復率 0.5 を超える最小の切り取りを出す。タンパク質ごとの回復率も記録する。

## 2. 条件

- 土台は資料Dの条件（接触の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 6,383件・テスト 2,915件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。静的特徴5個。キャッシュは `~/workspace/kinescope/work/k50_cache/`（接触の解離の候補）。
- 6 統計量の定義は G71 の full_hist と同じ形で、境界は接触の 4.5 Å：[最初, 平均, 標準偏差, 最小, 最後−最初, 4.5 Å以下割合] を切り取りのフレームで計算する。切り取りは 0.1 ns = フレーム [0,1]、0.25 ns = フレーム [0,1,2]、0.5 ns = フレーム [0,1,2,3,4,5]。
- 条件: 静的のみ／履歴全部入り（11フレームの 6 統計量、参照）／切り取りの 6 統計量（0.1・0.25・0.5 ns）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）。土台の静的のみ・全部入りの AUPRC は、K16・K50 の記録値（G71 が再現した値と同じ）と小数第4位まで一致することを各予測幅で確かめた。
- タンパク質ごとの回復率の定義は G48・G66・G72・G75 と同じ：テストのタンパク質それぞれ（3レプリカを合算）について、静的のみ・全部入り・切り取りの AUPRC を出し、回復率 =（切り取り − 静的のみ）÷（全部入り − 静的のみ）で、そのタンパク質自身の利得を分母にする。陽性が 0件・全件のタンパク質と、利得の絶対値が 0.01 以下のタンパク質は回復率を出さない。接触の解離のテストは 1mix_A と 2qt4_A の 2タンパク質だけなので、タンパク質ごとの表は 2行になる。平均と中央値の両方を出すが、2タンパク質しかないため平均は 2つの値の平均にすぎない点に注意する。
- 注意: K50 のキャッシュの `hist` は (n, 11) の並びで保存されているため、転置は要らない（G71 と同じ。K46 のキャッシュとは並びが違う）。

## 4. 読み取り

先に固定した読み方に照らすと、全体で見た回復率 0.5 を超える最小の切り取りは、5・10・30・50・90 ns先のすべてで 0.1 ns。タンパク質ごとの平均でも同じ形。平均だけ（G71）と同じ形で、接触の解離では 6 統計量でも 0.1 ns で全予測幅が 0.5 を超える。90 ns先の 0.1 ns は 0.938 と高く、水素結合の解離（G72）の 90 ns先の 0.1 ns（0.183）とは対照的。

接触の解離では、6 統計量は平均だけとほぼ同等で、10 ns先の 0.5 ns は 1.009 と実履歴を上回る。50 ns先では切り取りを長くしても回復率が単調に上がらず、0.1 ns の 0.659 から 0.25 ns の 0.610 へ下がる。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の解離では、6 統計量の切り取りでも 5・10・30・50・90 ns先のすべてで 0.1 ns が 0.5 を超える。全体とタンパク質ごとの平均は全予測幅で一致するが、1つ1つで見ると 50 ns先の 2qt4_A の 0.1・0.25 ns と 90 ns先の 2qt4_A の 0.25 ns は 0.5 に届かない。接触の解離では 6 統計量は平均だけとほぼ同等で、ほかの現象で見られた 6 統計量の崩れは出ない。
- まだ分からないこと: 50 ns先で 2qt4_A の 0.1 ns だけが 0.320 と低い理由。接触の 1 ns先（G06）の 6 統計量と長い予測幅での形が同じ原因か。
