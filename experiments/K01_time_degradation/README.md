# K01: 実軌道の履歴の時間を加工する

## 仮説

H2（時間の表現の不一致）と H5（特徴量の抽出と読み出しの問題）です。履歴のフレーム数や時間の並びを壊したときに、指導力がどれだけ落ちるかを見ます。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。水素結合形成、起点1 ns、履歴0〜1 ns、予測幅1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。
- モデルは条件ごとに学習し直す比較です。変えたのは履歴系列の時間の加工だけです。
- 加工は4条件です。
  - 間引き6: フレーム 0,2,4,6,8,10 の6フレームから6統計量を作り直す
  - 間引き3: フレーム 0,5,10 の3フレームから6統計量を作り直す
  - 順序の入れ替え: 候補ごとにフレーム順をランダムに入れ替える（seed 固定）。6統計量のうち平均・標準偏差・最小値・閾値以下の割合は順序で変わらないため、実際に変わるのは「最初の値」と「最後−最初」だけです
  - 時間の逆転: 11フレームを反転させる。これも主に「最初の値」と「最後−最初」の符号が変わります

## 結果（AUPRC、テスト合算）

基準は土台の履歴あり（D6）です。括弧内は基準との差です。

| 5 ns | 0.4648 | 0.4367 (−0.028) | 0.4321 (−0.033) | 0.4711 (+0.006) | 0.4830 (+0.018) |

## 判断できること

- フレームを11から3まで間引いても、指導力の大半は残ります。1 ns先で AUPRC の低下は約0.017で、静的のみとの差（約+0.118）の大部分が残っています。履歴の時間解像度は、少なくともこの土台とこの集計では、指導力の主因ではありません。
- フレームの順序を入れ替えても、時間を逆転させても、指導力はほぼ落ちません。予測幅によっては基準より少し上がる点もあります。この土台の6統計量では、時間の並びの情報はほとんど使われていないことが分かります。指導力の中身は、並びではなく、距離の水準や分布（平均、最小値、閾値以下にいた割合など）にあると考えられます。
- そのため、生成軌道で指導力が出なかった理由を「時間の刻みや並びの違い」だけで説明するのは、この結果とは合いません。ただし、これは集計が順序の情報をほぼ捨てている土台での結果です。順序を使う読み出し方（系列そのものを入れるモデルなど）では結論が変わる可能性があります。

## まだ分からないこと

- 生成軌道の時間の相関の違い（速すぎる・遅すぎる動き）が、分布の統計量を通して効いている可能性は、この実験では切り分けられていません。
