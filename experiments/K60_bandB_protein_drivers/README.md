# K60: 遠い幅のばらつきを引っ張るタンパク質はどれか（K55・K57 の続き）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。遠い幅（4.5〜6.0 Å）での平均だけの戻り方のばらつきは、2タンパク質の利得の向きの食い違いによるもので、食い違いを引っ張っているのは 2qt4_A です。2qt4_A では幅Bの利得が 6幅中4幅で負（実履歴が静的のみを下回る）のに対し、1mix_A では 5幅で正で、幅Aでは両タンパク質とも全幅で正でした。ただし回復率の「高い・低い」は予測幅によって入れ替わり、分母がほぼ 0 の幅では比率が爆発するため、ばらつきを1つのタンパク質の回復率の性質として言い切ることはできません。2タンパク質しかないため、2qt4_A の違いがタンパク質の性質によるものか、陽性の少なさによる揺れかも決められません。

## 1. 何を確かめる実験か

K57 で、遠い幅（4.5〜6.0 Å）での平均の戻り方のばらつきは、タンパク質ごとの違いによることが分かりました。どのタンパク質がばらつきを引っ張っているか確かめます。

読み方は先に固定しました。特定のタンパク質だけが外れていれば、ばらつきはそのタンパク質の性質です。タンパク質ごとにまんべんなくばらつけば、遠い幅では平均の担い手がそもそも安定しません。テストが2タンパク質しかないため、「特定のタンパク質だけが外れている」かどうかの判定は、2つのタンパク質の回復率の差（範囲）が幅Aの2タンパク質の差よりはっきり大きいかどうかで読むことにします。具体的には、(a) 幅Bの範囲が幅Aの範囲より大きい予測幅が 6幅中4幅以上、かつ (b) 幅Bで同じタンパク質が「高い」側になる予測幅が 6幅中4幅以上、の両方を満たせば「特定のタンパク質が引っ張っている」と読みます。この定義は、タンパク質の性質の値を計算する前に固定しました（タンパク質ごとの回復率の値そのものは K57 の既知の値です）。

## 2. 方法（K55・K57 のデータの使い方）

- 新しい学習はしていません。タンパク質ごとの利得・回復率・AUPRC は K57 の `results.json`（K55 と同じ条件・同じ seed で学習し直したモデルの、テストをタンパク質ごとに評価した値）をそのまま使いました。K57 の `results.csv` と突き合わせて、値が一致することも確認しました。
- タンパク質の性質は、資料Dの抽出済みキャッシュ `~/workspace/kinescope/work/data_cache/`（6タンパク質×3レプリカ）と、変換済み軌道 `~/workspace/gpt-model-check/data/trajectories/` から計算しました（`run_k60.py`）。
  - 大きさ: 残基数（`atoms.parquet` の `residue_index` の種類数）、幅ごとの候補数・陽性数。
  - 柔らかさ: 候補ペアの11フレームの距離系列の標準偏差の平均、距離の範囲（最大−最小）の平均、最後−最初の絶対値の平均、Cα距離系列の標準偏差の平均。さらに、軌道の Cα 座標から、履歴のフレーム 0〜10 での1ステップあたりの Cα の移動量の平均（箱を軸ごとに扱う最小イメージで計算。3レプリカの平均）。
  - その他: 幅ごとの候補の起点距離の分布（平均、中央値、四分位数）。
- テストは2タンパク質（1mix_A、2qt4_A）しかないため、「最も高い」「最も低い」はこの2つの比較になります。タンパク質の性質の違いと回復率の違いの因果は、2タンパク質では決められません。違いを「挙げる」ことが目的で、因果の主張はしません。

## 3. タンパク質ごとの回復率（K57 の値）

回復率は「平均だけの利得 ÷ 全部入りの利得」です。利得はタンパク質ごとの全部入りの利得（AUPRC の差）です。

|---:|---:|---:|---:|---:|---:|---|---|
| 1 ns | +0.0318 | 0.972 | −0.0961 | 0.640 | 0.333 | 1mix_A | 2qt4_A |
| 5 ns | −0.0086 | −0.501 | +0.0938 | 0.104 | 0.605 | 2qt4_A | 1mix_A |
| 10 ns | +0.0661 | 0.647 | −0.0384 | −1.092 | 1.739 | 1mix_A | 2qt4_A |
| 30 ns | +0.0459 | 0.445 | −0.0037 | −19.093 | 19.538 | 1mix_A | 2qt4_A |
| 50 ns | +0.0557 | 1.182 | −0.0616 | −0.638 | 1.820 | 1mix_A | 2qt4_A |
| 90 ns | +0.0442 | −0.230 | +0.0394 | 0.926 | 1.157 | 2qt4_A | 1mix_A |

30 ns先の 2qt4_A の回復率 −19.093 は、分母の利得が −0.0037 とほぼ 0 のため比率が爆発したもので、比率としての意味はありません。5 ns先の 1mix_A（利得 −0.0086）や 90 ns先の 1mix_A（回復率 −0.230）も、利得が 0 に近い・負のセルでの比率で、読みには注意が必要です。

幅Aでも 50 ns先の 1mix_A の回復率 3.949 は、分母の利得が +0.0101 と小さいために膨らんだものです。利得が 0 に近いセルでは、幅Aでも回復率は比率として読めません。

### 範囲の比べ（先に固定した判定の材料）

- 範囲の中央値は幅A 0.444、幅B 1.448 で、幅Bの方が約3.3倍大きいです。
- 幅Bの範囲が幅Aの範囲より大きい予測幅は 6幅中5幅です（50 ns先だけ幅Aの方が大きい）。
- 幅Bで同じタンパク質が「高い」側になるのは 1mix_A が 6幅中4幅です。ただし幅Aでも 1mix_A が「高い」側になるのは 6幅中4幅で、同じ回数です。「同じタンパク質が高い」という条件だけでは幅Aと幅Bを区別できません。区別できるのは範囲の大きさと、利得の向きの食い違いです。

## 4. 利得の向きの食い違い（ばらつきを引っ張っているもの）

- 幅Bでは、1mix_A の利得は 5 ns先の −0.0086 を除いて全幅で正（+0.032〜+0.066）ですが、2qt4_A の利得は 6幅中4幅で負（−0.096〜−0.004）です。全体まとめの利得（+0.007〜+0.051）は、正のタンパク質と負のタンパク質の平均に過ぎません。
- 幅Aでは、両タンパク質の利得は全幅で正です。しかも 2qt4_A の利得の方が大きく（+0.140〜+0.279、1mix_A は +0.010〜+0.139）、2qt4_A は幅Aではむしろ指導力を多く持つタンパク質です。幅Bではその 2qt4_A が指導力を失い、利得が負になります。つまり、ばらつきを引っ張っているのは 2qt4_A の幅Bでの利得の符号の反転です。
- ただし、2qt4_A の幅Bの陽性は 1 ns先で6件、他の幅でも 11〜21件しかなく、利得の符号が陽性の少なさによる揺れかどうかは、この規模では分かりません。

| 量 | 1mix_A | 2qt4_A |
|---|---:|---:|
| 残基数 | 206 | 95 |
| 幅Bのテスト候補数 | 2,238 | 1,409 |
| 幅Bのテスト陽性数（1/5/10/30/50/90 ns） | 22 / 35 / 52 / 51 / 47 / 55 | 6 / 19 / 14 / 11 / 21 / 17 |
| 幅Bの起点距離の平均 / 中央値 | 5.330 / 5.338 Å | 5.306 / 5.315 Å |

| 幅Bの履歴の範囲の平均（ペア距離） | 1.302 Å | 1.009 Å |

- 起点距離の分布は、幅Bでは2タンパク質でほぼ同じです（平均の差 0.024 Å）。起点距離の違いがばらつきを引っ張っている、という読みはできません。
- 違いがあるのは大きさと柔らかさです。1mix_A は 2qt4_A の約2.2倍の残基数で、Cα の1ステップあたりの移動量は約1.4倍、幅Bの候補ペアの履歴の揺らぎ（標準偏差の平均）は約1.3倍です。1mix_A の方が柔らかいタンパク質で、その分だけ履歴の情報が残っている、という見方はできますが、2タンパク質しかないため因果は決められません。
- 陽性の数も大きく違います。幅Bの 2qt4_A の陽性は 6〜21件で、1mix_A の 22〜55件の半分以下です。2qt4_A の利得の符号が揺れやすいのは、陽性の少なさだけでも説明がつきます。

## 6. 読み取り

- **先に固定した読み方に沿うと、ばらつきは特定のタンパク質（2qt4_A）が引っ張っています。** 範囲の大きさの条件（幅Bが幅Aより大きいのが 6幅中5幅、中央値で約3.3倍）と、同じタンパク質が高い側になる条件（1mix_A が 6幅中4幅）は両方満たしました。ただし「同じタンパク質が高い」という条件は幅Aでも同じ回数（1mix_A が 6幅中4幅）なので、この条件だけでは幅Aと幅Bを区別できません。区別しているのは範囲の大きさと利得の向きの食い違いで、その食い違いの主役は 2qt4_A です。2qt4_A は幅Aでは指導力を多く持つタンパク質なのに、幅Bでは利得が 6幅中4幅で負になります。
- **ただし、回復率の「高い・低い」だけを見ると、特定のタンパク質が一貫して引っ張っている、とは言えません。** 幅Bで「高い」側は 1mix_A が 4幅、2qt4_A が 2幅で、予測幅によって入れ替わります。30 ns先の範囲 19.538 は 2qt4_A の分母がほぼ 0 による爆発で、比率としての意味はありません。回復率のばらつきそのものは、利得が 0 に近いことによる比率の不安定さでもあります。
- **2qt4_A の違いがタンパク質の性質によるものか、陽性の少なさによる揺れかは決められません。** 2qt4_A は 1mix_A より小さく（95残基 対 206残基）、柔らかさの量も小さい（Cα の移動量 0.750 Å 対 1.027 Å）ですが、幅Bの陽性も 6〜21件と少なく、利得の符号が揺れやすい条件です。タンパク質が2つしかないため、性質と結果の結びつきを確かめることはできません。

## 7. 判断できること・まだ分からないこと

- 判断できること: 幅Bの全体まとめの戻り方の振れは、2タンパク質の利得の向きの食い違いによるもので、その食い違いを引っ張っているのは 2qt4_A です（幅Bの利得が 6幅中4幅で負なのは 2qt4_A だけで、1mix_A は 5幅で正、幅Aでは両タンパク質とも全幅で正）。起点距離の分布の違いでは説明できません（幅Bの平均の差は 0.024 Å）。
- まだ分からないこと: 2qt4_A が幅Bで指導力を失うのが、タンパク質の性質（小さい、柔らかさが小さい）によるものか、陽性の少なさ（6〜21件）による揺れかは、この実験だけでは分かりません。幅Bのタンパク質を広げて、利得の向きがタンパク質によって本当に違うのかを確かめる必要があります。また、2qt4_A の幅Bの利得が負になる理由（実履歴が静的のみを下回る理由）も、この実験だけでは分かりません。
