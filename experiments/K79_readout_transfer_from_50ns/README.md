# K79 50 ns先で学習した読み出しは、他の予測幅で使えるか（K06(b) の条件、水素結合の形成）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる読み出しの移し替え
- 状態: 完了。50 ns先で学習した読み出しは 1 ns先と 90 ns先の両方で利得の8割以上を戻しました（1 ns先で 1.026／0.996、90 ns先で 1.330／1.283）。逆向きでも使えます。むしろ 50 ns先で学習した読み出しのほうが、同じ予測幅で学習した読み出しより利得が大きいです。

## 1. 何を確かめる実験か

K56 で、1 ns先で学習した読み出しを 50 ns先で使うと利得の戻り率は 0.608 と弱いことが分かりました。K77 で、50 ns先の担い手は平均（0.933）と 3.5 Å以下割合（0.888）の両方だと分かり、50 ns先の指導力そのものに担い手がないわけではありません。では逆向きはどうか、50 ns先で学習した読み出しは他の予測幅で使えるかを確かめます。

読み方は先に固定しました。逆向きでも利得の8割以上が戻れば、50 ns先の読み出しは他の予測幅でも使えます。戻らなければ、50 ns先の読み出し自体が他と違います。「8割以上」は 1 ns先と 90 ns先の両方での読みとし、片方だけ戻る場合はその旨を正直に記録します。

## 2. 条件

- 土台は K06(b) と完全に同じです。凍結した本体 T1I2006＋補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）で、較正用の8タンパク質（2vh3_A、3ga3_A、3wx4_A、3ol3_A、2es9_A、2in8_A、2iay_A、1lsl_A、候補 13,808件）で学習し、未見100タンパク質×3レプリカ（163,074件）で評価しました。特徴量は K06(b) の保存済みデータ（`~/workspace/k06b/run/k06b_out/`）をそのまま使いました。軌道の取り直しも、本体 T1I2006 の読み込みも、生成器のチェックポイントの読み込みも行っていません。距離の計算もしていません。
- 補正モデルの入力は、K56 と同じ静的5特徴＋実履歴10特徴です。特徴量は予測幅によらないので、50 ns先で学習したモデルをそのまま 1 ns先・90 ns先のラベルに当てています。静的な特徴だけの条件も、同じ容量で予測幅ごとに学習して評価しました。
- 利得は、評価する予測幅での静的な特徴だけの条件との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。参照する利得は、評価する予測幅で学習した条件の利得です。戻り率は、移し替えた利得を、評価する予測幅で学習した利得で割った値です。K56 の定義とやり方をそろえています。
- 測ったのは、50 ns先で学習した補正を 1 ns先と 90 ns先で評価する条件です。参照として、1 ns先と 90 ns先で学習・評価した条件も同じコードで測り直しました。
- 対照の確認: 静的な特徴だけの条件と実履歴の条件は、1 ns先と 90 ns先の両方で K06(b) の記録と全4指標で完全に一致しました（最大差 0.0、1 ns先で静的のみ マクロ AUPRC 0.4539、実履歴 0.5251、90 ns先で静的のみ 0.4357、実履歴 0.4630）。

## 3. 結果

50 ns先で学習した読み出しを 1 ns先と 90 ns先で評価した結果です。利得と戻り率は、全体まとめ（ミクロ）とタンパク質マクロ平均の両方で見ています。

| 評価する予測幅 | 静的のみ AUPRC（マクロ） | 同じ幅で学習した実履歴 AUPRC（マクロ） | 50 ns先で学習した実履歴 AUPRC（マクロ） | 移し替えた利得（全体／マクロ） | 参照の利得（全体／マクロ） | 戻り率（全体／マクロ） |
|---|---:|---:|---:|---:|---:|---:|
| 1 ns | 0.4591（0.4539） | 0.5293（0.5251） | 0.5311（0.5248） | +0.0720 / +0.0709 | +0.0702 / +0.0712 | **1.026 / 0.996** |
| 90 ns | 0.4418（0.4357） | 0.4683（0.4630） | 0.4770（0.4707） | +0.0352 / +0.0350 | +0.0265 / +0.0273 | **1.330 / 1.283** |

他の指標です。50 ns先で学習した実履歴は、1 ns先で AUC 0.9339、Brier 0.0451、Log Loss 0.1500、90 ns先で AUC 0.9066、Brier 0.0540、Log Loss 0.1809 で、同じ幅で学習した実履歴（1 ns先で AUC 0.9349、Brier 0.0451、Log Loss 0.1485、90 ns先で AUC 0.9060、Brier 0.0542、Log Loss 0.1812）とほぼ並びます。

## 4. 読み取り

- **50 ns先で学習した読み出しは、1 ns先と 90 ns先の両方で利得の8割以上を戻しました。** 先に固定した読み方の1つ目の枝に当たり、50 ns先の読み出しは他の予測幅でも使えます。戻り率は 1 ns先で 1.026／0.996、90 ns先で 1.330／1.283 で、どちらも8割を大きく超えています。
- 戻り率が 1 を超えている点に注意してください。50 ns先で学習した読み出しは、同じ予測幅で学習した読み出しより利得が大きいです（1 ns先では AUPRC 0.5311 対 0.5293、90 ns先では 0.4770 対 0.4683）。50 ns先の読み出しは他で使えるだけでなく、他より強い読み出しです。
- K56 との照合です。K56 の全組み合わせ（6×6）の 50 ns先で学習した行は、1 ns先で 1.03、90 ns先で 1.33（全体まとめ）で、K79 の 1.026 と 1.330 と小数第4位まで一致しました。タンパク質マクロ平均でも K56 の 0.996 と 1.283 と一致します。K79 は K56 の 50 ns先の行を、必要な学習だけを絞って測り直したもので、食い違いはありません。
- K56 との非対称です。1 ns先で学習した読み出しを 50 ns先に当てると 0.608 と弱い一方、50 ns先で学習した読み出しを 1 ns先に当てると 1.026 と強いです。移し替えの弱さは向きによって違います。50 ns先のラベルそのものが別で、他の予測幅の読み出しがそこに届きにくい一方、50 ns先で学習した読み出しは他でも使える、という K56 の読みと同じ形です。なぜ 50 ns先で学習した読み出しが他より強いのか（50 ns先のラベルが読み出しに何を教えるのか）は、この実験だけでは分かりません。
- K77 との関係です。K77 で 50 ns先の担い手は平均と割合の両方だと分かりました。50 ns先で学習した読み出しが他でも使えることは、担い手が予測幅によらず同じ形であることと合います。K56 の 1 ns先→50 ns先の弱さは、50 ns先の担い手の不在では説明できず、読み出しの移し替えの問題である、という K77 の読みも変わりません。

## 5. 判断できること・まだ分からないこと

- 判断できること: 50 ns先で学習した読み出しは、1 ns先と 90 ns先の両方で利得の8割以上を戻し（1.026 と 1.330）、他の予測幅でも使えます。むしろ同じ幅で学習した読み出しより利得が大きく、50 ns先の読み出しは他より強いです。K56 の 50 ns先の行と完全に一致します。
- まだ分からないこと: なぜ 50 ns先で学習した読み出しが他より強いのか。1 ns先で学習した読み出しが 50 ns先に移らない理由の中身も、この実験だけでは分かりません。
