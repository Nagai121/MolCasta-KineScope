# G68: 塩橋の形成で、50 ns先と 90 ns先の混合は足しになるか（K15 の条件、塩橋の形成、50 ns先・90 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDと生成の混合の続き。塩橋の形成の混合で、残っている予測幅 50 ns先と 90 ns先を埋める。
- 状態: 完了。50 ns先でも 90 ns先でも、どの案も +0.05 を超えなかった。混合は 4 案すべてで切り取り平均だけを下回った。予測幅で並べると、+0.05 を超えた案の数は 1 ns先で 4 案、5 ns先で 3 案、10 ns先で 2 案、30 ns先で 0 案、50 ns先で 0 案、90 ns先で 0 案。これで塩橋の形成の混合は 1・5・10・30・50・90 ns先のすべてが埋まった。

## 1. 何を確かめる実験か

K15 の条件（塩橋の形成、50 ns先と 90 ns先）で、0.1 ns の切り取り平均に G19 で作り直した残基レベル生成平均（第11〜14案）を別々の特徴量として足した混合を測る。比較のため、切り取り平均だけと生成平均だけの条件も同じ土台で測る。参照は実履歴の利得で、50 ns先は +0.027（静的のみ 0.2295、全部入り 0.2569）、90 ns先は +0.060（静的のみ 0.2136、全部入り 0.2736）、どちらも K15 と同じ。回復率は実履歴の利得に対する比で測る。

生成平均は、案ごとの branch-mean 9点系列を 9点で平均したもの（G13・G19 と同じ）。生成系列は G19 の gen/ をそのまま使う（K17 と同じ作り方で 88タンパク質×3レプリカ分作り直したもの）。

読み方は先に固定した。これまでと同じく、混合の回復率が切り取り平均だけより +0.05 を超える案の数で見る。土台の利得が小さいので、AUPRC の差の絶対値も記録する。

## 2. 条件

- 土台は K15 の条件。ATLAS 解析版、学習58タンパク質（2,557件）・テスト30タンパク質（1,170件、50 ns先の陽性 137件、90 ns先の陽性 149件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（キャッシュをそのまま使う）。
- 塩橋の形成の候補（K15 と同じ）: 正側（LYS の NZ、ARG の NE/NH1/NH2）と負側（ASP の OD1/OD2、GLU の OE1/OE2）の荷電重原子ペアの最小距離が、起点で 4.0 Å より大きく（塩橋ができていない状態）で配列距離2以上の残基ペア。ラベルは予測先で最小距離が 4.0 Å 以下になること。静的特徴は5個、履歴の閾値は 4.0 Å。
- 切り取りの定義（G02/G03 と同じ、結果を見る前に固定）: 軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。0.1 ns → フレーム 0, 1（2フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 50 ns先（フレーム510）と 90 ns先（フレーム910）のまま。

### 条件の一覧

- 静的のみ: 静的特徴だけ。
- 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、閾値 4.0 Å）。
- 切り取り平均だけ: 静的特徴＋0.1 ns の切り取り平均（フレーム [0,1]）。
- 生成平均だけ（第11〜14案）: 静的特徴＋案ごとの生成平均。
- 混合（第11〜14案）: 静的特徴＋切り取り平均＋案ごとの生成平均。

## 4. 読み取り

- **50 ns先でも 90 ns先でも、どの案も +0.05 を超えなかった。** 混合は 4 案すべてで切り取り平均だけを下回った。予測幅で並べると、+0.05 を超えた案の数は 1 ns先で 4 案、5 ns先で 3 案、10 ns先で 2 案、30 ns先で 0 案、50 ns先で 0 案、90 ns先で 0 案。塩橋の形成の混合は、10 ns先までで足しになり、30 ns先からは足しにならない。
- 50 ns先では、切り取り平均だけ自体が静的のみを下回る（AUPRC 0.2261 に対して 0.2295）。G60 でも 50 ns先は 0.5 ns の切り取りでも回復率 0.476 と 0.5 に届かず、利得そのものが +0.027 と全予測幅で最小だった。50 ns先では切り取りも混合も、そもそも利得がほとんどない幅である。
- 回復率の差は、利得の分母が小さいため AUPRC の小さな差を大きく見せている。50 ns先の第13案の回復率の差 −0.312 は、AUPRC にして −0.0086 の差にしかならない。90 ns先の第14案の −0.152 も、AUPRC にして −0.0091。向きは AUPRC の差でも同じ（すべて負）なので、混合が下がるという読み取り自体は分母のせいではない。
- 生成平均だけでは、50 ns先で 4 案すべてが静的のみを下回り、90 ns先でも第13・14案だけが静的のみをわずかに上回る。長い予測幅では生成平均だけでは何も戻らない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 50 ns先と 90 ns先ではどの案も +0.05 を超えず、混合は 4 案すべてで切り取り平均だけを下回った。これで塩橋の形成の混合は 1・5・10・30・50・90 ns先のすべてが埋まった。
- まだ分からないこと: 50 ns先は利得そのものが +0.027 と最小で、回復率の分母が小さいため、回復率の値は大きく振れる。ただし AUPRC の差でも混合はすべて負なので、向き自体は確か。単一の学習 seed の結果でもある。
