# L30: L01 の曲がりを塩橋の形成で測る（K15 の土台、30 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の形成（K15 の土台、全予測幅、L27〜L32）の 30 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は 0.1 ns で 0.966 まで上がり、その後は 0.80〜1.13 の高い水準でほぼ平らでした。分母の利得も全体 +0.0884／平均 +0.0965 と安定していて、ブートストラップで利得が 0 以下になった抽出は 0 件でした。ただし統合値の最初の跳ね（0→0.1 ns、+0.340）はタンパク質ごとでは裏づけられていません（増え分の中央値 −0.213）。

## 1. 何を確かめる実験か

L27 と同じ段取りで、予測幅だけを 30 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15（学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。候補の定義は K15 の記録どおり（起点の最小距離が 4.0 Å より大きく 10.0 Å 以下、配列の隔たり 2以上）。テスト 1,170件、30 ns先の陽性 133件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え

1. **回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0.1 ns（全体 0.966）**。平均では 0 ns の時点で 1.148 と線を超えています。その後も全体は 0.80 を下回らず、水準は保たれます。
2. **増え幅がいちばん大きい場所: 0→0.1 ns（全体 +0.340）**。平均では 0.3→0.4 ns（+0.400）。
3. 段の位置（0→0.1 ns）のタンパク質ごとの増え分は、中央値 −0.213 [−0.705, +0.575] で、正だったのは 20タンパク質のうち 45% でした。統合値の跳ねはタンパク質一般の動きではなく、回復率の水準が高いこと自体は全長さに共通しています。タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 20タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 30 ns先は、塩橋の形成の 6つの予測幅の中で曲がりがいちばん読みやすい部類です。短い切り取り（0.1 ns）で利得の大半が戻り、あとは高い水準で平らになります。G60 の走査（30 ns先、0.1 ns で 0.966）と点推定が一致します。
- それでも 95% 区間は幅 0.9〜1.2 と広く、長さの間の細かい差は決められません。「0.1 ns で大半が戻り、長くしても大きくは変わらない」という大まかな形が、この実験で言える範囲です。
