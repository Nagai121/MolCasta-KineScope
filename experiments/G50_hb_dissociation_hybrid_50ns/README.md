# G50: 解離で、50 ns 先の混合は足しになるか（資料Dの条件、水素結合の解離、50 ns先）

- 確かめること: G18 では 1 ns 先で −0.052、G44 では 30 ns 先で +0.086 だった。50 ns 先はまだ測っていない。
- 状態: 完了。混合の回復率は 0.578 で、切り取り平均だけ（0.563）より +0.015 しか上がらなかった。解離では 50 ns 先でも混合は足しにならない。

## 1. 何を確かめる実験か

条件は水素結合の解離、50 ns先。0.1 ns（フレーム [0,1]）の切り取り平均だけと、作り直した第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.1142（K46 の 50 ns先と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、解離でも 50 ns 先では混合が足しになることになる。+0.05 未満なら、解離では 50 ns 先でも混合は足しにならないことになる。

## 2. 条件

- 土台は資料Dの条件（水素結合の解離）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 4,051件・テスト 2,080件（50 ns先の陽性 362件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 50 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。
- 実履歴側は K46 のキャッシュ（`~/workspace/kinescope/work/data_cache_k46/` の `{protein}_R{rep}.npz`、静的特徴7個・11フレームの履歴・ラベル）を使った。解離の候補は起点距離 3.5 Å 以下のドナー・アクセプターのペア。
- 生成平均の出所: 解離の候補向けに作り直した第22案の生成5点系列（`~/workspace/kinescope/work/g18_gen22/` の `atlas-*.npz`、18軌道分、6,131ペア）。作り直しの経緯は G44 と同じ。K05 の生成系列は起点距離 3.5〜6.0 Å の形成候補だけで、解離の候補には1件も対応しなかったため、Echizen の判断（選択肢 (a)）で、候補選びの絞りを起点の距離が 3.5 Å より大きいペアだけを残す作りから、すべての残基をまたぐドナー・アクセプターのペアを残す作りに変えて作り直した（`expand_all`、K54 の gen_k54.py と同じ変更）。変えたのはその1行だけ。生成器のチェックポイントは weights_only で読み込み、読み込む前に generator.json に記録されたハッシュと照合した（K05・K74 と同じ決め事）。対応付けのキーは（軌道ID、ドナー原子、アクセプター原子）で、解離の候補 6,131件すべてをおおい、欠けは 0件だった。
- 注意: 生成器は形成の候補だけで学習しているため、解離の候補への当てはめは学習した範囲の外への当てはめになる。生成系列は起点から先への前方系列で、実履歴は起点までの後方系列。両者は起点距離 d0 を共有するが時間の向きが逆（G11 と同じ留保）。平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しない（平均の列だけを使うため）。
- 条件: 静的のみ／履歴全部入り（参照）／切り取り平均だけ（0.1 ns）／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.1142）。

## 3. 結果

### 土台の再現

50 ns先で静的のみ AUPRC 0.4088、全部入り 0.5231、利得 +0.1142 で、K46 の記録と小数第4位まで完全一致した。

### 50 ns先の利得の回復率

| 条件 | AUPRC | AUC | Brier | Log Loss | 回復率 |
|---|---:|---:|---:|---:|---:|
| 静的のみ | 0.4088 | 0.8419 | 0.1279 | 0.3706 | 0.000 |
| 全部入り（実履歴） | 0.5231 | 0.8708 | 0.1123 | 0.3355 | 1.000 |
| 切り取り平均だけ（0.1 ns） | 0.4731 | 0.8575 | 0.1217 | 0.3551 | 0.563 |
| 生成平均だけ | 0.4231 | 0.8430 | 0.1285 | 0.3699 | 0.125 |
| 混合（切り取り平均＋生成平均） | 0.4748 | 0.8577 | 0.1218 | 0.3569 | 0.578 |

混合の回復率は 0.578 で、切り取り平均だけ（0.563）より **+0.015** しか上がらず、先に固定した +0.05 の線には届かなかった。

### 作り直した生成系列の質（解離の候補、境界 3.5 Å）

| 量 | 生成系列 | 実の前方系列 |
|---|---:|---:|
| 平均距離 | 2.776 Å | 2.815 Å |
| 全体の標準偏差 | 0.428 Å | 0.689 Å |
| ペアごとの標準偏差 | 0.069 Å | 0.157 Å |
| 3.5 Å 以下だった割合 | 97.9% | 89.3% |
| ペアあたりの往復回数 | 0.054 | 0.487 |

生成系列は実系列より静かで、境界を往復する回数は約 1/9。形成の候補で測った K05 と同じ形（生成は実の約 1/5.5 の揺らぎ）で、解離の候補でも生成は静かすぎる。

### 切り取り平均と生成平均の関係（テスト側）

生成平均 − 切り取り平均は平均 −0.081 Å・標準偏差 0.593 Å、相関 0.683。生成平均と 0〜1 ns の平均の相関は 0.801、切り取り平均と 0〜1 ns の平均の相関は 0.937。

### 解離の混合の上がり幅（予測幅ごと、0.1 ns の切り取り）

| 予測幅 | 混合 − 切り取り |
|---|---:|
| 1 ns先（G18） | −0.052 |
| 30 ns先（G44） | +0.086 |
| 50 ns先（この実験） | +0.015 |

## 4. 読み取り

先に固定した読み方に照らすと、混合の回復率は切り取り平均だけより +0.015 しか上がらなかったため、解離では 50 ns 先でも混合は足しにならない、というのがこの測定の結論。解離の混合は、1 ns先で −0.052、30 ns先で +0.086、50 ns先で +0.015 と、予測幅によって向きも大きさも違い、30 ns先だけが +0.05 の線を超える。形成の混合が 1・30・90 ns先で +0.19〜+0.25、+0.48、+0.10 とそろって足しになるのとは違う形。

AUPRC の絶対値で見ると、混合が切り取り平均だけを上回る幅は +0.0017（0.4748 に対して 0.4731）とほぼゼロ。生成平均だけでも回復率 0.125 と弱く、解離では生成平均が持つ情報が切り取り平均の上にほとんど乗らない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 解離では、0.1 ns の切り取りに生成平均を足しても、1 ns先・50 ns先では混合は足しにならず、30 ns先だけが +0.086 と線を超える。解離の混合の効き目は形成より弱く、予測幅によってばらつく。
- まだ分からないこと: 30 ns先だけが線を超える理由。0.5 ns の切り取りにすれば解離の 50 ns先の混合が強まるか（形成の G30・G32 のように）。強い土台（K06(b)）の解離でも同じ形か。
