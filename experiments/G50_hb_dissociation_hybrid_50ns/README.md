# G50: 解離で、50 ns 先の混合は足しになるか（資料Dの条件、水素結合の解離、50 ns先）

- 確かめること: G18 では 1 ns 先で −0.052、G44 では 30 ns 先で +0.086 だった。50 ns 先はまだ測っていない。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は水素結合の解離、50 ns先。0.1 ns（フレーム [0,1]）の切り取り平均だけと、作り直した第22案の生成平均を足した混合の両方を、同じ補正モデルで測る。土台の利得は +0.1142（K46 の 50 ns先と同じ）。

読み方は先に固定した。混合の回復率が切り取り平均だけより +0.05 以上上がれば、解離でも 50 ns 先では混合が足しになることになる。+0.05 未満なら、解離では 50 ns 先でも混合は足しにならないことになる。
