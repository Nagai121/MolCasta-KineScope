# K84 接触の形成でも、案22の生成の平均の誤差の形は同じか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。接触の形成では、誤差の形は生成方式によりました。(a) の境界の勾配と (c) の隔たりの効果は案22と第11〜14案で同じですが、(b) の外れたペアでの誤差の大きさは違います。案22では 1.46 倍、第11〜14案では 1.16〜1.17 倍です。解離の3つの場合（K70・K76、K72・K81）では両方式が同じ形だったのと違い、形成の接触では初めて形が分かれました。

## 1. 何を確かめる実験か

K76・K81 で、解離では案22でも誤差の形が残基レベルの生成方式と同じだと分かりました。形成の接触でも同じか確かめます。

読み方は先に固定しました。案22でも誤差が境界の近くで大きくならず、外れたペアで大きければ、接触の形成でも誤差の形は生成方式によりません。形が違えば、誤差の形は生成方式によります。

## 2. 条件

- 対象は K13 の接触の形成の候補（資料Dの6タンパク質、23,310件）のうち、K14 で案22が与えられた 4,968件です。与えられるのは、代表原子ペア（起点で最小距離をとる重原子ペア）がドナー・アクセプターのペアである候補だけです。結果はこの部分集合に限ります。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は案22の5点系列（起点＋0.1／0.3／0.5／1.0 ns）の平均です（K30・K35・K76 と同じ約束）。第11〜14案の生成の平均は、枝の平均の9点系列（起点＋8段）の平均です（K48・K58・K67・K70 と同じ約束）。
- 分け方：(a) 起点の距離の帯（境界付近 4.5〜5.5 Å と、それ以外 5.5 Å 超。細かく 0.5〜1.0 Å 刻みでも測る）、(b) 実の平均の全体の平均からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K67・K70 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K67・K70 と同じ区切り）。
- 対照として、K35 の対照（実の代表ペア系列と実の最小系列、それぞれ実履歴の平均との差）も同じ分け方で測ります。
- ラベルとの関係も K35 と同じ測定をします。1 ns先のラベル（最小距離が 4.5 Å 以下になったか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べます。

## 3. 準備：K35 の並べ替えの再現と、第11〜14案の系列の作成

K35 の測定は、K14 の生成系列（案22）と K13 のキャッシュの並べ替えに `/tmp/k35_align.npy` を使っていましたが、このファイルはもう残っていません。そこで並べ替えをここで作り直しました。K14 の `min`（与えられる候補の5点最小系列）は `min_all`（全候補）の部分列で、`min_all` の起点の列は K13 のキャッシュの履歴の最終点と一致します（最大の差は 4.8e-07 Å で、これは `min_all` が float32 で保存されているための丸めです。K35 の文書には 0.0 と書かれていましたが、実際の値は 4.8e-07 でした）。5点系列の値そのもので突き合わせたところ、4,968行がすべて一意に一致しました。この並べ替えで案22の測定を再現したところ、K35 の数値と一致しました（全体のずれ −0.232 Å、誤差の標準偏差 0.435 Å）。

第11〜14案の系列は、接触の形成の候補には存在しなかったため、`gen_k84.py` で新しく作りました（K58 の生成コードを、キャッシュだけ K50 から K13 に変えたものです。資料Dの6タンパク質、18軌跡、23,310件）。起点の構造から弾性モードを取り、モード経路の信号と局所経路で第11〜14案を作り、候補の残基ペアの最小重原子距離を8段分計算しています。実の11点履歴は K13 のキャッシュと照合して通過しています（許容誤差 1e-9）。

生成の系列の質の確認では、実の前向き5点系列は平均 7.379 Å、ペアごとの標準偏差 0.330 Å、4.5 Å 以下になる割合は 0.021 でした。第11・12案の枝の平均はペアごとの標準偏差が 0.011／0.009 Å とほぼ動きません。第13・14案の枝の平均は 0.079／0.078 Å でした。解離の場合（K58）では枝の平均は同じく 0.078／0.082 Å でしたが、枝ごとのペアごとの標準偏差は形成では 1.33 Å と、解離の 0.16 Å よりずっと大きくなっています。枝ごとの系列は形成では大きく揺れますが、枝の平均を取ると打ち消し合って静かになります。形成の候補は起点の距離が大きく（平均 7.1 Å）、最小値をとる原子ペアが枝ごとに替わるためだと考えられますが、測定で使うのは枝の平均です。

## 5. 読み取り

- **境界の近くで誤差が大きくなる勾配は、どちらの方式にもありません。** 境界付近（4.5〜5.5 Å）とそれ以外の比は、案22 が 0.87 倍、第14案が 0.89 倍、第11案が 0.88 倍です。細かい帯も、案22・第14案のどちらもほぼ平らです。K35 の案22の測定（0.87 倍）を再現し、第11〜14案も同じでした。
- **外れたペアでの誤差の大きさは、方式で違います。** (b) では、実の平均が全体の平均（7.151 Å）から 1.0 Å 以上離れた候補（2,627件）で、案22の誤差は 0.486 Å になり、中心（0.25 未満）の 0.332 Å に対して 1.46 倍です。第14案では同じ帯が 0.419 Å、中心が 0.361 Å で、比は 1.16 倍です。第11案も 1.17 倍です。案22の裾の誤差は中心より大きく、第11〜14案の裾の誤差は中心とほぼ同じです。件数が多いため（裾 2,627件、中心 816件）、この比の違いは誤差のばらつきでは説明できません。
- **隔たりの効果は、どちらの方式でも同じです。** 21以上と 2〜5 の比は、案22 が 1.45 倍、第14案が 1.43 倍、第11案が 1.43 倍です。対照の実の前向き系列ではこの比が 1.74〜1.82 倍と、生成の方式より大きくなっています。
- **全体の誤差の大きさは、第11〜14案の方が小さいです。** 全体の誤差の標準偏差は、案22 が 0.435 Å、第14案が 0.408 Å、第11案が 0.408 Å です。全体のずれも、案22 が −0.232 Å に対して第14案が −0.036 Å、第11案が −0.031 Å と、第11〜14案の方が小さくなっています。第11〜14案の生成の平均は起点の距離とほぼ同じで、起点の距離と実の平均の相関は 0.960 と高いため、誤差が小さくなっています。弾性のみの系列も同じ数値（全体のずれ −0.033 Å、標準偏差 0.408 Å）で、第11〜14案の生成の平均は弾性のみの系列とほぼ同じです。
- **(b) の違いの仕組みは、生成の平均が実の平均にどれだけついていくかです。** 生成の平均を実の平均の線形の式で当てはめると、案22 の傾きは 0.837、第14案の傾きは 0.933 です。案22の生成の平均は中心に縮むため、実の平均が中心から遠い帯では縮みによる誤差が大きくなります。第14案の生成の平均は起点の距離とほぼ同じで、起点の距離は実の平均によくついていくため、裾の帯でも誤差が大きくなりません。
- **裾の帯の内訳は、解離の場合と違って両側に広がっています。** 裾の帯（2,627件）の実の平均は 3.19〜11.75 Å で、全体の平均より上が 1,259件、下が 1,368件です。生成の平均は、案22 が 4.29〜10.96 Å、第14案が 4.40〜11.25 Å です。誤差は、案22 が −3.36〜+2.88 Å、第14案が −3.83〜+2.66 Å と、両側に出ます。解離の場合（K67・K70・K72）では裾の帯の実の平均はすべて全体の平均より上で、誤差はすべて負の側に出ました。形成では裾の帯が両側に広がるため、誤差も両側に出ます。裾の帯の候補の起点の帯は、4.5〜5.5 Å が 809件、5.5 Å 超が 1,818件です。
- ラベルとの関係では、案22の誤差とラベルの相関が +0.170 で、縮み＋乱数の合成の +0.089 より強くなっています（K35 と同じ）。第14案の相関は +0.109 で、合成よりは強いものの、案22より弱くなっています。案22の生成の平均は、陽性と陰性の平均の差が −1.716 Å と、実の平均の −2.357 Å に比べて小さくなっています。第14案は −1.970 Å で、実の平均により近くなっています。
- 対照の実の前向き系列でも、(b) の裾と中心の比は 1.34〜1.37 倍と、案22（1.46 倍）に近くなっています。第11〜14案の 1.16 倍は、対照より小さくなっています。つまり、案22の誤差の形は実の前向きと後ろ向きの違いに近く、第11〜14案の誤差の形はそれより平らです。

## 6. 判断できること・まだ分からないこと

- 判断できること: 先に固定した読み方では、案22の誤差は境界の近くで大きくならず（0.87 倍）、外れたペアで大きくなります（1.46 倍）。しかし第11〜14案の誤差は、境界の近くで大きくならない点は同じですが（0.89 倍）、外れたペアで大きくなる点は弱くなっています（1.16 倍）。(a) と (c) は同じ形ですが、(b) の形が違います。そのため、接触の形成では誤差の形は生成方式によります。解離の3つの場合では両方式が同じ形だったのと違い、形成の接触では初めて形が分かれました。
- 判断できること: 全体の誤差の大きさは第11〜14案の方が小さく、生成の平均が実の平均についていく傾きも第14案の方が高くなっています（0.933 に対して 0.837）。第11〜14案の生成の平均は起点の距離とほぼ同じで、起点の距離と実の平均の相関が高いためです。
- まだ分からないこと: 対象は与えられる候補 4,968件に限られ、接触の形成全体（23,310件）ではありません。陽性は 67件（1.3%）と少なく、ラベルとの関係の数値は不確かです。また生成器は水素結合の形成のペアだけで学習したものを流用しており、学習範囲の外への当てはめである点は変わりません。
