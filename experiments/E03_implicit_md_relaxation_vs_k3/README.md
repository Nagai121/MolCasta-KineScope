# E03: 水なし 100 ps 陰溶媒 MD 緩和（OpenMM GBn2）による K3 の壁の突破と 1〜90 ns 指導力回収

- **確かめる仮説**: [E02](../E02_public_k3_and_replica_floor/README.md) で静的特徴量 5 系統すべてが崩せなかった局所平衡オフセット（sub-ns basin mean）の壁に対し、単一静的フレーム `10` のみを出発点とする**水分子なしの超短時間陰溶媒 MD 緩和**（`4 seeds × 100 ps`, OpenMM `amber14-all` + `implicit/gbn2`, 300 K）で、顕溶媒残差および下流 1〜90 ns の水素結合形成指導力をどこまで回収できるか。
- **状態**: 完了（2026-11-26）。
- **データ・軌道**: ATLAS 未見 25 タンパク質（`1a62_A`〜`7ead_A`, R1, `N = 13,687` HB 形成候補ペア）。全 25 タンパク質で初期座標一致を確認（`d0_err = 0.0000 Å`, `fail = 0`）。
- **計算コスト**: `NVIDIA GeForce RTX 4060 Ti`（OpenCL）で平均 **55.0 秒/タンパク質**（全 25 タンパク質合計 `1,374 秒`）。
- **評価条件**: 100% 公開 20 特徴量（`static20`）をベースラインとし、5-fold タンパク質群 CV で再学習評価。
- **コード・結果**: [run_e03_implicit_md.py](./run_e03_implicit_md.py) → [e03_results.json](./e03_results.json)

## 判断できることと、まだ分からないこと
- **確立**: 静的特徴量 5 系統が崩せなかった局所平衡オフセットの壁は、**明示的な水分子なしの `4×100 ps` 陰溶媒 MD 緩和（平均 55 秒/タンパク質）** によって明確に突破できる（残差 `r = +0.520`, `SD 0.6028 → 0.5133 Å`, 1〜90 ns 指導力回復率 `55.4–85.7%` [mean のみ] / 90 ns `115.6%` [7 統計量]）。4 seed の平均化により、単一レプリカ顕溶媒 MD の熱ノイズを抑え、5〜90 ns では残差とラベルの相関でも顕溶媒 1 ns MD に匹敵・凌駕する。
- **未解決**: 100 タンパク質全件および他現象（HB 解離・接触・塩橋）への拡張、および `10–25 ps` へのさらなる短縮と Δ-learning（陰溶媒→顕溶媒の機械学習補正）の上限検証。
