# G102: 塩橋の形成の混合で、切り取りを 6 個の統計量にした場合の、切り取りの長さを変えた場合も測る

## 仮説

G90 では、塩橋の形成の混合で切り取りを 0.1 ns の 6 個の統計量にした場合、5 ns先で第11・12・13案、30 ns先で 4 案すべてが +0.05 を超えました。ここでは切り取りを 0.25 ns に長くして、同じ測定をします。切り取りが長くなれば、切り取りだけの回復率は上がります（G66: 5 ns先で 0.299 から 0.756 へ、30 ns先で 0.491 から 0.684 へ）。その分、生成平均の足しは小さくなるかどうかを確かめます。

読み方は先に固定しました。混合の回復率から 0.25 ns の 6 統計量の切り取りだけの回復率を引いた差が +0.05 を超えるかどうかで見ます。土台の利得が小さいので、AUPRC の差の絶対値も記録します。

## データと条件

- 条件は K15 の広げた条件の塩橋の形成です。K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/`）と K15 の分割（学習58タンパク質 2,557件、テスト30タンパク質 1,170件）を使いました。テストの陽性数は 5 ns先 129件、30 ns先 133件です。
- 切り取りは 0.25 ns（フレーム [0,1,2]、実際には 0.2 ns を覆います）の 6 個の統計量（最初・平均・標準偏差・最小・最後と最初の差・4.0 Å 以下の割合）です。生成平均の出所は G19 の `gen/`（第11〜14案の生成系列、4分岐×9点）で、生成平均は G19 と同じ定義で 4分岐×9点の平均です。対応付けはファイルの並びそのままで、res_i・res_j が K15 キャッシュと一致することを確かめています（G19・G82・G90・G92 と同じ）。条件は静的特徴（5個）に、切り取りの 6 統計量・生成平均・その両方（7列）を足したものです。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件・予測幅ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 土台の検証：静的のみ・全部入りの AUPRC は両予測幅で K15 の記録と一致しました（5 ns先 0.2513 / 0.3301、30 ns先 0.1582 / 0.2466）。切り取り 0.25 ns の 6 統計量だけの回復率も G66 と一致しました（5 ns先 0.756、30 ns先 0.684）。

### 切り取り平均と生成平均の関係（テスト側）

第12案で、0.25 ns の切り取り平均と生成平均の相関は 0.587、生成平均と実の平均の相関は 0.732、生成平均と実の平均の差の標準偏差は 1.517 Å です。0.1 ns の切り取り（G19・G82・G90・G92）では、切り取り平均と生成平均の相関は 0.580、切り取り平均と実の平均の相関は 0.9035 でした。切り取りを 0.25 ns に長くすると、切り取り平均と実の平均の相関は 0.930 に上がります。生成平均との相関は 0.580 から 0.587 とほとんど変わりません。

## 結論

先に固定した読み方に沿うと、**切り取りを 0.25 ns に長くすると、混合の足しは 0.1 ns の切り取りより小さくなりました**。5 ns先では超えた案が 3 案から 1 案（第12案だけ）に、30 ns先では 4 案から 3 案（第11・12・14案）に減りました。切り取りだけの回復率は 0.1 ns から 0.25 ns に長くすると上がります（5 ns先 0.299 から 0.756 へ、30 ns先 0.491 から 0.684 へ）。切り取りが強くなった分、生成平均が足す余地は小さくなっています。

5 ns先では第13・14案がはっきり負になりました（−0.194、−0.249。AUPRC の差でも −0.0153、−0.0196）。切り取りが強いとき、生成平均は足しにならないどころか邪魔になる案もあります。30 ns先では第13案だけがわずかに負（−0.019、AUPRC の差 −0.0017）で、ほかは正です。

なお、G96 で 0.1 ns の切り取りの混合の差に区間を付けた結果、5 ns先の 3 案と 30 ns先の第11案の区間は 0 を含み、区間が 0 を含まなかったのは 30 ns先の第12・13・14案だけでした。0.25 ns の切り取りの混合については、区間はまだ付けていません。
