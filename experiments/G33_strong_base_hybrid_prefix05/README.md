# G33: 強い土台で、0.5 ns の切り取りに生成した平均を足すとどうなるか

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G21 では、強い土台（K06(b)、凍結した本体モデル＋補正モデル）で、0.1 ns の切り取り平均に生成平均を足すと、回復率が −0.083／−0.062 と逆に下がりました。弱い土台（G11、+0.186）とは正反対の結果でした。切り取りを 0.5 ns まで長くすれば、混合が戻るか確かめます。

読み方は実験前に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がれば、強い土台でも切り取りを長くすれば混合が足しになることになります。+0.05 未満なら、強い土台では切り取りを長くしても混合は足しにならないことになります。

## データと条件

- 条件は K06(b) の水素結合の形成、1 ns先です。G05・G21 と同じ段取りで、系列は G05 で作り直した11点系列（`~/workspace/kinescope/work/g05_series/`）、生成平均は K06(b) の保存データの生成6特徴量（`r{r}_gen6`、K06(b) の保存データ `~/workspace/k06b/run/k06b_out/`）のうち平均の列です。生成平均は第22案の生成5点系列（起点＋0.1／0.3／0.5／1.0 ns先）の平均です。検証として、生成平均と実の 0〜1 ns の平均の相関はテストで 0.786 で、K43 の記録と一致しました。
- 0.5 ns の切り取りはフレーム [0〜5]（6フレーム）で、平均はその6フレームの距離の平均です（G05 と同じ）。
- 土台は K06(b)／G05／G21 と同じです。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉15、葉あたり最小20件、L2 0.15、種 20261121）。較正8タンパク質で学習し、未見の100タンパク質×3レプリカ（163,074件、1 ns先の陽性 11,712件）で評価します。静的特徴は5個です。
- 条件: 静的のみ／履歴全部入り（参照）／実の平均だけ（参照）／切り取り平均だけ／生成平均だけ／混合（切り取り平均＋生成平均）。
- 回復率 =（条件の AUPRC − 静的のみ）÷（実履歴の利得）で、全体（pooled）とタンパク質ごとの平均（macro）の両方で測ります。実履歴の利得は全体 +0.0702、タンパク質ごとの平均 +0.0712 です。
- 注意: 生成系列は起点から先への前方系列で、切り取りは起点までの後方履歴の始めの部分です。平均は向きに依らない量なので、向きの違いは平均の定義に影響しません（G11・G21 と同じ留保）。
- 確認: 静的のみ 0.4591／0.4539、全部入り 0.5293／0.5251、切り取り平均だけ 0.5079／0.5027（回復率 0.695／0.686）で、K06(b) と G05 の記録と小数第4位まで一致しました。生成平均だけも、G21 の記録と小数第4位まで一致しました。

## 結果

| 条件 | AUPRC（全体） | AUPRC（macro） | 回復率（全体） | 回復率（macro） |
|---|---|---:|---:|---:|
| 静的のみ | 0.4591 | 0.4539 | — | — |
| 履歴全部入り | 0.5293 | 0.5251 | 1.000 | 1.000 |
| 実の平均だけ | 0.5275 | 0.5221 | 0.975 | 0.957 |
| 切り取り平均だけ（0.5 ns） | 0.5079 | 0.5027 | 0.695 | 0.686 |
| 生成平均だけ | 0.4568 | 0.4520 | −0.032 | −0.027 |
| 混合 | 0.5036 | 0.5008 | 0.635 | 0.659 |

混合 − 切り取り平均だけ: 全体 **−0.060**、タンパク質ごとの平均 **−0.027**。

切り取り平均と生成平均の関係（テスト、163,074件）: 相関 0.701、生成平均 − 切り取り平均は平均 −0.265 Å・標準偏差 0.803 Å。生成平均と実の 0〜1 ns の平均の相関は 0.786、切り取り平均と実の平均の相関は 0.977（0.1 ns では 0.908、G21）。

## 判断

先に固定した +0.05 の線で見ると、**強い土台では切り取りを長くしても混合は足しになりません**。混合の回復率は切り取り平均だけより、全体で −0.060、タンパク質ごとの平均で −0.027 と、どちらも下がりました。

0.1 ns の切り取り（G21）との違いは、下がり幅がやや小さくなったことです。G21 では全体 −0.083／タンパク質ごとの平均 −0.062 でしたが、G33 では全体 −0.060／タンパク質ごとの平均 −0.027 と、切り取りを長くすると逆効果は弱まります。ただし向きは変わらず、混合は足しにはなりません。切り取り平均と実の平均の相関も、0.1 ns の 0.908 から 0.5 ns の 0.977 へと上がり、生成平均が補う余地はさらに小さくなっています。G21 の読み取り（強い土台では生成平均は大半が静的情報から予測できる量で、補正モデルにとって新しい情報にならず、ばらつきと短いほうへの偏りが雑音として働く）と合う形です。

## 注意点

- 強い土台では実履歴の利得そのものが小さい（全体 +0.0702 に対して弱い土台は +0.1178）ため、回復率の分母が小さく、同じ AUPRC の差でも回復率は動きやすい点には注意が要ります（G05 と同じ留保）。混合と切り取り平均だけの AUPRC の差は、全体で −0.0043、タンパク質ごとの平均で −0.0019 です。
- 実行は約165秒かかりました（他のスレッドの計算と CPU を分け合っていたためと思われます）。
