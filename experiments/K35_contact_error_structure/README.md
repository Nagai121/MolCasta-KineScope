# K35 接触でも、生成の平均の誤差は情報のある候補で大きいか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）、H7（実軌道が持つ追加の観測情報）に関わる誤差の出方の切り分け
- 状態: 完了。接触でも、水素結合と同じ大まかな形でした。境界付近で誤差は大きくならず、実の平均が全体の平均から外れた候補で誤差が大きくなります。ただし外れでの増え方は水素結合より弱く、ラベルとの関係は水素結合より強いです。

## 1. 何を確かめる実験か

水素結合では、生成の平均の誤差は境界付近では大きくならず、実の平均が全体の平均から外れた候補で約2倍になりました（K30）。接触でも同じ形か確かめます。ラベルとの関係（K29 の (a) と同じ測定）も、接触の 1 ns先について測ります。

読み方は先に固定しました。接触でも同じ形（外れた候補で誤差が大きい）なら、誤差の出方は現象に共通です。接触で形が違えば、誤差の出方は現象ごとに違います。

## 2. 対象と定義

- 対象は K14 の接触の生成系列が作れた 4,968件（K13 の接触候補 23,310件のうち、代表原子ペアがドナー・アクセプターの組になる 21%）です。ドナー・アクセプターらしいペアに偏った部分集合なので、結果はこの部分集合についてのもので、接触全体に広げることはできません。
- 実の平均は、K13 のキャッシュにある 11フレームの最小距離系列（0〜1 ns）の平均です。接触の履歴の統計量でいう「平均」と同じ量です。生成の平均は、K14 の生成系列の5点（起点と +0.1／0.3／0.5／1.0 ns）の平均で、K30 の第22案と同じ約束です。弾性のみの系列も同じ約束で測りました。生成系列は代表ペア1組の距離で、最小値そのものではない点に注意してください。
- 突き合わせの確認: K14 の `min_all`（全候補の5点の最小値系列）の起点の列は、K13 のキャッシュの `hist` の最終フレーム（フレーム10）とタンパク質・複製の順序も含めて完全に一致しました（最大の差 0.0）。生成系列の各行は、5点の最小値系列そのものを鍵にしてキャッシュの行と突き合わせ、4,968行すべてが重なりなく対応しました（非有限の行は 0件で、落とした行はありません）。代表ペア系列の起点と生成系列の起点も一致しています（最大の差 1e-6 未満）。
- 分け方は K30 と同じ3通りです。(a) 起点の距離の帯: 境界 4.5 Å の付近（4.5〜5.5 Å）とそれ以外（5.5 Å 超）、細かく 0.5 Å 刻みでも測りました。(b) 実の平均の全体の平均（7.151 Å）からのずれの大きさ: 0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。(c) 残基間の隔たり: 隣り合う残基、2〜5、6〜10、11〜20、21以上。ただし接触の候補は隔たりが2以上と決まっているため、「隣り合う残基」の帯は 0件です。
- 各群で誤差の平均（全体のずれ）・標準偏差・平均絶対値を出し、実の平均の群内標準偏差も併記しました。
- 対照として、実の代表ペア系列と実の最小値系列（5点）の平均と実履歴の平均との差も同じ分け方で測りました。生成の平均の誤差のうち、どれだけが「代表ペアと最小値の量の違い」によるものかを見るためです。
- ラベルとの関係は 1 ns先について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測りました（K29 の (a) と同じ）。比較のため、生成の平均を実の平均の線形の式で当てはめたもの（生成の平均 = 0.932 + 0.837 × 実の平均、残差の標準偏差 0.365）から作る「縮み＋乱数」の合成の誤差も、3つの乱数 seed で測りました。

## 3. 結果

### 全体の誤差

| 系列 | 誤差の平均 (Å) | 誤差の標準偏差 (Å) | 平均絶対値 (Å) |
|---|---:|---:|---:|
| 第22案（生成） | −0.232 | 0.435 | 0.370 |
| 弾性のみ | −0.033 | 0.408 | 0.278 |
| 対照: 実の代表ペア系列 | +0.106 | 0.436 | 0.241 |
| 対照: 実の最小値系列（5点） | +0.009 | 0.325 | 0.190 |

水素結合（K30、第22案の全体のずれ −0.155、ばらつき 0.483）と比べると、接触の誤差のばらつきは同じ水準で、全体のずれはやや大きいです。対照として、実の代表ペアの平均でも実履歴の平均との差のばらつきは 0.436 と、生成の誤差とほぼ同じ大きさでした。つまり接触では、生成の平均の誤差の大きさのうちかなりの部分は、代表ペアと最小値の量の違いと、未来の5点と履歴の11点の違いで説明できてしまいます。ただし下の (b) の形は、対照には出ない生成側のものです。

| 4.5〜5.5 Å（境界付近） | 821 | −0.067 | 0.380 |
| 5.5 Å 超（それ以外） | 4,147 | −0.265 | 0.438 |

## 4. 読み取り

- **(a) 境界付近で誤差は大きくならず、水素結合と同じ形でした。** 境界付近の 0.380 Å に対してそれ以外は 0.438 Å と、むしろやや小さいです。細かい帯でも境界の側に山はありません。誤差の出方は、起点の距離の帯によらないものに近いです。
- **(b) 実の平均が外れた候補で誤差が大きくなる形も、水素結合と同じ向きでしたが、増え方は弱いです。** ずれ 0.25 未満の 0.332 Å に対して 1.0 以上は 0.486 Å で約1.5倍です。水素結合は 0.329 Å に対して 0.738 Å と約2.2倍でした。全体のずれも、水素結合では外れの帯で −0.312 Å と大きくなりましたが、接触では −0.250 Å とほぼ変わりません。生成の平均は全体の平均の側に縮む（当てはめの傾き 0.837）ため、平均が外れに位置するペアについていけていない、という形は共通ですが、接触ではその寄りが小さいです。弾性のみと対照の実の代表ペアでは外れの帯での増え方が出ないため、この (b) の形は生成器の学習した補正の側のものです。
- **(c) 隔たり 21以上の候補で誤差がやや大きくなる点も、水素結合と同じでした。** 2〜5 の 0.357 Å に対して 21以上は 0.518 Å で約1.5倍です。水素結合は 0.461 Å に対して 0.553 Å と約1.2倍でした。
- **ラベルとの関係は、水素結合（K29）より強いです。** 生成の誤差はラベルと相関 +0.170、陽性−陰性 +0.640 Å、AUC 0.850 で、縮み＋乱数の合成（相関 +0.089、AUC 0.713）より明らかに強いです。水素結合では生成の誤差のラベルとの関係は合成より弱かった（相関 +0.09〜+0.10 対 +0.18〜+0.20、AUC 0.62〜0.65 対 0.71〜0.74）のと逆です。対照の実の代表ペアの誤差にはラベルとの関係がない（相関 −0.014、AUC 0.475）ため、この関係は代表ペアと最小値の量の違いによるものではなく、生成側のものです。ただし陽性が 67件と少なく、AUC の揺れは大きいです。生成の平均そのものはラベルの信号を実の平均とほぼ同じだけ持っており（相関 −0.156 対 −0.187）、誤差がラベルに関わるのは、生成の平均が実の平均の縮み方と、残差の側のラベルとの関わりが合わさったものです。
- 先に固定した読み方に照らすと、**(a)(b)(c) の3つの分け方すべてで、誤差の出方は水素結合と同じ大まかな形**でした。境界付近で大きくならず、外れた候補と遠い残基ペアで大きくなる、という形は現象に共通です。ただし (b) の外れでの増え方は接触のほうが弱く、ラベルとの関係は接触のほうが強い、という量の違いがあります。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触でも、生成の平均の誤差は境界付近で特に大きくならず、実の平均が外れた候補と隔たりの大きい残基ペアで大きくなります。誤差の出方の大まかな形は水素結合と共通です。
- まだ分からないこと: (b) の増え方が水素結合より弱い理由と、ラベルとの関係が水素結合より強い理由。接触の候補の実の平均のばらつきが水素結合より大きいこと（標準偏差 1.453 Å）と、陽性が 67件と少ないことが、量の違いにどう関わるかは、この実験だけでは分かりません。また、対象がドナー・アクセプターらしい 21% の部分集合であるため、接触全体でも同じ形かは分かりません。
