# K37: 生成の特徴量で学習した補正モデルは、実の履歴に通用するか（強い土台、水素結合）

## 仮説

H5（特徴量の抽出と読み出し）に関わる検証です。K12b では実で学習したモデルを生成の特徴量で試し、K34 では生成で学習して生成で試しました。残る組み合わせは、生成で学習したモデルを実の履歴で試すことです。生成の特徴量が学習データとして使えるかを確かめます。

読み方は実験前に固定しました。生成で学習したモデルが実の履歴で利得の大半を出せれば、生成の特徴量は学習データとして使えます。利得が出なければ、生成の特徴量は学習データとしても使えません。

## データと条件

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的補正との AUPRC の差で、全体をまとめた値とタンパク質ごとの平均の両方を見ます。
- 学習と評価のタンパク質が重ならないことを確認しました（較正8と評価100、共通 0件）。
- 主条件は、生成の特徴量（8特徴）で学習し、実の履歴の特徴量で評価するものです。生成8特徴は実履歴10特徴と形が違うため直接当てられません（K34 でも同じ指摘があります）。そこで実の側は、K22 で取り直した実の11フレーム系列から、生成8特徴の要約と同じ定義で8特徴を作りました。変化量を「系列の距離 − 起点の距離」とし、[変化量の平均、標準偏差、最小値、最大値、3.5 Å 以下だった割合、4.0 Å 以下だった割合、最後のフレームの変化量、距離が減ったステップの割合] です。作り方の確認として、この8特徴のうち 3.5 Å 以下割合は実履歴10特徴の同じ列と完全に一致しました（差 0.0）。
- 副条件として、6統計量の形での交差（生成6で学習し、実履歴の6列で評価。K12b の (d) の再検証）も測りました。対照として、実履歴の6列で学習し実履歴の6列で評価する条件も測りました。
- 対照の確認: 生成8特徴で学習して生成8特徴で評価する条件は、K06(b) の記録と全予測幅で完全に一致しました（AUPRC の差 0.0）。6統計量の交差条件も、K12b の記録と 1 ns先で完全に一致しました（AUPRC 0.4115）。

## 判断

先に固定した読み方に照らすと、答えは「生成の特徴量は学習データとしても使えません」です。生成で学習したモデルを実の履歴に当てると、利得が出ないどころか、全予測幅で静的補正を下回ります。1 ns先では AUPRC が 0.3931 と、凍結した本体だけの 0.4929 すら下回ります。6統計量の形でも同じで、10 ns先のわずかなプラス（+0.0025）を除いて全てマイナスです。

さらに、生成で学習したモデルは、実の履歴に当てたほうが生成の特徴量に当てるより悪くなります（1 ns先で 0.3931 対 0.4517、90 ns先で 0.4103 対 0.4399）。生成の特徴量の分布（変動が小さく、値の範囲が狭い）で学習した分け方が、実の値の範囲では外れてしまう、という読み出しの不一致が逆向きにも出ています。

対照の実の6列で学習→実の6列で評価は、実履歴の利得のほぼ全部を保ちました（回復率 0.97〜1.16）。6統計量という読み出しの形そのものは問題ではなく、生成の特徴量の側に情報が無い、という K34 の結論と整合します。

強い土台での4通りの組み合わせは、これで全部そろいました。実で学習→実で評価は利得 +0.0712（1 ns先）、生成で学習→生成で評価は −0.0074、実で学習→生成で評価は −0.0587（K12b の (b)）、生成で学習→実で評価は −0.0660（本実験）です。読み出しの不一致は両向きにあり、どちら向きでも静的補正を下回ります。
