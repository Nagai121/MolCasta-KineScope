# K46: 解離でも、実履歴に指導力があり、担い手は平均か（資料Dの条件、水素結合の解離）

- 確かめる仮説: H5（特徴量の抽出と読み出しの問題）に関わる担い手の特定
- 状態: 完了。解離でも指導力があり、平均だけで利得の 0.84〜1.30 が戻りました。先に固定した目安（8割）を全予測幅で超えたので、担い手の形は形成と共通です。

## 1. 何を確かめる実験か

これまでの担い手の切り分け（K21・K27・K31）はすべて形成の側でした。解離の側でも実履歴に指導力があるか、担い手は同じかを確かめます。

読み方は先に固定しました。解離でも指導力があり、平均だけで利得の8割以上が戻れば、担い手の形は形成と共通です。指導力が無い、または平均だけでは戻らなければ、解離は形成と違います。「8割以上」は全幅または多くの幅での読みとし、1 ns先を主判断とします。

## 2. 解離の定義（結果を見る前に固定）

形成の対になる形です。資料Dのコード（`fixed_1ns_history_3phen_6h.py`）で確認した形成の候補規則は、起点（フレーム10、1 ns）でドナー・アクセプター原子間距離が 3.5 Å 超〜6.0 Å 以下で、ドナー残基とアクセプター残基が異なること、ラベルは予測先で 3.5 Å 以下になることです。解離はその鏡像です。

- 候補: 形成と同じドナー・アクセプターの規則（`atom_layout` と同じ。ドナー N/O、アクセプター O、Pro の骨格窒素はドナーから除外）で、起点フレーム10の距離が 3.5 Å 以下（水素結合ができている状態）で、ドナー残基とアクセプター残基が異なるペア。形成の候補（起点で 3.5 Å 超）とは重なりません。起点の距離の範囲は、学習側 2.06〜3.50 Å、テスト側 2.12〜3.50 Å でした。
- ラベル: 予測先のフレームで距離が 3.5 Å を超えること（解離した）を 1 とします。
- 静的特徴は形成と同じ7個（起点距離、Cα間距離、配列距離の log1p、ドナー主鎖か、アクセプター主鎖か、ドナー酸素系か、アクセプター側鎖酸素か）です。
- 履歴の6統計量も形成と同じ定義（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下だった割合）です。ただし解離では起点で 3.5 Å 以下の候補だけなので、3.5 Å以下割合の分布は形成と違います。テスト側では平均 0.878、中央値 1.000、全体の 65.9% が11フレームすべて 3.5 Å 以下でした（学習側も平均 0.882、中央値 1.000、68.7% がすべて以下）。つまりこの統計量は解離ではほとんど変化がなく、情報は主に他の統計量にあります。
- 候補数: 学習 4,051件（1bgf_A 1,008、1ifg_A 763、1j8r_A 1,137、2b0a_A 1,143）、テスト 2,080件（1mix_A 1,415、2qt4_A 665）で、合計 6,131件です。形成（学習 9,610件、テスト 4,972件）より少ないのは、起点で結んでいるペアの数が、結んでいないが届く範囲にあるペアの数より少ないためです。
- テストの陽性数（解離した件数）: 1 ns先 311件（陽性率 15.0%）、5 ns先 352件（16.9%）、10 ns先 368件（17.7%）、30 ns先 368件（17.7%）、50 ns先 362件（17.4%）、90 ns先 413件（19.9%）。形成の陽性率（テストで 5.8〜6.9%）より高く、陽性数も多いため、解離の利得は形成より読みやすい条件です。

## 3. 条件

- 土台は資料Dの条件です。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算、起点フレーム10、履歴 0〜1 ns の11フレーム、予測幅 1/5/10/30/50/90 ns、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- 条件は3つです（分け方は K21/K27 と同じ）。
  - 静的のみ: 静的7特徴だけ
  - 全部入り: 静的＋実履歴6統計量
  - 平均だけ: 静的＋履歴6統計量のうち平均1つだけ（他の統計量は入れない）
- 対照の確認: 形成の土台を同じコードで再計算し、静的のみと全部入りが全予測幅・全指標で形成の記録と小数第4位まで一致しました（1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815）。形成の平均だけの条件も併せて測ったところ、1 ns先で AUPRC 0.4865 と全部入りをわずかに上回りました（参考値として結果ファイルにあります）。

## 5. 読み取り

- **解離でも指導力ははっきりあります。** 利得は 1 ns先 +0.1785、5 ns先 +0.1757、10 ns先 +0.1478、30 ns先 +0.1322、50 ns先 +0.1142、90 ns先 +0.0679 で、全予測幅で正です。形成の利得（+0.0625〜+0.1211）より短い予測幅では大きく、長い予測幅では小さくなります。
- **平均だけで、利得の 0.84〜1.30 が戻りました。** 先に固定した目安の8割を全予測幅で超えています。1 ns先 0.858、5 ns先 0.993、10 ns先 0.973、30 ns先 0.887、50 ns先 0.838、90 ns先 1.304 です。90 ns先で1を超えているのは、利得そのものが最も小さい（+0.0679）幅で平均だけの方が全部入りを上回ったためで、比率が振れやすい幅です。単一の学習 seed の結果でもあります。
- 形成の側でも、資料Dの条件で平均だけを測ると 1 ns先で全部入りを上回り（0.4865 対 0.4815）、K21 の強い土台での「平均だけで 0.87〜1.08」と同じ形でした。解離と形成の両方で、平均が担い手という形は土台の強さによらず成り立ちます。

## 6. 判断できること・まだ分からないこと

- 判断できること: 解離でも実履歴に指導力があり、担い手はペアの平均距離という1つの量でほぼ担えます。事前に固定した読み方に沿うと、担い手の形は形成と共通です。接触（K27、平均だけでは 0.65〜0.71）や塩橋（K31、幅ごとに振れる）とは違い、解離は水素結合形成と同じく平均が担い手です。
- まだ分からないこと: 平均以外の統計量が単独でどれだけ戻るか（最小値だけ・割合だけ・形だけ）は測っていません。解離では 3.5 Å以下割合がほとんど変化しないため、割合だけの戻り方は形成より小さいはずですが、未測定です。また、90 ns先の戻り方 1.304 が本当に平均の方が良いのか、単一 seed の揺れなのかも、この実験だけでは分かりません。
