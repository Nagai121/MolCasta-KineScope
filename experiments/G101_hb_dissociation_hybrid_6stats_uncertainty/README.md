# G101: 水素結合の解離の混合で、切り取りを 6 個の統計量にした場合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G95・G97 では、切り取り 0.1 ns の 6 個の統計量に生成平均を足した混合の差が +0.05 を超えたのは、1 ns先の第11案 +0.059・第12案 +0.071・第14案 +0.087、30 ns先の第13案 +0.072・第14案 +0.060、10 ns先の第13案 +0.082、50 ns先の第12案 +0.086、90 ns先の第11案 +0.135・第22案 +0.102 の9セルでした。1・5・10・30・50・90 ns先 × 第11〜14案と第22案について、混合と切り取り 6統計量だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G59・G62・G67 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（1 ns先の第11・12・14案、30 ns先の第13・14案、10 ns先の第13案、50 ns先の第12案、90 ns先の第11案と第22案）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの水素結合の解離です。G95・G97 と同じ段取りで、実側は K46 キャッシュ（`~/workspace/kinescope/work/data_cache_k46/`、候補は起点距離 3.5 Å 以下のドナー・アクセプター原子ペア、ラベルは予測幅で 3.5 Å より大きい）と、生成平均は第11〜14案が K54 の残基レベル生成系列（`~/workspace/kinescope/work/k54_gen_residue/`、4分岐×9点の平均）、第22案が G18 で作り直した生成系列（`~/workspace/kinescope/work/g18_gen22/`、5点系列の平均）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（4,051件）、テスト 1mix_A＋2qt4_A（2,080件、うち 1mix_A 1,415件・2qt4_A 665件）。静的特徴は7個、履歴はドナー・アクセプター距離の系列の6統計量（3.5 Å 以下だった割合）です。対応付けは、K54 のファイルの並びそのままで、donor_atom・acceptor_atom が K46 キャッシュと一致することを確かめました。第22案は (軌道ID, ドナー原子, アクセプター原子) のキーで対応付けました。生成器のチェックポイントは読み込んでいません。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）の 6 個の統計量です（G95・G97 と同じ）。6統計量は [最初のフレーム、平均、標準偏差、最小、最後−最初、3.5 Å 以下だった割合] で、2フレームの系列から計算します。生成平均は、生成系列の平均です。なお、切り取りの平均だけの回復率も照合のために測り直しました（1 ns先 0.5109、5 ns先 0.5520、10 ns先 0.5313、30 ns先 0.5184、50 ns先 0.4731、90 ns先 0.5599、G18・G44・G50・G54 の記録と一致しました）。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り 6統計量だけ、生成平均だけ（第11〜14案と第22案）、混合（切り取り 6統計量＋生成平均、別々の特徴量として 7列。第11〜14案と第22案）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り 6統計量だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G95・G97 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。
- 第22案についての留保（G95・G97 と同じ）: 第22案は生成器が学習した範囲（形成の候補だけ）の外への当てはめです。解離の候補に対する生成平均として使うのは、生成器の学習範囲の外への当てはめになります。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G23・G49・G59・G62・G67 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（1,415件）と 2qt4_A（665件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り 6統計量だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G95・G97 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。学習し直した予測確率は、ブートストラップの前に `test_predictions.npz` に先に保存しておきました（実行が途中で止まっても学習し直しからやり直さずに済むようにするため）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。
- 90 ns先は土台の利得が小さい（+0.0679）ため、回復率の差だけでは読みを誤ります。90 ns先については、混合と切り取り 6統計量だけの AUPRC の差の絶対値も記録します（点推定、タンパク質ごとの値、ブートストラップ 95% 区間）。AUPRC の差の区間は、全予測幅について同じやり方で出しました。

## 判断

先に固定した読み方に沿うと、+0.05 を超えた9セルのうち、**区間が 0 を含まないのは7セル**で、**0 を含むのは 50 ns先の第12案と 90 ns先の第22案の2セル**です。

- 1 ns の第11案 [+0.003, +0.127]、第12案 [+0.071, +0.090]、第14案 [+0.005, +0.191] は、いずれも 0 を含みません。2タンパク質とも差が正です。ただし第11案の区間の下限 +0.003 は 0 に近く、1mix_A だけの差も +0.003 とほぼ 0 です。第14案も下限 +0.005 は 0 に近く、2qt4_A だけの差も +0.005 とほぼ 0 です。
- 30 ns の第13案 [+0.004, +0.134]、第14案 [+0.028, +0.068] は、いずれも 0 を含みません。2タンパク質とも差が正です。ただし第13案の区間の下限 +0.004 は 0 に近く、1mix_A だけの差も +0.004 とほぼ 0 です。
- 10 ns の第13案 [+0.012, +0.120] は 0 を含みません。2タンパク質とも差が正です（1mix_A で +0.120、2qt4_A で +0.012）。
- 90 ns の第11案 [+0.032, +0.528] は 0 を含みません。2タンパク質とも差が正です（1mix_A で +0.528、2qt4_A で +0.032）。ただし上の通り、1mix_A だけの実履歴の利得が +0.0196 と極端に小さいために回復率の差が大きく出ており、AUPRC の差で見ると +0.0092 と小さいものです。
- 50 ns の第12案の区間 [−0.026, +0.168] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で +0.168、2qt4_A で −0.026）。AUPRC の差の区間 [−0.0037, +0.0153] も 0 を含みます。
- 90 ns の第22案の区間 [−0.082, +0.185] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で −0.082、2qt4_A で +0.185）。AUPRC の差の区間 [−0.0016, +0.0217] も 0 を含みます。

+0.05 を超えなかったセルでは、30 ns先は 5 案すべてが区間も 0 を含みません（第11案 [+0.032, +0.092] は正、第12案 [−0.076, −0.026] と第22案 [−0.113, −0.013] は負）。90 ns先の第13案 [−0.474, −0.020] と第14案 [−0.497, −0.067] は区間も 0 を含まず負です。10 ns先の第12案 [−0.096, −0.024] も区間も 0 を含まず負です。50 ns先の第14案 [−0.115, −0.091] も区間も 0 を含まず負です。5 ns先は 5 案すべてが区間も 0 を含みます。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・案ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- **90 ns先は土台の利得が小さい（+0.0679）ため、回復率の差は大きく出やすいです。** 1mix_A だけの実履歴の利得は +0.0196 と極端に小さく、1mix_A だけの回復率の差は +0.528 と大きく出ています。90 ns先の読みは、AUPRC の差の絶対値（第11案 +0.0092、第22案 +0.0069）と併せて見るべきです。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約11分でした。
