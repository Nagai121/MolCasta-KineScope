# L72: L01 の曲がりを塩橋の解離で測る（統計量6種、K15 の土台、30 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。L36（平均だけ）と同じ土台・同じ覆う長さで、履歴の特徴量を切り取りの統計量6種に変えた曲がりです。塩橋の統計量6種の担当分（解離 L69〜L74）の 30 ns先です。
- 状態: 完了。平均だけの L36 と同じく、分母の利得が小さく（全体 +0.0633、平均 +0.0156）、回復率の比率は正確には読めません。点推定では統計量6種の条件も全長さで全部入り以上でした。必要な長さの読みは両形とも 0 ns で、縮みは 0 でした。

## 1. 何を確かめる実験か

L69 と同じ段取りで、予測幅だけを 30 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み）で切り取りの統計量6種（最初・平均・標準偏差・最小・最後−最初・4.0 Å以下割合）を入れたときの回復率を測り、先に固定した読み方で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法）。区間は統計量6種の曲がりについて計算します。
4. 段の前後ではタンパク質ごとの値も記録する。
5. あわせて、同じ実行で測り直した平均だけの曲がりと比べて、必要な長さが縮んだかどうかを記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、30 ns先の陽性 149件。
- 条件は静的のみ、全部入り（静的＋履歴6統計量）、切り取りの統計量6種 11通り、照合用の平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

### 先に固定した読み方への答え（機械的な適用の結果を含む）

1. 回復率 0.8 と 0.9 に届く最小の長さ: どちらも覆う長さ 0 ns（全体 1.108）。平均だけも 0 ns で、縮みは 0 でした。
2. 増え幅がいちばん大きい場所: 全体では 0.2→0.3 ns（+0.597）。段の位置でのタンパク質ごとの増え分は中央値 +0.158、正だったのは 15タンパク質のうち 53% で、段とは読めません。
3. 長さごとの回復率の差（6種 − 平均、全体）は長さによって正負が入れ替わり（−0.510〜+0.483）、一様な優劣はありません。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 15タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- L36 と同じく、比率の区間は非常に広く（全体の上限 +6.0〜+13.8）、「どれだけ上回るか」は決められません。確かなのは AUPRC の水準として、統計量6種の条件（全体 0.543〜0.596）が全部入り（0.5432）と同等以上であることまでで、平均だけの条件（全体 0.543〜0.595）と同じ範囲です。
- 平均の利得（+0.0156）が特に小さいため、平均の回復率は読みの対象にできません。
