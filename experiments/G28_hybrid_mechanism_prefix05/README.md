# G28: 0.5 ns の切り取りでの混合の仕組みは、0.1 ns のときと同じか（資料Dの条件、水素結合の形成、1 ns先）

- 確かめること: G15 では 0.1 ns の切り取りで、単純な平均では回復率 0.435、差では 0.348 と弱く、2 つの推定値を別々の特徴量として入れたときだけ 0.756 になった。G24 では 0.5 ns の切り取りで混合が 1.015 まで上がった。0.5 ns でも同じ仕組みか。
- 状態: 進行中。

## 1. 何を確かめる実験か

条件は資料Dの水素結合の形成、1 ns先。0.5 ns の切り取り平均と第22案の生成平均について、単純な平均を 1 つの特徴量として入れた条件と、差（生成平均 − 切り取り平均）を 1 つの特徴量として入れた条件を測る。

読み方は先に固定した。単純な平均か差のどちらかが混合と同程度（差が 0.05 以内）なら、0.5 ns の切り取りでは混合の仕組みが変わったことになる。どちらも混合より 0.05 以上下回れば、仕組みは 0.1 ns のときと同じで、2 つの推定値を別々に入れるところが効いていることになる。
