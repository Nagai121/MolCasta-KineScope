# K28: 生成の平均の誤差を、縮みと乱数の組み合わせで再現できるか（強い土台、水素結合）

## 仮説

H6（運動の生成そのものの問題）に関わる検証です。K22 では独立な乱数だけ（利得は実履歴の 0.43〜0.64 が残る）、K24 では縮みだけ（利得はほぼ残る）と、どちらも単独では生成条件の水準までは落ちませんでした。ただ、生成の平均は「縮めた実の平均 ＋ 独立な乱数」でできている可能性があります。平均の誤差を、その組み合わせとして実系列に当てはめて、生成の水準まで落ちるか確かめます。

読み方は実験前に固定しました。組み合わせた実履歴の利得が生成条件の水準まで落ちれば、生成の失敗は「平均の誤差の構造（縮み ＋ 乱数）」で説明できます。利得が上に残れば、生成の平均の誤差は、線形の縮み ＋ 独立な乱数では表せない、候補の状態や未来と関わった出方をしています。

## あてはめ（生成の平均の回帰）

K05／K08 と同じ候補（資料D、候補 14,582件）で、同じ定義の平均を使いました。生成の平均は第22案の5点系列の平均、実の平均は実履歴11フレームの平均です。

生成の平均 = a ＋ b × 実の平均 ＋ 残差、という線形の式で当てはめた結果は次のとおりです。

| 対象 | 件数 | a | b（回帰の傾き） | 残差の標準偏差 |
|---|---:|---:|---:|---:|
| 学習側 | 9,610 | 1.3977 | 0.6926 | 0.4055 |
| テスト側 | 4,972 | 1.3507 | 0.7069 | 0.3968 |
| 全体 | 14,582 | 1.3829 | 0.6972 | 0.4028 |

b は K24 で測った回帰の傾き（0.697）と一致します。残差の平均は 0 です。この式で作り直した生成の平均は、実際の生成の平均と、平均・ばらつき・実の平均との相関が一致するように作られています。なお、この式から出る生成の平均 − 実の平均の平均は −0.155 Å で、K08 の測定とも一致します。

## 方法（組み合わせの再現）

- K06(b) の条件です。凍結した本体 T1I2006 に補正モデル（HistGradientBoosting、反復160回、学習率0.065、葉15、min_samples_leaf 20、L2 0.15、seed 20261121）を付け、較正用の8タンパク質（候補 13,808件）で学習し、未見の100タンパク質×3レプリカ（候補 163,074件）で評価します。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。実系列は K22 で再抽出したもの（K06(b) の保存した統計量と全タンパク質で完全に一致することを確認済み）を使います。
- 加工の方法: 候補ごとに実系列全体を平行移動して、平均が「a ＋ b × 実の平均 ＋ 独立な乱数（標準偏差 0.4028）」になるようにします。乱数は候補ごとに独立に引き、学習側とテスト側の両方に当てます。乱数の種は3通り（101、202、303）です。平行移動なので系列の形は変わりません。補正モデルは条件ごとに学習し直します。実際に当たった平行移動は、平均 −0.170〜−0.173 Å（学習側）、−0.162〜−0.165 Å（テスト側）、標準偏差 約0.50 Å で、狙った大きさと一致しました。
- 参照: 静的補正、全部入りの実履歴、生成6特徴・生成8特徴は K06(b) の結果から引用し、K22（独立な乱数だけ）と K24（縮みだけ）の結果も並べます。

## 判断

先に固定した読み方に照らすと、答えは「縮み＋乱数でも説明できない」です。組み合わせた実履歴の利得は、全予測幅で生成条件よりずっと上に残りました（最も差が小さい 90 ns先でも +0.0149 対 約 −0.001〜−0.002）。生成の平均の誤差は、線形の縮み ＋ 独立な乱数では表せない出方をしています。

もう1つ、K22 との比較が示すことがあります。縮み＋乱数の利得は、乱数だけの K22（+0.0451、+0.0279、+0.0205、+0.0234、+0.0154、+0.0151）と全予測幅でほぼ同じです。縮みの成分を足しても、利得はほとんど変わりません。ダメージを出しているのは残差の乱数の側で、縮みの側は K24 でも本実験でもほぼ無害でした。

平均という1つの統計量については、ここまでで次のことが言えます。生成の平均は、実の平均との関係を平均・ばらつき・相関まで合わせた線形の式と独立な乱数で作り直しても、その失敗は再現できません。残る説明は、平均以外の統計量の誤差（生成系列の変動の大きさは実系列よりずっと小さいことが K05 と K11 で分かっています。今回の加工は平行移動なので、系列の形は実のまま残っています）か、残差が候補の状態や未来と関わって出る形か、その両方です。平均だけをいくら合わせても、生成の失敗には届かない、というのが現時点での結論です。
