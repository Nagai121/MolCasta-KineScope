# G12: 強い土台で、0.1 ns の切り取りの 6 統計量は平均だけよりどれだけ戻るか（K06(b) の条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、短い実MDの経路の続き。G05 では 0.1 ns の切り取りの平均だけの回復率が全体 0.545、タンパク質ごとの平均 0.553 だった。同じ切り取りの 6 統計量を全部使えば、さらに戻るか。
- 状態: 完了。0.1 ns の 6 統計量の回復率は全体 0.446、タンパク質ごとの平均 0.468 と、平均だけ（0.545 / 0.553）より悪かった。先に固定した6割の線にも届かず、強い土台では 0.1 ns の切り取りは平均だけで十分。ただし 0.5 ns の 6 統計量は平均だけより良かった（0.768 / 0.751 に対して 0.695 / 0.686）。

## 1. 何を確かめる実験か

G05 で作り直した 11点系列（`~/workspace/kinescope/work/g05_series/`）を使い、0.1 ns の切り取り（フレーム 0, 1）の 6 統計量を補正モデルに入れ、1 ns先の利得の回復率を測る。0.5 ns の切り取り（フレーム 0〜5）の 6 統計量も測る。参照は実履歴の利得で、全体（pooled）+0.0702、タンパク質ごとの平均（macro）+0.0712。回復率は両方で測る。

6 統計量の定義は G02 の prefix_hist6 と同じ（資料Dの D6 と同じ）: [最初、平均、標準偏差、最小、最後−最初、3.5 Å以下割合] を切り取りのフレームで計算する。

判定は先に固定した。0.1 ns の 6 統計量で回復率 6 割以上なら、強い土台でも統計量を全部使う価値がある。6 割未満なら、強い土台では平均だけで十分ということになる。

## 2. 条件

- 土台は K06(b) と同じ。凍結した本体モデル T1I2006＋補正モデル HistGradientBoosting（160回、学習率 0.065、葉 15、葉あたり最小 20件、L2 0.15、種 20261121）。較正タンパク質 8つで学習し、未見の100タンパク質×3レプリカ（163,074行、1 ns先の陽性 11,712件）で評価する。静的特徴は5個。履歴の要約値は10個。
- 起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、ラベルは 1 ns先。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴5個だけ。
- 全部入り（full_history）: 静的特徴＋実履歴の要約値10個。参照条件。
- 平均だけ（mean_only_full）: 静的特徴＋0〜1 ns の平均だけ。参照条件。
- 切った平均だけ（prefix_mean_0.1/0.5ns）: 静的特徴＋切った履歴の平均だけ。G05 の再現。
- 切った6統計量（prefix_hist6_0.1/0.5ns）: 静的特徴＋切った履歴の6統計量。今回の条件。

## 3. 結果

### 土台と G05 の再現

1 ns先で静的のみ AUPRC は全体 0.4591、タンパク質ごとの平均 0.4539。全部入りは全体 0.5293、タンパク質ごとの平均 0.5251。利得は全体 +0.0702、タンパク質ごとの平均 +0.0712 で、k06b_results.json の記録と小数第4位まで完全一致した。平均だけの条件も G05 と完全一致した（0.1 ns の平均だけは全体 0.4974、タンパク質ごとの平均 0.4933。0.5 ns の平均だけは全体 0.5079、タンパク質ごとの平均 0.5027）。

### 1 ns先の利得の回復率

| 条件 | AUPRC（全体） | AUPRC（タンパク質ごとの平均） | 回復率（全体） | 回復率（タンパク質ごとの平均） |
|---|---:|---:|---:|---:|
| 0.1 ns の平均だけ | 0.4974 | 0.4933 | 0.545 | 0.553 |
| 0.1 ns の6統計量 | 0.4904 | 0.4872 | 0.446 | 0.468 |
| 0.5 ns の平均だけ | 0.5079 | 0.5027 | 0.695 | 0.686 |
| 0.5 ns の6統計量 | 0.5130 | 0.5074 | 0.768 | 0.751 |

静的のみは AUPRC 全体 0.4591、タンパク質ごとの平均 0.4539。

## 4. 読み取り

- **0.1 ns の 6 統計量の回復率は全体 0.446、タンパク質ごとの平均 0.468 と、先に固定した6割の線に届かなかった。** 読み方に沿うと、強い土台では 0.1 ns の切り取りは平均だけで十分で、統計量を全部使う価値はない。むしろ平均だけ（0.545 / 0.553）より悪くなった。
- 0.1 ns の切り取りはフレーム 2つだけなので、6統計量のうち平均以外はほとんど情報を持たない。標準偏差は2つのフレームの差の半分、最小は2つのうち小さいほう、最後−最初はフレーム間の差そのもの、3.5 Å以下割合は 0 / 0.5 / 1 の3通りしかない。平均とほぼ同じ内容の量を5つ足しただけになり、補正モデルが較正タンパク質のノイズに引っ張られて悪化した、という見立てが自然。確かめの計算はしていない。
- 0.5 ns の切り取り（フレーム 6つ）では、6統計量は平均だけより良かった（全体 0.768 に対して 0.695、タンパク質ごとの平均 0.751 に対して 0.686）。フレームが6つあれば、標準偏差や最小、3.5 Å以下割合が平均とは別の情報を持ち、補正モデルが使える。切り取りの長さで、統計量を足す意味が変わる。
- 弱い土台（G02）との違いもある。G02 では 0.1 ns の 6 統計量は 0.583 と、平均だけの 0.570 よりわずかに良かった。強い土台では 0.446 と平均だけより明らかに悪い。凍結した本体モデルがすでに平均以外の情報の一部を持っているため、短い切り取りの統計量は強い土台では上乗せにならず、ノイズだけが残る、という見立てもできる。確かめの計算はしていない。
- 0.5 ns の 6 統計量の回復率（0.768 / 0.751）は、0〜1 ns の平均だけ（0.975 / 0.957）にはまだ届かない。短い切り取りで 6 統計量を使っても、0〜1 ns の平均には及ばない。

## 5. 判断できること・まだ分からないこと

- 判断できること: 強い土台では、0.1 ns の切り取りは平均だけで十分で、6統計量を足すとむしろ悪くなる。0.5 ns の切り取りでは 6統計量を足すと回復率が 0.695 / 0.686 から 0.768 / 0.751 に上がる。
- まだ分からないこと: 0.1 ns の 6統計量が悪化した理由は、上の見立てのままで、確かめの計算はしていない（たとえば平均以外の統計量を1つずつ足す、較正タンパク質を変える、など）。0.25 ns の切り取りで 6統計量がどうなるかも測っていない。
