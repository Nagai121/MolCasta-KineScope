# K2-46: K2-09 の問い（水素結合の解離の前半と後半、平均だけ）を 50 ns先で測る

- 確かめること: 水素結合の解離の前半と後半の平均の利得を、50 ns先で測る。1・5・10・30 ns先は測り終えた。50 ns先で前半と後半の形がどうなるかを見る。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-09 では、水素結合の解離の 1 ns先で、前半（フレーム [0..4]）の平均だけの利得は全部入りの 0.541、後半（フレーム [6..10]）だけでは 0.828 だった。先に固定した読み方のどちらにも当てはまらなかった。5 ns先（K2-31）では前半 0.822・後半 0.967 と、前半も後半も 8 割以上で「続いている状態」に当てはまった。10 ns先（K2-36）では前半 0.923・後半 0.750 と、前半のほうが大きく、30 ns先（K2-25 の照合用）では前半 0.749・後半 0.684 だった。ここでは、同じ問いを 50 ns先で測る。1・5・10・30 ns先は測り終えた。50 ns先で前半と後半の形がどうなるかを見る。

比べる条件は K2-09 と同じく先に固定した。静的な特徴量に、つぎのどれか 1 つを足した形で比べる：前半（フレーム [0..4]）の平均、後半（フレーム [6..10]）の平均、前半と後半の両方、全部（フレーム [0..10]）の平均。土台の再現は水素結合の解離の 50 ns先の記録（K46）と照らす。

読み方は K2-01 と同じく先に固定した。後半の利得が全部入りの 8 割以上で前半が 5 割以下なら「今の状態が効いている」、前半も後半も 8 割以上なら「続いている状態が効いている」、どちらでもなければ数値をそのまま記録する。
