# G60: 塩橋の形成で、長い予測幅でも短い切り取りで指導力が戻るか

## 仮説

H6（運動の生成そのものの問題）に関わる、短い実MDの経路の広がりの確認です。G03 では塩橋の形成（K15 の広げた条件）で 0.1 ns の切り取りの平均だけが 1 ns先の利得の 0.647 を戻しましたが、長い予測幅での形は空白でした。G27・G43 は 1 ns先で切り取りを長くしたときの形を見たもので、長い予測幅はまだ測っていません。ここでは予測幅 5・10・30・50・90 ns で、切り取り 0.1・0.25・0.5 ns の平均だけの回復率を測ります。

読み方は実験前に固定しました。各予測幅で、回復率 0.5 を超える最小の切り取りを出します。3つの切り取りのどれでも 0.5 を超えなければ、その予測幅では「0.5 ns まででも届かない」と記録します。

## データと条件

- 条件は K15 の広げた条件そのままです。塩橋形成の定義は、正側 LYS NZ / ARG NE・NH1・NH2、負側 ASP OD1・OD2 / GLU OE1・OE2 の荷電重原子間最小距離で、候補は起点（フレーム10、1 ns）で 4.0 Å 超〜10.0 Å 以下、配列距離2以上、ラベルは予測先で 4.0 Å 以下です。静的特徴は5個、履歴は 0〜1 ns の11フレームの距離系列の6統計量（4.0 Å 以下だった割合）です。学習58タンパク質で候補 2,557件、テスト30タンパク質で候補 1,170件です。K15 のキャッシュ（`~/workspace/kinescope/work/k15_cache/`）と `split.json` の分け方を再利用しました。
- 切り取りの定義は G02・G03 と同じです。軌道の保存間隔は 100 ps（0.1 ns）で、0.1 ns の切り取りはフレーム [0,1]（2フレーム）、0.25 ns はフレーム [0,1,2]（3フレーム、実際に覆う長さは 0.2 ns）、0.5 ns はフレーム [0〜5]（6フレーム）です。条件は「静的特徴＋切り取りの平均だけ」です（他の統計量は入れません）。起点フレーム10（1 ns）とラベルは変えていません。
- モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 回復率は、切り取りの平均だけの条件の利得を、その予測幅での実履歴の利得で割った値です。利得はどちらも同じ条件・同じ予測幅の静的な特徴だけの条件との AUPRC の差です。
- K15 の欠けについて: 2hng_A の R3 と 4cv4_A の R2 はキャッシュで候補が0件だったため、テスト側は約20件（約2%）欠けています（K15 の記録の通りで、K15・K19 の結果と結論には影響しないとされています）。G60 も同じキャッシュを使うため、同じ欠けを含みます。
- 確認: 静的のみと全部入り（実履歴）は全予測幅で K15 の記録と一致しました（AUPRC の差は 0.00005 以下）。1 ns先も同じコードで計算し、静的のみ 0.2402・全部入り 0.3842 で K15 と一致し、0.1 ns の切り取りの回復率 0.647 は G03 の記録と一致しました。

## 判断

先に固定した読み方に沿うと、**5・10・30・90 ns先では最小の切り取りは 0.1 ns で、50 ns先だけは 0.5 ns まででも 0.5 に届きません**。

- 5・10・30 ns先では、0.1 ns の切り取りで回復率が 0.85〜0.97 と、1 ns先（0.647）よりむしろ高く戻ります。30 ns先では 3つの切り取りすべてが 0.92 以上です。塩橋の形成では、長い予測幅でも短い切り取りで指導力の大半が戻る、という形です。
- 90 ns先でも 0.1 ns で 0.654 と 0.5 を超えます。ただし切り取りを長くしても単調には上がらず、0.25 ns で 0.801、0.5 ns では 0.465 と 0.5 を割り込みます。10 ns先でも 0.1 ns（0.868）から 0.5 ns（0.526）へ下がる向きで、切り取りの長さと回復率は単調な関係ではありません。
- 50 ns先は例外です。0.1 ns では回復率が −0.126 と静的のみより悪く、0.5 ns でも 0.476 と 0.5 に届きません。ただし 50 ns先は土台の利得そのものが +0.027 と全予測幅で最小で、回復率の分母が小さいため比率が振れやすい幅です。K15 の時間の加工でも 50 ns先だけ反応が大きく振れていました（シャッフルで −0.015）。「50 ns先では短い切り取りが効かない」と読むより、「50 ns先は指導力そのものが小さく、回復率の読みが安定しない幅」と読むのが記録に合います。

## まだ分からないこと

- 50 ns先で回復率が低い理由が、利得の小ささによる比率の振れなのか、50 ns先の指導力の担い手が平均ではないためなのかは、この実験だけでは分けられません。
- 切り取りを長くすると回復率が下がる幅（10・90 ns先）がある理由も分かりません。候補数がテスト 1,170件と限られるため、1条件の揺れの範囲かもしれません。
