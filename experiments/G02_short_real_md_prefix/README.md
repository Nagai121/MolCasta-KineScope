# G02: 短い実MDで、ペアの平均距離と指導力はどこまで戻るか（資料Dの条件、水素結合の形成）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、もう一つの経路「短い実MDを安くする」方向の最初の一手。G01 の第1段（座標からの学習）では 0.45 Å の線を超えられそうにないため、実の履歴を短く切って使う経路を確かめる。
- 状態: 完了。0.1 ns の切り取りだけでも利得の 0.570 が戻り、先に固定した5割の線を超えた。短い実MDは 10分の1 の計算量で指導力の大半を戻せる経路。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切る長さは 0.1 ns、0.25 ns、0.5 ns の3通り。2つの量を測る。

- (a) 切った履歴の平均と 0〜1 ns の平均との残りのばらつき。参照は複製の下限 0.249 Å（実の平均のレプリカ間差の標準偏差）と、生成器の平均の誤差 0.483 Å。
- (b) 切った平均だけを履歴の特徴として資料Dの補正モデルに入れたときの 1 ns先の利得の回復率。参照は実履歴の利得 +0.1178。

読み方は先に固定した。0.1 ns の切り取りで回復率が5割以上なら、短い実MDは 10分の1 の計算量で指導力の大半を戻せる経路。0.5 ns でも5割に届かなければ、短くするだけでは足りず、別の工夫が要る。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。距離はフレームごとの箱を軸ごとに扱う（K01 の抽出コードと同じ段取り）。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の 18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（`~/workspace/mt-venv` の Python）。

### 切り取りの定義（結果を見る前に固定）

軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。

| 切る長さ | フレーム | 実際に覆う長さ |
|---|---|---|
| 0.1 ns | 0, 1（2フレーム） | 0.1 ns |
| 0.25 ns | 0, 1, 2（3フレーム） | 0.2 ns |
| 0.5 ns | 0〜5（6フレーム） | 0.5 ns |

0.25 ns は 100 ps 刻みに合わないため、実際に覆う長さは 0.2 ns になる。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
- 平均だけ（mean_only_full）: 静的特徴＋0〜1 ns の平均だけ。K21 の「平均だけ」と同じ形。
- 切った平均だけ（prefix_mean_0.1/0.25/0.5ns）: 静的特徴＋切った履歴の平均だけ。
- 切った6統計量（prefix_hist6_0.1/0.25/0.5ns）: 参考条件。切った履歴の6統計量全部を入れる。

## 3. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、形成の記録と小数第4位まで完全一致した。平均だけ（0〜1 ns）は AUPRC 0.4865、回復率 1.042 で、K64 の値（0.4865、1.042）と一致する。

### (a) 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差

| 切る長さ | テスト（4,972件） | 学習（9,610件） |
|---|---:|---:|
| 0.1 ns | 0.396 Å | 0.421 Å |
| 0.25 ns（実際は 0.2 ns） | 0.319 Å | 0.350 Å |
| 0.5 ns | 0.188 Å | 0.205 Å |

参照と比べると、複製の下限 0.249 Å、生成器の平均の誤差 0.483 Å に対して、0.1 ns の切り取りでも残りのばらつきは生成器の誤差（0.483 Å）より小さく、0.5 ns の切り取りでは複製の下限（0.249 Å）を下回る。切った平均と 0〜1 ns の平均の差の平均は +0.02〜+0.03 Å で、始めの短い部分の平均のほうが 0〜1 ns の平均よりわずかに大きい（距離が 0〜1 ns のあいだにわずかに伸びる向き）。

### (b) 1 ns先の利得の回復率（平均だけの条件）

| 切る長さ | AUPRC | 回復率（平均だけ） | 回復率（6統計量、参考） |
|---|---:|---:|---:|
| 0.1 ns | 0.4308 | 0.570 | 0.583 |
| 0.25 ns（実際は 0.2 ns） | 0.4399 | 0.647 | 0.700 |
| 0.5 ns | 0.4544 | 0.770 | 0.803 |
| 0〜1 ns（全部の平均） | 0.4865 | 1.042 | 1.000 |

静的のみは AUPRC 0.3637。切る長さが長くなるほど回復率は単調に上がり、0.1 ns でも 0.570 と5割を超える。6統計量を全部入れても、平均だけと比べて回復率は 0.01〜0.05 しか上がらない。

## 4. 読み取り

- **0.1 ns の切り取りで回復率が 0.570 と5割を超えた。** 先に固定した読み方に沿うと、短い実MDは 10分の1 の計算量で指導力の大半を戻せる経路になる。0.5 ns まで伸ばすと 0.770 まで戻るが、0.1 ns でも半分以上は戻る。
- 残りのばらつきの側から見ても、0.1 ns の切り取りの 0.396 Å は生成器の誤差 0.483 Å より小さく、0.5 ns の切り取りの 0.188 Å は複製の下限 0.249 Å を下回る。短い実MDは、生成器が届いていない水準の平均を、始めの短い部分だけでほぼ再現できる。
- 平均だけと6統計量の差は小さい（0.01〜0.05）ため、短い切り取りでも担い手は平均のまま。切る長さを伸ばすほど平均が 0〜1 ns の平均に近づき、回復率も上がる、という素直な関係。
- ただしこれは「実の始めの短い部分」をそのまま使った場合の話で、短い実MDを実際に回す計算量や、始めの 0.1 ns が安定するまでの平衡化の扱いは、この実験では測っていない。実MDを短く回す運用上の段取りは別の問い。

## 5. 判断できること・まだ分からないこと

- 判断できること: 0.1 ns の実の履歴だけでも、1 ns先の指導力の 0.570 が戻る。短くするだけでも足りる経路がある。0.5 ns では 0.770 まで戻る。
- まだ分からないこと: 0.1 ns よりさらに短い切り取り（フレーム0だけ、つまり起点の距離そのもの）ではどこまで戻るか。短い実MDを実際に回すときの計算量と平衡化の扱い。強い土台（K06(b)）でも同じ形か。
