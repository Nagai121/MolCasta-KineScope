# L35: L01 の曲がりを塩橋の解離で測る（K15 の土台、10 ns先）

- 確かめる仮説: H6 に関わる L 系列の続き。塩橋の解離（K15 の土台、全予測幅、L33〜L38）の 10 ns先。方法と長さの定義は L01・L02・L27 と同じです。
- 状態: 完了。統合値の回復率は全長さで 0.61〜1.03 の高い水準にあり、利得が大きい（全体 +0.1781）ため区間も比較的狭く（幅 0.5〜0.65）なりました。0.8 の線は 0.2 ns、0.9 の線は 0.4 ns で届きます。増え分が集中する場所はなく、段はありません。

## 1. 何を確かめる実験か

L33 と同じ段取りで、予測幅だけを 10 ns先に変えたものです。覆う長さ 11通り（0〜1.0 ns、0.1 ns 刻み、フレーム 0〜(L/0.1)）で切り取りの平均だけを入れたときの回復率を測り、先に固定した読み方（L02 と同じ）で読みます。

1. 回復率 0.8 と 0.9 に届く最小の覆う長さを統合値で読む（タンパク質ごとの平均も併記）。
2. 段の判定は増え幅がいちばん大きい場所と大きさ。
3. 信頼区間はタンパク質単位のブートストラップ 10,000回（seed 42、パーセンタイル法、標本内で利得と回復率を計算し直す）。
4. 段の前後ではタンパク質ごとの値も記録する。

## 2. 条件

- 土台は K15 の解離側（K53 のキャッシュ。学習 58・テスト 30タンパク質、静的特徴 5個、HistGBM は条件ごとに学習し直し、120回・学習率 0.075・葉 31・葉あたり最小 15・L2 0.02・種 42）。学習 735件、テスト 360件、10 ns先の陽性 131件。
- 条件は静的のみ、全部入り（静的＋履歴 6統計量）、切り取りの平均だけ 11通り。回復率 =（その長さの AUPRC − 静的のみ）÷（全部入りの利得）。
- 実行はローカルです。

## 3. 結果

### 土台の再現

静的のみ AUPRC 0.3572、全部入り 0.5353、利得 全体 +0.1781／平均 +0.0954 で、K2-50 の記録と 5e-4 以内で一致しました（`premise_check.json`）。重なる長さの回復率も G69 の平均だけの走査と一致しました（覆う長さに直して 0.1 ns で 0.605、0.2 ns で 0.851、0.5 ns で 0.980）。

### 先に固定した読み方への答え

1. **回復率 0.8 に届く最小の長さ: 覆う長さ 0.2 ns（全体 0.851）**。平均では 0 ns の時点で 1.067 と線を超えています。
2. **回復率 0.9 に届く最小の長さ: 覆う長さ 0.4 ns（全体 0.922）**。平均では 0 ns（1.067）。
3. **増え幅がいちばん大きい場所: 全体では 0.1→0.2 ns（+0.246）**、平均では 0.3→0.4 ns（+0.333）。全体の段の位置でのタンパク質ごとの増え分は中央値 0.000、正だったのは 18タンパク質のうち 44% で、段とは読めません。曲がりは最初から高い水準にあり、増え分の集中はありません。
4. タンパク質ごとの回復率が定義できたのは全部入りの利得が正だった 18タンパク質です。全値は `per_protein.csv` と `results.json` にあります。

## 4. 読み取り

- 10 ns先では、どの長さでも回復率は 0.6 以上あり、短い切り取りで利得の大半が戻ります。解離の 1 ns先（L33）と同じく、形成側より曲がりが読みやすい予測幅です。
- 0.1 ns で一度下がる（0.605）形は G69 の走査でも同じで、再現性のある形ですが、区間が重なるため確かな落ち込みとは言えません。
