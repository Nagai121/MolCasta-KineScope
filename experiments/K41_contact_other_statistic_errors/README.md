# K41 接触でも、平均以外の統計量の誤差の形は水素結合と同じか（資料Dの条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。水素結合とは形が違いました。接触では 1 ns先で3つまとめると利得が消え、その担い手は 4.5 Å 以下割合の誤差です。50 ns先だけは水素結合と同じ形でした。

## 1. 何を確かめる実験か

水素結合では、平均以外の統計量の誤差は予測幅によって形が違いました（K33）。1 ns先では3つまとめても利得の 0.65 が残り、5・30 ns先では3つまとめで生成水準まで落ち、90 ns先では標準偏差だけで利得が消えました。接触でも同じ形か確かめます。

読み方は先に固定しました。接触でも同じ予測幅の形が出れば、平均以外の統計量の誤差の形は現象に共通です。形が違えば、現象ごとに違います。

## 2. 条件

- 土台は K16 の接触の条件（資料D）です。学習は 1bgf_A・1ifg_A・1j8r_A・2b0a_A（15,926件）、テストは 1mix_A＋2qt4_A 合算（7,384件、陽性は予測幅ごとに 219〜257件）で、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・4.5 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、4.5 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、4.5 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は K14 の接触の生成系列（第22案、5点: 起点と +0.1／0.3／0.5／1.0 ns）で、生成の統計量はその5点から同じ定義で計算しました。参考条件として、6統計量すべてを生成の値にしたもの（gen6）も測りました。
- 測れる範囲の注意: K14 の生成系列があるのは、代表原子ペアがドナー・アクセプターの組になる 4,968件（K13 の接触候補 23,310件のうち 21%）だけです。そのため置き換え条件の評価は、テスト側のうち生成系列がある 1,771件に限られます。参照条件（静的のみ・実履歴）も同じ 1,771件で測り直しました。1,771件の陽性は予測幅ごとに 24〜38件と少ないため、AUPRC の揺れは大きいです。
- 突き合わせの確認: 生成系列の各行は、5点の最小値系列そのものを鍵にして K13 のキャッシュの行と突き合わせ、4,968行すべてが重なりなく対応しました（K35 と同じ確認をこのスクリプトの中でもう一度行っています）。
- 対照の確認: 静的のみと実履歴をテスト全体（7,384件）で測ると、K16 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.3398、実履歴 0.5669）。

## 4. 読み取り

- **1 ns先の形は、水素結合と違います。** 水素結合では3つまとめても利得の 0.65 が残りましたが、接触では3つまとめで利得が消えます（残存率 −0.22）。1つずつ見ると、標準偏差だけでは 0.96、最小値だけでは 0.87 とほとんど落ちないのに対し、4.5 Å 以下割合だけでは 0.10 まで落ちます。接触の 1 ns先では、平均以外の統計量の誤差の担い手は 4.5 Å 以下割合です。これは K27 の結果（接触では割合だけで 1〜30 ns先で利得の 0.87〜1.08 が戻る。50 ns先は 0.78、90 ns先は 0.72）と整合します。生成系列は静かで境界以下にほとんどならないため（K14 で、生成は 0.2%、実の最小値は 1.0%）、割合を生成の値に置き換えると「境界以下になったことがある」という信号がほぼ消えてしまいます。
- **5・10 ns先では、3つまとめると利得の大半が落ちます**（残存率 0.28、0.19）。水素結合では 5 ns先で 3つまとめが生成水準まで落ち（−0.06）、10 ns先では 0.52 が残ったのに対し、接触では 10 ns先でも 0.19 まで落ちます。1つずつでは 0.58〜0.87 が残るため、3つの誤差が合わさって利得が崩れる形は水素結合と同じです。
- **30 ns先は、土台の利得そのものが小さいため（+0.0510）、残存率は揺れやすく、細かい値では読めません。** 3つまとめでは利得が消えますが（−0.79）、最小値だけでは利得が増えています（2.31）。この幅の数値は、利得が消えるという大まかな形までしか読めません。
- **50 ns先だけは、水素結合と同じ形でした。** 3つまとめで 0.74 が残り、水素結合の 0.72 と同じです。1つずつでも 0.84〜1.06 とほとんど落ちません。
- **90 ns先では、3つまとめで利得がほぼ消えます**（0.08）。水素結合でも 3つまとめで −0.23 と消えましたが、水素結合では標準偏差だけで利得が消えた（−0.35）のに対し、接触では標準偏差だけでは 0.80 が残ります。90 ns先で利得を消す担い手は、接触では標準偏差1つではなく、3つの組み合わせです。
- 先に固定した読み方に照らすと、**平均以外の統計量の誤差の形は、接触と水素結合で違います。** 1 ns先では接触のほうが3つの誤差で説明がつき、90 ns先では標準偏差1つで説明がつくのが水素結合だけで、接触では組み合わせが必要です。50 ns先だけが同じ形でした。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触では、平均以外の3つの統計量の誤差を合わせると、1・10・30・90 ns先で利得の大半が消えます。1 ns先の担い手は 4.5 Å 以下割合の誤差です。水素結合の K33 とは予測幅ごとの形が違い、平均以外の統計量の誤差の形は現象ごとに違います。
- まだ分からないこと: 測れたのはドナー・アクセプターらしい 1,771件（陽性 24〜38件）だけで、接触全体でも同じ形かは分かりません。特に 30 ns先は土台の利得が小さく、残存率の細かい値は揺れの範囲です。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
