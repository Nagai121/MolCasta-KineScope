# K43 生成の平均は、静的な予測と同じものか（強い土台、水素結合）

## 問い

K39 で、生成の平均は静的な特徴で 97% 説明できました。生成の平均と、静的な特徴から実の平均を予測した値が、ほぼ同じものかどうか直接確かめます。

## 対象と条件

- 第1部は K06(b) と同じ候補です。較正用の8タンパク質（13,808件）で実の平均の予測を学習し、未見の100タンパク質×3複製（163,074件）で評価します。学習と評価のタンパク質が重ならないことを確認しました（共通 0件）。予測は K39 の当てはめ（静的な5特徴から実の平均を予測する線形回帰と HistGradientBoosting 回帰）です。
- 第2部は資料Dの候補（6タンパク質×3複製、14,582件）で、学習は4タンパク質（9,610件）、評価は 1mix_A・2qt4_A（4,972件）です。資料Dの7特徴による予測（K23 の設定）と、K40 の豊かな99特徴による予測（K40 と同じ設定）を比べます。生成の平均は K05 で作り直した第22案の系列から取ります。
- 測るのは、生成の平均と静的な予測の相関（Pearson と Spearman）と、差（生成 − 予測）の平均・標準偏差です。

## 注：指示の (a) の特徴量について

指示には「資料Dの7つの静的な特徴から実の平均を予測した値（K39 の当てはめ）」とありましたが、K39 の当てはめは K06(b) の静的な5特徴（本体の予測確率、起点距離、基礎記述子3個）を使ったもので、資料Dの7特徴ではありません。資料Dの7特徴は K06(b) の候補には存在しないため、第1部は K39 の当てはめそのもの（静的5特徴）で測り、資料Dの7特徴による予測は第2部で測りました。

## NaN の扱い（決めたこと）

豊かな99特徴には NaN があります。数えた結果（14,582件中）：Cβ間距離が 1,544件（10.6%、グリシンには Cβが無いため）、Cαの i−2 距離がドナー側 99件・アクセプター側 136件（末端の残基のため）、鎖方向との角度がドナー側 31件・アクセプター側 60件（末端のため）、Cαの i+2 距離がドナー側 28件・アクセプター側 26件（末端のため）です。

扱いは、候補を落とさず、学習側の中央値で補うことにしました。候補を落とすと 10.6% の候補が消えて K23・K40・K05 との対応が壊れるためです。線形回帰には学習側の中央値で補う処理を入れ（評価側には学習側の中央値を使い、情報の漏れはありません）、HistGradientBoosting 回帰は NaN をそのまま扱えるため変更しません。最初の実行は線形回帰が NaN で止まりましたが、この扱いを入れて再実行し、最後まで完了しました。

## 結果

### 第1部（K06(b) の候補、評価 163,074件）

| 予測 | 生成の平均との相関 | 差の平均 | 差の標準偏差 |
|---|---:|---:|---:|
| K39 の当てはめ（線形回帰） | 0.969 | −0.223 Å | 0.195 Å |
| K39 の当てはめ（GBM 回帰） | 0.963 | −0.225 Å | 0.214 Å |

参考：生成の平均と実の平均の相関は 0.786、静的な予測と実の平均の相関は 0.791（線形）・0.797（GBM）でした。K39 の再現確認として、実の平均の当てはめの R² は線形 0.626・GBM 0.635、生成の平均の当てはめの R² は線形 0.967・GBM 0.976 で、K39 の記録値と一致しました。

### 第2部（資料Dの候補、評価 4,972件）

| 予測 | 生成の平均との相関 | 差の平均 | 差の標準偏差 |
|---|---:|---:|---:|
| 資料Dの7特徴（線形回帰） | 0.977 | −0.172 Å | 0.158 Å |
| 資料Dの7特徴（GBM 回帰） | 0.966 | −0.183 Å | 0.195 Å |
| 豊かな99特徴（線形回帰） | 0.964 | −0.171 Å | 0.200 Å |
| 豊かな99特徴（GBM 回帰） | 0.960 | −0.175 Å | 0.213 Å |

## 結論

先に固定した読み方のどちらにも、きれいには当てはまりませんでした。相関は 0.96〜0.98 と高く、0.9 を下回ってはいませんが、0.99 前後とも言えず、差も小さくありません。生成の平均は静的な予測より系統的に 0.17〜0.22 Å 低く、そのまわりにも 0.16〜0.21 Å の散らばりがあります。系統的なずれは、生成の平均が実の平均より短い側にずれるという既知の偏り（K05・K08・K23）と同じものです。

つまり、生成の平均は静的な予測にほぼ沿ってはいますが、同じものではありません。ただし、静的な予測のまわりの散らばり（0.16〜0.21 Å）は、実の平均の静的な予測のまわりの残差（0.47〜0.61 Å）に比べれば小さく、生成の平均が静的な予測を超えて持つ成分は少ない、というのが実質の結論です。これは K39 の結果（生成の平均の残差はラベルとほとんど関わらない）と整合します。豊かな特徴による予測は、生成の平均に近づくどころか、むしろ単純な資料Dの7特徴による予測のほうが生成の平均に近かった（差の標準偏差 0.158 Å 対 0.200 Å）ことから、生成器の平均は単純な静的な予測に近い振る舞いをしているとも言えます。
