# G29: 接触の形成で、混合の足しが消える境目はどこか

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。G13 では、0.1 ns の切り取り平均に K17 の残基レベル生成平均（第11〜14案）を足すと、回復率が第11〜13案で +0.070〜+0.097 上がりました。G25 では、0.5 ns の切り取りではどの案も +0.05 に届きませんでした。そのあいだの 0.25 ns の切り取りで測り、足しが消える境目を探します。

読み方は実験前に固定しました。混合の回復率が切り取り平均だけより +0.05 以上上がる案があれば、混合の効き目は 0.25 ns の切り取りまで続くことになります。どの案も +0.05 未満なら、効き目は 0.1 ns から 0.25 ns のあいだで切れることになります。

## データと条件

- 条件は資料Dの接触の形成、1 ns先です。G13・G25 と同じ段取りで、実側は K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/`、静的5特徴、11点の履歴、ラベル）、生成系列は K17 の保存値（`~/workspace/k17/out/`、第11〜14案の分岐平均の9点系列）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（15,926件）、テスト 1mix_A＋2qt4_A（7,384件、1 ns先の陽性 219件）。生成平均は9点系列の平均で、K17 の予測で使った6統計量のうち平均の列だけを使う形です。実側は K17 の保存値と配列単位で一致することを、実行時に全軌道で確認しています（G13・G25 と同じ確認）。生成器のチェックポイントは読み込んでいません。新しい軌道の取得もしていません。
- 注意: 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離を共有しますが時間の向きが逆です（G11・G13・G25 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません。
- 切り取りの定義（G02・G07 と同じ）: 0.25 ns の切り取りはフレーム [0,1,2]（3フレーム）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。
- 条件の一覧（1 ns先）:
  - 静的のみ: 静的特徴5個だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム、閾値 4.5 Å）。
  - 切り取り平均だけ: 静的特徴＋0.25 ns の切り取り平均だけ。
  - 生成平均だけ: 静的特徴＋第11〜14案の生成平均だけ（案ごとに1条件）。
  - 混合: 静的特徴＋切り取り平均＋生成平均（2列、案ごとに1条件）。
- 回復率 =（その条件の AUPRC − 静的のみ）÷（実履歴の利得 +0.2271）で測ります。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。
- 確認: 静的のみ 0.3398・全部入り 0.5669 で K16 の記録と一致し、切り取り平均だけは AUPRC 0.4561・回復率 0.512 で G07 の記録と一致しました（いずれも AUPRC の差は 0.00005 以下）。生成平均だけの4案も、G13 の記録と小数第4位まで一致しました。

## 判断

先に固定した +0.05 の線で見ると、**どの案も +0.05 に届きませんでした**。上がり幅は最大でも第14案の +0.039 で、第11〜13案はむしろ下がります。混合の効き目は、0.1 ns から 0.25 ns のあいだで切れることになります。

切り取りの長さによる足しの変化を並べると、第11〜13案の上がり幅は 0.1 ns で +0.070〜+0.097（G13）、0.25 ns で −0.027〜−0.005、0.5 ns で −0.015〜+0.032（G25）です。0.25 ns ですでに足しは消えています。切り取り平均と 0〜1 ns の平均の相関も、0.1 ns の 0.979 から 0.25 ns の 0.986、0.5 ns の 0.995 と、切り取りを長くするほど 0〜1 ns の平均に近づき、生成平均が補う余地がなくなります。

なお、第14案だけは 0.1 ns では −0.001 と上がらず、0.25 ns では +0.039 と4案のなかで最も上がりました。ただし +0.05 には届いていないので、境目の読みは変わりません。なぜ第14案だけ動きが違うのかは、この実験だけでは分かりません。

## 注意点

- 単一の学習 seed の結果です。テストは 7,384件、1 ns先の陽性は 219件（陽性率 3.0%）と陽性が少ない条件で、回復率の揺れは水素結合の形成より大きい可能性があります（G13・G25 と同じ留保）。
- 実行は約226秒かかりました（他のスレッドの計算と CPU を分け合っていたためと思われます。G25 は約35秒でした）。
