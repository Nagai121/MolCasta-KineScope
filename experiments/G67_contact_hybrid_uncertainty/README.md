# G67: 接触の形成での混合の差に、区間を付ける

## 仮説

H6（運動の生成そのものの問題）に関わる、混合の経路の確認です。接触の形成では、G13 で 1 ns先に第11〜13案が +0.05 を超え（+0.076/+0.097/+0.070）、G36 で 5 ns先に第11案だけが +0.057、G42 で 10 ns先に第13案だけが +0.053、G63 で 50 ns先に第14案だけが +0.058 でした。30 ns先と 90 ns先では、どの案も +0.05 に届きませんでした。全予測幅（1・5・10・30・50・90 ns）×第11〜14案について、混合と切り取り平均だけの差（mixed_minus_prefix）のブートストラップ 95% 区間を出します（G49・G59・G62 と同じやり方）。

読み方は実験前に固定しました。+0.05 を超えたセル（1 ns の第11〜13案、5 ns の第11案、10 ns の第13案、50 ns の第14案）の区間が 0 を含むかどうかを見ます。

## データと条件

- 条件は資料Dの接触の形成です。G13・G36・G42・G55・G63 と同じ段取りで、K13 のキャッシュ（`~/workspace/kinescope/work/k13_cache/`、起点の最小距離 4.5 Å 以下の候補、ラベルは予測幅で 4.5 Å より大きい）と、K17 の残基レベル生成系列（`~/workspace/k17/out/`、第11〜14案、分岐平均の9点系列）を使いました。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A（15,926件）、テスト 1mix_A＋2qt4_A（7,384件、うち 1mix_A 5,012件・2qt4_A 2,372件）。静的特徴は5個、履歴は残基ペア間の最小距離の系列の6統計量（4.5 Å 以下だった割合）です。
- 切り取りは 0.1 ns（フレーム [0,1]、2フレーム）で、平均はその2フレームの最小距離の平均です（G02・G03・G13 と同じ）。生成平均は、K17 の分岐平均の9点系列の9点の平均です。対応付けは、K17 の保存済みの実側（X・hist・y）が K13 のキャッシュと配列として同一であることを確かめた上で、位置で対応付けました（G13 と同じ）。生成器のチェックポイントは読み込んでいません。
- 条件は予測幅ごとに次の通りです。静的のみ、全部入り（実履歴6統計量、参照）、切り取り平均だけ、生成平均だけ（第11〜14案）、混合（切り取り平均＋生成平均の2列、第11〜14案）。回復率は、その予測幅での実履歴の利得で割った値です。差の定義は mixed_minus_prefix = 混合の回復率 − 切り取り平均だけの回復率です。モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）で条件ごとに学習し直しました。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています（各キャッシュの取り出し時に適用済みで、ここではキャッシュをそのまま使いました）。
- 生成系列は起点から先への前方系列で、実履歴は起点までの後方系列です。両者は起点距離 d0 を共有しますが時間の向きが逆です（G13 と同じ留保）。ただし平均は向きに依らない量なので、この実験では向きの違いは平均の定義に影響しません（平均の列だけを使うため）。

## ブートストラップの段取り（結果を見る前に固定）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。G49・G59・G62・G23 と同じです。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（5,012件）と 2qt4_A（2,372件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。区間が粗いことは留保として記録します（下の「読みの注意点」を参照）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・切り取り平均だけ・混合の AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- G13・G36・G42・G55・G63 の結果をそのまま使うはずでしたが、ブートストラップには候補ごとの予測確率が要るため、同じ段取り・同じ種でモデルを学習し直し、合算の AUPRC が記録と一致することを確認しました（下の「土台の再現」を参照）。
- 計算の工夫: タンパク質が2つだけのため、再標本化の標本は3通りの組み合わせのどれかでしかなく、差の値は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります（差が組み合わせの関数であるため）。抽出の乱数 seed は G23 と同じ 42 です。

## 判断

先に固定した読み方に沿うと、+0.05 を超えた6セルのうち、**区間が 0 を含まないのは5セル**で、**0 を含むのは 5 ns先の第11案だけ**です。

- 1 ns の第11案 [+0.035, +0.084]、第12案 [+0.068, +0.145]、第13案 [+0.005, +0.084] は、いずれも 0 を含みません。ただし第13案の区間の下限 +0.005 は 0 に近く、2qt4_A だけの差も +0.005 とほぼ 0 です。1 ns の「3案とも正」は、1mix_A（+0.084/+0.068/+0.084）に引っ張られた面が大きいです。
- 5 ns の第11案の区間 [−0.043, +0.115] は 0 を含みます。タンパク質ごとの差の向きが食い違います（1mix_A で +0.115、2qt4_A で −0.043）。5 ns先の +0.057 は、2タンパク質で向きが定まらない位置づけです。
- 10 ns の第13案 [+0.042, +0.058] は 0 を含みません。2タンパク質とも差が正（1mix_A +0.042、2qt4_A +0.058）で、区間も狭いです。
- 50 ns の第14案 [+0.027, +0.094] は 0 を含みません。2タンパク質とも差が正（1mix_A +0.094、2qt4_A +0.027）です。

+0.05 を超えなかったセルでは、30 ns先の4案すべてが区間も 0 を含まず負です（第11案 [−0.037, −0.034]、第12案 [−0.076, −0.042]、第13案 [−0.116, −0.051]、第14案 [−0.080, −0.063]）。30 ns先では混合はどの案でも足しにならず、2タンパク質とも差が負です。10 ns先の第12案 [−0.133, −0.024] と第14案 [−0.101, −0.029]、90 ns先の第13案 [−0.058, −0.039] と第14案 [−0.032, −0.011] も、区間が 0 を含まず負です。

## 読みの注意点

- **タンパク質が2つしかないため、区間は「95% 区間」としては粗いものです。** ブートストラップ分布が取る値は3つだけで、区間はその3値の最小値〜最大値に等しくなります（1万回回しても、取りうる値は3通りしかありません）。したがって、ここでの「0 を含む／含まない」は、実質的には「2タンパク質の差の向きと大きさが、予測幅・案ごとにどう違うか」と同じ読みです。3つめのタンパク質でも同じ形になるとまでは言えません。
- テスト陽性が 1mix_A に偏っています（1 ns先で 1mix_A 173件に対し 2qt4_A 46件）。2qt4_A だけの組み合わせは陽性が少なく、その値の揺れが大きいことに注意が必要です。
- 測っているのはテスト集合の取り方による揺れだけで、学習の揺れは入っていません。モデルは種 42 で決定的です。
- 実行は約18分かかりました（ほかのスレッドの重いジョブが 8 本ほど並走し、CPU の取り合いになっていたため）。
