# G22: 塩橋の解離で、切り取りの 6 統計量は平均だけより戻るか（K53 の条件、塩橋の解離、1 ns先）

- 状態: 閉じた。測り直しはしていない。この実験で測るはずだった条件は、G09 の中で「参考」の条件としてすでに測られていたため、G09 の値をそのまま記録に残す。

## 1. 経緯

G22 の割り当ては、K53 の条件（塩橋の解離、1 ns先）で、0.1 ns の切り取りの 6 統計量を補正モデルに入れ、平均だけの回復率（0.693）と比べることだった。ところが G09 の `run_g09.py` には、平均だけの条件に加えて `prefix_hist6_0.1ns` と `prefix_hist6_0.5ns` の条件が「参考」として入っており、同じキャッシュ・同じモデル・同じ seed で測り終えていた。G09 の README にも結果と読み取りが書かれている。同じ計算の測り直しになるため、G22 では測り直さず、G09 の値を記録に残して閉じる。統括の指示（2026-11-24）による。

## 2. G09 の値（測り直しではなく、G09 の結果ファイルからの引用）

出所は `experiments/G09_salt_dissociation_prefix/results.json`（`run_g09.py` で測定）。土台は K53 の条件と同じ。静的特徴5個、履歴の閾値は 4.0 Å、モデルは HistGradientBoosting（120回、学習率 0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）。学習58タンパク質（735件）、テスト30タンパク質（360件、1 ns先の陽性 101件）。

| 条件 | AUPRC（1 ns先） | 回復率（1 ns先） |
|---|---:|---:|
| 静的のみ | 0.3734 | ― |
| 全部入り（実履歴6統計量） | 0.5522 | 1.000 |
| 平均だけ（0〜1 ns） | 0.5382 | 0.921 |
| 切った平均だけ 0.1 ns | 0.4973 | 0.693 |
| 切った6統計量 0.1 ns | 0.4745 | 0.566 |
| 切った平均だけ 0.5 ns | 0.5434 | 0.951 |
| 切った6統計量 0.5 ns | 0.5495 | 0.985 |

利得は +0.1788（0.5522 − 0.3734）。6統計量の定義は [最初、平均、標準偏差、最小、最後−最初、4.0 Å以下割合]。0.1 ns の切り取りはフレーム 0, 1、0.5 ns はフレーム 0〜5。

## 3. 読み取り（先に固定した判定に沿う）

- **0.1 ns の 6 統計量の回復率は 0.566 と、平均だけ（0.693）を下回った。** 先に固定した読み方に沿うと、塩橋の解離では平均だけで十分で、統計量を全部使う価値はない。
- 0.5 ns の 6 統計量は 0.985 と、平均だけ（0.951）とほぼ同じ。G09 の読み取りにもあるとおり、短い切り取りから作った他の統計量は、解離の候補ではほとんど変化がなく、むしろ読み出しを乱す側に働く。
- ただしテストは 360件と小さく、1 ns先の陽性も 101件なので、回復率の揺れは形成より大きい条件。単一の学習 seed の結果でもある（G09 の記録と同じ注意点）。
