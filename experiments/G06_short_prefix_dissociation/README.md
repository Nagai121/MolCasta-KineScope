# G06: 短い実MDの切り取りは、解離でも指導力を戻すか

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、もう一つの経路「短い実MDを安くする」方向。G02 は水素結合の形成で、0.1 ns の切り取りだけでも利得の 0.570 が戻った。解離でも同じか確かめる。
- 状態: 完了。両方の解離とも、0.1 ns の切り取りの平均だけで利得の5割以上が戻った。短い実MDの経路は解離でも使える。

## 1. 何を確かめる実験か

G02 と同じ切り取り（実の 0〜1 ns の履歴の始めの短い部分だけを使う）を、解離の2現象で確かめる。

- (a) 水素結合の解離（資料Dの条件、K46 のキャッシュ）
- (b) 接触の解離（K50 の条件、K50 のキャッシュ）

読み方は先に固定した。両方とも回復率が5割以上なら、短い実MDの経路は解離でも使える。片方だけ届かなければ、その現象では短くするだけでは足りない。

## 2. 条件

- 土台は資料Dの条件。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、seed 42）で条件ごとに学習し直した。距離はフレームごとの箱を軸ごとに扱う周期境界で計算している（抽出済みのキャッシュの段取り）。
- 切り取りの定義（G02 と同じ、結果を見る前に固定）。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。切る長さ L に対して、時刻が L 以下のフレームを使う。
  - 0.1 ns → フレーム 0, 1（2フレーム）
  - 0.5 ns → フレーム 0〜5（6フレーム）
  - 起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。
- 解離の候補の定義（K46・K50 と同じ）:
  - 水素結合の解離: 形成と同じドナー・アクセプターの規則で、起点フレーム10の距離が 3.5 Å 以下（水素結合ができている状態）のペア。ラベルは予測先で 3.5 Å を超えること。静的特徴7個。履歴の閾値は 3.5 Å。候補は学習 4,051件、テスト 2,080件。テストの陽性は 1 ns先で 311件（陽性率 15.0%）。
  - 接触の解離: 形成と同じ残基ペアの規則（Cα間 12 Å 以下、配列距離2以上）で、起点フレーム10の重原子の最小距離が 4.5 Å 以下（接触ができている状態）のペア。ラベルは予測先で 4.5 Å を超えること。静的特徴5個。履歴の閾値は 4.5 Å。候補は学習 6,383件、テスト 2,915件。テストの陽性は 1 ns先で 207件（陽性率 7.1%）。
- 条件の一覧（1 ns先、2現象とも同じ分け方）:
  - 静的のみ: 静的特徴だけ。
  - 全部入り: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。
  - 平均だけ: 静的特徴＋0〜1 ns の平均だけ。
  - 切った平均だけ: 静的特徴＋切った履歴の平均だけ（主判断の条件）。
  - 切った6統計量: 参考条件。切った履歴の6統計量全部を入れる。
- K46・K50 のキャッシュ（`~/workspace/kinescope/work/data_cache_k46/`、`~/workspace/kinescope/work/k50_cache/`）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM（`~/workspace/mt-venv` の Python）。

## 3. 結果

### 土台の再現

両方の現象とも、静的のみと全部入りが K46・K50 の記録と小数第4位まで完全一致した。

- 水素結合の解離: 静的のみ AUPRC 0.4160、全部入り 0.5945、利得 +0.1785。平均だけは 0.5691、回復率 0.858 で K46 の値と一致する。
- 接触の解離: 静的のみ AUPRC 0.3105、全部入り 0.5246、利得 +0.2142。平均だけは 0.5036、回復率 0.902 で K50 の値と一致する。

### (a) 残りのばらつき（切った平均 − 0〜1 ns の平均）の標準偏差、テスト側

| 現象 | 0.1 ns | 0.5 ns |
|---|---:|---:|
| 水素結合の解離 | 0.297 Å（学習 0.290 Å） | 0.163 Å（学習 0.143 Å） |
| 接触の解離 | 0.249 Å（学習 0.252 Å） | 0.106 Å（学習 0.115 Å） |
| 参考: 水素結合の形成（G02） | 0.396 Å | 0.188 Å |

切った平均と 0〜1 ns の平均の差の平均は、解離では +0.01〜+0.03 Å で、始めの短い部分の平均のほうがわずかに大きい（G02 の形成と同じ向き）。解離の候補は起点で結んでいるペアだけなので、距離の動きが小さく、残りのばらつきは形成より小さい。

### (b) 1 ns先の利得の回復率（切った平均だけの条件）

| 現象 | 切る長さ | AUPRC | 回復率（平均だけ） | 回復率（6統計量、参考） |
|---|---:|---:|---:|---:|
| 水素結合の解離 | 0.1 ns | 0.5109 | **0.532** | 0.590 |
| 水素結合の解離 | 0.5 ns | 0.5211 | **0.589** | 0.772 |
| 水素結合の解離 | 0〜1 ns（全部の平均） | 0.5691 | 0.858 | 1.000 |
| 接触の解離 | 0.1 ns | 0.5073 | **0.919** | 0.700 |
| 接触の解離 | 0.5 ns | 0.5128 | **0.945** | 0.748 |
| 接触の解離 | 0〜1 ns（全部の平均） | 0.5036 | 0.902 | 1.000 |

静的のみは、水素結合の解離で AUPRC 0.4160、接触の解離で 0.3105。1 ns先の他の指標も、切った平均だけの条件で静的のみより改善した（水素結合の解離、0.1 ns: AUC 0.8606→0.8787、Brier 0.1025→0.0969、Log Loss 0.3058→0.2946。接触の解離、0.1 ns: AUC 0.8667→0.9079、Brier 0.0574→0.0471、Log Loss 0.1949→0.1638）。詳しくは `results.csv` / `results.json` を参照。

## 4. 読み取り

- **両方の解離とも、0.1 ns の切り取りの平均だけで利得の5割以上が戻った。** 先に固定した読み方に沿うと、短い実MDの経路は解離でも使える。水素結合の解離では 0.1 ns で 0.532、0.5 ns で 0.589。接触の解離では 0.1 ns で 0.919、0.5 ns で 0.945。
- 形成（G02、0.1 ns で 0.570、0.5 ns で 0.770）と比べると、水素結合の解離は形成とほぼ同じ形だが、接触の解離は 0.1 ns だけでも 0.919 と、0〜1 ns の平均だけの 0.902 を上回る。接触の解離では、始めの短い部分の平均が 0〜1 ns の平均とほぼ同じ働きをする。
- 接触の解離では、切った6統計量を全部入れる条件（0.1 ns で 0.700、0.5 ns で 0.748）が、切った平均だけの条件（0.919、0.945）より悪かった。短い切り取りから作った他の統計量（特に 4.5 Å以下割合や標準偏差）は、解離の候補ではほとんど変化がなく、むしろ読み出しを乱す側に働く。短い切り取りでは、平均だけを使う方が6統計量全部より良い。
- 水素結合の解離では逆に、切った6統計量の方が平均だけより良い（0.1 ns で 0.590 対 0.532、0.5 ns で 0.772 対 0.589）。0.5 ns の6統計量は 0.772 まで戻る。現象によって、短い切り取りで平均以外に頼れる量が残るかどうかが違う。
- 残りのばらつきの側から見ても、解離の候補では 0.1 ns の切り取りのばらつきが 0.25〜0.30 Å で、形成の 0.396 Å より小さい。解離の候補は起点で結んでいるため距離の動きが小さく、短い切り取りでも平均が 0〜1 ns の平均に近い。

## 5. 判断できること・まだ分からないこと

- 判断できること: 短い実MDの切り取りは、解離でも指導力を戻す。0.1 ns の切り取りの平均だけで、水素結合の解離では 0.532、接触の解離では 0.919 が戻り、両方とも先に固定した5割の線を超えた。接触の解離では 0.1 ns だけでも 0〜1 ns の平均とほぼ同じ働きをする。
- まだ分からないこと: 強い土台（K06(b)）でも解離で同じ形か（G05 は形成の強い土台の確かめ）。短い実MDを実際に回すときの計算量と平衡化の扱いは、この実験では測っていない。塩橋の解離でも同じか（K53 の条件では陽性が少ない）。
