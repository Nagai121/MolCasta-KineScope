# K65 塩橋の解離でも、平均以外の統計量の誤差の形は同じか（K53 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。塩橋の解離では、平均以外の統計量の誤差はほとんど利得を落としません。標準偏差でも割合でもなく、3つまとめでも利得は残ります。塩橋の解離は独自の形です。

## 1. 何を確かめる実験か

水素結合の解離では標準偏差の誤差が担い手で（K54）、接触の解離では 4.5 Å 以下割合の誤差が担い手でした（K58）。塩橋の解離でも同じ切り分けをします。

読み方は先に固定しました。塩橋の解離でも標準偏差の誤差だけで利得の大半が消えれば、水素結合の解離と共通です。割合の誤差が担い手なら、接触の解離と共通です。どちらでもなければ、塩橋の解離は独自の形です。

## 2. 条件

- 土台は K53 の塩橋の解離の条件（K15 の広げた条件）です。学習は 58タンパク質（735件）、テストは 30タンパク質（360件、陽性は予測幅ごとに 101〜166件）で、モデルは HistGradientBoosting（反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）です。予測幅は 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。利得は静的のみに対する AUPRC の改善で、残存率は「その条件の利得÷実履歴の利得」です。
- やり方は K33 と同じです。実の履歴（静的＋実履歴6統計量）で学習したモデルを使い、学習し直しません。テストの特徴量だけを変えます。実の履歴のうち平均は実のままにして、標準偏差・最小値・4.0 Å 以下割合を1つずつ、また3つまとめて、生成の値に置き換えます。6統計量は [最初の値、平均、標準偏差、最小値、最後−最初、4.0 Å 以下割合] で、置き換えは標準偏差は実履歴[2]←生成[2]、最小値は実履歴[3]←生成[3]、4.0 Å 以下割合は実履歴[5]←生成[5] です。
- 生成の系列は残基レベルの生成方式（第11〜14案、K11/K17/K20 の手順）です。詳しくは第4節です。
- 実の統計量は起点までの11フレームの履歴（0〜1 ns）から、生成の統計量は起点からの分岐平均の9点系列（起点＋8ステップ）から計算しています。後ろ向きと前向きの違いは、K33 と同じ作りです。
- 対照の確認: 静的のみと実履歴は、K53 の記録と全予測幅で完全に一致しました（差 0.0。1 ns先で静的のみ 0.3734、実履歴 0.5522）。
- 注意点: テストは 360件と少なく、実履歴の利得も 30 ns先 +0.0633、90 ns先 +0.0582 と小さいため、残存率は K54・K58 より揺れやすくなります。1.0 を超える残存率（置き換えたほうが利得が増える）は、その幅での揺れの範囲と読むのが安全です。

## 3. K20 の系列では測れなかった理由

- 最初に K20 の生成系列で測ろうとしましたが、そのままでは解離の候補に使えません。K20 の系列は 3,727件で、起点の距離がすべて 4.0 Å より大きく（最小 4.004 Å）、形成の候補だけを対象に作られています。K53 の解離の候補は 1,095件で、起点の距離はすべて 4.0 Å 以下（最大 3.9955 Å）です。同じ軌道では、形成の候補（起点 4.0 Å 超）と解離の候補（起点 4.0 Å 以下）は重ならないため、K20 の系列は解離の候補に1件も合いません。
- そこで、K54・K58 の作り直しと同じく、残基レベルの生成方式（第11〜14案）で解離の候補の系列を作り直しました。以下の結果はこの方式での測定です。

## 6. 読み取り

- **塩橋の解離では、平均以外の統計量の誤差はほとんど利得を落としません。** 第14案では、標準偏差だけの残存率は 0.68〜1.09、最小値だけは 0.77〜1.16、割合だけは 0.67〜1.07 で、1つずつの置き換えは利得をほとんど落としません。3つまとめでも 0.49〜1.18 が残り、5 ns先では実の履歴より利得が増えました。第11案でも、1つずつの置き換えは 0.49〜1.23 が残ります。3つまとめでは 50・90 ns先で 0.34・0.30 まで落ちますが、1・5・10・30 ns先では 0.72〜1.16 が残ります。
- **水素結合の解離（K54）とも接触の解離（K58）とも形が違います。** K54 では第14案の標準偏差だけで残存率が 0.34〜0.75 まで落ち、K58 では第14案の割合だけで 0.46〜0.78 まで落ちました。塩橋の解離では、どちらの統計量だけでも利得はほとんど落ちません。先に固定した読み方に照らすと、**塩橋の解離は独自の形です。**
- なぜ誤差が利得を落とさないのかを、統計量そのものの性質で確かめました。テストの 360件で、実の標準偏差は実の平均と相関 0.870、実の割合は実の平均と相関 −0.902 で、平均以外の統計量はほぼ平均の言い換えになっています。置き換えの条件では平均は実のまま残るため、標準偏差や割合の誤差が入っても、モデルは平均から同じ情報を拾えます。比べると、水素結合の解離では標準偏差と平均の相関は 0.769、割合と平均の相関は −0.768、接触の解離では標準偏差と平均の相関は 0.564、割合と平均の相関は −0.710 で、塩橋の解離ほど平均に結びついていません。平均との結びつきが強いほど、その統計量の誤差が利得を落としにくい、という並びになっています。ただし相関だけが理由のすべてとは言えず、モデルは静的な特徴量も使うため、これは手がかりの1つです。
- なお、6統計量すべてを生成の値にした条件は、第14案では利得の 0.15〜0.64 が残りました（第11案では −0.13〜0.19）。平均まで生成の値に置き換えても、第14案では利得の一部が残ります。生成の平均が実の平均の信号をある程度持っているためです。ただしこの条件は平均の置き換えも含むため、平均以外の統計量の誤差の話とは別です。

## 7. 判断できること・まだ分からないこと

- 判断できること: 塩橋の解離では、平均以外の統計量の誤差は利得をほとんど落としません。標準偏差でも割合でもなく、3つまとめでも（第14案では）利得は残ります。水素結合の解離・接触の解離とは形が違います。塩橋の解離は独自の形です。
- 判断できること: 誤差が利得を落とさない理由の1つは、平均以外の統計量が平均と強く結びついていることです（標準偏差と平均の相関 0.870、割合と平均の相関 −0.902）。平均が実のまま残る置き換えでは、その分は誤差の影響を受けません。
- まだ分からないこと: テストが 360件と少なく、30・90 ns先の利得も小さいため、残存率の細かい数値（1.0 を超える値など）は揺れを含みます。3つの解離での結論の並び（標準偏差が担い手の水素結合、割合が担い手の接触、どちらでもない塩橋）は2案（第14案と第11案）でそろっていますが、塩橋だけテストが小さいため、別のタンパク質の組み合わせで同じ形になるかはまだ確かめていません。また本実験は実の履歴で学習したモデルに生成の値を当てる設計で、モデルの壊れやすさを測っています。生成の統計量そのものがどれだけ情報を持っているかは別の問いです。
