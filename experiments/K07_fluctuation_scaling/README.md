# K07: 実履歴の揺らぎを縮小する（αによる距離系列の縮小）

## 仮説

H6（運動の生成そのものの問題）の検証です。K05 で、生成経路の距離のばらつきは実軌道の約5分の1（ペア内標準偏差 0.060 Å 対 0.332 Å）しかないことが分かり、K06(a) ではその生成方式は実履歴の利得の約45%（1 ns先、8特徴）までしか取り戻せませんでした。「揺らぎの小ささが、指導力の残りを失う主因か」を、実履歴の側を加工して確かめます。

## データと条件

- データ、候補、ラベル、学習・テストの分け方、静的特徴量（7個）、モデルは土台の再現（`experiments/base_reproduction/`）と完全に同じです。ATLAS 解析版 6タンパク質×3レプリカ、学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A と 2qt4_A の合算（候補は学習 9,610件、テスト 4,972件）。水素結合形成、起点 1 ns（フレーム10）、履歴 0〜1 ns の11フレーム（100 ps間隔）、予測幅 1/5/10/30/50/90 ns、指標は AUC、AUPRC、Brier、Log Loss です。距離はフレームごとの箱を軸ごとに扱う周期境界で計算しています。
- モデルは条件ごとに学習し直す比較です（HistGradientBoosting、反復120回、学習率0.075、葉31、min_samples_leaf 15、L2 0.02、seed 42）。変えたのは履歴系列の揺らぎの大きさだけです。
- 加工: 各候補ペアの11フレーム距離系列 d(t) について、系列の平均 mean を取り、d'(t) = mean + α × (d(t) − mean) と変換します。α は 1.0（対照）、0.5、0.25、0.18（K05 の生成側の比率 0.060/0.332 ≈ 0.18 に相当）、0.0（平均で一定）の5通りです。学習側・テスト側の両方に同じ変換を適用し、変換後の系列から履歴の6統計量（最初の値、平均、標準偏差、最小値、最後−最初、3.5 Å以下だった割合）を通常どおり作り直します。
- この変換で平均は不変、標準偏差は α 倍になります。最小値・最初の値・最後−最初・3.5 Å以下割合は非線形に変わります。α=0.0 では標準偏差は0、最小値＝最初の値＝平均、最後−最初は0になり、3.5 Å以下割合は「平均が閾値以下なら1、超なら0」の二値になります。つまり α=0.0 の履歴特徴は、実質的に系列の平均（とその二値化）だけです。
- 対照の確認: α=1.0 は土台と完全一致しました（1 ns先で静的のみ AUPRC 0.3637、履歴あり 0.4815、AUC 0.9056 → 0.9352）。

## 判断できること

読み方は実験前に固定したとおりに判定します。

- α=0.18（生成側の揺らぎの比率）でも、1 ns先の残存率は 1.064 で、半分以下には落ちませんでした。他の予測幅でも 90 ns先の 0.684 が最小で、全幅で半分を上回ります。したがって「揺らぎの大きさが指導力の主な担い手」という読みは、この土台では支持されません。
- α=0.0、つまり履歴を系列の平均だけで代表させても、残存率は 0.84〜1.20 でした。指導力の担い手は揺らぎの大きさではなく、履歴期間中の距離の平均の水準そのもの（起点の1フレームの距離にはない、0〜1 ns の平均的な近さ）にある、という結果です。K01 で順序や間引きに頑健だったこととも合います。
- そのため、K06(a) で生成方式が実履歴の利得の約45%までしか取り戻せなかった理由を、生成経路の揺らぎの小ささ（K05 の標準偏差の差）だけで説明することはできません。生成側で失われているのは、揺らぎよりも、ペアごとの平均の水準の正確さ（どのペアが平均的に近いか）である可能性が高くなりました。
- 予測幅の長い側（90 ns先）では α を小さくすると残存率がやや下がる傾向があり（0.68〜0.84）、揺らぎの情報が長幅では一定の寄与を持つ可能性は残ります。ただし半分以下にはならず、主因とは言えません。

## まだ分からないこと

- この実験は実履歴の平均を正しく保ったまま揺らぎだけを縮めたものです。生成経路は平均の水準自体も実軌道とずれている可能性があり、そのずれの効果はここでは測っていません。平均の水準をずらす加工（例: 起点距離への引き戻し、ペア間での平均の入れ替えに近い条件）は K03 の差し替えと合わせて読む必要があります。
- 残存率が1を超える点が複数あります（最大 1.246）。揺らぎを縮めると特徴量のノイズが減って学習が安定する効果と考えられますが、この土台では単一の学習 seed の結果であり、ばらつきの範囲は測っていません。

## コードと出力

- `extract.py`: 土台と共通の抽出コードです（キャッシュの作成）。
- `run_experiments.py`: 本実験のコードです。土台のキャッシュ（候補・静的特徴・距離系列）を読み、α 変換と学習・評価を行います。
- `results.csv` / `results.json`: 静的のみと各 α 条件の全指標、および利得の残存率です。
- 実行はこの仮想マシン上です。
