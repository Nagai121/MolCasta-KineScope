# K81 塩橋の解離でも、案22の生成の平均の誤差の形は同じか（K53 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 進行中。案22の生成系列の作成と測定を進めている。

## 1. 何を確かめる実験か

K76 で、接触の解離では案22でも誤差の形が残基レベルの生成方式と同じ方向だと分かりました。塩橋の解離でも同じか確かめます。

読み方は先に固定しました。案22でも誤差が境界の近くで大きくならず、外れたペアで大きければ、生成方式によらず同じ形です。形が違えば、誤差の形は生成方式によります。

## 2. 条件

- 対象は K53 の塩橋の解離の候補（K15 の広げた条件、88タンパク質）です。案22で扱える候補だけが対象になる点は、件数と一緒に記録します（下の「与えられる候補の確認」参照）。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は案22の5点系列（起点＋0.1／0.3／0.5／1.0 ns）の平均です（K30・K35・K76 の案22の平均と同じ約束）。
- 分け方：(a) 起点の距離の帯（境界付近 3.0〜4.0 Å と、それ以外 3.0 Å 以下。細かく 0.5 Å 刻みでも測る）、(b) 実の平均の全体の平均からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）。
- 対照として、実の前向き5点系列の平均と実履歴の平均との差も同じ分け方で測ります（K38・K72 の対照）。同じ候補での比較として、K65 の残基レベルの第14案と第11案の誤差も、同じ候補に限って同じ分け方で測ります（K76 と同じやり方）。
- ラベルとの関係も K35・K70・K72・K76 と同じ測定をします。1 ns先のラベル（最小距離が 4.0 Å を超えたか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べます。

## 3. 与えられる候補の確認（2回の違いの記録）

案22の特徴量は（ドナー、アクセプター）の原子ペアにしか定義されていないため、候補の代表原子ペア（起点で最小距離をとる荷電重原子ペア）がドナー・アクセプターのペアである候補だけが与えられます。この確認を2回行い、1回目は失敗し、2回目で成功しました。違いは次の通りです。

### 1回目（失敗）

- 使ったファイル: `check_feedable.py` の最初の版。
- 使ったデータの読み方: minitopol の Registry（`gpt-model-check/data` の Workspace）から原子と軌跡を読み、資料Dの元の6タンパク質（1bgf_A、1ifg_A、1j8r_A、2b0a_A、1mix_A、2qt4_A）の18軌跡だけが対象でした。
- 処理の順番: 各軌跡で、箱（`cell(box[10])`）を先に読み、K53 のキャッシュを後で読んでいました。候補が0件の軌跡を避ける仕組みがありませんでした。
- 失敗: `ValueError: Invalid or unsupported ATLAS box [0. 0. 0.]` で止まりました。箱がすべて0の軌跡に当たったためです。
- 分からない点: 出力には軌跡ごとの行が1行も出ていなかったため、どの軌跡で止まったかは記録に残っていません。後から同じ6タンパク質の18軌跡の起点の箱を Registry 経由で確かめたところ、すべて有効でした。そのため、1回目の失敗の軌跡は後から特定できません。かかった時間も約181秒と、同じ18軌跡を同じ読み方で確かめた K76 の約19秒よりずっと長く、読み込みが遅かったことも記録しておきます。原因の特定には至っていません。

### 2回目（成功）

- 使ったファイル: `check_feedable.py` の書き直し版。
- 使ったデータの読み方: `atoms.parquet` と `A.zarr` から直接読む方式（`gen_k65.py` と同じ読み方）に変えました。元の6タンパク質は `gpt-model-check/data/trajectories` から、残りの82タンパク質は `k15_atlas/<タンパク質>/trajectories` から読みます。原子の辞書は `atoms.parquet`（元素の列あり）から作り、残基の対応は `layout()` と照合しています。
- 処理の順番: K53 のキャッシュを先に読み、候補が0件の軌跡は箱に触る前に飛ばすようにしました（4cv4_A R2 は箱がすべて0と記録されており、2hng_A R3 は候補が0件です。K20・K65 と同じ扱いです）。
- 結果: 候補 1,095件のうち、与えられる候補は 1,095件（100%）でした。塩橋の代表ペアは（正の窒素、負の酸素）のペアなので、すべてドナー・アクセプターのペアでした。接触の解離（K76）では 34.0%、接触の形成（K35）では 21% だったのと違い、塩橋の解離では部分集合の制限がありません。

### 直した点（まとめ）

- 順番の修正: 箱を先に読むのをやめ、キャッシュを先に読んで候補が0件の軌跡を飛ばすようにしました。箱が壊れている軌跡があっても、確認が止まらなくなりました。同じ順番の修正は `gen_k81.py` にも入れています（候補が0件の軌跡は、箱に触る前に空の出力を書いて返ります）。
- 対象の広げ方: 元の6タンパク質だけから K53 の88タンパク質すべてに広げました。K53 の候補は88タンパク質に広がっているため、6タンパク質だけでは 1,095件のうち 118件しか測れませんでした。
