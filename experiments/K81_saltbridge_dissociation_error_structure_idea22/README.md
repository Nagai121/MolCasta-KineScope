# K81 塩橋の解離でも、案22の生成の平均の誤差の形は同じか（K53 の条件）

- 確かめる仮説: H5（特徴量の抽出と読み出し）と H6（運動の生成そのものの問題）に関わる検証
- 状態: 完了。案22でも、誤差の形は残基レベルの生成方式（第11〜14案）と同じです。境界の近くで誤差が大きくならず、外れたペアで誤差が大きくなります。誤差の形は生成方式によりません。ただし全体のずれは案22の方が小さく、生成の平均は残基レベルの方式より約 0.25 Å 高い位置にあります。

## 1. 何を確かめる実験か

K76 で、接触の解離では案22でも誤差の形が残基レベルの生成方式と同じ方向だと分かりました。塩橋の解離でも同じか確かめます。

読み方は先に固定しました。案22でも誤差が境界の近くで大きくならず、外れたペアで大きければ、生成方式によらず同じ形です。形が違えば、誤差の形は生成方式によります。

## 2. 条件

- 対象は K53 の塩橋の解離の候補（K15 の広げた条件、88タンパク質）です。案22で扱える候補だけが対象になる点は、件数と一緒に記録します（下の「与えられる候補の確認」参照）。
- 誤差は候補ごとの「生成の平均 − 実の平均」で、実の平均は実履歴11点の平均、生成の平均は案22の5点系列（起点＋0.1／0.3／0.5／1.0 ns）の平均です（K30・K35・K76 の案22の平均と同じ約束）。
- 分け方：(a) 起点の距離の帯（境界付近 3.0〜4.0 Å と、それ以外 3.0 Å 以下。細かく 0.5 Å 刻みでも測る）、(b) 実の平均の全体の平均からのずれの大きさ（0.25 未満、0.25〜0.5、0.5〜1.0、1.0 以上の4帯。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）、(c) 残基間の隔たり（隣り合う残基、2〜5、6〜10、11〜20、21以上。K30・K35・K38・K67・K70・K72・K76 と同じ区切り）。
- 対照として、実の前向き5点系列の平均と実履歴の平均との差も同じ分け方で測ります（K38・K72 の対照）。同じ候補での比較として、K65 の残基レベルの第14案と第11案の誤差も、同じ候補に限って同じ分け方で測ります（K76 と同じやり方）。
- ラベルとの関係も K35・K70・K72・K76 と同じ測定をします。1 ns先のラベル（最小距離が 4.0 Å を超えたか）について、誤差とラベルの相関、陽性と陰性の誤差の平均の差、誤差でラベルを予測する AUC を測り、生成の平均を実の平均の線形の式で当てはめたものから作る「縮み＋乱数」の合成の誤差とも比べます。

## 3. 与えられる候補の確認（2回の違いの記録）

案22の特徴量は（ドナー、アクセプター）の原子ペアにしか定義されていないため、候補の代表原子ペア（起点で最小距離をとる荷電重原子ペア）がドナー・アクセプターのペアである候補だけが与えられます。この確認を2回行い、1回目は失敗し、2回目で成功しました。違いは次の通りです。

### 1回目（失敗）

- 使ったファイル: `check_feedable.py` の最初の版。
- 使ったデータの読み方: minitopol の Registry（`gpt-model-check/data` の Workspace）から原子と軌跡を読み、資料Dの元の6タンパク質（1bgf_A、1ifg_A、1j8r_A、2b0a_A、1mix_A、2qt4_A）の18軌跡だけが対象でした。
- 処理の順番: 各軌跡で、箱（`cell(box[10])`）を先に読み、K53 のキャッシュを後で読んでいました。候補が0件の軌跡を避ける仕組みがありませんでした。
- 失敗: `ValueError: Invalid or unsupported ATLAS box [0. 0. 0.]` で止まりました。箱がすべて0の軌跡に当たったためです。
- 分からない点: 出力には軌跡ごとの行が1行も出ていなかったため、どの軌跡で止まったかは記録に残っていません。後から同じ6タンパク質の18軌跡の起点の箱を Registry 経由で確かめたところ、すべて有効でした。そのため、1回目の失敗の軌跡は後から特定できません。かかった時間も約181秒と、同じ18軌跡を同じ読み方で確かめた K76 の約19秒よりずっと長く、読み込みが遅かったことも記録しておきます。原因の特定には至っていません。

### 2回目（成功）

- 使ったファイル: `check_feedable.py` の書き直し版。
- 使ったデータの読み方: `atoms.parquet` と `A.zarr` から直接読む方式（`gen_k65.py` と同じ読み方）に変えました。元の6タンパク質は `gpt-model-check/data/trajectories` から、残りの82タンパク質は `k15_atlas/<タンパク質>/trajectories` から読みます。原子の辞書は `atoms.parquet`（元素の列あり）から作り、残基の対応は `layout()` と照合しています。
- 処理の順番: K53 のキャッシュを先に読み、候補が0件の軌跡は箱に触る前に飛ばすようにしました（4cv4_A R2 は箱がすべて0と記録されており、2hng_A R3 は候補が0件です。K20・K65 と同じ扱いです）。
- 結果: 候補 1,095件のうち、与えられる候補は 1,095件（100%）でした。塩橋の代表ペアは（正の窒素、負の酸素）のペアなので、すべてドナー・アクセプターのペアでした。接触の解離（K76）では 34.0%、接触の形成（K35）では 21% だったのと違い、塩橋の解離では部分集合の制限がありません。

### 直した点（まとめ）

- 順番の修正: 箱を先に読むのをやめ、キャッシュを先に読んで候補が0件の軌跡を飛ばすようにしました。箱が壊れている軌跡があっても、確認が止まらなくなりました。同じ順番の修正は `gen_k81.py` にも入れています（候補が0件の軌跡は、箱に触る前に空の出力を書いて返ります）。
- 対象の広げ方: 元の6タンパク質だけから K53 の88タンパク質すべてに広げました。K53 の候補は88タンパク質に広がっているため、6タンパク質だけでは 1,095件のうち 118件しか測れませんでした。

## 5. 読み取り

- **境界の近くで誤差が大きくなる勾配はありません。** 境界付近（3.0〜4.0 Å）の誤差は 1.042 Å、それ以外は 1.068 Å で、比は 0.98 倍です。細かい帯も 1.068／0.981／1.125 Å とほぼ平らです。K72（第14案）では同じ比が 0.96 倍、細かい帯が 1.074／0.979／1.104 Å でした。案22でも同じです。
- **外れたペアで誤差が大きい形は、案22でも出ました。** (b) では、実の平均が全体の平均（3.469 Å）から 1.0 Å 以上離れた候補（156件）で誤差が 1.201 Å になり、中心（0.25 未満）の 0.302 Å に対して 3.98 倍です。K72 では同じ比が 3.61 倍、同じ候補での第14案では 3.61 倍、第11案では 3.78 倍でした。この帯の誤差はすべて負の側に出ます（全体のずれ −2.476 Å、平均絶対値も 2.476 Å）。この帯の実の平均は 4.47〜10.49 Å とすべて全体の平均より上にあり、生成の平均は 2.67〜4.34 Å の範囲に留まります。この帯の候補の起点の帯は、2.5〜3.0 Å が 126件、3.0〜3.5 Å が 10件、3.5〜4.0 Å が 20件です。K72 の第14案でも、この帯の実の平均は 4.47〜10.49 Å、生成の平均は 2.45〜4.07 Å と、ほぼ同じでした。
- **誤差の大きさも、生成方式によらずほぼ同じです。** 全体の誤差の標準偏差は、案22 が 1.065 Å、第14案が 1.070 Å、第11案が 1.070 Å です。隔たりの効果も、21以上と 2〜5 の比が案22・第14案・第11案のすべてで 0.86 倍と、どれも同じです。対照の実の前向き系列でも、裾と中心の比は 1.98 倍、境界付近とそれ以外の比は 0.74 倍と、誤差の形の大部分は前向きと後ろ向きの違いから来ています。
- **違うのは全体のずれの大きさだけです。** 案22の全体のずれは −0.379 Å で、第14案の −0.635 Å、第11案の −0.659 Å より小さいです。生成の平均の全体の平均は案22 が 3.090 Å で、第14案の 2.835 Å より約 0.25 Å 高い位置にあります。中心の帯（0.25 未満）の全体のずれも、案22 が −0.276 Å で、第14案の −0.527 Å より小さいです。案22の生成の平均は、代表ペアの距離を追うため、最小値を直接作る残基レベルの方式より高めに出ます。ただし誤差の形（比や勾配）は同じです。
- **生成の平均は、案22でもほぼ一定になってしまっています。** 生成の平均の全体の平均は 3.090 Å で、ペア間のばらつきは 0.249 Å しかありません。実の平均のばらつきは 1.083 Å です。生成の平均を実の平均の線形の式で当てはめると傾きは 0.043 で、K72 の第14案の 0.042 と同じです。実の平均がどうであれ生成の平均はほぼ一定です。
- ラベルとの関係では、誤差とラベルの相関が −0.352 で、縮み＋乱数の合成の −0.375 とほぼ同じ強さでした。K72 の第14案でも −0.345 に対して合成 −0.373 と同じでした。生成の平均は、陽性と陰性の平均の差が +0.110 Å と、実の平均の +0.960 Å に比べてほとんどありません。生成の平均は、解離するペアとしないペアをほとんど区別できていません。
- 生成の系列の質の確認では、案22の系列は実の前向き系列より静かでした（ペアごとの標準偏差 0.149 Å に対して実の最小系列は 0.554 Å、境界を越える回数は 0.034 回／ペアに対して実は 0.589 回／ペア）。K05・K54・K76 と同じ静かさです。生成の平均は 3.090 Å で、実の最小系列の平均 3.243 Å よりやや短いです。
- (c) では隔たりによるはっきりした並びはなく、2〜5 が 1.133 Å、6〜10 が 0.832 Å、11〜20 が 1.139 Å、21以上が 0.977 Å でした。K72 の第14案でも 1.134／0.838／1.159／0.970 Å と、ほぼ同じ数値でした。なお、塩橋の候補は隔たりが2以上と決まっているため、「隣り合う残基」の帯は 0件です（K35・K70・K72・K76 と同じ）。

## 6. 判断できること・まだ分からないこと

- 判断できること: 先に固定した読み方では、案22でも誤差が境界の近くで大きくならず（比 0.98 倍）、外れたペアで大きくなります（中心の 3.98 倍）。誤差の形は生成方式によらず同じです。全体の誤差の大きさ、隔たりの効果、ラベルとの関係、生成の平均がほぼ一定になる点も、残基レベルの生成方式と同じでした。
- 判断できること: 全体のずれだけは案22の方が小さく（−0.379 Å に対して −0.635 Å）、生成の平均は約 0.25 Å 高い位置にあります。誤差の形は同じでも、誤差の水準は生成方式で少し違います。
- まだ分からないこと: 候補は 1,095件と少なく、境界付近の帯は 70件と 45件しかありません。別のタンパク質の組み合わせでも同じ形になるかは、まだ確かめていません。また生成器は水素結合の形成のペアだけで学習したものを流用しており、学習範囲の外への当てはめである点は変わりません。
