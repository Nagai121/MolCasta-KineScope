# GA305 静的起点から生成した暗黙溶媒MDによるペア残差

GA301の学習20配列、選定3配列、確認8配列、起点・候補、静的Ridge基準と実観測教師を固定。入力は静的な起点構造と、その構造から独立に生成した100 ps×2シードの標準暗黙溶媒MD。観測履歴や将来の実観測は推論入力に含めない。GA301に対する変更は、学習器に生成MD統計を追加した点。MD積分を用いない結果はGA303・GA304を参照。

生成側の各統計から、静的特徴で説明できる成分を学習20配列のRidgeで除去。生成残差から実履歴平均の残差を予測する。実履歴残差の訓練ターゲットは配列外の静的基準で作成。5種の特徴群と3学習器、固定オフセット対照4件の19条件。検証相関で選んだ residual-ridge は検証0.520235、確認0.550534、誤差SD 0.446856 Å。確認9,843候補は探索に使っていない。過去のGAで既出の確認パネル。8配列を単位とする2,000回再標本化の95%範囲は0.523676–0.597015。個別配列の範囲は0.505629–0.680170。相関0.500は達成、誤差SD 0.30 Åは未達、100配列×3レプリカの指導力回復率は未測定。

再現はGA301と同じ作業フォルダに ga_static_offset.py と ga_native_offset.py を t2i/ に置く。native_cache/ の距離サンプルを runs/ga_native240/ に置き、python -m t2i.ga_native_offset。baselines.npz は静的基準と生成統計の基準、residual-ridge.npz は選定した最終回帰。元の生成設定はInternalResearch 3991c688 の t2i/ga_native240.py を参照。
