# L01: 短いMDの長さに対して、指導力がどれだけ戻るかの曲がり具合（資料Dの条件、水素結合の形成、1 ns先）

- 確かめる仮説: H6（運動の生成そのものの問題）に関わる、「短い実MDを安くする」経路の L 系列の最初の実験。G02 では切り取りの長さが 0.1 / 0.25 / 0.5 ns の3通りだけだったのを、0.1 ns 刻みの11通りに増やし、長さに対して回復率がどう曲がるか（どこで頭打ちになるか、どこが一番効くか）を測る。
- 状態: 完了。回復率は覆う長さ 0.6 ns で初めて 0.8 と 0.9 の両方を超え（1.029）、0.7 ns で最大（1.145）になったあと、1.0 ns では 1.042 と少し下がる。増え分が大きいのは最初の 0→0.1 ns（+0.259）と 0.5→0.6 ns（+0.260）の2か所。

## 1. 何を確かめる実験か

実の 0〜1 ns の履歴を、始めの短い部分だけに切って使う。切り取りの長さを 11通り変え、各長さで「切り取りの平均だけ」を履歴の特徴量として資料Dの補正モデルに入れたときの 1 ns先の利得の回復率を測る。あわせて、各長さの回復率にタンパク質単位の再標本化によるブートストラップ 95% 区間を付ける。

読み方は先に固定した。

- 回復率 0.8 に届く最小の長さと、0.9 に届く最小の長さを出す。
- 0.1 ns 刻みごとの回復率の増え分を出す。分母はシミュレーションの長さで、増え分は「0.1 ns 長くしたときに回復率がどれだけ増えるか」で読む。
- 実測の費用への換算はしない。費用への換算は G04（短い実MDの実測）の後にする。L01 で出すのは「長さ（ns）あたりの戻り方」まで。

## 2. 条件

- 土台は資料Dの条件（水素結合の形成）と同じ。学習 1bgf_A・1ifg_A・1j8r_A・2b0a_A、テスト 1mix_A＋2qt4_A 合算、候補は学習 9,610件・テスト 4,972件（テスト陽性 290件）、起点フレーム10（1 ns）、履歴 0〜1 ns の11フレーム（100 ps 間隔）、予測幅 1 ns先、HistGradientBoosting（120回、学習率0.075、葉31、葉あたり最小15件、L2 0.02、種42）。距離はフレームごとの箱を軸ごとに扱う（キャッシュの取り出し時に適用済み）。
- K01 のキャッシュ（`~/workspace/kinescope/work/data_cache/` の 18軌道分の距離系列）を再利用した。新しい軌道の取得や生成器の読み込みはしていない。実行はローカルVM。

### 長さの呼び方（結果を見る前に固定）

長さは「覆う長さ」で統一する。軌道の保存間隔は 100 ps（0.1 ns）で、フレーム k は時刻 k×0.1 ns。覆う長さ L ns の切り取りはフレーム 0〜(L/0.1) を使う。

| 覆う長さ | フレーム | フレーム数 |
|---|---|---:|
| 0 ns | 0 | 1 |
| 0.1 ns | 0, 1 | 2 |
| 0.2 ns | 0〜2 | 3 |
| 0.3 ns | 0〜3 | 4 |
| 0.4 ns | 0〜4 | 5 |
| 0.5 ns | 0〜5 | 6 |
| 0.6 ns | 0〜6 | 7 |
| 0.7 ns | 0〜7 | 8 |
| 0.8 ns | 0〜8 | 9 |
| 0.9 ns | 0〜9 | 10 |
| 1.0 ns | 0〜10 | 11 |

覆う長さ 0 ns はフレーム0だけ、つまり履歴の最初のフレームの距離そのもの（平均を取っても値は同じ）。起点フレーム10（1 ns）は変えず、ラベルは 1 ns先（フレーム20）のまま。

G02 の呼び方との対応は次の通り。G02 は「時刻が切る長さ以下のフレームを使う」定義で、名前と覆う長さがずれる箇所があった。

| G02 の名前 | フレーム | L01 の覆う長さ |
|---|---|---|
| 0.1 ns | 0, 1 | 0.1 ns |
| 0.25 ns | 0, 1, 2 | 0.2 ns |
| 0.5 ns | 0〜5 | 0.5 ns |
| 平均だけ（0〜1 ns） | 0〜10 | 1.0 ns |

### 条件の一覧（1 ns先）

- 静的のみ: 静的特徴7個だけ。
- 全部入り（base_hist_D6）: 静的特徴＋実履歴6統計量（0〜1 ns の11フレーム）。回復率の分母（実履歴の利得）の参照。
- 切り取りの平均だけ: 静的特徴＋切り取りの平均だけ。覆う長さ 0.0〜1.0 ns の11通り。

回復率 =（その長さの AUPRC − 静的のみ）÷（実履歴の利得）。

## 3. ブートストラップの段取り（結果を見る前に固定、G49・G59 と同じ）

- 回数: 10,000回。乱数 seed: 42。区間はパーセンタイル法（2.5%点と 97.5%点）。
- 再標本化の単位: タンパク質。テストのタンパク質は 1mix_A（3,101件）と 2qt4_A（1,871件）の2つだけです。2つから復元抽出で2つ選ぶため、取りうる組み合わせは {1mix,1mix}・{1mix,2qt4}・{2qt4,2qt4} の3通りしかありません。ブートストラップ分布も3つの値しか取らず、95% 区間はその3値の最小値〜最大値になります。**テストは 2タンパク質だけなので、区間は粗い**（留保として記録する。G23・G49 と同じ）。
- 各ブートストラップ標本の中でも、静的のみ・全部入り・その長さの平均だけの AUPRC を測り直し、実履歴の利得と回復率をその標本の中で計算し直しました。モデルは学習し直さず、学習済みのモデルの候補ごとの予測確率（`test_predictions.npz` に保存）を再標本化しています。測っているのはテスト集合の取り方による揺れで、学習の揺れではありません。
- 計算の工夫は G49 と同じです。タンパク質が2つだけのため再標本化の標本は3通りの組み合わせのどれかでしかなく、回復率は組み合わせだけで決まります。そのため 3通りの組み合わせの値を正確に計算し、10,000回の抽出は組み合わせへの写像として行いました。行を並べ替えて AUPRC を 1万回計算し直す G23 のやり方と数学的に同じ結果になります。抽出の乱数 seed は 42 です。

## 4. 結果

### 土台の再現

1 ns先で静的のみ AUPRC 0.3637、全部入り 0.4815、利得 +0.1178 で、資料D・G02 の記録と小数第4位まで完全一致した。G02 と重なる長さでは、AUPRC と回復率が G02 の記録と一致した（覆う長さ 0.1 ns で 0.4308 / 0.570、0.2 ns で 0.4399 / 0.647、0.5 ns で 0.4544 / 0.770、1.0 ns で 0.4865 / 1.042）。

K21 の記録との照合について。K21 の「平均だけ」は 1 ns先で 0.957（マクロ）/ 0.975（ミクロ）だが、これは強い土台（K06(b)、参照の利得 +0.0712）での値で、土台と分母が違うため L01 の曲線とは直接比べられない。資料Dの条件で全長（1.0 ns）の平均だけを測ると 1.042 になり、G02・K64 の記録と一致する。食い違いは土台の違いによるもので、L01 の側の再現に問題はない。

### 先に固定した読み方への答え

- **回復率 0.8 に届く最小の長さ: 覆う長さ 0.6 ns**（回復率 1.029）。0.5 ns では 0.770 と届かない。
- **回復率 0.9 に届く最小の長さ: 覆う長さ 0.6 ns**（同じ長さで 0.8 と 0.9 を同時に超える）。
- 増え分が大きいのは 0→0.1 ns（+0.259）と 0.5→0.6 ns（+0.260）の2か所。0.2→0.3 ns（−0.001）、0.4→0.5 ns（−0.014）、0.7→0.8 ns（−0.040）、0.9→1.0 ns（−0.071）はわずかに下がり、単調な曲線ではない。

## 5. 読み取り

- **曲線は3段の形をしている。** 最初の 0.1 ns で 0.570 まで一気に上がり、0.2〜0.5 ns は 0.65〜0.78 の緩い上がり、0.6 ns で 1.03 へ跳ねて、0.7 ns の 1.145 を頂点に、その後は 1.04〜1.11 でほぼ頭打ち（わずかに下がる）。「短くするほど素直に悪くなる」曲線ではなく、0.6 ns のところに段がある。
- 0.8 と 0.9 の線はどちらも 0.6 ns で初めて超える。0.5 ns までは 0.78 が上限で、G02 の3点（0.570 / 0.647 / 0.770）だけでは見えなかった段が、0.1 ns 刻みで初めて見えた。
- ただし段の位置はタンパク質に強く依存する。1mix_A では 0.6 ns で 1.190 まで跳ねるが、2qt4_A では 0.850 で、跳ね方は小さい。テストが 2タンパク質しかないため、0.6 ns の段が一般の形かは L01 だけでは決められない。95% 区間も 0.6 ns で [+0.850, +1.190] と広く、0.5 ns の区間 [+0.770, +0.805] とは重ならないものの、区間自体が3値しか取らない粗いものだという留保がつく。
- フレーム0だけ（覆う長さ 0 ns）でも回復率 0.311 が戻る。履歴の最初のフレームの距離1点にも、利得の3割ほどの情報がある。
- 費用の側はまだ何も言えない。L01 の分母はシミュレーションの長さ（ns）で、実測の費用への換算は G04 の後にする。短い実MDを実際に回すときの平衡化の扱いも、G02 と同じくこの実験では測っていない（実の長い軌道の始めを切ったもので、短いMDを回し直したものではない）。

## 6. 判断できること・まだ分からないこと

- 判断できること: 資料Dの条件・1 ns先では、回復率 0.8 と 0.9 に届く最小の覆う長さはどちらも 0.6 ns。0.5 ns 以下では 0.78 が上限。増え分は最初の 0.1 ns と 0.5→0.6 ns に集中する。
- まだ分からないこと: 0.6 ns の段がタンパク質一般の形か（テスト 2タンパク質のみ）。0.6 ns より細かい刻み（フレーム単位では測っているが、0.55 ns のような中間の長さは 100 ps 刻みの制約で測れない）。他の予測幅・他の現象での曲がり具合。実測の費用に直したときの形（G04 の後）。
