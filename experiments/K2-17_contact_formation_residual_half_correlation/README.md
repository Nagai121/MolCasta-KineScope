# K2-17: K2-08 の問い（平均の残りが前半と後半で続くか）を接触の形成で測る

- 確かめること: K2-08 では水素結合の形成で残りの平均の前半・後半の相関が +0.703（GBM）だった。接触の形成では担い手が分散している（K27）ため、残りの続き方も違うかもしれない。
- 状態: 進行中。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-08 では、履歴の平均のうち静的な特徴量で予測できない部分（残りの平均）を作り、その残りが履歴の前半と後半で同じペアの値として続くかどうかを見た。水素結合の形成では、残りの平均の前半・後半の相関が合算ピアソン +0.703（GBM の残り）・+0.729（線形の残り）で、先に固定した 0.5 の線を超え、「担い手は前半と後半で続いている」と記録した。ここでは、同じ問いを接触の形成で測る。接触の形成では担い手が分散している（K27: どの 1 つの統計量を定数に置き換えても指導力の 0.88〜1.08 倍が残る）ため、残りの続き方も違うかもしれない。

測るものは K2-08 と同じく先に固定した。資料Dの条件のデータで、K2-08 と同じ形で残りの平均を出す（前半と後半の平均ごとに、K39 と同じ設定の GBM で静的な予測を作る）。前半（フレーム [0..4]）の平均の残りと、後半（フレーム [6..10]）の平均の残りの相関（ピアソンとスピアマン、合算とテスト 2 タンパク質ごと）を測る。比較のため、生の平均の前半・後半の相関も同じ形で記録する。

読み方は K2-08 と同じく先に固定した。相関の絶対値が 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」、0.3 未満なら「続いていない」と記録する。0.3 以上 0.5 未満の場合は、そのどちらでもない（中間）として数値をそのまま記録する。
