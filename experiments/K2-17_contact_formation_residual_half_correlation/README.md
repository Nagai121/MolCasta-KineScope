# K2-17: K2-08 の問い（平均の残りが前半と後半で続くか）を接触の形成で測る

- 確かめること: K2-08 では水素結合の形成で残りの平均の前半・後半の相関が +0.703（GBM）だった。接触の形成では担い手が分散している（K27）ため、残りの続き方も違うかもしれない。
- 状態: 完了。残りの平均の前半・後半の相関は、GBM の残りで合算のピアソン +0.719・スピアマン +0.711、線形の残りで +0.726・+0.721 だった。先に固定した読み方（絶対値 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」）に照らして、接触の形成でも、指導力を運ぶずれは前半から後半へ続いている。水素結合の形成（K2-08、GBM で +0.703）とほぼ同じ強さで、担い手が分散している（K27）にもかかわらず、残りの平均そのものの続き方は変わらなかった。

## 1. 何を確かめる実験か

K2 系列は「指導力の正体は何か」を探る系列。K2-08 では、履歴の平均のうち静的な特徴量で予測できない部分（残りの平均）を作り、その残りが履歴の前半と後半で同じペアの値として続くかどうかを見た。水素結合の形成では、残りの平均の前半・後半の相関が合算ピアソン +0.703（GBM の残り）・+0.729（線形の残り）で、先に固定した 0.5 の線を超え、「担い手は前半と後半で続いている」と記録した。ここでは、同じ問いを接触の形成で測る。接触の形成では担い手が分散している（K27: どの 1 つの統計量を定数に置き換えても指導力の 0.88〜1.08 倍が残る）ため、残りの続き方も違うかもしれない。

測るものは K2-08 と同じく先に固定した。資料Dの条件のデータで、K2-08 と同じ形で残りの平均を出す（前半と後半の平均ごとに、K39 と同じ設定の GBM で静的な予測を作る）。前半（フレーム [0..4]）の平均の残りと、後半（フレーム [6..10]）の平均の残りの相関（ピアソンとスピアマン、合算とテスト 2 タンパク質ごと）を測る。比較のため、生の平均の前半・後半の相関も同じ形で記録する。

読み方は K2-08 と同じく先に固定した。相関の絶対値が 0.5 以上なら「指導力を運ぶずれは前半から後半へ続いている」、0.3 未満なら「続いていない」と記録する。0.3 以上 0.5 未満の場合は、そのどちらでもない（中間）として数値をそのまま記録する。

## 2. 条件

- 資料Dの条件。接触の形成の候補ペア。学習は 4 タンパク質（1bgf_A・1ifg_A・1j8r_A・2b0a_A、15,926件）、テストは 1mix_A と 2qt4_A（7,384件）。起点はフレーム 10（1 ns）、履歴は 0〜1 ns の 11 フレーム。距離は残基ペアの重原子間の最小値で、境界は 4.5 Å。候補は起点で最小距離が 4.5 Å を超えるペア。
- 前半の平均は履歴フレーム [0..4] の最小距離の平均、後半の平均はフレーム [6..10] の平均（フレーム 5 は除く。K2-01・K2-08 と同じ分け方）。テストでの半分の平均は、前半 7.317 Å、後半 7.316 Å、全部の平均は 7.317 Å と、前半と後半でほとんど変わらない（水素結合の形成では前半 5.079 Å から後半 5.016 Å へ 0.06 Å 縮んだ）。
- 静的な予測は、接触の静的な特徴量（X の 5 列: 起点の最小距離、Cα間距離、配列距離の log1p、両残基の重原子数）から各半分の平均を予測したもの。線形回帰と HistGradientBoosting 回帰（K39 と同じ設定: 160回、学習率 0.065、葉 15、葉あたり最少 20、L2 0.15、seed 20261121）の 2 通りで、どちらも学習側の候補だけで当てはめ、テスト側の統計は使わない。残りの平均 = 半分の平均 − 静的な予測。
- 予測は半分ごとに当てはめ直した。形成の候補は原点に向けて距離が縮む向きに動くため、前半と後半では平均の水準が系統的に違う。全部の平均に対する予測をそのまま当てはめると、その水準の違いが残りに混ざるためである。
- K2-08 のスクリプトと同じ形で、X は保存されたままの型で sklearn に渡した（K13 の保存値は (N, 11) の向きで、転置は要らない）。sklearn の学習はスレッド数を 1 に絞って、この仮想マシンで実行した（半分の平均に対する回帰 4 件だけで、軽い計算である）。
- 当てはまり: 前半は線形で R² が学習 0.864・テスト 0.888、GBM で学習 0.873・テスト 0.887。後半は線形で学習 0.928・テスト 0.944、GBM で学習 0.933・テスト 0.943。テストでの残りの平均の標準偏差は、前半が線形 0.506 Å・GBM 0.509 Å、後半が線形 0.352 Å・GBM 0.353 Å。水素結合の形成（K2-08: 前半の R² がテストで 0.562、残り 0.642 Å）より、接触の平均は静的にずっと予測しやすい。

## 3. 結果

### 残りの平均の前半・後半の相関

| 残りの作り方 | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| GBM | +0.719 / +0.711 | +0.706 / +0.693 | +0.782 / +0.765 |
| 線形 | +0.726 / +0.721 | +0.712 / +0.702 | +0.792 / +0.779 |

### 比較：生の平均の前半・後半の相関

| | 合算（ピアソン / スピアマン） | 1mix_A | 2qt4_A |
|---|---:|---:|---:|
| 生の平均 | +0.973 / +0.973 | +0.965 / +0.963 | +0.990 / +0.990 |

生の平均の前半・後半の相関は +0.973 と非常に高いが、これはペアごとの水準（静的な特徴量で決まる部分）が両半分に共通に入るためである。静的な予測を引いた残りでも、相関は合算で +0.72（GBM）・+0.73（線形）と高く、タンパク質ごとでも 1mix_A で +0.71、2qt4_A で +0.78 と 0.5 を上回る。

## 4. 読み取り

先に固定した読み方に照らすと、残りの平均の前半・後半の相関は、GBM・線形のどちらでも、合算でもタンパク質ごとでも、ピアソンでもスピアマンでも、絶対値が 0.5 を上回った（最も小さい 1mix_A の GBM のスピアマンでも +0.693）。**指導力を運ぶずれは前半から後半へ続いている。** 水素結合の形成（K2-08、GBM で +0.703）とほぼ同じ強さで、担い手が分散している（K27）にもかかわらず、残りの平均そのものの続き方は変わらなかった。

接触の形成では、平均そのものの動きが水素結合と違う。前半と後半の平均は 7.317 Å と 7.316 Å でほとんど変わらず、原点に向けて縮む向きの系統的な動きは見られない。残りの標準偏差も前半 0.509 Å・後半 0.353 Å と、水素結合（0.642 Å・0.398 Å）より小さい。接触の平均は静的に予測しやすく、残りは小さいが、その残りの前半・後半の続き方は水素結合と同じくらい強い。つまり、残りの平均が前半から後半へ続くのは、水素結合だけの形ではなく、接触の形成でも同じである。

## 5. 判断できること・まだ分からないこと

- 判断できること: 接触の形成でも、残りの平均は前半と後半で続いている（相関は合算で +0.72〜+0.73）。指導力を運ぶペアごとのずれは、前半から後半へ続く。担い手が分散している（K27）にもかかわらず、残りの平均そのものの続き方は水素結合と同じくらい強い。接触の平均は水素結合より静的に予測しやすく（前半の R² がテストで 0.887 対 0.562）、前半と後半の平均の水準はほとんど変わらない。
- まだ分からないこと: ペアごとのずれが何の影なのか（水素結合では K2-03 の 4 つの候補で説明できなかった。接触ではまだ試していない）。ずれが窓の外でも続くのか。ずれが指導力にどう効くのか（この実験は相関だけを見ており、予測への寄与までは測っていない）。
