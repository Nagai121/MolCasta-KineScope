# MolCasta KineScope

分子軌道を予測器に入力することで予測精度が上がる能力を、ここでは「指導力」と呼びます。
KineScope は、実軌道が持つ指導力が、生成軌道やその処理の過程でどこで・なぜ・どのように失われるのかを調べる独立研究です。
性能の高い軌道生成器を作ること自体は目的ではありません。

## 分かっていることの要約

- 実軌道の初期履歴（0〜1 ns）を入力すると、水素結合形成などの予測は 90 ns 先まで一貫して良くなります（100% 公開特徴量・未見100配列の 5-fold CV でも、HB形成 1 ns 先 `+0.0944`・90 ns 先 `+0.0538`、接触形成 1 ns 先 `+0.2146`・90 ns 先 `+0.1437`：E01）。
- 指導力の 90〜96% は「平均距離（局所平衡オフセット）」1 本に集約され、独立レプリカ間で再現する本物の物理信号です（100 配列レプリカ床 `0.201 Å` に対し静的残差 `0.561 Å`、レプリカ間残差相関 `r = +0.39〜+0.57`）。一方、静的物理特徴量 5 系統を同時投入しても残差分散の 9% 程度しか説明できません（E02）。
- 単一静的フレームからの水なし `4×100 ps` 陰溶媒 MD 緩和（OpenMM GBn2, 55 秒/タンパク質）はこの静的特徴量の壁を突破し、顕溶媒残差 `r = +0.520`、下流 1〜90 ns 指導力の `55–86%`（mean のみ）／最大 `116%`（90 ns, 7統計量）を回収します（E03）。
- 公開 SOTA 生成モデル `MDGen`（`atlas.ckpt`, 40 秒/タンパク質, 厳密な未見 `atlas_test` 25 配列）は静的冗長（$R^2 \approx 0.96$）ではなく、短期 1 ns 緩和は弱い（`-5〜+25%`）ものの、100 ns 生成で 5〜90 ns 指導力の `55–78%` を回収します（E04）。
- 同一の厳密未見 49 タンパク質（`atlas_test.csv` `L ≤ 250` 全件）・全 6 現象（117,803 ペア）のペアード大規模追証では、水なし陰溶媒 GBn2 が H 結合（59–141%）および残基間接触（71–109%）で MDGen を 22/24 セルで有意に上回る一方、塩橋解離では MDGen が唯一残差整合（`+0.40/+0.33` vs `+0.26`）で逆転し、両者のハイブリッド（`GBn2 + MDGen`）が H 結合・長期接触解離・塩橋で統計的有意な上乗せ（最大 161%）を達成しました（E05）。
- 詳細は [FINDINGS.md](./FINDINGS.md) および `experiments/E01`〜`E05` を参照してください。

## 進め方

1. 実軌道を少しずつ壊す・要約する・粗くする加工実験で、指導力がどの条件でどれだけ落ちるかを測ります。
2. 生成軌道そのものの質（距離の分布や時間の相関など）を、予測を介さずに実軌道と比べます。
3. 土台と評価条件をそろえた再比較で、軌道の差と土台の差を切り分けます。
4. 単独の要因で説明できない場合は、複数の要因を同時に変える組み合わせを試します。

## 記録の置き場

- `FINDINGS.md` — 発見事項の英語サマリー（E01〜E04 の公開再検証アップデート含む）
- `docs/facts.md` — 既存実験から確認できた事実と、実験どうしの条件の食い違い
- `docs/hypotheses.md` — 原因の仮説の一覧、既存実験との対応、未検証の組み合わせ、実験の登録
- `docs/literature/` — 先行研究レビューと新規性監査（E01〜E04 の反映済み）
- `experiments/` — 実験ごとの記録（`K*`・`K2*`・`K3*`・`G*`・`L*`・公開再検証 `E01`〜`E04`。記録の約束は `experiments/README.md`）
- `notes/` — 参照元の調査ノート
